## 交什么

写 `底稿/神域/交稿/<份名>.md`，里头三种节，标题照下面的写法，一个字不差：

- `## 域｜<域名>`：你这一柱源稿里有的正神，一位一域，照全表的域名。翻页甲、翻页乙各写自己那六域。
- `## 纷争纪｜<名>`：纷争纪源稿里每一条一节。`<名>` 是源稿标题里「纷争纪·神谱｜」后头那一截，照抄（比如 `## 纷争纪｜未落之箭卡瑟蕾`）。正神、魔神都写。
- `## 月银纪｜<名>`：月银纪源稿里每一条一节，同样照抄标题后半截。
- 末尾一节 `## 备注`，随便写，不进卡。

节里只写「- 栏名：正文」这样的条目行（域条目另加一行 `触发词：`），不写别的。主会话拿脚本把神域栏插进源稿各条的「- 锁：」那一行前头，所以**不要重复前头已有的栏目**（是谁、样子、殿、高座在哪、倒下的经过、留下的），只添新东西。

另写 `底稿/神域/备注/<份名>.md`：新起了哪些名字（权柄、神国），哪几处拿不准，哪几处跟源稿对不上、你是怎么取的。

### 一、域条目（一域一条，汉字 220 到 400）

四纪和迷宫纪 1001 年共用一条，所以归属要把各纪说清。栏目：

```
## 域｜弓之域
- 这一域：弓与射艺，在离弦一柱底下，占一份。
- 正位：射出去的东西到得了。风偏不了它，雾遮不了它，隔着一道山也算数。在未落之箭卡瑟蕾手里。
- 逆位：射中了的伤好不了。箭拔出来，伤口从里面烂开，寻常的祷告合不上它。在不愈之镞勒莱耶手里。
- 三迹：必中，一支箭照祭司看见的那一处去。传讯，把一句话绑在箭上射向一个名字，箭落在那个人脚边。破障，一箭射穿一道术式立起来的墙。
- 相克：正位的奇迹合得上逆位的箭伤，逆位的箭穿得过正位护着的人。
- 归属：月银纪约3120年以前是一座空坛，卡瑟蕾在北境雪线下的谷里聚成以后是祂的。纷争纪5933年正位空，7166年逆位空。止戈以后正位落到风之璐璐薇身上，逆位挂在理之冠上，这一句只给 AI。
触发词：弓之域、弓这一域、弓手的祷告、朝弓起誓
```

- 正位、逆位那两句和三迹的名字照全表，句子可以润、可以添半句，不改意思。「相克」写这一域里具体怎么克，不抄样条。
- 归属：月银纪哪一年聚成（照月银纪源稿的「聚成」栏，开纪就在的写开纪就在），纷争纪哪一年空，止戈以后归哪一位柱神。逆位去向照全表「怎么读」那一段，例外四域照表。
- 柱神本域（两份的那一域）多写一句：这一柱十域今天都压在祂身上。
- 触发词三到五个，玩家嘴里会说的短语，不放神的名字。

### 二、纷争纪的神域栏（一位一块，汉字 240 到 440）

正神照这个样子（陨落的那一栏叫「陨落以后」，活过纷争纪的七位柱神不写这一栏）：

```
## 纷争纪｜未落之箭卡瑟蕾
- 神力：只给 AI。神力十二级，执柄。倒影不愈之镞勒莱耶同级。
- 神性：未落之箭，正位。本域是弓之域。
- 权柄一｜屏息：弓手开弓屏住那一口气的时候，祂看得见他看见的，他的箭借得到祂的眼力。长垒上三支弓手齐射以前那一息，整段墙的箭都算祂的，几万支箭照同一处落。
- 权柄二｜未落：祂射出去的箭不落地。祂不松念，箭就一直飞，绕过山，穿过云，隔着一片海也到得了。5933年最后那一箭是这一份。
- 神域专长：应名千里，神罚，神选。祂的神罚是一支箭。
- 神国：不落之空。一片没有地的天，脚下是云，射出去的东西永远在飞。国律是在这里什么也不落。国门是天下每一张拉满的弓，弦响那一下开一线。
- 陨落以后：神国塌在盐海上空，那一层天从此留不住云。弓之域的正位空到止戈。
- 对上祂：离祂越远越险，一千步以外祂没有射不中的东西。贴到十步以内，未落用不上，屏息也只剩半口气，不愈之镞那三箭就是贴着身射的。
```

魔神照这个样子（高座在哪前头已有，这里只写国律。倒下了的写「倒下以后」）：

```
## 纷争纪｜不愈之镞勒莱耶
- 神力：只给 AI。神力十二级，执柄，跟未落之箭卡瑟蕾同级。5933年以后高一级。
- 神性：不愈之镞，逆位。拿着弓之域的逆位。
- 权柄一｜……：……
- 权柄二｜……：……
- 神域专长：神威，神罚，赐名。……
- 国律：弓背岭方圆……里照祂的规矩走。……
- 倒下以后：……（高座散成了什么，祂的权柄有没有人拿。塔妮丝死在那一片地里，没有拿。）
- 对上祂：……
```

规矩：

- **神力**：起点照全表（域名后头括号里的级，倒影同级）。往后变了的写哪一年：杀了对面那一位、自己活着回去的高一级，十四级封顶。柱神七位纷争纪里十三到十四级，写一句止戈以后一样一样接了本柱的域、今天十七到十九级（璐璐薇十七，欧巴德斯十八，伊兹帕鲁特十九，库米罗妮十七，艾赫卡托尔十七，朱亚十八，耶万十七）。档的叫法：六到十级燃火，十一到十四级执柄，十五到二十级擎世。
- **神性**：尊号里最重的那一个，正位或逆位，再一句本域。
- **权柄**：执柄的神两份，一份也行，不写三份（例外见下面各份的话）。名字两到四个字，从祂的尊号、样子、做过的事里取意象（屏息、未落、无界之风、炉枷）。每份写它做得到什么，往大里写，写到天地和战局看得见的结果为止，再带一件源稿里祂真做过的事。正神和祂的倒影，权柄要成对，看得出一个是另一个翻过来的样子。
- **神域专长**：三到四枚，名字只能从规则层目录那二十四枚里取，逗号隔开写在这一行头一句，后头可以添一句祂怎么用。执柄的神学不了灭却和夺柄。
- **神国**（正神）：起一个名字，写国相、国律、国门，一位一幅只此一处的画面，跟祂的域和样子对得上。**国律**（魔神）：高座方圆多少里，一条只在那里成立的规矩，要叫玩家进去以前就得盘算。
- **陨落以后／倒下以后**：神国或高座塌成了什么，落在哪里，要跟源稿「留下的」对得上、不重说。谁杀的、拿没拿权柄，照源稿的史实，源稿没写的不编成有人拿了。
- **对上祂**：给主持的一段，祂强在哪、短在哪、拿什么克。短处要是真能打的口子。
- 神有性别、有样子的照源稿。**源稿里的年份、死法、谁杀的谁，一个字不改**，对不上的记进备注。
- 这一层给主持的 AI，可以直说。源稿里标了「这一层只给 AI」的事照旧标。

### 三、月银纪的神域栏（一位一块，汉字 120 到 240）

月银纪没有魔神，不写倒影和逆位。那一纪神自己也在往上走：

```
## 月银纪｜未落之箭卡瑟蕾
- 神力：只给 AI。约3120年聚成那一刻六级，燃火。信众是北境的猎户，到6007年坛上开口以前八级，往后弓手供祂的多了，纪末十一级。
- 神性：未落之箭。本域是弓之域，约3120年以前这一域是空坛。
- 权柄｜屏息：……（只写这一纪已经有的。第一份是聚成那件事里长出来的，名字跟纷争纪那一块的权柄一对上。到了执柄才有第二份，写哪一年前后凝的、凭哪件事）
- 神域专长：应名千里，神选。
- 神国：不落之空，这一纪还只有一道谷那么大。
- 对上祂：……（一句）
```

- 级怎么走：聚成那一刻六级。祭火到万兽那几千年信众是地域级，六到八级。6007年坛上的众神头一回彼此开口以后，信众到了国家、大陆，九到十二级。纪末的数要接得上纷争纪的起点（差一级以内）。开纪就在的老神开纪十一级。
- 行走相在月银纪一站几十年，源稿「样子」里的扮相就是行走相，不重写。

- **离弦**：璐璐薇、卡瑟蕾照样稿，专长名照规则层目录。塔兰迦约2700年剥了神性成了凡身，写清剥掉以后神力那一栏空了、权柄去了哪里（照源稿）。

- **翻页甲**：伊兹帕鲁特十四级。托纳修、乌姆拉十四级，管的是根上的事，日轮、海潮各占三份，权柄往天象上写。佛卡洛、比夫龙活过纷争纪。乌姆拉源稿里那句「祂不是魔神，跟深渊没有关系」照留意。

- **返青**：莫罗赫两份权柄，一份是吞（吞掉活人的饱足，越吃越饿），一份是献祭（拿活物换东西），名字你起，十三级，往后十四级。只给 AI 提一句山铜纪851年以后改了方向分成食梦和渡。
- **立边**：格莫瑞活过纷争纪。这一柱的权柄是运、兆、签、机缘，写成看得见的事（哪一仗的风向、哪一箭偏了），别写成说不清的概念。

## 写法

- 往大里写。神的权柄是看得见的大魔法，出手先写天地的反应。别把神写小，也别写成规则怪谈。
- 标点：不用 ——、—、；、…、！、...。冒号只在栏名后头。不用「」。对白用“”。
- 不写月相（新月、满月、月亮、月光这类字）。禁词表在 `tools/check_people_v7.py` 里，常犯的：时辰、登记、威压、修为、一丝、一抹、不禁、长老、能量、频率、系统、坐标、营（少用）。
- 神用祂。不点那一位恶神的名。四位执政的名字和「四执政」三个字不进卡面。
- 新起的名字（神国名、权柄名三个字以上的）跑一遍 `python -I -X utf8 tools/namegrep.py 名字1 名字2 …`，报「无」或者只在 底稿/神域/ 里有才算没撞。一柱之内权柄名、神国名不重字架子。

## 自查

写完跑 `python -I -X utf8 底稿/神域/tools/check_jiaogao.py <份名>`（在仓库根上，Windows，Python 要带 `-I -X utf8`）。要：三种节的数对得上，结构问题 0，cardscan 合计 0，硬问题合计 0，ngram hits 0，字数都在范围里。不是 0 就改到 0。

最后回话只要几行：交了几域几块，新起的名字有几个，备注里最要主会话看的两三处。
