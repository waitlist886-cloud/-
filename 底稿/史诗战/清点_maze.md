# 迷宫纪前传史诗战清点（迷宫纪2年到1000年）

用途：给主会话照底卡 #1099 的写法起名号、起阶段后缀用。这是只读清点，仓库一个字没动。

## 〇、记法和口径

### 〇.1 记法

- 页名简写。下面六页都在 /home/user/-/迷宫纪前传/：
  - p1 = 迷宫纪前传时段_一_探井的年月.md
  - p2 = 迷宫纪前传时段_二_共约的年月.md
  - p3 = 迷宫纪前传时段_三_繁荣的年月.md
  - p4 = 迷宫纪前传时段_四_深井的年月.md
  - p5 = 迷宫纪前传时段_五_黑潮的年月.md
  - p6 = 迷宫纪前传时段_六_垂暮的年月.md
- 补卷写成「补卷_NN:行」，文件在 迷宫纪前传/补卷/。委托写成「委托:行」，指 迷宫纪前传/迷宫纪前传_委托_第一版.md。
- 行号规则：「位置」一栏给的是条目标题行，就是 `## ` 那一行；引文后括号里的行号是那一句所在的行。
- 引文照抄原文，「…」是我省掉的部分。原文自带的（★）、（#NNN）照抄。
- 「推定」是我拿底卡 #1110 对出来的，原文没有这样写。「只给 AI」照原文。
- 设计备注、方向稿、说明、计划、起名簿一律没算。只有一处在备注里顺带提了一句，已经注明。
- 神名照 底稿/神名/神名表.tsv 现行写法。

### 〇.2 前传里史诗战的年份（补卷_17:5，迷宫纪·规则｜史诗战与生死）

- 2年到约397年：没有雾门，也没有圣歌。原文：“七八层上下头一回撞见守着一层不走的大东西，早年管它叫守层的。门槛是下到那一层的楼梯口，或者阶顶…守层的不离那一层，往楼梯上退，它不追（★）。”
- 约397年（补卷_17:11）：圣歌头一回响，在第二十五层，“塔隆顶住白地上那一台砸下来的一拳…往后公会管这支歌叫圣歌。这以后…守层的跟前有时会响，响不响、为什么响，没有人说得准，叙述只写听见了歌。”
- 约600年：层间起雾，约650年连第一层底下也有了。原文：“楼层主跟前那一道更白更静，穿过去就开打，分出结果以前穿不回来。”死在白雾门里、歌响着的时候倒下的人，有的会在旅印大厅门口醒过来，620年吉迪恩就是这样醒的。
- 784年：楼层主和圣歌写进冒险者法典，旅印大厅添首杀板。原文：“穿过楼层主的白雾门圣歌必响，一段浮起一道线，首次复活庇护是歌的底，同一个楼层主只头一回作数。”第五十二层那一份764年已经用掉（补卷_17:13）。
- 850年起是黑潮。852年起有只收传奇的斩首单子。原文：“黑潮里长出来的大东西跟前也起白雾门，852年第三十层往下那一道是头一道。”（补卷_17:14）
- 866年白碑第七夜：七道线同响，只这一回。原文：“七道线的名字从这一年往后才叫得出。”（补卷_17:15）
- 史诗战卡（补卷_17:25）：“约397年以前圣歌那一行写无，866年以前那一行不写线的名字，只写响没响、这一段是要扛还是要跑（★）。首次复活庇护那一行，600年以前写无，600年到784年写不知道，784年以后照引擎（★）。”
- 五座迷宫城（补卷_17:25）：“队里有没有传奇，层主是两个样子。”补卷_08 写明这几座城的楼层主前传里没有人见过，见第二节。
- 名号（补卷_17:35）：“名号由别人叫开，公会记得下名号，替不了世界去认。”
- 俗名和名号的层次：
  - 第一项_规则:102：“浅几层的守层东西叫人反复撞见、记过，册子上有俗名，越往下越只剩整段的名号，再往下就没有第二个人写过报告。楼层主这个叫法是深井的年月里在井口叫开的。”
  - 补卷_16:14 说法相同，另加一句：“层带的名字是往后才起的。”
- 敌情卡的档（补卷_16:10）：“寻常的东西当 E，成群的当 D，极境当 C，英雄当 B，传奇当 A。”下文的「敌情卡上它当 B」照这个读，就是英雄那一档。
