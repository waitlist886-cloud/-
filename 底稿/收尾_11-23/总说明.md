## 规矩

- **只动你那一份名下的文件。** 别的文件发现了毛病，写进备注，不动手。
- 各页有分段源稿的（纷争纪 `纷争纪/parts1` 到 `parts7`，山铜纪 `山铜纪/parts1` 到 `parts6`，前传 `迷宫纪前传/parts1` 到 `parts6`），**改分段源稿，再拼页**，不要直接改拼好的页。拼页：
  - 纷争纪 `bash tools/assemble_strife.sh N`
  - 山铜纪 `python -I -X utf8 tools/assemble_shantong_pN.py .`（N 是 1 到 6，一页一支）
  - 前传 `python -I -X utf8 tools/assemble_maze.py . N`
- 受保护的行不动：条目设置、固定锚定、底座、体态数据、`## ` 标题、`### ` 星标题。这一轮点名要改的（黑名单、底座的档、星名）可以改，改了哪一行写进备注。改完拿 `python -I tools/check_protected.py 改前.md 改后.md` 对一遍（改前的用 `git show HEAD:路径 > 临时文件` 取），差出来的只能是有意改的。
- 卡面检查，改过的每个文件都跑，硬问题不能比改前多：
  - `python -I -X utf8 tools/cardscan.py 文件`
  - `python -I -X utf8 tools/check_people_v7.py 文件 .`
  - `python -I -X utf8 tools/authormark.py 文件`
  - 新名字：`python -I -X utf8 tools/namegrep.py 名字…`、`python -X utf8 tools/collide.py 名字…`
- 不提交 git，不推送，不动 CLAUDE.md。主会话收稿以后统一提交。
- 这台机器是 Windows 加 Git Bash：跑 Python 用 `python -I -X utf8`；Bash 的 heredoc 会把 Python 里两个反斜杠剥成一个，带反斜杠的脚本用 Write 工具写成 .py 再跑；`python -c "…"` 的双引号里别带反引号。临时脚本和临时文件放你自己的临时目录里单开的子目录，别放仓库里，别往 out/ 写。
