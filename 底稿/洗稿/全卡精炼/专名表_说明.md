# 专名表｜审补卷的人顺手交的一份表

审完一份补卷（羁绊、支线、地点、人物、装备这一类文件）的洗稿以后，替主会话把这一份里的专名盘成一张表。只盘不改：不动 `稿/`，不换名字。

## 为什么要这张表

用户 11-15 要“扫一遍专有名词（命星、武器、任务名称、地名），看看有没有不够西幻的，不用全改，针对性的改”。判法（方向稿第六节）：

1. 读出来是一句大白话、一个动作的白描的，要改（补桥、留碗、推不动；床脚又湿了；那一车送错了墙）。
2. 是一件东西、一个意象的留，哪怕只有两个字（锤歌、炭字、雾结）。
3. 拿口语的日用品直接当名字的，抬成雅称（补锅之章是行釜之章，软皮鞋之章是霜履之章）。
4. 乡土的通名（沟、坡、岗、洼、坪、屯）换成西幻里通行的（谷、丘、原、台地）。只在一两个文件里出现的小地方才动，上了时代地图的大地名不动。

## 交什么

在活的文件夹里写 `专名表_<文件名去掉.md>.tsv`（UTF-8，制表符分栏，头一行是栏名）。这一份文件里每一条有 `## ` 标题的条目一行，照先后。

| 栏 | 填什么 |
|---|---|
| 文件 | 文件名 |
| 类 | 羁绊、支线、地点、城邦、人物、装备、名器、规则、风土……照标题里“纪·类｜”那一截 |
| 条目名 | 标题里“｜”后头那一截，一个字不改 |
| 题 | 条目里 `题：`、`- 题：`、`专属羁绊：` 那一行现有的题或者章名，没有写“无” |
| 是什么 | 二十个字以内：这一条讲的是哪一件事、哪一处地方、哪一样东西 |
| 落点 | 这一条最要紧的那一样东西或者那一下（起题、起名要落在它上头），二十个字以内。羁绊写这个人这一章落在哪件事上 |
| 白话名 | 是或者否。条目名、题、章名里有一个照上面第 1、3、4 条该改的，就是“是” |
| 哪一个 | 白话名填“是”的，写清是哪一个名字（条目名、题还是章名），原样抄出来 |
| 备注 | 可以空着。想到合适的名字可以写（不强求）；这个名字别的条目也用着的，说一声 |

支线条目名是“地名·一句话”那种（“网岛·拍一拍石人的肩膀”）又没有题的，白话名填“是”，哪一个那一栏抄“·”后头那一截，主会话会给它补一个题。
