# 命星表｜给审稿的人顺手交的一份表

审完一份洗稿以后，你已经把这一页的主线、旅伴、人物和命星都读过了。趁这个，替主会话把这一页的命星盘成一张表。只盘不改：不动 `稿/`，不换星名，不起新名字。

## 为什么要这张表

用户 11-16 定的，原话：“许多人的那颗special命星也可以斟酌下修改，命星映照出的应该是这个人的命运，宿命。比如麦伦，他的那颗命星应当与他那屠龙的命运呼应。”

主会话的读法：

- **Special 是命。** 这个人这一辈子落在哪一件事上（麦伦是屠龙，希尔妲是向长夜讨回一个春天），这颗星的名字和头一句应当照得见那件事，回头看像一句谶语。
- **Passive 是身子。** 生来的体质，直说就行。
- **Art 是手艺。** 学来的、传下去的一门。

另外，三类星的名字里有一批读出来是一句口语半句或者白描的动宾（补桥、留碗、推不动、熬得住），要挑出来换成正名。是一件东西、一个意象的不算，哪怕只有两个字（锤歌、炭字、雾结、裂晓）。

## 交什么

在活的文件夹里写 `命星表.tsv`（UTF-8，制表符分栏，头一行是栏名）。这一页（这一份活里的每个文件）里每一颗有 `### 名字 (类 | 档)` 标题的星一行，照页上的先后。能力那一行里借来、这一页没有星条的星不列。

| 栏 | 填什么 |
|---|---|
| 文件 | 文件名，比如 第四歌_雷纹豹裘.md |
| 持有人 | 这颗星是谁的（照星条和旅伴、人物条的能力那一行）。几个人都有的写全，顿号隔开 |
| 星名 | 照标题，一个字不改 |
| 类 | Special、Passive、Art |
| 档 | Epic、Legend、Unique、Rare |
| 它是什么 | 照星条头一句，二十个字以内说它是什么本事 |
| 这个人的命 | 只给 Special 填。正史里这个人这一辈子落在哪一件事上，照他的“正史里的下场”、主线的默认收束、这一页的歌，三十个字以内，带年份。几个人共用的星，挑最要紧的那位写，备注里说一声 |
| 映不映 | 只给 Special 填，三选一：映着、沾边、没映。映着：星的名字或者头一句讲的那件本事，正是他命里那件事用上的，或者像那件事的预兆。沾边：本事在那件事里用得上，可是名字和头一句看不出来。没映：星讲的是另一样本事，跟他落在哪件事上没有关系 |
| 白话名 | 三类星都填，是或者否。是：名字读出来是一句口语半句或者白描的动宾 |
| 备注 | 可以空着。比如：这颗星别的页也借；标题上的档跟正文写的对不上；他还有一件更要紧的事也可以算他的命；你想到一个合适的名字（不强求） |

样子（制表符这里拿｜代着）：

```
文件｜持有人｜星名｜类｜档｜它是什么｜这个人的命｜映不映｜白话名｜备注
第七歌_焚原断刃.md｜麦伦｜不折之腰｜Special｜Legend｜弯着腰割到最后一垄也不直起来的那股劲｜1693年崖上三日，拿半截断刃楔穿焚原的龙颅｜沾边｜否｜屠龙那一下就是割最后一垄的架势，名字里看不出龙
第七歌_焚原断刃.md｜麦伦｜眠山血脉｜Passive｜Legend｜眠山村纳贡那一户生来不怕红火的身子｜｜｜否｜
第七歌_焚原断刃.md｜麦伦｜刈穗｜Art｜Rare｜千穗原上收麦的镰法｜｜｜否｜
```

## 判的时候

- “这个人的命”照正史写，就是玩家不插手时他会走到的那一步。活到老死、没有哪一件事特别重的人，写他最让人记得的那一件（凝名的那件伟业、歌里唱他的那一句）。实在没有，写“无大事，某年老死”。
- 判映不映只看名字和头一句，不看后面的效果栏。拿不准写沾边，备注里说为什么。
- 白话名那一栏别管它好不好听，只看是不是一句话或者一个动作的白描。
