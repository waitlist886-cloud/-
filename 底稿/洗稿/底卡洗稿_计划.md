# 底卡洗稿的写法（10-25，六批共用）

> 照 底卡洗稿与命名重审_方向稿_第三版.md 第一节写。用户回了第三版“这一版可以了，做得很好”，第一节第2条的留和改、样稿一二六、六批的分法都算定了，第七节第2件（系统那一批只动标点和禁词）、第8件（关系到设定的月相字、奶茶墨镜那一类留着）照倾向走。这一份是各份共用的写法，一份洗清单上自己那一节的条，写进清单给的那一个文件。

## 一、底本和清单

- 底本是打完补丁的那一版底卡，就是打好的卡前一千三百九十七条，照 #号排。补丁有 v7 到 v9 的进卡补丁、patch_truth、patch_strife、patch_bronze。清单（底稿/洗稿/底卡洗稿_第N批_清单.md）是拿 tools/wash_manifest.py 从底本出的，一条一行写着 #号、文件夹、标题、字数、底本哈希。
- 底卡源文件 src/rili_v7.json 不动。洗稿是一层，打包时套完补丁最后套，哈希对不上就停下来报，不悄悄盖掉。
- 拿底本：`python3 -I -X utf8 -c` 读卡，找到第一个元素带 content 的那个列表，取第 #号 个的 content。清单头一行写了是哪一张卡。

## 二、洗稿文件的样子

文件开头一节写这一份的说明（不进卡，打包只读 `## #号` 起的节）：洗了几条、哪几条没动和为什么、新起的★、拿不准要主会话定的。往下一条一节：

```
## #885 凡世至强：光辉顶点 · 莱恩哈特·奥兰（Reinhardt Orlane）
- 底本哈希：0123456789ab
- 添触发：（有新添的触发词才写，顿号隔开，没有就不写这一行）
- 放行：圣座巅峰、东境军权最高支柱（有意删掉的名词串，wash_check 报少了的时候照这里放行，没有就不写）

````
（洗过的整条正文，头一行标题一字不改，用四个反引号围起来）
````
```

- 只写动了的条。通篇已经是人话、只差一两个标点的也写进来，改标点。一个字都不用动的不写，在说明里列出来。
- 整条写全，不写片段。打包拿整条换。
- 正文里不留（★）这一类给作者看的记号，新起的设定写进文件开头的说明。名字里带禁词的（底卡命星龙裔威压、#152 的 Feat 能量抵抗这一类）不改，在说明里列出来。

## 三、留什么

- 事一样不丢：人名、地名、年份、数、位阶和 LVL、亲属和师承、谁做了什么、裁定锁里每一条硬规矩。
- 标题行（头一行）一字不动。固定锚定那一行一字不动。
- 状态栏那一行（状态栏：Feat ★…）一个字符不动，前端正则读它。
- 好感增减的加、减、坎、破裂、不换五个栏目照旧，栏里的话可以改标点和两三个字，分数不动。
- 卡里自己定义过的结构词照用，#1302 羁绊生成规则写明了是给 GM 看的：核心结、核心钩子、蝴蝶钩子、节点、兆、伏线台账、临界蓄势、冠名、Feat、上位存在、几级代理。主线、羁绊、探索那几个文件夹靠它们跑。
- 命星名、传奇之名、条目标题、触发词不改（底卡的命星只有古龙元素王息仪轨改秘仪，在第五批）。
- 写得好的段落不动。人间侧、好感增减有不少已经是人话，碰上了只改标点。
- 「」里引的是系统提示词里的段落的（裁定锁、统一运行驱动这一类），留着。

## 四、改什么

1. 六个设计文档栏目换名字：

| 现在 | 换成 |
|---|---|
| 可牵引线索 | 人物写「相关的事」，地方写「能接的活」 |
| 【后台能力收录｜AI一致性锚点】 | 【能力｜X】，X 是这个人的名字，跟【独立声口｜X】【好感增减｜X】一个样子 |
| ### 主线接口 | ### 在主线里 |
| 首个高影响场景 | 头一回碰上 |
| ### 离场自转、玩家离场后 | ### 玩家不在的时候 |
| 声口补锚 | 并进台词样例 |
| 原创台词样例 | 台词样例 |

2. 名词串拆成事：他管什么，做过什么，别人怎么看他。拆不出事的那一截删掉，删掉的写进放行。样子照样稿一：帝国大元帅、东境军权最高支柱，写成晨曦帝国大元帅，东境的兵归他调。
3. X线：能说成事的说成事（圣座巅峰压制线，写成圣座一档的对手打上门来，晨曦先派的是他），说不成的删。撤离线、防线、战线、补给线、海岸线是真东西，留着。羁绊线、世界线、政治线、神迹线、主线六线这一类，规矩条目里给 GM 看的照留，叙述里的拆。
4. 抽象大词（核心、机制、叙事、体系、支柱、锚点、底层、母题）在叙述里换成事，规矩条目和结构词里的照留。
5. 金句收尾删掉，收在那件事最后一个画面上。不是A而是B一条里至多留一回。凝名伟业收在金句上的，照样稿一换成一个人说的一句话或者一个画面，名字从哪里叫开的有来路就写上，没有就收在画面上，别新编一个出名的人。
6. 那一句抄了三十几遍的套话（她注意的是眼前真正要紧的那件事。X、Y、Z这类词只在她真的在做那件事时出现……），每个人照自己写一句：他进门先看什么，什么事总绕回去，平常聊什么。样子照样稿一的观察与用词。
7. 标点照卡面口径：破折号、分号、省略号、感叹号不用，对白用“”，加粗只留性格底色那一行。冒号只在标签行，标签八个字以内，长了用｜（技艺【奥兰光剑术】｜…）。斜杠串起来的地点和名字拆成句子（样稿二）。
8. 禁词照 tools/check_people_v7.py 那张表在叙述里换（系统、登记、军令、流程、坐标、时辰、编制、长老……）。规矩条目里给 GM 看的词、条目标题里的不动。军功核验全卡统一成军功评定（军功核验官长改军功评定官长），别处的核验照上下文改成查验、核对（10-26 试洗定的）。丈和算盘留着，我们自己的页上也用丈。月相字只洗修辞里的，关系到设定的不动（月光庇护、镜湖未竟城满月才出现、双月内海、月下生）。迷宫纪魔导都市的奶茶、墨镜、口罩、漫画、游乐园留着。
9. 引别的条目，「」里只写真的条目名（底卡的标题，或者标题｜前头那一截）。（见「X」「Y」「Z」）一条里至多留一处。对不上任何标题的，对上真标题；对不上的当寻常的字写，去掉「」。对白放在「」里的改成“”。
10. 东方语感和中式口语照写作口径换（旧字换词表_10-20.md）。菲伦嘴里叫芙莉莲的师父改老师（#815、#1313、#1364，#1364 标题行照底本留着菲伦师父）。
11. 人名写成名·姓，照底卡别处给的姓。底卡有几处写成名·称号（亚历山大·白鲸、索林·神代炉心这一类），改回名·姓，称号要留就另写一句（10-26 第三份 #926 照这个改了九处）。

洗完的口气照样稿一、样稿二：短句和长句掺着，主语清楚，一件事一件事说，不替人下判语。别洗成我们各页旅伴条那样的格式，底卡的栏目照底卡。

## 七、检查

一份写完自己跑：

1. `python3 -I -X utf8 tools/wash_check.py 底卡洗稿/你的文件.md --dump 临时/正文.md`：有问题的条 0。少了的东西是有意删的，写进那一条的放行。还剩的标点只数标题行以下，标题行照底本，带着分号也不报。--dump 出来的正文每条前面有「## #号 标题」，标题行不在里面，人物羁绊这种不以「## 」起头的条 check_people_v7 也查得到（10-26 改的）。
2. `python3 -I -X utf8 tools/check_people_v7.py 临时/正文.md .`：硬问题 0。剩下的只许是规矩条目里给 GM 看的词和关系到设定的月相字，在说明里一条一条列出来。
3. `python3 -X utf8 tools/ngram.py 临时/正文.md 语料`：0。
4. 洗前洗后的破折号、分号、八股词、禁词，wash_check 末两行有，抄进说明。
