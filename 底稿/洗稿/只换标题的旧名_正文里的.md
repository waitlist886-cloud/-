# 只换了标题的旧名，正文里还剩的地方（10-26）

第4步换名时，两三个字、本身就是寻常话的旧名一百五十二个（底稿/洗稿/只换标题的旧名.txt）只换了星标题和【】，正文里的照留。这里把这些旧名在现行源稿正文里出现的地方一处一处列出来，第5步去模板时各份照自己那几个文件逐处看：

- 说的是这颗命星（他用的那一门、她生来的那一份、那颗星亮了），换成新名字。名字放进句子里读不顺的，改句子，别硬塞。
- 说的是寻常的事（接火是接过火种，虎口是手上那一处，照影是照一照影子，推杆是推一根杆），不动。
- 拿不准的照这一句的上下文定，定不了写进回报。

条目设置、设计备注、改名经过的行不在单子里，不动。行号是 10-26 换名以后的，改了前面的行，往后的行号会挪，照引的那一段找。
