# 去八股往深里改：批次_16凡世至强_六（11-09）

洗的是 `底卡洗稿/批次_16凡世至强_六.md` 二十八条（#968 到 #995），全是遗物条，没有人物条，也没有「前传的局」「山铜纪的局」那几节。照派活说明第〇节往深里改，下手的是器物描述、来历（各条 ### 底下的故事）、效果和使用规则，【调用】【名】两行也换开写了。文件开头那一节是上一轮的说明，没动。

这一份里不动的先说在前头：标题行，状态栏（遗物条没有），## 和 ### 小标题（一个没增、没删、没挪），条目设置外的 `- 底本哈希：` `- 放行：` 两行，附表一的统一句（【用途】二十八行、【品阶判据】二十八行、“不复活，不显灵，不以英灵的样子正面登场。”二十三处），数值那一行的数，遗物名、品阶、效果的数和冷却，主会话写进来的几句锁（见第三节），还有对白和引语块（只改了一句台词，是第二节第1条那一处）。

## 一、改前改后（十七处）

1. #968 凛塔银羽，器物
   - 改前：一杆真银长枪。银是好银，整杆枪却是黑的。不是火烧的，也不是锈的，是渗进去的，洗不掉。／枪颈上本该缀一簇银白的羽饰，羽早没了，只剩下扣它的那一圈卡箍。
   - 改后：一杆真银长枪。银是上好的银，整杆却黑透了，那黑是从银里头渗出来的，火烧不成这样，锈也锈不成这样，拿什么都洗不掉。／枪颈上本该缀一簇银白的羽饰，羽早没了，扣羽的那一圈卡箍还空着。
   - 为什么：“不是…也不是…是…”先立两个靶子再推倒，改成直说它怎么黑的；末句落在空着的卡箍上，跟使用规则“银羽不得补上”对着。

2. #968 凛塔银羽，三十年
   - 改前：他没想报仇。至少一开始没有。（空行）他只想知道一件事，哥哥最后看见了什么。（空行）三十年里，他把那件事一环一环拆开。那天在场的人，后来调走的人，忽然富起来的人，忽然死了的人。／他一环一环走过去，走了三十年。
   - 改后：起先他没想报仇，他想知道的只有一件，哥哥最后看见了什么。他把那一天拆成一环一环，那天在场的人，后来调走的人，忽然富起来的人，忽然死了的人，一个一个找过去，这一找就是三十年。
   - 为什么：五行单句里“一环一环”“三十年”各说了两遍，并成一段一遍；“至少一开始没有”是倒装的找补，收进“起先”两个字。四种人一个没少。

3. #969 穿石之掷，开头
   - 改前：他是个异乡人。（空行）他原本是个了不得的人物。故国没了以后，他一路往北走，走到雪线上，把随身带着的旧兵器全扔了。／那个人，他不想再当了。
   - 改后：他是个异乡人，在故国的时候是个了不得的人物。故国没了，他一路往北走，走到雪线上，把随身那几件旧兵器全扔了，从前那个了不得的人，他不想再当了。
   - 为什么：“那个人”单起一行，读着像另有一个人，写明是从前的自己；三处单句段并成一段。

4. #972 角上狼烟，她的活
   - 改前：那位少主要做的事很大。大事要往前走，就得先把挡在路上的东西一根一根拔掉。（空行）拔钉子的是她。（空行）她做的不是打仗，也不是明面上的争，是那些做完了谁也不会说出口的事。叫一个人改口，叫一样东西不见，叫一个夜里的动静在天亮以前收拾干净。
   - 改后：少主想做的是一件大事。大事要往前走，路上的钉子就得一根一根拔掉，拔钉子的就是她。她做的事打不了仗，也摆不上台面，做完了谁也不会提，叫一个人改口，叫一样东西不见，叫夜里的一阵动静在天亮以前收拾干净。
   - 为什么：“不是…也不是…是…”改成直说；“挡在路上的东西”和下一行的“钉子”是一样东西说了两遍，并成钉子。三个“叫”是三样不同的活，留着。

5. #973 外邦银杖，她做的事都是实的
   - 改前：有三回荒年，是她撑过去的。靠的不是祈祷，是她自己算清了粮从哪里来，走哪一条路，先给谁。……（空行）论动手，她也不弱。只是她极少动手，旁人常常忘了这一点。
   - 改后：三回荒年都是她撑过来的，她不靠祈祷，粮从哪里来，走哪一条路，先给谁，都是她自己一笔一笔算清楚的。……（空行）论动手，她并不比谁弱，只是难得出手，旁人常把这一点忘了。
   - 为什么：“靠的不是…是…”直说。“很能打，旁人常忘了”在 #973、#975、#984 三条里一个架子，换开写（#975 落在她在路上从不先动手，#984 写成“认识他的人多半想不起他还有这一层”）。

6. #976 锁与半句，开头
   - 改前：那时候，神明还在大地上走。（空行）她是个凡人，个子不高，穿一件大得过分的外袍，说话很快。（空行）她做成过一件事。那件事以后，再没有人问她凭什么站在那里。（空行）有一年，一座城的底下有东西往上来。城要弃了。／她用了九天。（空行）她把地底下所有的口子照一个次序锁死。她没有去堵，她叫它找不到出口。／它出不来，一直到城里的人全撤空。
   - 改后：那是神明还在大地上行走的年月。她只是个凡人，个子不高，裹着一件大得过分的外袍，说起话来很快。凭什么站在那里，起先也有人这样问她，后来她做成了一件事，就再没有人问了。（空行）那一回，一座城的地底下有东西正往上来，城眼看就要弃了。她只用了九天，把地底下所有的口子照着一个次序一一锁死。她并不去堵，只是叫它找不到出口，它怎么也出不来，城里的人就这样一直撤到撤空。
   - 为什么：十行一事一行，读着像一摞卡片；并成两段，拿“那一回”把“做成过一件事”和九天锁城接成同一件事，前后的因果读得出来。

7. #977 长夜一灯，压
   - 改前：压得住的人极少，她是一个。（空行）压，也不是坐着就压得住。（空行）以太病要往外溢的时候，得有人站到最前头，把它顶回去。／她一个人顶过十九回。
   - 改后：压得住的人极少，她算一个，而且压也不是坐在床边就压得住的。以太病往外溢的时候，得有人站到最前头把它顶回去，这样的事她一个人做过十九回。
   - 为什么：四个单句段并成一段，“压，也不是……”单起一行的找补收进前一句；“坐着”落到病房的床边，是收容处里看得见的样子。

8. #979 万象秤杖，三币（这一处同时是底本自己拧着的，见第二节第1条）
   - 改前：三币圣约以后，钱是这样的。（空行）赤金巴尔，正面铸着魔王的侧影。／月银索恩，铸的是那一位的名。／山铜便士，最小的那一种，铸的是万象众生，没有脸。……> “我不想每天摸他的脸。”
   - 改后：三币圣约以后，通行的钱分成三种。赤金巴尔，正面铸着魔王巴尔缇娜的侧影，月银索恩，正面铸着圣君索恩薇娅的侧影，最小的山铜便士上铸的是万象众生，没有一张王者的脸。……> “我不想每天摸那两张脸。”
   - 为什么：照 #132 统一货币体系的形制改，她不用的两种钱上各有一张脸，那句话跟着对上。

9. #985 暗巷歌谱，这个人不存在
   - 改前：这个人不存在。（空行）没有失传，也没有被谁抹掉，是从来就没有过。／词是她编的。她自己也说过，说了很多回，没有人信。
   - 改后：这个人不存在，世上从来就没有过他，谈不上失传，也用不着谁去抹。词是她编的，这话她自己说过很多回，没有人信。
   - 为什么：“没有…也没有…是…”的架子，先下结论，两个否定跟在后头收住。

10. #988 门上之铃，三个人
    - 改前：一个耗着，他认为门都是等开的，不是撬开的。他在深层一处地方等出过一样谁也没见过的东西，等了两年。
    - 改后：还有一个耗着，他认定门都是等开的，撬是撬不开的，在深层一处地方，他守了两年，等出过一样谁也没见过的东西。
    - 为什么：“不是…是…”换成他自己会说的话；原来三个人三行同一个“一个”起头，并成一段，第三个用“还有一个”收。

11. #991 引路火矢，他放的是路
    - 改前：信号放一回就够了，他放的不是信号。／他放的是路。援军看不见城，看得见天上每隔一刻亮一下的那一点，照着那一点走，就是一条直线。
    - 改后：他放的是路，信号放一回就够了，路得一直放下去。援军看不见城，却看得见天上每隔一刻亮一下的那一点，照着那一点走，就是一条直线。
    - 为什么：“不是信号，是路”先推倒再立，改成直说两样差在哪，信号一回就够，路得一直放，这正是使用规则那一条守着的事。

12. #993 松林之赠，收下弓
    - 改前：他收下了弓。（空行）然后他拿它射了三十年。（空行）他没有背信，他从来没有答应过她。／他只是收下了。他真心以为，他接着打下去，才能让更多的地方不再有仗打。
    - 改后：他收下了那张弓，然后拿它射了三十年。说他背信是冤枉的，他从来没有答应过她什么，只是收下了。他真心以为，他接着打下去，才能让更多的地方不再有仗打。
    - 为什么：五处单句段并成一段，叙述的人站出来交代一句“说他背信是冤枉的”，跟使用规则“不得写成背誓”是同一个意思。上一轮为躲原神撞句改过的那一句（他真心以为……）一字没动。

13. #994 灰旗之名，他做成的事
    - 改前：前头所有人加起来，没有打下过一座城。（空行）他打下了三座。（空行）他没有去袭扰，也没有去烧粮。他打进去，守住，把血誓的东西一件一件搬出来烧掉，再接着守。（空行）第一座守了四个月，第二座三个月，第三座他整整守了十一个月。
    - 改后：几百年里起过事的灰旗，前头所有人加起来，没有打下过一座城，到他手里，打下了三座。他不去袭扰，也不去烧粮，打进去就守住，把血誓的东西一件一件搬出来烧掉，烧完了再接着守，第一座守了四个月，第二座三个月，第三座整整守了十一个月。
    - 为什么：六个单句段并成一段，“前头所有人”是谁原来要读者自己对，前头补一句是几百年里起过事的灰旗（同一条里“几百回起事”“那几百年里”都写着）。

14. #975 众手之典，效果
    - 改前：你被三个以上的敌人围住的时候，你的每一次攻击同时打中围住你的每一个人。围你的人越多，你越快。／你可以把一样东西交给一个人，告诉他送到哪里。只要那个人还活着，东西一定送得到，半路被夺、被搜、被截、被毁，都不作数。
    - 改后：三个以上的敌人围上来，封板上那七道凿痕会一道接一道亮起，你的每一次攻击同时打中围住你的每一个人，围你的人越多，你越快。／你把一样东西交给一个人，告诉他送到哪里，只要那个人还活着，东西一定送得到，半路被夺、被搜、被截、被毁，都不作数。
    - 为什么：效果写成一样看得见的魔法，落在器物一节本来就有的七道凿痕上（★），条件、范围、被夺被搜被截被毁四样和数值一样没动；“你可以把”是八条效果共用的句头，换开。

15. #970 面具短枪，效果
    - 改前：你可以指定一个你输给过的对手。从那以后，他的伪装、拿节奏骗人的手法、故意卖出来的破绽，对你一概不起作用，他骗不了你第二回。
    - 改后：你指定一个输给过的对手，枪尾那张木面具就转过来朝着他，右颊那道裂里透出一点暗光。从那以后，他的伪装、拿节奏骗人的手法、故意卖出来的破绽，对你一概不起作用，他骗不了你第二回。
    - 为什么：同上，落在器物一节里那张木面具和右颊的裂上（★），机制没动。

16. #968、#982【调用】【名】
    - 改前：【调用】玩家拿到这杆枪，问起北境凛塔家的那两兄弟，问起一杆本该缀着银羽、却整根发了黑的枪，或者问起一个花了三十年、只想知道哥哥最后看见了什么的人的时候。／【名】世界叫它骨磨之镜。祷告的人只说“镜”。
    - 改后：【调用】问起北境凛塔家那两兄弟，问起一杆本该缀着银羽、却整根发了黑的枪，问起一个花了三十年、只想知道哥哥最后看见了什么的人，或者这杆枪落到玩家手里的时候。／【名】外头叫它骨磨之镜，祷告的人只说“镜”。
    - 为什么：二十八条【调用】都从“玩家拿到这X”起头、末尾都是“……的时候”，【名】二十六条都是“世界叫它X”，一份里一个模子。各条换开写，每一条的触发条件、正名和俗名一个没少。

17. 使用规则，#968、#969
    - 改前：- 他起先不是为了复仇。不得写成痛快的复仇故事，他要的从头到尾是哥哥最后看见了什么。／- 已故，伤重，死在谷口。不复活，不显灵，不以英灵的样子正面登场。
    - 改后：- 弟弟这三十年追的是哥哥最后看见了什么，起先不是为了复仇，不得写成痛快的复仇故事。／- 他伤重死在谷口，已故。不复活，不显灵，不以英灵的样子正面登场。
    - 为什么：一条一件事，先说是什么事，再说不许怎么写；原来二十二条以“不得写成”起头、九条以“已故，死在”起头，改成从这件事的主语起头，“不得”一个没少，统一句照留。

## 二、改了底本自己拧着的

1. #979 万象秤杖：同一条里，月银写的是“铸的是那一位的名”（没有脸），赤金铸的是魔王的侧影（巴尔缇娜，她），她却说“我不想每天摸他的脸”，两种钱上都找不到一张“他的脸”，锁里也照着写“月银铸索恩薇娅的名”。#132 统一货币体系写明赤金巴尔主面铸魔王巴尔缇娜侧影，月银索恩主面铸圣君索恩薇娅侧影，山铜便士不铸任何王者头像。照 #132 改了三处：叙述里月银写成铸圣君索恩薇娅的侧影；那句台词改成“我不想每天摸那两张脸。”（两种钱她都不用，两张脸都对上，也不用替她定那道命令是谁下的）；锁里“三币的形制是卡里定死的”那一句跟着写成两张侧影、山铜不铸王者头像，“这一句她一辈子只说过一回”那条锁引的台词跟着换。原句在放行里本来就有，wash_check 过。这是上一轮文件开头“要主会话定的”第2条，这一回照第〇节第3条改了，请主会话看一眼。
2. #975 众手之典：同一条前头写她二十年被围四十多回，走脱的法子是把围她的人打散，最凶的一回从七十几个人围住的街里走了出来，后头又写“她从来不在路上动手”。读成她在路上从不先动手，叫人围住了才打，改成“她在路上从不先动手”，后一句“一动手就有人记住她的脸”照留。

看不出来哪一种对、照留的：

- #978 出城的匣：“三十一年里他进过十一座城，每一座都是城破以前进去，城破以后出来”，可他最后死在城破那一夜的城里。那一座要是第十一座，前一句就打架；要是第十二座，三十一年的数也得往后挪。照底本留着。
- #993 松林之赠：“站的那个位置，连他自己都觉得安全”，“他”是射手还是守将，底本两种读法都通，照原句留着。

## 三、没动的

- 对白和引语块（> 开头的行，五千七百六十四个字符）：只改了 #979 那一句台词，和 #995 引语块里一句不是台词的旁白（“那笑里没有苦，也没有哭，是事情终于说清楚了的那种笑”，“没有…也没有…是…那种”的架子，改成“那一笑里不带苦，也不像哭，像是一件事终于说清楚了”，意思照使用规则“不得解释成苦笑或者崩溃”）。别的一字没动：这些对白短，各人一个口气，像人说的话（“回来看看你。”“总得有人拿着。”“那不算。”“砸开就不是解开了。”），jrpg-lore-writing 要的“至少两处直接引语”就靠它们；上一轮已经把「」换成“”，三百零三句跑过 voice_check。#985 那四句歌词是上一轮为躲原神撞句重写的，也没动。
