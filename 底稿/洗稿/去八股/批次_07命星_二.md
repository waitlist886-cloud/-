# 去八股对照：批次_07命星_二（命星与天赋后半，#357 到 #474，11-09）

洗的是 `底卡洗稿/批次_07命星_二.md` 一百一十八条：Rare、Epic、Legend、Unique 的 Passive 和 Special 一百一十五颗，#472 圣剑，#473 猎魔剑术，#474 命星总则。这一份 10-30 已经洗过一遍，标点、引号、加粗、禁词、修行关联补 Skill 都做了，这一回照派活说明第〇节往深里改句子。

命星名、阶、数值、机制、冷却、消耗一个没动，【】里的招式名、「」里的条目名、裁定和硬锁一条没少，强弱字逐条数过，一个没少，也没多添。改的是说明的句子，五样：

1. **说明头一句的框。** 改前一百一十七颗星都从「【X】是……的体质／天赋」起头，一百一十颗写成「是……的体质／天赋」。这一回各写各的：从一样看得见的事起头（摔下去别人先着头、仗打到一半伤口已经在合），从谁家常有起头（炉城和炎角的孩子、长垒守备的老兵家里），从一句老话起头（有些孩子生下来，地就不记得他走过），从别的星对照起头（元素精通的人有一条近路）。starlint 要的「头两句写成天赋」照守，生来、天生、生下来、胎里、骨子里、血里带、与生俱来换着用。星名标题行里有，说明里多半不再重报，「【X】是」只留 #367 一处。
2. **修行关联只写吃哪几门 Skill。** 这一行原来是用处的筐，在哪里顶用、谁抢这种人、打到后头多吓人都塞在这里。照写作口径「命星」那一节，修行关联只留 Skill、哪几条命路用得多、修行怎么往上长，用处挪进被动、主动或者头一句，挪的时候跟那一栏原有的话并成一句，不重说。
3. **主动的冷却挪到效果后头。** 改前五十九颗的主动以「每场战斗一次」「24 小时一次」「CD 24h」起头，这一回一律先写做什么、看得见什么，冷却跟在效果后头，用处另起一句。
4. **一份里成了模子的几样换开。** 判定获得优势、某某的说法是、带着这颗命星的人、只对……算数、不在其中、不归它管、一类的 Skill、两路、跟某某一起用的时候、世界反应里的会知道／会认你／会来要人，各至多留两处。「不是……是」十三处改成直说。一条里同一件事说两遍的并成一遍。
5. **看得见的魔法。** 写作口径要每一颗有看得见的魔法、写结果不写原理。三十来颗星的被动、主动添了一句照它自己的名字和说明推出来的样子（掌心变成灰石的颜色、胳膊上爬过一道雷纹、车厢的影子从墙里开出来），不添人、不添事，列在第六节，标★。

## 三、没动的

- 裁定和硬锁里的否定。#400「它不是回溯，不是闪避，也不是护盾」，#472「圣剑不是破晓……也不是太阳王冠圣剑」，#474「Active 是类别，不是级别」「是一条路，不是一招」。否定就是约束，删了等于放开。
