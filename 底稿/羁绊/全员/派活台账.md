## 派活的话

照这一段派，份号换成自己的。停在半截的份（文件里已经有写完的章），末尾加第6条。

```
你是奥尔德兰卡「全员羁绊」那一轮的「份号」份。工作目录是仓库根，仓库根上的 CLAUDE.md 是这个项目的总说明，写作口径照它。

1. 先读 底稿/羁绊/全员_写作计划.md，照它写，它让你读的几份照读。
2. 你的名单是 底稿/羁绊/全员/分份表.md 里「### 份号」那一节，一人一章，写进那一节标的文件（新建）。
3. 备注写进 底稿/羁绊/全员/份号_备注.md，起的名字一动笔就先登记。同一纪别的份同时在写或者已经交了，起名以前读一遍 底稿/羁绊/全员/ 里同一纪已有的备注，也拿 grep "^## X纪·羁绊" 看一眼那一纪已经写好的章名和题，别撞。
4. 别的文件一个字不改，不提交，不推送。
5. 检查照计划第七节，全是 0 才交。voice_check.py 的路径和 --corpus 用这一回的：（主会话填）。交稿回一段两百字以内的中文。
6. （停在半截的份才加）这一份已经写了几章，文件里有条目设置那一行的章是写完的，不重写，接着写名单上还没有的人；写完的那几章照第七节补跑检查，备注接着已有的写。
```
