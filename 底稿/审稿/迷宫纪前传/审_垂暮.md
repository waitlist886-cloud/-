# 迷宫纪前传剧情审稿｜垂暮（第六页·垂暮的年月）

审的范围：第六页的三条主线（空着的环、无谬之城、星形钥印），另附 1001 年那一头的支线「兆八·归火开炉」。所用的尺子是用户这一回的原话、方向稿第四版、补完方向稿第五节，以及写作口径里的「玩家在场」和「上台下棋的对手」两条。这一回看不到页面文件，旅伴、人物、迷宫各条都没有查，只凭主线和总纲判断，拿不准的地方写明拿不准。

---

## 一、垂暮的年月·空着的环

**判定：偏了，要加力**

**骨架**
973 年第四十五层的骨桥底下亮起一片“天亮”，看见它的人从此只看得见它，桥那边五个营一百三十几个人断了粮路。瞎了一百一十五年的传奇文森特口述了一张要人“收我”的单子，萝珊和提珀两个人陪他下到桥头哨。他一个人上桥，凭脸上的热和耳朵里的鸟叫找到那东西，这辈子头一回先出了手，一刀一刀把鸟叫砍停。那东西翻下裂缝，他靠着桥栏坐下，没有再起来。看见过它的人都恢复了视力，他被埋在北沿外头。

**敌人和目标**
- 目标清楚：送走桥上那个东西，把断了的路打通。
- 敌人不清楚，也不出手。“天亮”没有名字，没有脸，没有来历，三幕里它只在桥底下待着。主线自己写的是“它不出手”。
- 它也不升级。它从头到尾只做一件事，就是被人看见。这条线没有一个出三回手、一回比一回狠的对手，不合 11-18 定的那条规矩。
- 缘故只交给 AI。以太院的人坐了一下午，之后再没有人去查它为什么在 973 年出现。

**王道的那几样**
- 伙伴：薄。旅伴三个人，萝珊和提珀大半时间在“背对着桥坐着”。有几拍斗嘴和照应：提珀要洗剑柄上的布，文森特说“布别动”；文森特头一回笑。但没有一起吃饭、一起打的戏。
- 成长：有，落在萝珊身上。她学会了他报的数，倒着数领大家出了第四十四层，往后成了不靠灯认路的人。这是这条线最实的传承。
- 热血：一半。高潮是做出来的事，砍到最后一种鸟叫，这一点立得住。但这是一个人的死战，没有“大家一起顶上去”。
- 轻喜剧：很少，只有提珀“这一笔他不讲价”一两处，整条线是挽歌调。
- 情义：真。一个瞎了的老传奇替一百三十个人去，“我要是坐着，就是我”。毛病是那一百三十个人从头到尾没上台，守护的对象是抽象的。

**时代感**
- 繁荣：没有。
- 魔导科技：只有剑脊里那一条以太结晶线嗡嗡地响，再加一面铜镜。
- 隔阂消除：没写，混编是默认的，这本身倒也说明隔阂已经平常了。
- 黑潮余波：写到了，“只报地名和日子”，费伊的环。
- 没有写成山铜纪那种权谋腐败的灰。但收尾落在结算台、结案栏、名录少一个名字、坟前报地名日子，是悼词调的灰。

**玩家能干的**
- 主动的有四五样，而且都改得了局面：背过身去看影子，跟他上桥，攥住环拽他退开、让他活着回来，替他报热的中心在哪里。这一栏写得好，符合「玩家在场」。
- 被动的写在各幕的“玩家可以是”里：医疗院守夜、坐在总会那间屋里的人、当值书记、按印的人、攥绳的一只手。正史各幕里玩家默认站的位置大多是陪着走。

**毛病**
1. 一幕世道到二幕：断粮的营立了起来就丢了。二幕把赌注写得很清楚，“吃的够二十天，粮背不过去”。可收束一个字也没写这些营怎么样了，粮送没送到，有没有人饿死。因果在这里断了，情义也跟着落了空。
2. 三幕：对手不出手，英雄的本事就成了取消冲突的开关。那东西整幕只是热、只是叫，砍下去它就退一格。这一拍好看靠的是写法，不是对局。
3. 二幕：“再派一队/派谁去”那场会。白烛、以太院、公会长三方坐了一下午，结果是“没有人答”。权力最高的几个人一件事也没做，只等主角推门进来。这是在用“众人无能”给英雄铺台阶。
4. 收束：结算台、结案栏写“结案。二人按印，二人到场。”，坟前“只说了地名和日子”，名录“少了一个名字”，剑三年后进封存箱。四样记录性的东西叠在一起做收尾，正是派活说明点名的那一路。高潮本身不是念名字，但收束全压在账和名录上。
5. 数目堆砌：三百一十步、四十二枚赤金巴尔、十一颗脑袋、一百一十五年、七张里领十张，偏密。
6. ★：几乎每一拍末尾都挂着（★），连读时很碍眼。
7. 拿不准：费伊和那个环全靠 #941，本条只给了一句“费伊的”。对没读过那一条的玩家，“环为什么空着”这件事撑不起收束那么多分量。

**该留的几拍**
- 单子正面整段，尤其是“我要是坐着，就是我。剑在我手里，别硬掰。”和按押“按在格子外头半个指头”。
- “那边有什么？”/“嗯，问惯了。”首尾呼应。
- 桥上一刀砍停一种鸟叫，最后一种“像天快亮的时候头一只醒的鸟”。
- 萝珊倒着数他的数，领人出第四十四层。往后她当不靠灯的人，嘴唇动着数他的数。
- 提珀那句“长到一块了，刷不下来，也不该刷。”
- 玩家能改里“背过身看影子”这一手。这个解法很好，正史里可以让一个 NPC 晚一步想到。

**改法方向**
- 给“天亮”一个有名有脸的形，让它出三回手：一幕吞掉桥头哨；二幕把视线从井口一路拽上来，医疗院里的人开始往井里走；三幕主动扑向上桥的人。
- 把桥那边断粮的营搬上台。高潮让文森特在桥当中砍，桥那头的营里人背对着、看着影子替他报方位，萝珊和提珀在桥这头接应，几方一起把它送下去。
- 他可以照旧死，但路要当场通，粮要当场过桥。
- 收束砍掉结案栏和名录那一串，落在萝珊头一回不拿灯带队上。

## 二、垂暮的年月·无谬之城

**判定：空转，要重写**

**骨架**
976 年第五十层的雾门那头响起表声，营头杜戈进雾走了十步又被退回原地。地图室的奥尔文贴出一张“只量，不打。”的单子，六个人下去量第五十一到五十三层，发现那里成了一座会把一切往回退的黄铜城。瑞秋从校准台上拓下五十七个快被磨平的名字，娜佳在一顶盔旁边坐了一天；第五十三层门口杜戈被困在十步的循环里，娜佳在铜地上刻下当天的日子，他走出第十一步。一行人顺着白线逃回，深度板底下添了一条木板，拓片钉在未归板旁边。

**敌人和目标**
- 目标清楚：只量，带图回来。
- 没有敌人。城本身是一种性质（往回退、要把东西校正），不是对手。科尔文和薇拉是可怜的残留者，不是反派。执政官和校勘者“这一年没有人走近”。
- 唯一像出手的是三幕“齿轮顶上的人影”抬手一指，只出了一回。
- 单子一开头就写明不打，等于主动放弃了对局。这条线也不合“上台下棋的对手”那条规矩。

**王道的那几样**
- 伙伴：三条里最像一支队。六个人各有一手：杜戈踩纹，瑞秋弹线，娜佳认日子，凹盾顶盾，疤手按伤，听针做斥候。小戏也多，凹盾骂铜臂，“我外号还叫疤手”，“它说你的凳子是好凳子呢”，杯子挪到西南“北边是放图的”。
  - 听针几乎没事做，只偷了一个齿轮、拽了一回凹盾。
- 成长：弱。杜戈从“营里没人信”到“走过第十一步”，这是身份上的变化，不是本事上的。
- 热血：只有三幕往回跑那一段算群体戏，凹盾“盾上又多了七个坑”。可那是逃跑，不是赢。
- 轻喜剧：有，是三条里最好的。
- 情义：落在名字和日子上（替死人拓名字、替祖辈坐一天、替同伴刻今天），没有落在“为一群人站出来打一场”上。

**时代感**
- 魔幻科技：有，黄铜齿轮城是全页最像魔导奇观的一处。但它是井里的异物，是一座死城，不是这个年代往上长的新东西。
- 繁荣、隔阂消除：没写。
- 灰调：主菜是账厅（“账对不平”的首席审计官）、校准名字的碑、拓片、深度板该不该擦的评议、结案栏、停战纪念日读名。这是三条里最像山铜纪的一条，名字、碑、账、条款、记一笔几乎全在。

**玩家能干的**
- 主动的：替瑞秋挡铜臂、拖住科尔文，替科尔文去取那个件，穿过白雾跟执政官开打。最后这一样只写在玩家能改里，正史整条线不打。
- 被动的：陪娜佳坐一整天，在评议桌边替哪一边说话，把晾绳巷的事告诉公会长，在旁边看着拓名字。正史的三处高潮（拓名字、坐一天、刻日子）玩家都只能陪着。

**毛病**
1. 三处高潮全是八股：
   - 二幕：拓名字。“这是名字。”/“名字更该刻正。”
   - 二幕：坐一天。娜佳在盔边“坐完了”。
   - 三幕：刻日子。“那就是今天。”刻下去，“叮的一声，像雷狱的牢门弹开”。
   - 收束：刻坦格的名字，钉窄木板，钉拓片，结案栏，停战纪念日读名，“这一张没有名字要读”。
   - 一条主线里把名字、碑、刻、账、读名用了五六回。
2. 三幕：困局靠一句话加刻一行字解开。娜佳问“回不回家”，杜戈说“回”，她刻下日子，门就开了。这是“说一句话解决”加“刻字当高潮”。
3. 二幕：科尔文的线开了没收。城当中的校勘者“热过头了”，要“等一个件”，他问他们是不是去取件的；之后再没人提，正史里谁也没去取。这是设了钩子就丢。
4. 二幕：“缺了一块”的那种东西，盾挡不住，伤了凹盾，之后“谁也不碰它”。来历和作用都没交代，悬着。
5. 对不上：
   - 总纲写杜戈“在雾里走到第十一步”看见城。主线里他第一回只走了十步，看见的是齿轮；第十一步是三幕走出循环的那一步。两处说法要统一。
   - 娜佳“得在蝉鸣月下旬二日到第五十二层”，缘故全靠坦格、刻期家、雷狱、第十九营这些没在本条讲清的东西。读者到收束看见“七百五十四年”才能倒推出来。
6. 给作者看的话漏进了卡面：瑞秋“想说晾绳巷里的晾衣绳从前也是拿粉线比着拉的，没说”，玩家能改又写“她听得懂，记不回来”。这是写给知道设定的人看的暗号，玩家不知所云。
7. 数目堆砌：五十七个、三十一个、七个、三十五天、二十份、七个坑，还有六枚印旁边点六个点。
8. ★：同空着的环，每拍都挂。

**该留的几拍**
- 杜戈那十步：“第七步左手边那一面墙在转”，奥尔文“你说得出第七步……我就写上去”。
- 瑞秋的白线，以及“线是直的，顺着线走，总回得来”。这是很好的地城规则，可以当全队的命门。
- 城会往回退，退不了的是线、带下去的东西和人记得的事。这条规则立得住。
- 铜臂替疤手把烫疤校平，“我外号还叫疤手”；凹盾的坑一个也不让敲平。
- 娜佳的角认日子，“城里的日子会跳，她的角不跳”。
- 杯子挪到西南，回来喝“搁了三十五天的酒，是酸的”。
- 公会长那句“板上写的是谁走到了哪一层，不是那一层如今长什么样”。这句可留，但不当收束。

**改法方向**
- 把执政官和校勘者立成对手。它要把一切“校正无谬”，出三回手：
  1. 先派工匠和铜臂校正这几个人；
  2. 再派齿轮顶上的印官追捕；
  3. 最后把杜戈锁进十步循环。
- 单子别写“只量不打”。可以写成量到一半发现城在往上长、要吞第五十层的营，非下去不可。
- 高潮落在殿当中：六个人各用自己那一手（白线定路、角认真日子破它的时间、盾顶住铜臂、杜戈踩纹），合力把件换上或者把校勘者打停。刻日子可以是破局的一环，但不是全部。
- 拓名字、坐一天、窄木板、读名四样，至多留一样。

## 三、垂暮的年月·星形钥印（卡面题作【约定的钟点】）

**判定：偏了，要加力**

**骨架**
第五十层营地东墙里每天当一声，响了十年。守营人法丽达挖出一个星形的窝，档案室的诺维安从“没门的那一屉”里找出一枚对得上的钥印，十几岁看着光复单子长大的第一千三百零五队四个人下去开门。门后是挽晨遗民的避难营地，只剩露希亚一个人，九百多年天天到钟点敲一下。她领着四人走了三条岔路，第三天“吞层兽”从三头吃过来，三个人各守一个口子，撑到钟点露希亚敲响、法丽达在墙外回了一下。三个口子接连合上，三个人被关在里面，莉齐被乱潮卷走，露希亚没有用钥印出去，门从此不见了。

**敌人和目标**
- 目标清楚：开门，问清门那边是谁，带人回来。
- 敌人有名（吞层兽，古德蒙起的），有形（“一道会走的褶子”），也真出了手，吃路、合口子。这是三条里最接近对手的一个。
- 但它只在三幕出场一回，没有前两回铺垫，也没有升级，是一种天灾，不是棋手。它为什么偏偏这一年来，“NPC 说不出”。
- 三幕又加了一道没有预告的乱潮把莉齐卷走，这是天灾叠天灾。

**王道的那几样**
- 伙伴：有，而且是实的。
  - 古德蒙一天说的话被盖文数着（“头一天九句，第二天七句”）。
  - 古德蒙在黑里拽着大家贴左墙退，躲过合上的石壁。
  - 盖文把斗篷给露希亚，把袖口挽三道。
  - 古德蒙看菌子“够他吃一百年”，露希亚说“这一朵你不知道”，他尝了说她对。
- 成长：没有。四个人带着什么本事下去，就带着什么本事没了。
- 热血：三幕三人分守三个口子，各用各的本事（盖文肩膀卡门洞，韦塞林托梁连祷，古德蒙抹苔照路），这是全页最像 JRPG 的一场“大家一起顶上去”。可默认结局是全输。
- 轻喜剧：有，古德蒙的话、菌子、九句七句。
- 情义：很足。“门那一边有人。得有人去问一声是谁”；韦塞林为露希亚又跪下；两边的敲声“九百多年里头一回”碰在一处。

**时代感**
- 开局委托厅劝回未满十八岁的孩子，把 980 年改年纪的新规落在了画面上，好。
- 第一千三百零五这个队名从光复单子的一千三百零四枚印往下数，把黑潮那一代接到了下一代，是全页唯一一处“传承往前走”的实笔。
- 魔导科技：几乎没有。
- 繁荣：没有。
- 灰调：收束是未归板、钉子、布袋、库房编号、结案“钥印未还。”、读名、注销、砸模子、法丽达一辈子敲墙，悼词灰压过了前面全部的亮。

**玩家能干的**
- 主动的很多，而且都改得了局面：把人从口子里拽出来，替盖文捡书，站到露希亚前头，接住古德蒙，替莉齐按着钥印数到三百，从墙外跟着敲、门开了进去找人。这一栏是三条里写得最好的。
- 被动的：一幕抄钥印、描图，问诺维安来历（答“出处不明”，要自己查）。

**毛病**
1. 三幕：默认结局全军覆没，而且三个人的死法有两个是自找的。
   - 盖文回头捡第三十本书。
   - 古德蒙最后一句“汤给我留一碗。”，正是派活说明点名的“收在一碗汤上”。
   - 这一场群体死守写得最热，结果什么也没换来：露希亚没出来，门没了，钥印注销了。热血被结局整个取消。
2. 三幕：露希亚的选择前后断开。二幕她答应“敲完再走”，三幕攥着钥印却“没有按”，回头看了一眼墙就坐下了，没有一个字交代。人可能是为了陪墙里的三个人，但卡面没给出来，读起来是前一拍和后一拍接不上。
   - 她念完三个名字又问“里头，是什么来着？”，这一笔像是她在失忆，或者井在吃她的记忆，也没有交代。
3. 三幕：乱潮凭空漫进来卷走莉齐，没有铺垫，是机械降神式的灾难。
4. 收束：结案栏“未结。四人按印，无人到场。”，库房“第三万九千三百一十八号”，读名时法丽达替担保人站起来，诺维安写“注销”、砸模子扔进炉子，地图室撤线，法丽达每轮敲墙。六七个记录和仪式性的动作叠在一起，是三条里收束最长、最灰的。
5. 法丽达“守闩的不进门”。这是一道职务规矩压过了情义，人被写成了职务。三幕那一刻她只在墙外敲一下就停了，墙里在死人。
6. 数目堆砌：三千六百一十二道、四十一枚、第三十九枚、九十四张、二十九本、二百一十七，还有编号。
7. 题名不统一：卡面题作【约定的钟点】，总纲和条目都叫星形钥印。

**该留的几拍**
- 开局委托厅劝回孩子，“念到一天也没断过，就没有人笑了”。
- 单子正面，“门那一边有人。得有人去问一声是谁。”和收尾“闩上了。”
- 诺维安那句“我比你们还想下去，所以我不下去。”
- 第一千三百零五队名的来历。
- 古德蒙的九句七句、黑里贴左墙退。
- 三条岔路的探索：倒悬图书馆书页边上一天一道，沸水矿井的活水死水，菌庭。这是一段正经的地城冒险。
- 盖文挽袖口；“到了上头，那个钟点我陪你敲”。
- 两边敲声相碰那一下。
- 三人分守三口的整场。

**改法方向**
- 让吞层兽出三回手：
  1. 二幕第一夜吃掉图书馆最里头几排；
  2. 第二天扑向营地、追露希亚；
  3. 第三天三头齐来。
- 高潮照旧是三人分守、露希亚敲钟、法丽达回钟，但要赢下来：钟声两边相合能把门撑住，或者能把褶子顶回去，四个人带着露希亚出门。若要留牺牲，留一个就够，让剩下的人把她带上去，在阳光下敲第一声。
- 把露希亚的选择写成她说出口的话。
- 砍掉“汤”、注销砸模子、编号这一串。

## 附：兆八·归火开炉（1001 年那一头的支线）

**判定：立得住**（有几拍要补）

**骨架**
1015 年起七神圣所的护火转暗，门洞底下守炉一千九百年的伊诺克以为算好的日子到了，开了炉，篝火里走出教人唱誓的孩子，天下的人一个个心冷、交出火。玛丽贝尔带着阿南刻和玩家，拿第二把钥匙下了门洞。伊诺克见到钥匙后自己倒念了门，睡死在炉边；玩家和归火打三阶史诗战，拧满九圈，十五六岁的斐里安从火里掉了出来。终局那天他坐在门洞火边，说“原来已经有人做成了”，把自己添进火里。

**敌人和目标**
- 目标清楚：拧满九圈，把火还回去，冷下去的人醒过来。
- 敌人有名有脸，归火是一团“披着一个二十五六岁年轻人的轮廓”的火。它出手三阶，一回比一回重：目光灭火，压灭一厅连人胸口的火，掉霜。这条合上棋盘规矩。
- 伊诺克是开炉的人，前两幕在场（教唱誓、借火说话），到三幕一见钥匙就自己收手，这一点下面另说。

**王道的那几样**
- 伙伴：玛丽贝尔（“我封过它一回，没封住。这回我不拿命去填了”）；阿南刻跨到玩家前头挡下最重一击，“打烂了，修得好”。这是标准的伙伴舍身戏，而且没有写死。
- 成长和救赎：斐里安从无心的王座变回十五六岁的孩子，崩铁、原神那种“迷途的人被领回来”的中式内核很足。
- 热血：三阶 boss、拧钥匙计圈，全页最 JRPG。
- 轻喜剧：几乎没有。
- 情义：“交回来吧。日子到了。”对“你怎么知道它不会来？”，守护和放下都落在了具体的人身上。

**时代感**
魔导和火（晶匣、铳里的晶、法阵的线一齐矮下去）、长垒三段城的烽火、圣女的火种，宏大和奇观都上了台。没有山铜纪那种灰。

**玩家能干的**
主动的居多：灭掉伊诺克要走出来的那堆火，定先后，打三阶，自己挡最重一下，拦下伊诺克，劝孩子别等。被动的只有“没有人来管”那一路。

**毛病**
1. 三幕：英雄到场，对手自己散了。“再看见玩家手里的钥匙，他不叫烬兽了”，随后他倒念门、睡死。伊诺克是开炉的人，却在对局前自己退场。至少让他打一阶，或者让他倒念门是因为玩家做了什么。
2. 通篇典故密度太高：玛蓓、先生、篮子、清查的夜、佩林、承火圣女、宴火、康科迪娅、碑匠街小牌、十王回廊，大半不在本条讲清。没读过上下游的人会不知所云。
3. 收在“坟前摆着他的两只碗”，后头还有“带他去看他少算的三笔账”。碗和账两样又回来了。
4. 跟前传接不上：
   - 本条接的是山铜纪那一头（“947 年唱誓”）和黑潮（残火喊队名），跟第六页三条主线一点也没挂上。
   - 第六页也没有替归火、门洞、灰雨城埋任何种子。总纲里 971 至 975 年“灰炉镇第七码炉头一回熄炉”、999 年对炉街的炉，不知道是不是伏笔，拿不准。
   - “947 年”指迷宫纪还是山铜纪，“门洞的火隔了一千三百年”从哪一年起算，拿不准，应在条内说清。

**该留的几拍**
- 篝火里走出戴圆顶小帽的孩子，只问怕不怕。
- 康科迪娅把寻人单子钉成一个圈，圈心是灰雨城。
- “交回来吧。日子到了。”
- 阿南刻替人挡下那一下，“修得好”。
- “你比在门洞底下的时候更像人了。”
- “原来已经有人做成了”，火高了一尺。

**改法方向**
- 伊诺克留一阶对局，或者把他的倒念门写成被玩家一句话、一件事扭过来的。
- 典故压到三个以内，其余放进人物条。
- 第六页 981 到 1000 年那一截里，给门洞或归火留一两样看得见的征兆，让前传和 1015 接上线。

## 这一份共有的

### 共有的毛病和套路（三条主线，不计支线）

**结构上**
- 没有有名有脸、出三回手的对手：3/3。天亮不出手；城没有棋手；吞层兽只来一回。
- 怪事缘故只给 AI、没人去查：3/3。天亮、城、吞层兽加钥印出处。
- 正史结局没赢：3/3。两条以死收（文森特死，第一千三百零五全没）；一条全员回来，但没打赢任何东西。整页没有一场胜利。
- 群体“一起顶上去”的高潮：只有星形钥印有，默认还输了；无谬之城只有逃跑；空着的环是单人。
- 伙伴戏实的：2/3（无谬之城、星形钥印）；空着的环偏薄。

**收束上**
- 收在名字、名录、板、读名上：3/3。名录少一个名字；窄木板、拓片、刻名；未归板、读名。
- 同一句架的结案栏“X 人按印，X 人到场”，加印旁边点点或画圈：3/3。
- 停战纪念日读名：2/3。
- 公会长蕾雅收尾露一面、只说一两句或不说：3/3；其中“几个？”“四个。”这一类数人头的台词出现两回。

**道具和数目上**
- 酒杯搁在第五十层桩头，等人回来再喝：2/3，几乎一模一样。
- 深度板“最上一行照旧写第五十五层”：3/3 的世道段都写。
- 层碑上的“别下了”：2/3。
- 收在汤或碗上：1 条（星形钥印“汤给我留一碗”），支线又有“两只碗”。
- 数目和编号堆砌：3/3。

**写法上**
- ★几乎拍拍都挂：3/3，影响读。
- 三条用同一个章名“地开以前的长夜”。973 至 981 年读来会糊涂；若指 1001 年那一局的地开，可留，拿不准。

### 跟用户要的王道 JRPG 比

**近在哪：**
- 委托单子的口吻和分量很好，每张单子本身都是一个钩子，这是前传“委托”这一纪的样子。
- 伙伴各有一手的配队法（无谬之城六人、星形钥印四人）是对的。
- 星形钥印的三岔地城和三口死守，是全页最像轨迹、传说那种“大家一起”的地方。
- 玩家能改三条都写得到位，改得了生死。

**差在哪：**
- 没有反派，没有赢，没有升阶和成长。
- 轻喜剧只做点缀。
- 繁荣、魔导科技、两王、隔阂消除几乎都只活在总纲里。三条主线全钉在第四十四到第五十三层的深井里，地面上的世界一眼也没看。

**是不是山铜纪那种灰：**
不是权谋腐败的灰，是挽歌的灰。但收束反复动用的道具是山铜纪那一袋：名字、碑、账、结案栏、读名、注销。无谬之城干脆把账厅和审计官搬成了第五十二层的地貌。这一页把“垂暮”两个字读成了悼词，而不是“仗打完了，日子重新往前走”。

### 方向稿的兑现

方向稿第八节那张表只有五页，没有第六页“玩起来是什么”那一行，只能拿总纲的自述和补完方向稿第五节“垂暮”那一行比：

| 项 | 兑现 |
|---|---|
| 补完方向稿：1001 年几支队的立队年（不灭之炎、黑曜誓约、银枝七人、铁与炉） | 0 |
| 补完方向稿：995 年队名栏九行 | 0 |
| 总纲：群星归途 975 年立队、979 年到第五十五层 | 只在总纲 |
| 总纲：改十八岁、星坠扩招 | 星形钥印开局一拍 |
| 总纲：两王 | 0 |
| 总纲：村子搬回 | 0 |
| 总纲：1000 年征兆 | 0 |
| 总纲：999 年比约格下井 | 0 |

粗算兑现两成上下。三条主线的年份停在 981 年，981 到 1000 这最后二十年没有主线，“收到 1001 年的开局”这一拍只靠总纲最后一段的征兆清单撑着，没有上台。

### 这一页在前传弧线里担住没有

- 弧线是“繁荣起来，隔阂消掉，齐心对黑潮”，第六页该担的是余波和交棒：仗打赢了，活下来的人怎么把日子和本事交给下一代，一路走到 1001 年的开局。
- 交棒只有一处实笔，就是第一千三百零五这个队名，可这一队在正史里全没了。三条的情感重心都往回看，看黑潮、看九百年前、看死人的名字，没有往前看。
- 这一截没担住。它担成了“前传的悼词”，不是“前传的尾声和 1001 的序幕”。
- 支线兆八在气质上更像这一纪该有的样子，但跟第六页两头都没接上。

### 最好的和最该重写的

- **最好的是空着的环。** 因果最清楚，高潮是主角亲手做成的一件事，单子、首尾那句“那边有什么”、萝珊倒数这几处都立得住。要补的是对手和那一百三十个人。
- 离 JRPG 最近的是星形钥印，结局一改就能翻身。
- **最该重写的是无谬之城。** 单子一开头就“只量，不打”，三处高潮全是拓名字、坐一天、刻日子，收束又是板、拓片、读名，是这一页八股最重、对手最空的一条，而它手里本来握着全页最好的魔导奇观和最整齐的一支队。
