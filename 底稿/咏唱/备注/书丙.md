# 咏唱重写｜书丙备注（11-24 夜）

名下：`底稿/门面/第二轮/大图书馆/书稿/` 里圆厅、月银纪廊、纷争纪廊、山铜纪廊、迷宫纪廊、戏台与说书、孩子的一架、廊（往前往后），一百零七本（`行当的歌_*` 八本没碰）。

做法：先拿字眼 grep 全架（咏唱、祷、颂、誓、咒、领应众、判词、安魂、立约、问答，再补一遍“念／唱后头跟引号”、分行的 `>` 块、【】术名、对神的呼告），八十来本有字眼，逐处读上下文。真正写出词来的在十七本里，五十七段。别的都是“念了一段祷词”“唱三句誓”这一类只提不写的，没补。

## 一、数

- 找到：五十七段（十七本）。整本是歌的不逐首算：墙上的歌二十一首、同行歌、北桥之歌、井口童谣、十兆里的跳绳歌。
- 抬了：二十段，五本。盾碑祷言七段，墓城安魂曲八段，祭火簿三段，逆咏一段，黑耀契约汇编一段。
- 添了：六处，五本（书里本来只有白话一句、或者卡里这一轮新立了定型词的地方，见第三节）。
- 判了不动：三十七段。
  - 定型句和卡里原文十八段：盾碑祷言四（殿里那一句、碑沿改的那一句、歌里“光属于祂”那一句、压阵颂是前半句念三遍），逆咏和夜医手记的三句誓各一，黑耀第一条，曜石审判证誓那一句，祭火簿问路那一句，红园“你可以不饮”，诸国志星湖三句誓，辉塔与圣荫铭环誓，万兽四夜的交火词和灰桥之誓，火别灭扉页的灰桥之誓，白鸢骑士传守土誓，旅人手册七神口传的一句（七条算一组），安魂曲第十段交灯的话。
  - 民间短祷、私下一句、孩子自己的话五段：逆咏的清雨、按回去、收火时说的，阶顶夜话白烛晚祷的短本（注二写明是改短了的），薇丝拉之路奈拉背面那一句。
  - 歌谣四段：逆咏门洞谣，阶顶夜话量身歌、数筐歌，偶与影开场诗。
  - 读着够味、或者是题眼的九段：盾碑祷言归颂（就两个字），逆咏闸上的令、封炉的令（刻在山铜上的铭文体，末句已经烧起来了），黑耀七权誓约文（一条一件事，冷的），安魂曲第六、九、十一、十三段和第十四段配了谱的头两行。
  - 有硬伤先不动一段：逆咏第三段封谱的令（见第五节）。

## 二、抬了的，一段一段

**纷争纪廊_盾碑祷言**（第二篇随阵，克拉拉，纷争纪一千零四十年前后，举盾者殿）。腔照不退一系里举盾者这一位：盾、盾沿、盾带、首列、墙、门，短，重。称号照神谱「举盾者斯卡索」（众人身前的墙、立于万军之前的那一位），神国金盾之荫、国门是并盾的那一下。事和“一句一拍”的规矩没动，每段只添一两句。
- 出墙颂：誓词骨架，起誓落在第二样实物上（盾带的铁扣，装帧里卷书的那一根），末句添对南风的一句。
- 起盾颂：成象，“千面是一面，这一下并上，就是祂的门”。
- 换气颂：对句，“千面盾是一面盾，千口气是一口气”。
- 补列颂：报数（缺一面补一面），实物（盾还是热的），末句呼名。
- 退颂：末句呼名，“我们退的每一步，都还在你身后”。
- 伤者颂：头一句添实物（解盾带），“祂”换成称号。
- 夜颂：借神国，“金盾之荫的火边总空着一个位子，今夜这一堆火边，空着的是我的”。

**戏台与说书_墓城安魂曲**（雅诺·沃尔明，迷宫纪约四百七十一年，照墓城老本子写）。骨架是葬礼和安魂：门前的问、替亡者答的“他没有”、迭句“那一夜”、末句回到开头的老话。墓城不拜七神，请的是钟，所以没用长眠之域。“全曲最响不过一个人念名字”的规矩照守，没往响里写。唱法、页边、图一个字没动。
- 第一段报号：头一行添“门前的是谁，从哪一条路上来”（亡档前的问），刻骨签那一行添“墓城认这一片骨”。
- 第二段念名：四行添到七行（唱法本来就是七部一部一句），中间三行是否定告白。
- 第三段初雪月：“一盏押着一个名字”“他们没有钟”。
- 第四段第十三下：迭句“那一夜”两回。
- 第五段空了的格子：“那一夜以后”，空了叠到三样（额骨、名册、心里背着的，照主线裁定锁里祂吃的那几样）。
- 第七段最底下三层：照唱法“一步一级台阶”排成“一级，再一级，再一级”。
- 第八段十三夜：添一行替十三具骨头答的“他们没有”。
- 第十四段没配谱的那四行：末尾添一行，回到第二段那一句“名字交给钟，人就不用背了”（定型句原样，当迭句收全曲）。

**月银纪廊_祭火簿**（十四　三段祷，欧德说、莱奥记，月银纪三千年）。书里原是自起的四字本。卡甲这一轮在 `月银纪补卷/技艺_01_公共技艺.md`「祭火守夜护身祷法」里添了祭火院理的三段词，写明“各处火边口传的差几个字，末一句都一样”。照卡里那一版改成欧德口传的本子：骨架是祝词（开头说火坐在哪里，末句“话告于火前，火已经听见”跟卡里一字不差），留了书里自己的几样（火自灰桥传来、借你一夜天亮奉还、十步、七个人、守火的醒着走路的睡、天亮以前我叫你的名字）。

**山铜纪廊_逆咏**（第一段夜祷，净血院的祷，伊诺克记）。添立证一句（“我生来带着一滴夜，今夜交在你面前”）和一句“石不暗，我不起身”，后一句跟下文对得上：倒着念到第三夜石头暗了，他站起来往外走。倒着那一行照书里原来的规矩重排（句序倒、每句的字倒、标点照原次序放回），脚本在我的 scratchpad，拿书里现成的五段对过全对。

**迷宫纪廊_黑耀契约汇编**（十　灰雨之誓，巴尔缇娜）。黑耀的腔：冷，准，念三遍。添“这一句我念三遍，一个字不添”，血印拆成三样一样一句，末句“灰落在我这里，名字留在你那里”。效果和界限照底卡洗稿凡世至强那一条的灰雨契约，没多给。

## 四、改前改后（八段）

**盾碑祷言·出墙颂**
- 前：“门在身后，盾在身前。我以此盾立誓，不教一步落在门里。南边的风，你先到，我们后到。”
- 后：（前头先称名三领三应）“门在身后，盾在身前。我以此盾立誓，以盾带上这一枚铁扣立誓，不教一步落在门里。南边的风，你先到，我们后到。你退的时候，我们还在。”

**盾碑祷言·补列颂**
- 前：“空的地方，有人。倒下的那一个，我们记着他站哪一排。”
- 后：“首列缺一面，后排补一面。空的地方，有人。倒下的那一个，盾还是热的，我们记着他站哪一排。举盾者，你的墙没有缺口。”

**盾碑祷言·夜颂**
- 前：“火在身后，夜在身前。我不睡，我身后的人睡。”
- 后：“火在身后，夜在身前。金盾之荫的火边总空着一个位子，今夜这一堆火边，空着的是我的。我不睡，我身后的人睡。”

**墓城安魂曲·第二段念名**
- 前：头一座钟楼念，第二座接，／号在前头，名字在后头。／名字交给钟，人就不用背了，／一年念遍墓层，一格也不跳。
- 后：头一座钟楼念，第二座接，／号在前头，名字在后头。／他是地上生的，名字是活人给的。／他没有顶过别人的号，没有吃过别人的名字，／该报名字的时候，他没有低头。／名字交给钟，人就不用背了，／一年念遍墓层，一格也不跳。

**墓城安魂曲·第七段最底下三层**
- 前：往下走，下到亡档库最底下，／叫水泡过的，从落火里抢出来的，／叫人一行一行涂黑了的，／纸上的名字，钟外头的名字，没有人吃得着。
- 后：往下走，下到亡档库最底下。／一级，叫水泡过的。再一级，从落火里抢出来的。／再一级，叫人一行一行涂黑了的。／纸上的名字，钟外头的名字，没有一张嘴吃得着。

**祭火簿·第三段额上灰**
- 前：一夜之火，一夜之灰。／抹你额上，留你一息。／你若倒下，倒在火边。／天亮以前，我唤你名。
- 后：一夜的火，一夜的灰，守它的人没有合眼。／这一撮灰，抹在你的额上。／你倒下去，倒在火边，这一口气不许走，火替你攥着。／天亮以前，我叫你的名字。／话告于火前，火已经听见。

**逆咏·夜祷**
- 前：白石在上，照我的血。黑的洗去，红的留下。一夜一夜洗，洗到天亮，洗到名字底下那一行干干净净。白石在上，我不睡。
- 后：白石在上，照我的血。我生来带着一滴夜，今夜交在你面前。黑的洗去，红的留下。一夜一夜洗，洗到天亮，洗到名字底下那一行干干净净。石不暗，我不起身。白石在上，我不睡。（倒着那一行跟着重排了）

**黑耀契约汇编·灰雨之誓**
- 前：我站在这里，不收任何人一滴血。／走上前来的人，报你的全名，按你的手。你身上旧魔神、高座、旧主留下的血印，从这一刻熄成灰。那一份血，你从此不欠。谁再拿它来讨，刀落不下去。
- 后：我站在这里，不收任何人一滴血。／这一句我念三遍，一个字不添。／走上前来的人，报你的全名，按你的手。旧魔神留在你身上的，高座留在你身上的，旧主留在你身上的，这三样血印，从这一刻熄成灰。／那一份血，你从此不欠。谁再拿它来讨，刀落不下去。／灰落在我这里，名字留在你那里。

## 五、拿不准的，要主会话定的

1. **添的六处要不要留。** 派活说明写的是不替它补词，除非讲仪式的书该有词。这六处我判成该有，可都是往书里添字，不想要的整段拿掉就行，前后没有改别的。
2. **书和卡互相照着的几处，往后谁改谁跟。** 第三节第 1 到 5 条照的是卡乙、卡丁、卡戊这一轮还没提交的字。祭火簿照的是卡甲的。白鸢骑士传的守土誓照的是 `底卡新条目/势力_阶衔封地与对头团.md`（书里三处全文、一处半句，注二写明“跟白阶之礼上念的一样”），卡己要是抬了卡里那一段，书要跟着换，这一轮我没动。
3. **盾碑祷言用了神国的东西。** 夜颂的“金盾之荫”“火边空着一个位子”，起盾颂的“这一下并上，就是祂的门”，取自神谱条的神域栏。图鉴里神国是明着的那一层，我照明着的用了。嫌露得多，这两句可以拿掉，剩下的照样立得住。
4. **安魂曲第八段添的那一行**（“他们没有住口，没有把划掉的号咽回去”）说的是十三个人为什么死。墓城人知道（主线二幕维吉莉亚当面说的），作曲的人照墓城的老本子写，我算他知道。
5. **祭火簿的设计备注**里“卡里只有三段的名目和用处”那一句过期了，设计备注我没动，要改请主会话改。
6. **逆咏封谱的令没抬**，缘故见下一节第 1 条。那一段正了以后，令可以照封印的骨架重写，我在这里留一个照卡里意思的底子：以白石之名，以长垒念进石里的光之名，封此一谱。本家的手按上来，字从石下浮起。外人的手按上来，页页皆白。法门不出此门，子孙同此，永不启封。
7. **点了名要抬、书里却没有词的几本**：夜医手记（只有三句誓，定型）、薇丝拉之路（只有奈拉背面那一句，是写完又后悔的一句私话，抬了就不像了）、公会委托存档和旅人手册（没有写出词的誓，旅人手册“出门一句，回来一句”没给词）、几本戏本（大征服者、春天没有来、叠牌班、万兽四夜里只有定型的交火词和灰桥之誓）、勇者小队之书（全书不用引号，卷十只有“念一句古老的咒语”）。都没补。勇者小队之书卷十要补的话，可以写成“南段的诗人各唱各的词，唱得最多的是这一种”，后头分行：比沙更老的，比火更白的，／睡在沙底下的那一口气，醒来。／我押上见过的每一个冬天，押上这一根比我还高的杖。／散开的，合上。流着的，站住。可那一卷末尾有一句“这一卷你写得太快了”，添了咒就不那么快了，所以我没添。

## 六、顺手看到的硬伤（只记，没改）

1. **逆咏第三段，封谱的意思跟卡里对不上。** 书里写成封的是有魔族血的人家（令里“谱中有黑者，不入上城之门，不近祭坛之火”，正文“封了谱的人家，孩子在门外头哭”，注二“封的是有魔族血的人家”）。卡里 `山铜纪/补卷/补卷_55_学艺与传承.md` 写的是上城各家把家传的法门抄成白石谱，请旧派祭司拿光封住，外人翻开是白的；管谁进得了上城的是白石拱门，不是谱。伊诺克条（补卷_64）只说“上城各家的谱叫白石封着，他没有替谁开过谱”。
2. **盾碑祷言第七篇**那片薄皮上写“首列，第四排”。书里和卡里“你站哪一排”的答法，首列就是头一排，跟第三排、第四排是并列的，两样写在一处说不通。
3. **祭火簿**：卡里写三段是诸国期祭火院理出来的，书里三千年欧德已经说“老守火的教的。三段”。可以读成口传本来就三段、祭火院只是理成本子，记一笔。
4. **墓城安魂曲第三段**词里是“荒原上来了一辆车，车上一只箱子”，同一段页边写“他背了一路”，亡档那一本和主线都是背着灯箱走来的。作曲的人没下过墓城，可以算他听来的，词我没改这一处。
