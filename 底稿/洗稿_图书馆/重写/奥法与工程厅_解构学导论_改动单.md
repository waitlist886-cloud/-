# 改动单｜解构学导论（声口重写，11-28）

从原稿 `底稿/门面/第二轮/大图书馆/书稿/奥法与工程厅_解构学导论.md` 起手，重写稿 `底稿/洗稿_图书馆/重写/奥法与工程厅_解构学导论.md`。人设包新写了一份 `底稿/洗稿_图书馆/人设/解构学导论.md`。

全书正文约一百段，动了 5 段（5 句）。元信息、扉页、目录、`## ` 小标题、〔图〕〔剧透〕〔注〕标记、第九讲三行、附页的册子六条、四条注脚、设计备注一个字没动。事实、年份、地名没动，没加原稿没有的事。

这一本改得少，缘故：书里自己写了“镜湖的规矩，说一句，停一下。这一本也一样。”，卡里镜湖那一条的写法也是“镜湖人说一句，停一下，再说下一句”，所以短句、单起一段是这本书的体例，是镜湖人的嗓门，不是冷笔。11-25 八股排查（`底稿/排查_八股/备注/书稿_B16.md`）判这一本“没毛病”，也是这个理由。这一回只挑了不像镜湖导师、也不像批注那几只手会说的句子：盖章词（照旧、不算）、一句格言收住没有下文、一处“你不改你照出来的东西”读着别扭。

## 一、七个层面

| 层面 | 导师（讲义口述） | 页边批注（几代人，褐、黑两种墨） |
|---|---|---|
| 时间尺度 | 一夜、第二天早上、三年、一年；讲次（读一讲停一夜）；“从今年起”“这几十年” | 年份（八三一二年以后）、几十遍；一个人的一辈子一句带过 |
| 自称称呼 | 几乎不自称，说“我们”“地宫”“镜湖”；句句冲着“你”（刚扫完三年地的学徒）；前人叫头一代导师、镜湖的老人、门口一个照兽的学徒 | 褐色的自称我（梦见妹妹那一条），黑色的学徒自称我；说湖边的人、地宫的人 |
| 连接词 | 几乎不用，句号断开；“所以”两回（所以地宫的规矩、所以地宫写），“然后”一回 | 不用，一行一事 |
| 问号 | 零。拿不准的事不问，写成规矩（看见的不一样，有一个拆错了） | 原稿零，这一回黑色学徒那一条添一个（这也算？） |
| 手边的东西 | 湖、笼子、月银的灯、刀、左手边那一排、曜核、环印、纸 | 抄了四十遍的那一句、牙磨平了一半的残兽、兽市、第七层 |
| 消息来源 | 镜湖的老人说；乡下人都知道，神殿也知道；外头的人说；第二讲说了、第六讲说过（往回指自己） | 自己看见的、自己梦见的；湖边的人说 |
| 怎么停笔 | 落在一条规矩上（不拆、不署名、拆的时候不说话），或一样要做的事（读完了再照一年兽才许拿刀） | 落在一件事实上（我说了、第七层快放不下了、这东西不该有） |

## 二、改了的

| # | 位置 | 原句 | 改后 | 为什么 |
|---|---|---|---|---|
| 1 | 第一讲，月银的灯那一段 | 灯比湖快，湖比灯准。 | 灯比湖快，湖比灯准，灯底下拿不准的，还是推回湖边照。 | 一句对仗收段，像碑上的格言，没有下文。导师是在教学徒干活，说完两样的长短，正常人会顺口交代该怎么办。“推回湖边”照上一段“把笼子推到湖边”，不添新事。对仗照留，那是要学徒记住的口诀 |
| 2 | 第一讲，赏格那一段 | 送它来的人要拿它去领赏格，你不改你照出来的东西。 | 送它来的人要拿它去领赏格，你照出来是什么就是什么，别替他改。 | 原句“你不改你照出来的东西”主语宾语都齐，读着像条文，不像师傅当面叮嘱。前半句说的就是送兽的人有改的理由（卡里活事件：染了渊的残兽赏格高一档，军团书记那一张脸），“别替他改”把这一层说出来，后面镜湖的老人那一句卡里原话照留 |
| 3 | 第一讲页边，褐色的字 | 这一讲照旧第一个讲。 | 这一讲还是放在头一个讲，残兽也得先照。 | “照旧”是盖章词。写这条批注的人刚说了送来的兽一年比一年小、老、牙磨平了一半，正常人接下来会说为什么还这么讲，理由就是讲题本身（先照，后拆） |
| 4 | 第七讲，账在人脑子里那一段 | 所以地宫写。 | 所以地宫写，你往后也得写。 | 一段推下来，末了四个字冷收。这一讲是讲给学徒听的“写”，导师把道理落回到听的人身上，这一讲的“写完了，不署名”才接得上。镜湖话少，只添半句 |
| 5 | 第七讲页边，黑色的字 | 湖边的人说地宫的人话多。写的话不算。 | 湖边的人说地宫的人话多。写在纸上的又没出声，这也算？ | “不算”是盖章收尾，意思也绕（哪个不算）。这是学徒在讲义边上顶一句嘴，替地宫辩：镜湖嫌的是大声说话（卡里：在这里大声说话，满湖边的人都转过头来看你），写下来的没有声音。学徒的手比导师松，给他一个问号，全书唯一一个 |

## 三、留着没改的冷句和缘故

| 句子 | 缘故 |
|---|---|
| 扉页题句、第七讲“看懂它是怎么做出来的，然后写下来。” | 迷宫纪解构那一行的认法，注四接着它，一字不动 |
| 前言“往下九层。一层比一层冷。”“合不回去的，不算拆开。”“镜湖的规矩，说一句，停一下。这一本也一样。读一讲，停一夜。” | 头一句是地宫的样子；“合不回去的不算拆开”是全书的总规矩，第三讲“装不回去的，你就是在杀它”接着它，规矩本身留冷；末一段是这本书的体例自己说出来 |
| 第一讲“先照。”“照的时候，蹲下来。”“照出来没染的，地宫不收。” | 命令和规矩，导师一句一停 |
| 第二讲“正面是它给你看的。接缝是它藏不住的。” | 对仗，可这是解构这一行要背的那一层意思（先看接缝），讲义里该有一两句口诀，留 |
| 第二讲页边“先看接缝，再看正面。这一句我抄了四十遍。” | 报数，可抄四十遍是学徒挨罚的实情，人味在数里，想过加一句为什么抄，那是新事，不加 |
| 第三讲“拆的时候不说话。” | 规矩，八股排查也点过“是规矩不是姿态” |
| 第四讲“要害在哪里，第二讲说了。在缝上。” | 导师有点不耐烦地往回指，是他的冷法，不是盖章 |
| 第五讲“核里有一声。”“所以地宫的规矩。”及三条规矩 | 讲到要紧处停一下，再列规矩 |
| 第五讲页边“我梦见我妹妹没有死。我说了。” | “我说了”是两个字的收，可这是全书最该冷的地方：妹妹死了，她照规矩第二天早上把梦说给旁边的人听，“一笔一笔写得很用力”在括号里已经交代了。后面不接感想 |
| 第五讲页边“这东西不该有。” | 卡里渊染那一条原话 |
| 第六讲、第八讲的“不拆。” | 规矩本身，一条一条排下来是名录 |
| 第七讲“这一页才算写成。”“写完了，不署名。” | “才算写成”是导师给学徒的尺子，说的是一页什么时候写完，留；不署名是这本书没有作者名字的来由 |
| 第八讲“活人，不拆。”“镜湖不照。请他出城，不收他的钱。” | 全书第二处该冷的地方。注三那一行刮掉的正是这条边往后没守住，这里越冷越好；“不收他的钱”照卡里“没要钱，把人请出了城” |
| 第九讲三行 | 剧透，三行是锁定的 |
| 附页六条、“第七层快放不下了。” | 地宫的账，表格一类；末条批注一句事实收，是这一本的落点 |
| 四条注脚 | 注一、注四是青墨，注二、注三是后人添的，都不动 |
