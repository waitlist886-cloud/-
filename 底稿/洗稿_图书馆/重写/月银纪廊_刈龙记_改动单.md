# 《刈龙记》声口重写｜改动单（11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/月银纪廊_刈龙记.md`，重写稿 `底稿/洗稿_图书馆/重写/月银纪廊_刈龙记.md`，人设包 `底稿/洗稿_图书馆/人设/刈龙记.md`（新做的，麦伦的声口块、性格底色、底线、手写活人层照第七歌旅伴条抄，史官照书头提炼）。卡里麦伦只有旅伴条和背景条，没有凡世至强条（名字在崖上凝住，人还是英雄，没有踏进传奇的记载），人设包里写明了。

正文（前言到后记）164 行，动了 24 行（20 处），不到一成五。书头元信息、扉页、目录、`## ` 小标题、每段“念的：”那一栏（左栏抄的歌、壁画题字、火录，是歌的原文）、〔注一〕〔注二〕、注脚、设计备注一个字没动。事实、数字、人名地名没动。添进去的只有两个人当下的动作和念头（史官削笔、笔尖的墨干了、右栏边上点一笔，麦伦“想着明天割下一垄”），和第十五段一处“她也数过”，见第四节。

这一本的底子跟落日之弓、夜医手记近：麦伦在卡里“话少，是当真没话”“一句不过十个字”“问三句答一句”，羁绊的坎就是“他对你说了一句超过十个字的话”，书里也守着“超过十个字的只有靠着下巴睡那一句”。所以他的短句一律不拉长，改完他每一句仍在十个字以内。要分的是两种短：他当真没话的短（烧了、咸、温的、一刀、渴、种麦的，落在麦、盐、风、刻道、谁没回来上）照留；他下判词、盖章的短（编对了、数对了、腿没软是烧不着那一串顶针、我不在我在城外、我没看他我看她）换成他会说的那一样东西。史官是记档的人，规矩是记看见的、不批，可他的冷收多半不是规矩，是段段压一句“我停了”“他就走了”，换成他手边的事。

## 一、两个作者的七个层面

| 层面 | 麦伦（右栏） | 史官（前言、问话旁记、后记） |
|---|---|---|
| 时间尺度 | 季节和茬（秋天、那一茬、八个秋天、九岁、十六岁），一天里只有歇和砍；五千七百年他不提 | 十一天，一天一段，第几天、霜降月、当值、傍晚、天不亮；编年院的年份（五千七百年、6007 年起记） |
| 自称称呼 | 我；对谁都叫你；龙叫它，只叫出口一个名字眠山；达格妮报名是为说明歌里没有的事；别人照做的事叫（打钉子的老头、不摘头盔的、射翼膜的姑娘、缝衣裳的那个“她”） | 我、编年院、我们；一回也不叫“麦伦”，只叫“他”；门房 |
| 连接词 | 几乎没有，一句一事；这一回添了一个“才”（才站得住） | 逗号串下去，“所以”“可是”“还是”；这一回添了“那我就” |
| 问号 | 原稿一处（白线还在吗？），照留，没添 | 原稿零个，问他的话都转述；这一回添一处，后记“他又是谁？”，是史官自己问自己的那一句 |
| 手边的东西 | 镰刀、仓签、木签、盐、麦垄、风、鳞、石头 | 左栏右栏、册子、笔、凳子、窗、面包、劈柴、门房、收存簿 |
| 消息来源 | 只说自己看见的、背对着的就说不知道 | 歌、王庭壁画题字、炉城火录、编年院自己理的那一段、门房说 |
| 怎么停笔 | 一样东西或一个动作（没回来的、刻道、拿石头接着刻） | 一张他看见的单子（点过两回头、说了一回太漂亮了、十一个半块面包） |

## 三、留着没改的冷句和缘故

- 扉页“这一茬我去收。”、后记“没回来的。”、第四段“烧了。”：卡里台词样例和初见原话。
- 第一段“不是山。是它的脖子。”：他在改歌，否定有对象，留。“不是它的。”“炉子的。”“她的。”：一层一层往下说，说到她就停了，是他这一本里头一回漏东西，留。
- 第二段九岁那一串（烫、咸、八个秋天、鳞是温的）：一个话少的人自己往外倒回忆，倒出来就是碎的，靠着下巴那一句是书里定的十个字以上的唯一一句，整串没动。
- 第二段“我念焚原，他说眠山，我接着念”：重复是这一段的骨头。
- 第五段“领主念过。挨个念的。”“我刻道。”：难过就刻道，卡里原样。“风从西南来。”：怕的时候看风，留。
- 第七段“我背对着。”“不知道。”“温的。”：锁（叶子还是手不裁定），“温的”跟第二段鳞是温的对着，留。
- 第八段三句和“那一茬还没收完。”：底线“不撂下没收完的一茬”，他回答为什么去送死就这一句，留。
- 第九段“它停了一口气。”“不知道。”：锁（停顿是它自己停的）。“太漂亮了。”：万兽纪事卷四引的就是这一句，不动。守南门那三句末一句“他站着。”：罗南死后绑在柱上站着，死人的地方，留冷。
- 第十段“咸的。”“它闻了。没吃。”“我叫它回家。”“它家没了。”：咸跟第二段“今年的盐咸不咸”对着；它闻了没吃是锁；它家没了是全书最该冷的一处，留。
- 第十一段“她叫达格妮。”“她不说，就没人知道。”“她跟我说了。”“半步。”“歌里那半步，对。”：报名字、证一句歌，事实层的话。
- 第十二段“她手快。”“没问她叫什么。”“该问的。”、不摘头盔那三句：后悔说得这么短正是他，“我没说”是底线。
- 第十三段“高。”“没往下看。”“它歇，我砍。我歇，它烧。”“一刀。”“它看了我一眼。”“跟城头那回一样。”“六个在下头。”：崖上三天的节拍，屠龙那一刀，留。“它歇我砍”是对仗，全书只这一处，留着当打法的口诀。
- 第十四段“这一段别念了。”“渴。”“背后的事我不知道。我背对着。”“这个不说。”：底线和锁。
- 第十五段老麦农那一串、“种麦的。”“底下那一茬，没收上来。”：转述别人的话、全书的收尾，不动。
- 后记“他出门的时候是侧着身子出去的，背没朝着门房。”：照手写活人层，是史官看见的样子，留。末一句那张单子不动。

## 四、新添的、跟卡对不上的、要主会话定的

- **第 19 条“她也数过”**：卡里旅伴之间“麦伦与菲娅｜她数他的刻痕，他不赶她”，好感减里“替他数仓签上的道 −5”，他想起的“她”读的人会认成菲娅，史官不知道是谁（“我问她是谁，他没答”）。这是往“他就是那个人”那一边又添了一小块分量（书里站在“是”那一边的本来有眠山村那滴血、达格妮的名字），设计备注里“两头都留着”的平衡没破，可也算新起的一笔（★）。嫌多可退回原句“一百一十四。数对了。”，或者只改成“一百一十四，没唱错。”
- **第 8 条“想着明天割下一垄”**：是他那一夜的念头，卡里没有，不是事实，倾向留。
- 第 7 条史官“在右栏边上点了一笔”是借“点头”起意的小动作，嫌俏可改回“我在右栏里记了一笔”。
- 原稿就有、照原稿没动的：设计备注末条“拿不准”（五千七百年以后有人自称是他，读的人会往他踏进传奇上想），跟这一轮无关，照旧等主会话。
- 别的跟卡对过：生于 1666 年、1690 年二十四岁坐城门边、1693 年二十七岁名字凝住、十七、四十一、二十五、一百一十四道、九岁上山八个秋天、十六岁下山，书里都对得上。
