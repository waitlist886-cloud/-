# 改动单｜那边有什么（声口重写，11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/迷宫纪廊_那边有什么.md`，重写稿 `底稿/洗稿_图书馆/重写/迷宫纪廊_那边有什么.md`，人设包 `底稿/洗稿_图书馆/人设/那边有什么.md`（新做的，文森特的身份和声口块照卡里抄，书记照卡里一句加书头提炼）。

正文（前言、七卷、后记、注脚）约一百二十四段，动了二十处（前言 1、卷二 2、卷三 1、卷四 4、卷五 4、卷七 1、后记 5、注五 1），两处是把单起的一句并回上一段。卷一、卷六一个字没动。元信息、扉页、目录、`## ` 小标题、〔〕标记、图题、单子六行、青墨注四、设计备注一个字没动。事实、数字、人名地名没动。添的只有他的念头、他注意的东西（塔隆的脚步）和书记照规矩的手续，来处在各条里写明。

这一本要先说清楚：文森特在卡里就是“短，慢，一句一停，常拿一个字收住”的人，书又是口述，短句是他说话的样子，不是冷笔，大半照留。要动的是两样：口述里几处像旁白盖章、单起一句的收尾；书记的前言、后记、注跟口述一个节拍，记账的人没有记账人的样子。

## 一、两个人的七个层面

### 文森特（说）

| 层面 | 他的 |
|---|---|
| 时间尺度 | 几岁那年、哪一年哪一夜；一百多年一笔带过（我听了一百多年），一夜的事记到一盏灯、一口气 |
| 自称称呼 | 我；父亲、母亲；塔隆叫名字；费伊卷五说一回名字，往后说她；书记当面叫“书记”；墙上的人、北段的兵、街上的孩子不点名 |
| 连接词 | 几乎没有，一句一事；“可”“还有一件”各一处，说话的人想起来补的 |
| 问号 | 只给“那边有什么？”和别人问他的话；自己问自己的“你为什么松手”写成句号，问的是一个不会回答的人 |
| 手边的东西 | 磨剑石、剑、剑脊里那条结晶、剑柄那两圈布和环、铜铃、绳、风、脚步、靴底的铁钉 |
| 消息来源 | 只有耳朵和脸上的风；看不见的写明是别人说的（他们说、墙上的人说），这一回把“看着四十七八”也改成他们说的 |
| 怎么停笔 | 一个字（好、行），或者“今天说到这里”，或者那一句“那边有什么？” |

### 委托厅的老书记（记）

| 层面 | 他的 |
|---|---|
| 时间尺度 | 年、月、旬、日写全，先写日子再写事；一旬一回、一个晚上不到一千字 |
| 自称称呼 | 我；文森特只叫“他”“那个老剑士”，一回不叫名字；会长；按印的两个人照名录写全名和部门 |
| 连接词 | 逗号串下去，“往后”“就”“照” |
| 问号 | 只在转述里（我问他写什么），不用问号 |
| 手边的东西 | 白边单子、格子、押、念一遍、空一行、订本子 |
| 消息来源 | 写明来处：前哨的人说、去收他的人说、北段一个老兵跟我说 |
| 怎么停笔 | 落在手续和本子上（没叫他重按、两页空着照样订进去）；不替人定论 |

## 二、改了的

### 前言（书记）

1. 第一段｜替人写一本书
   - 原：……要留一本书，叫我写，写完念给他听。
   - 改：……要留一本书，叫我写，写完念给他听。替人写一张单子，委托厅柜上天天有，替人写一本书，我还是头一回。
   - 为什么：原前言跟口述是同一个短节拍，书记一开口就该露出他是管单子的人。替不认字的人写单子是委托厅的日常（卡里那张单子委托人一栏就是书记的字），拿单子去比一本书，是他会有的念头。“头一回”是他的话，没添事，**算是一句新起的自述，嫌多可删**。

### 卷二

2. 我退不了
   - 原：退一步，场子里的人就嘘你。／正好。我退不了。
   - 改：……／那正好，我想退也退不了。
   - 为什么：两个短句单起一段，是冷收。这是他不笑的玩笑（场子要人不退，他天生退不了），“那正好”是他卷五回费伊的同一句口头话（卡里“那正好，会打的都想自己动手”），一个人的口头话前后对上。

3. 往后五年
   - 原：刃比风慢，风先到，我就先接。／往后五年，没有输过。
   - 改：刃比风慢，风先到，我就先接。往后五年就这么接，没有输过。
   - 为什么：报数单起一段，“往后五年，没有输过”是战报的口气。说话的人讲到这里会顺着往下说，“就这么接”指回上一句他的法子，五年没输照留。

### 卷三

4. 第二天又走过去
   - 原：他走了。第二天又从我身边走过去，没停。第三天也没停。
   - 改：他走了。第二天又从我身边走过去，脚步没停，左边照旧比右边重一点。第三天也没停。
   - 为什么：“没停。第三天也没停。”是否定对称的两拍。他看不见，能知道塔隆没停是听脚步，“左边比右边重一点”是这一卷前头他自己说的塔隆的脚步，他先注意的就是这个（卡里声口：注意脚步）。“第三天也没停”留着，等的味道在这里。

### 卷四

5. 走了多少步
   - 原：书记问我那一夜走了多少步。我没数。那一夜我头一回没数步子。
   - 改：书记问我那一夜走了多少步。我没数，顾不上，那是我头一回没数步子。
   - 为什么：“我没数。”接一句换个说法再说一遍，两拍冷收。他是在回书记的话，回话的人会顺口给个缘故，“顾不上”是这一夜本身（潮压上来、从这一头走到那一头），没添事。

6. 我本来就看不见
   - 原：我本来就看不见。
   - 改：我本来就看不见，灯灭不灭，跟我没什么两样。
   - 为什么：单起一段五个字，标准的一句一段冷收。意思是他不笑的玩笑：满墙的人都瞎了，他本来就瞎。说成井口老兵那种平话（卡里“说话跟井口的老兵一样”），玩笑还在，章没了。

7. 叫我名字就行
   - 原：往后北段的兵管我叫剑响处。叫我名字就行。那三个字是墙上喊的，……
   - 改：往后北段的兵管我叫剑响处。叫我名字就行，那三个字是墙上喊的，……
   - 为什么：夹在中间单起的一句短句像一枚章。卡里台词就是一口气的“叫我名字就行。剑响处那三个字，留给墙上喊吧”，并回去。

8. 他们照旧不点
   - 原：我说那是那一夜没灯，不是往后都不要灯。他们照旧不点。
   - 改：……他们还是不点，我也拿他们没办法。
   - 为什么：“照旧”在盖章词单上，“他们照旧不点。”是一句冷收。他劝过，人家不听，一个老剑士说起这种事是带点无奈的，“拿他们没办法”是活人会接的半句。

### 卷五

9. 那正好
   - 原：我说那正好。会打的都想自己动手。
   - 改：我说那正好，会打的都想自己动手。
   - 为什么：卡里台词是一口气的“那正好，会打的都想自己动手”，断成两句读成两枚章，照卡里并回。

10. 别替我握剑
    - 原：我把手转过去一点，说够你放。别替我握剑。
    - 改：……说够你放，别替我握剑就行。
    - 为什么：“别替我握剑。”单句压在段末是盖章。他是在跟一个十九岁的姑娘交代，“就行”把命令放回当面说话，意思不变，跟卡里“你别替我想多了”是同一路的交代。

11. 我退不了
    - 原：我退不了。只有她拽，我才退得了。
    - 改：我自己是退不了的，只有她拽，我才退得了。
    - 为什么：“我退不了。”是全书第三回，前两回（卷一、卷二）已经说过，这一回单起再盖一次章。改成一口气，“自己”跟后半句“她拽”对上，这一句是全书的骨头，意思一个字没动。

12. 不是
    - 原：墙上的人说她是我的眼睛。／不是。眼睛不会替我判断该不该打。
    - 改：……／不是，眼睛不会替我判断该不该打。
    - 为什么：“不是。”两个字单起，接着一句理由，节拍是冷笔。并成一句，后头费伊那句“你又要说不是了吧？”和他的“我说不是”就成了这一段唯一的短句，重复到那里才有分量。

### 卷七

13. 看着四十七八
    - 原：我今年一百五十六了。看着四十七八。名字凝住的那一夜我六十，往后脸就不动了。书记说这一句要不要写。写吧。墙上的人老问。
    - 改：我今年一百五十六了。他们说我看着四十七八，我自己看不见，就信他们的。名字凝住的那一夜我六十，往后脸就不动了。书记说这一句要不要写。写吧，墙上的人老问，写上了省得我一个一个答。
    - 为什么：他瞎了一百多年，“看着四十七八”是别人告诉他的，原句像他自己照过镜子，消息来源不对。“我自己看不见，就信他们的”是他不笑的玩笑。“写吧。墙上的人老问。”两拍短收，添半句写上的缘故，是一个嫌麻烦的老人会说的。

### 后记（书记）

14. 单子全停
    - 原：往骨谷去的单子全停了。
    - 改：往骨谷去的单子，会长发了话，全停了。
    - 为什么：段末一句冷收。管单子的人记停单，会记是谁发的话（卡里：公会长蕾雅·帕斯洛当场定了往骨谷去的单子全停）。

15. 我念了
    - 原：叫我写完念一遍给他听。我念了。他说好，拇指按在格子外头半个指头，我没叫他重按。
    - 改：……我念了一遍，一个字没漏。他说好，拇指按下去，按在格子外头半个指头。照规矩该叫他重按，我没叫。
    - 为什么：“我念了。”三个字一句是冷收。记账的人会记他念全了没有（卡里：书记照文森特说的写，一个字没漏）。“照规矩该叫他重按”把书记这一行的规矩说出来，读的人才知道“没叫”是他破了一回例，书记的情绪全在这一处手续上，不出口。

16. 提珀按印
    - 原：头一个按印的是遗体回收部的提珀·鬃刷。第二个是……星图纹压歪了半边。
    - 改：头一个按印的是遗体回收部的提珀·鬃刷，按得端端正正。第二个是……
    - 为什么：书记是看押的人，两枚印他都会看。卡里“背面两枚印，提珀的端正，萝珊的星图纹压歪了半边”，原稿只记了歪的那一枚，补上端正的那一枚，两枚并排，是记账人的眼睛。

17. 头一回先出了手
    - 原：接了一辈子剑的人，那一夜头一回先出了手。
    - 改：他在这一本里讲了两年的接，接住了不退，往回送。前哨的人说，那一夜是他先出的手，接了一辈子剑，这是头一回。
    - 为什么：原句是旁白下的判词，书记那一夜不在桥上，看不见谁先出手。改成他从这本书里知道的（卷二、卷四两回“接住了不退，往回送”）加前哨的人说的，消息来源对了。“接了一辈子剑”“头一回”照卡里那一句留着。

18. 两页空着
    - 原：他说留着。我照他的意思没有填。
    - 改：他说留着，我照他的意思没有填，订本子的时候照样订了进去。
    - 为什么：“他说留着。”单句盖章。管本子的人最后说的是本子怎么订的，空页他没拿掉，这是他守着那两页的方式。

### 注脚（书记）

19. 注五
    - 原：两样我都记下了，哪一样是真的，我不替他们定。
    - 改：两样我都照说的人写在这里，哪一样是真的，轮不到我定。
    - 为什么：“记下了”在盖章词单上，“我不替他们定”是一句硬收。书记的本分是照说的人写，“轮不到我定”是一个管单子的人说自己的位置。锁照守，两种说法都留着，不裁定。

## 三、留着没改的冷句和缘故

- **卷一“钉没钉我不知道。往后退那一步，我一辈子没迈出去过。”“我听了一百多年，没听出来几样。”**：都是他不笑的玩笑，前一句是全书“退不了”的头一回，后一句是他父亲那句话的回音，自嘲，留。
- **卷二“下去了二十年。有的。”**：注一专门写了“下去了二十年那一句，他没往下说”，这一句的短是书记记下来的事实，动了注一就对不上，留。
- **卷二“我说我看了。他说你看的是风。”**：一问一答落在老剑手那一句上，是这一卷的题，留。
- **卷三塔隆那四句对答、“八百六十年开春，我把剑拿起来了。”、塔隆的“好。”**：卡里原句；“好”是全书头一个“好”，后头他自己一直拿这个字收住，从塔隆那里来的，留。
- **卷三“可它是谁，我觉不出。脸，我觉不出。……回来的那些，你都认得。”**：黑潮最重的一处，重复是他一下一下想明白，留。
- **卷四“一口气，一段墙。”、“天亮的时候，北段一段墙也没丢。”**：前一句是设计备注定的风之心眼的写法，后一句是那一夜的结果，留。
- **卷五“行。”、她报路的“左三个。前头矮。身后有。”、“十九年……四回她都没让人碰着我。”**：“行”是他的一个字收住（卡里声口）；报路是费伊的三个字；四回数三遍是他心里数的，数的是她护着他，留。
- **卷六整卷**：费伊死的那一回，“说完，手指从环里滑出去了。她没拽。”“上了。打赢了。回过身来，环上没有人。”“没有人抓。”“那一回她报错了。”都是全书最该冷的地方；塔隆“他开了闸，没说话”在盖章词单上，可这是死人背上来的那一刻，又跟卷三塔隆说“好”对着，留。
- **卷七“三百一十。往右半步。对，再半步。”“你喘气快了。怕就说怕。”**：卡里台词样例原句，留。
- **卷七“好。今天说到这里。”“那边有什么？”**：停笔，全书的题，留。
- **后记“单子我照原样抄在这里。”、单子六行、“天亮以前十一个人都又看得见了。粮当夜过了桥。”**：单子是二幕原文，一字照抄；结果两句是书记记事，留。

## 四、跟卡对不上的地方（照原稿没改，等主会话定）

1. **他几岁到的阿卡迪亚**：书里卷二写“十九岁那年……约八百三十八年”，可他生于 817 年，十九岁是 836 年；卡里写十五岁（约 832 年）上场、五年没输、约 838 年到阿卡迪亚，算下来是二十一岁。书里“十五岁上场，往后五年没有输过”加起来也是二十，跟“十九岁那年”自己差一年。改法二选一：“十九岁那年”改“二十一岁那年”，或者“约八百三十八年”改“约八百三十六年”（卡里的 838 也要跟着动）。
2. **那张单子在哪里写的**：书里后记写“那天晚上他照旧来委托厅，没有说书，口述了一张单子”；卡里人物条写书记是“中旬五日在总会那一间屋子里照文森特说的写”。书里的写法跟“一旬一回在委托厅”的体例接得上，卡里的写法跟二幕“总会那间屋里”接得上，两边差一个地方。
3. **书头“一卷一个晚上”和“一旬一个晚上”**：口述从 971 年霜降月到 973 年蝉鸣月，一旬一回是六七十个晚上，书头篇幅栏又写“七卷，一卷一个晚上”，前言写“一个晚上说不到一千字”。七个晚上、五千字对得上篇幅，对不上两年。元信息没动，主会话要的话可改成“一个晚上说一段，七卷”，或者篇幅栏去掉“一卷一个晚上”。
4. 卷七“我今年一百五十六了”：他生在蝉鸣月中旬八日，口述在 973 年蝉鸣月中旬五日以前就停了，严格算是一百五十五。卡里旅伴条写 973 年一百五十六岁，照原稿没动，只记一笔。
