# 改动单｜黑潮（声口重写，11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/迷宫纪廊_黑潮.md`，重写稿 `底稿/洗稿_图书馆/重写/迷宫纪廊_黑潮.md`，人设包 `底稿/洗稿_图书馆/人设/黑潮.md`（新做的，烈刃的声口块照卡里 #896、#1339 抄，老歌者卡里只有一句，嗓门是我提炼的）。

正文约一百二十段，动了二十六段（扉页一、前言三、卷一二、卷二四、卷三四、卷四四、卷五三、卷六二、后记三），两成上下。元信息、目录、`## ` 小标题、〔注〕〔剧透〕标记和剧透段、各卷末“抬的人”名单、四条注脚（注一到注三是老歌者的，注四青墨）、设计备注一个字没动。事实、数字、人名地名没动。添进去的只有两个人的念头、一句对人说的话、一个停笔的理由，都落在书里或卡里已有的东西上（见第四节）。

这一本先说清楚一件事：烈刃的短句是他的本色，卡里写“句子像骑阵里的口令”，书里他自己说“冲锋不用长句”，注一老歌者也拿这一句打趣他。所以短句大半照留。要动的是短句后头那一枚章（这一句好、我服、我写了、我没看、照旧价、就这样、他们不听），和两个嗓门没拉开：原稿里老歌者代写的卷三跟烈刃一样短，除了头一段，看不出是另一个人在写。卡里烈刃真说话的时候，短句是冲着人去的，带问号、带“行啊”“都听见了？”，叫人去做一件事，落在水袋、火边的肉、喘气上；他跟老歌者为抬伤号的名字常争得脸红。这两样是这一回的抓手。

“X是抬人的”是全书的叠句（莱恩哈特的墙、亚龙、唱名者、卷六“那就是抬”），重复的分量在重复本身，留了四处，只把薇赛拉那一处换成一样东西（第 16 条）。

## 一、两个人的七个层面

### 烈刃·狮原（写，正文）

| 层面 | 他的 |
|---|---|
| 时间尺度 | 年份加月份，一仗一仗；一百二十年整着说；他自己的事按那年几岁、就职一年 |
| 自称、称呼 | 我；部里、部里的人；老歌者；两个王；战士叫名字或战名（巴鲁、阿鲁娜、萨嘎），不知道名字的照身上的记号叫（兽耳、耳朵上一圈烧痕、缺了左耳的） |
| 连接词 | 几乎没有，一句一事；“可是”“所以”各一两回；这一回添了几处逗号串，是他冲着人说话的时候 |
| 问号 | 原稿零个；这一回添三个，扉页、前言冲部里的人问（卡里台词样例“你没听出来？”），卷六“还喘得动吗？”（卡里原句），另把墙那边喊的“你们那边还有水吗”补上问号 |
| 手边的东西 | 刀、马、草、喘气、担架、斧子、火堆边的肉、盐、爪印 |
| 消息来源 | 只写站过的地方；不在的写明谁说的（跑信的人、白鸢的骑手、兽耳骑手、轰狱车夫、北段老兵、去了墙上的部里人） |
| 怎么停笔 | 每卷停在“抬的人”那一格；全书停在一条规矩和火上的肉 |

### 狮原部的老歌者（注，代写卷三）

| 层面 | 他的 |
|---|---|
| 时间尺度 | 歌的时间，一天、一阵风；“一代狮子里总有一头”那种几代的说法 |
| 自称、称呼 | 我；烈刃一律叫“他”，不叫名字；“部里的老人”“后头活着的骑兵” |
| 连接词 | 逗号一路串下去，注脚里尤其长 |
| 问号 | 没有，替烈刃问的话不写成问句 |
| 手边的东西 | 歌、火堆、他看了几十年的那个人（营门口站到天亮、调马再出去、吼一声） |
| 消息来源 | 部里的老人说、跟在他后头跑的骑兵说、后头活着的骑兵说 |
| 怎么停笔 | 注脚停在一件烈刃自己不写的事上；卷三停在他跟烈刃抬杠的那一句 |

尺子：烈刃量的是抬了几个、谁抬的；老歌者量的是这个人唱不唱得进歌里。卷三里他写天地的节拍照留（草叶贴地、红风撕开云、“拐了三里。”单起一行），那是歌者写一场仗的嗓门，只在头尾两处让他自己出来说话。

## 二、改了的

1. **扉页｜题句**
   - 原：“那首歌漏了抬伤号的两个名字。重唱。”
   - 改：“那首歌漏了抬伤号的两个名字，你没听出来？重唱。”
   - 为什么：这是卡里台词样例的原话，扉页截掉了中间那一问，两句断开读成两枚章。他说这句话是冲着唱歌的人去的，问的那一下是他的火气，照卡补回。**请主会话过目**，扉页想留短的可以退回。

2. **前言｜歌不对**
   - 原：歌不对。少人。
   - 改：这歌不对，少人。你们唱了一百二十年，没听出来？
   - 为什么：两个短判断单起一段，盖章。他“碰上不公，当众顶回去”，这本书头一个对着的就是部里唱了一百二十年的歌，冲部里的人问一句，跟扉页同一副口气。“一百二十年”是上一段的数。

3. **前言｜别的书比我写得全**
   - 原：别的书比我写得全。这一本少，少的地方是我不知道。
   - 改：别的书比我写得全，要全的，去读别的。这一本少，少的地方是我不知道。
   - 为什么：前一句单说是谦词，他不说谦词，说成一句叫人去做的事（口令那一路），后一句照留，是他的规矩。

4. **前言｜短就短**
   - 原：老歌者说我写得太短。短就短。冲锋不用长句。
   - 改：老歌者说我写得太短。嫌短，卷三归他写，他爱写多长写多长。冲锋不用长句。
   - 为什么：“短就短。”盖章。他跟老歌者是争惯了的（卡里人间侧），顶回去用的是书里现成的事：卷三确实是老歌者写的。“冲锋不用长句”照留，注一引的就是这一句。

5. **卷一｜一千零九十二**
   - 原：一千零九十二。这个数我记得。接的人有多少，通报上没写。
   - 改：一千零九十二，这个数我记到今天。接上来的写了数，下去接的那些人有多少，通报上一个字都没有。
   - 为什么：用户点名的“报一个数加两个字”。数留着，“我记得”说成一个记了一百二十多年的人会说的“记到今天”；后半句是他写这本书的缘故（只记被救的、不记抬的），把“没写”说出他的不平。

6. **卷一｜抬回来的、没有抬回来的**
   - 原：少的那几个，有的是抬回来的，有的是没有抬回来的。
   - 改：少的那几个，有的是抬回来的，抬不回来的，就留在草里了。
   - 为什么：“有的是X，有的是没有X”否定对称。他是草原上的人，抬不回来的落在哪里他知道，一样东西（草）替掉一个“没有”。

7. **卷二｜我写了**
   - 原：老歌者说这一句要写进去，我写了。
   - 改：老歌者说这一句要写进去，我跟他争了半夜，还是写了。
   - 为什么：“我写了”盖章。上一句“我不喜欢这一条”，他是不情愿写的，卡里两人常为写什么、唱什么争得脸红，“争了半夜”是这一处的情绪。添的是一个争的动作，没添事。

8. **卷二｜这一条我喜欢**
   - 原：……人多的地方、粮走的路先守。这一条我喜欢。
   - 改：……人多的地方、粮走的路先守。这一条我喜欢，我在草原上也是这么排的，人多的营先护。
   - 为什么：“这一条我喜欢”跟上一段“我不喜欢这一条”对称成一对章。补一句他为什么喜欢，落在他自己的事上：卷二他护三个部的冬营、卷三护南头收伤号的营，都是人多的营。

9. **卷二｜他们不听**
   - 原：我说叫我名字。他们不听。
   - 改：我说叫我名字。他们不听，不听就不听吧，叫狮子也不丢人。
   - 为什么：“他们不听。”收段冷收。他兴奋起来笑声大、爽快，这一处是他少有的自夸，自己先笑着放过去，比一句冷收像他。

10. **卷二｜第七夜那个骑手**
    - 原：我写上了。兽耳，耳朵上一圈烧痕，白碑第七夜，抬了三个。
    - 改：不留名字也行，我写他的耳朵。兽耳，耳朵上一圈烧痕，白碑第七夜，抬了三个。
    - 为什么：“我写上了。”盖章。上一句骑手说抬人的不留名字，他回的是一个办法（卡里“对战士叫名字或者战名”，没有名字就照身上的记号叫），记录那一句照留。

11. **卷三（老歌者）｜我先写了**
    - 原：写到抬人的地方他要我先写。我先写了。
    - 改：写到抬人的地方他要我先写。我依了他，这件事上跟他争，回回是我先松口。
    - 为什么：“我先写了”盖章，而且跟烈刃的“我写了”一模一样，两个人一个嗓门。老歌者让一步，顺口带出他们俩争了多少年（卡里人间侧），他自己的“我”头一回有了口气。第 13 条是这一句的下文。

12. **卷三（老歌者）｜萨嘎**
    - 原：萨嘎是前锋队里斧子使得最好的一个。
    - 改：萨嘎是前锋队里斧子使得最好的一个，火堆边我唱过他好几回，往后再唱，只唱得到他那一把斧子了。
    - 为什么：原句是一句介绍，老歌者在这里没有自己。歌者量人的尺子是唱不唱得进歌，萨嘎死在上一段，“只唱得到他那一把斧子”是他的悼念，也接上烈刃名单里“他的斧子把我抬过去了，写他”。添的是“唱过他好几回”，部里的歌唱冲在前头的人（前言），前锋队里斧子最好的那一个被唱过，是顺下来的。

13. **卷三（老歌者）｜荒原血风这个名字**
    - 原：他不喜欢这个名字，说太像在夸那一阵风。他说风是萨嘎的斧子招来的。
    - 改：他不喜欢这个名字，说太像在夸那一阵风，风是萨嘎的斧子招来的。他这么说，我就这么写，可火堆边唱起来，我照旧唱荒原血风，这一回我不松口。
    - 为什么：卷三收在烈刃的一句转述上，读不出是谁写的。老歌者在这里跟他抬一回杠，接第 11 条“回回是我先松口”，两个嗓门在全书唯一一回由老歌者执笔的地方分开。名号是人叫开的，世界认的是那件事，这一句没碰凝名的规矩。

14. **卷三（烈刃）｜一半是他们的**
    - 原：这一卷的数，一半是他们的。
    - 改：这一卷的数，一半是他们的。老歌者，往后唱这一卷，别只唱我那一半。
    - 为什么：原句留着，是他的账；后头冲老歌者交代一句，是他“非要老歌者第二天唱进去”的那一下（卡里人间侧），也回了第 13 条老歌者的抬杠。

15. **卷四｜这一句好**
    - 原：这一句好。部里的门照这一句开。
    - 改：这一句比八百五十八年那一道好，头一行写的就是回家的人。部里的门照这一句开。
    - 为什么：“这一句好。”三个字盖章。他夸一条令，拿卷二那一道封门令来比，好在哪里说出来，都是书里的事。

16. **卷四｜挑的是抬人的事**
    - 原：我挑几件记。挑的是抬人的事。
    - 改：我挑几件记，挑抬人的，打得漂亮的那些，歌里都有了。
    - 为什么：后一句单起是冷收。他挑抬人的是因为歌里只唱打得漂亮的（前言），把缘故说出来，连成一口气。

17. **卷四｜照旧价**
    - 原：部里吃过他的盐。照旧价。
    - 改：部里吃过他的盐，到那时候他卖给部里的还是旧价，一枚铜币也没往上加。
    - 为什么：“照旧价。”三个字，用户点名那一路。粮路断了九天，盐贵是顺下来的，他服巴罗的是这个，说成一个吃过人家盐的人会说的话。

18. **卷四｜这一回我服**
    - 原：这一回我服。倒下的人他念名字。
    - 改：这一回我服他。倒下一个，他念一个名字，部里的歌一百二十年都没做到这一样。
    - 为什么：“这一回我服。”盖章。卡里他“强者服气，肯护着弱者的那一只爪更服气”，服莫尔图斯服在念名字，正是他跟部里的歌较劲的那件事，把这个对比说出来。

19. **卷五｜你们那边还有水吗**
    - 原：……隔着墙喊的头一句是，你们那边还有水吗。
    - 改：……隔着墙喊的头一句是“你们那边还有水吗？”换我也先问这个。
    - 为什么：问话照口径用问号，补引号。添的半句是他的：卡里台词样例“水袋先往后传”，他打仗先想的也是水。

20. **卷五｜薇赛拉**
    - 原：这一个我要写。她是抬人的。
    - 改：这一个我要写。船上放不下担架，她那一根针就是担架。
    - 为什么：“她是抬人的。”是叠句，可这一处紧跟“这一个我要写”两枚章连着落。叠句另外留了三处（莱恩哈特的墙、亚龙、唱名者）加卷六“那就是抬”，这一处换成一样东西，意思一样：缝伤口就是抬。

21. **卷五｜我服唱名者**
    - 原：我服唱名者。他们干的是抬人的活。
    - 改：唱名者，我是真服。他们干的也是抬人的活。
    - 为什么：跟第 18 条“这一回我服”句子形状一样，一本里两枚同样的章。前后两回，第二回说重一点（真服），“也”把唱名者接到前面那些抬人的人后头。

22. **卷六｜我没看**
    - 原：我按了。我的印按在第几行，我没看。
    - 改：我按了，按在第几行没顾上看，后头还排着一长串等着按的。
    - 为什么：“我没看。”盖章。一千三百零四枚印，他没看是因为后头有人等，他总顾着身后的人（卡里“火一上来先护住身后的人”）。

23. **卷六｜数后头的喘气**
    - 原：往下走的时候，我数后头的喘气。喘气在，人就在。
    - 改：往下走的时候，我数后头的喘气，隔一阵喊一声，还喘得动吗？后头有人应，我就接着走。喘气在，人就在。
    - 为什么：“喘气在，人就在”照留，是他的尺子。“还喘得动吗？”是卡里台词样例原句，他不回头（Passive 荒原狮心：回头那一步得有别人替他看），所以写成喊，不写成回头看。

24. **后记｜我不唱这个数**
    - 原：这个数部里的歌唱。我不唱这个数。四十七里有我。
    - 改：这个数部里的歌唱。我不爱唱它，四十七里有我，自己的仗自己不唱，这是部里的规矩。
    - 为什么：“我不唱这个数。四十七里有我。”否定加冷收。不唱的缘故书里有：卷三老歌者写的“部里的规矩，自己的仗自己不唱”，让他自己把这条规矩说一回。

25. **后记｜我说没有**
    - 原：我说没有。
    - 改：我说没有，空着一百零三格，哪能算写完。
    - 为什么：一句四字单起一段。他顶回老歌者的那一下，用上一段的数。

26. **后记｜就这样**
    - 原：就这样。
    - 改：就写到这儿。火上的肉该翻面了。
    - 为什么：“就这样。”盖章收尾，书的最后一句。研读笔记说停笔要有理由；上一段他刚说完头一块肉留给守队尾的人，下了马他说的是“宴上的肉烤得够不够火候”（卡里观察与用词），停在火上的肉上。

## 三、留着没改的冷句和缘故

- **前言“所以我写这一本。”“照部里的规矩写。”**：立书的那一句，口令的样子，全书只有这一处，留。
- **卷一“我那年十七。就职一年。……嗓门比刀大。”**：报岁数是口令式的自我介绍，“嗓门比刀大”是他的自嘲，留。
- **卷一剧透段“那一团没了。会长没有回来。”**：死的地方，留。
- **卷二八百六十年那一天**（我们往北跑。跑了一整天。／潮在后头追。草在前头倒。／三个部的帐篷一顶没烧。）：冲锋的节拍，“冲锋不用长句”，一句没动。
- **卷二“我不喜欢这一条。可是这一条救的人比它关在外头的多。”**：他服理的那一下，有“可是”撑着，不是章。
- **卷二莱恩哈特“那一回的抬人格子，我空着。可是……就是抬人的。”**：叠句头一回，留。
- **卷三老歌者写的那一场**（前锋队迎上去，冲了一回，没有回来。／拐了三里。／南头那一处营，一个人也没有丢。）：歌者的节拍，死和结果，留。
- **卷三“我撞偏三里，他们抬远三里。”**：对仗，可这是他算的账，是全书的题眼之一，留。
- **卷四“我说刀也是。”**：跟加兰斗嘴，是对答里的一句顶回去，活的。
- **卷五“墙是一面，背是两边的。”**：一句画面，全书唯一一处格言式的句子，留。
- **卷五亚龙“那一头亚龙天亮以前死在泊架上。它是抬人的。”**：死的地方，叠句，留。
- **卷五剧透段凑不满的斩首**（回来的两个里有我。……他已经凉了。……空着，按爪印。）：全书最冷的一处，他自己背回来的人，留。
- **卷六“退了。”**：潮没了来处的那一下，一个字的段，留。
