# 改动单｜决斗图谱（声口重写，11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/命路厅_决斗图谱.md`，重写稿 `底稿/洗稿_图书馆/重写/命路厅_决斗图谱.md`，人设包 `底稿/洗稿_图书馆/人设/决斗图谱.md`（作者卡里没有条目，嗓门是照书头和白鸢骑士城那一条提炼的）。正文约九十段，动了 11 段（11 行），前言两段、卷一三段、卷二一段、卷四两段、卷五三段。元信息、扉页、目录、`## ` 小标题、〔图〕〔〕标记、每幅图上头那一行题、四条注脚（三位后来人和青墨）、设计备注一个字没动。事实、数字、人名地名没动，没添原稿没有的事。

这一本本来就是教场的规程书，一招一图，图上一行题，题下一两句教法。短句大半是他的口令，不是冷笔。改的只是散文里盖章收尾、报数加两个字、同一句话说两遍的那几处，改成一个管了二十三年比武的人会接的那半句。

## 一、七个层面（欧特温·马尔纳，一个作者）

| 层面 | 定法 |
|---|---|
| 时间尺度 | 二十三年、一年一回的杯、一场、三回合；房里的规矩按年份数（约300年、420年、约500年）和“两百多年”“一百多年里” |
| 自称称呼 | 我、我们（剑术官房里、白鸢、骑士城）；下场的人教的时候叫“你”，说起来叫“下场的人”“对面”“他”；剑神不点名，叫“那一位” |
| 连接词 | 很少，一句一条；用“要是”“因为”“照……”；这回添了“干脆”“倒是”“好歹”“说到底”各一处，都在他议论的散文里，教法那几句不添 |
| 问号 | 原稿零。前言替来问规程的人问了四句（几回合？用什么？谁裁？输了怎样？），字一个没改，只把逗号换成问号，是他转述别人的问。他自己全书不发问 |
| 手边的东西 | 白杖、白灰线、两副担架、册子上的手印、白盾、马厩那一盏灯、坑沿的白灰 |
| 消息来源 | 剑术官房里定的、白鸢的老话、骑士的叫法（敲门）、他自己在场看见的（三回不肯认输） |
| 怎么停笔 | 教法落在一个动作或一条规矩上（举左手、捡起来去补、杖落下去）；议论落在他自己身上（我也没想出来、我到今天也不知道）；全书停在圈和杖上 |

## 二、改了的

| # | 位置 | 原句 | 改后 | 为什么 |
|---|---|---|---|---|
| 1 | 前言第一段 | 我做剑术官二十三年。管长枪道，管石场上的比武，管蝉鸣月下旬的白鸢杯。 | 我做剑术官二十三年了，长枪道、石场上的比武、蝉鸣月下旬的白鸢杯，都归我管。 | 报数加三个“管”排比，是简历的口气。一个人自我介绍不会这么排，说成一句，数留着 |
| 2 | 前言第二段 | 问的都一样。几回合，用什么，谁裁，输了怎样。我答了二十三年，嗓子答哑了，写一本。 | 问来问去就是那几句。几回合？用什么？谁裁？输了怎样？我答了二十三年，嗓子都答哑了，干脆写成一本，往后谁再来问，我把书翻到那一页给他看。 | “写一本”三个字盖章收尾。写书的缘故是图省事，正常人会把这一点说出来；四句问是他在学来问的人，字没动，加了问号。“翻到那一页”接上书的样子（一招一图），也跟注四那一年有人翻第六幅对得上，不是新事 |
| 3 | 卷一 圈里的规矩 | 祂在纷争纪就倒了。我们画的圈里没有神。三条还在，因为没有人想出比它好的。 | 祂在纷争纪就倒了，我们画的圈里没有神。三条倒是一直用到今天，没有人想出比它好的，我坐在这个位子上二十三年，也没想出来。 | 三个短句连着收。“我们画的圈里没有神”是全书末段要回响的那一句，留着；后面换成管规矩的人对自己的一句自嘲，他改过面板那一条三回，三条一回没动，这话他说得出 |
| 4 | 卷一 担架 | 担架不撤，比武不开。 | 担架从头摆到尾，担架没摆好、祭司没坐下，我的杖不举起来。 | 八个字的对称口号，读着也拗（“不撤”跟“不开”接不上因果）。他是举杖开场的人（卷一第二幅），规矩落到他手里的杖上，意思没变：担架一直在，不到不开 |
| 5 | 卷一 冠军迎战 | 我画了点地的那一下。哪一年有冠军在墙上站过，他知道该怎么做。 | 点地的那一下我还是画上了。哪一年再有冠军在墙上站过，翻到这一页，他自己知道该怎么做。 | “我画了”是盖章。前面刚说这一下省了，他偏画上，加“还是”是他的执拗；“翻到这一页”接注四（865年第六幅叫人翻得最多），没添事 |
| 6 | 卷二 英雄下场 | 那一年的木栏是石头砌的。 | 那一年的木栏只好拿石头砌，木头的立不住。 | 一句冷收。管场地的人说这件事会带上缘故，缘故照上一幅（极境就得包铁）和这一幅（枪没碰上草先倒）推的 |
| 7 | 卷四 压剑出剑 | 剑和盾一起动，数一下。 | 剑和盾一起动，只数一下，数到第二下，他的剑早抽回去了。 | “数一下”三个字收住，读的人不知道数什么。教场上喊拍子的人会接着说慢了会怎样，跟卷二“打在盾边上，你自己从马上带下来”一个路子 |
| 8 | 卷四 盾裂了 | 盾裂了，事照旧是你的。 | 盾裂了，事还是你的，比武的输赢拿不走它。 | “照旧”是盖章词。补半句把比武和讼斗分开：比武拿不走，到了卷五讼斗，输的人要自己刮掉，前后对得上 |
| 9 | 卷五 坑 | 让快的那一个慢一点，让真话有机会。 | 让快的那一个慢一点，好歹给说真话的那一个留一点机会。 | “让真话有机会”像一句标语。他写这一卷是因为断坏过，自己知道坑也只是一道布，加“好歹”“留一点”，口气是他在讼斗这一卷一贯的老实 |
| 10 | 卷五 认输就停 | 赢的那一个，盾上那一件留着，往后谁也不许再提。出了圈，这件事石场上不许再提。 | 赢的那一个，盾上那一件留着。出了圈，这件事石场上谁也不许再提。 | 两句“不许再提”连着说，是重了，不是重复到变的那种声口。并成一句，意思一个字没少 |
| 11 | 卷五 不肯认输的末段 | 讼斗断不了真的东西。我写这一卷…… | 说到底，讼斗断不了真的东西。我写这一卷…… | 单起的判断句，前头刚讲完三回不肯认输。加“说到底”，是他讲完三回以后的那一口气，后面的长句原样 |

## 三、留着没改的冷句和缘故

| 句子 | 缘故 |
|---|---|
| 每幅图上头那一行（圈三十步。下场先念。让一寸。举左手。盾裂了，事还在。坑。……） | 书头写明“每一幅图上头一行字，字是剑术官自己写的”，是题，教场的口令，短是它的格式 |
| 扉页“下场以前，先说好怎么出圈。” | 题句，整本书的一条底线，不动 |
| 前言“我写下来，因为断得不好的那几回，我都在场。”“画得丑的，照丑的描。” | 前一句是全书的缘起，后一句是他少有的干笑话，都是他 |
| 卷一“杖落了还动手的，判负，这一辈子不许再下白鸢的圈。”“不报备就在石场上动手的，不算决斗，算斗殴，归城卫管。” | 规矩本身，该硬 |
| 卷一“这一条我们改过三回，回回是因为有人死了。” | 死人的地方，全书该冷的一处 |
| 卷二“让一寸，他的枪就落空，你的枪还在。” | 对称，可这是教场上的顺口诀，下场的人要记得住，留 |
| 卷二“狮鹫是去看的，不是去撞的。” | 白鸢的老话，他引来当道理（卡里写法略不同，见第四节） |
| 卷三“白鸢的骑士管这一下叫敲门。”“举左手不丢人，丢人的是举得太晚。” | 行里的叫法和教头的话，活人会这么说 |
| 卷四“救过人的，多半护身。斩过东西的，多半先出手。” | 读盾的两条口诀，并列是教法的样子，不是冷收 |
| 卷五“灯灭了，谁去添油，谁就是先认了。” | 规矩本身 |
| 卷五“剑分不出谁说的是真话，剑只分得出谁的剑快。” | 讼斗这一卷的题眼，跟注二判词“剑断不了真假”前后照应，留 |
| 卷五三回不肯认输（第三回那个人没有死，他的一只手没有了。） | 死伤，平铺不接感想，全书第二处该冷的地方；“我到今天也不知道”已经是他的老实话 |
| 卷五末两段（立三条的那一位自己没有认输。我们画的圈里没有神，我们只有三条，和剑术官手里一根杖。） | 收尾，回到卷一那一句，冷收留给这一处 |

## 四、跟卡对不上的地方（照原稿没改，等主会话定）

- 卷二“白鸢的老话，狮鹫是去看的，不是去撞的。”卡里 `迷宫纪·城邦｜白鸢骑士城` 写的是“狮鹫不是去打的，是去看的”。意思一样，字不同，老话要不要逐字对，主会话定。
- 前言落款写“迷宫纪六一二年蝉鸣月”，正文和注脚年份都写阿拉伯数字（420年、641年），书头写“约612年”。可能是有意让落款像手写，没动。
- 卷一和末段两回“我们画的圈里没有神”，是有意的首尾呼应，没拆。
