# 《别一个人下井》声口重写｜改动单（11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/孩子的一架_别一个人下井.md`，重写稿同目录 `孩子的一架_别一个人下井.md`，人设包 `底稿/洗稿_图书馆/人设/别一个人下井.md`（新做的）。

全书大半是顺口溜：十二首各两节，照《蓬头彼得》的路子，数数、拟声、叠字小名、一层两层往下排，派活说明第 3 条“童谣不动”，十二首一个字没碰。散文只有前言七段（连落款）和末页三段，动了前言 3 段，末页没动。事实、数字、人名地名、元信息、〔图〕、注脚、设计备注一字没动，没有添原稿没有的事（添的是给念书的大人的交代，不是新的事）。

## 一、作者的七个层面（冒险者公会安全科，约迷宫纪290年编）

1. **时间尺度**：每年、这些年、天一黑、夜里、天亮；对孩子说的是“等你长大了”。不报年份，科里的人记的是一年一年拎回来的孩子。
2. **自称称呼**：自称“我们”（科里一伙人），前言叫念书的大人“你们”，孩子叫“他”；末页转过身叫孩子“你”。书里的孩子都是叠字小名，全名只露一回（贝尔纳·绳匠，那一首的笑点）。
3. **连接词**：可是、就、等……那时候。不对仗，不转书面的弯。顺口溜里是“一……两……”“爬一层……爬两层……”的数数，那是体裁。
4. **问号**：两处，都是问孩子的，前言教大人问的“你会不会也这样？”，末页的“对吧？”。别处不问。
5. **手边的东西**：晾衣绳、木桩、绞盘、结算台上一枚一枚的钱、绳头、旅印。说事拿这些说，不讲道理。
6. **消息来源**：只认拎回来的孩子和自己人：“这些年拎回来的”“他们自己来科里说”“画图的人照他在井里看见的画”。不引规章、不引书。
7. **怎么停笔**：停在绳上，“绳那一头，有人攥着”，跟扉页“底下黑，上头有人等你”接上。

嗓门的总样子：半夜去井口拎过孩子的人，坐下来给爸妈写几句交代。直，实，一句一件事，带一点没好气的疼，知道孩子坐不住、嘴硬、夜里会怕。原稿前言已经大半是这个样子（“这本书吓人，是我们故意的”“从绞盘底下钻过去”），改的只是三处像盖章、像告示的收尾。

## 三、留着没改的冷句和缘故

- **十二首顺口溜全部**：体裁就是短句、数数、拟声、叠句，派活说明第 3 条不动。里头像冷笔的几处也照留：第一首“上头的灯，没有了。”、“一，二，三。”，第五首“呜。”，第七首“扑通。”，第八首“一个不少，／走了。”（贝贝被落下的那一下，是全书最吓人的一拍），第六首老向导“记住了，比你老六百岁的规矩”（`迷宫纪廊_井下层带志` 碑藤那一条“比我老六百年”的孩子版），第四首祖母“雾里那个，不是我。”。
- **扉页“底下黑，上头有人等你。”**：题词，本来就该短，末页最后一句接的就是它。
- **前言“这本书吓人，是我们故意的。”**：一句一段，可它不是冷收，是安全科的人开门见山，有脾气，留。
- **前言“名字是改过的，事是真的。”**：有一点否定对称的样子，可这是这类书头上惯常的一句交代，后面紧跟着“书里那一个就是我，名字别改回来”把它化开了，留。
- **前言“你在上头，你没事。”**：教爸妈说给孩子听的原话，短才哄得住孩子，又接扉页那句，留。
- **末页三段**：“这一页是给你的。”“你不会一个人下井，对吧？”和停在绳上的那一句，已经是对着一个孩子说话的口气，带问，带手边的东西，不动。
