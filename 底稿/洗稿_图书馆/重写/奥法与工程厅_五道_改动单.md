# 改动单｜五道（声口重写，11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/奥法与工程厅_五道.md`，重写稿同目录外 `底稿/洗稿_图书馆/重写/奥法与工程厅_五道.md`，人设包 `底稿/洗稿_图书馆/人设/五道.md`（新做的，卡里没有她的人物条和声口块，嗓门是照书头、姓氏清单和两条帝国史提炼的）。

散文（前言到庆典以后）59 段，动了 18 段（三成），原来单起一行的“一圈。”并进了上一段。书头元信息、扉页、`## ` 小标题、括号里的编注、〔图一〕到〔图五〕、〔注一〕〔注二〕标记、三条注脚、设计备注一个字没动。事实、数字、人名地名没动，没添卡里和书里没有的事（添的是她的缘故、宴上的比方、左手和那一口气这些书里已有的东西）。

## 先说这一本的判断

原稿的毛病正是用户点名的那一路：“四条，打架。”“一圈。”“五样，一口气里。”“当中是我。”“也许。”，报一个数接两个字，段段一枚章；另有“不是X，是Y”一本用了六回（四条打架、递、心跳、做不到、本事、名字），成了架子。可尤尼娅是上城人家的女儿，从小替母亲排宴席，句子该是完整的、交代事情像吩咐管家，冲着往后背她名字的学徒说话，不是这样一刀一刀地剁。所以改法是：冷收的那一句换成一个排座的人会接的话（带缘故、带一样宴上的东西、冲着“你们”），“不是X，是Y”留母亲那一句、图四那一行小字和末尾“名字是我家的，不是我的”三处，别的拆开。她那几处真冷的（流鼻血、母亲那一句、家里替我应了、不能）留着。

| 层面 | 尤尼娅 |

| 连接词 | 所以、可是、后来；她推下一步时用“所以”，改主意时用“后来”；这一回添了“可”“后来我才想明白”“倒也”各一处 |

## 四、跟卡对不上、要主会话看的

1. **〔注二〕标记的位置**：正文〔注二〕挂在末段“管家写的”后头，可注二说的是凯尔萨斯借散页、第三叠里多夹了一张环心空着的环，跟请帖上的名字不相干；注三（“反着写的那一行，本馆照过了”）正文里没有标记。读着像注二该挂在第三叠末尾、注三该跟〔注一〕挂在一处。照原稿没动。
2. **“塔林这一百年教的格子”**：卡里是约9300到9500年塔林把格子写上纸，她约9560年起笔，“这一百年”说得过去，严格算是两百来年。照原稿。
3. 跟 `塔林日志` 重写稿卷三千零一对过：五样（浮起的山头、套腰的锁环、水墙、削平的山壁、冷白的火）、满城没人出声、火灭了才喊、她只报“五道，一齐”，都对得上。这一回她落地前后的话没改，只改了“五样，一口气里”那一句的说法，事没动。
4. 卡里没有她的人物条，人设包是提炼的。她的位阶书里一处没写，照 `塔林的手艺` 的锁。
