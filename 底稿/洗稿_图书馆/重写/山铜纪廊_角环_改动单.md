# 改动单｜角环（声口重写，11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/山铜纪廊_角环.md`，重写稿 `底稿/洗稿_图书馆/重写/山铜纪廊_角环.md`，人设包 `底稿/洗稿_图书馆/人设/角环.md`（新做的，从底卡 #875 凡世至强和山铜纪旅伴条抄的两份声口块，加一段提炼）。

正文（前言到卷五，目录、图不算）79 段（列表一条算一段），动了 11 段：前言 2，卷一 2，卷二 2，卷三 2，卷四 3。卷五一个字没动（整卷是给外乡人的清单，一条一事，正是他“一句一道令”的体例），扉页题句、第十九页、五条注脚（穆拉、军府书记、清点人青墨）、设计备注、元信息栏、`## ` 小标题、〔图一〕〔注〕〔剧透〕标记一个字没动。卷三六阶的列表（凭什么、欠什么照角环条原意）、卷二“怎么上”五步的列表没动。事实、数字、人名地名没动；添的只有他的交代、理由和一句很干的玩笑，用的都是书里已有的东西（石屋递名、场心的地、卷五的鞋、穆拉答疑、灰市街的邻居）。

这一本的底子跟航图、焚冰近：瓦尔德拉克卡里就是“短，硬，一句就是一道令”，短句是他的嗓门，不拿来洗长。要分开的是两种短：下令、报数、交代规矩的短照留；盖章、格言、否定对称的短（就够了、不怪、不是不许是没有人来、规矩是人守出来的不是錾出来的、两个都没错、他的事不说、认了），换成他会接的那半句，多半是“你该怎么做、该找谁”，或者一个他看得见的理由。

## 一、七个层面

| 层面 | 瓦尔德拉克·烬角 |
|---|---|
| 时间尺度 | 自己的事记到旬和日（七百四十二年炎潮月中旬三日），城里的事记到年和月（去年炎潮月，约三百年），七百九十年一笔带过；年份写中文数，跟钢上錾的落款一样 |
| 自称称呼 | 我；读者是你、外乡人；别人照差事叫（翻译、裁者、保人、炉匠、执火席的人、王前席的人）；书里点名的只有穆拉、贾比尔、卡尔冈、提兹；赎罪军那一人不点名；说到自己的位子用“族里的王”“我面前的那几席”，不说魔神将、不说军锋 |
| 连接词 | 几乎没有，一句一事，句号断开；“所以”全书一处（所以錾一回）；“先……再……”“要……先……”是他下令的骨架 |
| 问号 | 原稿零个。改了一处：前言外乡人问的五件事，原来是五个句号，照卡面口径问话用问号改成五个问号。他自己的话里没有添问号，他不问读者，他交代 |
| 手边的东西 | 角、环、铜丝、包角的布、石壁、冷水池、场心那一圈蓝缝、钟三下、鞋底、焦了的烤肉、钢页和錾刀 |
| 消息来源 | 自己看见的、石壁上刻的、族里的老规矩、酒馆里讲得最多的；问不明白的推给穆拉；他自己不肯说的（为什么用左角碰环、二十个人的名字、第十九页）交给注脚里别人的字 |
| 怎么停笔 | 每卷落在一件要你做的事上（问穆拉、换鞋、递名），全书停在“就这些。” |

## 四、跟卡对不上、要主会话定的（照原稿没改）

- 卷一“我派二十一个人下去……回来一个”跟“断口上二十道，一道一个人”：卡里也是这个账（下去二十一个回来一个，法里斯死在伊德娜背上，二十个没回来、刻二十道），对得上；只是书里“回来一个，背回来的时候已经没有声音了”读者会以为二十一个全死了、二十道少一道。照卡里法里斯算不算在二十道里卡里没说，照原稿。
- 卷二“我在城门里戴枷那一夜，贾比尔……叫我下去进圈”：卡里是中旬二日夜里（第二夜），当夜戴枷是中旬一日。书里“戴枷那一夜”可以读成戴着枷的那几夜里的一夜，没改。
- 卷四“站在圈外的那一场”标题说站在圈外，正文是他自己下到场心挨顶，结尾是对方把他拉起来（照卷二是赢的人拉输的人）。标题指的大概是那个兄弟死在“线外”，书里没点明，照原稿。
- 注脚五条一个字没动（派活说明青墨不动；注一到注四是穆拉和军府书记添的，另两副嗓门，前几本的做法也是注脚不动）。voice_check 报“穆拉和书记像一个人”，两人各七句、都是添注的平话，原稿就报，要拉开得动注脚，等主会话说。
