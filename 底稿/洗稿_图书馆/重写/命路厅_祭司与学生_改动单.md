# 《祭司与学生》声口重写｜改动单（11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/命路厅_祭司与学生.md`，重写稿 `底稿/洗稿_图书馆/重写/命路厅_祭司与学生.md`，人设包 `底稿/洗稿_图书馆/人设/祭司与学生.md`（作者卡里没有条目，子任务照书头和耶万的条目提炼的）。

这本是剑术书，一页一图，图下两行念词是祭司教学生时嘴上念的口诀，跟歌诀一样本来就是短句，三十二页的念词一个字没动。散文的部分（前言、各页图下“我怕往后忘了”的那几行、各段开头和收尾）约三十八段，动了七段，都是在原句后头接半句或把一句冷收换成他会说的话，原句的事实都留着。书头元信息、扉页、目录、`## ` 小标题、〔〕图注、注脚三条、设计备注一个字没动。没加原稿没有的事，添的只是祭司此刻的念头、理由和他对学生说的一句交代。

## 一、七个层面

| 层面 | 祭司的 |
|---|---|
| 时间尺度 | 两头：一辈子（十九岁下仗、殿里四十年、年轻时在七王的阵里）和一堂课（头一个月、一刻钟、站到天黑、第二天早上开殿门） |
| 自称、称呼 | 我；对着学生、往后拿这本学剑的人叫“你”，念词里对着对练的人也是“你”；学生、我教的人；来问的人；诸国剑场上的老师；那位英雄；耶万用祂；河谷那一位剑神不点名 |
| 连接词 | 逗号串下去，“往后”“是因为”“所以”“要是……就……”；没有对仗，没有“然而” |
| 问号 | 几乎不用。替读者问的那一句（管仗的神的祭司不教剑，教什么呢）收句号，是反问；念词里的“收不收”也不加问号 |
| 手边的东西 | 一尺半的短剑、比脸大一圈的小圆盾、殿后头的院子、扫帚和灯、殿门、地上画的圈、剑鞘 |
| 消息来源 | 自己在七王阵里亲眼见的；学生站了一夜说出来的；剑场上的老师怎么教；河谷那位剑神的规矩，照实说是别家的；殿外的事听来问的人说 |
| 怎么停笔 | 落在一个动作上（剑回鞘、盾上背、往殿门走），或者一件不写的事（后八页图底下没有我写的话）。不解释刀子 |

尺子是“收在哪里”：说什么都绕回打完了怎么收、知道为什么打。眼睛先落在学生的手、盾、脚下那一步，和学生敢不敢迈那一步。人谦，前头三样说别人教得比他好，只有收那一样他说两回是这座殿自己的。

## 二、改了的七处

1. **前言第二段｜打了没打**
   - 原：来问的人多半答不上，回去了，有的打了，有的没打。
   - 改：来问的人多半答不上，就那么回去了。回去以后，有打起来的，也有到底没打的，这些我都是听下一拨来问的人说起的，我自己只在殿里扫地。
   - 为什么：“有的打了，有的没打”是否定对称的冷收。一个扫地的祭司说殿外的事，会顺嘴说他是怎么知道的（消息来源），扫地是前言头一句就有的。意思没变（有打的有不打的）。“往后两国要开仗，先派人到殿里来问”是原稿前一句，下一拨来问的人从这一句来，不是新事。

2. **第一守｜头一个月**
   - 原：我教人，头一个月只教这一守。
   - 改：我教人，头一个月只教这一守，这一守站不稳，后面六守站了也是摆样子。
   - 为什么：报一个时长收段。当老师的说这句话会接一个理由，理由就是这一守“最安稳”（上一句）。

3. **第七围那一段｜对了一半**
   - 原：我说对了一半。另一半在这一本的最后一段。
   - 改：我跟他说，你想对了一半，先去吃饭。另一半在这一本的最后一段，那时候他还没学到那里。
   - 为什么：两个短句一顿一收，像盖章。学生站了一整夜，老师当面会先顾着人（先去吃饭，照第二十四页念词“明天还有饭吃”那一路）；“还没学到那里”说清为什么那时不告诉他。另一半指第三十二页祭司先退一步，原稿的钩子留着。

4. **缚那一段｜我画了**
   - 原：退回去那一页，诸国剑场上的老师多半不画，他们觉得丢人。我画了。
   - 改：……他们觉得丢人。我偏要画，学生要是只学会往前，到了外头也就只会往前。
   - 为什么：“我画了。”正是口径里点名的那一路（不画／画了，否定对称加两个字收）。他偏要画是有缘故的，缘故在书后头他亲眼见的那个举着灭了火的盾往前冲、没有回来的人，这里不点破，只说他怕学生只会往前。

5. **缚那一段｜缚住老师**
   - 原：第二十页是学生缚住了我。我画进来，是因为学生总得有一天缚得住老师。
   - 改：原句后加“真到了那天，当老师的别挣，低头看看他是怎么缚住你的。”
   - 为什么：原句是一句格言收住。图上画的就是“祭司没有挣，低头看着”，他把自己画里的样子说成一句给往后当老师的人的交代，这是他对着“你”说话的习惯。没有新事。

6. **第二十二页｜火为什么不烧人**
   - 原：我问过他，火为什么不烧人。他说，他想好了收在哪里。
   - 改：原句后加“我那时候年纪轻，听了只当他嫌我烦，随口打发我。”
   - 为什么：英雄那一句短答是这一本的题眼，原样留。冷的是祭司就这么转述完收住，像替英雄盖了章。正常人回头讲年轻时问过的一句话，会顺带说自己当时怎么听的；他当时没听懂，这一整本就是他后来懂了的东西，不用再说破。“年纪轻”照前言十九岁下仗。

7. **第二十四页｜教完了**
   - 原：七守七围一缚一收，到这一页教完了。
   - 改：七守七围一缚一收，我会的，到这一页都教完了。
   - 为什么：报名目加“教完了”收段。接上前言“我教的东西不多”，他谦的那一面。改得很轻。

## 三、留着没改的冷句和缘故

- **三十二页的念词**（剑藏臂下盾压其上、弓拉满了不放、谁先放谁先空、盾也是一只拳头、从头来不丢人、今天打完了明天还有饭吃……）：口诀，跟歌诀一样，本来就是短句。
- **各守各围的标签行**（第二守，右肩。第五守，胸前。第二围，对肩。第七围，弓对弓。）：剑术书的条目名，不是收章。
- **前言“最后那一样，是这座殿自己的。”和收那一段开头“这一段是这座殿自己的。”**：他全书唯一一处骄傲，说两回是有意的重复。
- **前言末“寻常的东西，学会了到哪里都用得上。”、第七守“拉满的弓，什么都能放出去，也可以一直不放。”**：老师的话，后一句给第七围和全书的“收”埋线，留。
- **第二十一页“他说收，就收。他不说话，再缚一回，再问。”**：这是收这一手的规矩本身，规矩该冷。
- **第二十一页“见过一个人举着灭了火的盾往前冲，冲了很远，没有回来。”**：死，全书最该冷的一处，一句事实不接感想。
- **第二十二页“那一天那位英雄身后的人一个也没有死。”“太阳下山以前，两边的旗都收了。”**：亲眼见的事照平铺写，不往庄严里拔，是祭司的写法。
- **第二十五页“这几页图底下只有那两行念的字，没有我写的话。”**：后八页的女人不说是谁，他有意不写，这一句冷是这一段的分量所在，留。
- **第六守“腿短的人站了，剑尖会先绊着自己。”、第六围“十个有六个不敢往前迈那一步。”**：已经是他的嗓门（打趣、记得学生的胆子），不动。

## 四、跟卡、跟书里自己对不上的（照原稿没改，等主会话定）

- **前言第二段的年份**：“殿立起来的那一年，我十九岁，刚从七王的仗里下来。那一年炎潮月，七王在盟坛上立盟，耶万在坛上聚成，第二年北岸立起了祂的殿。”前一句说十九岁是立殿那一年（卡里 5381），后一句的“那一年”接着指同一年，却写聚成在“那一年”、立殿在“第二年”，读下来立殿那年变成了 5382。设计备注写的是“祭司十九岁那年殿立起来”。照卡要么把“那一年炎潮月”改成“前一年炎潮月”，要么把头一句改成聚成那年他十九岁。动的是年份关系，留给主会话。
