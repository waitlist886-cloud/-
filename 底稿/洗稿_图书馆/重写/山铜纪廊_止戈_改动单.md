# 改动单｜止戈（声口重写，11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/山铜纪廊_止戈.md`，重写稿 `底稿/洗稿_图书馆/重写/山铜纪廊_止戈.md`，人设包 `底稿/洗稿_图书馆/人设/止戈.md`（新做，抄了凡世至强条、七年巡礼旅伴条和背景条、探井的年月人物条三份声口，加方向与写法第五版第三节少女时的声口）。

正文（前言到后记）约七十五段，动了 18 段（18 行）：前言 2、一 3、二 3、三 2、四 2、六 4、七 2、后记 1，第五节没动。元信息栏、扉页、目录、`## ` 小标题、〔剧透〕〔注一〕〔注二〕标记、引号里的法典条文、两条注脚、设计备注一个字没动。事实、数字、人名地名没动，没加原稿没有的事，添的都是她当下的理由、一句顶嘴或自嘲，取自书里和卡里已有的东西。

这一本的体例是她自己说的“照我听报告的次序写，先报数，再报谁担着，最后才说别的”，所以每节头上的报数短句是骨架，不是冷笔，照留。她的冷是报告的冷，可她不是盖章的人：卡里她嘴上刻薄（“这汤跟苇棚区的一样难喝。很好，说明厨子没给我另开一锅。”），会顶人（“议错了，明年再议，你急什么？”），什么都折成一户一户的人和一顿一顿的饭。要改的是那几处“报完数，再压一个两字章”和对称格言，换成她会接的那半句：一句刻薄、一句自嘲、一个落在人和饭上的理由。

## 一、七个层面（索恩薇娅·里德，一个作者）

| 层面 | 定法 |
|---|---|
| 时间尺度 | 报告的尺度，年份、月、旬、日一个不差（661年花信月中旬四日、668年花信月上旬九日）；几百年一笔带过（将近三百年、二百一十七年以后）；夜里的事记到一夜、天亮以前 |
| 自称称呼 | 我；跟着她的人是“我们”“我营里的人”；别人照干的活叫（伙夫、帮工、侍从、史官、段守、守长阶的卫兵），议政院当面是“你们”；巴尔缇娜只说她、灰雨的魔女、对面，名字一回不叫；雨城那个人不报名字 |
| 连接词 | 少，句号断开；“先……再……最后”是全书的骨头；论理时用“所以”“可”；这回添一处“倒”（倒不是替我自己留个名、这一点倒跟她一样），是她松一口气说实话的口气 |
| 问号 | 原稿零。添三处，都是卡里她问过的：岔口那一处问自己“我怎么就信了呢？”（背景条原话“三天，你说我怎么就信了呢”），“早到半天，能多几个？”（旅伴条坎原句），签净血院那一章以前问的“还有几个孩子？”（她先问数） |
| 手边的东西 | 面包、汤、伙房门口那口钟和钟绳、名单、账碑、三条长凳、麻绳缠柄的旧剑、草稿纸、王冠压纸、一把椅子、一小罐果酱 |
| 消息来源 | 报告和数（台地上送来一个数）、史官记下的、侍从说的、码头上的老兵、段城伙夫跟她说的、碑上有、苇棚区的人吵出来的 |
| 怎么停笔 | 每节停在一件事或一样东西上（抬上车、签了、长凳、空椅子）；全书停在厨房里一碗凉汤，站着喝了 |

## 四、跟卡对不上、要主会话看的地方（照原稿没改）

- 第四节“这一节写进法典的有两行”和下面“后一行不在法典里”原稿自相矛盾。我照她的声口加了一句改口“后一行我说错了”，事实没动；要是嫌这样替作者认错，可退回原句，另改上头为“这一节留下的有两行”。
- 设计备注“拿不准”里那三条（磨坊村和水磨村、“高了一点”、“将近三百年”）原稿收稿时已处理或记明，没动。
- 第五节812年“冠台的敕令写南线一夜无事”：812年冠台是她自己的朝廷，敕令写“无事”像是她有意压下来的，书里没说缘故，卡里也没有，照原稿不添。
- 卡里探井的年月那一条的 Art 写【黎明剑律】(Legend)，凡世至强条写 (Unique，318年跨进神域)，书在迷宫纪4年，书里不涉及档，没动。
