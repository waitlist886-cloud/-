# 改动单｜九矛夜话（声口重写，11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/行当的歌_九矛夜话.md`，重写稿 `底稿/洗稿_图书馆/重写/行当的歌_九矛夜话.md`，人设包 `底稿/洗稿_图书馆/人设/九矛夜话.md`（新做的）。

全书正文约一百四十段，动了十四段（前言四段、第二夜一段、第四夜一段、第五夜一段、第九夜三段、后记四段），一成上下。元信息、扉页、目录、`## ` 小标题、〔〕里的字（布罗坎记的火边的事、〔剧透〕〔注一〕〔注二〕）、注脚、青墨注三、设计备注一个字没动。事实、数字、人名地名没动，没加原稿没有的事。

这一本要先说清楚一件事：方括号外头是凯兰讲的夜话，夜话的规矩是“只讲亲眼看见的，不添，不减”，第一夜方括号里布罗坎写明了他讲事时“一个字一个字地往外放，像在数饼”。所以夜话里的短句是这一门行当的声口，不是冷笔，大半照留。要动的是三样：夜话里几处不像他、像旁白盖章的收尾；平常那个话多爱笑、叫人兄弟小子姐的凯兰在书里一回也没露过面；布罗坎的前言后记跟凯兰的夜话一样短，两个嗓门没拉开。

## 一、两个人的七个层面

### 凯兰（讲，九矛里跑得最快的，三十一岁的脸，一千五百多岁）

| 层面 | 他的 |
|---|---|
| 时间尺度 | 他几岁那年、哪一夜、天黑天亮；年份只给三件大事（一千四百三十年、四十九年、五十年），一千五百年一笔不提 |
| 自称、称呼 | 我；九矛里的人叫弟兄；席恩只叫“头领”；艾丹、多纳尔叫名字。平常嘴上叫年轻人小子、男的兄弟、女的姐（卡里传奇条），夜话里不叫人 |
| 连接词 | 夜话里几乎没有，一句一事，“可”一处；平常说话逗号串下去 |
| 问号 | 夜话里没有，他不替听的人问，也不问自己 |
| 手边的东西 | 矛、鹿皮、水囊、火、柴、鞋底、步子；放羊人家的老底子（喊羊、认狼踪、羊群） |
| 消息来源 | 只有自己的眼睛；别人说的标明“后来我知道了”“接生的老妇人说过”“他说是……”，没在的那一回不讲 |
| 怎么停笔 | 一句“就这些”“我讲完了”，或者停在一件看见的事上（那头犀后来叫焦犁） |

尺子：看见了没有，量了没有。他的热只从缝里漏，一句替自己找的缘故、一句拿多纳尔开的玩笑、一句放羊的底子。

### 布罗坎（记，镜湖东岸老诗人头一年的学徒）

| 层面 | 他的 |
|---|---|
| 时间尺度 | 那年开春、当夜、天亮以前、九夜；落款年月 |
| 自称、称呼 | 我；凯兰叫名字；老诗人；年轻的猎手、老猎手、孩子，不点名 |
| 连接词 | 可、就、往后，逗号串下去，句子比夜话长 |
| 问号 | 他问得多，可都写成“我问……”的转述，不用问号 |
| 手边的东西 | 桦皮、烧黑的柳枝、划痕、火苗高矮 |
| 消息来源 | 老诗人说、年轻猎手说、老猎手说，写明来处 |
| 怎么停笔 | 前言落款带地点；后记停在檐下那一格桦皮上 |

## 二、改了的

1. **前言｜凯兰那年秋天回来了**
   - 原：可那一年冬天，火边的人最想听的是另一个人讲。凯兰那年秋天回来了。
   - 改：可那一年冬天，火边的人最想听的是另一个人讲，就是凯兰，他那年秋天才回到白丘。
   - 为什么：段末单起一句做余韵，是一句一段的冷收。正常人写到这里会一口气说下去，“才”带出他是晚回来的，跟后面“没有赶上东城那一夜”接上。

2. **前言｜凯兰的来历**
   - 原：他是九矛里跑得最快的，一千四百四十九年霜降月……喊醒了三十个村子。平原上的村口都挂着铜铃，是给他留的。他名字凝住了一千五百年，脸还是三十一岁，蜂蜜色头发，一笑先看见牙。
   - 改：他是九矛里跑得最快的。火边的老猎手跟我数过他的事，一千四百四十九年霜降月……喊醒了三十个村子，平原上的村口都挂着铜铃，是给他留的。他名字凝住了一千五百年，脸还是三十一岁，蜂蜜色头发。老猎手说他跑过来的时候先看见牙，再看见人，这话不假。
   - 为什么：原段是一张人物卡，一个刚到白丘的学徒没有全知的眼睛。照“消息来源”那一层，写明是老猎手数给他的（老猎手前言、第八夜末都有）。“先看见牙，再看见人”是卡里凯兰容貌评价里九矛老猎手的原话，换回原话，学徒加一句自己的见证，是他本人头一回露出一点口气。

3. **前言｜火矮下去的地方，你划掉**
   - 原：凯兰说那就这样，每天天亮以前你把头一夜记的念一遍给火听，火矮下去的地方，你划掉。
   - 改：凯兰倒笑了，说，“那就这样吧，小子，每天天亮以前你把头一夜记的念一遍给火听，火矮下去的地方，你自己划掉。”
   - 为什么：全书只有这一处和后记一处，凯兰是平常的凯兰，不在讲夜话。卡里他爱笑、话多，叫年轻人“小子”（传奇条称谓），火边的人都看着他等他发话，他先一笑把气松了，比一句干的“那就这样”像他。改成直接引语，夜话的慢嗓门和平常的快嗓门在书里第一次分开。

4. **前言｜划痕底下的字**
   - 原：划痕底下的字还看得出来，那是我添的，不是他。
   - 改：划痕底下的字还看得出来，那几处是我添的，算不到他头上。
   - 为什么：“那是我添的，不是他”是否定对称收句。学徒这时在替凯兰挡，怕后人拿这几处说凯兰讲大了，换成他会说的“算不到他头上”。

5. **第二夜｜我没回头**
   - 原：那头鹿后来怎样，我不知道。我没回头。
   - 改：那头鹿后来怎样，我不知道。我没回头，一回头就看不见前头哪里亮了。
   - 为什么：“我没回头。”收段是盖章。他不知道就说不知道，这是他的规矩，可一个十二岁过考的孩子没回头是有缘故的，缘故在本夜前面（“我不看脚，看前头的光，哪里亮踩哪里”），让他自己说出来。没添事。

6. **第四夜｜一个人也没伤着**
   - 原：我们一个人也没伤着。它也没伤着。
   - 改：我们一个人也没伤着，它也没伤着。多纳尔说开春它自己走，它没等到开春，可到底也是自己走的。
   - 为什么：两句否定对称收夜，用户点名的那一路。凯兰讲多纳尔向来带一点打趣（第五夜冻裂的耳朵），这一夜开头多纳尔说过“别惹它，开春它自己走”，熊天快亮自己回了洞，收在多纳尔那句话上，是只有他讲得出的一句，一样事实也没加。

7. **第五夜｜天亮狼走了**
   - 原：那一夜我们扎了十一头。天亮狼走了。村子里没死人。
   - 改：那一夜我们扎了十一头。天亮了，火还没小，狼就走了。村子里没死人。
   - 为什么：报数加三个短句，节拍跟用户举的例子一样。数照留，中间那一截接回本夜前面他说的“它们在等火小”，火没小、狼没等到，这是猎手讲完一夜会顺口落的那一句。“村子里没死人”照留，是这一夜真要说的。

8. **第九夜｜我去了**
   - 原：我去了。我跑了南边七堆火。
   - 改：我去了，南边七堆火，一堆一堆都跑到了，话都带到了。
   - 为什么：“我去了。”是盖章短句。他是送信的，送信的人交差说的是话带到了没有，七堆火照留。

9. **第九夜｜最大的一头兽**
   - 原：这是我这辈子看见的最大的一头兽。我看见它的时候它已经死了。
   - 改：这是我这辈子看见的最大的一头兽，可我看见它的时候，它已经死了。
   - 为什么：后一句单收是冷收。他一辈子总晚一步（东城没赶上、三回水没跑在前头，卡里性格底色），这一句里有遗憾，加一个“可”连成一口气，遗憾就是他的，不是旁白的。意思没变。

10. **第九夜｜我过了**
    - 原：兽都不肯从石头中间过。我过了。
    - 改：兽都不肯从石头中间过。我过了，我小时候放羊，羊群中间走惯了的。
    - 为什么：“我过了。”盖章收尾。上一句他自己说白石头“像一群睡着的羊”，第一夜他说“我们家是放羊的”，放羊的人穿羊群是他的老底子，一句话把第一夜和第九夜接上，带一点他平常的笑意。没添事。

11. **后记｜算不算添**
    - 原：他说不算。哪一头先讲哪一头后讲，是讲的人的事。每一头讲的是什么，是火的事。
    - 改：他说不算，先讲哪一头、后讲哪一头，那是讲的人自己拿主意，火不管这个，火管的是每一头讲得对不对。
    - 为什么：“是X的事。是Y的事。”两句对称，像刻在石头上的格言。这是布罗坎转述凯兰平常说话，凯兰平常是快、碎、一口气说下去的，意思一样，拆了对称。

12. **后记｜歌就会大**
    - 原：……他们讲的就不是夜话了，是歌。歌就会大。
    - 改：……他们讲的就不是夜话了，是歌，歌嘛，哪有不越唱越大的。
    - 为什么：“歌就会大。”四个字冷收。凯兰平常说话带语气，前言里那个年轻猎手也说过“歌……唱大了也没人管”，凯兰说起歌是那种见怪不怪的口气。

13. **后记｜你那一捆桦皮**
    - 原：“你那一捆桦皮，往后也是歌。你记的是对的，往后抄的人不一定。”
    - 改：“小子，你那一捆桦皮，往后也是歌。你记的是对的，往后抄的人可就不一定了。”
    - 为什么：“不一定。”收句短硬。临走前对着学徒说的一句，叫一声小子（卡里称谓），“可就不一定了”是他半开玩笑的那一下，也正好是注三（四百二十步）那一句的伏笔，伏笔原来就有。

14. **后记｜老诗人没说话**
    - 原：他没说话，把桦皮捆好……
    - 改：他没再问，把桦皮捆好……
    - 为什么：“没说话”在冷笔口径的盖章词表上。老诗人刚问了一句为什么不写成歌，学徒答了，接下来是他不再追问、动手把桦皮单放一格，“没再问”是这一问一答的下文，动作收尾照留。

## 三、留着没改的冷句和缘故

- **九夜开头的“我讲我看见的。”**：夜话起头的老规矩，也是卡里凯兰的原话。九回一字不换，重复的分量在重复本身（研读笔记魈那一条），第九夜接一句“我看见的不多”，就是重复到变的那一回。
- **收夜的“就这些。”“我讲完了。”**：九夜里只有四夜有，第一、七夜是就这些，第八、九夜是我讲完了，是讲夜话的人交差，不是每夜一枚章。
- **第五夜“那一回我没在，我不讲那一回。”**：句形正是用户举的“没到的那一节，我不画”，可这一句是九矛夜话这一门的规矩落在他嘴上，下一句“我讲我看见的那一回”马上接了出去，全书只此一处，留。
- **第一夜“他没扎狼。”“它们要的是一堆人，不要一个。”**：一个十一岁放羊孩子看见的头一件事是这个九矛不动手，留着读者往后（第五夜缺耳的多纳尔）自己对上。狼要一堆人是猎户人家认狼踪的眼力，是他的。
- **第三夜“蟒死了。鹿也死了，在它嘴里。”**：死的地方，“罗莎琳死了”那一路，留。
- **第五夜“他骂我。骂了半夜。骂完了把他的水囊给我，说喝。”**：“喝”是多纳尔的一个字，粗人的嘴，不是凯兰盖章；冻裂的耳朵那一句紧跟着把热接上了。
- **第六夜“我看见他没受伤，可他捂着肋下”和末尾“那头犀后来叫焦犁。”**：前一句是重复到变，后一句是全书的接榫（第七、八夜），一夜里留一处冷收。
- **第七夜整夜**（我跺了三下脚。／我数着。第十个村子，天黑了。第二十个，天亮了。……／它要找的不是我。／三十个村子，人都跑出来了。就这些。）：报数是他边跑边数的样子，跟他数饼是一个人。这是他自己的伟业，他压着讲，正是人设包里“一个字一个字地往外放”；“它要找的不是我”是艾丹那一头的伏笔。
- **第八夜整夜**：艾丹的死、三回水，三回水那一段是卡里台词样例的原句，“头领的矛，我没看见”是不裁定的锁，全书该冷的地方就在这一夜。
- **第九夜“四百一十七步。”**：注三挂在这里；前两夜他两回说“我没量”，这一头死了，他量了，不解释，留给读者。
- **第九夜“大雨。”“它倒在门外。”**：讲到最要紧的地方他慢下来，留。
- **扉页引语、前言里夜话的规矩那一段**：扉页是卡里原句；规矩本身照规矩的口气写。
- **前言“我请他讲东城。他说他没看见，不能讲。我问他看见过什么。……够讲九夜。”**：一问一答的转述，是学徒记事的样子，后头第 3 条已经让凯兰开口一回，这里不再加。

## 四、方括号里想改、照旧没动的（交主会话定）

〔〕里是布罗坎记的火边的事，照叠牌班那一份的做法这一轮不动。凯兰平常的嗓门（爱笑、叫人兄弟小子姐）只有在这几处方括号里才露得出来，主会话认了可以单改：

- 第三夜〔……凯兰说，“我看见的是比我高、比我的腰粗。别的我没看见。”〕，问话的是个年轻人，可改成“小子，我看见的是比我高、比我的腰粗，别的我没看见。”
- 第七夜〔……有人说歌里唱你脚下生火。凯兰说那是歌。〕，可改成“凯兰笑了，说那是歌。”他爱笑，这一笑也给第八夜“凯兰不笑了”一个反衬。
- 第九夜〔……凯兰说，“我没看见。头领在里头，你们问去过的人。”〕，可在“我没看见”后头加一声“兄弟”。

## 五、跟卡对不上的地方（照原稿没改）

- **他怎么进的九矛**：卡里背景条写他八岁追丢失的母羊跑了一天一夜，抱着羊到了九矛的火前，席恩看过说留下吧，从此住在九矛。书里第一夜是十一岁还在白丘外放羊，坡上一个左耳缺了半只的九矛（照第五夜是多纳尔）叫他“明年来考”。年纪和是谁收的都不一样。设计备注把第一夜记成★新起，没注意到背景条。
- **艾丹什么时候教他那一跃**：第三夜是他十三岁（1431 年长曦月以后）那一回，书里写“他教我那一跃，是第二年开春”，算下来是 1432 年；卡里技艺走势、兼修两处都写“1431 年起艾丹在林子里教他”。设计备注说“对得上”，差一年。
