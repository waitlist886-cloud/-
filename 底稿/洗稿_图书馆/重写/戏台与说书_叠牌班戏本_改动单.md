原稿 `底稿/门面/第二轮/大图书馆/书稿/戏台与说书_叠牌班戏本.md`，重写稿 `底稿/洗稿_图书馆/重写/戏台与说书_叠牌班戏本.md`。从原稿起手。GPT 第二轮的稿对过一遍，没有借它的句子：它把班主的话改顺了，可是加的俏皮话（“可没叫你催债”“非敲到人家笑”）就是报告里说的洗俏，塔菲那一段它并的句（“班子散了，车也卖了”）我试过，会把她的短句弄没，也退回了原稿。

## 一、两个人的七个层面

### 马蒂诺·蜜轮（班主，半身人，写给自家演员的提纲）

| 层面 | 他的 |
|---|---|
| 时间尺度 | 今晚、这一出、上台那一刻；年份只在落款和纸板背面出现（五百八十一年寒星月那一夜）。几十年是“脸”的尺度，不是他的 |
| 自称、称呼 | 我；整班叫“你们”“班里的人”；一个一个叫名字（哈布、博塞、裴珀），不叫诸位，不叫孩子“小家伙”；提到戏里的人只叫脸名（扛包的、老钱袋）。说到自己演的那一副，用“我演” |
| 连接词 | 逗号串下去，“所以”“要是……就……”“先……再……”“别……”，没有对仗，没有“然而” |
| 问号 | 几乎没有，只替往后的人问一回（词为什么不写？），提纲里另有女仆问台下那一问 |
| 手边的东西 | 牌（五十二张）、铃鼓、篷车、纸板和钉眼、木头鹅、桌布、四十枚银币 |
| 消息来源 | 台下的脸。修鞋的、扛包的、桥头的兵、前排的孩子，他信台下笑没笑，不信上城 |
| 怎么停笔 | 落款带地点（篷车里），前头一句停笔的缘故（灯油见底了）。纸板背面停在一个人身上（裴珀说……、给裴珀看） |

尺子：台下坐的是谁、笑没笑、钱够不够换车。正经话后头跟一句打岔，打岔落在自家人身上（塔菲、博塞、裴珀），不落在俏皮话上。碰上审判庭、灰袍、白石压契，不打岔。

## 二、改了的

1. **班主的话第一段**
   - 原：这五十张是给班里自己人看的，外人拿去也看不懂，看懂了也演不了。
   - 改：这五十张是给班里自己人看的，外人拿去也看不懂。真看懂了也演不了，脸在我们七个人身上，纸上只有个架子。
   - 为什么：“看不懂，看懂了也演不了”是一句否定对称的冷收。班主会给理由，理由就是他们七个人，顺手把下一段的七副脸接上。

2. **班主的话第二段**
   - 原：叠牌班七口人，一辆篷车，一副牌箱。车停在哪条巷子……我们演的戏没有词，词是上了台当场编的，台下坐的是修鞋的……纸板上只写四样，前情，谁上，要什么东西，一段一段谁做什么。写了这里笑的地方……
   - 改：叠牌班七口人，一辆篷车，一副牌箱，车停在哪条巷子……词是上了台当场编的，所以上了台先看台下坐的是谁，坐的是修鞋的……一段一段谁做什么，别的你们看台下。写了这里笑的地方……
   - 为什么：研读笔记点过这一段像写给外人的介绍，跟“给班里自己人看的”打架。“七口人，一辆篷车，一副牌箱。”单起一句是报数加句号，并进下一句，读成他得意自家班子。添“先看台下坐的是谁”“别的你们看台下”两处，把介绍改成交代，冲着班里人说（你们），也是他的尺子。没加任何新事。哈布那一句是研读笔记说好的，原样留。

3. **班主的话第三段**
   - 原：词为什么不写，班里的人都知道……当场编的话，说完就散了，散在巷子里，谁也拿不走。
   - 改：词为什么不写？班里的人都知道……散在巷子里，谁也拿不走，台下笑过的人第二天问他笑的是哪一句，他自己都说不上来。
   - 为什么：头一句改成问号，是替往后读的人开口（市井抓手第 3 条），全书班主的字里唯一一个问号。“谁也拿不走”是盖章式的段末冷收，后面接一句班主从台下看来的事，让“拿不走”有个看得见的样子，也是他引的消息来源（台下）。审判庭那一句是硬的，照原样，不打岔。

4. **七副脸那一行**
   - 原：七副脸，一人一副，几十年不换。
   - 改：七副脸，一人一副，几十年没换过，往后谁接手也别换。
   - 为什么：报数加“不换”三字的冷收。改成一句交代，接上一段“给往后的人”，也跟塔菲末尾“七副脸照着演就行”对上。

5. **扛包的那一条（清单破格之一）**
   - 原：扛包的｜我演。饿，懒，翻跟头……最后什么事都叫他办成了。
   - 改：原句后加“饿那一样我演得最像，不用排，问塔菲就知道。”
   - 为什么：七条全是“谁演，三四个形容”，同一个句架连七回。照研读笔记第五节，他自己那一条加一句对自己的嘴。打岔落在自家人（塔菲）身上，是心软嘴不认的那一路：班子穷，他拿自己开玩笑。没写具体的事。

6. **少爷那一条（清单破格之二）**
   - 原：少爷｜博塞演，塔菲的哥哥。墙上回来的，一张嘴吞得下火，见了耗子跳上桌子。
   - 改：原句后加“博塞，火等前排的孩子都抬起头了再吞。”
   - 为什么：研读笔记示范是加一条规矩（吞火以前不许喝酒），那一条带进了喝酒这件新事，我换成一句点名的台上叮嘱，尺子还是台下（前排的孩子）。另五条照原样。

7. **驴那一段**
   - 原：……她那一年七岁，演驴不说话，只踢。
   - 改：……演驴不说话，只踢，踢我踢得最重。
   - 为什么：“只踢。”两个字收段，冷。后接一句当父亲的嘴，跟第十三出收场“驴踢扛包的一脚”、塔菲批注“踢扛包的可以踢重”对上（扛包的是他演的），不是新事。

8. **落款前添一行**
   - 改：灯油见底了，先写到这里。
   - 为什么：研读笔记第五节第 3 条，给停笔一个理由。落款“马蒂诺·蜜轮，五百八十六年，篷车里”原样。这是全书唯一一处添句，不涉事实。

9. **第四十七出三段**
   - 原：驴从桌布底下钻出来，鞠躬。不踢人。
   - 改：驴从桌布底下钻出来，鞠躬，这一回不踢人。裴珀，上城的客人踢不得，踢一脚，这一年的四十枚就没了。
   - 为什么：“不踢人。”是否定式冷收。驴在五百九十年归裴珀演，这一句是班主当面交代女儿，带上他算钱的尺子（四十枚是前情里的数）。“这一回”接第十三出驴踢人的老规矩。

10. **塔菲的话第二段**
    - 原：五十张我穿起来带走。这一车的人，一个一个走了，戏还在纸上，纸上没有词，词跟着人走了。往后谁拿着……
    - 改：五十张我拿麻绳穿起来带走了。钉眼正好穿绳。这一车的人，一个一个走了，纸上还是他写的那四样。词他们带走了，本来也没写过。往后谁拿着……
    - 为什么：“戏还在纸上，纸上没有词，词跟着人走了”是顶真接句，收在一句像格言的话上，不是一边收牌箱一边说话的人会说的。换成她手上的东西（麻绳、钉眼，都在 > 装帧里），“那四样”回指班主的话里的四样，是她读过他写的。句子照她的形状短着断开。“演砸的时候比演好的时候多”是全书最暖的一句，原样。

## 三、留着没改的冷句和缘故

- **扉页“上台以前数牌。五十二张，少一张不演。”**：叠牌班的规矩，引的是班规原文，规矩本来就这样说。
- **第四出背面“上城的巷口不演。替役的家门口不演。桥头演，桥头的兵笑得最响。”**：墨重写的禁令，注一引了“桥头演”，〔〕里不动。研读笔记说这是班主才会注意的东西。
- **第四十一出背面“台下的人陪着站了一夜，没有一个先走。”**：灰袍那一夜，班主不打岔的地方，〔〕里不动。
- **第四十七出背面“演完了。客人没有笑，也没有不笑。”**：这是全书最像冷笔的一句（否定对称），我想改成“演完了，客人没有笑。也说不上不笑，我在幕后看了一晚上的脸，一张也没看懂。”（他的尺子是台下的脸，这一回读不出来，比否定对称更像他）。可它在〔〕里，这一轮不动，留给主会话定。
- **第四十九出背面“看见了。”、塔菲批注“初雪月，跳板底下。”**：全书该冷的两处（白石压契、他的死），研读笔记说是“罗莎琳死了”的做法，〔〕里不动。
- **第四十九出两回“这里不笑。”**：重复到变，研读笔记说是全书最好的一笔。
- **塔菲的话第一段“班子散了。”**：试过并成“班子散了，车也卖了”，句子一长，voice_check 报她跟丈夫读起来像一个人。短句是她的形状，照原稿。“我说戏法变不出四十枚银币，她说那就变别的。”是卡里羁绊的原话。
- **塔菲的话末“第五十出我没有填。那是他的事，我替不了。”**：她的诀别，全书留给她的那一处冷收。往后羁绊里是她拆的封，书里不替那一支写。
- **提纲里的短拍**（老钱袋不报了、驴把剩下的桌布吃了、演到天亮就算收、台下怎么答就怎么收）：是给台上人的动作和收法，提纲本来一行一件事，不算盖章。
- **第十三出塔菲批注“裴珀记着。”**：当母亲的叮嘱，活人会这么说，留。
