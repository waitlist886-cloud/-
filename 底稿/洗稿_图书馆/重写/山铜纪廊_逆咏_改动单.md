# 改动单｜逆咏（声口重写，11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/山铜纪廊_逆咏.md`，重写稿 `底稿/洗稿_图书馆/重写/山铜纪廊_逆咏.md`，人设包 `底稿/洗稿_图书馆/人设/逆咏.md`（新做的，抄补卷_64 伊诺克条和声口块、第一页门洞的孩子们条、暗线第四版第四节第 2 条）。

这一本大半是词：十段的“正着｜”“倒着｜”两行一个字没动（倒着那一行是脚本照正着排的，正着也不动），“〔这一面是空的〕”照留。动的只是每段底下伊诺克写的那几行散文和前言，约五十八段，改了十一处、十一段（第三段末两段并成一段）。元信息栏、扉页、目录、`## ` 小标题、〔剧透〕〔图七〕〔注N〕和〔〕里的编注、四条注脚、设计备注一个字没动。事实、数字、人名地名没动。添的东西都是书里或卡里已有的：祷词里的“石不暗，我不起身”、第四段的姐姐和铃、三句誓里“在日光下报出自己的名字”、卡里台词“现在我替先生收火”“好不好”、前言“记得一个字也不错”、擎天之心那一头“我说我叫斐里安。他说先生。”

伊诺克的嗓门原稿已经立住了大半：句子短，紧张了一句话说两遍（真的，回不去的／先生说的／先生现在都吃得很少），叫先生，玛蓓只叫姐姐。要改的是三样：一是段末单起一行的冷收（我念了二十年它都亮着／我就没念／我没倒过它／南门外那一台我不碰），换成这个孩子会接的半句，理由是孩子的理由（怕、先生没叫、那里头有人摇过铃）；二是两处格言腔的否定对称（人记住的不回去／这一段不倒着写），一个改成他的问话，一个改成冲着读的人说；三是卡里写他“问句多”，原稿正文一个问号也没有，两处本来就是问话（她不累吗／你知道吗）补上问号，另添三处问句，都是他心软的时候问的。

## 一、七个层面

| 层面 | 伊诺克（一个孩子的词本，两千年里字没长） |
|---|---|
| 时间尺度 | 大段的年月一句带过（二十年、九百年里、黑潮那一百二十年、一百多年），一夜的事记得细（清雨一滴、一片、一整城；闸上念到第三遍、后半夜）；记日子用“第二十年霜降月”“二年炎潮月”“那年霜降月清查的日子” |
| 自称称呼 | 我。先生从不叫名字；玛蓓叫姐姐，瑟尔卡叫守门的那个高个子，茨维娅叫一个生角的女人，罗兰德叫老爷爷，都不点名；读的人叫你（你要是念，正着念就好） |
| 连接词 | 几乎没有，句号断开；所以、可是、后来、念着念着，孩子的接法；紧张时一句说两遍 |
| 问号 | 原稿 0（她不累吗。你知道吗。都是句号）。这一回 5 处：补号两处，新添“好不好”“总不会自己回去吧”“那个人就不用坐在墙根底下哭了吧” |
| 手边的东西 | 白石头、篮子、门柱上的刻道、水桶和锅、谱、铃、闸、炉心、烬兽、旧钱、两只碗、灯 |
| 消息来源 | 先生说（当真理，像可莉的妈妈说）；雨城的老人说；墙上的兵骂；他自己看见的。火他看不见，火的事是先生告诉他的（他说，伊诺克，全城的火都亮了一下） |
| 怎么停笔 | 一句先生的话或先生的事（先生说的／先生现在吃得很少）；一个孩子的理由；一样东西（铃、碗） |

## 二、改了的

| # | 位置 | 原句 | 改后 | 为什么 |
|---|---|---|---|---|
| 1 | 第一段 | 我念了二十年它都亮着。 | 我念了二十年，它回回都亮着，我也回回没有起身。 | 单起一行报数加一句，冷收。孩子会把这件事跟自己连起来：祷词里就是“石不暗，我不起身”，二十年它没暗，他就二十年没起身，下一段“我站起来，往外走”才落得下。“回回”重复两遍是他的样子 |
| 2 | 第一段末 | 他叫我出来。我叫他先生。〔注一〕 | 他叫我出来，我就跟他走了。我叫他先生，他说不用这么叫，我还是叫。〔注一〕 | “他X我。我X他。”对称两拍，盖章。这是他一辈子最要紧的一下，孩子会写得笨一点、拗一点：跟着走了，叫先生，人家不要，他还是叫。擎天之心那一头是“我说我叫斐里安。他说先生。”，两边对上，这一本照旧不写先生的名字 |
| 3 | 第二段 | 这一段不倒着写。 | 这一段我不倒着写，你也别倒着念，好不好？ | 一句硬规矩打头。他在前言里就冲着读的人说（你要是念，正着念就好），这里同一个口气，“好不好”是卡里台词原样。为什么不倒，留给段末那一句“倒过来念，就没有人来领了”，原句没动 |
| 4 | 清雨 | 他说，伊诺克，全城的火都亮了一下，你知道吗。 | ……你知道吗？ | 先生的问话，卡里先生“问句多”，问话用问号 |
| 5 | 清雨末 | 倒着念松开的东西，过些日子会自己回去。人记住的不回去。 | 倒着念松开的东西，过些日子会自己回去。可那一夜喝过清水的人都记得，记住的总不会自己回去吧？ | “X会回去。Y不回去。”是格言腔的否定对称，不像孩子。意思（人记住的留着）没变，改成他拿不准、盼着的一问。前言他怕“松开了就回不去”，这一回反过来盼着回不去，跟前言接上 |
| 6 | 第三段末 | 先生没叫我念。／我就没念。〔注二〕 | 先生没叫我念，我就没念。先生要是叫了，那个人就不用坐在墙根底下哭了吧？〔注二〕 | 两段一句的冷收。设计备注说剧透以外读起来是“心软又听话的孩子”，原句只有听话；添的一问是心软：他看着那个人哭，想的是先生要是叫了就好了，还是不自己动手（卡里锁“先生没开口的事他不做”照守）。墙根底下哭是上一段原有的 |
| 7 | 第四段 | 她不累吗。 | 她不累吗？ | 他真在问，补问号 |
| 8 | 第五段末 | 南门外跪着的那一台我不碰。 | 南门外跪着的那一台我不碰，姐姐在那里头摇了一夜的铃。 | 单起一行的冷收。不碰的缘故第四段就写了（剧透以外：姐姐坐在座上摇铃，摇到后半夜），给孩子一个理由，玛蓓照旧只叫姐姐，她死在里头的事不写。南门外那一台就是第四段那一台（c2 开局“长垒南段，南门外跪着擎天级的那座段城”） |
| 9 | 第六段 | 我没倒过它。 | 我没倒过它，我怕倒过来，生角的孩子就报不出自己的名字了。 | 单起一行的冷收。别人起的誓他倒得过来，偏不倒这一段，要有一个孩子的怕。怕的东西取誓的末一句（直到最后一个生角的孩子能在日光下报出自己的名字），他自己也是一个验出了黑的孩子，这一层不说破 |
| 10 | 第八段末 | 现在不哭了。 | 现在不哭了，现在我替先生收火。 | 卡里台词原样（“现在不哭了，现在我替先生收火”），“现在”说两遍是他的口气，也把下一段收火接上。原句四个字单收，像大人说狠话 |
| 11 | 第九段 | 收过的，我记得每一样。 | 收过的东西我都记得，跟念过的词一样，一件也不会记错。 | 一句一段的冷收。他记东西的本事前言写过（念一遍就记得，记得一个字也不错），收火的事他拿念词来比，是他自己的尺子 |

## 三、留着没改的冷句和缘故

| 句子 | 缘故 |
|---|---|
| 十段的“正着｜”“倒着｜”和三处“〔这一面是空的〕” | 歌诗咏唱不动，倒着那一行是照正着一字一字排的 |
| 前言“倒着念会松开东西的……真的，回不去的。”“先生说我念得好。先生说的。” | 紧张了一句话说两遍，卡里声口原样；“先生说的”是台词样例原话，全书的签名 |
| 第一段“石头……像一块路边的石头。我站起来，往外走，没有人拦我。” | 他自己出来的那一下，短是对的 |
| 第二段“倒过来念，就没有人来领了。” | 孩子的逻辑，全书最好的停笔之一 |
| 清雨“我不知道，我看不见火。可是我很高兴。” | 孩子可以直说高兴（研读笔记孩子一类），他看不见火是他的尺子 |
| 第三段“今天听会了一句新的，倒过来念很好听。” | 卡里原话，一字不动 |
| 第四段“我再念，她再摇。我念一遍，她摇一回。” | 说两遍是他的口气，也是那一夜的节拍 |
| 第四段剧透全段（那张脸我记得……我叫错了名字，又改了口。） | 锁，归火主线一幕公开的拍子，原样 |
| 第六段“别人起的誓，我倒得过来。自己起的，我倒不过来。” | 规矩本身（逆咏之舌“自己起的誓解不开”），该冷 |
| 第六段剧透“改过的那一句，我不写在这里。” | 锁 |
| 第七段整段（这一页只画了灯／我不写在纸上／靠里那一扇，我只开一回） | 门是他一辈子最好的一手，锁最多的一段；“只开一回”是诀别，全书最该冷的一处 |
| 第八段“后来我知道了，倒着念这一段，它们就出来。” | 一句事实当刀子，不接感想 |
| 第九段“不卖我就等，我等得起。”“我蹲在火堆边上，等他倒下，问他疼不疼，再念这一段。” | 一个看着十四五的长生种说“等得起”，天真里透冷，是这个人 |
| 第九段“他们讲的是把东西还给家里，我讲的是先生要。” | 对称，可两半说的是两种人，他只认先生，留 |
| 第九段两段剧透（第三百一十一个……我说炉里见／先生现在吃得很少。先生现在都吃得很少。） | 暗线样稿原句和卡里台词，重复一遍是全书的落点 |

## 四、跟卡对不上的地方（照原稿没改，等主会话定）

- 净血院出来的月份：这一本第一段写“第二十年霜降月”倒着念了三夜，擎天之心重写稿卷二写“约二十年，坠叶月”斐里安在院门外等三夜。两本说的是同一件事，月份差一个月，要不要对齐。另外“念了二十年”从 2 年霜降月进院算，第二十年是约 21 到 22 年，卡里写约 20 年，跟约 22 年寒星月下死域边挨得很紧，读作“约”，没动。
- 哭和烬兽：补卷_64 烬兽条写“他一松手，或者他一哭，就散成一地热灰”，可 c2 主线和这一本第四段剧透写他“一边哭一边把它们叫了进去”，第八段也写“叫它们出来的时候我也哭”。卡里自己两处不一，书照主线，没动。
- 第 8 处添的“姐姐在那里头摇了一夜的铃”，依据是 c2 开局那一台就在南门外；补卷_64 只说“南门外跪着的那一台他再没碰过”，没说为什么。嫌把缘故说白了，可退回原句。
- 擎天之心注一是伊诺克的嗓门，末句“先生没问是谁撕的，我也没问。”是否定对称的冷收，不在这一本，没动，主会话收那一本时可以看一眼。
