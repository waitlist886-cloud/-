# 《塔林日志》声口重写｜改动单（11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/奥法与工程厅_塔林日志.md`，重写稿同目录 `奥法与工程厅_塔林日志.md`，人设包 `人设/塔林日志.md`（新做的）。正文一百二十段上下，动了 10 处、13 段（三处把两段并成一段），远不到一半。书头元信息、扉页、目录、前言整页、`## ` 小标题、〔剧透〕、括号里的编注、两条注脚、设计备注一个字没动。事实、数字、人名地名没动，没添原稿和卡里没有的事（添的只是记日志的人的缘故、手上的感觉，贝洛尼卡自己的一句话）。

## 先说这一本的判断

这是一本日志，体例照阿兰那一路：一条一件事，主语能省就省，记的人只排事、不评，卡里 `塔林的手艺` 的写法那一行也这么要。所以全书的短句大半是体例，不是冷笔，不洗：井那一栏的寸数、窗外几只鸟、“塔离了地。”“冷柜结了霜。”这一类一行一事都留着。

查下来真正的冷笔有一个共同点：**都是记日志的人跳出来说这本日志自己的地方**（记了、日志不记、日志照改、削山不挂名、塔林不问）。原稿把这几处写成了盖章的格言。一个管册子的人真在册子里写自己的事，会像跟同行交代手续，说一句为什么、前头的怎么办，这一回就照这个改。另有三处是报数加两个字和否定冷收（连炉，带王／龙没有来／宴没有停），并进上一句，让事情自己落地。

## 一、七个层面

| 层面 | 记日志的人 | 报的人（日志照他们的字记） |
|---|---|---|
| 时间尺度 | 一卷一年；一年里用月名（萌芽月、长曦月、初雪月、归寂月）和一天里的时辰（前一夜、正午、日落、头一夜、天亮）。四千年一卷一卷往下记，人的一辈子一笔带过（鲁珀特十九岁进塔心，到卷一百零一一冬就没了） | 各报各的那一天：军团报一夜，掌板报十一天，削山报一整个夏天 |
| 自称称呼 | 不用“我”，自称“记日志的人”，第三人称；大魔导叫大人（梅瑞丝大人、鲁珀特大人），导师叫导师，学徒叫名字，皇帝叫陛下；凯尔萨斯“塔林管他叫”，不点他是谁 | 鲁珀特报“我算了”这类话都转成“他算了”；尤尼娅只有一句 |
| 连接词 | 几乎没有，一句一事；只有“往后”“同一夜”“今年”这类时间上的接头 | 军团、铸造所平铺；梅瑞丝只报数 |
| 问号 | 零。问话都转成陈述（铸匠问不要芯怎么点、导师问她算的是哪一座） | 零 |
| 手边的东西 | 册子本身：井那一栏、荫册、卷子、挂名字的那一格、门楣上那四个字、正厅挂名字的墙 | 铜灯、门环、冷柜、锤、托板、曜炉、雕蛋、墨碗、骸银、贯穹 |
| 消息来源 | 每条末尾挂报的人；自己看见的另标“记日志的人自己看见的”；没有人报的写明“这一条没有人报” | 塔里的大人、军团、营、学院、帝国记档、矿工 |
| 怎么停笔 | 一条停在报的人的名字上（括号）；一卷停在这一年最后一件事上；全书停在半句“塔林今夜”上 | — |

头一代记的人写方字、一笔一顿（前言编注），卷一句子最短；帝国以后卷子厚了，记的人肯多写一两句自己站在山脊上看见的，这是原稿已有的“字会长”，这一回没往里加。

## 三、留着没改的冷句和缘故

- **前言整页**：日志的规矩，每一任接手的人要先抄一遍，规矩本身该短该硬（“日志不记向谁求过。”“记的人署了名，记的就是他自己了。”），不动。
- **扉页“不问而成。”**：门楣上的字。
- **卷一“慢。像一个人从床上坐起来。”**：头一代写方字、一笔一顿，“慢”一个字是他亲眼看塔离地时手上的速度；后半句跟 `辉塔与圣荫` 那一本对得上，不动。
- **窗外几只鸟**（卷一“窗外十一只”，卷一千五百一十一“窗外一只也没有。太高。”，卷三千零一“窗外三十五只。三十五只。”）：固定栏，重复到变，跟 `辉塔与圣荫` 那一本逐字对上，设计备注写明，一个字不动。
- **井那一栏**（井沉半尺、三寸、四寸、二寸、五寸，星湖“湖面落了一指”，“盐井照旧出盐”）：阿兰那一路的固定栏，一座一行，不动。“盐井照旧出盐”有“照旧”，可它是一条井的数旁边的实情，不是收章。
- **卷四十一“一个也没有填。”**：九十三个空位是北口那一夜死了的九十三个人（`辉塔与圣荫` 那一本有“那是北口的”），日志不说为什么，正是这一本该冷的地方，留。
- **卷一百零一“新芯装上那天早上，塔心里站着的是六个人。（塔心六个人报）”**：鲁珀特死在这里，一句数当悲伤，“罗莎琳死了”那一路，全书最该冷的一处，留。
- **卷七百零一“小。罩一个营。（军团报）”**：军团报的字，战报的短，不是记的人收章。
- **卷一千二百八十一“一道锁，锁一位。往后照这一道画。”**：规矩本身（卡里“一道一位”）。
- **卷一千六百零七“湾里原先的歌，去年已处置。（帝国记档）”**：抄的是帝国记档的原字，卡里写记档只有“已处置”三个字，那份冷是帝国的，留着才对得上。
- **卷一千七百一十三“带曜核的东西，从今年起是旧的。”**：管册子的人的算法，往后的卷子里曜核都要标旧，是他的话，不是格言。
- **卷三千零一尤尼娅“五道，一齐。”**：编注说她报的只有这一句，她这个人就这么短。
- **卷三千四百七十六“一共四十七层，穿了四十七层。”**：铸造所报的，工匠报数报两遍是骄傲，留。
- **末一卷**：一百、十一、又一百，空一行，“塔林今夜”停在半句。全书的落点，规矩是剧透锁，一个字不动。“守门的人没有拦。”是那一年的实情，挨着剧透，不碰。

## 四、跟卡对不上的地方

读下来没有找到正文跟卡打架的。两处顺手记一下，照原稿没改：

- 卷三千零一“落在环山外头的荒坡上”：7300年起城改叫穹都，这里的环山读作山，不是城，跟卡里 `到顶` 那一条一致。
- 卷一千二百九十一 削山连炉带王，这一回写明是黄岩的君王，依据是上一卷缚印锁的是曜冠山心里黄岩的君王、削的是曜冠的山头（卡里 `塔林的手艺`：那一座山头连炉带王削下来）。主会话觉得不该点名，可以退回“炉里锁着的君王”。
