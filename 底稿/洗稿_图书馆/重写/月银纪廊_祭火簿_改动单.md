# 改动单｜祭火簿（声口重写，11-28）

原稿 `底稿/门面/第二轮/大图书馆/书稿/月银纪廊_祭火簿.md`，重写稿 `底稿/洗稿_图书馆/重写/月银纪廊_祭火簿.md`，人设包 `底稿/洗稿_图书馆/人设/祭火簿.md`（新做的，欧德、莱奥两人的独立声口照卡里第十五歌原样抄）。

前言到第十六条的正文约一百一十段（不算祷词），动了十五段（十五行），不到一成半。书头元信息、扉页、目录、`## ` 小标题、交火的两句老话、第十四条三段祷词、〔注〕标记、五条注脚、设计备注一个字没动。事实、数字、人名地名没动；添的只是莱奥当下的缘故和念头，用的东西都是书里已经有的（马谱、横着添、剩柴、五十年没出城门、守满一整夜、冠殿前那一盆火）。

这一本的病跟别的几本不一样：欧德话少是卡里定的（“句子比五十年前还短”），短句本身不是病；病在两处，一是欧德有几句短得像盖章（就够了、别的护不住、很远），二是记的人莱奥跟着老师一起冷收（他教了、他不应也不拦、我没问、我还没守满），voice_check 原稿报“莱奥和欧德读起来可能是一个人”。改法是欧德那几句改成手上有活的老人会接的半句，莱奥的冷收改成一个直、认真、容易脸红的年轻骑士会写的缘故。改完 voice_check 不再报两人一个腔。

## 一、七个层面

| 层面 | 欧德（说的人，老守火人，后来的王） | 莱奥（记的人，牧野王的小儿子，守冠的骑士） |
|---|---|---|
| 时间尺度 | 一夜、天亮、一冬；最远是“五十年前那一夜”，十四岁接火 | 哪一年哪个月、第二天、第二年冬天、隔了好几年；三十年记一本 |
| 自称称呼 | 我；来的人是你；他的老师是“老守火的”；火、兽、冠都叫它；王们叫各城的 | 我；先叫老先生，后来叫陛下，对他用您；黛拉姐姐、嘉琳老夫人、父王 |
| 连接词 | 几乎没有，一句一件事，逗号也少 | 转述多（我问、他说、我又问），“才”“又”“后来”“往后” |
| 问号 | 全书一个（城外的麦收了没有） | 只有当面那一问（您是怎么抬起来的呢），别的问都写成“我问……” |
| 手边的东西 | 柴、火、斗篷、狼皮、银片、毯子、灰、火塘边的白石 | 炭条、羊皮背面的马谱、冠殿前那一盆火、冠、门槛、绳头的白石 |
| 消息来源 | 老守火的说的、灰桥的规矩；神殿的说法他只说“他们说的” | 陛下说的、嘉琳老夫人跟我说的、城里的老人说、神殿的祭司；自己添的写明 |
| 怎么停笔 | 添一根柴，或者起身走；不想说的说不知道 | 停在老师的一句话或动作上，自己的话停在一个缘故上；全书停在“他不从我这一盆火边过了” |

“他添了一根柴”全书十来回，是欧德的节拍（卡里声口“说一件火边的事就添柴”），也是莱奥记他的固定栏，跟铜舌的“明天来”一个做法，没有拆。

## 二、改了的

| # | 位置 | 原句 | 改后 | 为什么 |
|---|---|---|---|---|
| 1 | 前言第三段 | 我请他教我守火。他教了。 | 我请他教我守火。他点了一下头，别的什么也没说，我就当他是答应了。 | 用户举的那一路冷笔（一个动作，两个字）。一个十九岁的骑士求老师收他，不会这么记。“点一下头”是卡里欧德认人的动作（传奇条人间侧），“我就当他是答应了”是莱奥老实、拿不准 |
| 2 | 前言第四段 | ……我从牧野带出来的，往后用不上了。 | ……往后用不上了，又舍不得扔，背面拿来记这个正好。 | “往后用不上了”冷收。正常人说起拿家里的马谱记别的，会顺嘴说为什么用它。没加事，装帧那一栏就写着正面马谱、背面这一本 |
| 3 | 前言第七段 | 我还是叫陛下。他不应，也不拦。 | 我还是叫陛下，他不应我也照叫，要我叫他老守火的，我张不开这个嘴。 | “他不应，也不拦”是盖章，卡里黛拉、莱奥两处都用过这个句架。卡里莱奥“对方不应也照叫”，他是王家出身、认真的人，改叫老守火的他开不了口，这是他自己的缘故 |
| 4 | 二　柴横着添 | 陛下在旁边，没说话，添了一根。 | 陛下在旁边看着，也不替我说一句，添了一根，横着的。 | “没说话”冷收。莱奥被黛拉抽了柴，心里有一点委屈，老师不帮腔，却当面横着添了一根，这一条的题就落在他手上。没加事 |
| 5 | 三　别坐上风头 | 他添了一根柴。那一夜他没再说话。 | 他添了一根柴，往后那一夜就盯着火，我再问什么，他都像没听见。 | “那一夜他没再说话”冷收。卡里欧德“难过了盯火”，提到墨勒他难过，写出他盯火、莱奥还在问，下一句“我后来问了嘉琳老夫人”接得更顺 |
| 6 | 六　兽怕的是光 | “它退了，火还在。我知道这个，就够了。” | “它退了，火还在，剩的柴烧得到天亮。” | “就够了”是盖章词。“我不知道”是锁（熄原两回退开的缘故不说破），照留；后半句换成老守火人真会接的那一样：卡里他注意的是火色、剩柴。不知道的事他不去想，他想的是柴 |
| 7 | 七　护火 | “我护得住身子底下的。别的护不住。” | “我护得住的，就身子底下这么一块。” | 否定对称。意思没变（只护得住身子底下），说成一个老人比划着说的大小，上一句“我没动。火在我底下。”照留 |
| 8 | 八　火灭了 | “西边。很远。” | “西边，很远，我没去过。” | 报两个字。卡里他五十年没出过城门，灰桥他是真没去过，这半句是他照实说，不是他懒得说 |
| 9 | 十　后半句 | 黛拉姐姐应了。 | 黛拉姐姐这才应了。 | 一句一段的冷收。加“这才”，是莱奥在边上松了一口气，单起一行的节拍照留 |
| 10 | 十一　火边的人都一样 | 我在冠殿前头看着，没过去。 | 我在冠殿前头看着，想过去，又怕他当着陛下骂我，到底没过去。 | “没过去”冷收。卡里莱奥“硬声叫父王”，正史里他带一队不烧麦“挨了父王的骂”，没随父王回牧野。他怕父王，这是他此刻真会写的 |
| 11 | 十二　按石头 | 我又说了一遍。 | 我又说了一遍，这一回说得比在门槛上稳。 | 冷收。头一回按的是门槛，第二回按着火烧过的石头，他自己觉得不一样，写出来才看得出这一块石头为什么拴在绳头上 |
| 12 | 十三　问路 | “头一堆记得。这一堆记得。中间的，火记得。” | “头一堆记得，这一堆记得。中间那些，火记着呢。” | 三拍排句，是设计备注里新起的那一句（★）。意思不动，前两拍并成一口气，末一拍加“呢”，是老人记不全、也不怎么在意的口气，不是一块碑 |
| 13 | 十四　三段祷 | 我学到第二段。……等我守满了再教。我还没守满。 | ……我还没守满，等守满了，那一段我补在后头。 | 冷收。记的人会替这一本留个口子。书后头没有补，卡里他到死学到第二段，读者看得出他一直没守满，这一笔不写破 |
| 14 | 十五　抬头 | 我不知道他是怎么知道的。我没问〔注四〕。 | 我不知道他是怎么知道的。脸上烧得厉害，这一回我没敢问〔注四〕。 | “我没问”冷收。莱奥是什么都要问的人（全书一条一条都是他问出来的），这一回不问是有缘故的：卡里“问完会脸红，说到试冠就低声”。〔注四〕位置没动 |
| 15 | 十六　冠在殿里 | 这一本记到这里〔注五〕。 | 往后他不用再去冠殿，也就不从我这一盆火边过了。这一本记到这里〔注五〕。 | 给停笔一个理由。前言写他每天“看完了从冠殿前头过，有时候在我这一盆火边蹲一会儿”，冠还回白石、他回东门以后就不路过了，书自然记到这里。不是新事 |

## 三、留着没改的冷句和缘故

| 句子 | 缘故 |
|---|---|
| 扉页、第一条、第十六条的“火边不能没有人。” | 书名句，卡里底线原话 |
| 第一条“会灭。” | 欧德回一个孩子气的问题，两个字是他懒得解释，下一回莱奥再问他才说出“有人在，灭了也有人知道”，这一来一回是这一条的骨头 |
| 第二、四、五、七、八、九、十一、十二、十三条开头那几行引语 | 守火的规矩本身，一行一条，祭火与守火条的原话也是这个形状 |
| 第三条“墨勒给的。” | 提到墨勒他就说这么多，接着盯火 |
| 第四条“这是嘉琳老夫人跟我说的，陛下没说。” | 莱奥标消息来源，前言说了“我自己添的话写明是我添的”，这是他守的规矩 |
| 第五条“他们说的。”“我不知道。兽知道。” | 设计备注点名的锁，神殿那一层说法只给莱奥转述 |
| 第六条“它冲着火来。”问熄原时又答一回、“我不知道。” | 他拿同一句挡回去，熄原退开的缘故照锁不说破 |
| 第七条“熄原拖着鱼叉冲过来，他没有跑。”“我没动。火在我底下。” | 全书最险的一处，该冷 |
| 第九条“十四岁。老守火的跟我说了，我应了。他就走了。” | 老守火的走了（交完火就死了），他说到这里就停，该冷的地方 |
| 第九条“火是她点的。” | 不点希尔妲的名，他就说这一句 |
| 第十条“都对。” | 他懒得在两句老话里挑一句，接着添柴，是他冷的方式 |
| 第十四条“我只会念，不会讲。” | 他照实说自己会什么，是这个人 |
| 第十五条“都是。”“你那一队没烧麦。” | 一问一答，冷的那一下是他看穿了莱奥，留 |
| 第十六条“冠在殿里，谁都碰得着。”“我添柴去了。”“火边不能没有人。你这一盆，有你。” | 诀别，全书该冷的一处，卡里传奇条台词样例原话 |
| 第十四条三段祷词 | 祷文，不动 |
| 前言“不是灯，是真火。” | 否定句，可它说的是一件实事（三段祷只认真火，第十四条“术式造的光不认”），不是收尾，留 |

## 四、跟卡对不上的地方（照原稿没改，等主会话定）

- 设计备注“新起的”那一条写“第十三条欧德知道莱奥那一队没烧麦”，锁那一条写“第十三条写成他自己看着它”，书里这两件都在第十五条（抬头），第十三条是问路。设计备注没动。
- 卡里欧德叫嘉琳“嘉琳姐”，书里他一回也没提她的名字，只有莱奥叫嘉琳老夫人，对得上，不算出入，记一笔。
- 卡里欧德 3000 年凝名时“灵格（LVL 58）”，凡世至强条写“LVL 60 上下”，两条之间自己差一点，书里不涉及。
