# 大图书馆声口重写｜派活说明（11-28，四本样稿用户认了：“改了感觉好多了，就按这个来吧”）

你给大图书馆的一本书做“声口重写”。书在 `底稿/门面/第二轮/大图书馆/书稿/<书名>.md`。

## 先读（照次序）

1. `底稿/洗稿_图书馆/冷笔_口径.md`：这一轮的重点，用户原话在头上。
2. `底稿/洗稿_图书馆/研读笔记_原神里一个人写的字.md`：第二节七个层面、第四节你这本作者那一类的抓手、“不做的事”。
3. 样稿四本的改动单（认了的做法照这个）：`底稿/洗稿_图书馆/重写/` 下 `*_改动单.md`，至少读两份。
4. `底稿/洗稿_图书馆/试点报告_11-28.md`：GPT 踩过的坑（叠字当病洗、书面词、改意思、加没有的事、把有声口的短句洗平），别重犯。
5. 根目录 `CLAUDE.md` 的「写作口径」：卡面标点和禁词、台词那一节、西幻译本腔不用中式口语和古文（`旧字换词表_10-20.md`）。

## 人设包

先看 `底稿/洗稿_图书馆/人设/` 有没有这本的（文件名是书名去掉厅名）。没有就自己做一份写进去：书头的作者栏、成书、装帧照抄；作者在卡里有条目的（`python -I -X utf8 tools/namegrep.py 作者名` 或 Grep 四纪源稿和 `底卡洗稿/`），把人物条或旅伴条里的身份、声口块（【独立声口】）抄进来；没有条目的，照书头写两三句嗓门画像，标明是你提炼的。

## 做法

1. 给作者定七个层面（时间尺度、自称称呼、连接词、问号、手边的东西、消息来源、怎么停笔），几个作者的各定各的，写进改动单开头。
2. 通读，找冷笔：报数加两个字、立住了／认了／作数／算数／记下了／收了／就够了／不画这类盖章收尾、否定对称、段段一句冷收。每一处问“这个人此刻会这么说吗”，不会的改成他会说的；几个人嗓门不分的拉开。
3. 歌、诗、童谣、祷文、誓词、呼告、名录、表格这类本来就是短句的不动；一本里大半是歌诗的，只动散文的部分，全是歌诗的就改动单里写明“不动”，整本照抄交回。
4. 真该冷的地方（死、诀别、发誓、规矩本身）留一两处。
5. 事实、数字、人名地名、元信息栏、`## ` 小标题、〔〕标记、青墨注脚、设计备注一个字不动。不加原稿没有的事；要添细节只用书里或卡里已经有的东西。
6. 改动的段落别超过一半。

## 交什么

- `底稿/洗稿_图书馆/重写/<书名>.md`：整本，格式跟原稿一样。
- `底稿/洗稿_图书馆/重写/<书名>_改动单.md`：七个层面；每一处改动原句、改后、为什么（“正常人会这么说吗”那一问怎么答的）；留着没改的冷句和缘故；跟卡对不上的地方（照原稿没改，等主会话定）。
- 改完跑 `python -I -X utf8 tools/check_people_v7.py <你的文件> .`，硬问题 0；有台词的照 genshin-dialogue-voice 跑 voice_check（`skills/genshin-dialogue-voice.skill` 是 zip，解到你自己的 scratchpad 子目录），加 `--written --ban "…！—；"`。

只动这两个文件、人设包和你的 scratchpad，不提交、不派子任务。回话八行以内：动了几段、改的主要是什么、要主会话定的。
