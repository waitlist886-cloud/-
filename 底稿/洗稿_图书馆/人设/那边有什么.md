# 人设｜《那边有什么》的两个嗓门：文森特·哈尔特（说）、委托厅的老书记（记）

书头照抄：

- 作者｜文森特·哈尔特 口述，阿卡迪亚委托厅的老书记 记
- 成书｜口述在迷宫纪九百七十一年霜降月到九百七十三年蝉鸣月中旬，一旬一个晚上
- 装帧｜纸是委托厅剩下的白边单子，翻过来写，背面还看得见单头的格子。封皮是一只没用上的剑鞘皮套，拆开压平了包上去，皮面上一圈针眼是磨剑街哈尔特家的针脚。每一页底下一行小数字，是口述的人要书记添上的步数。

## 文森特·哈尔特（卡里有条目）

出处：`迷宫纪前传/parts6/a_空着的环.md`「旅途同行：文森特·哈尔特（迷宫纪·空着的环）」「旅途同行·背景：文森特」，`迷宫纪前传/parts5/p7_空着的环.md`「剑响处，黑潮的年月里的文森特·哈尔特和费伊·拉森（人物）」。

- 身份：人族盲剑士，817 年生在露玫城花冠决斗场后头磨剑街哈尔特家，父亲磨剑，母亲缝剑鞘皮套。十五岁上决斗场，五年没输，约 838 年到阿卡迪亚下井。858 年黑潮第九年瞎了，四十一岁；860 年塔隆·黑燧劝他又拿起剑。877 年寒星月第一道墙北段灯全灭的那一夜凝名，北段的兵管他叫剑响处。940 年费伊·拉森来给他报路，943 年剑柄缠出环，959 年第七十四回她松了手。971 年起领骨谷暗窦的路。973 年蝉鸣月下旬三日死在第四十五层的骨桥上。973 年一百五十六岁，看着四十七八。
- 性格底色：慢，静，话少，开口多半是一句短的，带一点不笑的玩笑。听的比说的多，不怕死，怕的是身后半步那一处一直空着。
- 【独立声口｜文森特】
  - 句式：短，慢，一句一停，常拿一个字收住，好，行，嗯。开玩笑不笑，玩笑跟正经话一个口气。报路报步数和方向，不报看见了什么。
  - 注意什么：脚步，喘气，风从哪边来，谁的靴子钉了铁掌，谁的喘气快了半拍。
  - 称谓：头一回见叫人的脚步，报了名字以后叫名字。说起她，只说过一回名字，往后说她。对谁都用你。
  - 情绪：难过的时候拇指在剑柄那两圈布上来回摸，摸到环那里停一下。高兴了说一句玩笑，没人笑，他自己点一下头。着急了反倒更慢，一个字一个字往外放。
  - 不写：一心求死的老人。也不写成神神叨叨的盲剑圣，他说话跟井口的老兵一样，嫌饭咸，嫌鞋紧。
  - 台词样例（卡里原句）：“三百一十。往右半步，对，再半步。”／“那边有什么？嗯，问惯了，没人答也行。”／“你喘气快了。怕就说怕，这一段谁也看不见，不丢人。”／“万一有人愿意抓呢。”／“你们跟去了也是白瞎。我本来就瞎，我去不算白。”／“环空着，退不了。”／“好。”／“叫我名字就行。剑响处那三个字，留给墙上喊吧。”／“你拽我就退，你不拽我就上，你别替我想多了。”
- 费伊（书里卷五、卷六的转述）：快，三个字三个字地报，报完了嘴闲不住，问东问西。台词“打的事归你，看的事归我，行不行？”“他们又说我是你的眼睛了，你又要说不是了吧？”“嗯，我是先看见的那个。”都是卡里原句。

**这一本里他的嗓门**：说话，不是写字。短句、一字收住是他本来的样子，不当冷笔洗；要动的是像旁白盖章的收尾（照旧、不是、别替我握剑这一类单起一句的）。他看不见，凡是“看着”的事都是别人告诉他的。他的热从三样缝里漏：一句替自己找的缘故，一句不笑的玩笑，一样他注意的东西（脚步、风、铁掌）。

## 委托厅的老书记（卡里不起名，嗓门是我提炼的）

卡里只在 `迷宫纪前传/parts6/a_空着的环.md` 人物「第四十五层那两队和医疗院里的十一个人」一条里有一句：委托厅的老书记，中旬五日照文森特说的写那张单子，一个字没漏，末一句“书记写完念一遍给我听”也写上了，押按在格子外头半个指头，没叫他重按；金穗月上旬结案是这一个书记写的。委托人一栏是书记的字。

提炼的嗓门（★）：管单子的人，一辈子替人写、替人念、替人记。在意的是格子、日子、押、一个字漏没漏、照规矩该怎么办、他这一回没照规矩办。句子比文森特长，逗号串下去，先写日子再写事；消息照来处写明（前哨的人说、去收他的人说、北段一个老兵跟我说）；不替人下定论，两种说法并排摆着。情绪不出口，落在手续上（没叫他重按、照他的意思空一行、照他的意思没有填）。停笔落在本子自己身上（空着的两页）。
