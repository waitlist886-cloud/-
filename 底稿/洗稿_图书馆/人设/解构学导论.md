# 人设｜《解构学导论》的作者（镜湖地宫，不署名）

书头照抄：
- 作者｜镜湖学城，不署名。讲义是地宫里头几代导师口述、学徒记下来的，一代一代抄，书上没有一个人的名字
- 成书｜讲义约月银纪8220年起在镜湖地宫里传抄，那时候叫拆兽讲义。解构学这个名字是约8400年前后叫开的，书名是那时候重抄时题的
- 装帧｜镜湖学城的灰蓝纸，纸面摸着发潮，放多少年都是潮的。封面嵌着一面巴掌大的铜镜，镜面朝里，贴着书页。书页边上有六七种不同的手写的批注，墨色从黑到褐

作者在卡里没有人物条。卡里管得着这本书嗓门的是地点条 `镜湖（月银纪）`（moon/batch2/c1_cities.md）：
- 人情：镜湖的人话少，记性好。城里没有账本，账在人脑子里。学徒从各国来，先在湖边扫三年地，三年里不许照湖。
- 风貌：镜湖的人走路轻，说一句停一下，在这里大声说话，满湖边的人都转过头来看你。
- 写法：先写湖面，再写窗。镜湖人说一句，停一下，再说下一句。
- 活事件《地宫门口不吭声的那一只崽》：乔琳·白窗照了湖，写了没染，字很小；镜湖的老人说，照出来的东西你得认，认了就得说；往后照兽先蹲下来，站着照，照不准。

照这些提炼的嗓门（声口重写这一轮写的）：
- **讲义的导师**：对着刚扫完三年地、头一天下第一层的学徒口述，句句冲着“你”。话少，说一句停一下，书里自己写明“这一本也一样”，所以短句、单起一段是体例，不是冷笔。冷法是规矩人的冷：先下命令（先照、拆到核停一下），再给一句理由，理由落在手上的事（蹲下、摆成一排、装回去）和一样东西（湖、灯、笼子、刀）上。消息来源是“镜湖的老人说”“乡下人都知道，神殿也知道”。偶尔不耐烦地往回指（第二讲说了、第六讲说过）。规矩本身（不拆、不署名、拆的时候不说话）照冷着留。
- **页边的批注**：六七只手，几代人。褐色的是后来的、年纪大的（八三一二年以后残兽变小那一条，梦见妹妹那一条），黑色的多是学徒（抄了四十遍、嫌湖边的人说地宫话多、第七层快放不下了），一个是看过兽市的人。学徒的手比导师松，可以有一句顶嘴和一个问号。
- **附页的册子抄件**：地宫的账，年份打头，一条一件事，固定的次序（照湖、眼、伤口、缝、拆、核里那一声、几人拆过、合回去了），是表格一类，不动。
