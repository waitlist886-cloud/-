# 打回意见｜三本共通（第一轮审稿，主会话）

你这一轮最好的地方：台词活了一些（“哈布，纸上叫你敲，可没叫你催债”“别拿裂过的地方试运气”“等它锈死在上面，再好的锅也白做”），排戏的叮嘱也贴班主的身份。下面四类毛病要改掉，没点到的地方别动。

1. **叠字不是病，扎堆才是。** 派活说明里那串词是让你压密度，不是一个不留。原稿里“一盏一盏灭”“一膛一膛往回退”“一层一层黑下去”“一个一个爬出来”“一行一行淡下去”这种是故意的节拍，你一律换成了“依次”“逐层”“逐行”“陆续”“接连”，节拍没了，还冒出了书面腔。这一类改回原稿的写法，只在一段里同一个叠字连用两回以上的地方才动。
2. **不许换成书面词。** 这一轮多出来的：享年、逐张、逐行、逐字、逐层、依次、陆续、接连、渐渐、始终、此前、则、竟、原来（表“竟然是”）、充作、供人、将（当“把”用）。这些在书里一个都别出现，换成原稿的说法或者口语。
3. **意思一个字不许走。** 不加原稿没有的事、动机、理由，不删原稿有的。这一轮几处意思变了，具体见各本的单子，一处一处改回原意，句子可以照你的顺法写。
4. **单独成行的短句是节拍，别并。** 原稿里一句话单独占一段的（“我那一台没有灭。”“我就慢下来了。”“唱到天亮，她走了。”），照原样单独成段。
# 打回意见｜《铜舌的锅炉》

先读 通用.md 的四条。这一本两种嗓门：开头一段和注脚是研究所的人写的（平实、不拿腔），中间是薇拉自己的账和图（炉匠，短、直、带炉灰味）。

- **开头研究所那一段你洗成了公文**：“享年一百七十二岁”“研究所将图纸和账本订在一起”“图纸供人抄用，账本留给自己”“书名沿用街上的叫法”。改回平实的说法，原稿“研究所的人把这两样订成一本，题目照街上的叫法写”“前头那一张是她给所有人看的，后头那一本是她给自己记的”是好句子，留原稿。
- 山腹那一夜：“满山的火一膛一膛往回退，炉城的窗子一层一层黑下去”“矿工从井里一个一个爬出来”“满山的炉子回主炉一膛一膛重新取火”，叠字是节拍，改回原稿。你写的“各处炉膛的火退尽”“逐层黑下来”“陆续”去掉。
- “我那一台没有灭。”原稿单独成段，拆回来。
- “首匠尼达尔在山腹里戴上炉冠。主炉头一道炉箍打成的，一圈黑山铜”：后一句没主语，读着断。照原稿“炉冠是拿主炉头一道炉箍打的一圈黑山铜”改顺。
- 第十八台：“这回得烧过才算”是你加的，原稿“点火以前我不说”。改回原稿的意思。
- 账里薇拉的话，你加的口气好的留着（“别拿裂过的地方试运气”“等它锈死在上面，再好的锅也白做”），这类不用退。
