# 金血祝颂改短：派活说明（11-17 晚）

七十九颗金血祝颂照 `改短样稿.md`（第三稿，用户认了）重写：名字改成四个字的一句话，祝颂照崩铁黄金裔的开场写，添一行箴言，效果收短成被动、限制两行。一份一个人写，各写各的输出文件，别动 `稿/` 里的原稿。

## 先读

1. `底稿/金血祝颂/改短样稿.md` 整份。“新的写法”那一节是规矩，九颗样稿是样子，末尾那张表是九颗各用了哪种构词、哪种收法。
2. 自己那一份的原稿 `底稿/金血祝颂/稿/份N_*.md`。本事、数、限制从这里来，收短，不另起新本事。
3. `底稿/金血祝颂/名单.tsv` 里自己那一份的几行（神、神号、尊号、倒影的魔神、倒影的神号）。
4. 想多看这一位神的样子，翻名单那一行指到的两纪神谱（`纷争纪/补卷/补卷_6x_神谱_*.md` 里“是谁”“样子”“留下的”），只取意象，事实以原稿为准。
5. 名字参考崩铁差分宇宙金血祝颂一览（https://wiki.biligame.com/sr/金血祝颂一览）的头一档：四个字，一句压紧的话，落在神话和效果上。只学做法，不搬那边的名字和句子。

## 每一颗写成这样

```
### 名字 (Passive | Legend)

【调用】……

- 祝颂：……
- 箴言：……
- 被动：……
- 限制：……
```

份8 每颗末尾照原稿再留两行：`- 只给 AI：……`（收到六七十字，不点倒下诸神的名字，那几样一样是一位、七支柱承载诸神宏愿这一层留着），`- 前传的局：……`（一句，隔代醒）。

- **名字**：四个字。照样稿“新的写法”里名字那几条：多半写一个动作或情形，少数是名词；虚字只用而、与、以、于、之、有、无；名字是这一颗本事的一幅画；带着这一位神的口气。不带逗号，不带你我，不写大白话，不照抄神号、尊号，不用武侠修仙的现成话。
  - 一份里构词错开：十颗上下的一份至少五种构词，同一种至多两颗（份3 十二颗至多三颗）。
  - 九颗样稿的名字已经占了：长风无缰、赤足逐晓、箭随目至、门槛借息、与山同立、握火锻铁、伏浪而归、以光缝伤、盾后有人。别撞，也别跟它们只差一两个字。
  - 例外：伊斯卡图那一颗照旧叫金雨之血（月银纪第二歌狄昂页上那一颗的名字，这一颗是黄金裔拿到的 +30% 那一版），本事照原稿收短，不加每天一回的那一手。
  - 份8 七神那一版的名字要跟份1 到份7 里同一位柱神那一版分得开（璐璐薇七神那一版是九阵风，别再叫长风什么）。
- **【调用】**：一句，三十字上下，写什么时候用（他在干什么、碰上什么、谁问起什么）。份8 写“山铜纪的局里……，前传的局看末一行。”这一类。
- **祝颂**：两截，四五十字到六十字。
  - 头一截：称号或身份，再“……的黄金裔”，中间是一个动词加这一位神管的东西。不点神亲，不报名字，不照抄尊号。一份里“……的孩子”至多三颗，称呼各不相同；头一截的动词一颗一个，别跟样稿的撞。
  - 第二截：天命，“你要”起头，两到四个分句，往大里写，落在实物上，不落在命运、荣耀、宿命、羁绊、永恒这类空词上。可以比效果大，不能跟限制打架。一份里至多两颗换成问句（你可愿……？）或别的起法（启程吧……）。
  - 祝颂里不套引号。
- **箴言**：一句，十五到三十字。收法换着用：反着说的一对，一幅画面，一句引语（套“”），一句不服输的话，一句格言。一份里至少四种收法，愿字起头的至多一颗，引语至多两颗。常跟这一位神的倒影对着写，倒影的名字不点。不讲道理，不点破。
- **被动**：两三句，八十字上下，至多一百字。直接写机制和数：几倍、加几成、几步以内、对哪一档有效、每天或每场仗一回的那一手。数照原稿（可以取整），不另加本事，也别比原稿强。传奇那一句可以不留，留就半句。末尾照原稿的六维，“XXX／YYY +30%”，两项、全角斜线。
- **限制**：一两句，三四十字，写什么时候不灵、管不到什么，照原稿挑最要紧的一两条。
- 原稿里“这一颗是什么”那一段、修行关联、世界反应都拿掉。

## 样稿九颗

九颗在自己那一份里的，名字、祝颂、箴言、被动、限制照样稿一字不改抄进来，只添一行【调用】：份1 璐璐薇、莉尤、卡瑟蕾、塞维娅，份2 欧巴德斯、卡尔德隆，份3 乌姆拉，份6 朱亚，份7 斯卡索。

## 卡面规矩

- 标点：不用 ——、—、；、…、！、...。冒号只在“- 祝颂：”这种行首标签后头，一行里别再有第二个冒号。对白和引语用“”，「」不用。
- 不写月相：新月、满月、残月、月牙、弦月、月亮、月光，带这些字的词也不行。
- 禁词照 `tools/check_people_v7.py` 那张表（一丝、一抹、不禁、威压、修为、登记、军令、晋升、时辰、客栈……），科技词（能量、系统、坐标、频率）不用。武侠古风的字不用（江湖、内力、吐纳、丹田、掌门、轻功这一路），中式口语不用（爹娘、俺、啥、晌午）。营不泛用。
- 神用祂。卡面不点神亲是谁，也不点倒影是谁。
- 份1 到份7 那七十二颗月银纪、纷争纪两纪都用，卡面别写只在一纪才有的东西：魔神、长垒、段城、联军、军册、萨尔维斯、辉塔、星冠圣城、白烛、客星城、浮空塔、机兵、炮、列车、命路、面板、旅印、公会。份8 写在山铜纪和前传两处都成立的东西（段城、白烛可以，公会、旅印、委托、黑耀、灰之魔女不写）。
- 弥拉德、欧墨伦在月银纪几歌里露过面，身份只给 AI，他们页上的原话别借进祝颂和箴言。
