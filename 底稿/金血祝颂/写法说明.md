# 金血祝颂：写法说明（11-17，给起稿的子任务看）

用户 11-17 原话：“黄金裔可以作为额外选项在后续加入并让玩家选择自己的金血祝颂（Legend Passive，来自哪一位的血，来自祂的祝福）”，又说“金血祝颂的命名可以参考崩铁”。方向稿是 `底稿/门面/前端精修_方向稿.md` 第九节第 3 小节。

**11-17 晚改短了，名字、祝颂、效果以 `改短样稿.md` 的“新的写法”为准**：名字照崩铁差分宇宙金血祝颂一览的头一档，四个字一句话；祝颂照崩铁黄金裔的开场，叫出人再用“你要”交代天命，另起一行箴言；效果只留被动、限制两行，带数；“这一颗是什么”那一段、修行关联、世界反应拿掉。这一份里神亲怎么挑、限制落在哪、七神那一版、不点神亲这几条照旧算数。改短以前的稿子在 `稿_改短前/`，旧名字对新名字在 `改名表.tsv`。

## 一、是什么（★ 这一轮定的）

- 神爱上凡人留下的孩子叫神裔，神血醒着的那些血生来是金色的，人管他们叫黄金裔（四纪常驻原话）。金血祝颂是神亲落在这个孩子血里的那一颗祝福：一颗 Legend 的 Passive，生来就有，头一回露出来多半在少年时的一件事上。写的是这一位神管的东西落在一副凡人身子上的样子。
- 一位正神一颗。七十二位正神（七支柱加六十五位）各一颗，月银纪和纷争纪是同一位神，用同一颗，所以写的时候不挂某一纪的人和事（不写长垒、段城、联军、萨尔维斯、星冠圣城这些只在一纪才有的东西），写在两纪都站得住。
- 七支柱到了山铜纪是七神，承载着倒下的诸神的宏愿，七神那一版另写七颗，一共七十九颗。山铜纪的黄金裔用这七颗，迷宫纪前传也用这七颗：七神迷宫纪本人不现身，前传的黄金裔是隔代醒，祖上是山铜纪七神的孩子，血隔了几代在他身上醒过来。
- 魔神生不出黄金裔，名单里没有魔神。凡人那一头是魔族的照旧算。
- 玩家建档时挑神亲，挑完拿到这一颗；建档时另挑本人知不知道自己是谁的血。叙述和旁人照旧不点破神亲是谁。

## 二、崩铁怎么起名（照 BWIKI 读的，只学做法）

1. 模拟宇宙的“祝福”一个命途一套词：丰饶全用佛经里的话，巡猎用星宿和弓的话，毁灭用天体物理，存护用晶体材料，虚无用哲学书名，记忆用电影名。同一个命途的祝福一读就知道是一家，不同命途的又一读就分得开。**我们照这个分组：七组正神一组一套口气（第三节），同组的名字读起来是一家人。** 词不借它的，借的是做法。
2. 翁法罗斯的黄金裔（金血就是从这里来的）。每人一段称号式的题词，骨架是“地方或身世的一句。称呼 名字，［一个动词］某某火种的黄金裔。你要……。”后面再接一句愿望或者本人的一句话。动词各人不同，容纳、寻索、守望、戏弄、执握、窃夺、诘问、哺育、逐猎、清洗，一个动词就是这个人跟那一位泰坦的关系。**我们的“祝颂”那一行照这个骨架写（第四节），动词全卷不重样。**
3. 翁法罗斯黄金裔的星魂和技能名，句式有这几种（我们自己的例子都是示意，不许照抄）：
   - 甲，两截：一个名词，逗号，一个动作。崩铁例：「哀悼，死海之涟漪」。我们的：灰烬里，第二个春天。
   - 乙，介词起头，六七个字：以……加冕，拥……安眠，待……破茧。崩铁例：「以扑翼繁花加冕」。我们的：以潮声为心跳。
   - 丙，动作带定语收在一个名词上：……的……。崩铁例：「呵护黑夜中的烛火」。我们的：九阵风织成的羽衣。
   - 丁，“当……”起头的半句。崩铁例：「当微风轻吻云沫」。我们的：当最后一盏灯也灭了。
   - 戊，一句话，神对孩子说的，或者孩子自己说的。崩铁例：「送你一颗橙晖琥珀」。我们的：潮水为你退一步。
   - 己，四个字的意象，像跃迁名。崩铁例：「冥途生花」。我们的：烬里生青。
4. 一份里六种句式至少用四种，同一种不超过三颗。名字四到十个字（逗号不算）。

## 四、一颗怎么写（卡面）

格式照页上的星（`### 名 (Passive | Legend)`，参考 月银纪史诗/第二歌_镜中石瞳.md 的金雨之血、第七歌_焚原断刃.md 的眠山血脉）：

```
### 名字 (Passive | Legend)

【调用】什么时候用，一句话，写这一颗具体在哪些场面露出来、有人问起什么的时候（不写成七十九颗一样的套话）。

> 祝颂：……（两三句，照第二节第 2 条的骨架）

【名字】是……（头两句：它是什么样的天赋，生来在血里，样子跟着那位神；再一句头一回露出来的样子）

- 被动：……（两三样看得见的魔法，写到看得见的结果，带数：多远、多大、几天、一天几回。位阶到传奇长成什么样，至多一句。末尾属性：如 VGR／DEX +30%，属性只用六维：STR、DEX、MANA、MIND、VGR、FTH，没有 IND、INT、CHA）
- 修行关联：吃哪两三门 Skill。
- 限制：管不了什么，挡不住什么，几时不应他。可以落在这位神的倒影上（倒过来的那一种水、风、火不认它），不点魔神的名字。
- 世界反应：一件事、一条规矩或一个价钱。可以不写。
```

几条规矩：
- 名字不带神名，也不照抄神号（神号是“朝潮夕汐之主”，名字就不写朝潮夕汐）。意象从神管的东西里取。名字之间不撞，不跟仓库里已有的名字撞（跑 namegrep）。
- 不把七十九颗都写成“X之血”“X血脉”。已有的金雨之血照收，别的不再用之血收尾。
- 祝颂是神亲留在血里的一句祝福，冲着孩子说。骨架“［称呼］的孩子，［动词］［这位神的东西］的黄金裔。你要……。”再接一句愿或者神的一句话。称呼不用神号原文，用意象（“涨落之间的孩子”）。动词全卷不重样，一份里先列出来自己查重。卡面不许用「」括这位神的东西（「」只给真条目名），直接写。
- 头一句要有“天赋”“生来”“与生俱来”“天生”这一类字（tools/starlint.py 查）。“落在金血里”这个说法一份至多三颗。
- 七十二颗写在月银纪、纷争纪两纪都站得住；七神那七颗写在山铜纪，另添两行：一行“只给 AI：……”写这一颗压着这一组倒下的神的回声（七支柱承载诸神宏愿，叙述不点破，★），一行写前传的局里是隔代醒。
- 效果是 Legend 的 Passive：比页上寻常的 Epic Passive 大一截，不到 Unique；写看得见的魔法，结果写到看得见为止，不写原理，不写成手续、账、条款。
- 卡面口径照仓库 CLAUDE.md「写作口径」：不用 ——、—、；、…、！、...；冒号只在八个字以内的标签后头，句子当中、一行里第二处都不用冒号（cardscan 会报）；不写月相字（新月、满月、残月、月牙、弦月、月亮、月光）；不用武侠古风和中式口语、古文（时辰、江湖、内力、爹娘、灶、庙、祠……），不借中式典故（帝星、太清这一路）和佛经词（涅槃、无常这一路）；神用祂；新起的设定标★。
- 已经有黄金裔的神，照页上那个人对：伊斯卡图就是狄昂的金雨之血，照收（只补祝颂那一行和【调用】，被动和限制照原条，可以顺一顺字，不改意思）；瑞恩达尔是第三歌埃蒙的父亲，赫斯陶是第四歌阿尔凯的父亲，写之前读那两个人的星，金血祝颂跟他们身上露出来的样子对得上。

## 五、样稿三颗（主会话写的，照这个分量和口气）

### 潮水为你退一步 (Passive | Legend)

【调用】他落进水里、在海上遇险，或者有人问他怎么不看潮表就知道几时涨潮的时候。

> 祝颂：涨落之间的孩子，与大海同息的黄金裔。你要记住每一回退潮，在岸上等它回来。愿出港的船都回港，等船的灯都等到人。

【潮水为你退一步】是一副跟着潮汐呼吸的身子，生来就有。他的心跳和呼吸合着海，涨潮时醒得早，落潮时睡得沉。头一回露出来多半在水里，浪头扑上来，在他跟前往后让了一步。

- 被动：他不看潮表也说得出这一处几时涨、几时落，在海上分得清哪一道是暗流。一口气在水底撑得住小半个钟头，海水泡过的伤口当天收口。一天一回，水要吞他的那一下（扑上来的浪、决了口的河、漩涡、灌进舱里的水），在他跟前往后退一步，让出三五步宽的一块干地，传奇让出一条小巷那么宽，撑到他走出去。VGR／DEX +30%。
- 修行关联：游泳、航海、察觉。
- 限制：退一步就是一步，潮照样涨，海照样大，他挡不住海啸，也渡不过一整片海。离海越远心跳越乱，在内陆住满一个月，退潮那一手要等他回到海边才应。倒过来的海，不托船、只张嘴的那一种水，不认这一颗。
- 世界反应：船上的人见过一回就想留他，说他上船那一趟浪都小一号。

### 身后的人都还在 (Passive | Legend)

【调用】他挡在别人前面挨打，或者有人问他为什么一站到前头就砍不动的时候。

> 祝颂：盾墙的孩子，站到众人身前的黄金裔。你要先走到前面去，再回头数一数。愿你数到的，和出门时一样多。

【身后的人都还在】是一副生来就当墙用的骨头。身后有人的时候，他的皮和骨一齐硬起来，像一面盾立住了。头一回露出来多半是替谁挡了一下，棍子、石头或者兽的爪子落在他胳膊上，断的是那一样东西。

- 被动：只要他身后三步以内站着他护着的人，刀、箭、爪子落在他身上伤减半，冲着身后那人去的，先落到他身上。一场仗一回，身后的人要挨死的那一下，由他替着挨，挨完站着不倒，撑到这一回合打完。他提盾不觉得沉，盾在他手里比旁人的大一圈。胳膊挡得住长剑，挡不住重锤。VGR／STR +30%。
- 修行关联：盾、耐力、意志。
- 限制：身后没有人，这一颗就睡着，他一个人的时候跟旁人一样挨打。他转身往后跑，这一颗就不应他，等他再站回前面才醒。替人挨的那一下，伤照样记在他身上。
- 世界反应：跟他一起打过仗的人，下一回自己往他身后挪半步。

### 九阵风织成的羽衣 (Passive | Legend)

【调用】山铜纪的局里，他站到风口上、射箭掷枪，或者有人问他身边的风为什么一阵一阵换脾气的时候。前传的局里照最后一行写。

> 祝颂：长风的孩子，披着九阵风的黄金裔。你要替停下来的风走完它们的路。愿你回头的时候，风还在你身后。

【九阵风织成的羽衣】是千里长风落在金血里的天赋，七神那一版，生来就有。他身边的风不止一种脾气，破晓时吹开云缝，出猎时跟着蹄声，迷路时朝家的方向偏，射出去的箭它托着不落。头一回露出来多半在风口上，他张开胳膊，风从九个方向一齐托住他。

- 被动：顺风、逆风、横风都认他，他射出去、掷出去的东西多走三成远，落地以前风替他扶正一回。一天一回，他能叫一阵风来应他。破晓的风吹开压在头上的云和雾，猎群的风叫他追得上骑马的人，头雁的风把他领回来过的路，满帆的风推着船走一整天，隘口的风把一个名字喊到远处，卷云的风掀翻一辆车，门槛上的风替一个快断气的人续上一口，断缰的风解开捆着他的绳。DEX／VGR +30%。
- 修行关联：弓、掷、察觉。
- 限制：一天只应一阵，挑了这一阵，别的八阵都歇着。风不替他杀人，掀得翻车，掀不翻城。关死的屋子、井底这种没有风的地方，这一颗什么也不做。
- 世界反应：骑鹰的人说，这种人站在崖上，鹰都不先飞。
- 只给 AI：七神那一版的祝颂里压着这一组倒下的九位的回声，一阵风是一位，是七支柱承载诸神宏愿露在凡人身上的那一点。叙述不点破，NPC 说不出来由（★）。
- 前传的局：这一颗是隔代醒的，祖上是山铜纪七神的孩子，血隔了几代在他身上醒过来，家里没人知道是哪一代（★）。
