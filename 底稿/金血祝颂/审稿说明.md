# 金血祝颂：审稿说明（11-17，给审稿的子任务看）

八份稿子在 `底稿/金血祝颂/稿/`（份1 到份8，七十九颗），写法在 `底稿/金血祝颂/写法说明.md`，名单在 `名单.tsv`。你把七十九颗一起审一遍：查错、查撞、查模子，小处直接在稿子里改，改了的每一处记一笔；动得大的（要整颗重写、要改设定的）不改，列出来交主会话。

## 一、逐颗查

1. 卡面：不用 ——、—、；、…、！、...；冒号只跟在八个字以内的标签后头，一行里不出第二个冒号；不写月相字（新月、满月、残月、月牙、弦月、月亮、月光）；不用武侠古风和中式口语、古文（时辰、江湖、内力、修为、爹娘、灶、庙、祠、茶……），不借中式典故和佛经词；「」只给真条目名，祝颂里不用；神用祂。
2. 属性只用六维 STR、DEX、MANA、MIND、VGR、FTH，写在被动那一行末尾，Legend 是 +30%。
3. 名字不带神名，不照抄神号；不写成 X之血、X血脉（伊斯卡图的金雨之血是照收的例外）。
4. 头两句里要有天赋、生来、与生俱来、天生这一类字（starlint 查）。“落在金血里”一份至多三颗。
5. Legend 的分寸：比页上寻常的 Epic Passive 大一截，不到 Unique。不许起死回生，不许一下定胜负，不许管神和奇迹；一天一回、一场仗一回的那一手写到看得见的结果为止，带数；“到了传奇”至多一句。
6. 七十二颗（份1 到份7）要在月银纪、纷争纪两纪都站得住：不写长垒、段城、联军、军册、萨尔维斯、星冠圣城、白烛这些只在一纪才有的东西，也不写只在某一年才有的事。七神那七颗（份8）写在山铜纪，末尾要有“只给 AI”和“前传的局”两行。
7. 事实对神谱：这位神管什么、样子、倒影是谁，照 `月银纪补卷/神谱_0*.md` 和 `纷争纪/补卷/补卷_6[0-7]_神谱_*.md` 那一位的条目。拿不准就翻。

## 二、七十九颗放在一起查

1. 名字不撞：七十九个名字之间不重，句架不撞（“X我来Y”“当……”这种一样的架子全卷至多三四个），也不跟仓库里已有的名字撞（`python3 -I -X utf8 tools/namegrep.py 名字…`）。
2. 句式：写法说明第二节那六种（甲两截、乙介词起头、丙定语收在名词上、丁当……、戊一句话、己四字意象），全卷每一种不超过两成五。
3. 祝颂：骨架是“［称呼］的孩子，［动词］……的黄金裔。你要……。”再接一句愿或者神的一句话。七十九个动词不重样（崩铁那十个也不用：容纳、寻索、守望、戏弄、执握、窃夺、诘问、哺育、逐猎、清洗）；称呼不用神号原文；末句不全是“愿……”。
4. 限制里落在倒影上的那一句，一份至多三四颗，句子换着写。
5. 修行关联、世界反应别一颗一个模子（“……爱请他来……”这种全卷至多三四回）。
6. 七支柱在两纪那一版（份1 到份7 各组头一颗）和七神那一版（份8）名字、意象分得开。
