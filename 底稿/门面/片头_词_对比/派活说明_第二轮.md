# 派给你的活：片头的词，第二稿

这是同一件活的第二轮。上一轮你照 `材料/` 里的东西写了一版片头的词，现在叫 `片头_词_第一稿.md`，就在本文件夹根上。

## 为什么要有第二稿

上一轮给你的研读笔记只记了参考片的架构和手法，没有研究字句。卡的作者看了那份笔记，说：

> 研究架构和手法是没错。但是你同样需要研究“文笔”：具体的用词，遣词造句，如何塑造出那种感觉，如何牢牢的把读者（目标读者是人类）勾住。

照那份笔记写出来的几版（包括你的第一稿）是同一个毛病：四章都在讲史。一拍交代一件事，谁、在哪、做了什么都说全了，句子是过去时的陈述句，听的人不在句子里，没有一处让人想往下听的别扭，没有一句里顶上去的那个字。

`材料/研读笔记_千星纪游与寓言集.md` 已经换成了新的一份，多了第二节「文笔」和第三节「第一版错在哪」。这一轮的活就是照第二节，把片头的词重新写一版。

## 这一轮怎么做

1. 先把新的研读笔记从头读完，第二节一小节一小节对着你的第一稿看，看它缺的是哪几样。
2. `材料/题诗_口气样本.md` 再读一遍。那八十行是作者说过“对味了”的字，你的第一稿里有没有一句到得了那个分量。
3. 重写，不是在第一稿上改字。讲法、分法、靠什么串起来都可以换。第一节「路子」里写清这一稿跟第一稿不一样在哪。
4. 写完自己当一个头一回点开这张卡的人，从头念一遍：头一句有没有把你留住，每一纪有没有一句让你想进去，末一句是不是把下一步交到了你手里。哪一拍只是在交代，就重写那一拍或者删掉。

## 不变的

上一轮的规矩全部照旧，再抄一遍要紧的：

- 屏幕全黑，玩家刚死，眼睛还睁不开。讲的人只有若娜瓦一个，对着“你”讲。她说话短，平，带一点冷的风趣，不自夸，不讲大道理，不抒情。她的口气照 `材料/现有神殿开场.md`。
- 四章，一章一纪：月银纪、纷争纪、山铜纪、迷宫纪。讲完一章，这一章收成一张牌，落到她手里。火贯穿四章。头一拍没有任何图，只有黑里的一点火星和一句话。
- 讲完，玩家睁眼，看见她的神殿和一张圆石桌。她在桌前的头一句是现成的，不改：「生者自有去处，亡魂也有归程。」片头要能接上这一句。
- 一拍是一行字加一个画面。有长短两个版本，短版是长版里挑出来的拍，单看也要通。
- 观众多半不认识这个世界的任何专名。专名要少，出现了要当场听得懂。
- 事实照 `材料/四纪要点.md`，那里没有的事不编；末尾“不碰的”那几条一个字不碰。实在要新起一点，在交稿末尾标★列出来。
- 标点：不用破折号、省略号、感叹号、分号。不写月相。神用“祂”。
- 两头都别去：一头是口语、村口、小气；一头是古文腔和成串的四字格。
- 参考片只学做法，一句也不照搬，也不要换几个字仿写它的句子。笔记里说到的词和搭配法是让你明白机理的，落笔要用这个世界自己的东西：火、灰、白石、长墙、碑、绳、灯。
- 她是念，不是唱。不要把她的话写成押韵的诗。

## 交什么

只写一个文件：本文件夹根上的 `片头_词_第二稿.md`。不要改别的文件，不用联网，不用跑检查脚本。里面依次写：

1. **路子。** 两三百字：她怎么开口，四章怎么分，全篇靠什么串起来，每一章落在哪里；跟第一稿不一样在哪。
2. **词（长版）。** 三十五到五十拍。一拍一行，从 1 起编号；每拍前头标 ●（短版也留）或者 ○（只在长版）。每一章开头用一两句话写这一章的题签和画面大意，章末用一句话写收成牌的那一刻。一拍的字不要太长，超过二十五个字的想想能不能拆。
3. **短版。** 列出标 ● 的拍号，自己顺着读一遍，确认单看也通。
4. **字句上的讲究。** 挑你最得意的八到十二拍，一拍一句话说它用了笔记第二节的哪一样（哪个词是顶上去的，哪一处搭配，听的人在哪里）。
5. **备选。** 拿不准的三到六处，各给一个备选。
6. **四张牌上的那一句。** 一纪一句，十到二十五个字。
7. **自查。** 规矩逐条过没过；新起的事实标★；这一稿最弱的是哪一处。
