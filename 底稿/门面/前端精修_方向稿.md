## 一、现在的样子

拿 act_wb.mjs、act_build.mjs、act_sandbox.mjs 在电脑（1920×945）和手机（390×844）上截过一遍。

- **世界之书**：一个米色的大框，左边一列目录（五卷，加上这一卷的页），右边一页字。一页只有标题、小标题和成段的字，地图那一页有图，别的页一张图也没有。五卷用的是同一种纸、同一种颜色，看不出是哪一纪。电脑上字只占中间一条，右边空着一大半。手机上是顶上两排页签。
- **建档**：死之神殿的黑底上，若娜瓦说四句话，底下一张很长的表（一纪一种册子的颜色），从上到下二十来栏：哪一年、你是、名字性别年岁、种族（十二张小卡）、支系、样子、从哪里来、本事、誓心、初心、立绘地址、还想让她知道的。一次全摊开，像填一张报名表。
- **确认页**：一块凭证原文加四个钮。
- 介绍页里已经精美的几样：牌桌（若娜瓦的手、一纪一张牌背），四本书（壁画长墙、战场之路和圣牌、碑路、往下的井），时代页的原画和节点原画，黑底的档案页（四套衣服、表情）。拿这几样当标尺，世界之书和建档差了一截。

## 二、总的路子

1. **不另起一套。** 牌桌、四本书、档案页已经定下这一张卡门面的样子：黑底，若娜瓦的手，牌，一纪一种材质（月银纪银蓝和石壁，纷争纪黑红和军册，山铜纪黑白两半的碑，迷宫纪深蓝和金线），一纪一枚徽记（共用/assets/ui/emblem_*.webp）。世界之书、图鉴、建档都照这个样子做。
2. **先用已有的图**：四纪主画，时代原画（月银纪 27、纷争纪 21、山铜纪 6），迷宫纪的壁画 43，节点原画，史诗战 687 张，神明显像 144 张，立绘和艺术照，四纪的四方画，主角预设 198 位。缺的另出（第六节）。
3. **都放在图床上，不动卡。** 上一轮量过：门面怎么改，卡的大小都不变。凭证一个字不改（首轮入局驱动认的就是这个格式）。
4. **先照手机做**：一屏只办一件事，字和钮都够大，横着滑的地方停得准。

## 三、世界之书：做成一本精装书

1. **形制**：一本摊开的精装书，电脑上左右两页对开，手机上一次一页。五卷各一种装帧：
   - 通用卷：深褐皮面，烫金。
   - 月银纪卷：银蓝布面，银线，扉页是壁画的石纹。
   - 纷争纪卷：黑红军册皮，铆钉，红缎带。
   - 山铜纪卷：黑曜石和白石拼成的封面，半黑半白。
   - 迷宫纪卷：深蓝布面，金线，公会的蜡印。
   页边是那一纪的花边，照四方画的花边收小。
2. **换卷、换页**：书侧伸出五条缎带书签，一卷一种颜色，上面是那一纪的徽记，点一条就翻到那一卷。每卷头一页是目录，一章配一幅小图。翻页是一张纸翻过去（照牌桌翻牌那一套），减少动画时直接换。
3. **每一章的样子**：
   - 章首一条横幅图，取那一纪的主画、时代原画或四方画里的一截。
   - 章名，底下一句题记（取歌里或题诗里的话）。
   - 首字下沉。电脑上正文排成左右两页各一栏。
   - 页边批注：纪年、数字、一句原话，小字放在页边。
   - 段落之间用那一纪的花饰隔开。
   - 正文里的人名、地名、条目名点得开，弹出小卡（用已有的专名小卡），人物点了跳图鉴或档案。
4. **单独做的几页**：
   - 编年：做成一条长卷时间轴，电脑上横排、手机上竖排，用那一纪的颜色。一件大事一颗钉，点一颗看一句，旁边一枚“去那一段”的钮，跳到时代页。
   - 神与坛（月银纪、纷争纪）：神排成坛阵（七支柱一排，七十二座分两列），配神明显像的小图。点开是神号、尊号、管什么、倒下在哪一年（剧透开关管）。
   - 兽与曜（月银纪）、各纪的魔物：图版式，一兽一版，配史诗战的阶段图和样子。
   - 山河与地图：照旧，只换上书页的边框。
5. **字还是现在世界之书里的字**，这一轮只动样子，不动内容。哪一页字太少、撑不满两页的，拿图补。

## 四、图鉴（新做）

1. **放在哪**：每本书右上角、世界之书旁边，添一个“图鉴”入口，一纪一本。入口上写“图鉴”，打开以后书名用那一纪自己的叫法（★）：
   - 月银纪《传唱录》：诗人唱过的人和兽。
   - 纷争纪《墙上的名字》：战报、伤亡册、圣牌上的人和魔神。
   - 山铜纪《拓本》：碑匠拓下来的，碑上和碑背的人。
   - 迷宫纪《公会名录》：挂号册、首杀板和楼层主。
2. **年代轴**：顶上一条，照这一纪的时代排：月银纪 27 个（分三部），纷争纪 21 张牌，山铜纪 6 个年月，前传 6 个年月。挑一个年代，下面只列那时候在世的，另有一个“全纪”。
3. **分类页签**：
   - 人物：旅伴、相遇、在世的传奇。传奇标出档位（撼世、天灾、圣座、凡极），凝名在这一段的、殁于这一段的各打一个小签（殁的那个归剧透开关管）。
   - 强敌：史诗战的对手（一阶一张图，几阶并成一张卡，点开逐阶看），首领和楼层主，魔神（纷争纪），灾祸之兽（月银纪）。
   - 神：七支柱，和那一纪在世的神（月银纪、纷争纪多，山铜纪、前传少）。
   - 生物：那一纪的魔物与首领、敌人的种类、兽与坐骑（条目里都有，多半还没有图，见第六节）。
4. **卡片**：竖版，上面一幅图（艺术照的半身、史诗战的图、神明显像），底下是名字、一行身份和档位小签。卡框一纪一种：月银纪银，纷争纪铁红，山铜纪黑白，迷宫纪金。
5. **点开以后**：人物跳已有的档案页（四套立绘、表情、来路）。强敌、神、生物用一张同样黑底的图鉴页：大图、各阶段、样子、出没的年代、在哪一条主线里碰得上，再带一个“去那一段”的钮。
6. **数据**：写一支脚本，从四本书的 data、史诗战阶段表、神谱、魔物与首领、敌人的种类里抽一份 atlas.json，一本书一份，推图床。人物在不在世，照各时代页上的名单（旅伴、相遇、传奇表）；强敌照它出场的年份和主线。
7. **剧透**：照已有的剧透开关，默认关着。关着的时候不露殁年、死因和藏着的身份（比如藏着的真龙）。

## 五、建档：拆成两幕（第一版，作废，以第九节为准）

1. **想法（★）**：降临本来就分两段。先在死之神殿，若娜瓦替你认下这一副身子；她请你离开以后，你落进那一年，头一个碰见你的人问你是谁。卡里一纪一种册子，问话的人已经写好了（build.json 的 sheet）：
   - 月银纪：火边守火的人，问“旅人，你自哪一堆火而来。”
   - 纷争纪：联军的书记，军册三栏。
   - 山铜纪：段城的书记，兵册。
   - 迷宫纪前传：公会的书记，挂号册，问谁担保。

   所以建档拆成两幕。
2. **第一幕：死之神殿**。黑底牌桌，若娜瓦的手一张一张发牌，你一张一张翻。
   1. 怎么来的：两张牌，落进来的人、生在这一纪的黄金裔。
   2. 血：十二张种族牌摊成扇形，牌面是主角预设的立绘。这时候世上还没有的那几族，牌背朝上、灰着。翻开一张，旁边展开这一族的支系，和这一族在这一纪里的样子。
   3. 身子：名字、性别、年岁、模样，写在一张薄纸上。她一栏说一句，用 build.json 里 ronova 那几句。
   4. 面容（可以跳过）：照族属、性别、体格挑一张主角预设的立绘，或者贴自己的图。

   然后请离：她的脸露一眼，说“去吧”，牌桌暗下去，你落进那一年。这一纪的牌从桌上立起来翻开，时代原画铺满整屏。
3. **第二幕：落地**。底下是你要去的那一段的时代原画，前面是那一纪的册子（火边的木牌、军册、兵册、挂号册），问话的人一句一句问。
   5. 册子上的几栏：照 sheet 的 cols（姓或家、族、从哪里来、谁担保），报不出的那一栏照 blank 那句话写。
   6. 本事：挑两样，用这一段的本事牌。
   7. 誓心：九格的星盘，可以不选。
   8. 初心，加上还想让她知道的。

   最后那一纪的册子写满你这一页，盖上那一纪的印：月银纪一道炭痕，纷争纪军册的红印，山铜纪碑匠的凿印，前传公会的蜡印。底下是“填进输入框、复制、回去改、回到牌桌”四个钮。
4. **进度**：屏幕底边一排扣着的小牌，一共八张，做完一步翻过来一张，点翻过来的那张可以回去改。手机上缩成顶上一条。
5. **自己报年份**（第二十二张、无字碑、空白委托）：落点那一步换成一条年代轴（跟图鉴用同一条），拖到哪一年，顶上的时代名和底下的时代原画就跟着换。
6. **黄金裔**：第一幕“血”那一步，牌面添一道金线。第二幕问话的人看得出你是这里生的，册子上那一栏照黄金裔的写法写。
7. **1001 年那一条**：眼下照旧走原来那一整页（建档器、前半生、赐物、六维都在里头），新建档先做四纪。1001 年要并进来，第一幕得添“魂”的三种（本地、转生、降临）和神殿赐物，第二幕的册子换成公会的面板觉醒，单列一步做。
8. **凭证一个字不改**，改的只是怎么填、怎么展示。卡不用动。

## 九、建档第二版：照 1001 的步子

### 1. 1001 底卡的建档现在怎么走

原来那一整页介绍页（old1001.html）里的建档器：目录，第一问“你是谁”（本地、胎穿、身穿），睁眼之前（若娜瓦那一段），第二问（手记、构筑）。手记是挑一张现成的出身卡（四十六张）。构筑一步一步来：胎骨与起点（十九档），六维，命路（二十三条），命星（抽，Passive 和 Special 一个池子一百零四颗，Art 和 Active 一个池子六十九颗，Unique 2%、Legend 8%、Epic 25%，五抽以内保一颗 Legend、十二抽以内保一颗 Unique），誓心与出身（身穿的拿若娜瓦的赐物），初心、落在哪、旅印。最后铸印，凭证八节。

### 2. 四纪照这个走

| 步 | 四纪怎么做 |
|---|---|
| 一、魂 | 本地、胎穿、身穿三种，四纪都开。本地是这一纪生下来的人，胎穿是带着前一世的记性生下来的，身穿是原样落进来的降临者 |
| 二、睁眼之前 | 若娜瓦那一段，最后一句换成你要落进哪一年 |
| 三、手记或构筑 | 四纪先只做构筑，手记要一纪一套出身卡，往后再说 |
| 四、胎骨与起点 | 照 1001，档位照这一纪量人的说法改叫（月银纪看斩过什么，纷争纪看守过哪一段，山铜纪看做成过什么，前传 420 年以前看行会和公会的档次） |
| 五、金血（可选） | 只给本地和胎穿。见下面第 3 小节 |
| 六、六维 | 照 1001 |
| 七、命路，或者兵器与技艺 | 一纪一样，见第 4 小节 |
| 八、命星 | 照 1001 的抽法，池子照这一纪、这一段滤掉还没有的星，Art 照传承表这一段那一门起头的版本（★） |
| 九、誓心与出身 | 出身是那一纪的册子加这一段的本事。身穿的赐物从原主在开局以前已经死了的遗物里给（★） |
| 十、初心、落在哪、旅印 | 落在哪从这一纪的时代地图上挑。旅印换成这一纪的那一样：月银纪没有（诗人还没唱你），纷争纪军册三栏（233 年以后），山铜纪团名和档次（约 30 年以后有团，60 年以后有行会），前传旅印（3 年霜降月以后，420 年以前不分阶，7 年起按印要有人担保） |
| 十一、铸印 | 盖那一纪的印：月银纪一道炭痕，纷争纪军册的红印，山铜纪碑匠的凿印，前传公会的蜡印 |

进度照第一版第五节第 4 条，一步一张扣着的小牌，做完一步翻一张。自己报年份照第五节第 5 条，落在哪那一步换成年代轴。

### 3. 金血祝颂

- 第五步“金血”，生在这一纪的人才有，可以跳过。先挑神亲，再看祂落在你血里的那一颗祝福。
- 一位正神一颗，都是 Legend 的 Passive，写的是这一位管的东西落在你身子上的样子，照写作口径 Passive 那几条起名、写效果。七十二位正神七十二颗，七位到了山铜纪是七神，那一版另写七颗，一共七十九颗。页上已经有的照收（狄昂的金雨之血就是伊斯卡图那一颗）。
- 神亲照这一纪：
  - 月银纪：你出生那一年已经聚成的神，照神谱的聚成年份。
  - 纷争纪：你出生那一年还在世的正神，照死期总表，倒下了的灰着、标哪一年倒下。止戈以后只剩七位。
  - 山铜纪：七神里的一位（build.json 里本来就是这样写的）。
  - 前传：七神本人迷宫纪不现身（#94），生不出孩子。倾向写成隔代醒：祖上是山铜纪七神的孩子，血隔了几代在你身上醒过来（★）。
  - 魔神生不出黄金裔，名单里没有魔神。凡人那一头是魔族的照旧算（提诺那样）。
