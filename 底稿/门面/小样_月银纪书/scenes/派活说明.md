# 月银纪的书·节点原画、死期死因、死的那一刻｜派活说明

2026-11-12。给写场面的人看的。你写的东西不直接出图，是交一份 JSON，主会话审过以后照它出图。

## 一、这是什么

《奥尔德兰的旅印》是一张西幻 JRPG 的角色卡，月银纪是它两万年历史的头一纪。门面里有一本“月银纪的书”，二十七个时代一个时代一页，玩家点进一个时代，看得到这一段的主线各幕、人物档案和原画。这一轮要给每条主线的每一幕配一幅“节点原画”（过场动画里定住的一帧，崩铁光锥那一路的画法），给会死在这一段里的人写死期和死因，给死在这一段里的旅伴各画一幅“死的那一刻”。

第七歌已经做完，是样子，见 `示例_m07.json`。画风用户认过了，不用你管，你管的是画什么、谁在哪、镜头在哪。

## 二、先读什么

1. 你那几个时代的任务单 `任务单/mNN.md`：源稿在哪、主线和各幕、这一段的人和立绘键、兽的参考图、你要用的键。
2. 源稿里那几条主线（“## 月银纪·主线｜……”那一节，一幕一拍一条，末一条是幕终）。每一拍都要读，画的是里面的事。
3. 源稿里旅伴和人物的条目，要用到的读：外貌、装束、正史里的下场。兽读“灾祸之兽”那一条。
4. `示例_m07.json`，照它的写法和详略。
5. 人的英文长相资料在任务单里（从立绘资料抄的 who 和 palette），要更细的看 `底稿/状态栏/comfy/cast/` 里对应的 json（casual、private、battle、formal 四套衣服各一段）。
6. 兽的英文设计在 `底稿/状态栏/comfy/epic/prompts/moon.json`（一个对手一条，design 那一段），任务单里列了这一段牵到哪几条。

源稿很长，照任务单给的行号跳着读，别从头读到尾。

## 三、交什么

一个时代一个文件 `scenes/mNN.json`（UTF-8，不带 BOM），样子：

```json
{
  "era": "m05",
  "nodes": [
    {
      "key": "m05_n1",
      "line": "万兽·冰矛抵眉",
      "act": "一幕",
      "name": "两到四个汉字",
      "style": ["fire", "anaxa"],
      "who": [["ge5_xien", "casual", "the white-haired apprentice"]],
      "beast": "moon_004_1",
      "light": "一句英文：主光什么颜色、从哪边来，对着什么颜色的暗部",
      "camera": "一句英文：机位和一点倾斜",
      "text": "Scene: ……（英文，两百到三百五十个词，照示例的详略）",
      "raw": false,
      "note": "中文：选的是哪一拍，源稿第几行，拿不准的地方"
    }
  ],
  "fates": {
    "人名": {"when": "月银纪1350年坠叶月", "where": "黑丘的火口", "how": "两三句。"}
  },
  "deaths": [
    {"key": "m05_d_xxx", "death": "人名", "name": "两到四个汉字", "age": 33, "minor": false, "style": ["anaxa", "fire"], "who": [["ge5_xxx", "battle", "…"]], "light": "…", "camera": "…", "text": "Scene: …", "raw": true, "note": "…"}
  ],
  "notes": ["拿不准、要主会话定的事，一条一句"]
}
```

- `nodes`：每条主线的一幕、二幕、三幕、收束各一幅（幕间不配）。键照任务单给的。`line` 写主线的名字，跟任务单一字不差，`act` 写 一幕、二幕、三幕、收束。
- `who` 和 `row` 二选一，都可以不写。`beast` 可以不写。`raw` 不写就是 false。
- 没有的栏不要写空串，整栏不写。

## 四、节点原画怎么挑、怎么写

### 挑哪一拍

- 一幕一幅，挑这一幕里最要紧、最有画面的那一拍，多半是幕终，或者这一幕的标题说的那件事。
- 四幅连起来要看得出这一段是怎么走的，别四幅都是人对着兽站着。有静的（一个人、一样东西、一句话落下以后），有动的（那一下正在发生）。
- 画的是事情正在发生的那一瞬，不画事后的合影，不画象征图。
- 收束那一幅画这一段落定以后留下的东西和活下来的人，多半是静的。

### text 怎么写（英文）

照示例的写法，顺序是：

1. `Scene:` 起头，一句交代时间、地方、天气。
2. 画面里最大的东西是什么、在哪一边、占多大（大的东西只露一部分，叫画框切掉，比整个画进去更有压迫感）。
3. 人在哪（left / right / near foreground / far behind）、朝哪边（toward us / away from us / seen from behind at three-quarter）、在做什么、手里拿什么、脸上什么神情。朝向和方位要写死，谁朝门走、门在哪一头，不写死它会画反。
4. 远处有什么小的东西（城、桥、逃的人、一排兵）。
5. 末一句写前景四角虚化的东西（飘的雪、火星、麦穗、盐粒、羽毛）。

要守的：

- 一幅只画一个瞬间，一个机位。不写“然后”“随后”。
- 数目和颜色照源稿写死（十二面盾、三十来个人、黑的兽、七个洞）。源稿写了的不改，源稿没写的可以补，补的东西要合这个地方和这个年代。
- 人用叫法，不用名字。`who` 里第三项是这个人在提示词里的叫法（英文，身份加一样认得出的东西，比如 `the reaper who came back`、`the boy who guards the gate`），text 里用同一个叫法，或者一眼认得出是他的说法（the reaper、the gate-boy）。头一回提到他的时候带一句认得出的长相（发色、眼睛、衣着、手里的东西），照任务单里的英文资料写。
- 没有立绘键的人在 text 里把样子写清楚（照源稿的外貌），年纪、发色、穿什么。
- 不写内心，不写比喻成串，不写“象征着”。只写看得见的。
- 魔法写成看得见的结果（火绕着他分开，雪在她脚印里化了），不写原理。
- 别出现会被照字面画出来的词，比如 white heart 会画成一颗心；写 ribbon 它会真画飘带。
- 衣着写严实。不写撕破的短裙、睡袍、湿衣贴身这一类（torn hem、nightgown、clinging wet），祭袍、囚衣、淋雨的衣裳都写成从颈到踝盖住身子的长衣。

### who、row、beast 和参考图的数

出图时参考图最多五张：两张画风，剩下三张给人和兽。

- `who`：有立绘键的人，一人一项 `[键, 哪一套衣服, 叫法]`，衣服是 `casual`（常服）、`private`（私服）、`battle`（战斗）、`formal`（正装）里的一个，照场面挑。有 `beast` 的时候 who 至多两个人，没有 `beast` 至多三个。
- 人多的场面用 `row`：`[[键, 衣服, 叫法], …]` 至多八个，拼成一排当一张参考，适合远远的一群人、多半是背影。用了 row 就不写 who。
- 画面里还有别的有立绘的人、可只是远处的小人的，不进 who，在 text 里用一句话写样子就行。
- `beast`：这一幅里有兽、任务单里又给了这头兽的参考图的，填参考图的名字（`moon_NNN_k`，k 是第几阶，照这一幕它是什么样子挑）。它只管兽的样子，画法还是照光锥。text 里照样要把兽写清楚。

### light、camera、style

- `light` 一句英文，比如 `the cold blue of an early-winter dusk outside, warm firelight from above the gate spilling onto the threshold`。
- `camera` 一句英文，要大胆，像动画的分镜：低机位仰拍、越肩、从门洞里往外、从高处俯看、贴着地面。带一点倾斜。
- `style` 两个名字，头一个是主的，照这一幅的光和调子挑：

| 这一幅是 | style |
|---|---|
| 夜里、火光、暗处的对峙、祭火边 | `["anaxa", "fire"]` |
| 冷的夜、星光、雪、冰、湖、辉塔的冷光 | `["fire", "anaxa"]` |
| 白天、麦田、原野、暖的日光 | `["wheat", "aglaea_card"]` |
| 明亮的白和金、神坛、王庭、日出 | `["aglaea_card", "wheat"]` |
| 正在打的那一下、带速度线的动作 | `["himeko_card", "anaxa"]` 或 `["himeko_card", "fire"]` |
| 夜里的城、灯、宴席、节庆 | `["sparkle", "fire"]` |
| 安静的屋里、两个人说话、一样东西的近景 | `["jingyuan", "wheat"]` |

一个时代的四幅别全用同一组。

### raw（血和伤）

用户定的：打过的仗画出打过的样子。场面里成年人身上有血、伤、烧伤、破衣裳的，在 text 里写出来，`raw` 写 true，照写的画。不写断肢、露骨、内脏。没打过的场面不硬添。

### 未满十八岁的人

任务单里标了每个人在这一段的年纪。未满十八岁的照常入画，穿戴整齐，可以在场、可以拿兵器，可是不画他身上的伤口和血，不画他挨打、受折磨、被杀的那一下。这一幅里只要有未满十八岁的人受了伤，就换一个瞬间画（那一下以前，或者他已经站起来以后）。

### 这个世界的规矩

- 西幻，中世纪欧洲打底，剑与魔法，JRPG。不写东亚的衣裳、屋檐、纹样，不写现代的东西。月银纪没有火药，没有玻璃大窗，萨尔维斯（m22 以后）有辉塔（术的光，冷白）、浮在天上的上城、骸银。
- 不画月亮和月牙，text 里别出现 moon、crescent。弯的角、牙、弧光也别写得像一弯月。
- 画里不写字。旗、碑、纸上的字写成 marks 或者不写。
- 走在凡人中间的神（源稿里“是谁不点破”的那几位，戴草帽的妇人、打钉子的老矮人这一类）可以入画，照源稿里凡人的样子画，不画神光，不写 god、divine。源稿里明着以神的身份露面的（坛前落座、客星城的宴席），照源稿写的样子画，写清个头、衣着和祂手里的东西，不画头顶的光环，不画成宗教画。神的立绘这一轮不用，都用字写。
- 四位执政、那一位恶神不入画。深渊写成看得见的东西（黑的火、往外渗的黑），不画成一个人形。
- 兽的样子照源稿的灾祸之兽条和 epic/prompts/moon.json 的 design，龙是西式的重龙，蝙蝠一样的翼，没有鹿角和须。

### name（中文，玩家看得见）

两到四个汉字，取这一拍里的一样东西、一个地方加一个时刻，或者那一句话：空鞍、那一声、白线之晨、火冠、雪仓、最后一环、鸦落、断刃。

- 不用口语半句，不直接拿一句台词当名字（趴下、别回头、回去吧这一类，写成一声趴下、头顶一箭那样的名词），不用“之战、对决、决战、觉醒、羁绊、命运、绝望、希望”这类大词，不带月相字。
- 一个时代里的几个名字别一个构词法，别跟这一段主线各幕的标题重样。
- 先用源稿里现成的叫法（歌里、诗里的小标题常常就是）。

## 五、死期死因（fates）

- 谁要写：这个时代的旅伴和相遇的人里，死在这一段剧情里的。说的是主线各幕到收束里讲到的死（连同收束紧跟着的那几个月），和主线的默认收束、这一歌里明着讲到的横死（哪怕隔了几年，比如第四歌阿尔凯的火葬堆）。在这一段剧情里下落成谜的也写，加一栏 `"label": "下落两说"` 或 `"下落不明"`。
- 不写的：活过这一段、几十年以后老死病死的（一个时代的年份跨几百年，不能照“死在这一页的年份以内”算），往后才离开、才不见的。这些人的下场页上的档案里本来就有全文。11-12 头一轮有几份把老死的也写了，主会话审稿时挪进了各份的 `later_fates`、`later_deaths`。
- `when` 写年份和月份，照源稿。`where` 一个短地名。`how` 两三句，只搬源稿里的事，口气照源稿平实的叙述。
- 不写给模型看的话（玩家、AI、裁定、照某条），不加评语。是谁不点破的人不揭他的底。未满十八岁的只写结果和后来，不写伤口和血。
- 标点：不用破折号、分号、省略号、感叹号。引语用中文弯引号。

## 六、死的那一刻（deaths）

- 只给旅伴（任务单“旅伴”那一栏的人）里死在这一段剧情里的（口径同上一节）。一人一幅，键 `mNN_d_<立绘键下划线后面那一截>`，`death` 写中文名，`age` 写他死的时候几岁（照源稿算），别的栏跟节点原画一样。
- 画他最后站着的那一下，或者那一下刚过去的一瞬，照源稿的下场。是这个人一生的定格，不是尸体，不画躺着的死人。
- 成年人可以 `raw: true`，血、伤、烧伤照写的画。
- 死的时候未满十八岁的：`"minor": true`，`raw` 不写。不画他受伤、被杀、倒下。改画他做那件事以前最后一个完好的瞬间，或者一幅空镜，只有他留下的那一样东西和那个地方，画面里没有他的身体。
- 死的时候十四岁以下的不出图，在 `notes` 里写一句。
- 在这一段剧情里病死、老死的旅伴也算（比如魔族之世的尤里安），画他最后做的那一件事。往后几十年才老死的不画。
- 他最后被人看见的那一拍要是已经是某一幅节点原画，不另出，写 `{"key": "mNN_d_xxx", "death": "人名", "name": "…", "same": "那一幅节点的键", "age": 21}`。
