# 派活说明：纷争纪、山铜纪、迷宫纪三本书的卡片和世界之书（11-15）

用户 11-15 看了月银纪那一本（世界之书、时代地图、卡片、剧透开关）回：“世界之书那块我感觉OK，可以先完成剩下纪元，和其他纪元把完整的前端拼起来，然后做进卡吧”。这一份是给起稿的子任务看的。方向在根目录 介绍页收尾_方向稿.md（第二节、第四之二节），月银纪那一本是样子。

你只写派给你的那几个文件，别的文件一个字不动（各页源稿、底卡、补卷、书的数据、页面都不动），不提交 git。仓库根是 E:\aldran_art，命令都在仓库根上跑，Python 用 `python -I -X utf8`。

## 甲、卡片

先把 `底稿/门面/卡片/写法.md` 从头读完，照它写。它是照月银纪写的，换成你那一本：

| 纪 | 书的数据（名字照它一字不差） | 档案 | 源稿（拿不准翻这里） |
|---|---|---|---|
| 纷争纪 | `底稿/门面/小样_纷争纪书/data/strife.json` 的 `eras[]`，时代 id 是 s01 到 s21 | `小样_纷争纪书/data/prof/sNN.json` | 纷争纪/纷争纪时段_*.md 七页（一页管三四张牌），纷争纪/纷争纪_旅伴与传奇总表.md，纷争纪/天黑以后_二十二张_第七版.md |
| 山铜纪 | `底稿/门面/小样_山铜纪书/data/bronze.json`，时代 id 是 p1 到 p6（一页一个时代） | `小样_山铜纪书/data/prof/pN.json` | 山铜纪/山铜纪时段_*.md 六页，山铜纪/山铜纪_碑_第一版.md |
| 迷宫纪 | `底稿/门面/小样_迷宫纪书/data/maze.json`，时代 id 是 q1 到 q6（前传一页一个时代） | `小样_迷宫纪书/data/prof/qN.json` | 迷宫纪前传/迷宫纪前传时段_*.md 六页，迷宫纪前传/迷宫纪前传_委托_第一版.md |

- 文件写到 `底稿/门面/卡片/<纪>/<时代 id>.json`，样子照写法.md 第一节（`lines` 一条主线一项，`people` 一个旅伴或相遇一项）。这个时代的 `lines[].name`、`cast[].name`、`meet[].name` 每一个都要有；传奇（`legends`）不写，传奇档案照旧。
- 样卡是写法.md 里的麦伦，和 `底稿/门面/卡片/月银纪/m07.json` 整份（月银纪第七歌，审过的）。动笔前读一遍 m07.json，再读两三份月银纪诸国期、萨尔维斯的（m16、m22）看相遇卡怎么收。
- 山铜纪、迷宫纪一页里主线多（十几条）、人多（三四十个旅伴），写之前把这一页的主线挨个读一遍，一个人照他自己那一段的开局写，别拿别段的事。
- 一张卡只写到这个时代页开局那一刻为止的事。往后的事、死、谁其实是谁，一个字都不写。
- 相遇里有一群人、一家、一伙的（“阶上十四家”“宴主十二家”“锁在一条链子上的三千个人”“烧麦那一夜的那几位”），也照相遇卡写：`head` 一项写他们是哪里的、什么人，`bg` 一两句写这一群人在这一段里是什么样子，`line` 有一句他们当中谁说过的话就放，没有就不写。
- 同一个人在几个时代里都有（巴尔缇娜·格雷恩、哈诺、不说名字的女人这一类），每个时代各写一张，照那个时代的年纪和处境写，别把后一个时代的事写进前一张。

主会话收稿时照这几样逐张审，你写的时候先自己过一遍：
1. 露底的钩子和星。钩子从 hooks 里挑不露底的那一句，两句都露底就写空串；星的名字或效果露了往后才揭开的事（他认得谁、他是谁、他会怎样），那一颗不列。
2. 口头禅撞人。“我记一下”只属于巴尔缇娜，别人的台词里不用；台词照这个人自己的声口挑。
3. 一个字、两个字的台词不挑（“嗯。”“你。”这种），挑一句有东西的。
4. 藏着的身份别从卡上露出来。走在凡人中间的神、乔装的人、改了名字的人，卡上只写时代页上看得见的那一层。源稿里写着只给 AI、NPC 不知道、不点破、叙述里不写、深层、真容的，一律不搬。各本要当心的（举例，不止这些）：
   - 纷争纪：诺伦表层一律写他（男性），真容、面甲底下的事不写；茵妮原来是谁，凯恩门口那个女人，法隆是谁动的手，不写；两军之间那个不说名字的女人（止戈）不点名；魔族的传奇之名这一纪当时叫得出，照时代页写。
   - 山铜纪：巴尔缇娜乔装时的化名那一层（看书的数据里这个人用的是哪个名字，照那个名字写，不点破）；雨城那个不说名字的女人是谁不写；七魔神将小时候的名字照那一页（第三页涅芙拉叫黛洛），往后的传奇之名不当姓用；维拉瑟只给 AI 的那一层不写。
   - 迷宫纪：梦里跪在口子边上的老人是谁不写；黑潮里七王的脸是照谁捏的不写；只给 AI 的楼层主来历不写。
5. 岁数照档案（`age`）和源稿底座；长生的写“外表十七”这种。

写完跑：`python -I -X utf8 底稿/门面/卡片/check_cards.py <纪> <时代 id> …`，要“合计 0 处”，cardscan、authormark 也要 0。

## 乙、世界之书一卷

先读 `底稿/门面/卡片/世界之书.json` 整份（通用卷五页、月银纪卷八页，审过的），照月银纪卷的样子、口气和长短写你那一纪的一卷。

- 写到 `底稿/门面/卡片/世界之书_<纪>.json`，一个对象：`{"id": "strife", "title": "纷争纪", "sub": "一句副题", "pages": [...]}`，id 纷争纪写 strife、山铜纪写 bronze、迷宫纪写 maze。
- 八页上下。一页 `{"id", "title", "sub", "sections": [{"h": 小题, "t": 三四句}]}`，正文三百到五百字，一段一百四十字以内。口气照底卡介绍页（src/intro_v7.html 的几卷）：对着要出门的人说话，一个小题加三四句，平实，有一两处好看的细节。
- 必有的三页：`age`（这一纪：总述，几个时代怎么分，“你能做什么”，落进这一纪的人是什么身份）、`map`（山河与地图：这一纪的地是什么样，几个年代地图上变了什么，页面会在这一页的字上头放一张能点的地图）、`chron`（编年：`{"id": "chron", "title": "编年", "sub", "kind": "chron", "items": [{"y": "年份", "t": "一句", "spoil": false}]}`，二十到三十条，一条四十五字以内，后半段和会剧透主线怎么收、谁怎么死的那几条 `spoil` 写 true）。
- 别的几页照方向稿第二节第2条，各纪自己挑题（举例）：
  - 纷争纪：诸国与联军，魔族与魔神，神与圣座，命路长出来，过日子。
  - 山铜纪：东边的新朝与联邦，西边的九座与黑耀，七魔神将与遗迹，佣兵、碑与铳枪，过日子。
  - 迷宫纪（前传两万年到1001年今天）：两个王与诸国，公会、委托与旅印，井、迷宫与楼层主，黑潮，过日子。迷宫纪这一卷前半写前传（2到1000年），1001年今天的样子照底卡介绍页收一两页（src/intro_v7.html 里初到奥尔德兰、山河与远方、国家档案几卷），别跟通用卷重了。
- 字从各纪现成的条目里收，不新起设定：
  - 纷争纪：纷争纪/补卷/ 里第一项那几份（常驻与纪元钟、规则补丁、陨落账、命路与超凡、钱与物价、墙后的日子），补卷_01 到 _99（国史、势力、城邦、地点、风土、历与月份、节与纪念日、聚落与人口、地图的几层补卷_19、魔法、战役），各页时段总纲。
  - 山铜纪：山铜纪/补卷/第一项_常驻与纪元钟.md、第一项_规则.md，补卷_01 到 _60（国史、势力、城邦、城区、地点、风土、地图的几层补卷_14、战役、规则、魔法），各页时段总纲，碑第一版。
  - 迷宫纪：迷宫纪前传/补卷/第一项_常驻与纪元钟.md、第一项_规则.md、第一项_势力与地点.md，补卷_01 到 _81（地图的几层补卷_14），各页时段总纲，委托第一版；1001年照 src/intro_v7.html。
- 只给 AI 的、锁、★、裁定、底卡条目号、“照某某那一条”一律不搬。通用卷的四纪编年、神与魔神写的是 1001 年那一局人人知道的那一层，你这一卷可以写得比它细，可神和魔神的真相层、四执政、那一位恶神不碰。
- 写完跑：`python -I -X utf8 底稿/门面/卡片/check_wb.py 底稿/门面/卡片/世界之书_<纪>.json`，要“合计 0 处”。

## 丙、交什么

- 写好的文件，和一份备注 `底稿/门面/卡片/<纪>/备注_<你的份名>.md`（世界之书那一份写 `底稿/门面/卡片/世界之书_<纪>_备注.md`）：
  - 换掉的钩子、没列的星、藏着的身份怎么处理的，一条一行。
  - 拿不准的地方（事实对不上、源稿两处说法不一、名字写法不一样）。
  - check 脚本最后一次的输出。
- 最后回一段话给主会话：写了几个文件、几张卡（或几页）、check 的结果、备注里要主会话看的几条。

## 规矩（照仓库根 CLAUDE.md「写作口径」）

- 不用 —— ； … ！ 这四种标点，卡片正文里不写冒号（json 的键不算），引号用“”。
- 不写月相字（月亮、月光、新月、满月、残月、月牙、弦月）。不用一丝、一抹、不禁、威压、修为、登记、晋升这一类禁词。
- 神用祂。不点那一位恶神的名字。四执政不入场。
- 西幻语域，不用中式口语和古文（爹娘、客栈、掌柜、时辰这一类，换词表在 旧字换词表_10-20.md）。
- 稀有度只有 Normal、Rare、Epic、Legend、Unique 五档。
