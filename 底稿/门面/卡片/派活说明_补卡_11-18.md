# 派活说明：门面补卡片（11-18）

11-17 夜到 11-18 四纪的旅伴照旅伴表重分过一遍，书里的名单跟着变了。有些人从“相遇”改成了“旅伴”，短的相遇卡要换成完整的旅伴卡；迷宫纪那一本多了六位从前面的年月一直活下来的旧人，各时代要各添一张相遇卡。这一份是给起稿的人看的。

## 你只写一个文件

主会话在派活的话里给你一个输出文件的路径和一张名单。你只写那一个文件，别的文件一个字不动（卡片文件、各页源稿、书的数据都不动），不提交 git，不另派子任务。仓库根是 E:\aldran_art，命令都在仓库根上跑，Python 用 `python -I -X utf8`。

输出文件是一份 JSON，一个时代一项，一个人一张卡片，名字照名单一字不差：

```json
{
  "m18": {
    "托德": {"kind": "cast", "head": ["…", "…", "…"], "tags": ["…"], "traits": ["…"], "bg": "…", "stars": [{"name": "…", "kind": "Special", "tier": "Legend", "text": "…"}], "meet": "…", "hook": "…", "line": "“…”"}
  }
}
```

  `python -I -X utf8 -c "import json,sys;sys.stdout.reconfigure(encoding='utf-8');print(json.dumps(json.load(open(sys.argv[1],encoding='utf-8'))[sys.argv[2]],ensure_ascii=False,indent=1))" <档案路径> <名字>`
- 现在的卡片文件里同名那一张是早先写的相遇卡（只有 head、bg、line），可以接着用它的字，照旅伴卡的栏目扩开。
- 这个时代页的开局年份和各条主线在书的数据里（`小样_<纪>书/data/<moon|strife|maze>.json` 的 `eras[]`，同一个 `id`），旅伴条里 `seg` 是他那一条主线。

## 旅伴卡（kind 写 "cast"）

照写法.md 第二节，另外几条：

- `head` 三项：出身，岁数，身份。岁数照档案 `age`（数字就写“41 岁”，档案写“外表…”的照写）。
- `tags` 三四项，最后一项是位阶，照档案 `rank` 去掉括号写成“共鸣 LVL 22”这种。
- `stars` 一到三颗：`name`、`kind`、`tier` 照档案 `stars` 一字不差地抄。这是 11-18 换过的新名字和新档，别用源稿别处、旧卡片里看到的旧名。`text` 自己收成一句，四十个汉字以内，不带冒号。名字或效果会露底的那一颗不列。
- `line` 从档案 `lines` 里挑一句不露底、最像他的，原样抄，连引号。一两个字的不挑。
- `bg` 一百二十个汉字以内，`meet` 七十以内，`hook` 八十以内，整张卡合起来两百到四百六十个汉字。
- 只写到这个时代页开局那一刻为止的事。档案里的 `fate`、下场、凝名、传奇之名、“往后”“后来”怎样，一个字都不写。`past` 只用开局以前的那一截。
- 同一个人在两个时代都有的，各写一张，照各自时代的档案（岁数、位阶、处境不一样），别把后一个时代的事写进前一张。

## 相遇卡（kind 写 "meet"）

- `head` 一到两项（出身或落脚的地方，他是什么），`bg` 一两句、八十个汉字以内，有一句现成的原话才写 `line`，没有就不写这一栏。整张卡一百五十个汉字以内。

## 规矩

- 字从档案和源稿里来，不新起设定，不改事实。
- 不用 —— ； … ！ 这四种标点，卡片正文里不写冒号，引号用“”。不写月相字（月亮、月光、新月、满月、残月、月牙、弦月）。不用一丝、一抹、不禁、威压、修为、登记、晋升这一类禁词。神用祂。
- 西幻语域，不用中式口语和古文（爹娘、客栈、掌柜、时辰这一类）。
- 口气照底卡介绍页，对着要出门的人说话，平实，有一两处好看的细节就够。先写这个人是什么、做得到什么，别往小里写，也别堆形容词。
- 藏着的身份、只给 AI 的、往后才揭开的事不从卡上露出来。

## 自查

写完在仓库根上跑（Bash 的写法，把路径换成你的）：

`CARDS_OVER=<你的输出文件> python -I -X utf8 底稿/门面/卡片/check_cards.py <纪> <时代 id> …`

名单里的人不许再有一行问题（别人的问题不归你管，照原样报给主会话）。cardscan、authormark 两行要“合计 0”。
