# 门面卡片的写法（11-15，介绍页收尾）

用户 11-15 定的：介绍页里包括人物在内的字太多了，照底卡介绍页那种写法简单介绍一下就行，其余细节留给玩家在实际游玩里发现。方向在根目录 介绍页收尾_方向稿.md。这一份是给写卡片的人看的。

卡片只给门面（介绍页）用，各页源稿、底卡、补卷一个字不动。时代页和档案页原来那些长字（来路、平日、下场全文、死期死因、没有你的那一版）照旧留在数据里，页面上收进剧透开关，卡片里不写。

## 一、一纪一份，一个时代一个文件

`底稿/门面/卡片/<纪>/<时代 id>.json`，比如 `底稿/门面/卡片/月银纪/m07.json`。样子：

```json
{
  "lines": {
    "万兽·焚原": {"hook": "“叫我王。”", "open": "1690年坠叶月，双虹城。南桥门楼边的木板上钉着悬赏，河滩上从穗塔城逃过来的人一堆火挨着一堆火。"}
  },
  "people": {
    "麦伦": {
      "kind": "cast",
      "head": ["千穗原", "24 岁", "种麦的"],
      "tags": ["深麦色头发", "青麦绿眼", "183cm", "启源 LVL 12"],
      "traits": ["话少", "只记数", "怕高", "只向麦子弯腰"],
      "bg": "千穗原穗塔城外种麦的人，从南边火山带的村子下来，一块地，一间屋，一把镰刀。1690年那条红龙落在穗塔城的城墙上，那一夜他在城外的麦垄里割麦，回来只剩一座城门。往后每一回联军出城，他都扛着镰刀跟在最后头，谁也没叫他。",
      "stars": [
        {"name": "不折之腰", "kind": "Special", "tier": "Legend", "text": "认下一茬要收的活，那一天里火、高和疼都拦不住他往那边走。"},
        {"name": "刈穗", "kind": "Art", "tier": "Rare", "text": "千穗原收麦人一镰一垄的那一门，割一整天不歇，后来他拿它砍龙。"}
      ],
      "meet": "双虹城北门底下，一个人拿镰刀尖在半截仓签上刻道，刻完一道，停一停，再刻下一道。你问他刻的是什么，他说，没回来的。",
      "hook": "他不跟人亲近，也不推开人。哪一天你跟着联军出了城，又跟着他走了回来，他在仓签上没有刻你，那就是他认下你了。",
      "line": "“这一茬得有人去收，这一茬我去收。”"
    },
    "某个相遇的人": {
      "kind": "meet",
      "head": ["双虹城", "守南桥的老兵"],
      "bg": "一两句，他是谁、在这一段里做什么。",
      "line": "“一句他说过的话。”"
    }
  }
}
```

名字（lines 的键、people 的键）照 `底稿/门面/小样_月银纪书/data/moon.json` 里那一个时代的 `lines[].name`、`cast[].name`、`meet[].name` 一字不差。这个时代页上的每一条主线、每一个旅伴、每一个相遇都要有一张；传奇不用写（传奇档案本来就短）。

## 二、每一栏写什么

**主线（lines）**
- `hook`：从这条主线的 `hooks` 里挑一句不露底的原样抄过来（连引号）。两句都露底就写空串。露底是说出了往后才揭开的事（谁其实是谁、谁会死、谁认得谁）。
- `open`：睁眼的地方，照 `open` 收成一两句，六十字以内，写年月、地方和眼前看得见的一样东西。

**旅伴（kind 为 cast）**，合起来三四百字（汉字）：
- `head`：三项，出身（一处地方或一个势力），岁数（照档案写法，长生的写“外表十七”这种），身份（八个字以内，是“他是什么”，不写职务）。
- `tags`：外貌和位阶，三四项，每项八个字以内，发色、瞳色、身高、位阶（照档案的 rank 写，比如“启源 LVL 12”），有角、尖耳、兽耳、鳞这类记号的放一项。
- `traits`：性格，三四个词，每个六个字以内。
- `bg`：身份与背景，两三句，一百二十字以内。他是谁、从哪里来、这一段里在做什么。只写到时代页开局那一刻为止的事，往后的不写。
- `stars`：一到三颗，照档案的 stars 抄名字、kind、tier，`text` 收成一句，四十字以内。名字或者效果会露底的那一颗不列（比如麦伦的“眠山血脉”露了他认得那条龙）。
- `meet`：初见契机，一两句，七十字以内，照档案的“初见”收。
- `hook`：关系钩子，一两句，八十字以内，照“相处”收，写怎样跟他走近，或者他看重什么、不能碰什么。
- `line`：一句台词，从档案 `lines` 里挑一句不露底、最像他的，原样抄（连引号）。

**相遇（kind 为 meet）**，合起来一百五十字以内：
- `head`：一到两项，出身和身份。
- `bg`：一两句，八十字以内。
- `line`：一句台词，没有合适的就不写这一栏。

## 三、规矩

- 字从这个人的档案（`data/prof/<时代 id>.json` 里同名那一份）和这个时代页的源稿里来，不新起设定，不改事实。拿不准去翻源稿（月银纪史诗/第N歌、诸国期/、萨尔维斯/ 各页），文件路径在 `底稿/门面/小样_月银纪书/build_data.py` 开头。
- 不写档案里的 fate、death、past 的后半截、只给 AI 的东西（数据里本来就挡掉了，源稿里有的也别搬）。“没有你的那一版”、死期死因、谁其实是谁、往后会怎样，一个字都不写。
- 口气照底卡介绍页：对着要出门的人说话，平实，有一两处好看的细节就够，不堆形容词。
- 卡面口径照仓库根上 CLAUDE.md「写作口径」：不用 —— ； … ！ 这四种标点，冒号只用在这一份规定的栏名里（卡片正文里不写冒号），不写月相字（月亮、月光、新月、满月、残月、月牙、弦月），不用一丝、一抹、不禁、威压、修为、登记、晋升这一类禁词，神用祂，不点那一位恶神的名字。引号用“”。
- 写完在仓库根上跑：`python -I -X utf8 底稿/门面/卡片/check_cards.py 月银纪 <时代 id>…`，要 0 问题。
