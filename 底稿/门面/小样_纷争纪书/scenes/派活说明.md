# 纷争纪的书·节点原画、死期死因、死的那一刻｜派活说明

2026-11-12。给写场面的人看的。你写的东西不直接出图，是交一份 JSON，主会话审过以后照它出图。

## 一、这是什么

《奥尔德兰的旅印》是一张西幻 JRPG 的角色卡。纷争纪是它两万年历史的第二纪：月银纪末一夜魔神降临，往后一万一千零三十四年，东西两块大陆隔着一道白石长垒打仗，神和魔神一位换一尊地死，凡人一代接一代补上墙头，直到止戈。门面里有一本“纷争纪的书”：一条战场上的路，二十一张圣牌，一张牌一个时代。玩家点进一张牌，看得到这一段的主线各幕、人物档案和原画。

这一轮要给每条主线的每一幕配一幅“节点原画”（过场动画里定住的一帧，崩铁光锥那一路的画法），给会死在这一段剧情里的人写死期和死因，给死在这一段剧情里的旅伴各画一幅“死的那一刻”。

月银纪那一本已经这样做完了，第七歌是样子，见 `示例_m07.json`。画风用户认过了，不用你管，你管的是画什么、谁在哪、镜头在哪。

## 二、先读什么

1. 你那几张牌的任务单 `任务单/sNN.md`：源稿在哪、主线和各幕、这一段的人和立绘键、神和魔神的参考图、你要用的键。
2. 源稿里那几条主线（“## 纷争纪·主线｜……”那一节，一幕一拍一条，末一条是幕终）。每一拍都要读，画的是里面的事。
3. 源稿里旅伴和人物的条目，要用到的读：外貌、装束、正史里的下场。神和魔神读“（人物）”那几节和主线里写祂的那几拍。
4. `示例_m07.json`，照它的写法和详略。
5. 人的英文长相资料在任务单里（从立绘资料抄的 who 和 palette），要更细的看 `底稿/状态栏/comfy/cast/` 里对应的 json（casual、private、battle、formal 四套衣服各一段）。
6. 神和魔神的英文设计：显像在 `底稿/状态栏/comfy/epic/prompts/gods_zheng.json`、`gods_mo.json`（照 key 找），史诗战的对手在同一个目录的 `strife_god1.json`、`strife_god2.json`、`strife_other.json`（照 block 找，design 那一段）。任务单里列了这一段牵到哪几条。

源稿很长（一页管三四张牌），照任务单给的行号跳着读，别从头读到尾。

## 三、交什么

一张牌一个文件 `scenes/sNN.json`（UTF-8，不带 BOM），样子：

```json
{
  "era": "s13",
  "nodes": [
    {
      "key": "s13_a1",
      "line": "炮的年月·空鞍的白马",
      "act": "一幕",
      "name": "两到四个汉字",
      "style": ["fire", "anaxa"],
      "who": [["z4b_brunhild", "battle", "the dwarf gunner"]],
      "beast": "strife_god1_015_1",
      "light": "一句英文：主光什么颜色、从哪边来，对着什么颜色的暗部",
      "camera": "一句英文：机位和一点倾斜",
      "text": "Scene: ……（英文，两百到三百五十个词，照示例的详略）",
      "raw": false,
      "note": "中文：选的是哪一拍，源稿第几行，拿不准的地方"
    }
  ],
  "fates": {
    "人名": {"when": "纷争纪3046年坠叶月", "where": "南线的炮阵", "how": "两三句。"}
  },
  "deaths": [
    {"key": "s13_d_xxx", "death": "人名", "name": "两到四个汉字", "age": 72, "minor": false, "style": ["anaxa", "fire"], "who": [["z4b_xxx", "battle", "…"]], "light": "…", "camera": "…", "text": "Scene: …", "raw": true, "note": "…"}
  ],
  "notes": ["拿不准、要主会话定的事，一条一句"]
}
```

- `nodes`：每条主线的一幕、二幕、三幕、收束各一幅（幕间不配）。键照任务单给的。`line` 写主线的名字，跟任务单一字不差（带页名，比如 `炮的年月·空鞍的白马`），`act` 写 一幕、二幕、三幕、收束。
- `who` 和 `row` 二选一，都可以不写。`beast` 可以不写。`raw` 不写就是 false。
- 没有的栏不要写空串，整栏不写。

## 四、节点原画怎么挑、怎么写

### 挑哪一拍

- 一幕一幅，挑这一幕里最要紧、最有画面的那一拍，多半是幕终，或者这一幕的标题说的那件事。
- 四幅连起来要看得出这一段是怎么走的，别四幅都是人对着敌人站着。有静的（一个人、一样东西、一句话落下以后），有动的（那一下正在发生）。
- 画的是事情正在发生的那一瞬，不画事后的合影，不画象征图。
- 收束那一幅画这一段落定以后留下的东西和活下来的人，多半是静的。
- 这是一场横跨整块大陆、打了一万年的仗，尺度要画出来：墙从天边连到天边，魔潮漫到地平线，神和魔神比塔还高。可每一幅的落点是近处那一两个人。

### text 怎么写（英文）

照示例的写法，顺序是：

1. `Scene:` 起头，一句交代时间、地方、天气。
2. 画面里最大的东西是什么、在哪一边、占多大（大的东西只露一部分，叫画框切掉，比整个画进去更有压迫感）。
3. 人在哪（left / right / near foreground / far behind）、朝哪边（toward us / away from us / seen from behind at three-quarter）、在做什么、手里拿什么、脸上什么神情。朝向和方位要写死，谁朝门走、门在哪一头，不写死它会画反。
4. 远处有什么小的东西（墙、塔、逃的人、一排兵）。
5. 末一句写前景四角虚化的东西（飘的灰、火星、麦穗、雪、花瓣）。

要守的：

- 一幅只画一个瞬间，一个机位。不写“然后”“随后”。
- 数目和颜色照源稿写死（三千残兵、七扇门、十一个生角的人、三十八个斥候）。源稿写了的不改，源稿没写的可以补，补的东西要合这个地方和这个年代。
- 人用叫法，不用名字。`who` 里第三项是这个人在提示词里的叫法（英文，身份加一样认得出的东西，比如 `the helmed emperor`、`the one-armed dwarf mason`），text 里用同一个叫法。头一回提到他的时候带一句认得出的长相（发色、眼睛、衣着、手里的东西），照任务单里的英文资料写。
- 没有立绘键的人在 text 里把样子写清楚（照源稿的外貌），年纪、发色、穿什么。
- 不写内心，不写比喻成串，不写“象征着”。只写看得见的。
- 魔法写成看得见的结果（赤土自己隆起成垒，盾阵亮成一道墙，花瓣离枝成刃），不写原理。
- 别出现会被照字面画出来的词，比如 white heart 会画成一颗心；写 ribbon 它会真画飘带。
- 衣着写严实。不写撕破的短裙、睡袍、湿衣贴身这一类，祭袍、囚衣、淋雨的衣裳都写成从颈到踝盖住身子的长衣。

### who、row、beast 和参考图的数

出图时参考图最多五张：两张画风，剩下三张给人和大东西。

- `who`：有立绘键的人，一人一项 `[键, 哪一套衣服, 叫法]`，衣服是 `casual`（常服）、`private`（私服）、`battle`（战斗）、`formal`（正装）里的一个，照场面挑。有 `beast` 的时候 who 至多两个人，没有 `beast` 至多三个。
- 人多的场面用 `row`：`[[键, 衣服, 叫法], …]` 至多八个，拼成一排当一张参考，适合远远的一群人、多半是背影。用了 row 就不写 who。
- 画面里还有别的有立绘的人、可只是远处的小人的，不进 who，在 text 里用一句话写样子就行。
- `beast`：这一幅里有神、魔神、攻城神殿、巨像、机甲这一类大东西，任务单里又给了它的参考图的，填参考图的名字（`god_…` 或 `strife_…_NNN_k`）。它只管那个东西的样子，画法还是照光锥。text 里照样要把它写清楚。

### light、camera、style

- `light` 一句英文，比如 `the cold blue of an early-winter dusk outside, warm firelight from above the gate spilling onto the threshold`。
- `camera` 一句英文，要大胆，像动画的分镜：低机位仰拍、越肩、从门洞里往外、从高处俯看、贴着地面。带一点倾斜。
- `style` 两个名字，头一个是主的，照这一幅的光和调子挑：

| 这一幅是 | style |
|---|---|
| 夜里、火光、暗处的对峙、烽火边 | `["anaxa", "fire"]` |
| 冷的夜、星光、雪、冰、死域的冷光 | `["fire", "anaxa"]` |
| 白天、麦田、原野、暖的日光 | `["wheat", "aglaea_card"]` |
| 明亮的白和金、神殿、加冕、神的光 | `["aglaea_card", "wheat"]` |
| 正在打的那一下、带速度线的动作 | `["himeko_card", "anaxa"]` 或 `["himeko_card", "fire"]` |
| 夜里的城、灯、宴席 | `["sparkle", "fire"]` |
| 安静的屋里、两个人说话、一样东西的近景 | `["jingyuan", "wheat"]` |

一条主线的四幅别全用同一组。

### raw（血和伤）

用户定的：打过的仗画出打过的样子。场面里成年人身上有血、伤、烧伤、破衣裳的，在 text 里写出来，`raw` 写 true，照写的画。不写断肢、露骨、内脏，不写尸堆的特写。战死的人写成盖着斗篷和盾躺着的、头盔搁在插进土里的剑上的。没打过的场面不硬添。

### 未满十八岁的人

任务单里标了每个人在这一段的年纪。未满十八岁的照常入画，穿戴整齐，可以在场、可以拿兵器，可是不画他身上的伤口和血，不画他挨打、受折磨、被杀的那一下。这一幅里只要有未满十八岁的人受了伤，就换一个瞬间画（那一下以前，或者他已经站起来以后）。

### 这个世界和这一纪的规矩

- 西幻，中世纪欧洲打底，剑与魔法，JRPG，高魔。不写东亚的衣裳、屋檐、纹样，不写现代的东西。
- 没有火药，没有枪。炮是刻着符文、烧魔晶的炮（crystal cannon、rune-carved cannon），不写 gunpowder、rifle、musket。
- 这一纪的东西什么时候才有，照源稿那一幕写了什么为准，别提前画：
  - 白石长垒：约 233 年开工，296 年合龙。以前没有墙。
  - 1020 年以后墙上有魔晶炮阵；约 2100 年龙雷炮；3046 年神杀炮（矮人的，比城门还粗）。
  - 约 3600 年星纱列车上战场（披甲的战争列车，在墙后的轨上跑）；约 4200 年魔导蒸汽机甲；约 5300 年浮空塔（塔底托着浮岩）；约 6400 年极限型机甲。
  - 8800 年以后死域里是发条机兵（人形或履带，背上一把上弦的钥匙，弦尽了跪下朝北）和魔族那一边骨匠拼的铁狼；约 9800 年擎天级机甲巨神兵（比塔高）。
  - 魔族那一边：会走的攻城神殿、神像战船、破城巨像、成群的魔物。
- 魔族：生着角，各系样子不一样（炎角的角上有火，夜魔、影魔、深潮、绯宴、白骸、轰狱……），照源稿和任务单里的英文资料写。他们是人，不画成怪物。
- 诺伦·晨曦（晨曦的皇帝，圣王）：从头到脚一身铭文亮银板甲，狮首闭盔，面甲垂着，白毛领大披风，手里是比人还长的白金双手大剑破晓。任何一幅都不画他的脸，不摘盔，叫法用 `the helmed emperor`，代词用 he。
- 神和魔神：源稿里明着露面的照源稿写的样子画，写清个头、样子和祂手里的东西。正神不画头顶的光环，不画成宗教画。魔神是高座上降下来的庞然大物，照任务单给的显像和史诗战的图。倒下的神写成看得见的结果（神血像滚烫的雨，落处草木倒生；神骸化成沙；盾立成碑）。
- 月银纪活下来的老传奇（希尔妲、霍布、凯恩、珀拉这些）不显老，照任务单里的立绘。
- 元年那一夜站在环心上的那个人只画成远处一个披兜帽的小人，不画脸。四位执政、那一位恶神不入画。
- 止戈那一天站在两军之间的女人：照源稿，一个不说名字的女人，朴素，写成背影或者远处的侧影，不画神光，不写 god、goddess。
- 死域（约 3000 年以后长垒以南）：铁会开出锈的花，草是白的，影子比人先倒下，死在那里的东西不烂。
- 不画月亮和月牙，text 里别出现 moon、crescent。弯的角、牙、弓、弧光也别写得像一弯月。
- 画里不写字。旗、碑、册子上的字写成 marks 或者不写。

### name（中文，玩家看得见）

两到四个汉字，取这一拍里的一样东西、一个地方加一个时刻：空鞍、那一声、白线之晨、火冠、雪仓、最后一环、鸦落、断刃。

- 不用口语半句，不直接拿一句台词当名字，不用“之战、对决、决战、觉醒、羁绊、命运、绝望、希望”这类大词，不带月相字。
- 一张牌里的几个名字别一个构词法，别跟主线各幕的标题重样，别跟牌名、主线名重样。
- 先用源稿里现成的叫法（歌里、牌文里的词常常就是）。

## 五、死期死因（fates）

- 谁要写：这张牌的旅伴和相遇的人里，死在这一段剧情里的。说的是主线各幕到收束里讲到的死（连同收束紧跟着的那几个月），和主线的默认收束里明着讲到的横死。在这一段剧情里下落成谜的也写，加一栏 `"label": "下落两说"` 或 `"下落不明"`。
- 不写的：活过这一段、几十年以后老死病死的（一张牌的年份跨几百上千年，不能照“死在这张牌的年份以内”算），往后才离开、才不见的。这些人的下场页上的档案里本来就有全文。
- `when` 写年份和月份，照源稿（纷争纪某年某月）。`where` 一个短地名。`how` 两三句，只搬源稿里的事，口气照源稿平实的叙述。
- 不写给模型看的话（玩家、AI、裁定、照某条），不加评语。是谁不点破的人不揭他的底。未满十八岁的只写结果和后来，不写伤口和血。
- 标点：不用破折号、分号、省略号、感叹号。引语用中文弯引号。
- 神和魔神不写进 fates（祂们的陨落在页上另有地方）。

## 六、死的那一刻（deaths）

- 只给旅伴（任务单“旅伴”那一栏的人）里死在这一段剧情里的（口径同上一节）。一人一幅，键 `sNN_d_<立绘键下划线后面那一截>`，`death` 写中文名（跟任务单上的名字一字不差），`age` 写他死的时候几岁（照源稿算），别的栏跟节点原画一样。
- 画他最后站着的那一下，或者那一下刚过去的一瞬，照源稿的下场。是这个人一生的定格，不是尸体，不画躺着的死人。
- 成年人可以 `raw: true`，血、伤、烧伤照写的画。
- 死的时候未满十八岁的：`"minor": true`，`raw` 不写。不画他受伤、被杀、倒下。改画他做那件事以前最后一个完好的瞬间，或者一幅空镜，只有他留下的那一样东西和那个地方，画面里没有他的身体。
- 死的时候十四岁以下的不出图，在 `notes` 里写一句。
- 他最后被人看见的那一拍要是已经是某一幅节点原画，不另出，写 `{"key": "sNN_d_xxx", "death": "人名", "name": "…", "same": "那一幅节点的键", "age": 21}`。

## 八、交回来说什么

最后一条消息里写：写了哪几个文件，每张牌几幅节点、几条死期、几幅死的那一刻，check_scenes 的结果，还有要主会话定的事（至多十条，一条一句）。只写 `scenes/sNN.json` 这几个文件，不要出图，不要改别的任何文件，不要提交。
