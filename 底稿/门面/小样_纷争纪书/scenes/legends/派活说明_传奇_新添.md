# 纷争纪的书·新添的传奇｜这一批不一样的地方

2026-11-15。先读同目录的 `派活说明_传奇.md`（主说明，栏目、写法、不能写的、falls 的画法都照它），再读这一份。两份说法不一样的地方照这一份。

## 一、这一批是谁

11-13 给纷争纪每个年代添了一批凝了名的传奇，一共八十七位，书里还没有他们的档案：

- 七十四位“地方上记得的传奇”。他们不进正史的战报，名字只留在那一处（一道段门的门框、一根鹿角、营火边的一支歌），往后说得出名字的只有那一带的人。源稿是各页的 `新传奇` 分段（`纷争纪/parts2/q8b_新传奇.md`、`parts3/r7c_新传奇.md`、`parts4/t7g_新传奇_上.md`、`t7h_新传奇_下.md`、`parts5/u7h_新传奇.md`、`parts6/v7f_新传奇.md`、`parts7/w7b_新传奇.md`），一位一条“凡世至强”短条。拼好的页里也有同样的条目，任务单给的行号指的是拼好的页。
- 两位持影（暗精灵里守根的那一支）：荻薇丝·垂根、瑟弗兰·深荫。
- 十一位原来页上有、表上漏了的：妲格玛、法埃尔、鲁达赫、希瑟娅、维卡尔、奥伊拉、岱勒姆、柯尔维斯、塔赫尔、瑟娜缇、伊维隆。他们没有自己的条目，任务单里只有总表那一行和页上提到他们的行号。

## 二、跟主说明不一样的地方

1. **没有立绘。** 这八十七位都没有立绘键。falls 里不写 `who` 这一栏。样子要在 `text` 里用英文写清楚：族、看着多大年纪、头发和眼睛、身形、衣甲、手里的东西，照他条目里“仪容与印象”那一行。条目没写的不编，写成看不清的（背影、兜帽、逆光）。对手要是任务单给了参考图，`beast` 照填。
2. **死法照条目，一个字的意思也别改。** 这一批的死法 11-13 照一条规矩审过：传奇只死在四样手里（三位以上同档的传奇围杀、克制他的传奇或高他一档的传奇；一百位以上的英雄拿命换伤、他自己不退；神、魔神和带着神性的东西；十万以上的精锐军团不计死伤、他死战不退），另外有自己把命烧进本事里的（燃尽）。寻常的兵和魔物杀不死传奇。`how` 里要看得出他落在哪一样上、他为什么不走，照条目里“凝名伟业”“往后”“使用规则”那几行搬。画也照这个画：对面是谁、是什么，照条目。
3. **名字凝住和到传奇可能不是同一年。** 条目写着“名字凝住，人还是英雄，哪一年才到传奇”的，who 里照着写（“那一年名字凝住”“约某年走到了传奇”可以写），撼世、天灾、圣座、极境、LVL 这些档位的字照旧不写。
4. **长相停在名字凝住的那一刻。** 条目写他名字凝住时不满十八岁、看着是少年的，falls 加 `"young": true`，照主说明未成年的规矩画（不画受伤流血倒下，画做那件事以前最后一个完好的瞬间，或者背影）。别的成年人照写 `"raw": true`。
5. **没有自己条目的十一位。** 照总表那一行和页上提到他的句子写，源稿只有一句就写一句，不补事。鲁达赫、维卡尔、奥伊拉、岱勒姆、柯尔维斯五位页上没写往后怎样：不写 falls，at 写到在表上的那一张为止，不替他编下场，也不写“下落不明”这一类的话。
6. **who 里带上名字留在哪。** 源稿写了他的名字留在哪一处、谁先叫开的，who 的第二句带上（“名字刻在某段门的门框上”这一类）。
7. **魔族那一边的传奇**照纷争纪当时的叫法写本名和传奇之名。反叛那一营的（10992年）死在魔神手里，照条目。
8. **quotes** 只抄条目里“声口”那一行引号里的原话，至多两句，没有就不写。
9. 辛美尔小队的矮人 11-15 起叫艾泽（原来写艾冯），传奇之名砧音，源稿已经改了。
10. JSON 里不要写 `reviewed` 这一栏。

## 三、怎么干

- 只写 `底稿/门面/小样_纷争纪书/scenes/legends/gX.json` 这一个文件（UTF-8，不带 BOM）。用 Write 工具写文件。这台机器的 Bash 里传 heredoc 会吞反斜杠，带反斜杠的脚本别走 heredoc。
- 写完在仓库根 `E:\aldran_art` 上跑自查，报“错”的都改掉：

```bash
python -I -X utf8 底稿/门面/小样_纷争纪书/scenes/legends/check_legends.py gX
```

- 不出图，不改别的任何文件，不提交。
