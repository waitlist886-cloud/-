# 纷争纪的书·二十一幅时代原画｜写场面的说明

2026-11-12。给写场面的人看的。你写的是出图用的英文场面，不出图，交一份 JSON，主会话审过以后照它出图。

## 一、这是什么

门面里“纷争纪的书”有二十一张牌，一张牌一个时代（s01 到 s21）。玩家点进一个时代，页面开头是一整屏横幅的“时代原画”，标题压在左下角。月银纪那一本的二十七幅已经做完、用户认过了，这一轮照同一个路子写纷争纪的二十一幅。

画法不用你管（平涂的装饰插画，像一层压一层的剪纸，人很小，庞然大物画成浅色的剪影）。你管的是画什么。

## 二、每一幅的规矩

- **下面**是这个时代开场的地方，和一小团暖的火（篝火、烽火、炉火、灯、火把，照这个时代有什么），火边是很小的、画得很简的人：这个时代的旅伴，一人靠一样东西认出来（一柄比人长的剑、一面旗、独臂和锤、背上的书箱），至多七个。火和人放在画面当中一半宽里，从上往下数一半到三分之二的地方。
- **上面**占满上半幅的，是这一段的庞然大物，画成一层压一层的浅色剪影，边上带细的亮线：降下来的魔神、赴南的正神、立在天边的长垒、悬在死域上的浮空塔、比塔还高的擎天级。它朝下看着那团火，或者正朝这边来。
- 画的是**事情做成以前**的样子：仗还没打、门还没开、墙还没合龙。做成的那一下留给节点原画。
- 最底下四分之一只有安静的、暗的前景，不放要紧的东西（页面在那里压标题）。
- 火的烟往上升成一道长长的 S 形，可以化进天上的东西里。
- 颜色是纷争纪这一套：铁灰、石板蓝灰、干血一样的暗红、骨白，神的光用一点浅金；暖的橙色只留给火。西边魔神和魔族那一侧偏暗红，东边联军和正神那一侧偏骨白和钢灰。越往后的时代越暗、越破；第十九张是全纪最亮的一个白天；第二十一张是灰色的雨和将亮的天。
- 二十一幅连起来看要有变化：别每一幅都是“墙加天上的神”。照这一段自己的东西挑：灰和倒下的辉塔、半疯的麦田、赤原、七扇门、西征的龙、合龙的车、鹿角、提灯的山路、盾、工场的烟囱、南去的神、神杀炮和白马、浮空塔、血誓的高座、沙海和三枚日轮、七根石柱、发条机兵和铁狼、墙根的麦子、两军之间、雨城的门洞。

## 三、这个世界和这一纪的规矩

- 西幻，中世纪欧洲打底，剑与魔法，JRPG，高魔。不写东亚的东西，不写现代的东西。没有火药，没有枪。
- 东西什么时候才有，别提前画：白石长垒约 233 年开工、296 年合龙；1020 年以后墙上有魔晶炮阵；3046 年神杀炮；约 3600 年星纱列车；约 4200 年蒸汽机甲；约 5300 年浮空塔；8800 年以后发条机兵（背上一把钥匙）和铁狼；约 9800 年擎天级。
- 诺伦·晨曦（晨曦的皇帝）：一身亮银板甲、狮首闭盔、白毛领大披风、比人长的白金大剑，永远不露脸。
- 魔族生着角，是人，不画成怪物。魔神是高座上降下来的庞然大物，样子照源稿和 `底稿/状态栏/comfy/epic/prompts/gods_mo.json`；正神照 `gods_zheng.json`。正神不画头顶的光环。
- 元年那一夜环心上的那个人只画成很小的披兜帽的背影。四位执政、那一位恶神不入画。
- 第二十张止戈：两军之间一个不说名字的女人，很小，背影，朴素，不画神光。第二十一张门洞里的篮子只画篮子，不画婴儿的脸。
- 不画月亮和月牙：text 里不要出现 moon、crescent，弯的角、弓、弧光也别写得像一弯月。画里不写字。
- 人都很小，不写伤口和血。

## 四、先读什么

1. `底稿/门面/小样_纷争纪书/data/strife.json`：二十一张牌的名字、年份、篇名和篇描述（pian、pianDesc）、主线的开局（lines[].open）、旅伴名单（cast）。
2. `纷争纪/天黑以后_二十二张_第七版.md`：每张牌的牌面和牌文，读调子用。
3. 每张牌的任务单 `底稿/门面/小样_纷争纪书/scenes/任务单/sNN.md`：源稿在哪、主线从第几行起、这一段的人的英文长相资料（who、palette）。照行号去源稿里读头一条主线的“开局”“世道”和一幕的头几拍，知道开场在哪、是什么季节、火边有谁。源稿很长，只读点到的节。
4. 样子：`底稿/状态栏/comfy/gpt_cg.py` 里 `S['m07_era']`、`S['m01_era']`、`S['m16_era']`、`S['m23_era']` 这几段的 text（月银纪那一本的时代原画，用户认过的写法和详略）。

## 五、交什么

一个文件 `底稿/门面/小样_纷争纪书/scenes/era_scenes.json`（UTF-8，不带 BOM）：

```json
{
  "s01_era": {"time": "night", "text": "Scene: ……", "note": "中文：开场在哪、火是什么、上面是什么，拿不准的地方"},
  "s02_era": {"time": "dusk", "text": "Scene: ……", "note": "……"}
}
```

- 二十一个键，`s01_era` 到 `s21_era`。
- `time` 写这一幅的天色，从 `night`（夜）、`dusk`（黄昏或天亮前）、`day`（白天）、`rain`（灰的雨）里挑一个。
- `text` 英文，`Scene:` 起头，一百六十到二百四十个词，照样子的写法：先一句交代时候和地方，再写地、火和火边的人（一人一样认得出的东西），再写上面占满上半幅的庞然大物（写清它是什么样子、朝哪边、多大），再写烟，末一句 `Palette:` 点这一幅用的几种颜色。只写看得见的，不写内心，不写比喻成串。
- 人用叫法不用名字（a helmed emperor on a tired horse、a one-armed dwarf with a hammer）。

写完自己过一遍：二十一幅有没有重样的；年份对不对；有没有 moon、crescent、字、枪；诺伦有没有露脸。

## 六、交回来说什么

最后一条消息里写：写了几幅，哪几幅拿不准（至多八条，一条一句）。只写 `era_scenes.json` 这一个文件，别的任何文件都不要改，不要出图，不要提交。写文件用 Write 工具。
