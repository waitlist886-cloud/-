# 久远与无垠的大图书馆 书目 第二版（11-23）

第一版六十四本，你回：“我觉得可以再多一些有名有姓的角色写的书。玛丽贝尔作为第一任院长和几百年的顾问应该也写有不少书。（顺便她不会在意著名，而且帝国也应当知道她的存在 - 她不会特意的隐藏自己，而且她与巴尔缇娜本就是好友）”

这一版：

- 作者能落到有名有姓的人身上的，都落上。一本书的口气就是这个人的声口，读书也是在认识这个人。
- 玛丽贝尔单列一架，七本，署名照写。她不藏身份这一条，卡里各处（1001 年、前传、山铜纪的人物条和科学院）正在改，另一份子任务在做。
- 一共一百零二本。一人写的书，口气照卡里这个人的声口和性子；事实照卡里。
- 作者是传奇、神眷的人物的，书里不替他们说卡里没定的事（暗线、真相层只露边），锁照守。四执政不写书（若娜瓦只留藏书票）。

图书馆的样子、量和先后照第一版第一、三节，下面只列书。“现成”是卡里已有的原文照书排一遍。

## 玛丽贝尔的一架（七本，署名照写）

她是黑耀自然与工程科学院的首任院长（山铜纪 863 到 945 年，公文署梅卡涅·游丝），迷宫纪约 350 年起是研究院的顾问。书上两个名字都见得到，她不在意。口气照她的声口：先挑你的毛病再帮你，叫人做事的话多，凡事先算、算完报几成，结论后头常跟一句“证毕”。

| 书名 | 写什么 |
|---|---|
| 《做出第二台以前》 | 科学院的头八十年。“做出第二台才算真”是怎么立的，萨马德·无二那三手，院里照二十年的影图铸出第二轮的那一天 |
| 《机巧与魔导：两陆工业小史》 | 从蒸汽、魔导炉心到电气和渊月电网，东西两陆谁偷了谁的、哪一台是第二台。你点名的那一本 |
| 《公理》 | 她的数学：析构、公理、阿希奥玛那台浮着的机关是怎么算出来的。写得很难，前言里说“看不懂是你的问题” |
| 《电气突破备忘》 | 研究院约 350 年起，她当顾问时给电气那一组写的备忘，一条一条，带图 |
| 《给新生的十三条》 | 研究院入学头一天发的小册子。第一条“迟到的人我不等”，第十三条“凳子别坐” |
| 《点心会纪要》 | 每旬一回的点心会，谁来了、吃了什么、吵了什么。巴尔缇娜来过几回，纪要上写“陛下又带了旧城那家的蛋糕，难吃” |
| 《阿南刻运算日志》 | 那台大机器胸口打出来的数，她一页一页抄下来，旁边批注。打了一千八百年还没算完，书也没写完 |

## 往前、往后的廊

照第一版：往前衔枝纪、赤金纪、葬火纪各三四本烫手的；往后 1001 年以后的书只有书脊，越往里越空白，最末一格空着。

## 要你定的

1. **这一百零二本**：添、删、换作者，告诉我。倾向：照这个起头。
2. **头一批**：你点名的（971、玛丽贝尔的七本、万兽纪事、北口以来）、七曜兽谱、王种考，加现成的十一本，三十本上下。倾向：照这个。
3. **卡里的人写书，事实照卡里，没定的不替他们定**；暗线和真相层只露边（斐里安的笔记撕掉几页，凯尔萨斯的登神术只露目录）。倾向：照这个。
