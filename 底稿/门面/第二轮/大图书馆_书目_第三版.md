# 久远与无垠的大图书馆 书目 第三版（11-23）

你看了第二版回：“一些书名和内容也可以参考我们的世界里的书，比如奥法协会和工程院的书。超凡技艺的书也可以参考一下现代的MA相关数据，比如971最开始就是参考的梅耶的战斗的艺术那本书。另外宗教比如星冠圣堂的书也可以收录一些。以及可以额外多收录一些可能比如rare技艺的歌谣，迷宫纪孩子们的阅读物或者睡前故事，各个纪元里可能有过的歌剧，故事集，小说等脱胎于奥尔德兰真实的历史或者说，过去纪元的主线成为了后世被人们铭记传承的故事这样的感觉”

这一版：

- 第二版那一百零二本照旧，改了两处，见第一节。这一版新添七十三本，分六处：兵书一架、行当的歌、星冠圣堂厅、奥法与工程厅、孩子的一架、戏台与说书。一共一百七十五本。
- 新添的每一本多一栏“照什么”，写它照现实里哪一本书的样子、做法。借的是体例和做法（怎么分卷、怎么配图、谁写给谁、口气），内容照卡里，不搬原书的话。
- 卡里已有的东西优先：素材是三个子任务从卡里清点出来的（奥法、工程、圣堂、歌谣技艺、童谣、戏），书里的事实、人名、年份照卡里。没有现成作者的，起了一个身份，标★。
- 往事成了故事那一类（歌剧、小说、故事集）有意跟真事对不上：唱大了、编了一场史书上没有的戏、两版说法打架。书的简介里写明哪里是编的，跑卡的时候照卡里的真事，书照书的说法。

## 一、第二版里改的

- 《神谱·月银纪》的作者原来写萨尔维斯神学院，卡里没有这个地方（月银纪没有统一的教会，只有神殿和祭火连成的网）。改成：星冠圣城七十二殿的祭司，月银纪 5600 年圣城奠基起一殿一卷接着记。
- 《战斗的艺术·971修订版》写法补一句：照梅耶 1570 年那本《击剑艺术的完整描述》的样子排，一条命路一卷，每卷几十幅版画，画的是院子里两个人对练、边上站着看热闹的人，卷首一页献词，大元帅的旁批写在版画旁边。

## 八、要你定的

1. **这一百七十五本**：添、删、换作者，告诉我。倾向：照这个起头。
2. **★的作者**：没有现成作者的起了身份（坐牢的骑士、赶车人、七十七岁的角力手、挪公款的账房），名字等写到那一本再起。倾向：照这个。
3. **格尔贝特四句的后三句**：卡里只有头一句，书里写全，后三句我来起。倾向：照这个。
4. **头一批**：第二版那三十本上下，加这一版六处各挑一两本：《不问者四句》《行当歌集》《星冠时祷书》《一座蓄电塔的来历》《长夜一灯》《春天没有来》，三十六本上下。倾向：照这个。
