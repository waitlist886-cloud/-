# 命星池收旅伴的生来星：派活说明（11-24）

## 为什么做

建档页第八步抽命星，现在分成 Special、Passive、Art·Active 三个池子，各留一颗。用户要“special 和 passive 跟着纪元走，越往后越多，不提前出现”。池子眼下只有底卡那 168 颗，四纪各页旅伴身上的生来星几乎没进来，所以越往后几乎不多。用户看了回“洗”：把各页旅伴自己的 Special、Passive 洗成谁都抽得到的天赋，收进池子。

材料在 `材料/<份>.json`，一颗一条：name、type（Special 或 Passive）、tier、era、from（这一页在建档里的起始年）、page、also（同名的星后来又在哪几页出现）、text（页上那一整块星条原文）。你只管自己那一份。

## 每一颗交什么

交稿写 `交稿/<份>.json`，一个数组，材料里每一颗都要有一条，次序照材料：

```json
{"name": "赤铁之手", "type": "Special", "keep": true, "tier": "Epic",
 "desc": "Special。烧红的金属在手下听话的天赋，炉边长大的孩子出得最多。被动：烧红的铜、铁、山铜握得住、不跳不滑，手上烫伤不到骨，锻造和金属雕刻的判定获得优势，DEX／VGR +15%。主动：握住烧红的凿子按上金属，一口气的工夫里手底下那一块软得像蜡，照心意吃进一笔，CD 24h，启源只软得下凿尖底下一笔，灵格起一整块铁件捏得动。限制：只认烧红的金属，凉铁和石头不听，刻错一笔照样是错，打仗来不及用。",
 "note": "", "last_era": null}
```

- `name`、`type` 照材料，一字不改。名字是这颗星的名字，玩家抽到的就叫这个，同一颗星在旅伴身上和玩家身上重名没关系（命星可以重复）。
- `keep`：收不收。不收的写 `"keep": false, "why": "一句话"`，别的栏可以不写。
- `tier`：照材料的阶。只有一种情况改：材料是 Unique 的，见下面“不收的”。
- `desc`：给玩家在建档页上看、也原样写进凭证交给跑卡的模型，五十到二百三十字（不算字母数字）。照命星池原有的写法（`小样_外壳/data/stars.json` 里随便翻几颗 Passive、Special 看）：
  - 开头写 `Special。` 或 `Passive。`，再一句说它是什么样的天赋或体质、谁家常有、生下来怎样（页上首段多半有这一句，留下）。
  - 接着 `被动：`、`主动：`（有就写，带 CD 和随位阶长的两三处）、`限制：`，属性加百分之几照页上的数，写在被动末尾。
  - 拿掉这个人自己的事：人名、他哪一年在哪里做了什么、这一段主线里的人和地方、“头一回露出来”那件事、【调用】、世界反应里点名的人、★。效果里挂在他私事上的那一截（赤铁之手摸碑认生死那一样）拿掉，剩下的照写。
  - 效果是这个人才做得到、换一个人就说不通的，改写成“有这份天赋的人”都做得到的样子，分量照阶不缩水。
  - 卡面规矩：不用 ——、—、；、…、！、...（分号一律改逗号或句号），不写月相字（新月、满月、残月、月牙、弦月、月亮、月光），不写科技词（量子、熵、坐标、频率、能量、系统），不用 `tools/check_people_v7.py` 里 BAN_W 那张禁词表的词，不点厄洛伽的名。神用祂。
- `note`：可空。这颗星挂着某一纪才有的东西、到了往后几纪说法要变的，写一句给玩家看的话。多半空着。
- `last_era`：可空（null）。这颗星往后几纪都抽得到（生来的天赋，血里带的，多半如此）就写 null。效果整个挂在某一纪才有、往后没了的东西上（比如只在长垒上才说得通、只在萨尔维斯的塔里才有的），写它最后能出现的那一纪：moon、strife、bronze、maze 之一。宁可改写成通用的也别轻易截断。

## 不收的

- Unique：一律不收（同一时刻世上只有这一个人有，玩家抽到会跟旅伴撞），`why` 写“Unique”。
- 整颗星就是这个人的一件事、一个誓、一样信物，拿掉他的事就什么也不剩了的。
- 跟命星池里已有的一颗（看 stars.json 的 1001 年名和各纪名）是同一样东西、只换了名字的。
- 跟你这一份里另一颗是同一样东西的（同族同家的同一种体质写了两遍），收一颗，另一颗写 why。

拿不准收不收的，收。不收的预计一成以内。

## 查

交完跑 `python -I -X utf8 tools/check.py <份名>`（在本目录 `底稿/门面/第二轮/建档/命星池_旅伴星/` 下跑），问题要 0。

## 别碰的

只写 `交稿/<份名>.json`，别的文件一个不改（stars.json、各页、材料都不动）。临时脚本放你自己的 scratchpad 子目录。

## 交回来说什么

一段话：收了几颗、不收几颗（各几颗是什么缘故）、改了阶的有没有、写了 last_era 的是哪几颗、拿不准的几处。

## 补：Unique 也收（11-24 用户：“unique其实也可以给，底卡也有放开，玩家和旅伴出开同一颗星也是一种玩法（旅伴与世界的反应）”）

头一轮不收的 Unique（交稿里 `"keep": false, "why": "Unique"` 的那几条）改成收，就地改交稿里那几条，别的条一个字不动。每一条：

- `keep` 改 true，去掉 `why`；`tier` 照旧写 "Unique"。
- `desc` 照上面同样的写法洗：拿掉这个人自己的事，效果写成“生来带着这颗星的人”做得到的样子，分量照 Unique，不缩水。开头一句照样写它是什么样的天赋、多久才出一个（Unique 多半是一世只一个、几百年一个、神看着才有的），别写成“某家常有”。
- `owner`：原来那位持有者，写成“名字，哪一段年月的旅伴”（比如“柯恩，犁的年月的旅伴”），一句，十五字上下。并池时会在这颗星那一纪的说明里自动写上“这一纪还有一个人生来就带着这颗星：……他和世界都会察觉”，不用你写这一句。
- `need`：这颗星长在身子上、别族说不通的（翅膀、角、鳃……），照 `种族挡.json` 的写法写一个数组（族 id 和支系名在 `种族表.json`），不是的不写。
- `note`、`last_era` 照上面。

跑 `tools/check.py <份名>`，问题要 0（Unique 那几条要有 owner、阶是 Unique）。
