# 建档·本事 第二稿（11-24）

用户原话：“本事，或者说初始skill那里，我想要洗一下，多一点，而且现在的感觉有点不明所以 - 有点八股的感觉。”

## 怎么洗的

- 第一稿的毛病：一项是“命路名加两个动词”（渊垒摧锋回团、天平换俘写约），读的人要先知道二十三条命路才看得懂。同一纪六个时段一串几乎一样，山铜纪六段里有五项一字不差。
- 这一稿一个时段十二到十六项，一项一个短名加一句说明。短名四到八个字，照游戏开局技能的路子起（读雪追迹、骨矛围猎、塔盾承击、层图叠绘），不拿命路名打头，命路是第七步的事。本事是“这一年里一个人手上真会的那一样”，分量照开局，不写招式、不写传奇。
- 说明一句话：做得到什么、这一年在哪里学来的，末尾“吃”后头是它落在底卡哪几门 Skill 上（底卡通用 Skill 名册二十二门加卡里修行关联常用的统率、意志、耐力、察觉、身法、武器熟练度、医疗、急救、生存、追踪、书写、礼仪、航海、学识、算学、药学、识图、奔跑、驾车、攀爬、察言观色、表演，生活技能八门：料理、锻造、炼药、采集、裁缝、木工、钓鱼、酿造）。残响共生只在迷宫纪给。
- 每段都掺着打的、做手艺的、跟人打交道的、活下去的、念书的，贴着那一段的事：祭火是火、冰河和结绳，萨尔维斯是环、塔光和荫册，魔族之世有藏角过关和仿笔改册，纷争纪从没墙到砌墙到守灯到魔晶炮和机兵，山铜纪是停战以后的团、白烛帐子、灰袍的银针、灰雨城、新朝招兵、凯撒法庭、黑耀的契约和科学院，迷宫纪从号墙认活一路到 1001 年各座城的本事。
- 带年份的照旧：`182起` 是 from 182，`到199` 是 to 199，`200到230` 是两样都有（shell.js 的 visible 认 from、to）。
- “接旧”一栏是这一项替下了第一稿的哪几项，给 apply_skills.py 改 life.json 用（见末节）。

## 凭证里写什么

shell.js 第九步（誓心与出身）底下“这一段的本事”是一排按钮，至多挑两样，另有一格自己写。凭证里那一行是 `这一段的本事：短名、短名、自己写的那一句`（第 1496 到 1497 行），只写短名，说明不进凭证。所以短名自己要读得懂，说明是给页面上看的。眼下页面只画短名，说明要显示得主会话在 STEP[9] 的按钮上接（比如 title 或者点开一行小字），这一稿没动 shell.js。

## 套进去

- `本事_第二稿.json`：{时段 id: [{"s": 短名, "d": 说明, "from": 年份, "to": 年份, "was": [第一稿替下的几项]}]}，from、to、was 没有就省掉。1001 年那一段的键是 "1001"。
- `tools/apply_skills.py`：
  - `python -I -X utf8 底稿/门面/第二轮/建档/tools/apply_skills.py --dry`：报每一段的项数、新增和拿掉的，life.json 里“前半生”那几页的 sk 提示要改成什么、改完以后还有没有找不到本事的提示。
  - 不带 --dry 写 build.json（照原来 indent=1 的排法），skills 一项写成 {"s", "d", "from", "to"}，shell.js 只读 s、from、to，d 留给页面以后显示。加 `--no-desc` 不写 d。
  - life.json 的 sk 是拿几个字去本事里找“带这几个字的”（lifeSkills），第一稿的名字换掉以后那些字就找不到了，所以 apply 照 was 一栏把每条提示换成接替它的新短名（新短名就是它自己的子串，找得到），只改 `"sk": [...]` 那一截，别的字一个不动。加 `--no-life` 不碰 life.json。
