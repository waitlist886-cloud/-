# 山铜纪的书·节点原画、死期死因、死的那一刻｜派活说明

2026-11-14。给写场面的人看的。你写的东西不直接出图，是交一份 JSON，主会话审过以后照它出图。

## 一、这是什么

《奥尔德兰的旅印》是一张西幻 JRPG 的角色卡。山铜纪是它两万年历史的第三纪：纷争纪末止戈，仗停了，号角挂上城墙，刀剑铸成犁头。往后九百四十七年，长垒还立着，墙西是西陆（灰之魔女巴尔缇娜往西走，九座高座一座接一座空出来，862 年立了黑耀），墙东是东陆（668 年苇棚区出来的索恩薇娅·里德斩断旧王冠，立了新朝），两边隔着墙和界碑对望，到 947 年归寂月最后一夜地裂开为止。门面里有一本“山铜纪的书”：沿着长垒往右走，两边立着碑，一页一章，玩家点进一章，看得到这一段的主线各幕、人物档案和原画。

这一轮要给每条主线的每一幕配一幅“节点原画”（过场动画里定住的一帧，崩铁光锥那一路的画法），给会死在这一段剧情里的人写死期和死因，给死在这一段剧情里的旅伴各画一幅“死的那一刻”。

月银纪那一本已经这样做完了，第七歌是样子，见纷争纪那一本的 `底稿/门面/小样_纷争纪书/scenes/示例_m07.json`。画风用户认过了，不用你管，你管的是画什么、谁在哪、镜头在哪。

## 二、先读什么

1. 你那一页的任务单 `任务单/pN.md`：源稿在哪、主线和各幕、这一段的人和立绘键、神和魔神的参考图、史诗战的对手、你要用的键。
2. 源稿里那几条主线（“## 山铜纪·主线｜……”那一节，一幕一拍一条，末一条是幕终）。每一拍都要读，画的是里面的事。
3. 源稿里旅伴和人物的条目，要用到的读：外貌、装束、正史里的下场。魔神读“（人物）”那几节和主线里写祂的那几拍。
4. 纷争纪那一本的 `示例_m07.json`，照它的写法和详略。
5. 人的英文长相资料在任务单里（从立绘资料抄的 who 和 palette），要更细的看 `底稿/状态栏/comfy/cast/` 里对应的 json（casual、private、battle、formal 四套衣服各一段）。
6. 魔神的英文设计：显像在 `底稿/状态栏/comfy/epic/prompts/gods_mo.json`（照 key 找），史诗战的对手在同一个目录的 `bronze.json`（照 block 找，design 那一段）。任务单里列了这一段牵到哪几条。

源稿很长（一页四千到六千行），照任务单给的行号跳着读，别从头读到尾。

## 三、交什么

一页一个文件 `scenes/pN.json`（UTF-8，不带 BOM），样子：

```json
{
  "era": "p4",
  "nodes": [
    {
      "key": "p4_a1",
      "line": "黎明的年月·灰雨之夜",
      "act": "一幕",
      "name": "两到四个汉字",
      "style": ["anaxa", "fire"],
      "who": [["s4a_hano", "casual", "the white-boned gatekeeper"]],
      "beast": "bronze_013_1",
      "light": "一句英文：主光什么颜色、从哪边来，对着什么颜色的暗部",
      "camera": "一句英文：机位和一点倾斜",
      "text": "Scene: ……（英文，两百到三百五十个词，照示例的详略）",
      "raw": false,
      "note": "中文：选的是哪一拍，源稿第几行，拿不准的地方"
    }
  ],
  "fates": {
    "人名": {"when": "山铜纪661年花信月", "where": "灰雨城南门", "how": "两三句。"}
  },
  "deaths": [
    {"key": "p4_d_xxx", "death": "人名", "name": "两到四个汉字", "age": 32, "minor": false, "style": ["anaxa", "fire"], "who": [["s4a_xxx", "battle", "…"]], "light": "…", "camera": "…", "text": "Scene: …", "raw": true, "note": "…"}
  ],
  "notes": ["拿不准、要主会话定的事，一条一句"]
}
```

- `nodes`：每条主线的一幕、二幕、三幕、收束各一幅（幕间不配，没有收束那一节的只配三幅）。键照任务单给的。`line` 写主线的名字，跟任务单一字不差（带页名，比如 `黎明的年月·灰雨之夜`），`act` 写 一幕、二幕、三幕、收束。
- `who` 和 `row` 二选一，都可以不写。`beast` 可以不写。`raw` 不写就是 false。
- 没有的栏不要写空串，整栏不写。

## 四、节点原画怎么挑、怎么写

### 挑哪一拍

- 一幕一幅，挑这一幕里最要紧、最有画面的那一拍，多半是幕终，或者这一幕的标题说的那件事。
- 四幅连起来要看得出这一段是怎么走的，别四幅都是人对着敌人站着。有静的（一个人、一样东西、一句话落下以后），有动的（那一下正在发生）。
- 画的是事情正在发生的那一瞬，不画事后的合影，不画象征图。
- 收束那一幅画这一段落定以后留下的东西和活下来的人，多半是静的。这一纪常常落在一块碑上：碑立起来的那一天，碑匠在刻背面，有人摸着一个名字。碑面上的字画成刻痕，不画成能认的字。
- 这一纪没有横跨大陆的大仗，尺度在别处：一条白墙从天边连到天边，一万一千人走九年，一百七十万具遗骨，一座城沉进海里，三十二座炮基一夜重铸。每一幅的落点是近处那一两个人。

### text 怎么写（英文）

照示例的写法，顺序是：

1. `Scene:` 起头，一句交代时间、地方、天气。
2. 画面里最大的东西是什么、在哪一边、占多大（大的东西只露一部分，叫画框切掉，比整个画进去更有压迫感）。
3. 人在哪（left / right / near foreground / far behind）、朝哪边（只取三种之一：正面 facing us、纯背影 seen directly from behind、正侧面 in full profile）、在做什么、手里拿什么、脸上什么神情。朝向和方位要写死，谁朝门走、门在哪一头，不写死它会画反。
4. 远处有什么小的东西（墙、塔、逃的人、一排兵）。
5. 末一句写前景四角虚化的东西（飘的灰、雨、火星、麦芒、雪、晨光里的尘）。

要守的：

- 一幅只画一个瞬间，一个机位。不写“然后”“随后”。
- 数目和颜色照源稿写死（三十三个孩子、三百赎罪军、七艘空艇、三十二座炮基）。源稿写了的不改，源稿没写的可以补，补的东西要合这个地方和这个年代。
- 人用叫法，不用名字。`who` 里第三项是这个人在提示词里的叫法（英文，身份加一样认得出的东西，比如 `the grey-haired witch of the rain city`、`the copper-haired soldier with a plain old sword`），text 里用同一个叫法。头一回提到他的时候带一句认得出的长相（发色、眼睛、衣着、手里的东西），照任务单里的英文资料写。
- 没有立绘键的人在 text 里把样子写清楚（照源稿的外貌），年纪、发色、穿什么。
- 不写内心，不写比喻成串，不写“象征着”。只写看得见的。
- 魔法写成看得见的结果（盐墙从咸水里立起来，雷伏在一个人身上不走，灰雨落下的地方火暗下去），不写原理。
- 别出现会被照字面画出来的词，比如 white heart 会画成一颗心；写 ribbon 它会真画飘带。
- 人体（11-13 纷争纪、月银纪两本查出来的毛病）：一个人只取正面、纯背影、正侧面三种朝向之一，不写背后斜看又要露脸（会画成背加侧脸，胸背分不清）；要看见敌人又要看见他的脸，就把镜头挪到敌人那一边。每只手写明在干什么、拿什么（left hand…, right hand…），一边才有的伤、缺指、断角写明是近侧还是远侧。倒退、回头、拧身这类姿势改成站定的一下。弓弦、长柄写明两头在哪只手里。多出来的胳膊腿先查设定（四臂的魔族照设定写明）。
- 衣着写严实。不写撕破的短裙、睡袍、湿衣贴身这一类，祭袍、囚衣、淋雨的衣裳都写成从颈到踝盖住身子的长衣。

### who、row、beast 和参考图的数

出图时参考图最多五张：两张画风，剩下三张给人和大东西。

- `who`：有立绘键的人，一人一项 `[键, 哪一套衣服, 叫法]`，衣服是 `casual`（常服）、`private`（私服）、`battle`（战斗）、`formal`（正装）里的一个，照场面挑。有 `beast` 的时候 who 至多两个人，没有 `beast` 至多三个。同一个人这一纪有好几个键（小时候、后来），挑任务单上这一页的那一个。
- 人多的场面用 `row`：`[[键, 衣服, 叫法], …]` 至多八个，拼成一排当一张参考，适合远远的一群人、多半是背影。用了 row 就不写 who。
- 画面里还有别的有立绘的人、可只是远处的小人的，不进 who，在 text 里用一句话写样子就行。
- `beast`：这一幅里有魔神、史诗战的对手（浮塔、神骸、巨兽、残火）这一类大东西，任务单里又给了它的参考图的，填参考图的名字（`god_…` 或 `bronze_NNN_k`）。它只管那个东西的样子，画法还是照光锥。text 里照样要把它写清楚。

### light、camera、style

- `light` 一句英文，比如 `the cold blue of an early-winter dusk outside, warm firelight from inside the gateway spilling onto the threshold`。
- `camera` 一句英文，要大胆，像动画的分镜：低机位仰拍、越肩、从门洞里往外、从高处俯看、贴着地面。带一点倾斜。
- `style` 两个名字，头一个是主的，照这一幅的光和调子挑：

| 这一幅是 | style |
|---|---|
| 夜里、火光、暗处的对峙、烽火边 | `["anaxa", "fire"]` |
| 冷的夜、星光、雪、冰、灰雨 | `["fire", "anaxa"]` |
| 白天、麦田、原野、暖的日光 | `["wheat", "aglaea_card"]` |
| 明亮的白和金、王座厅、加冕、晨光 | `["aglaea_card", "wheat"]` |
| 正在打的那一下、带速度线的动作 | `["himeko_card", "anaxa"]` 或 `["himeko_card", "fire"]` |
| 夜里的城、灯、宴席、舞会 | `["sparkle", "fire"]` |
| 安静的屋里、两个人说话、一样东西的近景 | `["jingyuan", "wheat"]` |

一条主线的四幅别全用同一组。

### raw（血和伤）

用户定的：打过的仗画出打过的样子。场面里成年人身上有血、伤、烧伤、破衣裳的，在 text 里写出来，`raw` 写 true，照写的画。不写断肢、露骨、内脏，不写尸堆的特写。死了的人写成盖着斗篷躺着的、兵器插在旁边的。没打过的场面不硬添。

### 未满十八岁的人

任务单里标了每个人在这一段的年纪。未满十八岁的照常入画，穿戴整齐，可以在场，可是不画他身上的伤口和血，不画他挨打、受折磨、被杀的那一下。这一幅里只要有未满十八岁的人受了伤，就换一个瞬间画（那一下以前，或者他已经站起来以后）。这一纪的戏里孩子多（门洞里的篮子、灰雨那一夜、献祭台上那六个孩子、魇镜幻都的一千一百零三个孩子），一律照这一条：画他们被救下的那一瞬、站在火边、被领回床边，不画他们受苦的那一刻。

### 这个世界和这一纪的规矩

- 西幻，中世纪欧洲打底，剑与魔法，JRPG，高魔。不写东亚的衣裳、屋檐、纹样，不写现代的东西。
- 长垒：一道白石的城墙，墙上一座一座段城，墙西是西陆，墙东是东陆。夜里白墙自己泛一层淡淡的光。
- 火器：这一纪的铳枪是施法的家什（一根带晶匣、身上刻着回路的长管，打出去的是术，不是铅弹），约 40 年以后才有，多半在上城贵族和新朝的兵手里。黑耀的单发火药枪 862 年以后才有，只在黑耀那一边。别的时候不写 gun、rifle、musket。
- 这一纪的东西什么时候有，照源稿那一幕写了什么为准，别提前画：
  - 发条机兵（人形或履带，背上一把上弦的钥匙）头三十年还在，30 年最后一列走进炉口打成犁，往后只剩死域边上跪着的野机兵和一台倒下的擎天级。
  - 星纱列车在墙后的轨上跑。沉了的浮空塔、坠落的天城是纷争纪留下来的残骸。
  - 黑耀（862 年以后）：烬灭之都、法碑、七城、界碑（白石和黑曜石背靠背拿山铜铆着）、射界里的麦、渊月长廊（地底下的铁道）。
  - 新朝（668 年以后）：公开账碑（一溜山铜板）、凯撒法庭、黎明日。
- 魔族：生着角，各系样子不一样（炎角的角上有火，白骸露一截骨，夜翼背上有翼，深潮有鳃和鳞，轰狱是高大的巨魔和牛魔，梦魇、绯宴……），照源稿和任务单里的英文资料写。他们是人，不画成怪物。
- 巴尔缇娜（灰雨魔女、灰之魔女、魔王）：灰银长发，金色的眼睛，冷白的皮肤，额角一粒红，照立绘。索恩薇娅·里德：深金棕偏旧铜色的头发，浅金的眼睛，照立绘，手里是一把河里捡来的旧剑（挽昼）。
- 魔神（九尊，这一纪 661 年死了六尊，余下三尊 720、790、851 年一尊接一尊死）：高座上降下来的庞然大物，照任务单给的显像和史诗战的图。倒下的魔神写成看得见的结果（残火在灰底下暗着，一张嘴张着什么也不往里送）。
- 七神这一纪不现身，不画神的样子。那个不说名字的女人（常来雨城的那一位）：朴素，高个子，短发，洗白了的旧军大氅，手里什么也不拿，写成背影或者远处的侧影，不画神光，不写 god、goddess。
- 那一位恶神、四位执政不入画。
- 不画月亮和月牙，text 里别出现 moon、crescent。弯的角、牙、弓、弧光也别写得像一弯月。
- 画里不写字。旗、碑、册子、账碑上的字写成 marks 或者不写。

### name（中文，玩家看得见）

两到四个汉字，取这一拍里的一样东西、一个地方加一个时刻：空鞍、那一声、白线之晨、火冠、雪仓、最后一环、鸦落、断刃。

- 不用口语半句，不直接拿一句台词当名字，不用“之战、对决、决战、觉醒、羁绊、命运、绝望、希望”这类大词，不带月相字。
- 一页里的几个名字别一个构词法，别跟主线各幕的标题重样，别跟页名、主线名、任务名重样。
- 先用源稿里现成的叫法（碑上的字、歌里的词常常就是）。

## 五、死期死因（fates）

- 谁要写：这一页的旅伴和相遇的人里，死在这一段剧情里的。说的是主线各幕到收束里讲到的死（连同收束紧跟着的那几个月），和主线的默认收束里明着讲到的横死。在这一段剧情里下落成谜的也写，加一栏 `"label": "下落两说"` 或 `"下落不明"`。
- 不写的：活过这一段、几十年以后老死病死的（一页的年份跨几十到三百年，不能照“死在这一页的年份以内”算），往后才离开、才不见的。这些人的下场页上的档案里本来就有全文。
- `when` 写年份和月份，照源稿（山铜纪某年某月）。`where` 一个短地名。`how` 两三句，只搬源稿里的事，口气照源稿平实的叙述。
- 不写给模型看的话（玩家、AI、裁定、照某条），不加评语。是谁不点破的人不揭他的底。未满十八岁的只写结果和后来，不写伤口和血。
- 标点：不用破折号、分号、省略号、感叹号。引语用中文弯引号。
- 魔神不写进 fates（祂们的陨落在页上另有地方）。传奇也不写进 fates（传奇那一栏另有殁于这一段的一句）。

## 六、死的那一刻（deaths）

- 只给旅伴（任务单“旅伴”那一栏的人）里死在这一段剧情里的（口径同上一节）。一人一幅，键 `pN_d_<立绘键下划线后面那一截>`，`death` 写中文名（跟任务单上的名字一字不差），`age` 写他死的时候几岁（照源稿算），别的栏跟节点原画一样。
- 画他最后站着的那一下，或者那一下刚过去的一瞬，照源稿的下场。是这个人一生的定格，不是尸体，不画躺着的死人。
- 成年人可以 `raw: true`，血、伤、烧伤照写的画。
- 死的时候未满十八岁的：`"minor": true`，`raw` 不写。不画他受伤、被杀、倒下。改画他做那件事以前最后一个完好的瞬间，或者一幅空镜，只有他留下的那一样东西和那个地方，画面里没有他的身体。
- 死的时候十四岁以下的不出图，在 `notes` 里写一句。
- 他最后被人看见的那一拍要是已经是某一幅节点原画，不另出，写 `{"key": "pN_d_xxx", "death": "人名", "name": "…", "same": "那一幅节点的键", "age": 21}`。

## 七、自查

交以前跑（在仓库根上）：

```bash
python -I -X utf8 底稿/门面/小样_山铜纪书/scenes/check_scenes.py pN
```

报的错都要改掉。再自己过一遍：
