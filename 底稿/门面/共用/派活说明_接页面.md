# 派活说明：把一本书的页面接上世界之书、卡片、剧透开关、小地图（11-15 拼装那一轮）

月银纪那一本（`底稿/门面/小样_月银纪书/index.html`）11-15 做了“介绍页收尾”那一套，用户看了回可以，叫另外三本照做。你只改派给你的那一本的 `index.html`（和它的走查脚本），别的书、共用/、卡片、源稿都不动，不提交 git。

## 先读

1. `底稿/门面/共用/codex.js` 开头那一段注释（世界之书抽成四本书共用的一份，API 是 `Codex.init / open / close / isOpen / mini / miniClick / syncSpoil / state`）。
2. `底稿/门面/共用/月银纪_介绍页收尾改了什么.diff`：月银纪那一本从“收尾以前”（index_v5.html）到现在（index.html）的全部改动，照它在你那一本里做同样的事。
3. 月银纪现在的 `index.html`：找 `Codex.`、`SPOIL`、`cardHTML`、`fateHTML`、`miniHTML`、`window.SHELL`、`#toTable`、`crossOrigin` 这几处看写法。
4. 你那一本的 `index.html` 和 `act_all.mjs`（全书走查）。时代页那一套代码当初是从月银纪搬的，函数名大体对得上（lineHTML、profHTML、openEra、openProf……），各本有自己的出入，照你那一本的实际写法改。

## 要做的（每一样照月银纪的做法）

1. **载共用的那两份。** 主脚本前头加一段（跟月银纪一字一样）：
   ```html
   <script>
   window.A = window.A || ((p) => p);
   document.write('<link rel="stylesheet" href="' + A('common/codex.css') + '"><script src="' + A('common/codex.js') + '"><\/script>');
   </script>
   ```
   共用的那一份已经拷进你那一本的目录里了，叫 `common/`（`底稿/门面/共用/sync.py` 拷的，别手改拷出来的那一份）。
2. **入口钮。** 右上角 `#wbBtn`（样式照月银纪那几条），图用 `common/assets/ui/emblem_<卷>.webp`（纷争纪 strife、山铜纪 bronze、迷宫纪 maze），底下小字“世界之书”。点了 `Codex.open('<卷>', '')`。时代页或档案开着的时候藏起来。要是右上角已经有别的钮，挪开不打架。
3. **Codex.init。** 照月银纪那一块：`vol` 写你那一卷，`host` 写撑满屏的那一层，`A: window.A`，`spoil/setSpoil`，`onOpen/onClose` 里把这本书自己的动画和手势停住（月银纪是 `wbOpen` 那个变量，凡是判 `pageOpen >= 0` 就不动的地方都加上它；世界之书开着的时候 Esc 归世界之书管，书里的键盘处理直接返回），`onEra(vol, id)`：是这一卷的就打开那个时代页，别的卷交给 `otherBook(vol, id)`（照抄月银纪）。
4. **时代页“这一带”。** 换成 `Codex.mini('<卷>', e.id, e.places)`，时代页的点击处理里加 `if (Codex.miniClick(ev, 这个时代的 id)) return;`。原来那一串地名和“在哪里”的字去掉（挪进地图了）。这个时代没有 places 的（纷争纪有几张牌是空的）就不出这一栏。
5. **卡片。** 多载一份 `data/cards.json`（`{时代 id: {lines: {主线名: {hook, open}}, people: {名字: {kind, head, tags, traits, bg, stars, meet, hook, line}}}}`，`共用/prep_cards.py` 出的，眼下子任务还在写，只有一部分时代有，没有的照旧用原来那一套）：
   - 主线：有卡片的，钩子只放卡片上那一句（空串就不放），睁眼的地方用卡片上的；各幕只留幕名配节点原画，幕间那一段的字不放；“没有你的那一版”加 `spoil` 类。
   - 旅伴和相遇的档案：有卡片的走 `cardHTML`（照月银纪：头一行和标签、性格词、身份与背景、能力、初见、相处、一句台词、表情九格），立绘四套照留；下场、死期死因、死的那一刻收进 `fateHTML`（上头一个剧透开关）。没有卡片的人照旧。
   - 传奇的档案不动。纷争纪的“传奇之陨”那一栏和传奇档案里的陨落照留，不进剧透开关（那是史书上唱的事）。
   - 名单上的种族用 `raceShow`（写着“藏”的不显示）。
6. **剧透开关。** 整本书一个 `SPOIL`，默认关：`#view`（或你那一本撑满屏的那一层）切 `spoil-on` 类，样式照月银纪那一段（`.spl`、`.spoil`）；时代页“从这里进”上头一个开关，档案里“没有你的那一版”上头一个；关着的时候看不到主线的没有你的那一版、旅伴和相遇的死期死因和死的那一刻（那几幅也不进原画那一串）。切了以后时代页和开着的档案原地重画（滚动位置留着），再叫 `Codex.syncSpoil()`。
7. **各本自己的。**
   - 山铜纪：碑照留。迷宫纪：委托单只留正面（委托人的话），单头、背面、结案栏收起来不显示；“这一段的迷宫”“冒险团”一样只留头一句。灾祸、首领那一栏去掉“在哪里”那一句。
8. **装在牌桌外壳里。** 照月银纪：`window.SHELL` 在的时候，“从这里进”不出原来那张“还没接上”的小纸，改成 `SHELL.post({ t: 'enter', book: '<卷>', era: '<纪名>', at: 时代 id, title: 时代名, line: 主线名, year: 年份, ti: 题 })`；左上角加 `#toTable`“回到牌桌”（`SHELL.post({ t: 'table' })`）；听 `message`：`{aldran: 1, t: 'open', at}` 打开那个时代页；启动时 `SHELL.at` 有值就打开那一页。纷争纪第二十二张（玩家自己报年份那一张）和山铜纪的无字碑、迷宫纪井底的 1001 年，也照这个发 `enter`（`at` 写 `'free'`、`'free'`、`'1001'`，`line` 空着）。
9. **图要进 WebGL 或画布的，载图以前加 `img.crossOrigin = 'anonymous'`**（装在外壳里是从图床载）。只是 `<img>` 显示或者背景图的不用加。
10. **走查。** `act_all.mjs` 改成先开剧透再走（照月银纪的 `act_all.mjs`、`act_cg.mjs`），数（节点原画、档案、死期、死的那一刻、碑……）要跟改以前一样；另照月银纪的 `act_wb.mjs` 写一支你那一本的 `act_wb.mjs`：入口、卷页、地图各年代、点一处出小卡、从地图进时代页、时代页和档案里的剧透开关、小地图翻进地图、一张卡片档案。电脑 1920×945 和手机 390×844 各走一遍，不许有报错和载不下来的文件。

## 怎么验

- 本地服务器已经起着：纷争纪 http://localhost:8769/ ，山铜纪 http://localhost:8770/ ，迷宫纪 http://localhost:8771/ （页面是 `local.html?skip=1`，迷宫纪是 `?sim=1`，看你那一本 act_all.mjs 里写的）。
- 无头 Chrome 各用各的端口，别用别人的：纷争纪 9341，山铜纪 9336，迷宫纪 9337。没起就自己起（照下面这一句，换端口和临时目录；用完别关，主会话还要用）：
  `"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --hide-scrollbars --no-first-run --remote-debugging-port=<端口> --user-data-dir=<临时目录> --window-size=1920,945 --enable-unsafe-swiftshader about:blank &`
  走查脚本里的端口照这个改（纷争纪原来写的 9335 是月银纪在用的，改成 9341）。
- 改以前先把 `index.html` 拷一份 `index_收尾前.html` 留底。
- 这台机器 Bash 的 heredoc 会把连着的两个反斜杠吞成一个，带反斜杠的脚本用 Write 工具写成文件再跑，别用 heredoc。改 index.html 用 Edit 工具或者写成 .py 文件跑。
