# 门面的背景音乐：底子和探针（11-26 夜）

用户定了曲子全用 Suno 出，这一回先把放音乐的底子做好，再拿一段本机合的探针音试日里、风月的介绍页沙箱里出不出得了声。**外壳推了图床、预取三遍都是 0、指针挪到第 35 代**（front_shell 7524fbcf7f，指针 7aa51956f4）。没提交 git。

## 做了什么

- **曲目表** `小样_外壳/data/bgm.json`：场景到地址。gate、table（死之神殿）、moon、strife、bronze、maze、now（五本书）、library（大图书馆）、build（建档），眼下都指着 `assets/bgm/probe.mp3`；另有 `vol`（默认音量 0.5）、`fade`（换曲淡入淡出两秒）。Suno 的曲子到了，放进 `小样_外壳/assets/bgm/`、改这一份的地址，推外壳、挪指针就行，卡不用动。
- **放音乐的那一段**接在 `小样_外壳/shell.js` 末尾（`// <bgm>` 到 `// </bgm>`），样式接在 `shell.css` 末尾（`/* <bgm> */`），源稿是本目录的 `bgm_shell.js`、`bgm_shell.css`（改源稿，再照标记换进去）。放在 shell.js 里没有另开 bgm.js，是因为 `deploy_front.py` 的 front_shell 只收外壳那几个固定的文件。
  - 两个 `<audio>` 轮着用，换场景两秒交叉淡入淡出。场景照外壳自己的状态每 0.4 秒看一回（`Shell.state` 的 cur、build，body 上大图书馆开着的标记），翻开哪一本书换哪一首，合上回牌桌换回去，进大图书馆、建档也换。
  - 曲子不预载（`preload="none"`），用到才取；取不到挨个换镜像。
- **起声**（浏览器要用户的手势）：载入页开门那一下（`window.__gateOpened`，点了跳过也走这一下）；没有载入页的（地址带 `?nogate`、减少动态效果、载入页出错拆掉了），第一次点页面任何地方。点右上角的小喇叭也算起声。浏览器要是还是不许（`NotAllowedError`），算没起声，下一回点页面再起。iOS 上一个 `<audio>` 要在手势里亲手放过一回往后才放得出来，所以起声那一下两个 `<audio>` 都放一下（第二个静音放一下就停）。
- **小喇叭**：右上角大图书馆钮的正下方（放在它左边会压住书里的“图鉴”钮，试过）。点一下静音，再点放出来。没有本地存储，只管这一回打开。书、建档开着也在。
- **测用的状态**：地址带 `?bgmtest`，或者三秒里连点喇叭五下，喇叭底下出一行绿字：起没起声、怎么起的、play() 成没成（没成写错误名）、在放还是停着、放到第几秒、场景、音量、哪个文件、换没换过镜像。再连点五下收起来。play() 失败的错误名同时记在 `window.__bgmErr`；`window.__bgm.state()` 看全部。日里、风月的介绍页是 srcdoc，地址带不了参数，在平台上看状态只能连点五下。
- **探针音** `小样_外壳/assets/bgm/probe.mp3`（95KB，8 秒一圈）：本目录 `make_probe.py` 拿 numpy 合的，D 大调两组上行的钟声琶音，正弦加两个泛音，底下一层很轻的长音，卷一段衰减噪声当混响，首尾淡入淡出，一圈接一圈不咔哒，峰值 -6.5dB。

## 用户在平台上怎么测

1. 日里：打开这张卡的介绍页（卡不用重打，现在卡里的薄壳认指针，会取到第 35 代的外壳）。等载入页走到门口，点“推开门扉”（或者右下角跳过）。**听到一串清亮的钟声琶音，八秒一圈循环，就算通了**；翻开一本书、合上，声音不断（眼下每一处都是同一段，换的时候听不出来，正常）。右上角大图书馆钮底下那个小喇叭点一下声音停、再点回来。
2. 没听到：先看手机是不是静音键开着、媒体音量是不是零（iOS 的静音拨片会让网页的声音也没了）。然后连点小喇叭五下，看喇叭底下的绿字：
   - 写“play()：成了 · 在放 N秒”、秒数在走，可是没声：是手机的音量或静音拨片，或者平台把介绍页的声音整个关了。
   - 写“没成 NotAllowedError”：平台的沙箱不许介绍页放声（iframe 没给 autoplay 的权限，点了也不行）。截图发回来。
   - 写“没成 NotSupportedError”或者“MediaError”：取不到或者解不了那段 mp3（镜像不通），截图发回来。
   - 写“起声：还没”：开门那一下没接到，点一下页面空白处或者点喇叭再看。
3. 风月：五张卡的简介页也是这一套薄壳（`底稿/风月版/fy_shell_descr.py` 照 `make_thin.py` 出的，认指针），打开简介页一样取到第 35 代的外壳，测法同上。
4. 手机、电脑各点一回（iOS Safari、安卓 Chrome、电脑 Chrome 各一回最好）。

# 交互音效（11-26 夜，做好了、录好了，等用户听；没推图床、没提交）

用户认了背景音乐那一版（“可以”），接着加交互音效。只配下面这些时刻，悬停、普通按钮、滚动都不配。

| 时刻 | 名字 | 声音 | 在哪接的 |
|---|---|---|---|
| 推开门扉 | door | 低沉的门轴：低频锯齿波慢慢弯一下，加一点摩擦的噪声，带厅里的混响（音乐起声那一下一起） | `shell.js` 里 `window.__gateOpened` |
| 牌桌：发牌落下 | deal | 一下纸拍（滤过的噪声加一点低音），四张四声 | 外壳 `index.html` 的 `leave()` |
| 牌桌：翻牌 | flip | 嗖一下，末了一拍（四张牌烧开成四纪，一张一声） | `ignite()` |
| 牌桌：选中一本书 | pick | D6、F#6、A6 三个亮的钟音叠着，短混响 | `pick()` |
| 书：翻开 | book_open | 一口气加一串上行的琶音（D5 F#5 A5 D6） | `shell.js` 的 `openBook()` |
| 书：翻页（换时代页） | page | 纸页翻过去（带通滤波从高往低扫，纸面抖一抖），末了一下 | 五本书的 `openEra()`；此刻那一本是 `openLine()`、`showLand()` |
| 书：档案展开 | arch_open | 纸面滑开，带一点光 | 五本书的 `openProf()` |
| 书：档案合上 | arch_close | 一下闷的 | `closeProf()`；此刻那一本是关档案那一格的 `closeDlg()` |
| 书：换衣着 | cloth | 布料一抖（颗粒感的噪声） | 档案里衣着那一排钮；此刻那一本是 `setOutfit()` |
| 书：剧透开关 | spoil | 木头轻扣一声 | `setSpoil()`（真的换了才响） |
| 大图书馆：推门进厅 | hall | 厚门一推、厅里回一下（很低） | `common/library.js` 的 `open()`、从圆厅进一厅的 `showWing()` |
| 大图书馆：从架上抽书 | draw_book | 书脊擦过、落在手里一下 | `library.js` 的 `openBook()` |
| 建档：牌翻过来 | bcard | 轻的翻牌 | `shell.js` 的 `dealIn()`（每一步的牌滑进来时一声） |
| 建档：掷骰子 | dice | 七下碰撞，越碰越轻 | `rollDice()` |
| 建档：命星落下 | star | 星铃：D6、A6、F#6 三个钟音错开，泛音照钟的不和谐比（2.76、5.4），混响长一点 | `drawStars()`（进命星那一步头一回发、再抽一回都响；三叠一起发只响一声） |
| 建档：铸印 | seal | 印压下去一声闷响（62Hz 加噪声的闷击） | `mint()` 里印落下那一刻 |

**声音**：全用本机合成（`make_sfx.py`，numpy 合、ffmpeg 压 mp3 80kbps），没从网上下任何音效包。声响类用滤过的噪声（纸页、布料、木头、石头、骰子），带音高的用正弦叠泛音加短混响，都在 D 大调上下，跟背景音乐那段探针一个调。每个 0.09 到 1.8 秒，1.6 到 18KB，十六个合计 120KB，在 `小样_外壳/assets/sfx/`。量过频谱：重心 280 到 3900Hz，6kHz 以上的成分至多一成半（布料最亮，已经压低），没有刺耳的高频。都归一到同一个峰值（-3dB），轻重在 `data/sfx.json` 的 gain 里调（0.55 到 1.0），再乘总音量 0.35。

**外壳那头**（源稿 `bgm_shell.js`，接在 `shell.js` 末尾 `<bgm>` 那一段里）：
- 第零层齐了就先开一个（还静着的）AudioContext，把十六个音效 fetch 下来解成缓冲（三路并着取，取不到换镜像）。门轴那一声要在开门那一下就有，所以不等开门再载。
- 起声那一下（开门、跳过、没有载入页时第一次点页面、点喇叭）在手势里 resume AudioContext，再放一个空缓冲（iOS 要这一下才算解开）。
- `window.__sfx(名)` 放一声：同一声 150 毫秒里来几回只响一回（三叠命星一起发那种）。
- 喇叭钮跟背景音乐共用：静音全静。背景音乐 `off`（现在线上就是关着的）不碍音效；音效另有总开关 `data/sfx.json` 的 `sfx_off`（默认 false）。背景音乐、音效都关着喇叭才不露；只有音效开着的时候，喇叭只管音效。
- 测用状态（`?bgmtest` 或连点喇叭五下）末尾多一段“音效：running 16/16”。`window.__bgm.state().sfx` 看 AudioContext 的状态、载了几个、报什么错；`window.__sfxLog` 记每一声放的时刻。

**书里的事**：书在嵌套的 iframe 里。装书时外壳塞进书里的那一小段（`shell.js` 的 `preamble`）多给一个 `SFX(名)`：发 `{aldran:1, t:'sfx', n}` 给外壳，外壳放（书里不另开声音，静音开关、缓冲都只有外壳一份）。`SFX` 只认真人点出来的那一下（`window.event` 是真的），书自己初始化、剧透切了以后原地重画、换过的衣着照留这些不响。五本书里加的那几句是 `hook_sfx.py` 加的（认 `/*sfx*/` 记号，重跑不会重复加），书单独打开（没有外壳）时没有 `SFX`，那几句什么也不做。大图书馆在外壳里调 `__sfx`、在书里调 `SFX`。

## 本地验过的

- 默认自动播放策略的 Chrome：点以前 AudioContext 是 suspended、放不出（`__sfx` 不响），点了页面变 running、十六个都载好、放得出；点喇叭静音以后不再放。不要手势的 Chrome 一样。
- 背景音乐那一套跟着重验了一遍（`?bgmtest=swap`）：开门起声、翻书换曲、合书换回都对。
- 走一遍（`walk_sfx.mjs`）：开门、牌桌发牌翻牌、选月银纪、进书、沿墙走、翻页、拨剧透、开档案、换衣着、合上、回墙前、大图书馆（书里那一枚）进厅、抽书、再翻一页、进建档（报的是迷宫纪 990 年：月银纪那时候没有面板，建档里没有命星那一步）、掷骰子、命星、铸印，二十九声都对得上画面（逐个时刻截了帧核过）。

## 带声的录像

`底稿/门面/载入页/音乐/录像_音效走一遍_手机.mp4`（390×844，81 秒）。无头 Chrome 没有声卡，录不到真的声音：画面照旧录屏，外壳把每一声放的时刻记下来（`__sfxLog`），`mix_sfx.py` 拿同一份音效文件、同样的轻重，照时刻混成音轨合进去，所以听到的就是页面上会放的那几声、在那几个时刻。视频里音效整体抬了 2.2 倍（网页里是 0.35 的总音量，单听偏小），彼此的轻重不变。背景音乐线上关着，视频里也没有。中间有几段等书载入、建档换步的空当，没剪。
