# 门面剧情润色｜派活说明（11-21）

用户看了样稿第三稿，回“照这样铺开”。你写这一份里每条主线门面上的三样：**任务介绍一段、每一幕的幕名、每一幕一句描述**。只进门面（介绍页四本书），卡里的主线不动，跑卡的模型看不到这些字。

## 先读

1. 根目录 `门面剧情润色_方向稿.md` 第二节（照原神、崩铁的写法，尤其“幕名要当钩子”那一段）和第四节（样稿四条，第三稿，用户认了的口气）。这四条是尺子，写之前对着读两遍。
2. 你那一份材料（主会话给的路径）：每条主线门面上现在的样子（标题、钩子引语、睁眼的地方、现在的幕行、没有你的那一版），后面跟着页上主线全文。主线全文从头读到尾再动笔，事实、人名、地名、数字照页上，不另起有名有姓的新东西。

## 写什么

**任务介绍**（intro）。两三句，五十到一百二十字。照崩铁章前的引子：可以拿一句台词开头（钩子引语、或者主线里哪个人的一句话，用“”），交代这一趟开头落在什么处境里，末一句留一个口子。门面上它替掉钩子引语那一行，所以钩子好用就把它放进介绍里。口气可以带一点寓言、咏唱的味道，可句子要落在具体的人和东西上。

**幕名**（name）。现在的幕行一行一个，次序、标签（一幕、二幕、三幕、幕间、收束……）照抄。幕名不是这一幕的摘要，是这一幕里最叫人想问“为什么”的那一下：
- 话说一半、反常的组合、一句台词里藏着事、一条禁令或规矩、点出代价不说结果、一个时刻、一个具体得奇怪的数或东西（城门边的第十七道刻痕、第一万一千零一次）。
- 不剧透这一幕的结果，不说谁死、谁赢、真相是什么。
- 一条主线的几个幕名连起来读，像一串越收越紧的问题。收束那一个也是钩子，不写成“尾声”“余波”。
- 原名（两个字的工作标签，风声、验血、口子）真有钩子的才留，多数要换。
- 两到十六个字。句式掺着用：一句话、名词短语、X与Y的Z、两样并排。同一条主线里四个幕名不用同一种句式，同一份里相邻两条主线也错开，别一份里排满“X的Y”或者排满“……的时候”。
- 不收句号，不带日期（日期和时长门面上会照原来的留在幕名后头当小字）。

**描述**（desc）。一幕一句到两句，二十到六十字。照原神子任务的描述：平平交代这一幕开头在做什么、要去哪、碰上了什么，末一句留悬念。不写结局，不抒情，不总结意义。可以对着幕名补一笔，让人更想点开。

**任务名**（task，只山铜纪、迷宫纪，可选）。门面标题上的【任务名】是 11-02 定的，大半好用，照留，JSON 里不写 task 这个键。只有真单薄、跟这一条对不上的，才写 task 提议一个新的，在备注里写为什么。月银纪、纷争纪的篇名和题不动，不写 task。

## 口径（卡面那一套，照守）

- 标点：用“”，，。？、。不用 ——、—、；、…、！、...、：、｜、「」、括号。原神的省略号我们不用，悬念靠句子本身。
- 禁词：学宫、客栈、朝廷、门客、时辰、掌柜、百官、丫头、宗门、长老、功法、镖局、一丝、一抹、不禁、威压、修为、登记、军令、条例、晋升；科技词（量子、熵、坐标、频率、能量、系统）；月相（新月、满月、残月、月牙、弦月、月亮、月光）。
- 东方语感、中式口语不用：龛、灶、长明灯、仪轨、会盟、诸侯、城主（写伯爵、领主）、诏书（敕令）、学塾、官道（大道）、佃户（佃农）、师门、长衫、庄子、伙计、街坊、爹娘（父母）、俺、啥、晌午、汉子、媳妇、闺女、江湖、武功、内力、银子铜钱（银币铜币）、磕头、师父徒弟（老师、学徒）、剑客（剑士）、米色茶色。
- 神用祂。那一位恶神不点名，四执政不出场。“营”少用。
- 不写“玩家”“AI”，可以用“你”，少用。也别写成你拦不下、救不下、改不了。
- 不用“不是……是……”的翻转句、三样并排、四字格成排、“那一X”的口癖。
- 典故顺手的时候用，一条主线至多一处，化在这个世界的东西里，不出现现实的人名地名，电影小说只借意象，不引原句。借了什么写进备注。
- 往大里写，这是高魔的世界，英雄传奇出手、神和魔神在场的那一幕，幕名和描述可以带出天地的反应。

## 交什么

1. 每个时代一份 JSON，写在 `底稿/门面/剧情润色/<纪>/<时代 id>.json`（纪是 月银纪、纷争纪、山铜纪、迷宫纪；时代 id 是材料里“## 时代 m07”那样的号）。时代里每条主线都要有，键是主线名，照材料里“### 主线｜”后面的原样抄：

```json
{
  "万兽·焚原": {
    "intro": "……",
    "acts": [
      {"tag": "一幕", "name": "城门边的第十七道刻痕", "desc": "……"},
      {"tag": "二幕", "name": "……", "desc": "……"}
    ]
  }
}
```

   UTF-8，用 Write 工具写，别用 shell 的 heredoc。
2. 一份备注 `底稿/门面/剧情润色/备注/<材料号>.md`：借了什么典、提议改的任务名和缘故、拿不准的（页上前后对不上的事实之类），没有就写没有。
3. 写完跑自查，问题要 0：`python -I -X utf8 底稿/门面/剧情润色/tools/check.py --file <你写的 json>`（一个一个跑）。幕名跟别份重了的只在主会话合起来查，你那份里自己别重。

样稿四条（月银纪 m07 万兽·焚原、纷争纪 s17 铁狼的年月·无名之柱、山铜纪 p4 黎明的年月·黎明篡位、迷宫纪 q1 探井的年月·寻人）用户认过，拿到这四条的照方向稿第四节原样抄进 JSON（标签对一下，幕行比四个多的补上），不重写。

做完回一句话：写了几个时代几条主线，自查几条问题，备注里有没有要主会话定的。不要把稿子贴回来。
