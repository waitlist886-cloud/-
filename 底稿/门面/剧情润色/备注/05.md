# 材料 05｜纷争纪 s10 到 s15（备注）

六个时代、十五条主线：s10 盾碑；s11 箭与冠的秤；s12 最后一垄、白鸢的天、无继之光；s13 空鞍的白马、第七座营垒、不熄火、锈花；s14 北归道、盐门、离地、塔与剑；s15 松开的锁链、射主。篇名和题没动，没写 task。check.py 逐份 0，合起来查纷争纪全纪也是 0。

## 借了什么典

没有借。纷争纪的题本身已经是翁法罗斯式的呼告，这一份的幕名全从页上的事、数和台词里取（“扔了盾的，今晚都活着”“下水的报船名，我数着”“你们烧的是石头，我们烧的是人”这类），没另外化用现实的典。

## 怎么取的

- 介绍：能用钩子引语的照放在开头（盾碑那一条换成殿里颂了一千年的祷词，北归道换成皇帝在楼梯上对卡蒂说的那句，塔与剑不放引语、从三国交冠写起，因为钩子引语是三幕高潮的原话）。
- 幕名：照派活说明不剧透结局，多取这一幕里的一句台词、一个数、一条规矩或一样反常的东西。几处有意前后呼应：北归道一幕的“上去吧，我扶着呢”，到三幕末皇帝自己扶梯说了同一句；最后一垄一幕“麦还青着”、收束“麦早黄了半个月”。
- 收束的描述都避开了谁死、谁赢，只写天亮以后看得见的一两样东西。

## 拿不准的、请主会话看一眼

1. s14 塔与剑二幕幕名“湖里多出来的十九颗星”：页上一幕写诺薇娅“把湖自己多出来的星刻在木板上”，二幕写她“把十九颗星一颗颗指给乌尔德看”，两处没明说是同一批，我照同一批写的。要是不是，改成“木板上的十九颗星”。
2. s14 离地的介绍用了材料“睁眼的地方”里的“三千四百块铅”，页上主线全文只写“满网的铅”。数是门面材料给的，页上没有，留着还是拿掉请定。
3. s12 白鸢的天收束的描述写“几十对翼折回来落在墙外的一处地方”，故意没说落进宽翼掉下去的地方，免得露底，读着略虚。
4. s13 锈花二幕幕名“骨头不开花”取自页上“身上只有铁扣开花，骨头不开”，跟本条钩子“热着的铁不开花”句式相近，是有意的呼应，嫌重了可以换成“两具高过烽塔的骨像”。

没有要改的任务名（纷争纪不写 task）。

## 第五稿（11-21 深夜）

十五条主线六十一个幕名全部重看过，换了五十八个，照留三个：盾碑三幕“退至我身后”（举盾者的原话）、白鸢的天三幕“不打，只看”（规矩，也是钩子）、塔与剑收束“四季不谢的王冠”。介绍十五段里改了十二段（数压到至多一处，几段换了开头的引语），描述删了多余的数，少数几句补了一笔落点。check.py 逐份 0，纷争纪全纪合查 0。

幕名的句式在对仗、X与Y的Z、名词短语、一句话（台词或问句）之间掺着排，同一时代相邻两条错开（空鞍的白马和第七座营垒原先撞成同一套，第七座一幕改成“当盐海走上陆地”；不熄火和锈花一幕原先都是对仗，锈花改成名词短语）。带数的幕名只有不熄火一幕“一生之路，八日行尽”，八天走完一辈子的路是这一条的奇观。

### 几处照页上取的、借了的

- 盾碑收束“盾碑之下，祷言未终”：照裁定锁“神的奇迹熄了，祷告还在”，不点碑沿改过的那半句，免得收束直接说出神倒下。
- 无继之光收束“破晓独自归来”：破晓是剑名，也是黎明，皇帝没回来、剑回来了，双关。
- 最后一垄收束“麦田先于信使知晓”：取页上“王城里的人说，麦早就告诉他们了”。
- 射主三幕“万风俱寂，箭转其身”：取篇描述“祂的箭转过了身”和三幕风一齐停。
- 松开的锁链三幕“这一碗，是谁的”、北归道收束“南门的灯，还亮着吗”、塔与剑三幕“剑在这里，拿起来”：都是页上人物的原话，略去或加了标点。
- 盐门收束“唱一句，停一下”：取收束里水手唱倒潮的样子。
- 没有另借现实的典。

### 拿不准的

1. 离地的介绍上一轮用了材料“睁眼的地方”里的“三千四百块铅”，这一稿拿掉了，改写天分三层、中层还空着（照时段总纲），上一节第 2 条可以不用定了。
2. 塔与剑的介绍开头换成伊希莱的“冠是要拿人去填的。”（一幕原话），原来没有引语。钩子引语“不问你姓什么”是三幕高潮的原话，仍不放进介绍。
3. 空鞍的白马收束幕名“白马回首”、描述写白马南飞回头，诉状那一句留着，白烛案十七页和一个准字没写进门面，嫌收束轻可以把描述换回“罗克兰家告到圣堂，诉状和辩词厚厚一叠，判词只有一个字”。
4. 白鸢的天收束“天空两端，各有归人”说的是狮鹫落回塔顶、翼群折回抬走领头的，有一点露底（领头的倒下了），比原来“折回来的几十对翼”重一分，嫌露可以换“折返的翼”。

没有要主会话定的大事，上面四条都是可留可换。
