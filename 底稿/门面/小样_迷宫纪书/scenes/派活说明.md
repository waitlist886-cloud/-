# 迷宫纪的书·壁画场面稿｜派活说明

2026-11-15。给写场面的人看的。你写的东西不直接出图，交一份 JSON，主会话审过以后照它出图。

## 一、这是什么

《奥尔德兰的旅印》是一张西幻 JRPG 的角色卡，迷宫纪前传是它的第四纪的头一千年（迷宫纪2到1000年）：947年归寂月最后一夜长垒底下地开了，口子往下长成一口井（阿卡迪亚大迷宫），冒险者公会从佣兵行会改出来，人一代一代往下走，探井、共约、繁荣、深井、黑潮、垂暮，六页，四十二条主线。

门面（介绍页）给每一纪做一本书。迷宫纪这一本是一口往下的井：一个年代一圈拱廊，最外一圈是地开那一夜，往里（往下）是六页，最里一小圈是1001年今天。镜头往下走就是往后的年月。每一条主线在它那一圈的墙上挂一幅壁画，点开进那一条主线。

画风照门面那一张迷宫纪主画：`底稿/状态栏/comfy/out/门面_主画_11-10/k4.png`（小图 `看_k4.jpg`），动笔前先看一眼。平涂的装饰插画，形大而简，靛蓝、石板蓝、淡紫的石头，暖色只给灯、火和井底的光，人很小，大东西画成一层一层的浅色剪影。画法、颜色、纸纹由出图脚本管，你管的是画什么。

## 二、先读什么

1. 任务单 `任务单/主线.json`：你那几页每条主线的标题、源稿行号（from 到 to）、题、章、开局头一句、有几幕。
2. 源稿里那几条主线（“## 迷宫纪·主线｜……”那一节，钩子、开局、世道、一幕一拍一条、收束、默认收束）。照行号跳着读，一条一条读完。
3. 要画到的人：同一页里他的旅伴条（“## 旅途同行：名（迷宫纪·段名）”）或人物条（标题以“（人物）”收尾）的外貌、装束，只取看得出来的样子（发色、角、翼、耳、身量、衣服的颜色和样子）。
4. 写地开那一夜的那一份另读 `山铜纪/山铜纪时段_六_麦的年月.md` 里“前夜”那一条主线，和前传第一页“迷宫纪·委托｜寻人”那一张。

## 三、画哪一下

- 一条主线一幅。挑这一条最认得出的那一下：钩子说的那件事，或者高潮的那一个画面，看一眼就知道是这一条。不必是打得最凶的那一刻，可以是那一刻前后的一个定格。
- 壁画挂在井里一圈拱廊的墙上，人是远远看过去的，要一眼读得出：一个主体，放在画面中间偏下，大的形状，前后两三层，人很小（跟 k4 里一样小），不画脸的细节，一幅里有名有姓的人至多五六个，人多的场面画成一片人的形状。
- 画在一个顶上是半圆拱的框里，上面两个角会被拱遮掉，要紧的东西别放在上面两个角。
- 大东西（楼层主、潮、门、龙、塔、井本身）可以画大，照 k4 那样画成一层一层的浅色剪影，形状写清楚。
- 时代要对：那一年还没有的东西不画。升降架约350年起，光柱约440年起，旅印七阶和面板420年起，雾门约600年起，星环天上那一圈环一节一节往上修，黑潮850年起。拿不准就不画那样东西。

## 四、不画什么

- 不画月亮、月牙，天上也不要像月牙的弯东西（弯角、弧光贴着天会像月牙，角写成短而直的）。
- 不画字、字母、数字、旗上的纹样写简单的形状。
- 不画十字架和十字纹，不画东方的东西（翘檐、祥云、灯笼、盘扣），这是西幻。
- 不画伤口和血的特写。不满十八岁的人不受伤，不画被杀的那一下。死了的人画成倒下的旗、熄了的灯、空着的位子这一类，或者画死以前站着的那一刻。
- 七神不露脸，画成光、背影或者祂的东西；四执政不画；那一位恶神不画，也不点名。
- 魔族照这几句写：night-wing 是人一样大小的人，背上一对大翼，多半是膜翼，不是龙也不是蝙蝠；fire-horn 是头上长角的人，角可以发光；bone folk 是高个子、骨白皮肤的活人，不是骷髅。别的族照源稿写。

## 五、交什么

一页一个文件 `scenes/qN.json`（UTF-8，不带 BOM），地开那一夜写进 `scenes/q0.json`：

```json
{
  "page": "q3",
  "murals": [
    {
      "key": "q3_a",
      "line": "繁荣的年月·第七次大迷宫潮",
      "task": "【……】（照题那一行方括号里的任务名抄）",
      "name": "两到四个汉字，这一幅的名字",
      "text": "Scene: ……（英文，一百二十到二百个词）",
      "light": "一句英文：这一幅的主光从哪里来、什么颜色，暗部什么颜色",
      "note": "中文：选的是哪一拍，源稿第几行，拿不准的地方"
    }
  ],
  "notes": ["拿不准、要主会话定的事，一条一句"]
}
```

- 键照这一页主线在任务单里的次序排字母：头一条 a，第二条 b，依次往下。地开那一夜的键是 q0_a，line 写“地开那一夜”，task 写“【地开】”。
- text 用英文写，像对一个画家交代：画面里有什么，在哪儿，什么样子，人的发色、衣服颜色、角和翼，大东西的形状，前后几层。不写画法和颜色风格（脚本统一管），不写“mural”“painting”这种词以外的作画指令，不写镜头术语以外的废话。
- 名字：四十几幅不重名，跟这一纪的主线名、任务名不一样，取画面里那一样东西或者那一下。
- 没有的栏不写空串，整栏不写。

## 六、交之前自查

- 每条主线都有一幅，键、line、task 跟任务单对得上。
- 读一遍 text，有没有第四节不许的东西，有没有那一年还没有的东西。
- JSON 解析得过（`python -I -X utf8 -c "import json;json.load(open('scenes/qN.json',encoding='utf-8'))"`）。
- 只写你那几个文件，仓库别的文件一个字不动，不提交。
