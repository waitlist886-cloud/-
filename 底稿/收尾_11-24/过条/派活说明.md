## 二、两类人有什么不一样

- **凡世至强（传奇）。** 一条一人，能力在【能力｜名（传奇）】那一块，`- 天赋【X】：……`、`- 被动【X】：……`、`- 技艺【X】｜……`，后头是 `- 随身【X】`。条目从【调用】写的那一年起醒，管到他死或者传给下一段。他手里的技艺多半是补完的那一版（Epic 补到 Legend），或者跨进神域的那一版（Unique），也有一辈子没补完、还是 Epic 的（希尔妲、费格、托卡）。凝名不等于技艺升档，传奇的分量靠伟业，不靠技艺的档。
- **人物（相遇）。** 大人、老人，有自己走完的一段来路，往后还能长。写法不齐：单人的条里一行 `- 本事：……` 或 `- 位阶与本事：……`，几个人合写的条里一人一行 `- 名｜本事。天赋【X】……技艺【Y】……`，也有像旅伴能力行那样的 `- 命星：Special【X】(…)｜Passive【Y】(…)｜Art【Z】(…)`。不少是名字凝住的英雄、地方上的传奇（各页「X的年月里凝名的几位」）和凯撒索恩薇娅一路往后的那几条。

材料里每人给了：条目里判阶用的几行、能力行（逐行编了字母）、主修那一门的星条（构成、阶、传承三行）和全谱那一行、生来星的档、他当过旅伴的那几页的能力行和兼修、同一人别的条、scan 报的要改的几样。不够的打开源稿看整条（材料里写了文件和条目标题）。

## 三、要做的五件

### 1. 主修那一门带开局阶

照底卡状态栏的写法把档和阶写在技艺名后头：`档·N阶`，还没学的写 `档·未入阶`（这一批几乎用不上）。只在原行里加，别的字不动：

- 凡世至强：`- 技艺【岭卫回风枪】｜……Epic。……` 改成 `- 技艺【岭卫回风枪】(Epic·五阶)｜……Epic。……`。句子里原来那个报档的字照留，读得通就行。
- 人物：`技艺【圣荫界焰杖术】(Epic) 是……` 改成 `(Epic·三阶)`；`技艺【鹰石塔灯守夜法】，Epic，……` 改成 `，Epic·四阶，`；`技艺【X】是……` 没写档的，加成 `技艺【X】(Epic·三阶)是……`；`Art【机心工学】(Legend，……)` 改成 `(Legend·四阶，……)`。

**阶是哪一年的。** 写这一条【调用】起头那一年（玩家最早碰得上他的那一年）他在第几阶。往后在这一条管的年头里还往上走的，括号里写起头那一阶，句子里或者【走势补】里补一句“约X年到五阶”。同一个人几条（材料「同一人别的条」），后一条的阶不比前一条低，兼修只添不丢。

**怎么判。**

1. 有星条、有「阶」那一行的：照那一行看每一阶要哪几门 Skill 到什么档、位阶上限多少（Epic 的五阶要极境，Legend 的五阶要英雄往上，Unique 的奥义跨进神域），对着这个人那一年的位阶、阅历、条里写的事判。条里写“这一门在他手里做到了头”“补完了”的，是五阶；写“还没做到头”“只学了头几课”的，照写的。
2. 没有星条的（scan 报「技艺没有星条」，凡世至强、地方上凝名的那几位多半是这样，这一门 11-20 技艺重洗没过，没有构成和阶那一行），照这把尺子判，再照条里的事挪一两阶：
   - 传奇（凡世至强、凝了名到了传奇的）：凝名、补完、跨进去靠的就是这一门的，五阶；凝名不靠这一门的（凯兰的九矛夜话、海蒂的补墙调这种行当），照他在这一行里做了多少年写，多半三到五阶。
   - 名字凝住的英雄：凝名那件事正好是这一门做到顶的那一下，五阶；不是的，四阶上下。
   - 没凝名的人物：位阶当参照，共鸣一到二阶，灵格二到三阶，极境三到四阶，英雄四到五阶，再看他在这一门里做了几年、条里写他做得到什么。
   - 位阶只当上限，不硬往上推。条里写他做得到的那几样，就是他那一阶该有的样子，判出来的阶跟条里写的本事对不上的，以条里写的为准，阶往下挪。
3. 档对不上的（scan 报「技艺档跟星条不一样」「技艺没写档」）：先看是不是本来就该不一样，页上的星条写的是旅伴手里那一版，传奇手里是补完的、跨进去的那一版（珀拉的采珠长咏是 Unique，星条是 Epic；梅瑞丝、费利克斯的骸银结环法是补完的 Legend），这种照留，行里写明是哪一版（“补完的那一版”“跨进神域的那一版”），对得上全谱的「缺什么或做到头的」「补法」两栏和星条的「传承」那一行。真写错了的，改行里的档。没写档的补上。星条这一回不动，星条自己写错了的在【没改】里写一句。
4. 技艺的名字一个字不改，次序不改（收稿脚本对不上就不换）。

### 2. 兼修

照技艺样稿第四节、旅伴过条第二节第 2 条写。

- 门数：灵格往上一到两门。英雄、传奇、长生种至多三门。没有一件事撑着的不添，写 `【兼修】无`。多数人一门就够，别凑数。
- 一门兼修一两句：哪一年、跟谁或在哪里学的，补什么短板或推什么长处，学到了哪几科。档写他手里那一版，多半比主修低一两档，带阶：`【Y】(Rare·三阶，……)`。
- 撑着的那件事先从条里现成的事里找（凝名伟业、往后的事、随身、他在哪一处守了几十年、跟谁并肩过），他当过旅伴、旅伴条里有兼修的，那几门照接，阶可以往上走。不为了兼修另编大事；要新补一件小事（哪一年跟哪个老兵学了几手），写得小、写得具体，标★。
- 从哪里挑，先后照旅伴过条：这一纪的公共技艺（材料页头，看清单里的年份，那一年还没有的不能学），这一纪页上现成的技艺（材料页头列了这几页的，别页的写全名也行），底卡技艺池子（迷宫纪前传可以借，早几纪只借有来历的）。照命路的跨路兼容挑。学的是别人那一门的，写“照某某那一门，用的是哪一版”。
- 施法的兼修两条施法路（魔法使和元素使），一两句里带一句越高阶越容易框架打架。
- 格式（整行交，收稿脚本插在这个人最后一行能力行后头）：
  - 凡世至强：`- 兼修：【Y】(档·N阶，……)｜【Z】(档·N阶，……)`，插在 `- 技艺【X】` 那一行后头。
  - 人物单人的条：`- 兼修：【Y】(……)`。
  - 人物几人合写的条：`- 名｜兼修。【Y】(……)`，名字跟他那几行起头的名字一样。
- 兼修那一行不进打包的持有人（打包只认「能力：」起头的行），也不会让那一门的星条在他的局里醒，这是有意的。

### 3. 生来的星（天赋、被动）

这一回不重写星条，不并星，只动能力行里的档和名字：

- **当过旅伴的**（材料里有「当过旅伴」那几行）：名字和档照旅伴条，那是 11-20 过条以后的。名字不一样、是这一条没跟上改名的（费格的被动、伊奥、托卡、伊妮德、瑞恩·无名），交【改名】旧→新，收稿脚本把这一条里的【旧】都换成【新】。凝名以后才露出来、旅伴条里本来没有的（塔隆·黑燧的宿火），照留，行里有一句哪一年露出来就行。
- **没写档的**（scan 报「天赋没写档」「被动没写档」，凡世至强几乎都没写）：在【】后头补 `(档)`，例：`- 天赋【银叶肺腑】(Legend)：……`。原句里的“传奇档”“到了传奇档”是说他到了传奇的本事，照留，不是星的档。档照 11-19 那一轮的口径定：生来的星是本钱，从血、家、身子、出生的地方长出来；天赋那一颗起步 Epic 往上给，身子那一颗可以低到 Rare；Unique 只给命运性、神话级、同一时刻世上只有这一个、世界会反应的；传奇不一定是 Legend 的天赋，照这颗星本身的分量给，别一律 Legend。
- 有星条的，行里的档照星条；不一样又有缘故的（古尔巴的负山之肩行里 Unique、星条 Legend），在【没改】里写一句，或者改行里的档跟星条一样。
- 首段的“谁家常有”这一回不补。行里本来写了的照留。

## 四、什么不动

- 受保护的行：条目设置、固定锚定、底座、体态数据、`## ` 标题、`### ` 星标题。
- 只交材料里编了字母的那几行，别的行（调用、位阶与职责、凝名纪年、凝名伟业、往后的事、传奇专长、使用规则、裁定锁、声口、随身）一个字不动。交上来的行只加档和阶、补生来星的档、换改名的星名、必要时改一两个字让句子读得通；整句重写的，收稿脚本会报“跟原行差得多”。
- 技艺的名字、次序不动；不给人添第二门主修，要添的写进兼修。
- 星条（`### 名 (Art | 档)` 那一块）这一回不动。
- 卡面规矩照 `底稿/命星重审第二轮/派活说明_技艺铺开.md` 第五节：不用 ——、—、；、…、！；冒号只在标签行；档只有 Normal、Rare、Epic、Legend、Unique；不写月相；神用祂；禁词照 check_people_v7。新起的设定标★。

## 五、交稿格式

一人一段，照材料的次序，编号照材料的【人】：

```
====
【人】G026
【行 a】- 天赋【灵纹之眼】(Epic)：残缺的字他认得，到了传奇档，……（整行）
【行 c】- 技艺【骸银结环法】(Legend·五阶)｜学院教的是梅瑞丝补完的那一版，Legend。……（整行）
【兼修】- 兼修：【墙下残卷初咏咒法】(Rare·三阶，……)
【走势补】无
【改名】旧名→新名｜缘故一句（没有就不写这一行）
【没改】一句（照 scan 报的没改的地方、拿不准的，没有就不写）
```

- 【行 x】只交改了的行，没改的行不交。字母照材料，换的是整行，一行写完，不折行。
- 【兼修】、【走势补】每人都写，没有写 `无`。
- 前后不加别的话。交稿以外的备注（新起的名字和设定标★、拿不准的、你替谁定了什么）写 `底稿/收尾_11-24/备注/<份>.md`。

## 六、交之前自查

```
python -I -X utf8 底稿/收尾_11-24/过条/tools/splice.py --dry 底稿/收尾_11-24/过条/交稿/<份>.md
python -I -X utf8 底稿/收尾_11-24/过条/tools/splice.py --dry --diff 底稿/收尾_11-24/过条/交稿/<份>.md
```

头一行看换了几人、几行、兼修几行、缺交几人；「看：」那几行逐条改掉（原行找不到、技艺名字变了、生来星换名没写【改名】、技艺没带阶、跟原行差得多、同一人几条对不上）。`--diff` 印出换回以后的样子，看兼修插的位置对不对。不要跑 `--apply`。

交稿和改过的几行也过一遍卡面：把交稿里【行】【兼修】那几行抽出来存成一个临时 .md，跑 `python -I -X utf8 tools/cardscan.py`、`tools/check_people_v7.py <文件> .`（临时文件放你自己的 scratchpad 子目录）。

## 七、收稿（主会话做）

1. 各份交齐，`splice.py --dry`（不给文件就读 交稿/ 下全部），看报告。
2. `splice.py --apply`，写回分段源稿和补卷、月银纪三卷的页，另写 `过条/收稿/过条记录.json`；照末尾印出来的命令重拼纷争纪、山铜纪、前传的页。
3. 改过的文件和拼好的页跑 cardscan、check_people_v7、authormark，`check_protected.py` 拿 HEAD 对（差的只能是能力行和插进去的兼修行）。
4. 收完以前别重跑 scan.py：重跑会把换过的行当成原行，交稿就对不上了。全部收完再跑一回，「样子」应当全是“新”。
5. 门面四本书的人物、传奇档案要跟上（build_data → fix_lists → star_true apply），卡照「11-17 机械瘦身」第 8 条的先后重打。
