# 份六备注（天亮以后的晚祷下、夜祷，天黑以前的魔族之世、末年上，七条主线）

11-02，照 底稿/合篇/润笔_计划.md 第三节轻润。只动四个文件里的七条主线，每条从「## 月银纪·主线｜」起，连着它后头那一节「## 裁定锁」，到条目设置那一行为止。题那一行、钩子引语、【调用】、条目设置、## 标题一个字没动，主线以外的条目（史诗、时段总纲、旅伴、人物、命星、凡世至强、设计备注）没动，拿脚本对过，七条以外的改动块是 0。没提交，没 git add。

这一份没有派到伏笔，没种。请愿和七人原里上部埋下的那几句原样留着，一字没动：
- 请愿：钩子引语「把我们从兽的那一页，挪到人的那一页上去」，三幕「纸上只有一个字」，收束「穹都回的是一个字，驳」「七行，换了一个字」，默认收束「最后认的是那一个字」，裁定锁「请愿和那一个字照北口以来第九十九卷」。
- 七人原：默认收束「七个人里头有一个是魔族，编年院照录了这一句，后来的抄本里，很多把这一句刮掉了」，第七个人兜帽没摘、第七行空着、界石空三面，玩家能改和锁里「第七人的族属永不确认」「魔族这一条不抹」。

主线里引的歌的原句一字没动：河谷「走得很慢，走一步，停一下，又再走一步」「看了一整天，有人问他看出了什么」「六个村子的井，一口接一口又满了」「他把山放下来，坐了一整天……往后再也直不回去」，黑石王都三幕喂鸽子、日光从高窗倾落、那三步、贵族伏了一地那几拍，收束「镣铐还挂在腕上，锁是开着的」，请愿收束引的那几行，薇丝拉之路引北口以来第七十卷的那几句。改的时候避开了，改完拿脚本搜过，都在。

跟合篇的真相层对过：七条里搜凯尔萨斯、页边、秘仪、反转、理想国、四执政、新墨、雨城、篮子、登神，只有请愿碰得上的人「照人物凯尔萨斯那一条里提比略那一句」（条目名，末年的穹都陛下就是凯尔萨斯不是秘密）和星湖锁里原有的「四执政不出场」，河谷锁里「不解释怎么可能」是寻常的话。没有两个瞬间、页边那只手、反转秘仪、两个新墨的字。光秃秃的「那一位」合篇里专指深渊那一位，七条里拿它指别的的两处改了：星湖玩家能改「那条船走的是那一位的路」（指长眠的引路人），七人原玩家能改「那一位自己不说」（指第七个人，又紧挨着魔族那一句）。带限定的「跟他一起回来的那一位」「湖对岸来的那一位精灵」「河谷外山头上的那一位」「赶兽潮的那一位」「写判词的那一位主祭」是条目名或者带着限定，照留。

「那一X」是这几页的叙述口气，一条四五十处，只收了扎堆的和顺手改到的句子里的。

七条一共改了六十八处。照句号数，神渡之盟一成三，星湖一成，薇丝拉之路九分，请愿八分，七人原、河谷、黑石王都七分。不到一成的几条，余下的拍子一条一条读过两遍，没再找出要动的毛病，照计划没毛病的拍子不动。

## 第三十行　诸国·神渡之盟（诸国期/诸国期时段_五_晚祷下.md）

汉字 4935 改成 4906，改了十七处，照句号数一成三。

改的：
- 开局：「刀架上的锁是东岸一个十四岁的锁匠学徒打的」，伊妮德的旅伴条写刀架换锁是她十二岁那年干的，这一年她十四，改成「东岸的锁匠学徒十二岁那年打的」。桥头排队交刀那一句从排队一路逗到桥卫记哪一国，在「背着弓的兽耳」后头断开。
- 世道第一段：河滩上的医棚开局刚写过一遍，这里又写搭着一顶、棚口点一支白蜡烛，收成「河滩上那一顶医棚，七个王的伤兵都收」。
- 世道第二段：贾曼尼和星湖两件事拿逗号连成一句，断开；「是七国里最后一个」跟「星湖进得最晚」重了，拿掉，一幕里那一句留着。
- 世道第三段：「城里三岸各有各的人」紧跟上一段开头「七国各有各的打法」，同一个句架，改成「三岸住的是三样人」。
- 世道第四段：「七王之战打了两百多年」这一段里第三回说两百多年，改成「七王之战起了以后」；「坐过神的坛这时候已经过了一半，坐过神的坛石头摸上去是温的」两个坐过神的坛连着，后一个拿掉。
- 一幕时长：坠叶月到寒星月是三个月，原写约两个月，改约三个月。
- 一幕：「两边都不杀她，是没有人追得上她」少了半截，读成两边不杀她，改成「两边都想杀她，没有人追得上她」，照柯黛旅伴条（不是不想，是追不上）；同一拍「来回地跑」「来回地晃」重了，后一个改「风一吹就晃」。
- 一幕幕终：七国的使节一句里出现两回，后一个改「使节吃完了」。
- 二幕：「是哪一国赶的」，这时候狼还没来，改成「是哪一国下的手」，锁里赶兽潮的默认是黑石照旧。「领头那一头比马高一头」改「领头的狼王比马高一头」。犬耳向导那一拍「一趟比一趟慢」「一趟比一趟不灵」连着，后一个改「鼻子和耳朵也跟着钝下去」。
- 三幕：「七个王在盟坛前面站了一整个上午」，同一幕星湖王是最后一个到的，人物埃德加那一条还写他的王冠留在星湖、从不带出来，改成「先到的六个王」「六顶冠」。柯黛「跑进黑石的阵里，接过回信」，上一拍说黑石要日轮先递信才肯交，补「递了信」。
- 默认收束：「那一批交了刀、到撤兵也没有回来领的刀」刀字重，改「交上来、到撤兵也没有人回来领的那些刀」。
- 玩家能改：「七支里挡下几支，荣誉就叫几羽」说反了，七羽是她身上中的箭，挡下几支就少几羽，改「七支里她中了几支」。

查出来没改的：
- 柯黛的旅伴条正史那一段写「七个王在盟坛前面站了一上午」，人物埃德加那一条写「七个王在盟坛前站了一上午……他最后一个到」，两条自己也对不上。主线改成先到的六个王，那两条没动，倾向照主线改成六个王。
- 人物盟坛上多出来的那一位写祂「看着坛下七个王问的」，这时候星湖王站在祂旁边，坛下是六个。主线写的是「看着七个王问了一句」，不用改，人物条那一句可以去掉坛下两个字。
- 各页一幕的时长算法不一样，有的照跨了几个月数（星湖、薇丝拉之路、请愿），有的照差几个月数（河谷炎潮月到金穗月约两个月）。都写着约，只改了这一处两种算法都不对的。
