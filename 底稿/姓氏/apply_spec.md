## 一、补在哪里

1. **旅伴条：身份那一行。** 头一句写全名，紧跟一句来由，意思照清单「为什么」那一栏和本文件第五节，十到四十个字，平白一句。新起的设定句末标（★）。已有的姓头一回写全（芬顿·满仓、格奥尔格·斯滕、莱娜特·斯滕）不标★，也不用写来由。
   - 例：身份：托比亚斯·蝉鸣，初光街口那一家面包房的第六代面包师。蝉鸣是他家的户名，祖上在8081年蝉鸣月排队入的荫册，比那一座炉子早得多（★）。炉子是他家祖上砌的，……
   - 出身在固定锚定里，不动。简称不动。【调用】那一行不动。
2. **姓是往后才有的**（奈拉、提诺的谷名），写在讲到那一段的句子里，下场那一行也是正文，可以写。
3. **背景条。** 正文里头一回说到这个人或这一家的地方，带上姓一回，全名或者「蝉鸣家」都行。顺才加，不顺就不加，不为了加姓改句子的意思。
4. **人物条、凡世至强。** 正文头一句（是谁那一句）写全名。凡世至强正文里写名号的地方照「名号 · 名·姓」。标题不动。
5. **传奇表。** 「名号·名」写成「名号·名·姓」，「- 名，名号，……」写成「- 名·姓，名号，……」。
6. **主线、碰得上的人。** 一般不加，有自己条目的人照旧叫名字。清单点了名的才加，在这一页头一回出现的地方写全名：索尔薇格·斯诺里朵蒂（灰的年月·半疯的麦田），沃尔夫冈·鸦岭（炮的年月·空鞍的白马），劳里·铃尾（铁狼的年月碰得上的人）。
7. **一条里全名只出一回**，往后照旧叫名字。一行里同一个姓不出两回，铃尾那几句跟着顺一下（原来写「铃尾信使家的女儿」的，补了姓以后写「信使家的女儿」这一类）。
8. **跨纪的人。** 你管的文件里，凡是传奇表、凡世至强和人物条头一句里出现了第五节补了姓的人，不管是哪一纪的人，都照第五节补上。别处照旧叫名字。
9. **设计备注。** 每一页末尾的设计备注添一节「10-21 补姓那一轮」，一条一行：这一页补了谁、补的什么、哪几处标了★，触发留到第三步。设计备注不进卡。第三批 r1、r2、r3 没有设计备注，不添。
10. **只动这些。** 不顺手润笔，不改别的事实，不添新的人和事。来由句只说姓是怎么来的。

## 二、不能动的

- 标题（## 和 ### 开头的行）、简称、固定锚定、底座、体态数据、条目设置（「> 条目设置：」开头的行）、能力行里【】中的星名。
- 触发这一轮不动，第三步我另做。
- 锁住的名字照旧不起，无姓的那一路照旧不加，清单里写了不加的人不加。
- 别人那一路的文件不碰。补卷、总表、方向稿、清单、名录、CLAUDE.md 由我改。不要 git commit。

## 三、写法

- 卡面不用 ——、—、；、…、！。冒号只用在八个字以内的标签行。
- 「」只用于卡里真有的条目名。
- 神用祂。月相的字眼不用（新月、满月、残月、月牙、弦月、月亮、月光、月相）。
- 不用中式口语和古文，不用真实世界的地名、国名、人名（音译的东边常见姓是例外，只用第五节那几个）。
- 名在前姓在后，中间一个「·」。名号和名字之间是带空格的「 · 」，照原样。

## 四、纷争纪的页是 parts 拼的

- 改 parts 里的源稿，不直接改页。改完跑 `python3 -I -X utf8 ../../surname/reassemble.py write 页号…` 重拼你那几页，再跑 `… check 页号…` 核一遍。
- 第六页的 v6_stars、第七页的 w6_stars 是合成以后的那一份，v6a、v6b、w6a、w6b、w6c 不在拼页的次序里。星这一轮一般不用动。
