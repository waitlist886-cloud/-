# 技艺重洗·方向稿第二版（11-20，带样稿）

第一版只换了口气，名字和每门管多大没动。用户 11-20 看了第一版，又说了下面几件，这一版照它们改。

## 一、用户这回说的

1. **从名字到效果整个重洗。** 已经很好的不动。批量跑起来以后，有一批名字和效果读着怪，这一批要改。
2. **一门技艺是一门完整的行当。** 生活系能成超凡，说的是超凡厨师、种植专家、魔药大师、炼金大师、铸造大宗匠这样实打实的手艺。把排座从礼仪里拆出来单算一门，就像把淬火从锻造里拆出来，说这个铁匠是淬火大师，会很怪。
   - 以礼仪为基的超凡，莉西娅有两种写法：一种是礼仪当成操纵木偶的线，像魔偶大师那样逼人照规矩来；一种是做成领域，她设下大范围的规则。
3. **命星可以重复。** Unique 以下的星，完全可能落在不同的人身上。
   - Special：Legend 要隔很多代才再出一个，Epic 隔得近一点，Rare 常见。
   - Passive 比 Special 松，因为血脉容易遗传。同一个时代、同一个地方的人有一样的体质或血脉，合理；隔了时代、隔了纪元有同一颗，也合理。比如金血是 Legend，一个时代可以同时有好几位觉醒了同一位神明血脉的黄金裔。
   - 一位传奇的 Legend Passive，传到几千几万年后的后裔，可能只剩 Epic，掺了别的效果，或者就是弱一些；也可能出一个返祖的后裔，跟祖上一模一样。
4. **一个超凡者不只修一门技艺。** 长寿的一生里，他会去学别的技艺，补短板，或者把长处再往上推。
   - 莉西娅可能学族里阵剑一系的技艺补近战，或者学真理系的施法理论加强施法，也可能两样都学。
   - 玛丽贝尔主修科研方向的超凡学问，作为施法者，应该也会几手真理或洪流的技艺补战斗的短板。
   - 弗洛里安最拿手的是吹号，可他是佣兵，必然会几手佣兵的剑术或枪术。
   - 卡上可以补一句：现在显示的是他最熟练的那一门，不一定是唯一的一门。

## 二、一门技艺是什么

### 尺子

**一门技艺要撑得起一个身份。** 读完名字，要叫得出这是个什么人：剑士、枪手、弓手、法师、牧师、歌者、厨师、园艺师、魔药师、炼金术士、铁匠、工匠、医师、书记官、礼官。

一门里的一步、一招、一样手法，不单算一门。排座、淬火、添水、点名、引路，都只是招式，或者某一阶要学的东西。现在页上有一批这样的，比如宴庭座次术（排座）、不竭釜炊法（初版只写了添水匀锅）、归途咸汤引路法、长辙添釜律、醒神拍击术、一网收潮、穿雾系命结、送灵烟引术。哪些要改，交给筛表逐门定，不一刀切。

**一个人的本事都在一门里。** 比如约伦是超凡厨娘，她的技艺管的就是做饭的整套功夫：认料、调味、火候、存粮、一口锅喂一营。不是“添水那一下”。

### 生活系的门类

照 JRPG 的生产、料理、社交、学识几系，再照底卡的命路落地：

- **生产**：锻造、符文刻印、炼金、魔药、附魔、农艺和园艺、酿造、裁缝、建造和筑城、造船、机关与魔导工学。
- **料理**：伙夫、宫廷厨师、行炊、药膳。
- **社交**：礼仪、交涉、乐舞、戏剧、吟游。
- **学识**：书记与档案、鉴定、占星与推演、医术、制图与地理。

生活系的超凡是这一行做到顶的样子。超凡厨师的汤能让一营人一夜不畏寒，魔药大师的药能把断了的手接回去，铸造大宗匠打的剑认主。照底卡命星总则，Rare 是一手，Epic 撑得起一个流派，Legend 是百年一出的大师。

### 社交系怎么写出超凡

社交系最容易写虚，写成“声音就低了”“没人拍桌子”。照用户给的两种路子落地，写出一样看得见的魔法：

- **丝线**：礼数、契约、誓言化成看不见的线，系在人身上，照规矩牵着他走。像魔偶大师，管个人，管得细。
- **领域**：她张开一片规矩，范围里的人都照它走，违者有代价。管一片，管得宽。

两种可以长在同一门里：低阶管人（丝线），高阶管场（领域），见下面莉西娅的样稿。别的社交系照这两样，或者照底卡绯宴支配术那种让人自己走到结论上，各门挑合自己的那一样。

### 名字

- 照底卡技艺池子起，同档对着比：Rare 对皇家宫廷剑术、矮人铁砧锻打法、初阶炼金解构手札；Epic 对虚空行者折跃步、矮人符文锻造法、圣光大净化仪式；Legend 对绯宴支配术、泰坦神力锻体法、精灵王庭秘传魔弓术。
- 写法照旧是出处、手法、门类三截。门类字要是一门行当的名字：剑术、枪术、礼法、炊法、锻造法、药典、农法、工学。不用一个动作当门类，像“座次术”“添釜律”“引路法”这种。
- 名字好的不动。比如不竭釜炊法，名字本身就是 JRPG 的路子，只把管的范围放大。

### 效果

招式表和按位阶解锁照第一版：一门两到四招，招式名短、带意象，每招写清做到什么、范围、人数、时长、冷却或代价。Epic 最后一招停在极境；Legend 有一招奥义，到英雄或传奇；Unique 的奥义跨进神域。

生活系的“战法”那一卷改叫**用法**，写它在这一行里做得到的事。打不了仗的，在“战法”那一行直说。

## 三、命星可以重复

照用户说的写进口径：

1. **Unique 只在一个人身上**，照旧。人死了跟着走，后人修到的是下一档。
2. **Special**：Rare 常见，一页里同一颗出现在两三个人身上都行。Epic 隔一两代、换一个地方又出一个，不稀奇。Legend 要隔很多代才再出一个，同一页里不重。
3. **Passive 更松。** 血脉和体质跟着家、跟着族、跟着地方走：
   - 同一家、同一族、同一个地方出生的人，同时有同一颗，合理，比如炽血体质“红头发的人家里常有”。
   - 隔了时代、隔了纪元有同一颗，也合理。
   - Legend 的血脉可以一个时代同时有好几位，比如觉醒了同一位神明血脉的黄金裔。
4. **祖上传下来的星会变。**
   - 衰减：一位传奇的 Legend Passive，几千年后的后裔多半只剩 Epic 或 Rare，或者掺进母家那一边的效果。衰减了的另起名字，名字里留着祖上那一颗的影子，传承那一行写明是从谁那里来的。
   - 返祖：偶尔有一位跟祖上一模一样，用同一个名字、同一档。返祖本身就是这一代的大事，世界会反应。
5. **卡上怎么落。** 同名同档的星，各页照旧各写一条（各页的条只在那一页醒）。同一页里几个人共用一颗，写一条就够，条里说这一颗谁家常有。
6. **11-20 那一轮的后续。** 那一轮照“不许重名”给 74 颗撞了名的另起了名字，底卡池子 32 个共用的旧名也给各人新起了 101 颗。按新口径，同家、同地、同血的那些可以改回共用的一颗；起得好、本来就该各是各的，留着。

## 四、兼修：一个人不只一门

1. **能力行里的 Art 是他最拿手的那一门。** 能力行后头、技艺走势后头添一行兼修，写他另外会的。门面档案“技艺”那一栏写“最拿手的一门”，底下列兼修。
2. **兼修学来做什么，两样：**
   - 补短板：施法的学几手近身的，近战的学一手护身术或一手感知，搞研究的学一门能打仗的。
   - 往上推：同一路再学一门，跟主修那一门配着用，比如高阶施法框架理论，学得越杂越强。
3. **从哪里学。** 照命路条里的跨路兼容挑（底卡每条命路都写了能跟哪几路兼容）。来源有三处：
   - 底卡技艺池子的八十八门（皇家宫廷剑术、基础魔力感应法、高阶施法框架理论、绯庭应身舞……）。
   - 这一纪各页上现成的技艺。
   - 每一纪新写一小批公共技艺（佣兵剑术、军中枪术、护身术、急救、骑术这一类），一纪十来门，多是 Rare，少数 Epic。
4. **档。** 兼修多半比主修低一两档，写他手里那一版。用的是底卡或别人那一门的哪一版、学到第几课，照旧写成“照某某那一门，用的是哪一版”。底卡施法者双轨制那一条说，越高阶越容易因为认知框架冲突出岔子，兼修两条施法路的，限制里写一句。
5. **谁有几门。** 启源、共鸣的少年人，兼修零到一门。灵格往上一到两门。英雄、传奇和长生种可以三门。每一门兼修都要有一件事撑着：哪一年、跟谁、为什么学。
6. **技艺走势跟着写。** 兼修也有节点，写进走势那一行。

## 五、样稿

### 甲、莉西娅·夜绯（白鸦的年月），名字和效果都换

原来那一门宴庭座次术是从礼仪里拆出来的“排座”。这一版写成夜绯家整门礼法，照用户说的两种写法：低阶是丝，高阶是领域。名字换成绯庭牵丝礼法，758 年长成的那一门宴庭情报术跟着换成红园七夜宴律。

```
### 绯庭牵丝礼法 (Art | Epic)

【调用】白鸦的年月里，莉西娅主持一桌、替人排座、让孩子靠门，或出了事要从桌边让出路时用。

【绯庭牵丝礼法】是绯宴夜绯家传的礼法，红园的人叫它牵丝礼，长桌边的人只说那是夜绯家的规矩。绯宴的礼数里浸着魅魔的魔力，行礼的人指尖牵出看不见的绯色细丝，系在入席的人身上，坐下、举杯、开口、离席，都照规矩一步一步来（★）。夜绯家几百年拿它定谁分血、谁上宴，莉西娅倒过来用，让孩子坐门边，让想走的人走得出去。三样里成了的是练法这一卷，战法只有半卷。

- 法门：没有成文的。牵丝靠的是魅魔生来那一点叫人回应的魔力，礼做得越周全，丝越韧，自己先失了礼，丝当场断（★）。修到灵格，她戴着手套的指尖在灯下会拖出一缕淡红的光。
- 用法：
  - 礼线（共鸣起）。向一个人行完一整套礼，丝便系上了，那人在这一桌上照礼数行事，拔刀、拍桌、抢话以前先要过一回意志判定，判定失败，手会自己放回桌上（★）。一回系得住三四个人。
  - 座次（灵格起）。她排过的一桌，每把椅子都牵着丝。仇人不对着坐，坐下的人火气往下压。出了事，她一拉，椅子连人往两边滑开，让出一条通到门口的路，孩子和不想掺和的人先走（★）。雨城的长桌她排得过来。
  - 礼域（极境起，这一门到此为止）。整座厅成了她的礼域，规矩张在厅里，入席的人都照着走，起身先告退，动刀先报名，违了礼的人身上的丝一紧，手脚慢下半拍（★）。一座城的宴她撑得住，撑一夜。
- 战法：半卷。丝管得住守礼的人，管不住不讲礼的人，真动了刀，她能做的只是让出路。
- 练法：夜绯家的孩子十一岁戴上手套，坐到大人身后去看，先认门，再看谁的手放在哪里，再记谁开口前要看别人。看满几年，大人叫你把一桌的座排一回，满桌的丝都系得上才算过，排错了，先拍桌子的就是排错的那一个（★）。莉西娅坐了十四年。
- 修行重点：礼仪、交涉、察言观色。她先看门在哪一边。
- 限制：只管自己肯坐下的人，被押来的、不讲礼的、构装和亡灵都不算。丝叫人守礼，不叫人改主意，挡不住刀，也不能让仇人就此和好。她自己失了礼，满桌的丝一齐断。
- 世界反应：雨城人家摆宴，靠门那一截留给孩子坐（★）。红园的老人说，夜绯家那个女儿的丝是往门那边牵的。
- 传承：绯庭一路的礼法，夜绯家传了几百年，跟红园家学绯宴支配术同出一处，支配术叫人自己走到结论上，牵丝礼叫人照规矩坐下（★）。她把座次倒过来用，起了这一版，练法一卷，Epic，缺一套出了事拿来护人的战法。只给 AI，758年霜降月七夜她补成红园七夜宴律，Legend，叙述不提前说。

### 乙、约伦·无炉（黎明的年月），名字留着，效果放大成一整门

不竭釜炊法这个名字是对的。毛病在第一版只管“添水匀锅”一件事，现在写成一位超凡厨娘的整套手艺。

```
### 不竭釜炊法 (Art | Epic)

【调用】黎明的年月里，约伦认料、掌勺、一锅喂一营，或有人学苇棚区的汤、想跟她学做饭时用。

【不竭釜炊法】是苇棚区几代人在码头停工的冬天凑锅凑出来的炊法，河滩上只叫它苇棚炊法。到了约伦手里，它成了一位营里伙夫的整套手艺，认料、调味、火候、存粮、一口大锅喂一营（★）。约伦说，好吃不好吃另说，先得够。法门和用法这两卷成了，练法没成册。

- 法门：火候。锅底的火跟着掌勺的人的呼吸走，添水、下料、起锅都在一口气里。修到灵格，锅底浮起一圈麦色的微光，光亮着，添下去的水照样顶饿（★）。修岔了叫贪锅，一锅想喂的人太多，汤一夜之间变得寡淡，喝了不顶饿。
- 用法：
  - 辨料（共鸣起）。一眼看出粮的新陈、肉坏没坏、菌子有没有毒，发霉的麦子挑一遍洗一遍，下锅照样能吃（★）。
  - 匀锅（共鸣起）。添一回水，一锅多喂一倍的人，一样顶饿（★）。
  - 营锅三味（灵格起）。暖腹汤，喝下的人一夜不畏寒，饿着肚子的乏力一扫而空。鱼骨汤，伤兵喝了伤口收得快，夜里睡得着。行军饼，烤一炉能放半个月不坏，一块顶一顿（★）。巡礼时她一口大锅喂过一营，凑来的料不够一半。
  - 不竭之釜（极境起，这一门到此为止）。一口锅不见底，人没走完就总有得舀，最后一碗和头一碗一样稠，从这口锅分出去的汤，几里外也跟着不断（★）。
- 战法：没有。吃饱了的人打得动仗，汤自己不替谁挡一刀（★）。
- 练法：没有成册的。苇棚区家家在锅边上传，大人凑锅，孩子烧火看着，看会了添水的那一下就会了。约伦是在河滩上看几户人家凑锅学的，往后营里帮厨的孩子跟她学，学到哪一味全看跟了她几年（★）。

## 六、规模和做法

1. **先筛。** 四纪各页的技艺一共 476 门（Epic 233、Legend 24、Unique 1、Rare 218），交 Opus 逐门判：
   - 留着不动；
   - 名字留，效果放大成一整门（像约伦）；
   - 名字和效果都换（像莉西娅）；
   - 本来就是一门里的一招，并回所属的那一门。
   筛表出来先给你看。顺带把生来的星里像魅魔指尖那种“族里常见的却给了 Unique”和 11-20 改掉的共用名列出来。约 $10。
2. **公共技艺。** 每纪新写十来门公共技艺，给兼修用，主会话写，不花 API。
3. **重写技艺。** 照筛表交 Fable 写，名字、招式、解锁一起换，粗估 $30 到 $40。
4. **兼修。** 576 位旅伴和要紧的人物，每人看要不要添、添哪一门，交 Opus 或 Fable 写一行，粗估 $20 到 $30。
5. **审稿和改名。** Opus 审一遍约 $10。改了名的技艺照旧拿 rename_stars.py 换全卷引用，STAR_GATE、技艺走势、门面跟着改。
6. 合计约 $70 到 $90，新号的 $200 够。

## 七、要你定的

1. 莉西娅这一门照“低阶是丝、高阶是领域”合在一起写，行不行，还是只取一种？（倾向合写，社交系别的门各挑合自己的。）

3. 兼修的来源：底卡池子、这一纪页上现成的、每纪新写十来门公共技艺。（倾向这样。）
4. 11-20 照“不许重名”改掉的那些星，同家、同地、同血的改回共用的一颗。（倾向改回，起得好的留着。）
5. 先筛表给你看，再写。（倾向这样。）
