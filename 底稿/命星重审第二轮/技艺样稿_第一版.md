# 技艺照异世界轻小说和 JRPG 的口径洗一遍·样稿第一版（11-20）

用户 11-20 说的：拿西幻轻小说加 JRPG 的口径，把技艺（Art）也洗一遍，先试一下。

## 一、现在的样子

四纪各页的技艺：Epic 233 门，Legend 24 门，Unique 1 门（命烛剑律），Rare 218 门。Rare 那一批 11-19 夜加魔法的时候已经照新文风写了，这一轮不算在里头。

Epic 往上的那 258 门，11-17 照法门、战法、练法三样重写过，分量、档次、传承都对，名字也照底卡池子对过档，你认过。毛病在口气上：
- **战法写成了一段散文。** 读完知道这门剑厉害，可说不出它有哪几招，每一招做到什么。JRPG 和轻小说里，一门剑术先是一张招式表。
- **长进写成了“到了极境……到了英雄……”的叙述。** 看不出哪一招是哪一档才学会的，像一篇说明文，不像一棵技能树。
- **法门偏白描。** 身上修出了什么样子，写成“修久了夜里刃上有一线淡金”这种句子，不像魔法体系里一眼认得出的征兆。
- **过日子的技艺（做饭、排座、书记）效果说不清。** 写的是“汤只管够”“声音就低了”，没写喝下去、坐下来以后身上多了什么效果。

## 二、口径草案

1. **名字照旧。** 11-17 已经照底卡同档对过，你认了，标题一个字不动，打包表、星名对照、技艺走势都不用跟着改。只有招式名是这一轮新起的。
2. **战法写成招式表。** 一门两到四招，每招一个名字，名字短、带意象，像技能列表里的一行（断号一闪、风隙、匀锅）。每招写清楚做到什么，范围多大，管多少人，撑多久，冷却或代价是什么。
3. **招式按位阶解锁。** 每一招后头写“共鸣起”“极境起”这样的字样，读着就是一棵技能树。Epic 最后一招停在极境；Legend 有一招奥义，英雄或传奇才用得出；Unique 的奥义跨进神域。
4. **法门写成魔法体系。** 开头点明是哪一门、哪一曜，修到哪一步身上会显出看得见的征兆（刃上的光色，呼吸带霜，眼里起纹）。修岔了的后果写得像负面状态。
5. **练法写成习得条件。** 分几阶，每阶学什么、怎么才算过关。Epic 缺的那一卷就是没写下来、或者失传了的那一阶，读着跟“这棵技能树后半截是灰的”一样。
6. **生活技能照 JRPG 的生产、料理、社交系写。** 效果写成增益、判定获得优势、产出多少，跟战斗招式一样分招。
7. **数值的分工。** 属性加几成只写在生来的星上。技艺不加属性，只写招式的范围、人数、时长、冷却、代价。
8. **照留的部分。** 限制、世界反应、传承、裁定的意思照留，只换口气。条目设置、标题、【调用】照旧，check_protected 照逐行核对。

## 三、样稿

每门先一句说改了什么，再写成稿。

### 甲、命烛剑律（白石的年月·诺伦），Unique

意思和裁定一字不碰，只把战法拆成两招，法门起个名字。

```
### 命烛剑律 (Art | Unique)

【调用】只在深层解释赤原第六日的剑、破晓的光与越阶斩击，或者三个坎都过了、玩家和诺伦夜里独处时用。表层 NPC、档案、鉴定和考据都不知道，叙述也不点名。

【命烛剑律】是晨曦岭大剑术底下真正的那一门，以命为薪的剑。她的命是一支看不见的烛，每一剑都从烛上烧下一截，剑上的光就是那一截的光，烛还剩多长，她心里有数。同一时刻世上只有她握着它，教不出来，也传不下去。

- 法门：命烛燃剑。不在饮血、呼吸、冥想、祷告四门里，力量从她自己的命里来，不往身子里收，往剑上烧，烧一截少一截。身后有她要护的人，烛才点得着（★）。
- 战法：
  - 以身为炬。烧一截命烛灌进剑里，这一剑越过一个位阶，斩得动高她一阶的对手，剑光扫过的地方夜色往后退（★）。一战至多烧三截。
  - 破晓一斩（奥义）。跟应许之晓同用，一回烧三截，剑光拉成一道横过战场的晨线。初成时一剑破得开城门，英雄时斩得进烧尽自己的传奇，赤原第六日斩焚冰赛弗就是这一剑（★）。到了传奇，烧得够多能伤魔神。
- 练法：没有，也不会有。底下那一卷晨曦岭大剑术练得出来，命烛这一层是她自己的，谁照着她的剑路学，学到的只是大剑术（★）。
- 修行重点：武器熟练度、意志。身后有她要护的人才点得着火，否则只是晨曦岭大剑术。
- 限制：烧掉的命不再长，回复术补不回来。一战烧过三截，她三天抬不起剑。为自己挥剑，烛不亮。
- 世界反应：史书把功劳都记给破晓。她后来留在剑上的约束，唯有心存以身为炬、点亮长夜之志的人举得起它，说的就是这门。
- 裁定：这是她自己的，不是血统、神谕、传承或谁的安排，不追问来处。她知道剩几剑，叙述不透露烛长与烧尽的后果，也不写成杀魔神的办法。止戈清算前，凡躯杀死的魔神只有一尊。
- 传承：只在她一人身上。2988年秋，她替立誓者奥尔达挡下背誓者乌瓦尔的攻击，凡身站到魔神面前，才跨进神域。
```

### 乙、黎明剑律（黎明的年月·索恩薇娅），Legend

残篇三步原来就在，改成三式加一招奥义，斩冠单列出来。法门叫“无源·先看后握”，修岔了写成一种看得见的状态。

```
### 黎明剑律 (Art | Legend)

【调用】黎明的年月里，山铜纪668年花信月上旬九日夜里以后，索恩薇娅拔剑斩令、封、冠或判，或者有人问起黎明篡位时的剑、想学她的剑时用。

【黎明剑律】是里德的断号走到头的一版，斩令之剑，剑先找号令，不先找人。668年她斩冠，断了压在苇棚区三百年的令，人们照着她出剑的样子起名（★）。有人说剑光把午夜照成黎明，有人说只有一声很短的响。法门、战法、练法三样到斩冠那一夜才齐，练法是跟过她的兵替她记下来的。

- 法门：无源·先看后握。她没修过哪一曜的呼吸，也不向哪一位神祷告，光不从外头借，从她定下要砍什么的那一眼里来，往后极光一路管这样的人叫无源（★）。出剑以前先看清叫人不得不打的是什么，那一眼定了，手就稳了，刃上才起淡金光。心里没定，刃就是一块冷铁。修岔了叫早明，先握后看，剑亮得早，落下去砍着的是人，往后一个月刃上的光发浑（★）。
- 战法：
  - 观阵（共鸣起）。站在阵前不拔剑，一眼看出对面是谁叫来的、靠什么号令聚在一处，号手、旗手、传令的人在哪里，在她眼里亮成一个个点（★）。
  - 断号一闪（灵格起）。一剑落在号角、旗杆、鼓面或一纸令上，一剑断一件。号令被断的那一队，听令的约束当场失效，往后一刻钟各凭自己的心思（★）。到了英雄，一剑扫过去，一整条阵的号旗一齐断，第三道拱桥上的号响了半声就断成两截。
  - 黎明行军（英雄起）。剑刃起淡金光，她举向哪边，自己人的恐惧解除，跟着她往哪边去，661到668年她一路就是这样走的（★）。
  - 斩冠（奥义，传奇）。斩得断一顶冠、一道法统、一纸压了几百年的判。被压着的人从此不再欠它什么，照着旧令办事的人也停下手，那一夜一城的天像提前亮了（★）。673年鸢羽滩那一剑，淡金光贴着地面过去，对面的号角、旗杆、鼓面一齐断了，被逼来的人自己放下兵器。用过一回，三天剑上不起光（★）。
- 练法：残篇三式。她没收过学生，跟她走了七年的兵把她出剑以前做的事记成了三式，就是往后传开的黎明剑律残篇（★）。第一式观阵，站在阵前不许拔剑，说得出对面是谁叫来的才算过。第二式断号，砍号角、旗杆、鼓面，砍到刃上起光才算过。第三式收剑，对面放下兵器的那一刻剑停得住才算过（★）。照残篇练得出前两式，新朝的兵多半停在这里，斩冠那一招只在她身上。
- 修行重点：武器熟练度、统率、意志。她说，先砍那个叫人不得不打的东西，砍完了，得有人把饭端上来。
- 限制：断不了人心里想打的念头，也断不了饥饿。斩完得有人立新章程，没人立，旧令就会换个样子回来。冲着她来的刀，这门剑也不替她挡（★）。
- 世界反应：金鸢城的人说起那个夜里，先说天亮了，才说到她（★）。
- 传承：断号是她自己磨出来的，没有师承（★）。668年斩冠的剑把它做到了头，她手里是 Legend 版。她没有收过学生，往后的人照残篇那三式学。
```

### 丙、岚野裂风剑技（黑潮的年月·苍风），Epic

只有战法一卷成了，就写三招，第三招停在极境。缺的练法写成“技能树后半截没写下来”。

```
### 岚野裂风剑技 (Art | Epic)

【调用】黑潮的年月里，苍风拔出岚野家那一把单刃长刀，骑在亚龙背上切开乱流，或者有人想学岚野家这一路游侠剑的时候。

【岚野裂风剑技】是岚野家在天池边上教的游侠剑，高原上的人只叫它岚野游侠剑技，刀上带一道风刃，专拿来切风。父亲教刀只说一句，刀要比风先到（★）。三样里只有战法这一卷成了。

- 法门：没有。刀上那一道风刃是高原孩子生来带的风亲和，岚野家不教人往身子里养什么，各人凭各人的一口气。
- 战法：
  - 先风斩（共鸣起）。拔刀的一瞬风刃先出鞘，切得开一丈外的苇子，刀还没到，对面的弓弦先断（★）。
  - 风隙（灵格起）。一刀劈开迎面的风，刀后留下一道风是顺的缝，他和身后几步内的人、骑的亚龙顺着缝走，逆风也不减速（★）。苍风骑上霜嗝以后，霜嗝往哪边缩脖子，他就往哪边劈。
  - 开岚连斩（极境起，这一门到此为止）。一刀接一刀，在一整股乱流里劈出一条通道，后头的船跟着刀走，刀不停，路就不合（★）。
- 练法：残的。岚野家在湖岸上教了几代，来学刀的年轻人住在湖边的石屋里，学拔刀、劈苇、追风几手，没有成文的步子，先后看教刀的人的心思，学到哪一招看天分（★）。苍风在船上和亚龙背上那一截，是他自己跑竞速跑出来的。
- 修行重点：身法、武器熟练度、骑术。父亲那一句，刀要比风先到。
- 限制：劈得开乱流，劈不开雷云，天脊上那一层雷谁也过不去。开岚连斩的路撑不久，刀一停风就合上，后头的船得一直跟着刀。练法残着，教得出劈苇的人，教不出劈天的人。
- 传承：风铃那一路游侠剑，岚野家在天池边上教了几代，苍风添了在亚龙背上切开乱流那一手，Epic。955年在霜眠群峰北头的山脊上，他迎着那一大片空劈出一道一里来长的口子，三十七艘照着口子滑了过去，那一刀是他凝名的那一下，往后长成他那一门岚野空斩（★）。它缺一卷成文的练法，谁把劈苇到劈风的步子写下来，这一路才教得下去。
```

### 丁、不竭釜炊法（黎明的年月·约伦），Epic，料理系

照 JRPG 的料理技能写，喝下去身上多一样效果。原来“只能匀开，不能凭空变食物”的限制照留。

```
### 不竭釜炊法 (Art | Epic)

【调用】黎明的年月里，约伦凑食材、一锅喂一营，或有人学苇棚区的汤时用。

【不竭釜炊法】是苇棚区码头停工的冬天几代人凑锅凑出来的手艺，河滩上只叫它苇棚炊法。各家把东西合起来，添盐添水，够一条巷子各喝一碗（★）。约伦说，好吃不好吃另说，先得够。火候和料这一卷是成了的，拿它打仗的那一卷没有。

- 法门：火候和料。陈麦、萝卜、鱼骨、半袋盐，什么都下得锅。火候在添水，看锅里稠的东西往哪里沉，一回添多少。修到灵格，锅底会浮起一圈麦色的微光，光亮着，添下去的水就照样顶饿（★）。
- 用法：
  - 匀锅（共鸣起）。添一回水，一锅多喂一倍的人，一样顶饿（★）。
  - 暖腹汤（灵格起）。喝过她汤的人一夜不畏寒，饿着肚子打仗的乏力一扫而空，第二天天亮前疲劳恢复加快（★）。巡礼时她一口大锅喂过一营，凑来的料不够一半。
  - 不竭之釜（极境起，这一门到此为止）。一口锅不见底，人没走完就总有得舀，最后一碗和头一碗一样稠，几里外同一口锅分出去的汤也跟着不断（★）。
- 战法：没有。汤只管够，不管打。吃饱了的人打得动仗，汤自己不替谁挡一刀（★）。
- 练法：没有成册的。苇棚区家家在锅边上传，大人凑锅，孩子烧火看着，看会了添水的那一下就会了。约伦是在河滩上看几户人家凑锅学的（★）。
- 修行重点：烹饪、耐力、交涉，包括跟伙夫要食材。
- 限制：只能匀开，不能凭空变出食物。空锅加水还是水，味道也不会变好。暖腹汤管冷和乏，不管伤和病。
- 世界反应：南线的兵把难喝的汤叫苇棚区的汤（★）。
- 传承：苇棚区几代人凑出来的，起先没人命名（★）。约伦手里是 Epic，火候和料到了头，没有战用的一卷。往后行炊法成了路，凑锅匀开这一手是里头的一截（★）。
```

### 戊、宴庭座次术（白鸦的年月·莉西娅），Epic，社交系

照 JRPG 的场地类技能写，坐进她排的座位就多了一层效果。只给 AI 的那一句照留。

```
### 宴庭座次术 (Art | Epic)

【调用】白鸦的年月里，莉西娅替人排座、让孩子靠门，或出了事要从桌边让出路时用。

【宴庭座次术】是绯宴排座的老规矩，夜绯家看了几百年，座位原本定的是谁分血、谁上宴。她倒过来用，让孩子坐门边，让想走的人不用从谁背后挤过去（★）。三样里成了样子的只有练法这一卷，可排座排了十四年，她碰过的椅子会听她的（★）。

- 法门：没有。她排座靠记性和一双看手的眼睛，座次长不进她的身子里。
- 用法：
  - 定席（共鸣起）。她排过的一桌，坐下的人火气往下压，想拍桌子、按刀以前，先要过一回意志判定（★）。八个人围着桌子，她把看不顺眼的两个错开，声音就低了。
  - 退席之路（灵格起）。出了事，她碰过的椅子连人滑开，桌边让出一条通到门口的路，孩子和不想掺和的人先走（★）。雨城的长桌她排得过来。
  - 满庭席次（极境起，这一门到此为止）。一座城的宴她都排得过来，整座宴厅照她的座次坐定，出了事，所有椅子一齐往两边让，留出几条通到门口的路（★）。
- 战法：没有。真动了刀，她能做的只是请人先坐下。
- 练法：夜绯家的孩子十一岁戴上手套，坐到大人身后去看，先认门，再看谁的手放在哪里，再记谁开口前要看别人。看满几年，大人叫你把一桌的座排一回，排错了，先拍桌子的就是排错的那一个（★）。莉西娅坐了十四年，几百个人哪年坐过哪个座，她闭眼也排得出来。
- 修行重点：礼仪、交涉、察言观色。她先看门在哪一边。
- 限制：只管自己肯坐下的人，被押来的不算。她挪得动椅子，挡不住刀，也不能让仇人就此和好。
- 世界反应：雨城人家摆宴，靠门那一截留给孩子坐（★）。
- 传承：绯庭一路的座次，夜绯家看了几百年（★）。她把纷争纪高座的座次倒过来用，起了这一版，练法一卷，Epic，缺一套出了事拿来护人的战法。只给 AI，758年霜降月七夜她补成宴庭情报术，Legend，叙述不提前说。
```

## 四、规模和下一步
