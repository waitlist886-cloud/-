# 命星重审第二轮·样稿第二版（11-19 夜）

第一版（`样稿_第一版.md`）用户看了以后补了两件：

- 品级搭配。月银纪那时说过不用强求全 Legend，Epic 也行，结果往后差不多每位旅伴都是两颗 Epic。该给 Unique 就给 Unique，该给 Legend 就给 Legend，搭配要多样。
- 文风。一切词汇、内容、文风参考异世界轻小说和 JRPG。

这一版照这两件改了口径和样稿，页还没动。

## 二、口径草案

### 品级

1. **档照底卡命星总则的四种世界反应定。**
   - Rare：改变一个普通人的起点。世界不反应，公会办事员多看一眼。
   - Epic：撑得起一个流派。流派会反应，有人想收你，有人想赶你走。
   - Legend：百年一出，名录记得下。国家、圣堂、魔神将、迷宫深层会对你另眼相看。
   - Unique：命运性、神话级，同一时刻世上只有这一个。正神注视、执政留痕、圣堂立案。
2. **旅伴是这个时代最有天赋的年轻人。** 天赋那一颗（多半是 Special）起步就是 Epic，往上给。身子那一颗（多半是 Passive）可以低到 Rare。两颗不必一样高。
3. **一页里掺着排。** 不是配额，是参照：一页十几位旅伴，Unique 一两位（这一段的主角，命运落在他身上的），Legend 三到五位，其余 Epic；Passive 里有几颗 Rare。搭配举例：
   - Unique+Rare：命运压在一副寻常的身子上。
   - Legend+Legend：从头到脚都是天才。
   - Legend+Rare、Epic+Rare：天赋出众，身子普通。
   - Epic+Legend：身子比天赋更稀罕。
4. **Unique 放宽。** 10-19 那条“只给神当着众人为他动过的那一颗”，改成：命运性、神话级、世上同一时刻只有这一个、世界会反应的，都给 Unique。神当众动过的那一颗照旧算 Unique 的一种。
5. **数值照底卡。**
   - Rare：判定小幅提升，或一项属性 +10%。
   - Epic：Special +15%，Passive +20%。
   - Legend：Special +40%，Passive +30%。
   - Unique：巨额，写成倍数或 +100% 以上。
6. 品级跟位阶照旧分开算。灵格的孩子可以身上带着 Unique。

### 文风

1. **参考异世界轻小说和 JRPG。** 星名照底卡命星池的起法：魔力洪流、元素精通、钢铁之躯、零迹步、鹰眼。
   - 高档的名字华丽、有点中二，像技能列表里一眼认得出的大招（风之宠儿、破晓之声）。
   - 低档的名字白、短，像状态栏上的一行（瘴毒耐性、炽血体质）。
   - 第一版那种“意象＋身上一处”的四字名（晓角胸腔、咸潮之腹）偏文学，不再当主路。
2. **说明头一句照底卡：** 【X】是什么样的天赋或体质，什么人家出这种孩子最多。再一句这个人小时候它头一回露出来的样子。
3. **效果写得像游戏。** 免疫什么，判定获得优势，属性加多少，范围多大，CD 多久，用完付什么。不写成白描散文。
4. **世界反应照档写。** Rare 不写，Epic 写流派，Legend 写国家和圣堂，Unique 写神。
5. 西幻语域、卡面标点、禁词照旧。

### 第一版里照留的几条

- 命星是本钱，不是摘要。从这个人的血、家、身子、出生的地方长出来。
- 两把尺子：换一个出身相近的人也成立；只看星名猜不出结局，读完故事认得出他是靠这一身走到那一步的。
- 剧情里的选择留给人去做，不做成星。
- 习惯和差事不做成星。写得出超凡的写出来，写不出来的给 Rare。
- “头一回露出来”挑小时候、少年时的事，不挑结局那一夜。

```
### 破晓之声 (Special | Legend)

【调用】长夜的年月里，弗洛里安吹号、喊人起身，或者有人叫睡过去、冻僵了、被梦魇拖住时用。

【破晓之声】是声音里带着天亮的天赋，号声、喊声，哪怕是一句叫人起床的话，听见的人都会醒透。下街的老人说这样的嗓子百年才出一个，车夫家里出得最多，天不亮一声吆喝，一条街的马先竖起耳朵（★）。弗洛里安十八岁进不锈号角，头一回在行会楼梯口吹起身号，通铺上二十几个人一齐坐了起来，团长说他吹得人想起床，不想打仗。

- 被动：听见他号声和喊声的友方立刻清醒，困倦、冻僵和恐惧带来的迟缓一扫而空。中了睡眠、魅惑、梦魇的人，听见他的声音可以再判定一次，判定获得优势（★）。MIND／VGR +40%。
- 主动：CD 24h。吸满一口气吹响起身号，号声像天边亮起的第一道光，沿着城墙往两头传。范围里的友方解除睡眠、冻结和恐惧，接下来一刻钟行动加快（★）。灵格时覆盖一座门楼，极境时覆盖一整座段城，到了英雄，号声走过的那一段长垒，墙砖上的霜一路化开（★）。吹完嗓子哑一天，号吹不响。
- 修行关联：乐器、意志、统率。跟长垒接号调同用，号谱给它说法，嗓子给它天亮。
- 限制：号声不分敌我，墙外的东西也会醒，也听得出号从哪里来，吹响的人会成为整片战场最显眼的目标。叫得醒人，叫不出胆子，醒过来想跑的照样会跑。
- 世界反应：号手行会和圣堂的晨祷班都想要这副嗓子（★）。北段的老兵说，半夜的起身号要是吹得像天亮，就是有东西摸上来了（★）。

【炽血体质】是血比常人热的体质，红头发的人家里常有，冬天抱在怀里像揣着一只暖炉（★）。弗洛里安到北段的头一个冬天，夜岗上别人冻得说不出话，他呼出来的气不起白雾（★）。

- 被动：耐寒，冷风里守一夜手脚不僵。呼气不起白雾，雪夜里更难被发现。VGR +10%。
- 修行关联：耐力。
- 限制：怕热，屋子一暖就犯困。热的只是血，火和毒照样伤他。
```

结局那一夜是破晓之声用到头：他挂着别人的腰牌守在门洞里吹响起身号，整座段城醒了，他成了夜里最显眼的那一个。腰牌照旧是他为了赎车行自己选的，写在旅伴条和主线里。

### 乙、马克斯·奥兰（白鸦的年月），Epic + Rare

原来是压阵肩胛（Epic）、码头肠胃（Epic）。前一颗出身和用处都对，只是看不见魔法；后一颗是习惯，够不上 Epic。他是后来奥兰家的祖上，莱恩哈特那一身站门的骨头往上数就数到他，前一颗留 Epic，给后人长到 Unique 留出路。

```
### 不动要塞 (Special | Epic)

【调用】白鸦的年月里，马克斯身边号令乱了、有人慌了、有东西撞上来，或者他把枪尾顿在地上时用。

【不动要塞】是站定了就推不倒的天赋，码头扛包的人家出这种孩子最多。几代人把整船的分量往肩上扛，扛到他这一辈，压在肩上的分量会顺着骨头沉进脚下的地里（★）。他七岁替父亲扛头一包盐，跳板晃，他没晃（★）。

- 被动：站定时免疫击退和撞倒，左右三步内的友方也跟着站稳。号令乱了、阵前发慌的时候，稳住队列、劝人停手的判定获得优势。VGR／MIND +15%。
- 主动：CD 24h。枪尾往地上一顿，喊一声站住，周围的人脚下像生了根，冲锋的、溃逃的、犹豫的，都在原地停住一口气（★）。共鸣时管得住一排人，灵格时一座门楼，到了极境，整座段城的墙头一齐站定。用完左肩青一个月。
- 修行关联：统率、耐力。配着城卫枪术守门，身后的人也站得稳。
- 限制：钉得住脚，钉不住心，铁了心要打或者要逃的人，站住一口气就会挣开。位阶比他高的人、下令的人不受影响。

### 瘴毒耐性 (Passive | Rare)

【调用】白鸦的年月里，马克斯吃发霉的口粮、喝不干净的水，或者有人中了瘴时用。

【瘴毒耐性】是吃什么都不坏肚子的体质，码头和苇棚区长大的孩子多少有一点。马克斯喝着苇棚区那条发黑的沟水长大，一回也没病过（★）。

- 被动：霉变、腐坏的食物和沼地的瘴气对他无效。半份口粮撑一天，饿两天力气不减。VGR +10%。
- 修行关联：耐力。
- 限制：防得住霉和瘴，防不住下给人的毒药。尝不出好坏，什么都说好吃。

### 丙、艾德温·岚脊（七城的年月），Legend + Epic

### 风之宠儿 (Special | Legend)

【调用】七城的年月里，艾德温在风口、崖边、车篷顶上出剑，或者风突然替他转了向时用。

【风之宠儿】是被风偏爱的天赋。风铃高原上的说法是，风会认出自己的孩子，认出来的那一个，风替他让路，替他送剑（★）。艾德温六岁在牦牛群里走丢，一场白毛风刮了一夜，第二天大人找到他，他坐在一圈倒伏的草中间，四周的雪一片也没落进来（★）。

- 主动：CD 24h。屏住一口气看准一道线，整片风顺着那条线先他一步冲过去，剑跟着风落下，剑痕沿着风走过的路一直裂开（★）。极境时一剑劈得开一扇城门，到了英雄，劈得开一道封死的山口，838年白母口那一剑就是这样劈开的。用完一天之内，风不再回应他。

### 凌风之足 (Passive | Epic)

【调用】七城的年月里，艾德温站在车篷顶、冰坡、崖边，或者横风大得别人站不住时用。

【凌风之足】是在哪里都站得稳的体质，高原放牧的人家常有。艾德温在晃着的车篷顶上坐一整天，一只手也不扶（★）。

- 被动：免疫强风、摇晃和湿滑地面造成的失衡，悬崖、屋顶、行进中的车顶上如履平地，攀爬和平衡判定获得优势。DEX／VGR +20%。
- 修行关联：身法、耐力。
- 限制：脚下得有东西踩，悬空就没用。站得稳不等于扛得住，重锤照样把他砸飞。

### 丁、Unique 给谁

这一回没写新的 Unique 样稿，尺子先对着现成的几颗：

- 底卡艾莉娅的魔力洪流：魔力本身比这个人大，星环奥法总塔立案。
- 诺伦的应许之晓：神当众动过的那一颗。
- 索恩薇娅的万夜一晓：纷争纪那一万年的夜结出来的一个早上。

往后筛表的时候，每页挑出这一段的主角、命运落在他身上的那一两位，单列成 Unique 候选给你定。

## 四、Rare 技艺加魔法（照新文风改了口气）

规矩同第一版：没有法门，不随位阶长，世界不反应，可手上要有一处看得见的小魔法；行当做久了会沾灵（★）。这一版效果写得更像游戏。

```
### 长厅点人谣 (Art | Rare)

【调用】长夜的年月里，丽芙唱谣点人，有人在雪里走散，或有人想跟她学北境数人的谣时用。

【长厅点人谣】是北境长厅数人用的歌谣，一户一句，唱进谣里的名字会应声（★）。丽芙跟祖母学来，又把它唱长了，一万一千人，两千多句（★）。没有法门，几百年的长厅都拿它点人，名字和歌缠在了一起（★）。

- 用处：她从队头唱到队尾，几百户逐句答应，暴风雪也盖不住。被唱到的那一家，一夜之内不会冻僵、不会在雪里睡过去，走散的人耳朵里一直响着自家那一句，顺着它走得回队伍（★）。327年没有日头的深谷里，三百来人就是听着自家那句牵手跟出来的。
- 限制：只管杆上有、又听得见的人，昏过去的、死了的叫不回来。得一句一句唱完，她半路停下，后面的人就断了。效果只撑一夜，唱得再熟也不会传得更远（★）。
- 传承：北境长厅老人传下来的谣，原来没有名字，丽芙把它唱成一万一千人的那一版，南枝村后来照她唱，长厅分肉前也是老人先唱一遍。祖母教她的话是，数人要叫名字，光数数不算。

### 割苇人左捻绳法 (Art | Rare)

【调用】共约的年月里，茉德捻一根绳、接一根断绳，或者有人想学三河东岸的苇绳的时候。

【割苇人左捻绳法】是三河东岸割苇人家捻苇绳的手艺，绳街上只叫左捻。茉德的祖母给渡口的船家捻，她十六岁把这一手带进绳街，跟老匠人学的麻绳打法掺在一处（★）。没有法门，几代人捻下来，苇绳沾了河的性子（★）。

- 用处：一夜捻得出一卷下井的长绳，三个人吊在上头不响一声，苇子、树皮、撕开的布、头发都捻得成。她捻的绳遇水反倒更韧，黑暗里发出苇叶一样的青光，井下的人顺着光摸得回井口（★）。她打的结只认她的手，别人拽不开，她一碰就松（★）。
- 限制：手里得有东西捻。撑得住人，撑不住塌下来的屋顶。青光只照得见绳子，照不亮路（★）。她不在，那个结谁也解不开。
- 传承：三河东岸割苇人家几代人捻出来的苇绳。茉德把它跟绳街老匠人的麻绳打法合在一处，往后绳街上的苇绳是她这一版，学徒婕西·富特接了下去（★）。

### 城卫枪术 (Art | Rare)

【调用】探井的年月里，雅尼斯挺着长枪和圆盾守一个门洞、一道豁口，或者有人问起段城的兵上墙先学什么的时候。

【城卫枪术】是长垒段城的兵人人要学的守门枪，一杆枪一面盾，横在门洞里。整门是墙上传了一万多年的东西，雅尼斯十七岁上墙，学了两年，手里只有头几课（★）。头几课没有法门，可一万多年的兵在门洞里摆过同一个架子，长垒的白石认得它（★）。

- 用处：门洞横枪式。盾立在左脚前，枪从盾沿上探出去，一个人守得住一个门洞。架子一摆开，门洞两壁的白石跟着一沉，撞上来的东西先撞在一道看不见的横杆上，冲击减半，才碰得到枪尖（★）。潮翻上来那几天，他守的就是水门段城的西门门洞（★）。
- 限制：只有头几课，换位、接阵、退着守都还没学。只在长垒的门洞里灵验，离了白石，一杆枪照样会被绕过去（★）。
- 传承：段城的老兵带新兵，上墙头两年学的就是这几课（★）。往下的课在墙上，他下了井，没有人接着教。

### 审判庭誊册法 (Art | Rare)

【调用】长夜的年月里，莫里茨誊册、记日子、归档、找旧档，或有人想学这门手艺时用。

【审判庭誊册法】是审判庭书记房把事情记进册子、几十年后还翻得出来的手艺。日子按落墨那天记，归了档的册子不能撕（★）。没有法门，书记房几百年誊下来，墨里沾了灵，誊过的字认得自己（★）。

- 用处：誊的字跟原件一模一样，一夜几十页，前后日子对得上。他誊过的册子，谁再添一笔、刮一个字，那一行的墨会洇开一圈，像落了一滴水（★）。老书记的手摸过册脊，要找的那一册会自己凸出半指（★）。
- 限制：只管誊和记，不管判。原件错了，誊下来的也错。洇开的那一圈只告诉人这一行被动过，不告诉人是谁动的（★）。
- 传承：断罪一路的书记手艺，从纷争纪长垒军法官合写的册子里分出来，止戈后一支流进审判庭，泰奥多尔教给莫里茨，头一句是誊册子的人不改（★）。后来分出段城书记房的段城对册法、施莱伯家进冠台那支的冠台回声复现术，留在审判庭的一支到阿玛莉亚手里成了审判庭存疑律（★）。

## 五、规模和下一步

四纪各页生来的 Special 约五百二十颗，Passive 约四百四十颗，Rare 技艺约两百一十门。

1. 口径、品级和文风你认了以后，先出一张筛表。
   - 每颗生来的星归三档：对，照留；轻改，出身对得上，补魔法或者调档；重写，射箭画靶或者只是习惯。
   - 每位旅伴拟一个新的品级搭配。
   - 每页标出 Unique 候选，给你定。
2. Rare 技艺全数过一遍，每门加一处魔法。这一件可以跟筛表同时做。
3. 照上一轮的路子走 API 批处理（写手 Fable、审稿 Opus），一页一份。改了名的星走 `rename_stars.py`，跟着换旅伴条、主线、羁绊、门面数据，真名层（`star_true.py`）重跑。
4. 活到 1001 年、底卡里有真名的那几十位，名字和档都不动，只看写法。
5. 跟着改的口径：CLAUDE.md 写作口径里命星那一节（品级、Unique、起名）和 `底稿/命星高魔化/铺开/写法说明.md` 的 Rare 那一行。
