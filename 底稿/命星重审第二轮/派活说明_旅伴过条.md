# 派活说明·旅伴过条（11-20）

你给一张日式西幻 JRPG 跑团卡《奥尔德兰的旅印》逐个过旅伴条，全程用中文。高魔世界，剑与魔法，异世界轻小说和 JRPG 的口气。技艺已经照新口径重写过（招式表、构成、阶）。这一回每位旅伴做三件事：能力行里的技艺带上开局在第几阶；添一行兼修；照提醒改生来的星。

## 二、三件事怎么做

### 1. 能力行里的技艺带开局阶

能力行里的 Art 照底卡状态栏的写法带上开局在第几阶：`Art【X】(Epic·二阶，原来那一句注)`。开局阶照这个人开局时的位阶、阅历、技艺走势，对着那一门的「阶」那一行（材料里给了）定。开局就高的（灌顶、血脉、天才自创、合天赋有人教）照走势里写的。别的字照原样。

### 2. 兼修

照第一节第四节（兼修：一个人不只一门）写一行：

`兼修：【X】(档，一两句：哪一年、跟谁或在哪里学的，补什么短板或推什么长处，学到了哪几科)｜【Y】(……)`

- 启源、共鸣的少年人零到一门。灵格往上一到两门。英雄、传奇、长生种至多三门。没有一件事撑着的不添，写 `兼修：无`。多数人有一门就够，别为了凑数添。
- 从哪里挑，按这个先后：这一纪的公共技艺（材料给了清单），这一纪页上现成的技艺（材料给了这一页的，别页的写全名也行），底卡技艺池子（见第三节，那是迷宫纪 1001 年的东西，迷宫纪前传可以借，早几纪只借有来历的）。照命路的跨路兼容挑（第三节）。
- 档写他手里那一版，多半比主修低一两档。学了别人那一门的几科，就写学到了哪几科。
- 施法的兼修两条施法路（魔法使和元素使），限制里写一句越高阶越容易框架打架。
- 兼修也要往技艺走势里补一句：`走势补：……`，写哪一年、哪件事学的，接在原来那一行的末尾读得通。没有兼修写 `走势补：无`。

### 3. 生来的星

材料里给了这一页的「生来星提醒」和这个人在 11-20 那一轮的换名记录。照第一节「命星可以重复」那几条：

- 提醒说档偏高、偏低的，改档，整条星条重写（照原来那一条的事实和写法，换档、换数值）。Unique 只留给命运性、神话级、同一时刻世上只有这一个的。
- 提醒说“某族、某家、某地常有”的，这一颗的星条首段补一句谁家常有，整条交回来。
- 同一页里两三个人同家、同族、同地，体质本来就是一样的，可以并成共用的一颗：在 `【并星】` 里写，能力行里用共用的那一颗的名字，被并掉的那一颗的星条就不要了。共用的那一颗星条补一句谁家常有、这一页谁有。
- 11-20 那一轮照“不许重名”给他另起的星（材料里写了原来叫什么），同家、同地、同血的可以改回原来共用的那一颗，也写进 `【并星】`。起得好、本来就该各是各的，留着。
- 提醒里拿不准的、跟故事打架的，不改，在 `【没改】` 里写一句为什么。
- 跨页的同一个人，材料里会写“生来的星在别页改”，这一页只写能力行的阶和兼修，Special、Passive 照原样。

## 五、交什么

一位旅伴一段，照材料次序：

```
====
【旅伴】全名
能力：整行
兼修：…… 或 兼修：无
走势补：…… 或 走势补：无
```

全部旅伴交完以后，再交这一份里改了的星：

```
【星条】
### 名 (Special | 档)
……整条……

【并星】旅伴全名｜被并掉的星→共用的星｜缘故（一句）
【没改】旅伴全名｜星名｜为什么没照提醒改（一句）
```

没有改星就不写【星条】那一段。星条的格式照原来那一条（【调用】、首段、被动、主动、修行关联、限制、世界反应这几行），标题写这一颗的名字，名字只有并星的时候才换。前后不加别的话。
