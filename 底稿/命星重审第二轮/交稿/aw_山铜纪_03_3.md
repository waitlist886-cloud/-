### 合山封石术 (Art | Epic)

【调用】白鸦的年月里，戈特哈德凿石头封口、顺着缝劈石头、替人看地基，或有人要学这门手艺时用。

【合山封石术】是石饲之乡封石匠施泰格家传了四百年的整门石工，乡里只叫它封石匠的合缝术。选料、叩缝、合石、分石、看地基，都在这一门里。他凿出的石头封住口子，合得一根头发也塞不进，山里的根也钻不过（★）。反着用，他就能找到石缝，一錾子劈开。凿法和料一辈一辈传得清清楚楚，成了的是练法这一卷。拿到仗上用的那一卷，这一家从来没有。

- 法门：没有养人的那口气，撑着它的是手艺，料和凿法。料是山南带铜层的石头，根钻得穿石，钻不穿铜。凿到要紧的地方闭上眼，拿指节敲，敲准了吃劲处再落錾子（★）。最后一錾念着家名和年份落下去，字进了石头，封石就成了一道界（★）。修到灵格，指节敲过的石面会留一圈铜绿色的微光，圈住吃劲处（★）。修岔了叫憋石，合得太急，劲憋在石头里，过不了几个冬天自己崩开（★）。
- 用法：
  - 叩缝（一阶起）。指节一敲，认出一块石头的吃劲处、暗裂和走向。一块石头敲三下，一面墙、一处地基要走着敲一遍（★）。
  - 合缝（三阶起）。铜石封口，头发塞不进，根钻不过。一块门板大的铜石封得严一道山口，落了家名和年份的封石是一道界，石头不碎，界不散（★）。从抽签那一夜到封山那一天要十天，一天也省不下。
  - 分石（三阶起）。顺着缝一錾劈开磨盘大的石头。砸自家的封石，要念着当年落錾的家名和年份，界先松开，石头才碎（★）。641年雨来，他这样九天砸完了四百块。
  - 山门合分（五阶，极境，这一门到此为止）。一面山墙在手底下合得上，也分得开。合一回要备一季的料，做完半个月握不住锤（★）。戈特哈德没走到这一步，这是家里传下来的说法。
- 战法：没有。出的东西是一块封石，封得住山口，挡得住根。拿它打仗，他不会，錾子对着人只是一把錾子（★）。
- 练法：父亲手把手教。先扶石头，再学敲，听得出缝了才许落錾子（★）。自己凿的头一块封石春天封上山口，过了一冬根没钻过，才算过关（★）。他父亲把凿子交给他那年说：“手艺是手艺。”（★）
- 构成：
  - 叩缝（发现隐藏、鉴定）。闭眼拿指节听石头，空、裂、水、铜和吃劲处。
  - 选料（采集、鉴定）。上山认带铜层的石头，一块料看得出封得住几年。
  - 凿法（锻造、耐力）。錾子和短柄锤的手上功夫，铜石要过火，十天不歇手。
  - 落名（识字、意志）。家名和年份錾进石头，念的人心里不能虚。
  - 缺的一科。把合石、分石用到墙上和仗上，这一家没有练法，也没有 Skill 撑着，所以是 Epic。
- 阶：一阶，发现隐藏到熟手。二阶，采集、鉴定到熟手，锻造到熟手。三阶，锻造、发现隐藏到匠人，识字到熟手，位阶灵格。四阶，锻造到名匠，耐力到匠人。五阶，锻造到宗匠，发现隐藏到名匠，位阶极境。戈特哈德在四阶。
- 限制：他只会凿普通石头和铜石，木头、铁和人都不行。劈石头也得找得到缝。凿一块封石，从抽签那一夜到封山那一天要十天，一天也省不下。界只认石头，石头碎了，界跟着没有（★）。
- 世界反应：乡里的门槛都是他家凿的，谁家盖房，也请他们看地基（★）。
- 传承：施泰格家传了四百年。戈特哈德597年接父亲的凿子，手里是练法这一卷，Epic。641年他砸完封石，从此只用分石那一半。往后他收汉娜做学徒，只教分，不教合。它缺的是战法，谁把合石、分石用到墙上和仗上，才算补上（★）。

### 闭目千步射术 (Art | Epic)

【调用】白鸦的年月里，卡尔恩在烟雪黑夜里放箭，或有人想学他看不见也射得中的弓时用。

【闭目千步射术】是远望猎队的弓在卡尔恩手里长出的一卷射法，北境走雪线的车夫只叫它盲射。远望的人站在山脊上替全队看，他把看过记住的东西接到了弓弦上。644年守雪线，三步外全是白的，他闭眼听风，记住白母的位置，练到箭能落在记着的地方（★）。它只有战法这一卷，法门空着，练法没成册。

- 法门：没有。这一路射法不养人，靠的是他生来那双眼睛记下的东西和一口稳住的气，位阶是他在山脊上守了十年熬出来的。那口气放完一箭就散，要睁眼重认一回才聚得起来（★）。
- 战法：
  - 记靶（一阶起）。看过一眼的靶，记住它站的地方、风从哪边来、它挪步的声音，闭着眼把箭送过去。烟、雪、黑夜里五十步内射得中。一回记得住三个靶，记得住一顿饭的工夫（★）。
  - 听弦改矢（三阶起）。靶挪了，等它再出一声，搭在弦上的箭跟着改，两百步内不落空（★）。闭着眼的时候他顾不到身边，要有人替他守着背后（★）。
  - 雪幕一矢（五阶，极境，这一门到此为止）。看过一眼的靶子，隔着黑夜、暴雪、烟墙，一里外照样射中，差不出一掌。放箭前要静听风过三回，放完那口气就散了（★）。644年归寂月下旬那一箭从白母后颈进去、眼窝出来，就是这样射的。
- 练法：没有成文的。他自己在山脊上认清一样东西，闭眼，数着风放箭，放完睁眼去看差了多少，一天不落（★）。他没教过谁。
- 构成：
  - 认靶（发现隐藏、记忆）。闭上眼以前，先把看见的记牢。
  - 听风（发现隐藏、意志）。风从哪边来，靶挪步是哪一声，三步外全白也要听得出来。
  - 弓本身（武器熟练度·弓）。猎队的短弓，十年一天不落放出来的。
  - 闭眼的气。缺。该落在冥想上，可他没有成套的练法，这口气是熬出来的，一箭一散，所以是 Epic。
- 阶：一阶，弓、发现隐藏到熟手。二阶，记忆到匠人。三阶，弓、发现隐藏到匠人。四阶，弓、记忆到名匠。五阶，弓到宗匠，发现隐藏到名匠，位阶极境。641年他在四阶，644年冬在雪线上到了五阶。
- 限制：没看过、没听过的射不中。风乱会差一指，人挪了，要再听一声才能跟上。一箭一口气，连不成串。
- 世界反应：北境走雪线的车夫，雪大的日子出门以前说一句，脊上有人。
- 传承：各自一门（★）。远望猎队传下的弓，631年以后他在南境山脊上守了十年，长出这一卷战法，Epic。它缺一门法门，谁给它配上一口闭着眼也不散的气，把认靶、记风的次第写成册，这一路才成得了一门。到660年没人配上。

### 十里贯阵冲枪术 (Art | Epic)

【调用】白鸦的年月里，托伦端枪冲锋、撞开拒马兽群，或有人想学他的骑枪时用。

【十里贯阵冲枪术】是托伦一路跑出来的骑枪，南段的骑兵只叫它撞阵。冲得越远，撞得越开。他说不出道理，跑起来枪就重了。十岁后他看南段骑兵学会握枪，没有老师，是一匹马接一匹马在墙后的大道上跑出来的（★）。它只有战法这一卷。

- 法门：没有。枪的分量从马的步子里来，不从他身子里来，马一停，枪就轻了。
- 战法：
  - 蓄势（一阶起）。起步的十几步是寻常一枪，往后每跑一里，枪重一分（★）。马不停，攒下的分量不掉。马一停，从头再跑。
  - 破拒（三阶起）。冲过一里，一枪破得开拒马和薄门，后面跟着的一队人马能从缺口进去（★）。枪头挂了东西也不停下来摘。
  - 贯阵（五阶，极境，这一门到此为止）。冲过十里不停，一杆枪抵得上撞城锤，撞得穿兽群，把魔物潮的后队撞个对穿。穿过去以后要再跑出一里才收得住马，掉头又是一回起步（★）。651年坠叶月他一昼夜跑了三百里，就是从赤盐边镇外那一股潮的后队正中这样穿过去的。
- 练法：没有。他换着马跑，跑停了再上一匹，没有次第可教（★）。南段老兵叫学冲锋的人先跑三里再端枪，是从他身上学去的一句话，算不上一套练法。
- 构成：
  - 跑（骑术、耐力）。十里不停，人和马一口气。
  - 枪（武器熟练度·枪）。端得平，撞上了不脱手。
  - 看路（发现隐藏、旅行）。看路，不看前面的东西。
  - 起步和急弯。缺。那十几步和拐弯时的劲没有练法，也没有哪一门 Skill 撑着，所以是 Epic。
- 阶：一阶，骑术到熟手。二阶，枪到熟手，骑术到匠人。三阶，枪到匠人，旅行到熟手。四阶，骑术、枪到名匠。五阶，骑术到宗匠，耐力到名匠，位阶极境。645年花信月他拴马入白鸦时已在五阶。
- 限制：起步的十几步只是寻常一枪，冲起来才重。拐不了急弯，马倒了，枪的分量也落一大截。窄巷、林子、楼里跑不开，这门就只剩握枪的手。
- 世界反应：南段的骑兵学冲锋，老兵叫他们先跑三里再端枪。
- 传承：各自一门（★）。他跑了十二年，自己跑成了这一卷战法，Epic。它缺一口在急弯里也不散的劲，谁把起步那十几步补上、写成骑兵学得会的册子，这一路才成门。到660年没人补上。

### 破封崩门重剑术 (Art | Epic)

【调用】白鸦的年月里，霍德抡重剑砸门墙、塌方和封印，或有人想学他只砸不砍的剑时用。

【破封崩门重剑术】是霍德拿维格迪丝·炉脉打的厚刃重剑砸出来的技艺，炉城和断崖一带只叫它砸门。它专为开路，不用来杀伤，他的剑没有一处是砍出来的，全是砸出来的凹痕。断崖一支开山时顺石缝下锤的手法，加上他半辈子锁匠的手，合成了这一卷战法（★）。法门没有，练法没成文。

- 法门：没有。撑着它的是一门手艺，锁匠摸门的那一套，门闩在哪边，承重落在哪里，石缝往哪里走。他身子里没修出什么，力气是矮人生来的，准头全在手上。
- 战法：
  - 摸缝（一阶起）。砸以前先把手掌贴上去，认出门闩、承重和石缝，定下头一剑落在哪里。一扇门几息就够，一面墙要走着摸一遍（★）。
  - 崩门（三阶起）。包铁门和顶死的地窖盖几剑砸开，砸开后一时合不上。城门、塌矿、封死的石门破得出容人钻过的洞。651年赤盐边镇的地窖是这样砸通的。
  - 碎封（五阶，极境，这一门到此为止）。符文墙和封印门连符带槽一起碎，碎的那一下剑不收，门后冲出来的东西正撞上下一剑（★）。门越老，要砸得越久，中间停了手，前面的要重新算（★）。651年他把升起来的门闸连符带槽砸回门槛。655年铁瀑他砸了一天一夜又大半天，古门连着符文墙碎了，第二百三十七下落在门后那东西头上。
- 练法：没有成文的。648年离了炉城，他一扇门一扇门砸过来，砸前贴手，砸完再摸一遍断口，记下这一扇本该落在哪里（★）。他没教过谁。
- 构成：
  - 摸门（鉴定、锻造）。锁匠的手，铁、石和木的吃劲处一摸就有数。先摸准，砸错一下要多砸十下。
  - 落剑（武器熟练度·重剑、耐力）。断崖开山顺缝下锤的手法换到剑上，一天一夜不歇。
  - 认符（魔法装置）。符刻在哪道槽里，先碎哪一处整面墙才跟着垮。
  - 誓。缺。誓锤里一句誓要有人在场听见才算的那一层没进来，也没有一口养人的气，所以是 Epic。
- 阶：一阶，鉴定到熟手。二阶，重剑到熟手，锻造到熟手。三阶，重剑到匠人，鉴定到匠人。四阶，重剑到名匠，魔法装置到匠人。五阶，重剑到宗匠，耐力到名匠，位阶极境。他锁匠的底子在，离炉城三年，651年在赤盐边镇就到了五阶。
- 限制：砍人只是卷刃的重剑。能砸开门，挡不住里面的东西先咬一口。活的东西、没有缝的整块山岩，这门认不出落剑的地方。
- 世界反应：断崖孩子学他砸门，先把手掌贴上去（★）。
- 传承：誓锤锻律里断崖一支的旁枝（★）。断崖开山的手法和锁匠手艺在他手里成了这一卷战法，Epic。它没有一口养人的气，誓锤里一句誓要有人在场听见才算的那一层也没进来，谁给它配上法门，才回得到誓锤那一门里。到660年那一层没进来。

### 高台牵袖传声法 (Art | Epic)

【调用】白鸦的年月里，莉赛尔传令、领人走出烟雾、雪盲和塌矿、喊住迷途的人，或有人想学她喊路时用。

【高台牵袖传声法】是西陆旧家系的嘴传下来的整门传声，鸦旗底下和墙下的村子还叫它引路声。族里一代出一个嘴，站上高台，把营主的话一句一句传遍全营。跟了白鸦，她把全营同听一道令改成一句“往这边走”，声音里牵出一根看不见的线，系在听的人袖子上（★）。几辈人的令把这副嗓子磨成了一条听得见的路（★）。用法这一卷成了，法门没有，练法只有高台上那半截。

- 法门：没有。靠的是她生来那副嗓子，嗓子哑了，这一门就没有了。
- 用法：
  - 传令（一阶起）。站在高处说一句，一座营的人同时听见，一字不差，远的近的一样响（★）。
  - 牵袖（二阶起）。看不见的人跟着她的声音认路。被喊到的人脚下三步之内像有人牵着袖子，闭着眼也不踩空，一句管到他走出看不见的那段路（★）。雾里十几个人分几路，她各喊一句，谁也不听错。几百人从塌矿、烟和雪盲里也领得出来，井和坎提前说清。
  - 唤归（三阶起）。对着雪下、雾里迷了路的人喊，线系在他身上，他听得见就不散神，不睡过去，认得出声音从哪边来（★）。她得一夜不停，停了线就断，一回喊得住三五个人（★）。644年冬天卡尔恩埋在雪底下，她在长厅门口喊了他一夜。
  - 声垒（五阶，极境，这一门到此为止）。一句话出口，同时落遍一道长垒，各段各听各的令，东段听见的是东段的话，谁也不串（★）。一道墙撑得住一场围城，各段的话得先有人告诉她。651年赤盐边镇被围，她把卡尔恩的话这样送遍各段墙。
- 战法：没有。她的声音只指路、只传话，伤不了人，也替不了谁挡一下。
- 练法：半卷。旧家系教嘴的规矩只教高台那一截，七岁上台，一句不许改，一字不许慢。牵袖往后的几招是她自己改出来的，没有次第，她没教过谁（★）。
- 构成：
  - 嗓子（音乐、耐力）。吐字、送气、一夜不停。
  - 传令（记忆、统率）。别人的话一字不差送到，几路人各是哪一句，心里不乱。
  - 喊住人（交涉、意志）。叫得出名字，说得出叫人肯迈步的那一句。
  - 认路。缺。看不见的地方她自己也看不见，眼睛是借别人的，这一科没有练法，她身上也没有 Skill 撑着，所以是 Epic。
- 阶：一阶，音乐、记忆到熟手。二阶，音乐到匠人。三阶，统率到匠人，交涉到熟手。四阶，音乐到名匠，意志到匠人。五阶，音乐到宗匠，统率到名匠，位阶极境。641年炎潮月她在井边改出牵袖，是二阶。644年冬到了唤归。651年在赤盐边镇到了五阶。
- 限制：路得真有，她喊不出一条没有的路。看不见的地方要有人替她看，卡尔恩不在就喊得慢。嗓子哑了就没有，喊得再响，也只管指路。袖子上那点劲只带得动肯跟的人，站着不走的、捂住耳朵的，她牵不动（★）。
- 世界反应：长垒南段墙下的村子起了雾，孩子们在井边学着喊“往这边走”，学的只是那一句。
- 传承：旧家系几辈人传令，高台那一截是教嘴的老规矩，凡人的手艺。614年她七岁头一回上台，630年开春不肯再说。641年薇丝塔在井边请她喊路，牵袖、唤归、声垒是她自己一招一招改出来的，Epic（★）。它缺一口养嗓子的气，也缺一双自己的眼睛，谁把喊路的次第写成册，这一门才传得下去。到660年她没教过谁。

### 绯庭牵丝礼法 (Art | Epic)

【调用】白鸦的年月里，莉西娅主持一桌、替人排座、让孩子靠门，或出了事要从桌边让出路时用。

【绯庭牵丝礼法】是绯宴夜绯家传的礼法，红园的人叫它牵丝礼，雨城长桌边的人还叫它宴庭座次术，只当那是夜绯家排座的规矩。绯宴的礼数里浸着魅魔的魔力，行礼的人指尖牵出看不见的绯色细丝，系在入席的人身上，坐下、举杯、开口、离席，都照规矩一步一步来（★）。夜绯家几百年拿它定谁分血、谁上宴。莉西娅倒过来用，让孩子坐门边，让想走的人不用从谁背后挤过去（★）。三样里成了的是练法这一卷，战法只有半卷。

- 法门：没有成文的。牵丝靠的是魅魔生来那一点叫人回应的魔力，礼做得越周全，丝越韧，自己先失了礼，丝当场断（★）。修到灵格，她戴着手套的指尖在灯下会拖出一缕淡红的光（★）。
- 用法：
  - 礼线（一阶起）。向一个人行完一整套礼，丝便系上了。那人在这一桌上照礼数行事，拔刀、拍桌、抢话以前先要过一回意志判定，判定失败，手会自己放回桌上（★）。一回系得住三四个人，管到散席。
  - 座次（三阶起）。她排过的一桌，每把椅子都牵着丝。仇人不对着坐，坐下的人火气往下压。出了事，她一拉，椅子连人往两边滑开，让出一条通到门口的路，孩子和不想掺和的人先走（★）。雨城的长桌她排得过来。657年霜降月刀出鞘那一天，她走到两边刀中间，她碰过的椅子连人滑开。660年寒星月长桌叫人掀翻的那一夜，椅子带着人避开白火，孩子从小凳前的路出了门。
  - 礼域（五阶，极境，这一门到此为止）。整座厅成了她的礼域，规矩张在厅里，入席的人都照着走，起身先告退，动刀先报名，违了礼的人身上的丝一紧，手脚慢下半拍（★）。一座城的宴她撑得住，撑一夜。白鸦的年月里她没走到这一步。
- 战法：半卷。丝管得住守礼的人，管不住不讲礼的人。真动了刀，她能做的只是让出路。
- 练法：夜绯家的孩子十一岁戴上手套，坐到大人身后去看，先认门，再看谁的手放在哪里，再记谁开口前要看别人。看满几年，大人叫你把一桌的座排一回，满桌的丝都系得上才算过，排错了，先拍桌子的就是排错的那一个（★）。莉西娅坐了十四年，几百个人哪年坐过哪个座，她闭眼也排得出来。
- 构成：
  - 看席（发现隐藏、记忆）。她先看门在哪一边，再看手，再记谁坐过哪里。
  - 行礼（交涉、意志）。一整套礼做周全，自己一步不错。
  - 牵丝（控制魔法）。指尖那点魔力拉成线，系得上，拉得动，松得开。
  - 护人。缺。出了事拿丝挡刀、缚人的那一科没有练法，她身上也没有 Skill 撑着，所以是 Epic。
- 阶：一阶，交涉、记忆到熟手。二阶，发现隐藏到匠人，控制魔法到熟手。三阶，交涉到匠人，记忆到名匠，位阶灵格。四阶，控制魔法到匠人，交涉到名匠。五阶，交涉到宗匠，意志到名匠，位阶极境。655年她起这一版时在三阶。
- 限制：只管自己肯坐下的人，被押来的、不讲礼的、构装和亡灵都不算。丝叫人守礼，不叫人改主意，挡不住刀，也不能让仇人就此和好。她自己失了礼，满桌的丝一齐断。
- 世界反应：雨城人家摆宴，靠门那一截留给孩子坐（★）。红园的老人说，夜绯家那个女儿的丝是往门那边牵的（★）。
- 传承：绯庭一路的礼法，夜绯家传了几百年，跟红园家学绯宴支配术同出一处，支配术叫人自己走到结论上，牵丝礼叫人照规矩坐下（★）。655年她在长桌上提出孩子不进账，把五岁的赛壬缇娅挪到门边，把纷争纪高座的座次倒过来用，起了这一版，练法一卷，Epic，缺一套出了事拿来护人的战法。只给 AI，758年霜降月七夜她补成红园七夜宴律，Legend，叙述不提前说。
