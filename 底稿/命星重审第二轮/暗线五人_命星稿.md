# 命星重审第二轮·暗线五人的命星稿（11-19 夜）

用户 11-19 夜说筛表漏了山铜纪暗线的主角，内森、伊诺克、斐里安、玛蓓、玛丽贝尔，命星也洗一下，跟原典要有关联。

他们五个都是人物条（相遇），不在旅伴条里，所以筛表没抽到。眼下只有斐里安有一颗成名的天赋（万烛瞳孔，Legend），别的四位的本事写在人物条的散文里，没有命星。这一份给五人各拟一套，照样稿第二版的口径（本钱不是摘要、品级搭配多样、异世界轻小说和 JRPG 的文风、Rare 起就踏进了超凡，完全没有超凡的是 Normal）。对照的原典是暗线第四版第二节和第二版第二节那两张表：斐里安照雷内，伊诺克照雅各布，内森照阿兰，玛蓓照玛丽安，玛丽贝尔照桑多涅。

落到卡上：每人在人物条里添一行“命星”（山铜纪那一条和迷宫纪前传那一条都添），写法照凡世至强那一路，一颗一句。散文里原来写的本事照留，跟命星对得上。下面先列搭配和原典的钩子，再给卡面的那一行。

## 二、各人

### 1. 斐里安（照雷内）

**为什么这样配。** 他是头一个看见世界自己的火的人，世界当夜记住了他，后来归火走上圣座。看见火的那双眼睛是他的本钱，也是他算出终末、又算漏了三笔的那双眼睛，照新口径给 Unique。原典里雷内割舍了自己的人格，成了那个名号，这里落成一副装得下别人的火、却越装越冷的身子。世界式落成一门推演的技艺。

**原典钩子。**
- 雷内算出的世界式，这里是火账，那门推演叫世界火式。
- 雷内割舍人格成了格式塔，这里是无我之器：他的“自己”脱得下来，归火那夜他把自己割了出去。
- 雷内少算的，这里是万烛瞳孔看不见的：没有火账可记的人，桌边那个空位。

卡面那一行：

```
- 命星：Special【万烛瞳孔】(Unique)，生来看得见火的一双深红眼睛，看人一眼，胸口那点火多大、多旺、还能烧多久、是借来的还是自己点的，他分得出颜色。他看得见天下的火往哪里斜，约22年在死域边上看见了它们斜过去的那一堆原初之火（★）。他看得见，也看得灭，刀上的附魔火、晶匣里的晶，他看一眼就熄，到了传奇，看一眼一整营人的火都暗下去一截。看不见他自己的火，也看不见火账上没有的人，可能性的奇点、桌边那个空位，在他眼里是黑的（★）。｜Passive【无我之器】(Legend)，一副装得下别人的火的身子，他的自己像一件外套，脱得下来。别人的火落进他身上不烧他，魅惑、附身、读心碰上他，找不着里头那个人，判定获得优势。装得越多人越冷，冷到后来想不起自己叫什么（★）。｜Art【世界火式】(Legend)，他拿纷争纪一万一千年伤亡册上火烧下去的快慢，推一处火还能烧多久，小到一个人，大到一座城、一个世界，约22年推出世界还剩两千年上下。法门是看火，战法是先一步知道谁先倒下，练法写在他的手记里，伊诺克抄得下来，旁人读不懂（★）。
```

### 2. 伊诺克（照雅各布）

**为什么这样配。** 他在净血院的祷告里长大，听一遍就记下、倒过来念，这是他小时候就露出来的天赋。原典里雅各布是走深渊那条路唯一成了的人，这里是吞火：同一份余烬，佩林吞了叫火吃了，他吞了成了。凭的是生来那一副身子：净血院拿白石验了他二十年，一回也没红过。所以 Passive 是这一副装得下魔神余烬的身子，世上同一时刻只有他一个成了，给 Unique。两扇门是他一辈子最好的一手，给 Legend。

**原典钩子。**
- 雅各布走深渊那条路成了、卡特劣化，这里是伊诺克吞火成了、佩林叫火吃了，渊烬之躯就是两个人不一样的地方。
- 雅各布守结社四百年、收藏家，这里是守炉一千年、收火的人。

卡面那一行：

```
- 命星：Special【逆咏之舌】(Legend)，听过一遍的祷词、誓词、封印的令，他能一字不差地倒着念出来，倒着念，那一段管住的东西就松开。净血院的白石叫他倒念了三夜念哑了，擎天级封炉的令叫他倒念了，还热着的炉心自己从座上松下来（★）。只解得开有字有句的东西，没念过的解不开，自己起的誓解不开（★）。｜Passive【渊烬之躯】(Unique)，一副装得下深渊里那团火的身子。净血院拿白石验了他二十年，一回也没红过，他的血不收光（★）。约22年他吞下死域边上一尊魔神留下的余烬，同一份东西佩林吞了叫火吃了，他吞了成了，从此火伤不了他，不吃不睡，脸停在十四五。他走进一堆明火，从隔着半块大陆的另一堆明火里走出来，叫得出一群烧着的烬兽，扑过的地方铁也软下去（★）。两头都得是烧着的明火。他一松手、一哭，烬兽就散成热灰。世上同一时刻只有他一个吞了余烬还是自己（★）。｜Art【归火双门秘仪】(Legend)，画在地上、拿灯围着的两扇门。靠外的一扇把一个人身上的火引出来送进炉里，要那个人自己唱誓才开，靠里的一扇把一个人从他自己的身子里割出去。归火会的灯怎么点、人跪在哪里、那句怎么念，都是这一门（★）。
```

### 3. 内森（照阿兰）

**为什么这样配。** 他从小拆迪特里希做的门闩，想弄明白一根木头几片铁怎么知道有人要撞门。这一份想弄明白的手，长成了隔着山铜甲摸得出一颗魔晶心的手，Legend。原典里阿兰一次也没信过雷内的记录，余生只信人智拿得住的东西，这里落成一副不叫“非如此不可”压住的心智，他拿它不信火账，Epic。技艺照第四版第三节：66 年给玛丽贝尔的心点上它自己的火，那一下跨进了神域，同一时刻只在他一个人身上，人死了跟着走。名字照原典“圣剑更像一把钥匙”，叫予心之钥。

**原典钩子。**
- 阿兰造了桑多涅，生日在他六十五岁那天，这里是予心之钥那一下。
- 圣剑更像一把钥匙，这里是给玛丽贝尔上弦的钥匙，他做了两把。
- 阿兰不信雷内的记录，这里是清明心智，他的本子上那一行，斐里安又来讲他的账，大概是这几天没吃甜的，不能信。

卡面那一行：

```
- 命星：Special【聆心之手】(Legend)，一双听得见机关的心的手。隔着山铜甲按上去，一颗魔晶心转得匀不匀、哪一道令刻歪了、哪一根弦快断了，从掌心传到他耳朵里，刻令的笔在他手里，一道令刻得比头发细（★）。他小时候拆雨城的门闩，头一回听见一根门闩“想”着门外的人（★）。听得见机关，听不见人心。｜Passive【清明心智】(Epic)，一副不叫“非如此不可”压住的脑子。神谕、预言、魅惑、谁说得再动听的大道理，落到他身上先松一半，判定获得优势。他拿它一辈子不信斐里安的火账（★）。好消息他也一样不信，到老没跟谁说过一句准成。｜Art【机心工学】(Legend)，化犁以后头一个拆心的人整理出来的那一门，魔导工程院照它教，造得出不用上弦、心里压一粒火自己转的机兵，可照样只认令（★）。66年冬天他六十五岁生日那天，这一门跨进了神域，成了【予心之钥】(Unique)：他给一颗机器的心点上它自己的火，跟她说，你是自由的。这一版只在他一个人身上，人死了跟着走，后世温克在星环拆了一百二十年的心也没弄明白（★）。
```

### 4. 玛蓓（照玛丽安）

**为什么这样配。** 她小时候跟机兵说话，化犁那回给排队进炉的机兵一台一台起名字。原典里玛丽安身边有机关狗西摩尔守着，这里是菲杜斯。她身上那份天赋落成给机器起名，名字一起，机器就认她，所以菲杜斯九百年守着她的坟，跪着的那台擎天级那一夜也认了她的声音，Legend。她天天给佩林送花，身子是一副叫病人安稳下来的体质，有一点超凡，给 Rare。白烛的手是她学来的，照白烛那一门的 Epic。

**原典钩子。**
- 玛丽安和机关狗西摩尔，这里是玛蓓和菲杜斯，古语里是靠得住。
- 厄里那斯尸骸里那一仗玛丽安重伤，这里是跪着的擎天级胸膛里那一夜，她死在术班的座上。

卡面那一行：

```
- 命星：Special【予名之声】(Legend)，一副叫机器认得的嗓子。她给一台机器、一头机关兽起了名字，它就记得她的声音，一日一回她喊它的名字，它放下身上的令先来护她。30年化犁那回她给进炉的机兵一台一台起名，炉前排着的那一列没有一台挣（★）。约38年那一夜，跪着的那台擎天级在她喊了一声以后把胸膛合上了一半（★）。叫得住机器，叫不住人和兽，名字她只给不收。｜Passive【暖烛之息】(Rare)，她坐在病人床边，屋里就安稳，咳的咳得轻，疼的睡得着，一夜里伤口不往坏处走（★）。佩林醒的时候花常常蔫了，咳却轻了。｜Art【白烛缝伤针法】(Epic)，白烛医官的那一门，手按上去血就止，白光里断骨接得上（★）。
```

### 5. 玛丽贝尔（照桑多涅）

**为什么这样配。** 原典里桑多涅给自己起的中二称号“析构万理的发条公主”，这里原样照用，她拿数解事、算完了证毕的那一手就叫析构万理，Legend。她胸口那颗心是内森给它点上自己的火的那一颗，世上只有她一个，银针、白石、上城的拱门都验不出她，圣堂没法给她立案，给 Unique，名字照“你是自由的”起。她做的人偶和机关（莱玛、康科迪娅、阿希奥玛）照内森的规矩拿古语起名，起的是证明里的词，这一门叫公理机巧，Legend。迷宫纪 3 年醒过来身上多出的那一颗，是默娜的火带来的，一双筛得匀面的手，她不肯说它叫什么，照留不起名。

**原典钩子。**
- 析构万理的发条公主，原样。
- 阿兰跟她说你可以自己挑生日、你是自由的，这里是自燃之心。
- 普隆尼亚是算未知事物的大机器，她当它是家人，这里是阿南刻；人偶师的手艺，这里是公理机巧。

卡面那一行：

```
- 命星：Special【析构万理】(Legend)，她拿数解事。一件事先算，算的时候身边的光一格一格亮起来，像有人在半空里一盏一盏点灯，算得越久，打出去越重，打出去的是凝成霜的光，一道一道棱柱钉进地里，收尾的那一下她叫证毕，落点上留一片六角的霜（★）。算不出来的东西她不打，打出去之前先报几成。小时候她管自己叫析构万理的发条公主，这一颗的名字是从那里来的，谁当面念出来她当场炸毛（★）。｜Passive【自燃之心】(Unique)，一颗烧着自己的火的机器的心，世上只有她一颗。发条的身子不吃不睡不老，没有血，银针、白石都验不出她，上城的白石拱门对她一缕烟也不冒，圣堂没法给她立案（★）。947年以前心里压着门洞那粒炭，迷宫纪3年醒来以后烧着默娜给的火。｜Art【公理机巧】(Legend)，她做人偶和机关的手艺，照内森的规矩拿古语起名，起的是证明里的词：莱玛是引理，康科迪娅是心连着心，阿希奥玛是公理。几处分会柜台后头的康科迪娅心是连着的，一处见过的旅印别处都报得出（★）。迷宫纪3年以后她身上多了一颗默娜的火带来的命星，一双筛得匀面的手，她不肯说它叫什么。
```

## 三、要你定的

1. 斐里安的万烛瞳孔从 Legend 升 Unique，伊诺克、玛丽贝尔各一颗 Unique，内森的予心之钥照第四版本来就是 Unique。这样暗线一院有四颗 Unique，合不合你的意。
2. 玛蓓一辈子停在灵格、三十几岁就死了，天赋给到 Legend，是照“暗线的主角、机器认她”给的。要是嫌高，降 Epic。
3. 落卡的位置：每人在人物条里添一行命星（山铜纪补卷_64 的斐里安、伊诺克、玛丽贝尔，第一页的内森和门洞的孩子们那一条里的玛蓓，迷宫纪前传补卷_83 的伊诺克、玛丽贝尔）。认了就照这个落，门面山铜纪那一本的档案跟着出。
