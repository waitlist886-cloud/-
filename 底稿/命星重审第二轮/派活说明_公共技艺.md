# 派活说明·公共技艺（11-20）

你给一张日式西幻 JRPG 跑团卡《奥尔德兰的旅印》写一纪的“公共技艺”，全程用中文。高魔世界，剑与魔法，异世界轻小说和 JRPG 的口气。

## 一、这是做什么用的

用户定了：一个超凡者长寿的一生不只修一门技艺，会去学别的补短板或者推长处。能力行里写的是他最拿手的那一门，另添一行「兼修」写他另外会的。兼修从三处挑：底卡技艺池子、这一纪各页上现成的技艺、每一纪新写的一小批公共技艺。你写的就是这一批公共技艺。

公共技艺是这一纪里行伍、佣兵、行会、学校、圣所人人能去学的东西：兵和佣兵上手的剑、枪、盾、弓，斥候认路，伤兵棚的急救，施法的入门课，护身的祷，骑术、驭兽，一两样生活手艺。弗洛里安是吹号的佣兵，他兼修的剑术或枪术就该从这里挑；玛丽贝尔做人偶，她兼修的那几手洪流就该从这里挑。

## 二、写多少、写什么

- 十到十二门。多数 Rare（头几课、一门行当），两三门 Epic（成体系的一卷，比如学校教的施法入门整卷、骑士团的骑枪）。不写 Legend 往上。
- 先看材料里“这一纪页上已经有的技艺”和“学艺与传承”那一条，页上已经有、谁都能学的（比如城卫枪术）不再另写，补没有的那几样。
- 每一门写明哪几年有、在哪里学、谁教，照这一纪的年代走（材料里写了这一纪分几段）。一门只在某一段有的，【调用】里写那几年。
- 照命路落：每一门写它在哪一条命路上（二十三条见材料），兼修的人照命路的跨路兼容来挑。
- 起名照材料里的口径：出处、手法、门类三截，门类字是行当的名字（剑术、枪术、盾术、弓术、祷法、医术、骑术……），Rare 对着底卡皇家宫廷剑术、矮人铁砧锻打法、初阶炼金解构手札那个档。不撞底卡池子和这一纪页上的名字。

## 四、格式

每一门是一条补卷条目：

```
## 纪名·技艺｜名

【调用】哪几年、在哪里，有人去学、用这几手，或者旅伴、人物兼修了它时用。

【名】首段：是哪里、谁教的什么，街上的俗名，在哪一条命路上，三样（法门、战法、练法）有哪样。

- 用处：（Epic 写「法门」「战法」「练法」三行，照第三节口径）
  - 招式名（一阶起）。……
  - 招式名（二阶起）。……
- 构成：科名（Skill、Skill）。……
- 阶：一阶，……。Rare 至多三阶，Epic 至多五阶、位阶到极境。
- 在哪里学：哪一座城、哪一个行会或营地，学多久，学费多少（照这一纪的钱，一句）。
- 限制：……
- 传承：谁起的头，往后长成哪一门（有的话，写页上那一门的名字）。

> 条目设置：文件夹 53·纪名｜魔法，触发（同时满足）〔纪名·正则〕、`/名|俗名|招式名|……/`，黑名单 无，范围 用户与助手，深度 2。
```

- 纪名照材料里给的（月银纪、纷争纪、山铜纪、迷宫纪），〔〕里的正则名也照材料。
- 触发正则写这门的名字、俗名、两三个招式名、兵和学徒嘴里会说的叫法，用 | 隔开，不写太泛的字（剑、枪、学）。

{卡面}

## 五、交什么

先交一张清单，一门一行，`清单｜名｜档｜命路｜行当｜哪几年｜一句话`。然后空一行，交全部条目。前后不加别的话。
