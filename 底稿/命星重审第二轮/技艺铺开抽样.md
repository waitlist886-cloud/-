## 绯庭牵丝礼法（莉西娅，换名，社交系）

```
### 绯庭牵丝礼法 (Art | Epic)

【调用】白鸦的年月里，莉西娅主持一桌、替人排座、让孩子靠门，或出了事要从桌边让出路时用。

【绯庭牵丝礼法】是绯宴夜绯家传的礼法，红园的人叫它牵丝礼，雨城长桌边的人还叫它宴庭座次术，只当那是夜绯家排座的规矩。绯宴的礼数里浸着魅魔的魔力，行礼的人指尖牵出看不见的绯色细丝，系在入席的人身上，坐下、举杯、开口、离席，都照规矩一步一步来（★）。夜绯家几百年拿它定谁分血、谁上宴。莉西娅倒过来用，让孩子坐门边，让想走的人不用从谁背后挤过去（★）。三样里成了的是练法这一卷，战法只有半卷。

- 法门：没有成文的。牵丝靠的是魅魔生来那一点叫人回应的魔力，礼做得越周全，丝越韧，自己先失了礼，丝当场断（★）。修到灵格，她戴着手套的指尖在灯下会拖出一缕淡红的光（★）。
- 用法：
  - 礼线（一阶起）。向一个人行完一整套礼，丝便系上了。那人在这一桌上照礼数行事，拔刀、拍桌、抢话以前先要过一回意志判定，判定失败，手会自己放回桌上（★）。一回系得住三四个人，管到散席。
  - 座次（三阶起）。她排过的一桌，每把椅子都牵着丝。仇人不对着坐，坐下的人火气往下压。出了事，她一拉，椅子连人往两边滑开，让出一条通到门口的路，孩子和不想掺和的人先走（★）。雨城的长桌她排得过来。657年霜降月刀出鞘那一天，她走到两边刀中间，她碰过的椅子连人滑开。660年寒星月长桌叫人掀翻的那一夜，椅子带着人避开白火，孩子从小凳前的路出了门。
  - 礼域（五阶，极境，这一门到此为止）。整座厅成了她的礼域，规矩张在厅里，入席的人都照着走，起身先告退，动刀先报名，违了礼的人身上的丝一紧，手脚慢下半拍（★）。一座城的宴她撑得住，撑一夜。白鸦的年月里她没走到这一步。
- 战法：半卷。丝管得住守礼的人，管不住不讲礼的人。真动了刀，她能做的只是让出路。
- 练法：夜绯家的孩子十一岁戴上手套，坐到大人身后去看，先认门，再看谁的手放在哪里，再记谁开口前要看别人。看满几年，大人叫你把一桌的座排一回，满桌的丝都系得上才算过，排错了，先拍桌子的就是排错的那一个（★）。莉西娅坐了十四年，几百个人哪年坐过哪个座，她闭眼也排得出来。
- 构成：
  - 看席（发现隐藏、记忆）。她先看门在哪一边，再看手，再记谁坐过哪里。
  - 行礼（交涉、意志）。一整套礼做周全，自己一步不错。
  - 牵丝（控制魔法）。指尖那点魔力拉成线，系得上，拉得动，松得开。
  - 护人。缺。出了事拿丝挡刀、缚人的那一科没有练法，她身上也没有 Skill 撑着，所以是 Epic。
- 阶：一阶，交涉、记忆到熟手。二阶，发现隐藏到匠人，控制魔法到熟手。三阶，交涉到匠人，记忆到名匠，位阶灵格。四阶，控制魔法到匠人，交涉到名匠。五阶，交涉到宗匠，意志到名匠，位阶极境。655年她起这一版时在三阶。
- 限制：只管自己肯坐下的人，被押来的、不讲礼的、构装和亡灵都不算。丝叫人守礼，不叫人改主意，挡不住刀，也不能让仇人就此和好。她自己失了礼，满桌的丝一齐断。
- 世界反应：雨城人家摆宴，靠门那一截留给孩子坐（★）。红园的老人说，夜绯家那个女儿的丝是往门那边牵的（★）。
- 传承：绯庭一路的礼法，夜绯家传了几百年，跟红园家学绯宴支配术同出一处，支配术叫人自己走到结论上，牵丝礼叫人照规矩坐下（★）。655年她在长桌上提出孩子不进账，把五岁的赛壬缇娅挪到门边，把纷争纪高座的座次倒过来用，起了这一版，练法一卷，Epic，缺一套出了事拿来护人的战法。只给 AI，758年霜降月七夜她补成红园七夜宴律，Legend，叙述不提前说。
```

## 命烛剑律（诺伦，Unique，名字不动）

```
### 命烛剑律 (Art | Unique)

【调用】只在深层解释赤原第六日的剑、破晓的光与越阶斩击，或者三个坎都过了、玩家和诺伦夜里独处时用。表层 NPC、档案、鉴定和考据都不知道，叙述也不点名。

【命烛剑律】是晨曦岭大剑术底下真正的那一门。她的命是一支烛，每一剑都从那支烛上烧下一截，剑上的光就是那一截的光，烛还剩多长，她心里有数。法门和战法都是她自己的，练法没有，也不会有。它只在她一个人身上，教不出来，也传不下去。

- 法门：不在饮血、呼吸、冥想、祷告四门里。力量从她自己的命里来，不往身子里收，往剑上烧，烧一截少一截。身后有她要护的人，火才点得着（★）。烧着的时候剑脊上走一线白金色的光，旁人只当是破晓自己亮了。为自己挥剑，烛不亮，手里就只剩晨曦岭大剑术。
- 战法：
  - 燃烛（一阶起）。落剑的一瞬从烛上烧下一点，这一剑抵两剑，劈得开城门的门闩（★）。一剑一烧，烧掉的不回来。
  - 越阶斩（三阶起）。连着烧下一整截，剑重到斩得动高一个位阶的对手。英雄时能斩进烧尽自己的传奇，赤原第六日破晓斩焚冰赛弗就是这一剑（★）。到了传奇，烧得够多能伤魔神。一战至多一两回。
  - 三烛之晓（四阶起）。跟应许之晓同起，一回烧三截，夜里举剑，晨光往前铺开，光里跟着她的人看得见路，站得住脚。一夜一回，烧过这三截，她三天抬不起剑（★）。
  - 以身为炬（奥义，五阶）。不再一截一截数，整个人当成炬点起来，凡身站到魔神面前，身后的人那一刻不被碾过去（★）。跨进神域的就是这一招。它是挡在前面的一招，烧掉多少、还剩多少，只有她知道。
- 练法：没有，也不会有。底下那一卷晨曦岭大剑术是练得出来的，命烛这一层是她自己的，谁照着她的剑路学，学到的只是大剑术（★）。
- 构成：
  - 护念（意志）。身后有她要护的人，火才点得着，这一念松了，烛就暗。
  - 数烛（冥想）。往里看一眼，知道还剩多长，这一剑烧多少，她不多烧一分。
  - 剑本身（武器熟练度·剑）。底下是晨曦岭的先守后劈，烛烧进去的是这一剑。
  - 承烧（耐力）。烧过以后身子空下去的那一段，她得站着把仗打完。
  - 同晓（统率）。身后的人信着明年，她的烛和他们的信在同一刻亮，三烛之晓靠的是这一科。
- 阶：一阶，剑到匠人，意志到熟手，她开局就在手里。二阶，冥想到匠人，数得清烛。三阶，剑和意志到名匠，位阶英雄。四阶，统率和耐力到名匠。五阶，剑和意志到宗匠，位阶传奇，再要凡身站到魔神面前那样的一件事，奥义才跨进神域。
- 限制：烧掉的命不再长，回复术补不了。一战烧过三截，她三天抬不起剑。为自己挥剑，烛不亮。
- 世界反应：史书把功劳都记给破晓。她后来留在剑上的约束，唯有心存以身为炬、点亮长夜之志的人举得起它，说的就是这门。
- 传承：只在她一人身上，真天才自创的那一种，开局就在手里。2988年秋，她替立誓者奥尔达挡下背誓者乌瓦尔的攻击，凡身站到魔神面前，才跨进神域。人走了，这一门跟着走。
- 裁定：这是她自己的，不是血统、神谕、传承或谁的安排，不追问来处。她知道剩几剑，叙述不透露烛长与烧尽的后果，也不写成杀魔神的办法。止戈清算前，凡躯杀死的魔神只有一尊。
```

## 神铁锻王法（放大，铸造大宗匠的整本）

```
### 神铁锻王法 (Art | Legend)

【调用】麦的年月里，山铜纪934年金穗月中旬八日天亮以后，布洛姆加守一座将熄的炉、叫它白着烧回来，在白火里锻山铜，或者有人问起王炉为什么是白的的时候用。

【神铁锻王法】是王炉听息手札走到了头的那一版，誓锤锻律炉脉一支守炉锻铁的整本手艺，炉台上的人叫它锻王法。看炉、养火、锻山铜、守炉，一位炉头一辈子的活计都在里头（★）。934年金穗月中旬八日天亮以前，王炉只剩最后一口暗红的气，他看准了那一口气，把右臂和那一锅山铜矿浆投了进去。王炉从底下一层一层白起来，白得看不出火苗（★）。法门、用法、练法，三样到这一版才齐。

- 法门：火色与山铜矿浆。火色是听息手札那一套，白里透黄、橙、红，一声一声听出来。料是山铜矿浆，炉脉最好的矿熔的，存得越久越沉，一座炉病到了底，添炭添铁都不顶用，要倒这一锅（★）。修久了的人看炉膛像看白天，烧红的铁攥得住，炉火跟着他的心跳起落（★）。修岔了叫贪火，什么都想往炉里添，炉烧得发青，打出来的东西脆。
- 用法：
  - 白火（一阶起）。添对了料，在对的那一口气上添，将熄的炉一层一层白着烧回来。一座寻常的炉熄到只剩一点红，一夜烧回原样（★）。料得是真料，一夜里他离不得炉门。
  - 神铁锻（三阶起）。在白火里锻山铜。打出来的器物认主，在主人手里听使唤，换一个人拿着只是一块沉铜（★）。一件要守着炉打上一年半载，一回只打得了一件。935年到937年，他拿左手打成了一条山铜的右臂，接上去手指听他的（★）。
  - 守炉（四阶起，位阶英雄）。他守着的炉，火只烧投给它的东西，有人想叫它换个烧的，叫不动（★）。只管他亲手守着的那一座，人离了炉台三天，这一手就松了。
  - 以身为燃（奥义，五阶，位阶传奇）。投进炉里的东西换一座主炉回白，炉底下吃火的东西叫白火逼着退进石头深处（★）。炉要什么就得投什么，投进去的回不来（#889）。王炉往后一直是白的。
- 战法：没有。白火不替谁挡刀，他守着炉的时候谁也挪不动他，那是他自己的命星，不是这一门里的。
- 练法：炉头一代传一代。先学听息手札，拉风箱、敲壁、划板，学成了再跟着炉头看一回救炉，看他添什么料、在哪一口气上添（★）。再上砧，在白火边上从递钳子学起，打得出一件认主的小件才算过（★）。炉台柱子上那一块山铜板，往后接着划。
- 构成：
  - 听炉（发现隐藏、鉴定）。听息手札整卷，炉病没病先听出来。
  - 火色与料（锻造、鉴定）。认火色，认山铜矿浆的陈新，知道哪一口气上添。
  - 砧上（锻造、耐力）。白火里的锤上功夫，山铜一凉就不认锤。
  - 守心（意志）。炉白着烧的那一夜人不能退，心跳乱了，火跟着乱。
  - 传板（记忆、识字）。板子接着划，救炉那一回怎么添的，讲得出来，教得下去。
- 阶：一阶，听息手札学成，锻造到名匠。二阶，鉴定到名匠，亲手救回过一座寻常的炉。三阶，锻造到宗匠，耐力到名匠。四阶，意志到名匠，位阶英雄。五阶，意志、发现隐藏到宗匠，位阶传奇，再要一件以身为燃那样的伟业。
- 限制：救得回炉，回不来投进去的东西（#889）。一座炉要什么得看那一座炉，有时候要的不是料。认主的器物只认一个主，主人死了，它就只是一件好铜器（★）。
- 世界反应：王炉白了以后，炉城的人过炉台不大声说话，学徒头一天上工，先去看柱子上那一块山铜板（★）。
- 传承：誓锤锻律炉脉那一支，前头几代炉头记下看炉的法子。934年那一夜，布洛姆加把王炉听息手札做到了顶，补上了救炉那一手，他手里是 Legend 那一版，往后炉城的炉头学的是这一版（★）。
```

## 网岛收潮网叉术（换名，原来叫一网收潮）

```
### 网岛收潮网叉术 (Art | Epic)

【调用】狄昂或网岛渔人撒网、投叉，在船上、滩上同海里上来的东西打，或有人想学这门手艺时用。

【网岛收潮网叉术】是网岛渔人一手撒网、一手投叉的整套打法，网岛的人一辈辈在滩上磨出来的，奥拉夫把它全教给了狄昂。岛上不叫这么长的名字，只叫它收潮，也有人拿练到头的那一下来叫它，叫一网收潮。三样里只有战法这一卷，法门没有，练法没成册。

- 法门：没有。网岛的人靠的是拉了一辈子网的腕子和肩背，力气是海上一天一天攒下的，岛上没有人教过怎么把曜引进身子里（★）。狄昂的金血是生来的，跟这一网不相干。
- 战法：先罩，后叉，再拖。
  - 罩鳞（一阶起）。网撒圆了兜头罩下去，十步之内罩一头。海里上来的东西一挣，网眼就勒进鳞缝，挣一回紧一分（★）。能罩住一头潮鳞蛇，就算学成。网收回来重撒，要十来息。
  - 穿鳃叉（二阶起）。叉从网眼里送进鳃，罩住的东西躲不开。背着身也收得了网，叉从肩头往后送，钉得住爬上礁背的蛇颈。狄昂在共鸣，手里就到这一步。叉离了手，要拽着叉绳收回来才有第二下。
  - 拖滩（三阶起）。叉扎住了往岸上拖。罩住的东西不论多大，只要脚下踩着湿沙和潮水，就拖得动（★）。拖一头比船长的，拖完一回，臂膀半天抬不起来。
  - 一网收潮（五阶，这一门到此为止）。一网罩住一群海里上来的东西，拖着群首在滩上走，网不破，叉不空。一趟潮水里只撒得出一回。
- 练法：没有成册的。老渔人带孩子，三岁补网，七岁撒网，在滩上撒一千回，回回撒圆了才许上船（★）。奥拉夫就是这么带狄昂的。往后学到哪一步，全看在海上站了多少年。
- 构成：
  - 撒网（武器熟练度·网）。全在腕子一抖，网要撒得圆，落得准。
  - 投叉（武器熟练度·叉）。从网眼里找鳃，正着送，背着身也送。
  - 拖力（耐力）。拉了一辈子网的肩背，罩住了拖得上岸。
  - 认潮（钓鱼、发现隐藏）。看浪头知道底下是什么上来了，从哪一边上来，网自己破了自己补。
  - 养气这一科是空的。没有成套的练法，也没有哪一门 Skill 撑着，所以这一门停在 Epic。
- 阶：一阶，网到熟手。二阶，网、叉到匠人。三阶，耐力到匠人，钓鱼到熟手，位阶灵格。四阶，网、叉到名匠，耐力到名匠。五阶，网到宗匠，位阶极境，一网收潮。
- 限制：只在海边灵。在干地上，罩住的东西也拖不动。网得自己补，网破了这门手艺就废了一半。没有一口养着的气，打久了全凭臂膀撑。
- 世界反应：岛民叫它收潮，说一网下去，潮水都收得回来。
- 传承：西海船和网一脉里，网岛一辈辈传下来的，只有战法一卷，Epic。狄昂用铜盾和刀凝名，没补完它，岛民后来撒的还是这一网。它缺一口离了水也撑得住的气，谁给它配上法门，这一网才上得了岸（★）。
```

## 断缰浅滩匿踪术（换名 Rare）

```
### 断缰浅滩匿踪术 (Art | Rare)

【调用】格莱妮、艾丹或逃难的人挑睡处、躲追兵的时候用。

【断缰浅滩匿踪术】是逃难的人口口相传的匿踪术头几课，路上的人还叫它一宿一迁法，一夜换一处睡。头三条是浅滩上那个腕缠断缰的女人说的，不在生火的地方吃饭，不在吃饭的地方睡觉，不在睡过一夜的地方睡第二夜。往后十五年格莱妮自己又添了数路、避回声、避水声几条。没有法门，逃难的人一代一代睡过又走开，走开的铺学会了替人留住气味，新铺学会了替人噤声（★）。

- 用处：
  - 数路（一阶起）。入夜先数退路。路少于三条的地方、有回声的地方、水声盖得住脚步声的地方，她心里先起一阵凉，这样的地方不睡（★）。
  - 空铺（二阶起）。照规矩离开的旧铺，气味和余温留到第二天日落，猎犬和追踪的人只认得那张空铺和一块饼（★）。九矛一整团猎手追了十五年，没有在夜里摸到过他们的床边。
  - 静眠（三阶起）。新挑的睡处从躺下到天亮，三十步外听不见里头的呼吸和翻身，遮两个人，一夜（★）。
- 构成：藏身（隐匿）。断气味、收声息，挑睡处、离铺都照规矩来。认路（旅行、发现隐藏）。到一处先把退路数清，听回声和水声。
- 阶：一阶，旅行、发现隐藏到熟手。二阶，隐匿到熟手。三阶，隐匿到匠人，这一门到三阶为止。
- 限制：三个人以上藏不住，吃的用的都得背着走。留下来睡了第二夜，追兵就追得上。它只管睡在哪儿，白天撞上了照样得跑。旧铺只留得住气味和余温，脚印和踩断的草它遮不了（★）。新睡处只遮两个人、一夜，天一亮就不灵（★）。
- 传承：逃难的人口口相传，没有长成流派。1434年格莱妮十七岁从订亲宴上逃出来，在浅滩上听腕缠断缰的女人说了头三条，后几条是她十五年里自己添的。1450年讲和回到白丘，她跟艾丹在同一处睡了第二夜，这一门在她手里用到了头。
```

## 瓦脊风路信术（两门并成一门）

```
### 瓦脊风路信术 (Art | Rare)

【调用】黑潮的年月里，蒂丽上房跑信，在雾门跟前、层碑旁边点一罐烟，烟往上走，跟着烟走的人走得出去，或者霓娜从地上一跃上了屋檐、墙头，在屋顶和墙头上跑信、传话、放烟，或者有人想学瓦脊家屋脊信使的手艺的时候。

【瓦脊风路信术】是下城瓦脊家屋脊信使的一门行当，上房、跑信、点烟三样收在一起，井里的人还照旧叫它烟路，瓦脊风路信术（★）。屋顶哪一片漏了雨，补瓦的人补完了在屋脊上点一小罐烟，烟里掺着瓦脊家自己配的料，青里带一点橘，风吹不散（★）。850年蒂丽把这一罐烟带下了井。没有法门，瓦脊家几代人在屋脊上点烟，烟沾了屋脊的性子，只认往上的路（★）。

- 用处：
  - 跃檐（一阶起）。上房跳脊，踩瓦不响，屋脊、矿道的横梁、井壁的窄台她都当路跑，背着一篓烟罐也照跑（★）。
  - 烟标（二阶起）。一层一罐，在雾门跟前、层碑旁边点上，烟只往上走，穿得过雾，一罐烧三天，黑里也看得见。850年她从第一层连到第二十层，矿道里迷了路的人跟着烟往上走就走不丢（★）。
  - 烟线（三阶起）。走在烟线十步之内的人免疫雾里的迷向，闭着眼也分得清上下，一罐烟带得住一队六个人。烟往哪边歪，就是哪边有东西（★）。
- 构成：
  - 跑脊（旅行、隐匿）。上房、落脚、认下一处踩得住的地方。
  - 配烟（炼药、采集）。瓦脊家那一份料怎么配，一罐怎么点才烧得满三天（★）。
- 阶：一阶，旅行到熟手。二阶，炼药到熟手。三阶，旅行到匠人，烟线成了，这一门至多到三阶（★）。
- 限制：烟罐得一罐一罐去点，没点到的那几层就没有线。烟只指往上的路，往下它不管。潮压过来的那几层，烟叫潮搅散，线就断在那里。烟只替人认路，不替人挡东西，离了烟线十步，雾照样迷人（★）。
- 传承：下城瓦脊家从她曾祖父起在屋脊上点烟报漏，850年她把它带下了井（★）。往后她在墙上教兽耳的斥候点烟罐，公会照她旅印的那一阶叫它风路信标，学的是她这一版。侄女霓娜跟她学，学得最好的是跃檐，三层楼一口气上去，墙头上跑起来跟平地一样快，下城的人还叫她那几手瓦脊跃檐步（★）。
```
