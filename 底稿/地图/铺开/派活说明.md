## 写

- 甲（新写）：一份一个文件，写进这一纪的补卷目录，文件名照计划里给的（比如 月银纪补卷/地点_06_万兽诸地.md）。文件末尾一节「## 设计备注」（不进卡），写：每一处的原有和★、跟别的条目对不上没改的、拿不准要主会话定的、起的名字。
- 乙（补两栏）：直接改原条目所在的文件，只添「风貌」「活事件」两栏，必要时放宽【调用】那一句，别的一个字不动（条目设置、触发、黑名单、## 标题、固定锚定都不动）。备注另写一个文件 底稿/地图/铺开/<纪>/乙N_备注.md，同样写原有和★、拿不准的。
- 份表：底稿/地图/铺开/<纪>/份名.tsv（甲必有；乙只在新提了分区、或者发现坐标不对时写），栏目照计划第六节。
- 起名：新起的人名、地名先跑 `python -I -X utf8 tools/namegrep.py 名字 …`、`python -I -X utf8 tools/collide.py 名字 …`、`python -I -X utf8 tools/namepairs.py 名字 …`，报无再用，再自己听一遍近音（同一纪里有没有差一个字的），登记在你那一份的设计备注里（起名一节，写名字、是什么、在哪一条、namegrep 的结果），别直接改 起名.md，几份同时写会互相盖掉，主会话收稿时并进去。

- 不点那一位恶神的名字，四执政不入场。锁里写着叙述不点破的，照不点破。
- 不起新的仗、新的传奇、新的神。活事件是一处地方的事。
- 不提交 git，主会话收稿以后提交。

## 交稿前自己跑

```
python -I -X utf8 tools/place_check.py 你的稿子.md --tsv 你的份表.tsv
bash tools/recv_check.sh 你的稿子.md
python -I -X utf8 tools/yearbl.py --test 你的稿子.md
```

place_check 的错要 0，提醒逐条看过写进备注。recv_check 那几项都要 0（cardscan、people 硬问题、authormark、ngram hits、regex 硬问题）。乙改的是原文件，recv_check 跑整份文件，跟改前比不能多。活事件里有台词的，抽出来跑 genshin-dialogue-voice 的 voice_check.py，加 `--ban "…！—；"`。
