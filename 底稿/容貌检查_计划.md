# 容貌那一轮（10-23）

用户原话：“容貌这一块也检查一下，别动不动就是晒黑的或者深色的..尤其是这些有原型的角色。二次元的那种画风，jrpg的感觉，有原型的角色注意核对原型的长相容貌（比如辛美尔应该是蓝发白皮肤）”

## 一、盘点

四十页（月银纪史诗十五歌、诸国期六页、萨尔维斯六页、纷争纪七页、山铜纪六页）一共四百零三个人有样子，外貌行三百六十八条，另有凡世至强的仪容与印象、人物条的样子。设计备注以外，晒黑、麦色、黝黑这一类九十一处，黑发、褐发、栗色头发这一类两百零二处，灰眼睛、黑眼睛、褐色眼睛这一类一百零六处。补卷、碑、二十二张、长诗里没有写人的长相。

辛美尔小队四个人主会话已经照原作改了（commit 55cc1d3），纷争纪第七页、山铜纪第一到三页，这四个人的条目不要再动：
- 辛美尔：蓝发，白净的脸，浅蓝的眼睛，左眼角一颗泪痣，个子高，亚麻色长斗篷，收腰的蓝上衣，白裤子，黑靴子。
- 海塔：往后梳的短绿发，方框镜片，褐色的眼睛，白烛的白袍镶窄金边。
- 艾冯：带两只弯角、护鼻压到眉下的旧铁盔，褐发褐须（10899年以后白了），铁肩甲，洗褪了色的红斗篷。
- 芙莉莲：银白长发中分扎成两股，浅绿的眼睛，眉毛偏粗，皮肤白，尖耳，一对坠水滴形红石的金耳坠。

## 二、口径

画风是日式二次元、JRPG 立绘。一个人往人堆里一站认得出来：一种发色，一种瞳色，再一样记号。记号可以是泪痣、雀斑、一缕挑染、头顶一撮翘起来的头发、发带、发饰、耳坠、一道疤、缺一颗的门牙、尖耳、竖瞳、角、兽耳、尾巴、身上的纹。

1. **肤色不默认晒黑。** 人族、精灵、半身人默认不写肤色，要写就写白、白净、白皙、象牙一样的白（冷瓷白底卡给了巴尔缇娜，别处少用）。晒黑、黝黑、麦色、古铜、黑红、脸叫风吹得黑，只留给真有来由、又是这个人记号的（沙海里的游民、海上二十年的人、高原上放牦牛的），一页至多一两个，写成好看的那一种（浅浅的小麦色、蜜色），一句里带上来由。拿晒黑来说这个人吃苦、能干、风里来雨里去的，换成别的写：手上的茧，眼角的细纹，冻红的鼻尖，叫风吹红的两颊，磨出毛边的衣裳，一道疤。腮红、冻红、风吹红是二次元常见的，留着。
2. **发色不默认深色。** 黑发、褐发、栗色、深褐、灰褐、乌发不当默认。照这个人的性格、出身和这一页的配色挑一样记得住的：天蓝、湖蓝、钴蓝、银白、白金、浅金、蜂蜜金、麦金、亚麻色、赤红、绯红、橘红、姜红、铜红、樱粉、浅粉、薄紫、丁香紫、青绿、薄荷绿、雪白、银灰。黑发可以有，写成有光泽、带蓝光、像鸦羽的那一种，一页两三个以内。老人白发、灰发、花白照留，那是年纪。
3. **瞳色不默认灰、黑、褐。** 灰眼睛全卷一百多处，最该收。挑琥珀、金、浅金、翠绿、碧绿、浅绿、湖蓝、天蓝、冰蓝、紫、紫罗兰、绯红、酒红、玫红、橙金、海青。灰蓝、银灰可以留几个，一页别超过两个。异色瞳一纪至多一两个，要有来由。
4. **一页之内错开。** 同一页别八个人银发、五个人琥珀眼。改之前把这一页所有人的配色列一张表，看着排。同一家人可以有一样相同的（布伦海姆家的蓝眼睛那种），写明。
5. **种族和身上的故事照旧。** 种族的样子照底卡和各页已经定的：精灵的尖耳，龙裔的鳞和竖瞳，魔族的角、印记和各系的皮色（轰狱的深青铜、白骸的白骨、深潮的鳞和湿发、夜翼的翼、梦魇慢半拍的影子），兽耳的耳朵和尾巴，矮人的胡子和辫子，獠牙、灰绿的皮这一类。事情写在身上的照留：一夜白了的胡子，圣土白了的胳膊，坑里锻出来的灰皮，烧伤、断指、缺牙、旧疤、炉火熏深的胳膊。
6. **有原型的照原型。** 主会话核过的：辛美尔小队四人（见上），诺伦的真容照 FGO 枪阶阿尔托莉雅那一型，金发绿眸，表层只露面甲缝里那一线绿，第二页已经是这样，不动；菲伦底卡写紫发紫眸；双王照底卡，巴尔缇娜灰银长发、金瞳、冷白肤、额角一粒红，索恩薇娅旧铜色的深金棕头发、浅金的眼睛。各页里要是还有别的照着哪部作品写的人，照原作对，对不上的写进回报。
7. **一处改，处处改。** 一个人改了样子，这一页所有说到他样子的地方一起改：旅伴条的外貌、容貌评价、初见、手写活人层、台词，主线的拍子，人物条的样子，凡世至强的仪容与印象和容貌评价，传奇专长里的说法，旁人对他的称呼（那个黑脸的、红头发的那个）。用名字和旧的样子词在整页（纷争纪、山铜纪是整个 parts 目录）里 grep 一遍。
8. **跨页的人照第三节那张表**，表上没有的跨页的人不改发色瞳色，只按第1条去掉晒黑。
9. **不动的。** 史诗、歌、诗、二十二张、碑的原文一个字不动，要是歌里唱到了一个人的样子，条目跟着歌，不改这个人那一样。受保护的行不动：固定锚定、体态数据、底座、条目设置、## 标题、### 星标题。条目设置的触发里要是有旧样子的叫法，不动，在设计备注里记一句。容貌评价的等级（绝世、出众、清秀、寻常……）不动，后半句跟着外貌改。
10. **句子照写作口径。** 别成排的四字格，别三样并排，别同一个句架子连着用，不写给作者看的话。新起的、有来由要交代的样子标★。卡面禁用的字照旧：米色、米白、茶色、茶褐里有米和茶，不用，月白也不用。

## 五、怎么验

每一页改前先存一份（git show HEAD:页 > scratchpad 里），改完：
- `python3 -I -X utf8 tools/cardscan.py 页`，合计不比改前多。
- `python3 -I -X utf8 tools/check_people_v7.py 页 .`，硬问题 0（萨尔维斯末年下、纷争纪第一页原有的感叹号照旧）。
- `python3 -X utf8 tools/ngram.py 页 语料`，0。
- `python3 -I tools/check_protected.py 改前 改后`，protected OK。
- `python3 -I -X utf8 tools/authormark.py 页`，不比改前多。
- `python3 -I -X utf8 <scratchpad>/looks/recount.py 改前 改后`，看晒黑、深色头发、灰黑褐眼睛三样的数降了多少。

每一页的设计备注末尾记一节「### 10-23 容貌那一轮」，写改了谁、从什么改成什么，一人一行，缘故一句。纷争纪第七页、山铜纪第一到三页主会话已经起了这一节的头，接在下面写。山铜纪记在各页 p9，纷争纪记在各页的 notes 分段。不提交，主会话收口时一起提交。
