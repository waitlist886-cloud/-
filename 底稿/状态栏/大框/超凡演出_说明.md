# 超凡演出（11-10）

用户 11-10 原话：“咏唱那里我的想法是不止做魔法，你回顾一下奥尔德兰里对于超凡的设定，即便是近战命路本质上也是一种施法，是一种以自身引动以太的‘仪式’。我们可以在伊索恩之上更进一步，为每一种超凡表现都做出专属的演出，同时也做出纪元风格上的区分”。

样式在 rite_css.py（纹样在 rite_svg.py），展开规则在 make_rules_frame.py 的「起手」「起手·息」「技」三条，提示词在 four_era_prompt.py 的 SYS_EDITS「正文」。样本行 超凡演出_样本行.json，拿 make_rite_samples.py 插进各纪现成的样本；截图在 截图/超凡演出/。

## 一、照的设定

- 开通道的五种法子（底卡 #559 到 #562）：魔法使拿 MANA 搭术式，元素使跟七大元素精灵立约，祷告拿信念当音叉、奇迹由活着的神降下，真龙和高阶龙裔吸一口气以太就低头，练到家的挥斩、格挡、踏进、拔刀、闭气、举盾做出来就是一场很短的仪式。
- 不念咒的路子，仪式落在呼吸、站姿和架势、誓、刻纹、祷告和圣印、契约和代价、血、歌、吼、吃上。
- 咏唱的规矩月银纪、纷争纪写的是同一句：两三个短句，名字收尾，粗人和光靠手艺的人不咏唱。按「息」计的：覆野两息、压城四息、倾天六息，摧锋蓄一两息。
- 各条命路的认法和老话（渊垒「你站的地方，就是墙」，真理「先分类，再动手」，天平押上钱再宣布规矩，铁律「契约第七条。逾期十四日。执行。」）。
- 各纪的叫法：月银纪没有命路，有四门法门（饮血、呼吸、冥想、祷告）、调曜和七曜、守火、结环，神回话只写伤合了、烛立了；纷争纪有术、阵、大术，同念脚下一圈白线、三角朝哪边术落哪边，誓不经神、当着人说就生力，1104年才有命路这个叫法；山铜纪的铳是施法的家什，有晶匣、缄火圣钉、灰帷、残火；前传和今天有圣歌（七芒星、光环、波纹）。

## 二、记法

- `§技｜施放者｜名｜类·稀有度｜路·元素｜一句结果`：放出去的那一下。类写 Active（放一个主动的招或术）、Special（命星主动的那一截）、Art（照一门技艺的路数出手，没放招）、Skill（要紧的技能判定，结果里写明成功、失败、大成功或大失败）；稀有度照面板写 Common、Rare、Epic、Legend、Unique（招随它的 Art，命星的主动随那颗命星），Skill 不写。中文的主动、命星、技艺、技能，普通、稀有、史诗、传说、唯一也认。
- `§起手｜施放者｜名｜类·稀有度｜路·元素｜一句｜一句｜一句`：引动以太的那一刻，只给 Active 和 Special。
- 旧写法照认：`§咏唱｜…`、没有类那一栏的 §起手（当 Active，不分稀有度），§技 第三栏写手法（斩突打射咏守援）的。
- 路：纷争纪1104年以后、山铜纪、迷宫纪写命路；月银纪写那一门或者兵器加风格（大剑·蓄斩）；纷争纪1104年以前写术、同念、誓、血誓、古龙祷告、高座之火。1001年那一局的提示词只说命路（没走命路的写兵器、祷告、圣歌、誓）。
- 起手那几句：一句十来个字，至多三句，不加引号；咏唱写两三个短句，祷告写看着哪里、手上做什么，立誓写那一句誓和当着谁，靠手艺的人写架势、呼吸和步子，要蓄的写蓄了几息。一轮至多一行起手、两行技。
- 句子里写了几息（一到九），名字后头排几颗珠子，一颗一颗亮（规则「起手·息」）。Skill 的结果里有成功、失败那几个字的，挂在条上换颜色（规则「技·判定」）。

## 三、类和稀有度（rite_tier.py）

用户 11-10 夜：“演出效果也可以做的动态一些……这一块演出要专门给active和special的主动使用做的华丽一些来体现与普通运用，skill判定和art发动运用的区别，特效与动态也要体现出能力位阶（epic，legend，unique）的差异”。

| 类 | 起手框 | 横幅 |
|---|---|---|
| Skill | 不写 | 一条细条，前头打勾、打叉，大成功一颗星，大失败暗红 |
| Art | 不写（写了收小，不放粒子、光圈） | 收一号，滑进来，不闪光 |
| Active | 框浮上来，光点从四周聚进纹样，纹样转着变大落定，句子一句一句出来，名字亮起，放出去一圈光 | 斜着砸进来，一下白光，几道速度线 |
| Special | Active 那一套，再大一号，两道边，一颗大星慢慢转，签上写 ✦ | 大一号，一颗大星，签上写 ✦ |

| 稀有度 | 样子（颜色照面板的品阶） |
|---|---|
| Common、Rare | Rare 一道蓝边，别的照常 |
| Epic | 紫边，外头一层紫光，隔一阵扫过一道紫光 |
| Legend | 金边，外头一层金光，扫过金光，往上飘的火星，名字一道金光来回走 |
| Unique | 七彩的边一直换颜色，放出去那一下整框一白、震一下，火星，名字七彩来回走，聚进来的光点是白的 |

前传的羊皮纸上金字、七彩字看不清，名字照旧是墨色。减少动画的设置下全停，停在放完的样子。

## 四、七种演法（路子定的）

| 演法 | 样子 |
|---|---|
| 咏唱 | 一句一句浮出来，斜体，名字最后亮一下 |
| 祷告 | 咏唱的样子，框上从纹样那里落下一道光，慢慢地明暗 |
| 演算 | 一二三编号，一句一句像划开，底下一层方格亮一下再淡下去 |
| 动作 | 几拍横着排，拍与拍之间一个▸，名字砸下来，一道光扫过去 |
| 誓约 | 句子加引号，名字后头落一枚红封蜡 |
| 煮药 | 底下冒热气 |
| 影 | 名字带两道残影，慢慢合成一个 |

纹样左边那一圈照路子换，各自一种动画（转、跳、明暗、闪、绷紧、摆）。减少动画的设置下全停。
