# 音乐探针怎么测（11-26）

两张卡都是平台探针，不讲故事，测完删掉，都设成私有：

- 日里：`奥尔德兰音乐探针_日里_11-26.json`
- 风月：`奥尔德兰音乐探针_风月_11-26.json`

想知道的是：聊天进行中，每一轮回复由 AI 在底座里挑一首曲子、显示正则把它变成播放器、循环放，这条路走不走得通。

## 先知道这几样

- **三段测试音**，各 20 秒，放完接着循环。每段**开头都有一声高音“叮”**，听到“叮”就是从头放了一回（循环一圈也会“叮”，所以两声“叮”隔不到 20 秒，就是被重放了）。
  - 甲（玩家说“平常”）：低低的嗡嗡长鸣
  - 乙（说“战斗”）：咚、咚的鼓点，夹着沙沙的镲
  - 丙（说“羁绊”）：叮叮叮三个音一组往上走
- **怎么打**：每一轮打一句，里头带上这几样，没说的照上一轮：
  - 写法：`测零` 到 `测七`（见下表）
  - 曲子：`平常`、`战斗`、`羁绊`
  - 位置：`首`（播放器放在回复开头）、`尾`（放在回复末尾）
  - 例：`测三`、`测三 战斗`、`测五 尾 羁绊`。输入框上头有现成的小签，点了会把那两个字填进去（替换输入框里的字），要组合就自己打。
- **回复长什么样**：头一行、末一行各是底座和曲尾。放播放器的那一行变成一个**蓝框**，框顶上写着「【测几】哪种写法｜放在开头还是末尾｜曲几｜第几轮」，旁边一盏**状态灯**（▶ 在响／■ 停着）。这盏灯靠浏览器认 `:playing`，本机的 Chrome 不认，电脑上多半一直写着“状态灯不亮”，那就靠耳朵；iPhone 的 Safari 认，手机上可以看它。蓝框底下一行是这种写法用到的标签和属性，留下了是绿的 ✓，被平台删了是红的 ✗。不放播放器的那一行只是一条灰字。
- **末一行前头有一块折着的「体检」**，点开是二十来行，报平台留下了哪些标签和属性，绿 ✓ 红 ✗。头一轮点开截一张图就够，后面不用每轮看。
- AI 偶尔会写错格式（比如竖线写成半角）。蓝框没出来、只有灰字，先看灰字里那一行是不是写歪了；写歪了就重新生成那一条。
- 先把电脑音量调小一点，戴耳机更好分辨。

### 八种写法

| 打 | 写法 |
|---|---|
| 测零 | 不放播放器，只有灰字（用来听上一条还响不响） |
| 测一 | `<audio src autoplay loop preload="auto">`，没有控件，看不见 |
| 测二 | 照“西幻音乐盒”那个 mod 原样：`<audio controls loop preload="metadata" playsinline controlslist="nodownload">`，手点才放 |
| 测三 | 测二那一版加 `autoplay` |
| 测四 | `<video autoplay loop playsinline controls>`，只放声 |
| 测五 | `<audio controls autoplay loop>`，里头四个 `<source>`（四个 jsDelivr 镜像）兜底 |
| 测六 | 一枚「♪ 点这里放一次」的钮：`data-action="audio-once"` |
| 测七 | `<embed>`、`<object>`、`<iframe srcdoc>` 三样（自动播放） |

## 本地复刻台先跑过的（只验展开，不算平台结论）

拿 `复刻台/` 里三支脚本跑的（日里照 rili-chat-frontend 第 7 节那一套：正则 → react-markdown → 拦 script、iframe、object、embed、base 和 on 开头的属性；风月照 `tools/rili_bench/static_bench_fy.mjs` 里抄的正则脚本和标签过滤），十六条样本（八种写法、首尾各一）：

- 两边展开都对：该出蓝框的出一个，另一行是灰字，没有漏网的 § 行；体检块在末一行前头。
- 留下的：audio（src、autoplay、loop、controls、preload、playsinline、controlslist 都在）、video、audio 里的 source、data-action。删掉的：embed、object、iframe（连 srcdoc）、onerror。script 不跑。回复里的 style 日里生效、风月整个拿掉（所以风月那张的探针样式放在卡的样式格里）。muted 在日里复刻台上报“没了”，是 React 只设属性值不写标签的缘故，不是被删。
- 日里那一套 React 挂法下（浏览器开着“不用点也能出声”，只看机制）：回复四个字四个字地长，开头的播放器从头到尾是同一个、只 play 一回，放在末尾的也一样；新回复出来，上一条照旧在放（会叠音）；一条回复卸载再挂上（虚拟列表滚远滚回），播放器是新的一个，从头再放。
- 真平台上要靠你听的：按了发送以后浏览器肯不肯出声、日里的流式写完那一刻会不会换一个组件重挂、风月怎么把 HTML 换进页面、手机。

## 附：东西放在哪

- 合成：本机 ffmpeg 的 `aevalsrc`，各 20 秒，44.1kHz 双声道 128k，开头 1.6 秒一声高音“叮”（1568Hz 加 2349Hz，衰减），后面的音 1.5 秒淡入、末尾 1.5 秒淡出，限幅 0.8。甲是 110、165、220Hz 三个正弦叠着慢慢起伏；乙是每半秒一声往下扫频的低鼓，每四分之一拍一点噪声镲；丙是 C5、E5、G5 每 0.3 秒一个、带衰减，底下垫一个 C3。
