# 状态栏美术 · 接用户电脑上的 ComfyUI 出图（11-03 起）

照状态栏美化方向稿第四版第七节、第九节第5条出大框两侧的画，先出迷宫纪 1001 年那一套（用户的电脑端构想图当风格参照）。

## 怎么接

这个会话跑在云端，连不到用户电脑上的 127.0.0.1:8188。用户在电脑上建一个文件夹（11-03 建议桌面上的 `aldran_art`），在 Claude 桌面版 设置 → Claude Code → Remote Control 里加进去，或者在那个文件夹里跑 `claude remote-control`。这边 list_computer_folders 看得到以后，request_computer_folder 请求连，用户点允许，连上以后命令在用户电脑上那个文件夹里跑。Claude Code 直接开在用户电脑上就不用这一步。Comfy Desktop 开着不等于 8188 有服务：它上次开的是 Comfy Cloud，本地要在 Desktop 里启动 ComfyUI (1)，或者用那一份的 `ComfyUI\.venv\Scripts\python.exe -s ComfyUI\main.py` 带上 `--extra-model-paths-config`、`--input-directory`、`--output-directory` 启动（路径在 Desktop 的 `instance-model-paths` 和 settings.json 里），冷启动要五分钟上下。

## 这一份的文件

- comfy_run.py：出图脚本，只用标准库，画底稿和收图用 Pillow（ComfyUI 自带的 python 就有）。
  - `python comfy_run.py probe`：查系统、显卡显存、装了哪些模型和节点，写 probe.json、object_info.json。
  - `python comfy_run.py sketch maze1001`：画构图底稿，彩色那一张给图生图打底，线稿给 ControlNet。
  - `python comfy_run.py run plan_maze1001.json [--only left] [--seeds 11,22] [--draft] [--dry]`：照计划出图，图、WebP 和工作流写 out/<套>/<件>/，每件拼一张小样 _sheet.jpg。`--draft` 只出第一遍、不做高清修复，写 out/<套>_draft/<件>/。
  - `python comfy_run.py comp plan_maze1001.json [--seeds 11,22] [--refine 0.14]`：计划里带 comp 的那一件（眼下是右扇）走这一条，七神一位一张裁进圆光，双王从 refs/ 里用户给的图抠，铺在背景上，写 out/<套>_draft/<件>/，零件在 parts/，已有的不重出。
  - 节点入参照 /object_info 补默认值，ComfyUI 版本不同多出来的必填项也跑得起来。SDXL 一路（底模、区域提示、ControlNet、IPAdapter、高清修复）、Flux 一路（UNET、双 CLIP、FluxGuidance、图生图）和 Anima 一路（UNET、单个文本编码器、VAE，负面和区域提示照用，11-03 添的）都写了，用哪一路看 probe。
- plan_maze1001.json：左右两扇的提示词、区域提示（七支柱照底卡 #86 到 #92 显相，双王照底卡）、尺寸（出 704×1408，高清修复到 1000×2000）、种子。config 一栏 11-03 照 probe 填了：这台电脑只装了 Anima preview3，没有 checkpoint、ControlNet、LoRA、放大模型和 IPAdapter 节点，所以走 anima 一路，构图只靠彩色底稿图生图，线稿和 refs/ 的风格参照没用上。
- sketches/maze1001/：构图底稿，左扇是大迷宫一圈一圈往下的井和城、井底的影子（不画脸）、黑日、崖边一个旅人；右扇是七支柱各一圈圆光、底下双王、再往下阿卡迪亚和空艇。左扇左边是外侧、右边贴窗，右扇反过来。
- refs/：用户构想图裁的左右两半，缩到 768 高，给 IPAdapter 当风格参照；巴尔缇娜、索恩薇娅两张是用户 11-03 给的长相参考，comp 直接从这两张抠。

## 画的规矩（方向稿第四版第九节）

- 两扇压在对话上面，靠窗那一边七十像素上下给花边切，要紧的人和物别贴着那一边，上下各一成给裁。
- 宽屏上两扇按 cover 裁，窄一点的屏幕裁掉的是外侧，所以要紧的东西偏窗那一边、离窗边七十像素以外。
- 全彩不抠底，暗面偏紫、亮面偏金，金线勾边。提示词里不写月相（反面提示词里写了 crescent moon、moon phases）。
- 七支柱不画成构想图那几处：欧巴德斯半身不朽石躯、山脉鳞层的翼，库米罗妮一百四十二公分、幼鹿角，伊兹帕鲁特翼里火焰冰雾雷光，朱亚头顶细小羽翼、翠玉眼，耶万朴素长袍。艾赫卡托尔先画她本人带着黑猫（用户还没定）。
- 出的图换掉大框样式里的 `__ART__/maze_left.webp`、`maze_right.webp`。

## 11-03 试出来的（RX 6700 XT 12GB，Anima preview3）

- 速度差得很悬殊：640×640 约一秒一步（一张二十六秒），704×1408 十到二十秒一步（一张五到十分钟），1008×2000 五十六秒一步（高清修复一张近二十分钟）。能拆成小图的就拆。
- 这个模型 shift 是 3，denoise 比面上的数猛：0.28 实际起点约五成四的噪声，0.38 约六成五。
- 区域提示不能用：每块一百八十像素上下，画不出人，还碎成方块。整幅一次出九个人也不行，自然语言描述再细也挤成一摞、特征串位。所以右扇走 comp。
- comp 那一路整幅低重绘不能用，0.28 就把圆光里的脸毁了，巴尔缇娜的眼睛也变红。只给双王做局部低重绘，0.20 抹掉额头红印、王冠散掉，0.14 刚好，红印、疤和王冠都在。
- 背景的提示词前缀不能带 art nouveau filigree，一带就自己长出一圈画框，所以 comp 里有单独的 bg_prefix。
- 高清修复（1000×2000）还没跑完过一张，第一张试跑时中断了。plan 里的 hires 0.38 照上面那条算偏猛，正式跑之前要先试低一点。右扇 comp 直接在 1000×2000 上合成，圆光和双王不用高清修复，只有背景是放大上去的。
- 左扇的旅人容易贴窗：种子 101 和 303 的斗篷伸进贴窗那七十像素，会叫花边切掉一点，202 没事。

七神长相的来源：底卡 #86 到 #92 显相为准，配色和服装参考 Elona Mobile 官方立绘（神々の休戦地），Elin 设定（Ylvapedia）跟底卡对得上。不合的地方听底卡：璐璐薇金发（立绘是黑发），库米罗妮是她（原作是他）。耶万没找到立绘，只照设定写朴素长袍、温雅而危险。索恩薇娅用户给的图是长发盘发，底卡写的是剪到肩头，这里照用户的图，等用户定底卡要不要跟着改。

用户说圆光拼贴的构图怪，放到对话框旁边更怪，给了凯旋门《马赛曲》、多纳泰罗灰石贴金两张，说“这种风格的浮雕样式，每个人都有自己的动作，但是中心点该是最中间的输出内容”，又给了一批原神活动页、《闪耀的群星》、书页动画，说“整体的美术风格其实我想参考的是原神的那种画法”。

- 圆光那一版（comp、out/maze1001_draft/）和左扇三张都作废，代码和图先留着。
- 试验在 out/方向试验_11-03/：石刻是 relief*，原神画法是 style*，mock_*.jpg 是贴回大框的预览（拿现成截图和占位图反推露出区域贴的，不是真跑样式）。脚本在 试验_11-03/，提示词都在里面。
- 512×1024 一张三十八秒，约 1.4 秒一步，很快。自然语言比标签写法好得多。石刻 Anima 也画得出来。
- 现在的样子还只是方向：人数比九个多，七神的特征没逐个对，双王只有发色和衣服像，没有用户那两张图的脸，颗粒肌理也偏弱。用户定了方向再逐个人物对。
- 用户这一批参考图只在对话里，磁盘上没有文件（《马赛曲》是吕德的凯旋门浮雕，灰石贴金那张是多纳泰罗的卡瓦尔坎蒂天使报喜），要留底得用户放进 refs/。

## 11-03 第二回：四方盖边、日式二次元、换模型（现行）

用户给构想图说“能够做到像这样、直接让四方的浮雕自然的覆盖边缘。而非现在的不自然的波浪”，“现在的画风虽然靠近原神了但感觉有点往西方动画迪斯尼的方向跑了，原神是日式二次元西幻”，“模型方面都可以升级”。上面几节写的整幅出图、圆光拼贴和 storybook 那一路提示词都作废，现行的做法是下面这些。

**做法**：一样东西一张图，白底出、抠透明，再一层一层拼。四张带透明的图（左、右、楣、座），靠窗那一边的轮廓就是画里的东西，平的地方停在框线上，弓箭、火翼、麦穗、剑、巨手、崖石这些伸过框线，把框线盖住。

- `maze1001_parts.py`：全部零件的提示词（七神、双王、烟、飘带、云、崖石、旅人、徽记、城、背景），`python maze1001_parts.py [名字前缀…]`，已有的不重出，不带参数时最后再做补全和重绘（EXTENDS 那几张）。
- `cut_cpu.py`：抠图。ComfyUI 的 RemoveBackground 节点在这张显卡上报 miopenStatusUnknownError，这里单独起一个进程跑同一个模型，`CUT_GPU=1` 走显卡（关掉 torch.backends.cudnn，一张九秒，起进程要一分半），不设走 CPU（慢）。退出时报的 ON_DETACH 不用管。
- `kit.py`：`gen` 出一张（turbo 或 aesthetic，可带 init、control、inpaint），`extend` 往左上续画、`extend_right` 往右续画，原来的像素不动。人物的手、剑、弓、王冠叫图边裁了就用它补全，官方 LLLite 重绘接得很好。
- `frame_comp.py`：拼合的小工具（去抠图白边、补细线、边淡出、压环境色、朝窗的轮廓光、投影）。
- `maze1001_frame.py`：四张图的排版，都是写死的坐标，`python maze1001_frame.py [right left top bottom]`，写 out/四方_11-03/art/。`frame_sheet.py` 拼透明说明图，`run_frame.sh` 重拼并跑真样式出预览。
- `tools/rili_bench/static_bench.mjs`：不装依赖的复刻台，用本机 Chrome 无头跑真样式出预览。

**尺寸的账**：两扇 1400×2000，高度跟视口走（`auto 100%`），靠窗 90 像素是伸进窗里的余量，所以样式里 `--fm-bite:4.5dvh`，高屏窗口跟着放宽（`max(760px, 640px + 11dvh)`），字不会被盖。1536×1024 上只露靠窗 850 像素，要紧的人都放在这里面，再往外是宽屏才看得见的。楣和座 3000 宽，样式里固定 1250×210、1250×230，框上沿在楣的 y=240，框下沿在座的 y=336。座在页签那一段不许往上画（`safe_zone`）。

**模型（都从官方仓库下的 safetensors，核过 sha256，放在 ComfyUI-Shared/models 下）**：anima-turbo-v1.1（4.18GB，现在用的）、anima-aesthetic-v1.1（4.18GB，左扇的底用了，见下）、birefnet（0.44GB）、anima-lllite 的 inpainting-v2、any-test-like-v2、lineart-1、pose-1、scribble-1（一共 0.13GB，只用了 inpainting）、RealESRGAN_x4plus（0.07GB，还没用）。Anima 的非商用许可管的是模型本身，模型卡写明出的图可以商用。

**试出来的**：
- 提示词要写日式二次元手游立绘那一路：`official art, game cg, genshin impact, anime coloring, soft cel shading, delicate thin lineart, detailed face, beautiful detailed eyes, shiny hair, gradient hair, intricate fantasy costume, gold embroidery`。上一回往迪士尼跑，是 storybook、flat color、minimal facial features 这几个词带的。
- Turbo 8 到 12 步、CFG 1，一遍过模型，显存压力小一半：768×1120 一张二十二秒，832×1216 就掉到九十秒，这张卡的悬崖在这两个尺寸之间。平时就用 768×1120。
- Aesthetic 要 CFG 4，两遍，768×1120 一步两到七秒，从头出一张三四分钟。线更细、衣服的纹样细密得多，人物从头出明显比 Turbo 精致（out/四方_11-03/Turbo与精修版对比.jpg，左边 Turbo 右边精修版），在 Turbo 的图上低重绘只多一点细节。左扇的底拿它重绘过（0.55），软了很多，黑日也画实了。人物这一轮还是 Turbo 的，整套换要半小时上下，等用户定。
- 模型卡说 Aesthetic 不要写 score_ 标签，Turbo、Base 可以写；画师标签要加 @，这里没用画师名。
- BiRefNet 会丢弓弦、箭杆这种细东西，`keep_thin` 拿白底图上不白的地方补回来。Turbo 的白底常在 245 上下，阈值要按图算，不然留一层淡淡的方块。
- 整张画（比如左扇的背景）抠不出里面的手，要伸过框线的东西单独出。
- 双王照用户的图写提示词，一张一个动作，头发、王冠、疤、额头红印、黑蝴蝶结都对得上，脸不是那两张图的脸。索恩薇娅的发色写 dark brown hair with auburn tips 才对，写 auburn 偏酒红。

**还差的**：只有迷宫纪 1001 年这一套，别的四纪还是花边遮罩和材质色。预览是复刻台跑的，平台上的外壳层次、图床还要在真页面上对。夜里两扇照钟点暗一档那个 filter 照旧，没有单独试。人物是白底出的，光是后拼的轮廓光，没有真正的场景光。

## 11-03 第三回：接外部模型（查到的，等用户选）

GPT 那一条下面第四回更正了：Plus 能走订阅出图，不用 API key。

用户回：右边这样的构图基本对味，左边大迷宫和右边的人物画风还差，“有点廉价二游的感觉”，问能不能接 Midjourney、GPT 或 Gemini 的账号。构图和四方盖边的做法留着，要换的是零件的画。

- Midjourney：官方社区规范写明没有 API，自动操作严格禁止，账号可能被封。第三方“Midjourney API”都是驱动账号，同样的风险。只能用户手动出，放进文件夹，这边抠图、排版。
- GPT：这台电脑装了官方 Codex（`%LOCALAPPDATA%\OpenAI\Codex\bin\…\codex.exe`，不在 PATH 上），已用 ChatGPT 账号登录，`image_generation` 也开着。试了 `codex exec` 八次都没出图：配置里的默认模型 gpt-6-astra 在 ChatGPT 账号下报不支持，这个账号能用的只有 gpt-6-luna、gpt-5.6-terra、gpt-5.6-luna；换这几个以后回“built-in image generation tool isn't exposed in this session”。原因没查实，官方写免费档没有这个功能，用户的档位不知道。官方文档说程序化出图走 API。
- OpenAI API：ChatGPT 订阅不含，要 `OPENAI_API_KEY`，按量。官方价 GPT Image 2 竖版 1024×1536 高质量 0.165 美元一张，GPT Image 2.5 图片输出 30 美元每百万 token。可以 `background: transparent`，自定义尺寸，比例到 1:3。
- Gemini：Pro 订阅和 API 分开。Gemini CLI 的 1500 次一天是对话额度，官方的 nanobanana 扩展要 API key。官方价 Nano Banana Pro 0.134 美元一张（1K、2K），Nano Banana 2.1 0.0504 美元一张（2K），图片模型没有免费档。
- ComfyUI 里有 `OpenAIGPTImageNodeV2`、`GeminiImage2Node` 这些合作方节点，走 Comfy 账号的积分，不走用户的 OpenAI 或 Google 账号，要 Comfy 的 API key。
- 网页版：Claude in Chrome 这会儿没有连上的浏览器。连上以后能在用户已登录的 Gemini 页面上慢慢操作，走订阅额度，但慢，也容易断，Google 的条款这一条没查实。
- out/四方_11-03/外部试图/ 是给用户手动试的一包：四张参考图、三家的提示词。这轮试 Codex 时参考图随请求发给了 OpenAI。

## 11-03 第四回：GPT 接上了（用户续了 Plus）

上一回“订阅接不进来”的结论错了。那时账号是免费档（Codex 的会话记录里 plan 是 free），免费档没有出图工具。用户续上 Plus 以后 plan 是 plus，工具表里就有 `image_gen__imagegen`，不用 API key，走订阅额度。官方文档写的底层模型是 gpt-image-2。

- **怎么跑**：`gpt_gen.py` 的 `gen(输出前缀, 提示词, refs=[参考图…])`，调用户电脑上官方 Codex 的 `codex exec`（不在 PATH 上，在 `%LOCALAPPDATA%\OpenAI\Codex\bin\…\codex.exe`）。模型写 gpt-6-luna、推理 low，只在命令里覆盖（配置里默认 gpt-6-astra、xhigh，拿来调图太贵），配置文件的事见第五回。一次两三分钟。
- **坑**：Codex 看不到自己出的图，会回“没拿到图”，左扇那回还多画了一张。图都在 `~/.codex/generated_images/<会话号>/`，`gpt_gen.py` 照日志里的会话号去取，提示词末尾加了只调一次、别重试。取图这一段拿这回的两份日志测过，sha256 一致。整条流程第五回跑通了。
- **额度**：三张图加十来次调用以后，Codex 报的 5 小时和一周用量都还是 0%，这个数可能有延迟，整套能出多少张没有实测。官方写出图消耗额度比普通对话快 3 到 5 倍，大批量建议走 API。
