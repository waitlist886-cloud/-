# 派活

你要照一份写好的说明，改一张中文 AI 跑团卡（日式西幻《奥尔德兰的旅印》）的源稿。这是创作文本的活，要手写，口气和分量照说明里的样稿。

活的文件夹就是这一份 `派活.md` 所在的文件夹。

## 做法

1. 先读这个文件夹里的 `任务.md`（你这一份要改的技艺和旅伴）和 `写法说明.md`（全读，第八节是样稿），再读 `样稿_定稿四门.md`，和 `门表.md` 的第二到五节。
2. 照说明改 `稿/` 里的文件。`原/` 是底本，不许动。只动任务里列的星条和旅伴条（连它后头的背景条）。
3. 文件很大，别整份读。用 Grep 找 `### 技艺名 (Art` 和 `## 旅途同行：人名` 的行号，再用 Read 的 offset、limit 只读那一段。要知道这个人在主线里拿这门本事做了什么，再去翻主线里写到他的那几拍。
4. 改完在这个文件夹里跑 `python -I -X utf8 自查.py`，「错」改到 0，「看」逐条看过。
5. 在这个文件夹里写 `备注.md`（三十行以内，写法见说明第七节，里头单列一节「任务以外要跟着改的」）。

## 规矩

- 只在这个文件夹里写东西，临时脚本也放在这个文件夹里、文件名带上份名。
- 文件原来是什么换行符就照什么换行符写回。
- 仓库 `E:/aldran_art` 只许读（要查这个人、这门本事在别处怎么写的时候可以 Grep），一个字不许改，不碰 git。
- 不要另派子任务。
- Legend 的技艺三样都要写实：法门、战法、练法哪一行也不许写“没有”。原条目没写的那一样，照这一门的来路和持有人做到头的那件事补出来，标（★）。
- 持有人的位阶比这一卷的顶高（英雄、传奇手里一卷 Epic）的，条目照这一卷写到极境为止，不用另写他本人那一层。
- 自查报的错要是误报（比如新名字里含着旧名），在备注里说一句，不用为了过自查去改对的东西。

## 交回

最后回一段话，两百字以内：改了几门技艺、几位旅伴，自查的结果（错几条、看几条），最拿不准的一两件。
