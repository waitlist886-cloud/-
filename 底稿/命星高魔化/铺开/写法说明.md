# 旅伴与命星重审·铺开·写法说明（11-17）

给写这一份活的人看。这张卡是日式西幻的 AI 跑团卡《奥尔德兰的旅印》，高魔，JRPG，剑与魔法。四纪的命星里，技艺（Art）原来写成了一人一手技巧，一律标 Epic，旅伴里混着不少长辈和孩子。用户定了新方向，判好了两张表，现在照表改源稿。你管一份：几位旅伴，和他们名下的技艺。

## 一、先读

1. 这一份的 `任务.md`。每一门技艺、每一位旅伴要怎么改，都在里头。
2. 这一份说明，全读。第八节是样稿。
3. `样稿_定稿四门.md`。用户认过的四门（守望长律 Legend、风铃长追法 Epic、七坑岩息 Epic、羊梁投石术 Rare），口气和分量照它。
4. `门表.md` 第二到五节，看你手里的技艺归的那几门讲的是什么、下游是底卡的哪一门。

文件都很大。别整份读，用 Grep 找 `### 技艺名 (Art` 和 `## 旅途同行：人名`，只读那几十行到一两百行。要知道这个人在主线里拿这一门做了什么，再去翻主线里写到他的那几拍。

## 二、怎么动手

- 只改 `稿/` 里的文件。`原/` 是底本，一个字不许动。
- 只动任务里列的星条和旅伴条（旅伴条后头紧跟的背景条算他的）。别处一个字不动，动了也不收。Special、Passive 的星条这一轮不动。
- 文件的换行符照原样，有的文件是 CRLF。整块替换不好对的时候，写一小段 Python 照行号换，脚本放在这个文件夹里，文件名带上这一份的名字。换完看一眼前后各两行，别丢了换行、别把下一块粘上来。
- 改完在这个文件夹里跑 `python -I -X utf8 自查.py`。「错」要改到 0。「看」逐条看一眼，对的留着，在备注里说一句为什么。

## 三、一门技艺三样，三档

技艺是一条能修一辈子的路，有三样东西。

- **法门**：力量从哪里来，平日怎么修，修久了身上什么样，修岔了怎样。照月银纪的四门写，写明是哪一门、哪一曜。饮血（喝兽血吃兽肉干重活，把身子练成兵器），呼吸（一曜一套呼吸法，七曜是赤火、橙冰、黄岩、绿草、青风、蓝水、紫雷），冥想（不往身子里吸，在身子外头调曜），祷告（求神）。血脉是生来的（沸血、龙息、逆鳞），技艺是驯它的法子。
- **战法**：打起来怎么用，成套的几手，对什么。
- **练法**：在哪里学，分几步，教得出来，传得下去。歌、调子、口诀、一趟要走的路，都是练法。

| 档 | 有什么 | 陪人长到哪 | 条目写几行 |
|---|---|---|---|
| Rare | 一手散招，一门的头几课，或者一门有用处的行当。没有法门，可手上有一处看得见的小魔法（11-19 夜起，行当做久了会沾灵） | 不随位阶长 | 用处、限制、传承，三行 |
| Epic | 一卷。只有一样成了体系，或者两样有而一样残缺、带大缺陷 | 写到极境为止 | 法门、战法、练法、修行重点、限制、世界反应（可以不写）、传承 |
| Legend | 整本。三样齐，教得出来，传得下去 | 写到英雄以上 | 同 Epic |

位阶的次序是启源、共鸣、灵格、极境、英雄、传奇。

## 四、技艺条目怎么写

### 1. 样子

```
### 名 (Art | 档)

【调用】什么时候用这一条。照原来那一句改，名字换成新的。

【名】是哪里的、谁家的什么。一两句来路。再一句直说它三样里有哪样、缺哪样。

- 法门：……
- 战法：……
- 练法：……
- 修行重点：吃哪几门本事。原来那一行照留，里头那句人话别丢。
- 限制：管不了什么。Epic 的大缺陷写在这里。
- 世界反应：原来有、写得好的照留，没有就不写。
- 传承：谁起的头，哪一代添了哪一样，这个人手里是哪一版、缺什么。

```

Rare 只有三行：

```
### 名 (Art | Rare)

【调用】……

【名】是哪里的、谁家的什么。一两句来路。直说它是散招、头几课还是一门行当。

- 用处：做得到什么，带数（多远、多少人、多久）。
- 限制：做不到什么。
- 传承：谁家的，谁教谁。一两句。

```

标题一字不差照任务里给的写。星条末尾留一个空行。原来的「定位」那一行拆掉，不留。

### 2. 任务里各栏怎么用

- **卷**和**缺什么或做到头的**：说的是这一门三样里有哪样、缺哪样。两栏对不上的时候照后一栏。条目里三行都写，有的写实，没有的直说没有，再说一句靠什么顶着、卡在哪。「没有」的那一行各门换着写，别一个模子。
- **法门**一栏：
  - 呼吸·某曜、冥想、祷告、饮血：法门那一行开头写明是哪一门、哪一曜，再写怎么修、身上什么样。
  - 血脉：写血里带的是什么，这一门怎么驯它。
  - 手艺：出东西的手艺（锻造、炼药、做饭、刻碑）。法门那一行写火候和料，战法那一行写出的东西顶什么用，练法照旧。
  - 无：法门那一行直说没有。
- **练到这一版的顶上看得见什么**（Epic 才有）：这一句是用户认过的分量。把它写进法门或者战法那一行的最后一层，写成“到了极境，……”。意思照它，句子可以顺。Epic 的顶就到这一句，不往上再加。
- **位阶写几层**：Epic 写两到三层，到极境为止。持有人眼下的位阶当其中一层（“蕾娃是灵格，……”）。原条目里写到英雄、传奇的那一层收掉，要是那一层正是“顶上看得见什么”那一句，就挪到极境上。Legend 多写一层英雄以上。Rare 不写位阶。别把共鸣、灵格、极境、英雄四档排满。
- **来路**：
  - 名字换了的：本事照旧。首段里把旧名带一回，写成谁嘴里的叫法（“墙上的兵只叫它梯道的枪”“绳街上只叫左捻”）。
  - 新起的：原来那一门行当撤了，这个人另补一门。照任务里的用处、限制和依据整块新写，只用这个人身上本来就有的事（他的兵器、出身、主线里真做过的那件事），不另编大事。原来的行当留在身份行里。
  - 同门共用的：这一门是别人那一脉现成的，他手里只有头几课或者一卷。照 Rare（或者任务里给的档）写一条短的，首段说清整门是谁家的、他手里是哪一截。
  - 任务里写着“同名的条目别人已经写了”的：把原来的块整块删掉，不另写，只改能力行。
- **这几门在四纪里的别的条目**：写传承那一行时对一遍上下游。可以写哪一代谁添了什么、后来分出了哪一门，这是事实。不写“见某页某条”这种出处。

### 3. 分寸

- **行当沾了灵（11-19 夜改，原写“行当就是行当，不添光”）。** 捻绳、撑船、记账、唱号子，先写它实实在在做得到什么，再写这一门做久了沾的那一点灵：一个人、一队人、一间屋、一夜的分量，落在它本来做的那件事上，带数，限制里写它管不到什么。样子照 `底稿/命星重审第二轮/样稿_第二版.md` 第四节。
- **不把本事写成一条规矩或者一个概念。** 写看得见的结果：打得中什么，顶得住多重，传得了多远，撑得了多久。
- **不往小里写。** 这是高魔的世界。Epic 顶上那一层照任务里那一句写足，法门修久了身上什么样、战法对上大东西怎样，都写得出画面。
- **也不起过头。** Epic 是一卷，不是整本，写到极境就停。Rare 朴素，两三行说清就够，一条不过三百来字。
- **原条目里的东西带过来。** 事实、数、年份、人名、引的话、带（★）的句子、“只给 AI”的句子，照原样带进新条目里合适的那一行，不丢，不改数。
- **可以补的。** 法门怎么修、练法分几步、战法具体是哪几手，原条目没写的可以照这一门的来路补，补的句子末尾标（★）。不编新的人物和年份。
- **一句交代一件事。** 不写“不是……而是……”的套句，不排三连的排比，“那一”“这一”少用。
- **各层别用同一串字。** 一行里写了持有人这一阶做得到什么，再写极境那一层，两句不要把同一个画面重说一遍，持有人那一阶写他眼下真做到过的事，极境照任务里那一句。
- **任务里那一句跟页上的事对不上，照页上的事。** 表里“顶上那一层”是照摘要排的。它跟这一页主线里写明的事实拧着的时候（谁的火、哪一年、谁在场），照页上的事实把那一句改顺，备注里记一笔。数跟样稿对不上的，照样稿。

### 4. 能力行、底座、裁定锁

- 能力行里只改 Art 那一段，写成 `Art【名】(档，一句话)`。一句话说清是哪一门的哪一卷或者头几课、他手里有什么、缺什么，四十个字以内。Special、Passive 那两段不动。
- 底座那一行末尾的“法门 旧名”换成“法门 新名”。别的不动。
- 这个人的裁定锁里说到这颗星的那一条，名字换成新的，意思对着新条目顺一遍。原来那一门撤了的，把那一条改成说新补的这一门，一句就够。
- 这个人条目里别的地方：带【】的旧名换成新名。不带【】、当寻常话用的（一支歌、一个习惯、一句口头话）照留，那是这个世界里本来的叫法。

## 五、旅伴条怎么改

照任务里那几栏。没写要动的栏不动。

- **去留是「降」**：紧跟在“固定锚定”那一行后头添一行 `类别：相遇｜缘故`。缘故照任务里的说明写成一句卡面的话，十来个字到二十来个字，写这个人自己是谁（“碑匠街带学徒的老碑匠”“七十岁的老书记长，誊了五十年册子”“八岁的孩子，这一段里是被护着的那一个”）。一份里几位降的，各写各的，不要个个收在“是这条线上的长辈”上，这一句一份里至多用一回。别的行不动，条目、羁绊、好感都照留。
- **去留是「归传奇类」**：同一处添 `类别：传奇｜缘故`。
- **位阶走势**：紧跟在“底座”那一行后头添一行 `位阶走势：开局某阶（LVL 数）。哪一年哪一件事那一下到某阶（LVL 数）。` 开局的数照底座。收束的数任务里给了照给的，没给的在那一阶的范围里取一个（启源 1 到 20，共鸣 21 到 40，灵格 41 到 80，极境 81 到 120，英雄 121 到 200，传奇 201 以上），标（★）。
- **下场添一句**：在“正史里的下场”那一节叙述的末尾添一两句，说他为什么没有再往上走。任务里给了是三种里的哪一种和他自己的那件事，照它写成这个人的事，不写成道理。例：“他生来一副跑三天不停的腿，一辈子没有拿它去换名字。他要的是羊，一间屋，三个孩子。”
- **年纪调整**：
  - “改成N岁（……）”：生年照开局那一年往回推，月日不动。固定锚定里的生年和外表、【调用】里的年份、身份和外貌里的岁数、底座里的岁数、下场和背景条里牵到的年份，一处一处改齐。括号里点了的句子照改。长相不用动。
  - “抬到极境”“开局抬到某阶”：底座里的位阶和 LVL 照改，条目里别处说到他位阶的地方对一遍。
  - “不动，添一句”：照下场添一句办。
  - “牵着某年某事，降”：照降办。
- **升传奇**：这一栏你不写，主会话另写。这个人别的栏照做。

## 六、卡面口径

- 不用这几种标点：破折号（长的短的都不用）、分号、省略号、感叹号。
- 冒号只用在行首的标签后头，标签八个字以内。引人说的话用“”，一句引语在同一行收住。「」不用。
- 不写月相（新月、满月、残月、月牙、弦月、月亮、月光）。
- 神用祂。不点那一位恶神的名字。
- 不用中式口语和武侠古风的字：爹、娘、师父、徒弟、掌柜、伙计、客栈、江湖、内力、功法、宗门、长老、时辰、灶、晌午。写父亲、母亲、老师、学徒、店主、帮工。
- 不用科技词：能量、系统、频率、坐标、量子。
- “营”不泛用。营垒、营地这些定名照留，别的写驻地、帐子、篝火、这一层。
- 新起的设定在句末标（★）。原来带（★）的照带。

## 七、交什么

- `稿/` 里改好的文件，自查的错是 0。
- 这个文件夹里写一份 `备注.md`，三十行以内：拿不准的，新补的（★）有哪些，跟任务不一样的地方和缘故，原条目自己前后对不上的地方（只记不改）。
- 备注里单列一节「任务以外要跟着改的」。你不许动的地方（别人的条目、Special 和 Passive 的星条、条目设置、主线、「## 星」开头、设计备注）里，凡是因为你这一份变了就不对了的事实，一处一行列出来：哪个文件、原句里的哪几个字、该改成什么。最要紧的是年纪调整牵到的年份（背景条触发正则里的年份、别的星条里写的那一年）和撤掉的那一门在别处当星引用的地方。只是旧名字还留着的不用列，主会话统一换。
- 最后回一段话，两百字以内：改了几门技艺、几位旅伴，自查的结果，最拿不准的一两件。

## 八、样稿

用户认过的四门在 `样稿_定稿四门.md`。下面六门是照同一把尺子写的，各是一种常见的情形。

### 甲、只有战法的一卷（Epic，名字换了，原名梯道断后枪术）

```
### 逆潮殿后枪术 (Art | Epic)

【调用】繁荣的年月里，玛蕾在台阶上、豁口前、窄过道里退着打，一步一退，身后的人有工夫走，或者有人想学守梯道的枪的时候。

【逆潮殿后枪术】是长垒上散裔守梯道的老枪法，墙上的兵只叫它梯道的枪。东西从底下往上涌，最后一个人倒退着上台阶，枪头朝下，一级一扫，不追，不停，顶上的人撤完了，他才转身（★）。它只有战法这一卷。暖谷里那个从墙上退下来的散裔老兵守过二十年梯道，玛蕾十岁起跟他学，十八岁那年他死在岩檐底下。

- 法门：没有。这一路枪不养人，使它的人靠自己的腿和一口不乱的气，位阶是在别处长的。
- 战法：退着守。脚先找到台阶再落，眼睛不离枪尖底下那一级。枪头朝下，一级一扫，扫的是扒上来的手和头，不贪第二下。共鸣的人守得住一道豁口，身后几个人一个一个过去。到了极境，往上涌的潮压到最窄的那一处，她退得比潮慢，潮就得等她（★）。
- 练法：没有成文的。墙上是老兵带着新兵在梯道上倒着走，走到不用回头看台阶。暖谷里那个老兵只教过玛蕾一个人。
- 修行重点：长杆熟练度、耐力、察觉。老兵教她的头一句是，断后的人不看前头，前头有人看着。
- 限制：只守窄处，宽的地方一杆枪扫不过来。人得往后退着守，往前追不出去。守到最后一个走了她才走，她自己走不走得了，枪法不管。
- 传承：长垒上散裔守梯道的老枪法，墙上的人几辈守出来的。暖谷那个老兵手里是这一版，传给玛蕾，只有战法一卷，Epic（★）。它缺一口退着走也不散的气，谁给它配上法门、把倒着走的步子写成册，这一路才成得了一门。

```

能力行：`Art【逆潮殿后枪术】(Epic，墙上散裔守梯道的老枪法，只有战法一卷，退着打，一级一扫，身后的人有工夫走)`。底座末尾：`法门 逆潮殿后枪术`。

原条目里“到了英雄，一股往上涌的潮压上来……”那一层，正是任务里“顶上看得见什么”那一句，挪到了极境上。

### 乙、只有练法的一卷（Epic，歌一路，原名回程调）

```
### 不惑归途咏 (Art | Epic)

【调用】繁荣的年月里，朗贝尔领着一队人往回走，唱着收绳谣往上收的那半首改成的咏，一队人的脚步跟着齐，或者有人想学往回走的路上怎么不出事的时候。

【不惑归途咏】是收绳谣往上收的那半首长出来的一枝，井口的人叫它回程调。井口人往上收人的时候唱收绳谣，一句一个结，唱到最后一句，人就到了井沿上。朗贝尔七岁在升降井边学会了，二十六岁起带新人，把它唱到了往回走的路上，他说往回走的时候最容易出事，人以为快到了，脚就松了（★）。它是一卷练法，自己不打仗。

- 法门：没有。它稳的是跟着唱的人自己的那口气，气从哪里来，各人照各人的。
- 战法：没有。碰上东西，各人还是使各人的兵器。
- 练法：一步一拍，一句一段路。领的人起头，跟的人接尾，谁的声音掉了，前后两个人各拉他一把（★）。头一回下井的孩子在井沿上先学会接尾那半句。带了十一回新人，他唱着，井里那一股甜、雾里一个熟人的背影、墙上一个手印，拉得动别人，拉不动跟着唱的人（★）。到了极境，他领着唱，一整队人一步一拍上楼梯、过射界、穿营房，一个也不岔出去。
- 修行重点：统率、意志、察觉。回来的路最要紧，这一句他带孩子下井以前一定要说。
- 限制：只管跟着唱的人，谁停了嘴，咏就管不到他。管往回走的路，往下走的时候不灵。拉得住人的心思，拉不住人脚底下塌下去（★）。
- 世界反应：约490年起星坠的生存庭教这一门，往后学院的孩子往回走的时候嘴里多半哼它，哼的人多半不知道这是井口人的歌（★）。
- 传承：垂绳谣往下放，收绳谣往上收，朗贝尔把往上收的那半首唱到了往回走的路上，往后星坠生存庭教的是他这一版（★）。只有练法一卷，Epic。它缺一套配着它打的战法，谁把往回走的路上怎么列队、怎么断后编进去，才算补上。
```

```
### 紫雷天锻法 (Art | Epic)

【调用】白鸦的年月里，博鲁打铁、引雷落锤，或有人想学砧家的锻法时用。

【紫雷天锻法】是砧家等雷打铁的手艺，街上的人叫它雷下打铁。纷争纪锻营里，打铁的人等雷落下来才一齐举锤，铁才能打得透。博鲁没有锻营，也没有祭台上分下来的火，就守着寻常的炉子等雨（★）。火候这一卷是成了的，拿它打出过什么叫得出名字的东西，还没有。

- 法门：火候和料。火候是天上的雷，料是寻常的铁。把砧搬到雨里，等蓝火跳起、云里的雷线垂到砧上，雷落锤也落，一锤顶十锤。落早了雷劈人，落晚了铁凉。到了极境，举锤天就暗，晴天也引得下雷，锤落处整块山石裂开（★）。
- 战法：出的东西。打出来的铁敲不出缺口。607年后他只打钉子、门轴和锁（★）。拿这一口雷火打兵器、打甲是什么样，这一辈没有人试过。
- 练法：没有成册的。砧家几户口传，先学等，等得住雨和雷，再学把锤落准。
- 修行重点：锻造、耐力、意志。
- 限制：天上要有云，晴天得到了极境才行。拿它打人，雷不认锤。
- 世界反应：雨夜街上响闷雷，邻居就知道他又打钉子了。
- 传承：从纷争纪锻营传到砧家几户手里，没进过路册，博鲁手里是火候这一卷，Epic（★）。它缺的是出的东西那一卷，谁拿这一口雷火打出一件叫得出名字的东西，才算补上。只给 AI，格罗姆后来从中分出弦锁，847年补完为伏雷刑锤，叙述不提前说（★）。
```
