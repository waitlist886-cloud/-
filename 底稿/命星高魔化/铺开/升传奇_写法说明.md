# 升传奇十三位｜给写手的说明

这一份说明给写“升传奇”那一栏的人看。技艺和旅伴条的别的栏已经照表改完、并回仓库了，你只管把名单上的人写成传奇，和这件事牵到的别处。

## 一、这是什么活

这张卡是中文 AI 跑团卡《奥尔德兰的旅印》，日式西幻，高魔。旅伴是一段年岁里最有天赋的年轻人。用户定了：本就该是传奇的旅伴升成传奇，其中几位一路活到迷宫纪1001年。全表在 `底稿/命星高魔化/全谱/旅伴表.tsv`「升传奇」那一栏，一共十三位，你这一份管哪几位写在派给你的话里。

每一位，表里给了伟业是哪一件、活不活到1001。你要读他那一页的主线、旅伴条和背景条，把这件事写实。

## 二、规矩（卡里定死的，照着写）

**怎么踏进传奇。**
- 要两样：走到凡人的极点（LVL 200，英雄的顶上），有一件世界认了的伟业。两样齐了的那一刻踏进传奇（LVL 201 起）。
- 名字凝住，是世界记住了那件伟业。认的是世界，人间唱没唱开不算数。名号多半是人先叫开的。
- 伟业先成了、人还没走到顶的，名字先凝住，往后肯往上走就一定走得到传奇，要几年到几十年，看他那时离顶上多远。写明那几年他在往上走。
- 英雄的最后一截（LVL 174 到 200）做成那一件的，当夜到传奇。174 以下做成的，名字先凝住，往后再到传奇。
- 位阶的数：启源 1 到 20，共鸣 21 到 40，灵格 41 到 80，极境 81 到 120，英雄 121 到 200，传奇 201 到 300。
- 传奇里分三档，只写在位阶走势、裁定锁里，叙述和人物嘴里不说：撼世（201 到 240，落在一段墙、一道谷口、几万人的潮上），天灾（241 到 280），圣座（281 到 300）。这一批都写撼世，不往上抬。

**长相和寿数。**
- 名字凝住那一刻，容貌和身子停住，往后不再老。踏进传奇就脱了寿数，老不再是死因。
- 所以写明他凝名那一年几岁、往后一直是那个样子。原来条目里写他后来老了、白了头、老死的句子，照这个改。

**什么杀得死传奇。** 传奇只死在这几样手里：
1. 三位以上同档的传奇围杀，或者高一档的杀低一档的。
2. 一百位以上配合惯了的英雄拿命换，死到九成六以上，被围的那一位不肯走。
3. 神性：神、魔神、带着神性的东西，王种和天灾一级的兽照它的档算。
4. 十万以上以极境为主的军团不计伤亡地围，他死战不退。
5. 他自己把命烧进本事里（燃尽），是他自己选的，要写明他为什么不走。
- 寻常的军队、魔物、老和病，杀不死传奇。
- 表里写“不必”活到1001的，他的下场要落在上面某一样上，或者写成走出了记载、往后不给（不知所终）。尽量贴着原来下场里已有的那一幕改，不另起大事。**不许叫他活过这一纪的末尾**：月银纪那一夜（10081年）在世的传奇、纷争纪各张牌的传奇数是定死的，这几位不能多出来。下场落在他那一页写到的年份附近最稳。
- 表里写“活到1001”的，要写他怎么过了后头几纪最凶的那几回（山铜纪的人过迷宫纪850到970年的黑潮，黑潮里传奇死了九成）：他守着一处没有离开，或者那些年在别处。一两句，落在他自己的事上。

**传奇之名。**
- 名字底下是一件事，写谁先叫开的。两到五个字，是名词。可以是 X之Y、X者、带一个动作或时刻的偏正。
- 不用霸主、龙尊、主宰、宗师这一路的字。勇者、圣王、剑圣这种现成身份不用。
- 一页里不出两个收尾一样的。跟同页已有的传奇之名别撞架子。
- 起了名在仓库根上跑 `python -I -X utf8 tools/namegrep.py 名字`，报无才算没撞。

**不上公会名录。** 迷宫纪约420年起公会有传奇名录，底卡写死了数（850年一千零六，970年四十七）。这一批活进迷宫纪的都不上名录，各写一句缘故，落在这个人身上（没让秘仪照过，不进公会的门，守着的地方不归公会管）。

**卡面口径。** 不用破折号、分号、省略号、感叹号。冒号只在行首标签后头，标签八个字以内。引语用“”。不写月相。神用祂。不用中式口语和武侠古风的字。新起的设定句末标（★）。不往小里写，传奇出手要有传奇的分量，写到看得见的结果。也不替玩家把事做完：这些是玩家不插手时的正史。

## 三、每一位交什么

不直接改仓库。在派给你的文件夹里写一份 `改动单_<你这一份>.md`，一处一块，照这个格式（主会话拿脚本套，原文要跟仓库里一字不差、在那个文件里只出现一回）：

```
### 文件：相对仓库根的路径
#### 原文
（一整行或者连着的几行，原样抄）
#### 改成
（改后的）
```

要新添一行、没有原文可换的，原文抄它前头紧挨着的那一行，改成里把那一行照抄再接新行。

每一位要动的地方：

1. **旅伴条的位阶走势那一行**（紧跟在底座后头，没有就添）：接着写到传奇。例：`位阶走势：开局灵格（LVL 45）。890年花信月上旬三日长廊贯通那一夜到极境（LVL 84）。约905年到英雄。约921年补全七坑岩息那一件名字凝住，那一年看着三十出头，往后一直是这个样子。约939年到传奇（LVL 203，撼世）。`
2. **正史里的下场**：末尾接上凝名那一件事怎么做成的（三五句，写画面，有名字有数），传奇之名和谁先叫开的，到传奇是哪一年，往后在哪里。原来写的老、死，照第二节改。
3. **这个人的裁定锁**：添一条。传奇之名哪一年以前没有人这样叫，底座日期在那以前的回合里叙述和 NPC 不用。玩家同行的局里这件事怎么算（玩家在场插手照玩家做的事走，他做成了照样凝名）。
4. **补全技艺当伟业的**（表里写“补全某一门”）：那一门的星条要添一版。在同一个文件里那一门的星条后头新写一条 Legend 的星条，名字用底卡或者全谱里给的 Legend 名，没有的照“原名去掉残缺的那一截”起，法门、战法、练法三行写齐，写到英雄以上，【调用】写明哪一年以后用。原来 Epic 那一条的传承行末尾接一句哪一年以后是哪一版。旅伴条能力行里接上 `Art【新名】(Legend，一句)`。星条的格式看同文件里别的 Legend（或者 `底稿/命星高魔化/铺开/写法说明.md` 第四节）。
5. **这一页的传奇表**（页尾，不进卡，标题多半是“这一段的传奇”）：添一行或者一句，照表里别的行的写法。表里“在世几位”的数：这一批不进正史点名的数，在表后头添一句“另有某某，凝名于哪一年，不计在上面的数里”。
6. **活到1001的**，另外交两样：
   - 后头各页“活过了某纪的那几位”“老传奇”那几条里各添一行（看 `迷宫纪前传/parts1/p7_people_mine.md` 开头那一条的样子，一位一行：传奇之名·名字｜族，哪一年在哪里凝名，凝名那一年几岁、这一年几岁、看着照旧几岁，这一页的年月里他在哪里、碰得上的一件小事）。那一条的【调用】里列的名号、条目设置的触发正则里也要添上他的传奇之名和名字，照原来的写法添。一位在他凝名以后的每一页都要有一行。
   - 1001年那一局的一行：写进 `改动单` 末尾单列的一节「1001年旧人」，一位一段，百来字：他如今在哪里，什么样子，玩家怎么碰得上，他不上名录的缘故。主会话拿去拼成一条。
7. **新起的名字、年份、事**：改动单末尾列一张清单，都标★。

## 四、怎么查

- 这个人的旅伴条：在他那一页的文件里 Grep `## 旅途同行：名字`。主线里他的拍、收束、默认收束都读一遍。
- 同页的传奇之名：Grep `传奇之名` 和页尾的传奇表。
- 这一纪的规矩：各纪 `规则｜命路与超凡` 的凝名一条（月银纪 `moon/batch1/`、纷争纪 `纷争纪/补卷/第一项_规则补丁.md`、山铜纪和前传 `补卷/第一项_规则.md`）。
- 文件很大，别整份读，Grep 找行号再 Read 那一段。
- 纷争纪、山铜纪、前传的页是分段稿拼的，改分段稿（`parts*/`），不改拼好的整页。

## 五、不许做的

- 仓库里一个字不许改，不碰 git，不另派子任务。只在派给你的文件夹里写。
- 不动歌、诗、牌文、碑文、委托单的原文。不动条目设置里的年份黑名单（要改的在清单里说）。
- 不给他添表里没有的大事，不把别人的伟业挪给他，不改已有传奇的数和下场。
