# 前3_四 备注（迷宫纪前传第四页深井的年月）

## 技艺
- 数：Epic 18、Rare 18、撤 7（Legend 0）。归H的有八门：七门撤（廷特代笔、委托厅识笔术、心跳校针术、施莱伯快笔、铁瀑钟号、台地笔录术、点人）加丘陵封契手法立Rare。
- 无帜流页上是Legend，我判Epic：料里写明多数人学到的只是护车佣兵剑术那一截，三样不齐；吉迪恩那一下做到头的是战法。归S:渊垒是我的连接（传承表只写「长垒上的手艺，护车那一路」）。
- 魔族这段没有哪一门是纯W系的整本：撞角归W1，钟楼念名调归W4，镜城穿梦步和魇镜梦诊手法归W5，量云飞图术归W6，闸口数浪律归W9，都是一卷或一手，没有一门够三样。
- 本页一半以上的技艺是各人家传的手艺加一个添的小手法，起名字的人就是持有人本人。判Rare的多，是因为只有一手、没有法门。
- 旅伴料里「现阶 Epic」的技艺有四十二条，我降到Rare 18条、撤7条；Epic保留的都有传承往后长成Legend（凯德叠图法、斯温藏针法、倒搅、帕斯洛弹线法、留铃、镜城穿梦步、台地押送短剑、撞角）或是一卷成了体系（雾结、喊阵、撑顶）。
- 几处往后补完到Legend的，我只填了「并进」写往后的名字，没动凝名在这一段的传奇条。
- 提的改法（★）：心跳校针术、点人各一处可另立Rare，已写在缺什么那栏。
- 门表想改的地方：C类的二门（C2炼药与解构）没有收「补遗物的裂口」，斯温藏针法我硬归C2；建议门表在C2说明里补一句「补残响、拆残响归这里」。X7里「探路」和「绳上听动静」也建议写明。

## 旅伴
- 留 36，降 7（翁贝托、胡萨姆、劳珂、加斯帕、梅芙、茹比、丝缇）。每条主线至少留一位，都满足。
- 年纪要调的 2 位，都是「牵着旧事」：胡萨姆牵着约480年生在焙石家、跟父亲烤面包一百多年、632年按契约到阿卡迪亚；梅芙牵着约650年到阿卡迪亚、677年于尔根的死、709到715年送一千一百四十六块铭牌。两位都倾向降，没有「改成N岁」的。
- 位阶起步普遍偏高：本页十八位开局已是英雄，八位是极境，灵格以下的只有十位上下。方向稿要的「启源或灵格起步」在这一页基本做不到，要么整页起步压一档（属位阶重排，不在这一回轻改里），要么把这些人改成相遇。我只在说明里标了「英雄起步偏高」。
- 凝名在本段的十一位（阿蕾缇娅、奥尔文、麦格尼、米蕾卡、维多利亚、阿卡夏、派派、诺维安、蕾雅、亚历山大、琥珀）都留，升传奇栏写「已在本段凝名」，不算新升。诺维安、蕾雅是名字凝住、约810/830年到传奇，另写了。
- 新升传奇人选只提两位：坎黛丝（第五十六层撑墙留下一条胳膊，炎角长生）、肯特（第七回讨伐，龙裔长寿）。两位都不上公会名录，到传奇的年份料里没有，要用户定。
- 下场添一句三位：伯娜（想过有限的人生）、菲莱雅（时代没给路）、卓根（性子和经历）。
- 拿不准：①肯特外表三十五、龙裔约140岁，我留；若按「队长是大人」就降。②罗瑟琳（教过亚历山大认浪）同样可降。③维多利亚44岁在文职线，但凝名在本段，我留。
- 料里未写外表的：麦格尼117岁矮人、劳珂约150岁矮人，我按看上去中年处理，没按老人降；劳珂降是因为看钟人角色。
