# 铜3前1 备注（山铜纪第六页，前传第一页）

## 技艺
- 数：新档 Legend 3（黑耀王律、灰拳战法、神铁锻王法），Epic 19，Rare 22，撤 5（唤羊调、唱价、搭套、换肩调、桩铃，都归 H）。
- 样稿两门照填：绞盘谣并进七坑岩息（Epic，X2，缺后半卷法门）；唤羊调撤，换成羊梁投石术（Rare，S:行猎），这条没另立一行。
- 新立一门 N:射界火耕（射界耕法、燕巢回烧法、直垄）：烧麦那一页三门同源，都是墙下射界里种麦、先打火道、烧荒到白地为止，归不进 E1 也不是行当。只提一门，门表若不想添，可把射界耕法、燕巢回烧法并 E1 的白垒，直垄撤。
- 连接标★的几处：灰拳归 W1（半兽人在炎角氏族焦门氏里，拿挨的那一下攒进拳里对烬冠锻躯法）；推殿架归 W7（半兽人石辙谷，推殿几十人肩顶一杠对连岳镇形法，但不是轰狱）；骸钟点营调归 W4（白骸点名对续灯骨律）；蜡板辨誓术、赤脊氏溯烬术归 W0（契约法庭认誓查火，不是魔族自己的法门）。
- 灰拳战法 Legend 拿不准：练法一栏只有格拉德一人修成，料里"跟他学的人学这一版"是传承行的话，没有谁学过。若按"没教过谁就落 Epic"，应落回 Epic 写明灰拳一卷做到头。
- 沉雾调的法门写冥想是我推的，料里没写。垂绳谣、收绳谣、雾脚、沉雾调、搭套同在墙下村掏井这一路，我分别放了 H、H、S:无形、S:无形；若想合成"井口手艺"一门要门表另立。
- 前传页护车佣兵剑术是后来无帜流（命名对照里）的前一卷，这里按 Epic 守一步判，没并进。
- 帕维尔斜凿术判 Epic 是因为字口夜里摸得出，有超凡效果；碑匠街拓印法并入 C6 但落 Rare。

## 旅伴
- 山铜纪第六页：留 21，降 8；前传第一页：留 22，降 2（奎妮、扎比内；莫莉拿不准，留）。两页合计 53 条，留 43，降 10。
- 年纪要调的九位，全部是"牵着旧事"，没有一位能直接改成 N 岁：
  - 伊芮丝：牵着661年灰雨那一夜（八岁出南门）。
  - 曼苏尔：牵着836年烧站（十七岁）与862年认罪。
  - 利诺斯：牵着836年左翼烧穿，十三岁起守灯路。
  - 哈迪雅：牵着846年父亲死、865年头一个坐上法官席。
  - 托芙：牵着872年母亲死在井里、919年听出石头在烧（934年那一夜已升极境）。
  - 弗罗德：牵着891年放锤出山门、守炮四十三年。
  - 塔隆：牵着927年下山、931年起做边官所边兵。
  - 杜尔夫：牵着934年王炉吃火那几夜。
  - 嘉莉：牵着873年旧事（背景条）。
  - 倾向都写了抬到极境，也可以改成降（降了它们所在的线至少还留有别人）。
- 弗罗德两栏对不上：位阶走势写灵格57到66，年纪调整写抬到极境，二选一。
- 升传奇人选：蕾娃（补全七坑岩息）、苏海拉（927年拆台成辙口城门）、托芙（往后守封口）、朵薇（约44年点营三天三夜，白骸活到1001）。格拉德、布洛姆加、吉迪恩凝名就在这两页里，没算在升传奇里。
- 莫莉实际十七岁、种族看着十三四岁，我留；蓓拉四十岁、奎妮五十岁、绍克四十岁、碧吉特三十八岁，按"做事的人还是长辈"各判一回，碧吉特是样表的降，奎妮是我加的降。
- 前后不一：卡雅100年一百二十五岁看着六十上下、阿托100年一百零七岁看着五十出头，提夫林的老法和阿托38年"看着二十五六"对不上，没改。茹丝、碧吉特、戈茨按样表。
- 前传页的位阶走势只在料里有数的写了（吉迪恩、绍克），别人料里没有就空着。
