# 原画核对：纷争纪书前半（s01 到 s10）

范围：`底稿/门面/小样_纷争纪书/assets/cg/` 下 s01_ 到 s10_ 开头的原画八十一幅（节点、死的那一刻、传奇之陨、时代图），画里的人对 `scenes/sNN.json`、`scenes/legends/gA|gB|gI|gJ.json`、`scenes/era_scenes.json` 和现行立绘 `底稿/状态栏/comfy/out/立绘_纷争纪/`（另有 立绘_v3 的 hob、calantia）。魔族的角另查了这一半里有角的十个键。

先说用户举的那一幅：用户附的 17.png（白发、红角、拄杖挂铃的夜魔女人加举盾的矮人）是 **s07_f_zvia**，也就是传奇之陨「杖头铃」，不是 s07_n3。s07_n3（三幕荫外谣）里茨维娅是黑发，那一幅要改的是哈尔加。两幅都列在下面。

原画都是 11-12 到 11-15 出的，早于 11-13 年纪那一轮（年纪前_1113）和 11-22 长相那一轮（长相前_1122）；11-15 那批传奇之陨（gI、gJ）出图时这十个人还没有立绘，scene 里没有 who，是照字画的。
