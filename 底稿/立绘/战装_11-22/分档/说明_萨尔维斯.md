# 战装分档改写｜萨尔维斯（11-22）

你给一张日式西幻 JRPG 跑团卡《奥尔德兰的旅印》改写角色立绘第三格（战斗那一身）的英文描述。用户看了山铜纪新人的战斗格说“比起时代的军事和科技太落后”，于是山铜纪先写了各段的「战装补层」、定了「战装分档」，逐人改写了战斗句、重画了战斗格（下面有六张用户认过的改前改后）。11-22 用户说先照山铜纪那样针对战装查一下，战斗装得符合纪元、年代和角色本身的设定，山铜纪以外已经画过的人都重画。这一份是萨尔维斯。

# 战装分档（用户 11-21 定的，各纪通用）

**战装分档（11-21 用户定的，★）。** 用户看了战装补层的样张回“基本可以”，又说要照位阶和家境分开，原话：“比如同为灵格，家境更加好的装备也会更好，这一层面的区别会随着角色的实力提升被缩小，强者本身就意味着具备创造财富的能力，拥有好的装备本就是合理的。同时根据角色也要注意区分，有的角色可能会倾向使用朴素的装备甚至依靠不装备，比如索恩薇娅就一直不喜欢过于华丽的装备。”照这个分：
- 位阶定底子。启源、共鸣是干活的衣服外头罩一两件捡来的附魔件；灵格是一套改合身的旧附魔甲，至少一件像样的；极境是一身成套的附魔战装，有一件招牌的东西；英雄是量身打的、设计过的战装，兵器够得上传家；传奇是这一纪顶上的那一身。
- 家境往上加。位阶低的时候家境差得最开：同是灵格，上城、世家、富商家的孩子穿家里买的、家传的整套，刻得深、晶石足，苇棚区、段城兵户、佃农出来的穿拆来拼的。到了极境差距小了一截，英雄往上几乎不看家境，强者自己挣得来、抢得来、打得出好东西。
- 偏好再改。有人不爱靠装备：索恩薇娅一直不喜欢华丽的装备，她的战装照她的位阶用好东西，可样子朴素、实用、不加装饰，一件不多。修士、法师、行者、不打仗的人照各自的路子，可以是法袍、护符、一件披风，甚至什么都不披，这是他的选择，写明为什么。同一个人跨几页，战装跟着位阶往上走，偏好不变。

# 怎么改

- 先从原页那一条和长相里判三样：位阶（原页底座或位阶那一行；没写的照身份和本事估，写明是估的），家境（贫、中、富、世家或上城，看出身和身份），偏好（照常、朴素、不靠装备、法袍、不打仗……，有来由才判不照常）。再定装备档 1 到 5：1 干活的衣服外头一两件这一段有的附魔件或兽材，2 一套改合身的旧甲带一两样会亮的东西，3 成套的这一段的战装加一件招牌，4 量身打造、设计过的，5 这一纪顶上的那一身。位阶定底子，家境低位阶时加减一到两档，极境以上至多一档，英雄往上不看家境；偏好朴素的照档用好料子，样子去装饰，偏好不靠装备的就别硬穿甲。魔族照它那一系在这一段的样子。

- 改写那一句：英文，跟样张一样的详略（七八十到一百二十个词），开头保留原句的场面短语（Holding the crossing: 这一类），兵器、手里拿的东西、姿势、法术光效、跟故事有关的物件一样不丢、不换，只把衣甲升到那一档，写清每一件是什么、哪里发光、什么颜色的符文或光。资料的配色照旧。不写脸、头发、眼睛、身材，不写场景、家具和地面（设定图要抠透明底），火和光贴在身上或兵器上，别往地上铺。不写东方式样（交领、宽袖、盘扣）。不写 crescent、moon。
