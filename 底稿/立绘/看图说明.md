# 立绘铺开：看图说明（11-05）

给逐张查图的人看的。一页出完，对着这一页的资料（`底稿/状态栏/comfy/cast/<纪>/<页>.json`）逐位看图，报出要重出的和怎么改资料。

## 看哪几张

每位一个文件夹 `底稿/状态栏/comfy/out/立绘_<纪>/<en>/`：
- `sheet.png` 四套衣服一张（从左到右常服、私服、战斗、正装），
- `art.png` 艺术照，
- `faces.png` 九格表情。

**透明图一定先铺灰底再看。** 看图工具不管透明通道，会把透明处原本的颜色也画出来，看着像有一层糊的底色或者画风跑偏（11-05 因此误判过一回）。用：

```
python -I -X utf8 底稿/状态栏/comfy/grey.py <输出.jpg> <图1> [图2 …]
```

它把几张图铺在灰底上竖着叠成一张 jpg，再看那张 jpg。输出放在会话的临时目录，不放仓库。

## 查什么

对着这一位资料里的 `who`、`face`、`casual`、`private`、`battle`、`formal`、`art` 看：
1. 发色、瞳色、肤色、种族记号（耳、角、尾、鳞、翼、獠牙、几只手）跟资料一致，四格之间也一致。
2. 招牌东西都在（资料里写的随身东西、兵器），没多画第二件（比如两只陶罐），兵器、杖没有倒着拿。
3. 身上有缺的（断翼、盲眼、义肢、疤）画出来了，左右没画反。
4. 年纪看着对：上了年纪的有皱纹白发，不老的传奇是凝名那时的样子，年少的看着是少年少女。
5. 年少的（`minor`）四格都穿得严实，没有往性感上画，艺术照只到头肩。成年人也别露得过分。
6. 不该有的：月牙、弯月的纹样，中式和东方的衣服，现实里现代的衣服，文字和水印。
7. 艺术照：脸跟立绘是同一个人，五官端正（两眼一样大、齐平，鼻子嘴巴居中，没有歪），发色没被光染成别的颜色，影子没压在眼睛上。五官歪的用 `立绘试验/art_face_fix.py` 出两张候选挑一张。
8. 表情九格：是同一张脸，跟立绘一致。

## 前几页反复出的毛病（先找这几样）

皮肤被画黑（资料写白净的）；一边才有的东西左右画反；招牌东西画了两份；东方式样（交领、宽垂袖、盘扣、中国结穗子、头顶发髻横插簪、像日本刀的刀）；月牙弯月；艺术照发色被光染了；身份参考图上的首饰眼镜护目镜被带过来；资料写唇间冒烟画成叼烟；纹章被读歪（金鸢画成菱形、星）；表情九格底没抠干净。

## 报什么

一位一行：`en 名字：没问题`，或者 `en 名字：问题……；重出 sheet / art / faces；资料改法：在 who（或 casual、art_extra……）里加一句英文 "……"`。
- 设定图有问题就重出 sheet，艺术照和表情是照设定图出的，也跟着重出。
- 只有艺术照不对，用 `art_extra` 补一句再重出 art。
- 拿不准的写出来，不要硬判。
