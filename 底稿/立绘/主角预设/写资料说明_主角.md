# 主角预设立绘：写资料说明（11-10）

用户 11-10 定了走甲：建档里挑的出生地（族属）加体格是一个人，一个人四套衣着（常服、私服、战斗、正装）、艺术照、九格表情，另外二十三条命路一条一身战斗装。格子见本目录 计划.md 第二节。这一份是给写资料的子任务看的。

## 一、写什么

资料是出图用的英文提示词片段，一个族一个文件：`底稿/状态栏/comfy/cast/主角/<族>.json`，一个 JSON 数组，一个人一条；另交一份同名 `.md` 备注（写了谁、自己起的设定标★、拿不准的）。人类晨曦人那六位已经有了（`人类_晨曦_样张.json`），写法照它，别改它。

格式样子先读 `底稿/状态栏/comfy/cast/主角/人类_晨曦_样张.json` 整份，再读 `底稿/立绘/写资料说明.md` 的「一条的栏」「守的口径」两节（那是各纪角色的写法，口径照用；下面写了不一样的地方以这一份为准）。

### 两种条目

**本人**（每一种长相加一种体格一条）：

```json
{
 "name": "高等精灵·女·纤细",
 "en": "pc_e_gd_f2",
 "race": "精灵", "zushu": "高等精灵", "body": "纤细",
 "src": "主角预设（11-10）：精灵·高等精灵，女，纤细",
 "sex": "f", "tier": "woman",
 "who": "…", "build": "…", "face": "…（可选）",
 "palette": "…",
 "casual": "…", "private": "…", "battle": "…", "formal": "…",
 "art": "…",
 "battle_note": "…"
}
```

- `battle` 写**还没选命路、刚出发的冒险者**的那一身（公会配的入门装备，一把寻常的兵器），二十三条命路的战斗装另有一张总表，脚本照总表拼，这里不写。
- `battle_note`：二十三身战斗装套到这个人身上要注意的，一两句英文，比如兽耳从帽子里露出来、尾巴从外套后摆的开口伸出来、角不被头盔盖住、翼收在背后、鳞色。没有要注意的写空字符串。
- `art`：艺术照的构图，一两句，穿常服。

**换族属**（只给长相不按族属分开的那几族：人类、矮人、半身人、半兽人、真龙幼体、提夫林）：同一个人按族属换常服、私服、正装，脸、身子、头发、战斗装照本人。

```json
{
 "name": "月镜人·女·纤细",
 "en": "pc_h_yj_f3",
 "race": "人类", "zushu": "月镜人", "body": "纤细",
 "src": "主角预设（11-10）：人类·月镜人，女，纤细（换族属，人照 pc_h_cx_f3）",
 "same_person": "pc_h_cx_f3",
 "cells": ["casual", "private", "formal"],
 "palette": "…",
 "casual": "…", "private": "…", "formal": "…"
}
```

### tier

人类、魔族男健壮写 `burly`，别的男人 `man`，女人 `woman`。半兽人两档男人、龙裔健壮男写 `burly`；半兽人、兽耳族的女人照旧 `woman`，壮在 `build` 里写。矮人、半身人写 `small`，半身人的 `who` 里一定有 halfling 这个词（模板认它走幼态脸、不写身段），女矮人写 `face`，注明是成年女人的脸（照写资料说明.md 那一句）。真龙幼体化形的看着十九、二十岁，一看就是刚成年的人，不是孩子：女的加 `"ya": true`、`tier` 写 `woman`；男的 `tier` 写 `man`，`who` 写 about twenty, a young adult。

## 二、照的设定

- 各族各族属的样子、文化、住哪：底卡 `src/rili_v7.json` 的世界书 #477 到 #494（种族与文化的界线、各族低耗总览、本版可建档种族、寿命、半精灵、半身人、矮人、龙裔），#31 到 #43（各族详史），#214 到 #221（各族的流派）。底卡洗稿层（`底卡洗稿/*.md`，「## #号 标题」那一节）洗过的条目以洗稿层为准。建档器的出生地在 `src/intro_v7.html`（搜族属名，`"d":` 是那一句介绍）。
- 衣着照迷宫纪1001年：`底稿/立绘/各时代风尚_新三纪.md` 第一节，加上 `底稿/状态栏/comfy/gpt_sheet.py` 的 GUARD_1001 那一句（现今的魔导奇幻，衣服和战斗装照现在二次元游戏的设计，带扣带、甲片、刻纹和晶核，利落好看，不写中世纪，也不写现实里的街头服装）。族属的不同主要落在常服、私服、正装上：月镜人、风铃人、蔷薇人、垒民这些各有各的颜色和剪裁，照设定起。
- 容貌照 CLAUDE.md 写作口径「容貌」一节：日式二次元、JRPG 立绘；一个人一种发色、一种瞳色、一样记号；人族、精灵、半身人不默认晒黑；发色瞳色别默认黑褐灰。同一族的几个人之间发色、瞳色、记号错开，跟晨曦人那六位也错开。各族各系身上的样子照底卡：尖耳，鳞和竖瞳，角，兽耳和尾巴（兽耳族只有兽耳，没有人耳），矮人的胡子和辫子，轰狱的皮色是深青铜，提夫林皮肤上带纹。

## 三、守的口径

- 都是成年人，画成二十二岁上下（真龙幼体十九、二十岁），一眼看得出是成年人。
- 不往性感上画。丰腴、均匀、纤细这几档照晨曦人那三位女性的 `build` 写成身形的分量和轮廓，不写胸、腰、胯、腿的字（cast_lint 会报 bust、hips、curv、thighs 这一类），衣服穿严实，私服也是。男人健壮那一档照晨曦人健壮那一位写。
- 四套衣服只写衣服、手里的东西和站姿，不写场景和家具，不坐不躺不跪；一样东西只写一处；一边才有的东西写明左右并加 `(on the viewer's left/right when they face us)`。
- 不写月牙、弯月（crescent、moon 都不写，连否定也不写）；不写东方的衣服和兵器的词（连否定也不写）。
- 纹章写清是什么东西（金鸢写 a gold kite, the bird of prey with spread wings）。
- 写完跑 `python -I -X utf8 底稿/状态栏/comfy/cast_lint.py 底稿/状态栏/comfy/cast/主角/<族>.json`，零问题再交。

`cast/主角/<族>.json` 和同名 `.md` 备注。回报里写：几条本人、几条换族属，哪几条自己起的设定，拿不准的。
