# 纷争纪对手立绘：写出图资料的派活说明（11-22）

11-21 纷争纪剧情铺开新起了 37 位主线对手（人物条，多数是魔族的有名者、血誓祭司、墙这一边的贵族和守将），门面上都没有图。这一轮给他们写出图资料，出图交 `gpt_sheet.py`。

## 先读

1. `底稿/立绘/写资料说明.md` 整份照守（栏的意思、tier、容貌和衣服的口径、防着的那几条）。
2. `底稿/状态栏/comfy/cast/cast_E.json` 五位，当写法的样子；`底稿/状态栏/comfy/cast/纷争纪/z*.json` 看纷争纪已画的人怎么写（魔族的皮色、角、翼怎么落字照这里已有的魔族条和页上的种族条）。
3. `底稿/立绘/各时代风尚_新三纪.md` 纷争纪那一段（墙后、段城、浮塔、魔导、炮的年代各有各的样子），`底稿/立绘/跨纪人物与穿衣脾气.md`。
4. 魔族各系的长相（炎角、白骸、有翼魔族、梦魇、影魔、深潮、长生系、血誓派）：在仓库里 grep 纷争纪补卷（`纷争纪/补卷/`）和底卡 `src/rili_v7.json` 里那一系的种族条。照设定写，别把魔族画成换了肤色的人族；有名者够得上传奇、撼世的写出压迫感。
5. 你这一份的材料：`底稿/立绘/铺开_11-22/材料/<页号>.md`（整条抄的页上条目，开头注释是名字和出处行号），名单在同目录 `名单.tsv`。

## 写什么

- 文件：`底稿/状态栏/comfy/cast/纷争纪/<页号>r.json`（z1r、z2r……，不碰已有的 z1.json 这些），另附同名 `.md` 备注。
- `en` 写 `<页号>r_<短罗马字>`，整纪不许重（先 grep 已有的 cast/纷争纪/*.json）。
- 页上写了长相、衣着的照写，一样不丢；页上没写的照种族、身份、这一纪的风尚起，起的写进备注（★）。
- 战斗装照位阶和身份：传奇、撼世的有名者写出 JRPG 头目的气势，`imposing: true`；不打仗的（判词司祭、掌玺大臣、审判官这一类）写 `battle_pose`。
- 母兽、整群、没有人形的（比如驮幼兽的母兽要是兽形）照说明判画不画，不画的写进备注说缘故；能画成兽人或半兽形的照页上来。
- 基利安（第一页苇岸的判词司祭）跟第五页旅伴基利安不是一个人，别写 same_as，别借那一位的长相。
- 伊拉瑟在第二页有人物条也有凡世至强条，写一条就行，照凡世至强的样子，`legend` 看底座。
- 不写月相（crescent、moon 连否定也不写）。

## 自查和交

`python -I -X utf8 底稿/状态栏/comfy/cast_lint.py 底稿/状态栏/comfy/cast/纷争纪/<页号>r.json` 零问题再交（腰侧、鞣皮这类以前的误报照判）。做完回一句话：写了几位、没画几位和缘故、备注里有没有要主会话定的。不要把 JSON 贴回来。别碰别的文件，别提交。
