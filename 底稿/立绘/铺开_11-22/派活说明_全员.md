# 四本书剩下的人：写出图资料的派活说明（11-22）

用户 11-22 看了纷争纪那本书传奇一栏空了一片，说“四本书都排”，又说先照山铜纪那样针对战装查一下：战斗装得符合纪元、年代和角色本身的设定。这一轮给四本书里还没有立绘的人写出图资料（整群的、不是人的不画），出图交 `gpt_sheet.py`。

## 先读

1. `底稿/立绘/写资料说明.md` 整份照守（栏的意思、tier、未成年的规矩、容貌和衣服的口径、防着的那几条）。
2. `底稿/状态栏/comfy/cast/cast_E.json` 五位当写法的样子；你那一纪 `底稿/状态栏/comfy/cast/<纪>/` 下已有的几份看这一纪怎么落字。
3. 你那一纪的风尚：`底稿/立绘/各时代风尚_旧三纪.md`（纷争纪、萨尔维斯、诸国期、祭火与万兽）或 `各时代风尚_新三纪.md`（迷宫纪前传第二节、山铜纪第三节），各段末尾的「战装补层」是战斗那一身的尺子。
4. **战斗那一句照战装分档写**：读 `底稿/立绘/战装_11-22/分档/说明_<纪>.md`（山铜纪读 `各时代风尚_新三纪.md` 第三节「战装分档」和各段「战装补层」），先判位阶、家境、偏好、档 1 到 5，再照那一档写 battle。说明里「怎么改」那几条（年代要对、不写场景地面、安全审核的字眼、不打仗的人写 battle_pose）照守。注意 battle_pose 只换掉设定图第三格那一句通用姿势，衣甲照旧从 battle 那一句来，所以 battle 都要照分档写好。判的结果写进 JSON 那一条的 `gear` 栏：`"gear": "灵格（估）｜贫｜照常｜2档｜一句中文为什么"`。
5. 你这一份的材料：`底稿/立绘/铺开_11-22/全员材料/<纪>_<页号>.md`（页上整条抄的，开头注释是名字、类别、出处行号、怎么找到的），名单在同目录 `名单.tsv`。

## 写什么

- 文件：`底稿/状态栏/comfy/cast/<纪>/<页号>x.json`（z4x、q3x、ge7x、zg2x、sa6x、s5x……，不碰已有的文件），另附同名 `.md` 备注。
- `en` 写 `<页号>x_<短罗马字>`，整纪不许重（先 grep 那一纪已有的 cast/*.json）。
- `src` 写材料注释里的出处。传奇（类别写着传奇的）照凡世至强那一条写，`legend` 看底座；够得上撼世、天灾的写 `imposing: true`，战斗句写出这一纪顶上那一档的气势。
- 页上写了长相、衣着的照写，一样不丢；页上没写的照种族、身份、这一纪的风尚起，起的写进备注（★）。
- 材料里那一条只是顺带提到他、没写长相的，照他的身份、种族和这一纪起，备注里写明；整群的、不是一个人的（食堂、糖罐、那几个人）不画，备注里写缘故。
- 同一个人在别的纪、别的页已有立绘的（grep 名字），年纪、衣服明显不同才另起一版，写 `same_as`；差不多的不画，备注里写明。
- 不写月相（crescent、moon 连否定也不写）。

## 自查和交

`python -I -X utf8 底稿/状态栏/comfy/cast_lint.py 底稿/状态栏/comfy/cast/<纪>/<页号>x.json` 零问题再交。做完回一句话：写了几位、没画几位和缘故、备注里有没有要主会话定的。不要把 JSON 贴回来。别碰别的文件，别提交。
