# 神明的人间形态与神座：写资料说明（11-07，给子任务）

用户 11-07 定的三档：
1. 神明显像（144 位）是神祇的全力姿态，走史诗战那一路（Midjourney 那种干净的电影感画法），提示词在 底稿/状态栏/comfy/epic/prompts/gods_*.json，不归这一份。
2. 神明行走大地：月银纪、纷争纪里祂们走在人世中的样子，走角色立绘同等规格（画法照立绘那一套），只出常服、私服、正装三套加艺术照和九格表情，不出战斗服。这一档是所有正神（七支柱七位加正神六十五位）加薇瑟兰（七十二尊魔神里落在善上的只有祂）。
3. 魔神只出正装和艺术照：魔族看到祂们在神座上的样子。用户说魔神基本不行走于魔族，魔族在祂们眼里跟口粮没有分别。

这一份管第二、三档的资料。底子照 底稿/立绘/写资料说明.md（栏的意思、容貌、西式剪裁、不写月相、一边才有的东西写明左右、四套衣服只写衣服手里的东西和站姿不写场景家具），下面只写神这边不一样的。

## 写什么

- 第二档写 底稿/状态栏/comfy/cast/神明/行走_<份>.json，第三档写 cast/神明/神座.json，一个 JSON 数组，一位一条（第二档跟风尚的一位两条，见下）。只写自己那一份的文件，别的一个字不动，不提交 git。
- 材料：底稿/立绘/神名清单.md（正神的“月银纪的样子”里有本相和“下到人间多半扮成……”，“纷争纪的样子”是墙上的人见到祂的样子；七支柱另有 1001 年的显相；魔神有高座和本体的画法★），再往下翻 月银纪补卷/神谱_*、纷争纪/补卷/补卷_60 到 _67。立绘那一套的画法看 底稿/状态栏/comfy/cast/纷争纪/z1.json 里随便几条，照它的口气和长短。
- 风尚：底稿/立绘/各时代风尚_旧三纪.md（月银纪那几段）、各时代风尚_新三纪.md（纷争纪那几段），穿衣脾气照 底稿/立绘/跨纪人物与穿衣脾气.md 的路子。

## 第二档：行走人世（正神七十二位加薇瑟兰）

- 栏照 写资料说明.md，另加：
  - `"cells": ["casual", "private", "formal"]`：只出这三套，不写 `battle`、`battle_pose`。
  - `"legend": true`：神不老。
  - `"era"`、`"fashion"`：用户 11-07 说“正神的人间形态装束会根据祂们的性格，不变或跟随风尚改变”。按这位神的性格定 `fashion`：`"守旧"` 或 `"跟风尚"`，在 JSON 外的备注里一句话写缘故。守旧的写一条，`era` 写 `"通"`，三套衣服是祂一直那样穿的、西式、不落某一个时代；跟风尚的写两条，一条 `era: "月银纪"`、一条 `era: "纷争纪"`，各照那一纪祂在人间走动最多的那一段的风尚（死得早的正神纷争纪那一条照祂死前那一段）。
  - 跟风尚的第二条（纷争纪那条）写 `"identity": "立绘_神明/<月银纪那条的 en>/head.png"`，脸照第一条，同一位神两纪认得出。
- `en`：守旧的 `gw_<柱>_<两位数>`，跟风尚的两条 `gw_<柱>_<两位数>_m`（月银纪）、`_z`（纷争纪）。柱的罗马字：离弦 lixian、负山 fushan、翻页 fanye、返青 fanqing、立边 libian、静光 jingguang、不退 butui；两位数照 epic/in/gods_zheng.json 里那位的键的末两位（七支柱用 `gwp_<柱>`，比如 gwp_lixian），薇瑟兰写 `gw_veselan`。
- `name`：神号加本名（照神名清单）。`src`：神名清单.md 的行号。
- `who`：祂走在人世时的样子，人那么大，英文，六十到一百四十个词：照“下到人间多半扮成……”那一句（是谁的扮相、多大年纪的样子、身高身架），再加跟祂的显像一眼认得出的东西（发色、眼睛、一样记号）。扮成老人、孩子以外的成年人的照写；扮相是孩子的不写（这一档一律成年人，原文写十几岁、孩子模样的，写成成年人的扮相）。不写神光、光环、巨大，这一档是祂混在人里头的样子；只在 `formal` 那一套才露出一点神的样子。
- 三套衣服：
  - `casual` 常服：祂在人间最常用的那身扮相，照“下到人间多半扮成……”，衣服照风尚（守旧的照祂一直穿的）。
  - `private` 私服：没人看着的时候、歇下来的样子（客星城上、自己的坛后头、一个人赶路歇脚），更松的一身。
  - `formal` 正装：以神的身份当众现身的样子（坛上受祭、纷争纪墙上的人见到祂），还是人那么大，衣服是祂的礼装：一尘不染、带一点光、祂那一样的纹印，西式；这一套可以有一圈淡淡的光环。
  - 三套都只写衣服、手里的东西和站姿，不写场景和家具，不写坐着跪着。神器照原文（风之弓、大地之锤、镰刀……），常服、私服里收着或者不带，正装里拿着。
- `art`：艺术照一两句，脸大、光从哪边来、前景虚化的东西跟祂管的事有关（麦穗、羽毛、浪花、火星……）。
- 七支柱：长相和神器照 1001 年的显相；艾赫卡托尔、朱亚、库米罗妮、欧巴德斯另照 底稿/状态栏/comfy/fix_gods.py 那四段英文（用户认过）；人间的扮相照神名清单的月银纪那一句（璐璐薇翻过来穿的灰羽衣、欧巴德斯极高大的男人……）。
- 薇瑟兰：在人间就是那个不说名字的女人，三十来岁的样子，洗旧的没有番号的军大衣，补过的靴子，空着手；照神名清单和她在山铜纪四方左扇里的样子。

## 第三档：神座（魔神七十一尊，薇瑟兰除外）

- 一尊一条，栏：
  - `name`、`en`（`gt_<柱>_<两位数>`，两位数照 epic/in/gods_mo.json 那一尊的键）、`src`。
  - `"cells": ["formal"]`、`"no_faces": true`：只出正装一格和艺术照，不出表情。
  - `"nonhuman"`：这一尊在神座上不是人形（兽、空羽衣、一团东西、骑兽合一……）写 `true`；是人形的写 `false`，再写 `sex`、`tier`（woman、man、burly）。
  - `who`：魔族在神座上见到的祂，英文，六十到一百四十个词：照神名清单的本体和画法★，加上高座（祂坐的那一处：神名清单“高座”那一栏），人形的写身高身架、头发、脸（没有脸的写明没有脸、兜帽里是黑的）；非人形的写形体、大小（立绘里画成一整只，不写比塔高这种场景里的大小）、材料、颜色、记号。
  - `formal` 正装：祂在神座上的样子，一整句：坐在或者立在祂的神座上（神座是这张图的一部分，写清神座的样子），身上的东西、手里的东西、姿势。只这一格可以写坐着，因为神座本身要画进去。
  - `art`：艺术照一两句，从魔族跪在下面往上看的角度，光从哪边来、什么颜色。
  - `palette`。
- 魔神的样子要跟祂在史诗战里的那一套对得上（epic/prompts/strife_god1.json、strife_god2.json 里祂那几块的 design），不能这边长着脸、那边兜帽里是黑的。
- 魔族眼里的神座：庄严、可怖、高不可攀，不是慈祥的神；但这一档画的是祂坐着的样子，不是全力的样子，全力的样子归显像。

## 守的口径

- 这张卡是全年龄的。原文写着十几岁样子的神，一律写成成年人；不往身材上写，衣服穿严实。
- 西式（用户 11-07 点名过瑞恩达尔第一稿像中式）：不写汉服、交领、宽袖、腰带垂流苏、玉、丝带飘带、莲花、仙人、塔楼屋檐；写 tunic, doublet, gown, cloak, mantle, hood, surcoat, breeches, boots 这一类；袍子写成前襟扣子、合身袖子的西式剪裁。
- 不写月相（moon、crescent 连否定都不写）。
- 写完跑 `python -I -X utf8 底稿/状态栏/comfy/cast_lint.py <你的文件>`，有问题改到零（lint 要是不认 cells、era、fashion、nonhuman、no_faces 这几栏而报错，在备注里写清是哪几条报了什么，别为了过 lint 删栏）。

JSON 文件，另附同名的 `.md` 备注：每一位写了几条（守旧一条、跟风尚两条）、跟不跟风尚的缘故一句、哪几样是自己起的（★）、拿不准的。
