## 先说几条通用的

- 出处缩写。前传一到前传六是 迷宫纪前传/迷宫纪前传时段_一_探井的年月.md 到 _六_垂暮的年月.md，铜一到铜六是 山铜纪/山铜纪时段_一_犁的年月.md 到 _六_麦的年月.md，纷七是 纷争纪/纷争纪时段_七_号角的年月.md。前传补NN、铜补NN 是两纪 补卷/ 底下的 补卷_NN 那一份，前传常驻、前传规则是 迷宫纪前传/补卷/ 的 第一项_常驻与纪元钟.md、第一项_规则.md。cast_0、cast_B 这些是 底稿/状态栏/comfy/cast/ 下的 json，按人名找。L 后头是行号。
- prompt 怎么贴。每一段的英文 prompt 列的是这一整段的衣裳，不是一个人一身全穿。贴进去的时候前头接一句 Use only the pieces that fit this character's role, station and side，蓄电芯、义肢、护目镜这些只给页上写了的人（★）。
- 四套差分怎么取。常服照这个人那一页的装束一行。私服是下了工、在自己屋里的样子，料子和剪裁照这一段的平民，去掉行当的家什（★）。战斗照这一段的战装。正装照这一段算得上体面的那一身，穷人的正装就是一件干净外套，码头、苇棚区出来的人进议政院换一件干净的深蓝外套（铜五 L3010，铜六 L975）。
- 东方样子不画。页上写的褂、坎肩、夹袍、短打、头巾，画成西式的短衫、背心、夹里长袍、收了袖口裤脚的贴身短衣、包头布，不画交领、斜襟、盘扣、宽袖大摆（★）。
- 年份没到的东西不上身。铳枪约40年才有（铜补01 L28），西陆862年以前没有铳，只有巴尔缇娜约616年自己做的那一把，862年以后才有单发火药枪，山铜纪西陆没有电（铜补15 L97），墙这边没有火药枪，铳是施法的家什（铜补15 L43）。前传里电灯约450年、电报约480年、电车头约500年、电械义肢约638年（前传补15 L82），旅印七阶420年、深印600年、战印850年（前传常驻 L323）。
- 立领扣到喉咙底下。1001年的图差不多人人这样（cast_0、cast_B、cast_C、cast_D）。往前它是几拨人的样子，收血人扣子扣到下巴（铜补05 L13），夜绯家、白骸领口扣到喉下（铜四 L1941、L595），莉赛尔领口扣到喉咙底下（铜三 L1546），往后是黑耀契约法庭（铜六 L201）和东边的书记（铜五 L2954）。读法定成西边起头，深井的年月各行立了制服以后两边都这样，山铜纪和前传前几段的平民领口多半敞着或者翻下来（★）。
- 颜色越往前越素。山铜纪平民多是本色麻、羊毛、油布和灰褐（铜补15 L16），染出来的颜色从花谷染布的人家来（铜补10 L11），前传繁荣的年月以后颜色才多起来（★）。

**总的样子，跟黑潮比变了什么。**
- 仗打完，人往回补，衣裳也往回补。墙上下来的人脱下战时那一身，穿回行当的衣裳。凯撒下了墙换回冠台上的衣裳（前传六 L1537），莱恩哈特做了大元帅，素旌烧穿的三处拿别的旗上剪下来的布补上（前传六 L1487）。
