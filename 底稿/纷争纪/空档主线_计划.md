## 一、总则（各份共用）

1. **写什么。** 一份一条短主线，写进一个新的分段文件（文件名见第三节），里面三样，格式照同一页现有的主线分段（炮的年月照 纷争纪/parts4/t5_line13.md，浮塔的年月照 parts5/u4_line15.md，铁狼的年月照 parts6/v3_line17.md）：
   - 主线条目 `## 纷争纪·主线｜页名·段名`：【调用】下面一句钩子引语，开局、世道、一幕二幕三幕（每幕一拍一条，末一条幕终）、收束、默认收束、玩家能改、碰得上的人，后面 `## 裁定锁` 只留锁。短主线：三幕，一幕四到七拍，整条五千到七千字上下，比现有的主线短一半。
   - 两到三个旅伴：`## 旅途同行：名（纷争纪·段名）` 加一条 `## 旅途同行·背景：名`，栏目照同页现有的旅伴条，年份黑名单照写作口径挡掉死后（老死的挡，死在这段主线里的不挡）。
   - `## 这一段旅伴之间｜段名`，短一点也行。
   另交一个星的文件（只写 `### 星名 (类 | 阶)` 那几块，不写「## 这一代的命星」那一行、不写条目设置，主会话并进那一页的命星一节），一个旅伴两到三颗，Art、Special、Passive 都有，阶照写作口径「命星」那一节（Epic 为主，Legend 只给歌、史书、名录里记下名字的人），名字照「起名」那一节分正名、俗名两层，Special、Passive 写成生来的天赋（10-25 定的，照 底稿/洗稿/去模板_计划.md 第一节写，别成模子）。要新起人物条（不当旅伴、只在碰得上的人里露面的有名有姓的人）的，另交一个人物的文件，`## 名，一句话（人物）`，格式照同页 t7/u7/v7 的人物条，也是主会话并。
2. **事实。** 战役志那一条（纷争纪/补卷/补卷_09_战役志.md）是这段主线的底子：年份、天数、伤亡、两个名字、文书那一行、留下的、玩家在场、裁定锁，一样不改，主线照它铺开成能玩的三幕。同一页的时段总纲、纪元钟（纷争纪/补卷/ 里的纪元钟那几条）、凡世至强、人物条说到这件事的，跟它对齐，对不上的先照页上，写进回报。不另起大设定，新起的人、名字、小事标★记在文件末尾的设计备注里（`## 设计备注（这一份）`，不进卡，主会话并进那一页的设计备注）。
3. **口径。** CLAUDE.md「写作口径」全守：卡面（标点、禁词、月相、祂、不点那一位恶神的名字）、润色口径（幕一拍一条、裁定锁只留锁、旅伴条句架换着写、【调用】写清）、台词、容貌、玩家在场（玩家在场插手照玩家做的事走，不写拦不下、救不下、改不了）、尺度高魔命路（写出整条墙和整场仗的尺度再落到玩家身边，高魔，不写成堑壕对耗也不写成古代野战）、起名、命星。动笔前读用户的三份写作 skill 和 genshin-dialogue-voice（路径在 /tmp/claude-0/-home-user/ac3b7386-5775-58fd-8a7e-6c4338f693a4/scratchpad/w1030/路径.md）。
4. **谁在场。** 碰得上的传奇照 纷争纪/纷争纪_旅伴与传奇总表.md 第五节那一张牌的现存传奇（年份落在哪一张牌的段里看哪一张），只写那几年真在那一处的（各人的凡世至强、人物条写了在哪）。魔族那一边的传奇之名只在魔族当时的嘴里，长垒这一边只叫得出代称。四执政不入场。七支柱在纷争纪里还是七十二位正神当中的七位，不写成柱子。
5. **钥匙。** 主线的条目设置照同页现有主线写：`触发〔主线·页名·段名〕（★新钥匙）……〔主线·页名·段名〕写成 /页名·段名·|开局时段：(?:段名|别名)/`。别名一两个，挑玩家开口最可能说的那个（下面第二节各条给了倾向），别名别撞同页别的主线和时段钥匙里已有的名字（grep 一遍那一页的 t2/u2/v2 时段总纲的条目设置）。旅伴条的触发照同页旅伴写成（同时满足）〔纷争纪·正则〕加名字，背景条触发写「名的(?:家|父亲|母亲|……)」那一路。时段钥匙里加这几段的名字由主会话做。
6. **起名。** 新名字跑 `python3 -I -X utf8 tools/namegrep.py 名字…`（报无才算没撞）、`python3 -X utf8 tools/collide.py 名字…`、`python3 -I -X utf8 tools/namepairs.py`（带上新名字），再 grep 一遍 纷争纪/ 的总表和七页（collide 不扫那里），再自己听一遍近音（莫尔嘉、霍斯特、利奥波德都是这样改的）。人名照姓氏那两条（纷争纪/补卷/补卷_15_姓与家名.md），名·姓，头一回出场报全名。别跟同一轮别的份撞：八份各起的名字主会话收稿时一并对，起名前看一眼 底稿/纷争纪/空档主线_起名.md（各份登记自己那一节，只改自己那一节）。
7. **检查**（一份写完自己跑，都过）：
   - `python3 -I -X utf8 tools/cardscan.py 你的文件`、`python3 -I -X utf8 tools/check_people_v7.py 你的文件 .`（硬问题 0）、`python3 -I -X utf8 tools/authormark.py 你的文件`、`python3 -X utf8 tools/ngram.py 你的文件 语料`（0）、`python3 -I -X utf8 tools/regex_check.py 你的文件`（硬问题 0），星的文件、人物的文件一样跑。
   - 旅伴的台词样例和主线里的原话抽成「说话人：台词」，跑 voice_check 加 `--ban "…！—；" --corpus 台词语料`，单人零警告、零撞句。
   - 年份：拿 `python3 -I -X utf8 tools/yeartest.py 你的文件` 看各条黑名单挡的年段对不对。
8. **不许做的。** 只写你那几个新文件（主线分段、星、人物、起名登记里自己那一节），不改别的页、别的分段稿、时段总纲、页头、设计备注、tools/、总表、补卷。不提交、不推送。临时文件放 /tmp/claude-0/-home-user/ac3b7386-5775-58fd-8a7e-6c4338f693a4/scratchpad/w1030/gap_<份>/。

### 甲　炮的年月·白鸢的天（约2400年坠叶月，十一天）
- 底子：战役｜白鸢的天。南段一段墙头几十门魔晶炮曲射，看落点全靠白鸢的狮鹫骑一百二十头，九天里只剩七头能飞，第十一天天亮以前狮鹫骑长吉纳维芙说「不打，只看」，七头上去回来三头，旗语一打，龙雷炮把领头的有翼有名者打下来，炮落进魔潮当中。
- 三幕的倾向：一幕头一天，天亮以前上天，云上头的翼下来，玩家头一回看见狮鹫骑是去看的；二幕第五天到第九天，一头一头少下去，炮一发一发落空，墙上的人管这几天叫南段瞎了；三幕第十一天。
- 旅伴：吉纳维芙（人族，狮鹫骑长，那一年四十一岁，活下来，往后的事你定，老死）、她机组里的一个年轻观测手或旗语手、那一门龙雷炮的炮手（高阶龙裔，打多了自己的血先烧干）。两到三个，吉纳维芙要有。
- 碰得上的：十二张那一段在世的传奇里那几年在南段的（独醒者席恩在南段守夜），别的照总表和各人的条。
- 别名倾向：开局时段写白鸢的天、南段瞎了都认。
- 要对的：时段总纲写龙雷炮约2100年、有名者一年比一年多；有翼的魔族这一段叙述里写有翼的，夜翼这个叫法往后才有（战役志的锁）。领头的有名者不起名。

### 乙　炮的年月·第七座营垒（约3399年秋到约3400年）
- 底子：战役｜七垒之潮，凡世至强七垒之潮珂伦娜。盐海北岸红晶滩上七座营垒，前六座开了门往北走，第七座修在她家那一片老滩上，一直没开，围了一年，井全咸了，最后她推门进去，里面的人都死在盐里，那一年她凝名。

- 旅伴：第七座营垒里的一个人（守军、管水的军需官、随军的白烛祭司，你挑），珂伦娜帐下一个看潮表的年轻深潮魔族。两个，一边一个。守将是碰得上的人，写一条人物。
- 碰得上的：珂伦娜（这一段还没凝名，凝名在这段主线的末尾，她这时候是真心信祂的，照她的凡世至强），十三张那一段在世的传奇。
- 别名倾向：第七座营垒、红晶滩。
- 要对的：时段总纲写约3400年她在第七座营垒前凝名，长垒的战报一百年里只写一句南线又被围了、从来不写她的名字。第七座里的人是她围死的，这一段不洗（战役志的锁）。

### 丁　浮塔的年月·盐门（约5200年长曦月，两天一夜）
- 底子：战役｜盐门。盐海第一舰队四十三条船一万二千人，舰队长博杜安，出盐海门去打深潮聚在门外的船，追了两天，第二天夜里两轮月的潮同时倒过来，船叫倒回来的潮推在门外的礁上，神像战船的火、海兽、潜船，四十三条一条也没有回港，回来的不到九百，都是自己游回门里、沿岸走回去的。
- 三幕的倾向：一幕出港，横过盐海，出门，门外的船往后退；二幕追了两天，看潮的人觉出不对；三幕倒潮那一夜。玩家劝得动博杜安别追、倒潮那一夜救下几条船几个人，都照玩家做的事走。

- 碰得上的：十四张那一段在世的传奇。深潮那一边领船的是一位潮主，战报只记了潮主在场，不点名，不写成珂伦娜（她不领冲阵的兵）。
