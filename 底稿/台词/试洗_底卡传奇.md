# 台词试洗｜底卡二十四位传奇的声口（11-10）

Codex 起稿（genshin-dialogue-voice），主会话逐句挑，已并进 底卡洗稿/批次_16凡世至强_二.md（wash_check 过，硬问题、撞句、禁用标点跟改前一样）。Codex 收尾时自己退回了米蕾卡那句裂痕（别处引过的招牌句），莱恩哈特一句没动。收的是对着没人讲的信条和道理、直陈情绪、说教的那几句，改成对眼前的人说的话；玩笑、自嘲、双关和带这个人世界观的那几句照留原句。

收 27 句，照留 15 句。

### 892｜卢米安，第2、4句（第1、3、5、8项）

- 收：“未来没有命令谁。在命令我们的，是今天的粮仓和桥。” → “粮仓和桥，你想先看哪一处？今天得去一趟。”
- 照留：“晚饭的未来我没看。照今晚这一盘来说，这是我今年最错的一个决定。”（先知拿自己没看见晚饭开玩笑，他的尺子，Codex 改成“唔，这一道我又点错了。你那盘怎么样？”）

### 893｜苍风，第2、4句（第1、6项）

- 收：“比赛输了就输了，奖杯明年还能再抢。下面那个村子叫云墙封住，可就没有明年了。” → “比赛输了，奖杯明年再抢。下面的村子叫云墙封住了，跟我下去。”
- 收：“布带还在啊。这地方没把我忘得太快。” → “布带还在啊。你看，风还能把它吹起来。”

### 894｜赫尔曼，第4、6句（第1、2、8项）

- 收：“彩绳别碰。今天最要紧的氏族标记，就是它。” → “彩绳别碰，开会就这么戴着。”
- 收：“背上的鳞裂了。你愿意的话，帮我上点药吧，不愿意也不欠我什么。” → “背上的鳞裂了。那几片我够不着，你肯帮我上药吗？”

### 895｜琥珀，第5、6句（第1、3项）

- 照留：“便宜一枚也是赢嘛，大统领的脸面就是这么一枚一枚挣回来的。”（大统领自嘲，商人的嘴，Codex 改成“便宜一枚也是赢嘛。拿来，幼崽的糖罐还等着呢。”）
- 照留：“名字可以告诉你一个。别的，等我确定它们变不成锁链再说。”（名字会变成锁链，狐族的说法，Codex 改成“名字可以告诉你一个。别的还不能说，你别追问。”）

### 896｜烈刃，第1、6句（第1、3、8项）

- 收：“强者先站到风口上，水袋最后才轮得到他。” → “水袋先往后传，我去风口站着。”
- 收：“你当着全族的面拦我，我今天丢了脸，可明天少埋十个人，这笔账我认。” → “今天丢脸就丢脸，你拦得对，明天少埋十个人。都听见了？”

### 897｜派派，第3、6句（第1、3项）

- 照留：“救世界以前先吃饭。饿着肚子的人，容易把勇敢认成好主意。”（派派的吃饭哲学，一个人只留这一句道理，Codex 改成“要救世界也得先吃饭。把碗端好，吃完了再谈你的打算。”）
- 照留：“今天不尝新东西。陪我喝碗没有故事的粥吧？”（没有故事的粥，Codex 改成“今天不尝新东西。你陪我喝碗普通的粥，好吗？”）

### 898｜塞莉卡，第1、4句（第1、3项）

- 照留：“先把泉眼封住。祷告替孩子们滤不了毒水。”（大祭司说祷告滤不了毒水，她的分量在这句，Codex 改成“先把泉眼封住，别让孩子们喝。取些水来，我看看毒混在哪里。”）
- 收：“叶子捞干净了吗？我们唱得多庄严，泉水是听不懂的。” → “叶子捞干净了吗？石缝也摸一摸，等你收拾好了，我们再唱。”

### 899｜埃兰迪尔，第5、6句（第1、5、8项）

- 照留：“火圈围得没毛病。刚才拔箭，是我的毛病，跟你没关系。”（毛病那个双关，Codex 改成“火圈围得没毛病。刚才不该拔箭，抱歉。”）
- 照留：“别问我想说什么。陪我走到下一棵倒木那里吧，走到了，我兴许自己就说了。”（原句的别扭就是他，Codex 改成“陪我走到下一棵倒木吧。我想一想怎么跟你说。”）

### 900｜夜魇，第5、6句（第1、8项）

- 收：“我试探过你。你没问题，可我这么做，是冒犯了你。” → “你没问题。之前不该拿假话试你，抱歉。”
- 照留：“今晚没有委托。你要是留下，就只能是因为你想留下，别的理由我不收。”（只能是因为你想留下，这一句改平就没了，Codex 改成“今晚没有委托。想留就留，别勉强。”）

### 901｜索林，第1、2句（第1、3、5、8项）

- 收：“裂纹在第三层，不在面上。你把它擦亮了，人只会死得体面一点。” → “敲这里，第三层。听出裂纹了吗？你光把表面擦亮，拿出去会死人的。”
- 收：“把步骤念一遍给我听。会做是一回事，能教别人做是另一回事。” → “把步骤念一遍给我听，再想想怎么教给下一个学徒。”

### 902｜麦格尼，第1、5句（第1、3、6项）

- 收：“左墙吃力了，上三个人换肩。别等石头来提醒你。” → “左墙吃力了。你们三个，上来换肩。”
- 收：“墙空了，人也撤完了。我再留下，守的就只剩我自己的名声。” → “墙空了，人也撤完了。走，跟上他们。”

### 903｜蕾雅，第3句（第1、6项）

- 收：“我留下来，跟怕不怕没关系。门什么时候关，我心里有数。” → “我留下。门什么时候关，我心里有数，你跟着他们走。”

### 904｜奥尔文，第5、6句（第1、3、8项）

- 收：“我不知道。把这三个字写上去，比编一条路靠得住，编出来的路，是要拿人去走的。” → “我不知道。你把这三个字写上去，别添一条没走过的路，后面的人还要照着它走呢。”
- 照留：“今天最后一段不补了。你说得对，回程的图上也得画上活人。”（绘界师的尺子是图，Codex 改成“今天最后一段不补了。嗯，听你的，今天先回家。”）

### 905｜米蕾卡，第4、5句（第1、5、8项）

- 收：“这只鸟的翅膀歪了，歪着也能在窗边待着。” → “这只鸟的翅膀歪了。你扶一下，我把它摆到窗边。”
- 收：“我还缝得动，可你已经说够了。那就停在这里吧。” → “够了？好，我收针，你歇一会儿吧。”

### 906｜阿卡夏，第6句（第7、8项）

- 收：“我刚才开玩笑，是因为怕。你别夸我坦白，我已经很不习惯了。” → “刚才那些笑话，你别当真。让我缓一缓，先别夸我。”

### 907｜格拉德，第6句（第1、7项）

- 收：“我笑了。别替它找什么意思，今天那句话是真好笑。” → “你那句话真好笑。再说一遍，我还想听。”

### 908｜索菲亚，第1、6句（第1、3、5、8项）

- 照留：“价钱可以谈，死人不能退货。”（佣兵的招牌话，Codex 改成“路上有什么危险？先说清楚，我们再谈价钱。”）
- 收：“我签错了。损失从我那一份里出，教训大家一起记着。” → “我签错了。你们的损失从我那一份里扣，少了多少，拿来对一对。”

### 909｜莫里斯，第5句（第3、6项）

- 收：“十息很珍贵，命也一样。关窗，撤人。” → “十息很珍贵。好，关窗，撤人。”

### 910｜诺维安，第2、4句（第1、6、8项）

- 照留：“钥匙，不一定是人。”（指着他自己那件事，留着，Codex 改成“人退开，我再找找钥匙。”）
- 照留：“这门叫咬手箱。学名太长，念完一遍，手上的指头说不定已经少了一根，往后就更难念了。”（絮叨的黑色笑话，Codex 改成“这门叫咬手箱。学名太长，先记这个。它真会咬手，你把手收回去，站远些。”）

### 911｜梅莉娅，第3、6句（第1、4、8项）

- 收：“我不说不疼。疼是真的，剂量也是。” → “疼得厉害吗？剂量照旧，别自己往下减。”
- 收：“我刚才骂错了人。药方没错，解释药方的人错了，我重来一遍，你从头听。” → “刚才骂错你了。药方没错，服法我没讲清楚，我从头再讲一遍。”

### 912｜巴罗，第1、3句（第1、3、8项）

- 照留：“这价钱里有三座桥、两回山洪和一根断了的车轴，不全是我的胡子。”（不全是我的胡子，Codex 改成“三座桥、两回山洪，车轴还断了一根。客人，这些都算在价钱里，你再算算。”）
- 收：“你会不会还，我不赌。我赌的是你还不上的时候，也不会跑。” → “这笔先赊给你。还不上就来找我，把难处说清楚，别躲着。”

### 913｜林薇，第2、5句（第1、3、7项）

- 收：“先戴手套。你拉不开弓的时候，勇气没有用。” → “手套戴上。手指冻僵了，你还怎么拉弓？”
- 收：“我看见你难过了。刚才没出声，是我判断错了。” → “刚才我该陪着你。还要我留下吗？”

### 914｜加兰，第5、6句（第1、5、8项）

- 收：“针不大啊。这句实话帮不上忙，换个话题。” → “针不大啊。好，好，我看天花板，你缝吧。”
- 照留：“你不想打，那就不打。我这一对耳朵没练过拳，也该派点用场了。”（耳朵没练过拳，Codex 改成“你不想打？好，我坐下。你说，我不插嘴。”）
