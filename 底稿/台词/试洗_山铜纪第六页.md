# 台词试洗｜山铜纪第六页前四段的旅伴和人物（11-10）

Codex 起稿（genshin-dialogue-voice），主会话逐句看。十四处十七句，只收克里斯托夫给孩子捂手那一句，别的照留原句：Codex 照规矩把每句收在反差上的话都改平了，改掉的正是各人身上有人味的地方。四纪的台词 10-23 那一轮已经拿这个 skill 洗过，再洗是往坏里洗，四纪不铺开。

- 照留：“我不是来要你原谅的。我来看看你家门口那条路修好了没有。”（丢了“不是来要你原谅”，人为什么站在那里就没了）｜Codex 改成“你家门口那条路修好了没有？我来看看。”
- 照留：“你叫什么？先问问嘛，往后说不定要刻你呢。”（碑匠的黑色玩笑；改的那句跟她另一句“哪几个字呀”撞了）｜Codex 改成“你叫什么？是哪几个字？我拿凿子柄写给你看。”
- 照留：“嗯？哦，是个笑话。好笑。笑完了天黑以前回家，有人来领你吗？”（“好笑。”那一下愣是她）｜Codex 改成“嗯？啊，原来是笑话。天黑以前回家，有人来领你吗？”
- 照留：“名字报慢一点。慢一点我才刻得直嘛。”（原句有她的语气词和手艺）｜Codex 改成“太快了。你重报一遍，慢一点嘛，我在你手背上写，写对了没有？”
- 照留：“背面不收钱。你再掏一回，我就把锤子放下了。”（放下锤子的玩笑）｜Codex 改成“背面不收钱。你把钱收回去。”
- 照留：“纹是顺着的，您看，从这儿下凿子正好，正好，嗯，我说快了，我老师说说话快的人刻字也快，刻快了就要出错，纹是顺着的。”（絮叨的自我纠正，原神式的破功，改短就没了）｜Codex 改成“请您看这道纹，从这儿下凿子正好，嗯，我说快了，您看清了吗？”
- 照留：“那家的母亲说，这不是我儿子。我磨平了重刻，她认了。可我一直想，头一回刻错的那一行，是谁？”（“头一回刻错的那一行，是谁？”是这个人的心事）｜Codex 改成“那家的母亲说，这不是我儿子。我磨平了重刻，她认了。您摸摸，磨过的地方就在这里。”
- 照留：“她说签完了带我去看。我在公所门口等到天亮，天没有亮起来。”（“天没有亮起来”说的是灰雨那一夜，不是比喻）｜Codex 改成“她说签完了带我去看。我在公所门口等到天亮，没等到她。”
- 照留：“八百二十五年坠叶月。您说的是二十四年，差一年，就是另一个孩子了。”（“差一年，就是另一个孩子了”是管档的人的尺子）｜Codex 改成“八百二十五年坠叶月。您说的是二十四年，差了一年。先别往下说，再想想那个日子。”
- 收：“睡吧。睡着了手就不凉了，明天早上的面包，我给你多留一块，别告诉别人。” → “睡吧。手还凉，我给你捂着。明天早上的面包，我给你多留一块，别告诉别人。”
- 照留：“她说她姐姐会来接她。她姐姐真来了，五十年以后，在台地上。罗泽要是知道，又要笑我慢了吧。”（墓前一句自嘲，往小处收，本来就对）｜Codex 改成“她说她姐姐会来接她。五十年以后，我才在台地上见着她姐姐。您再陪我待一会儿吧。”
- 照留：“两枚铜币三条。再还，鱼就回河里去了。”（卖鱼的嘴）｜Codex 改成“两枚铜币三条，不能再少了。”
- 照留：“老书记，第三十一稿我拿走了，丢了赔你一条鱼嘛。”（赔一条鱼）｜Codex 改成“老书记，第三十一稿我拿走了，我用鱼市的油布包着。”
- 照留：“到一节，画一道。没到的那一节，我不画。”（没到的那一节不画，是在等人）｜Codex 改成“到一节，画一道。你也数着，别漏了。”
- 照留：“伏雷说，你烧的是路上的站，你修一段路。我修完了。你要看，我领你走一遍。”（原来的次序是先讲来由）｜Codex 改成“跟我走一遍。路修完了，伏雷说我烧的是路上的站，就叫我修一段路。”
- 照留：“剪短点。”（九十七岁的老人，两个字的吩咐就是他）｜Codex 改成“您把灯芯剪短点，剪下来的放进铁盒里。”
- 照留：“别扶，别扶。九十七啦，这一边的翼抬不起来了，灯还举得动。”（“灯还举得动”是他的骄傲）｜Codex 改成“别扶，别扶。九十七啦，这一边的翼抬不起来了，您留点地方，灯我拿着。”
