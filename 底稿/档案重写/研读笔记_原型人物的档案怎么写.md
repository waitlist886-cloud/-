# 研读笔记：原型人物的档案在百科和官方资料里是怎么写的（11-28）

用户 11-28：作者群说门面和卡里的角色介绍“GPT 和克劳德的风味浓”，点名菲伦的档案和 971 那一本。用户原话：“问题主要还是在于部分文本的写法与词句和语法的使用上面，比如说截图中关于971那里，以及菲伦的角色档案中外貌这些的描述。……角色档案一定程度上可以看一看学习一下比如wiki上面或者萌娘百科上面对应原型人物是怎么写的。然后辐射给我们卡中那些角色的档案”

读了四份：萌娘百科的菲伦、芙莉莲、蒂法·洛克哈特，B 站原神 wiki 桑多涅的「角色详细」（官方文本）。只记做法，不抄原文。

## 一、百科条目的骨架

1. **先摆硬资料，一项一格**：本名、别号、发色、瞳色、年龄、出身、所属、亲属或相关人。发色就写“紫发”，瞳色就写“紫瞳”，不加形容。
2. **“萌点”一栏是一串名词标签**：长直、齐刘海、长鬓角、遮耳发、半扎、发饰、连衣裙、披风、长靴、毒舌、甜食控、敬语……外貌靠这一串部件立住，读的人在脑子里拼得出一个人。没有一处比喻。
3. **别号带来历**：一个外号一个缘故，写在注里（因为什么叫开的、谁叫的）。外号本身就是旁人怎么看她。
4. **简介一句一样东西**：一个特点，配一个看得见的表现。“性格沉稳，不过说话却十分毒舌。”“和其他人对话的时候一直使用敬语。”转折用“不过”“却”“但是”，都是口头的词。不下判词，不总结人生。
5. **经历照时间往下写**：几岁、哪一年、在哪、出了什么事、谁做了什么、结果怎样。带数（“仅用4年就超越了常人10年才能到达的水准”），数是用来说事的，不拿来压句尾。
6. **“其他”一栏是小习惯清单**，这是活人感最足的一块：
   - 生气时爱鼓脸颊。
   - 吃到好吃的心情就会变好。
   - 生闷气的时候嘴上说没事，心里很介意。
   - 知道自己也有错，消了气很快就道歉。
   - 小时候受谁影响，吃饭前会祈祷，后来把这习惯带给了同伴。
   - 头上那个发饰是谁在哪儿买给她的，一直很珍惜。
   - 芙莉莲：明知是宝箱怪还是忍不住去开，每回被吞进去半截，平时那么冷静，这时候会大喊大叫；爱赖床，是因为对时间迟钝又怕冷，醒来常过了晌午。
   每一条是“在什么情况下，她会怎样”，或者“她有个什么，从哪来的”。有触发、有动作、有来历，有的带点好笑。
7. **能力单列成一张单子**：一条一样本事，写它做什么、有什么毛病（芙莉莲“发动魔法的瞬间会停止魔力探知”这种低级魔法使的坏习惯），毛病和本事写在一处。

## 二、官方角色介绍（游戏里的那一段）

- FF7 蒂法的官方介绍：先说身份和手上的事，再说“和活泼的外表不同，她的内心其实比较内向，常常一个人扛着痛苦，不过开朗的性子给了她撑下去的劲”。外表和里子各一句，用“不过”接上，话说得很白。
- 原神桑多涅的「角色详细」：不描她长什么样，写**不同的人怎么叫她**（造她的人私下怎么叫、至冬的人当面怎么叫、同事朋友怎么叫），每一种叫法后头跟着一种看她的眼光，最后让她自己用对白说一句她怎么看这件事，带一点淑女的不耐烦和刻薄。人物是从别人的嘴里和她自己的嘴里立起来的，叙述者不替她下评语。

## 三、对照我们卡里的档案，毛病在哪

拿菲伦那一条（底卡 #815、#816 的洗稿层）对着看：

| 我们现在的写法 | 毛病 | 百科会怎么写 |
|---|---|---|
| 外貌：紫发紫眸，表情沉静，这两年脸上的稚气淡了。黑白法衣绣着细致的银露一门纹饰。她习惯看清楚再说话，因而常让人觉得冷淡。 | 外貌里混进了性格；“因而”是书面连接；衣裳只有一句笼统的“法衣” | 紫色长直发，齐刘海，长鬓角遮住耳朵，后头半扎，别一枚发饰；黑色长裙外罩白色短披风，长靴。部件写清楚 |
| 容貌评价：静静的，像一页未翻开的书。她笑起来好看，自己却不知道。 | 比喻加“自己却不知道”，就是群里说的那种 AI 味 | 写旁人怎么看她、怎么叫她（外号和来历），或者一件看得见的事 |
| 分清了“看见”和“被引着看见”的区别 | 概念对仗，抽象 | 写她那一回做了什么、结果怎样 |
| 她要找一把自己的尺子 | 套话比喻 | 写她想自己定哪几件事 |
| 最深恐惧：她以为的独立，只是把老师的法子用熟了。 | 一句话的概念反转，“以为的X只是Y” | 写一件她怕的具体的事 |
| 还顾不上感动／别让她离开一趟仍毫无变化 | 前一句是作者替她下的心理判语，后一句是给模型的指令混在人物描写里 | 写她做了什么；给模型的规矩单独一句说清楚 |
| 这个世界没有、也不会有修塔尔克 | 对原作的元话写进了档案 | 写成规矩：她身边没有那样一个人，不另起名补上 |

另一面：原典里菲伦对谁都说敬语，生气鼓脸颊，饭前祈祷，头上的发饰是小时候照看她的老人送的，嘴毒可是自己有错消了气就道歉，像个管着芙莉莲起居的小妈妈。这些我们的档案只写了“嘴毒爱吐槽”“老师的起居也归她管”，最有辨识度的几样习惯没有。“点名当本土化同人角色写的，本事、经历、性格照原典”（记忆 homage-openly-follow-source-skeleton），这一条在档案里做得不够。

## 四、学过来的做法（写进口径）

1. 外貌照“萌点”那种写法：发型、发色、瞳色、一样记号、衣裳几件、随身的东西，一样一样写成名词。不放性格，不放比喻。
2. 容貌评价写旁人眼里的印象：别人怎么叫她、头一眼注意到什么，或者一件事。一句。
3. 性格一句一样，配一个看得见的表现，转折用口头的词（不过、可、却、倒）。
4. 加一栏小习惯（照“其他”那一栏）：触发加动作，或者东西加来历，三到六条，挑原典里最有辨识度的、本土化成这个世界的东西。
5. 经历照时间写，带年份和数，写事，不写意义。
6. 给模型的规矩（锁、好感、玩家不在的时候）用平话写成规矩，不混进人物描写，也不写对原作的元话。
7. 原型人物先翻百科对一遍：口癖、称呼、习惯、跟谁什么关系、外观部件。原典里有的照搬做法，名字和东西换成本世界的。
