# 入局那一条的包装（11-26d）

用户在日里真页面上用 gemini 试了入局：浅色主题下一片淡灰字，顶上一个小小的“◆ 入局”，片头、前半生平铺，锚点一块浅灰框，末尾一行灰字。能用，但是素。用户原话：“关于第0轮，我觉得可以包装得漂亮一点”。这一轮照这张卡自己的样子包了一层，**记录写法没改**，只动显示（显示正则、样式）和 #0 里两句措辞。没打卡、没提交；题头那张画推上了图床的新分支（见第五节）。

## 一、样子

从上往下五块，整条自己带底色，深浅两套主题一个样子（外头一圈金线和阴影，深底浅底上都看得清）：

1. **殿门题头**：一张死之神殿的画（灰白石柱、柱间悬着的青火、黑亮如水的地面、红毯通到殿深处黑石金线的王座；王座里一片黑，只露一截黑袖口和搭在扶手上的一只冷白的手，不出脸）。画照它自己的宽高比放在最上，王座和手不叫字压着；题字压在画底下渐黑的那一截：小字“死之神殿”，大字“入　局”，下一行三格“纪名年份｜开局的地方｜潮汐”（从 §底座 里拆出来）。
2. **片头**：星点暗底，居中，字距宽，**一句一行**（显示正则照句号拆开），末一句（多是“这是一个关于……的故事”）金色、大一号，底下一道金线一颗点。最新那一条（对话里还没有大框的时候）一句一句淡入，往后翻回来不再动；`prefers-reduced-motion` 下不动。
3. **前半生**：一页账。旧羊皮纸底、28px 一道的格线（字和格线对齐，段与段空一行，像账上隔一行记）、左边两道红线、左上一行红字“前半生”、右上一枚红印（两圈红线当中一朵火的形，不成十字）、头一段首字放大成红字。**祂的话**（“”起头的段）是深墨色、大一号；**旁白**（殿里的样子、那只手做了什么）浅一档、小一号。
4. **旅印**：一张封了红蜡的笺。蜡封压在上沿，标题“旅印 · 名字”（名字取锚点头一行【旅印·X】），一行小字“复制下来，贴进你自己那边的提示词，往后每一轮都认得你”，底下是锚点（**照旧是 Markdown 代码块**，平台若给代码块带复制钮照样有；样式给了 `user-select:all`，手机上点一下整块选中），再底下一个钮“填进输入框”（`data-action="set-textinput"`，值是整块锚点，玩家在输入框里长按全选、复制，手机上更顺手）。锚点里有半角双引号、尖括号的（进不了属性），这个钮不出，代码块照留。
5. **门扉**：黑石门框嵌金的一扇拱门做大钮“推开门扉 / 进第一幕”（点了把“推开门扉”填进输入框，玩家再按发送）。两扇门板，悬上去往里开一点、按下去开得更大；手机上（没有悬停）常开一条缝。底下一个次一点的字钮“哪里不对，我说给你听”（填“前半生里有一处不对：”），再一行小字“点一下填进输入框，再按发送”。

旧回复：整页照留（玩家往后可能还要回来复制锚点），只是片头不再动。对话里已经有大框时（中途换锚点、或者重来一回入局），这一条照样是这张页，坐在大框正中那扇窗里。

`§功能｜旅印`（半路要一份新锚点）也走旅印那张笺，没有题头和门；模型在锚点前头写的一两句话排在一张小纸上。

和我原来的倾向比改了两处：片头那一段原来想放在题头画上，试下来字压住了王座和手，改成画在上、字接在画底下渐黑的那一截；格线原来按 em 画，字号一大一小对不上，改成一律 28px 一行。

## 二、记录写法：没改

模型照 11-26c 的 #0 写（§底座、§环境、`§功能｜入局`，空一行接片头一段、前半生几段、“这一页是你的旅印……”一行、```text 代码块、“回 推开门扉……”一行、§预载）。显示正则只认这些东西的位置：片头＝正文头一段，前半生＝片头以后到锚点代码块以前，祂的话＝“ 起头的段，锚点＝头一行是【旅印·X】的代码块。所以模型不用学新记号，11-26c 以后已经出过的入局回复也直接换上新样子；风月和日里同一套。

#0 只添了两句措辞（`底卡洗稿/批次_00核心运行_01玩家建档_一.md` 的「#0 首轮入局驱动」）：
- 片头“一两百字”后头加“写成一段”。
- 前半生末尾加：祂开口的段落用“”起头收尾，一段话一段；旁白另起一段，不跟话挤在同一段里，也不写成 §话 那一行。

主提示词骨架、后置词没有动（写法没变，里头入局那几句照旧对）。

## 三、写歪了怎么接

拿月银纪那一局的入局造了十种歪法（`<scratchpad>/rj/mk_bad.py`），都接得住：

| 歪法 | 接法 |
|---|---|
| 没写片头（头一段就是殿里的旁白） | 头一段带“殿里、青火、扶手、那只手”这类字的不当片头，直接开账页 |
| 片头写成两段 | 头一段当片头，第二段落进账页当旁白（小毛病，照留） |
| 祂的话写成 `§话｜若娜瓦｜…｜台词` | 照祂的话排，没带引号的补上“” |
| 多写了 §推演、§面板、§分支 | 入局这一条里别的记录行一律拿掉 |
| 锚点没包代码块 | 头一行【旅印·X】上一行不是围栏的，补开头那一道 |
| 代码块没收尾 | 到末尾都没有收尾围栏的，在末尾补上 |
| 整条没有 §底座、§环境，也没写门扉那一行 | 题头的画照出（样式里的退路，不带字），门照出 |
| 锚点里有半角双引号 | “填进输入框”那个钮不出，代码块照留 |
| 整条包进代码围栏 | 原来那条“去外层围栏”先拆掉 |
| §功能｜旅印（半路换锚点） | 只出旅印那张笺 |

模型要是在入局里写了 §正文｜，那就不是入局的样子了，整条照普通的一轮走大框（原来就这样）。

流式：三局加十种歪法每 37 字切一刀，673 刀，展开出来没有漏出的记号和 §，最久 7.8ms。

## 八、还要用户定的、没做的

1. **日里真页面没上过。**要看的：平台的 markdown 是不是照复刻台那样把 HTML 块和空行隔开的 markdown 接成嵌套（unified 那一套是这样，平台用的是 react-markdown＋rehype-raw，应当一样）；代码块有没有复制钮；手机上点一下锚点能不能整块选中；“填进输入框”填进去的锚点换行在不在。
2. 题头那只手偏小，要不要再出一张手放大的（复查说不改也能用）。
3. 片头写成两段的，第二段落进账页当旁白。要不要改成两段都算片头（得再加一条规则，或者 #0 里写死“一段”，眼下已经写了）。
4. 风月没有点击：门扉、“哪里不对”、“填进输入框”都不能点，门扉退成一行字说“回 推开门扉 就进第一幕”。门照旧画出来（悬上去也会开一点），会不会让风月的玩家以为能点，看用户。
5. 卡没重打、风月外壳没重出。下回打卡照常一串（make_four_era_card 读重出的 rules_frame.json、frame.css；css_cdn 推新样式），风月 `fy_shell.py 全部`。
