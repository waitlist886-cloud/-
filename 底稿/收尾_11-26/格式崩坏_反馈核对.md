## 三、改了什么

### 1. 显示正则（只给显示，发给模型的历史一个字没动）

根上的毛病在两处：

- **队友浮栏抄得太多。** 「浮栏·抄」把从头一个 §角色 到 §见闻 中间的东西整段抄到手札页头上，中间要是夹着别的记录（战斗栏、§物品、又写一遍的面板、一段正文），也一起抄过去；各页的「开页」只认头一个出现的那一行，于是在浮栏里开了页，整页正文、对话、分支跟着掉进那一页。改成只抄连着的那一串 §角色、§宠 行（中间空行不算断），碰到别的行就停（`estate_page.py` 的 `FLOAT_COPY_NEW`，那一条最后是它改的）。
- **一页从哪一行开始，看那一类记录头一回出现在哪。** 写错了地方的那一段把它后头几行都带进自己那一页。添了几条在一切展开以前把最常写错的两段挪回骨架的次序（`robust_rules.py` 的 `FRAME_ORDER`）。

添的规则（`robust_rules.py` 三组、`make_rules_frame.py` 四条，接法写在 `make_rules_frame.py` 里）：

| 规则 | 管什么 |
|---|---|
| 稳·去标签·块、稳·去标签 | 模型写进来的 `<style>`、`<script>` 连里头的字一起拿掉，别的 HTML 标签拿掉、里头的字留着。没关的 `<div>`、`<details>`、`<b>` 会把后头的页撑歪，`<style>` 全页生效、带歪别的回复。排在「功能轮」后头（存档代码块不碰）、「地图页」前头 |
| 稳·去围栏行 | 单占一行的 ``` 拿掉（整条包着的那种原来就拆了） |
| 稳·整行竖线（三条） | 记录行中间写成半角竖线的，整行换全角。原来只换名目后头那一道，后头几道还是半角，整行认不出。§记忆、§话 两种不碰 |
| 稳·次序·战斗补头 | 写了 §敌情 没写 §战斗 那一行的，补一行 `§战斗｜交战｜` |
| 稳·次序·战斗挪前、挪后 | 战斗栏（§战斗、§首领、§史诗 起头，连着的 §敌情、§战况、§史诗势、§史诗况，中间空行不算断）写在面板后头或者没紧挨着面板的，挪到头一行 §面板 前头。分支和后半截正文留在手札 |
| 稳·次序·物品挪回、挪回·前头的 | 写在角色后头的 §物品 挪到 §背包 那一行前头；写在面板前头的一行 §物品（跟在别的记录末尾拆开以后落在那里的）挪到后头那一段 §物品、§背包 前头 |
| 稳·次序·面板第二遍 | 面板那一段（§面板｜身份 起头）写了两遍的，后头那一遍拿掉 |
| 记录行的引号 | 记录行里一对半角引号换中文引号。各条规则的栏都不收半角引号（格子把名字抄进 `data-n="…"`），带了的那一行整行认不出 |
| 物品·四栏·带数、物品·四栏 | 漏了品阶那一栏的 §物品 照样出一格，品阶空着 |
| 记录兜底·接在页头 | 一页头一行记录认不出的时候，它跟「开页」那一串标签在同一行，原来的兜底认行首认不到，§ 和竖线原样露在页上 |

改了字的：「浮栏·抄」（上面说的），「物品·带数」「物品」品阶一栏放到 12 个字、类型一栏放到 40 个字（原来认得的照旧认）。

条数：`rules_frame.json` 358 → **374**；卡里的显示正则照这一份打出来是 408 → **424**（“稳”43 + 大框 374 + 认不出纪元算迷宫纪 1 + 扩展页 5 + 样式上图床 1），离五百还有 76。
