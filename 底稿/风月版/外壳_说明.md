# 风月版四张卡的外壳（11-25）

用户 11-25：“风月直接按纪元拆卡，到时候我先把现有的卡替换为迷宫纪，然后发一个月银纪。有什么bug直接修同时检查山铜和纷争，修好了没问题了在把剩下两个发出去。”

四张：迷宫纪（顶替线上那张 1001 年底卡，里头是前传 2 到 1000 年加 1001 年那一局）、月银纪、纷争纪、山铜纪。这里出每一张的“外壳”：提示词的风月切法、显示正则、样式、简介页、快捷指令。纪元内容的世界书是另一支脚本（`fy_lore.py` 那一套）转的，打包时并进来。

## 一条命令

```bash
python -I -X utf8 底稿/风月版/fy_shell.py <迷宫纪|月银纪|纷争纪|山铜纪|全部> [日里全本.json] [--no-push] [--no-check]
```

- 出 `out/发布卡_风月_四纪/<纪>/外壳_<纪>.json`（一张风月格式的卡）、`外壳_<纪>.接口.json`（给并世界书那一支看的）、`样式_<纪>.css`（推上图床的那一份，留着对照）。
- 日里全本默认 `out/发布卡_四纪大框/奥尔德兰_四纪大框_原介绍页_全本.json`。这一纪的常驻、前置词、快捷指令从它取。
- 显示正则和样式读的是日里的源稿：`rules_convert.json`、`rules_frame.json`、`frame.css`，再过跟四纪大框一样的流水线（补认不出纪元的那一条、`mod_page.apply_rules`、`four_era_art.css`）。日里那头改了规则和样式，重出 `rules_frame.json`、`frame.css` 以后再跑这一条就跟上了。开头会拿日里全本里的规则核一遍，对不上只提醒、照源稿出。
- `--no-push` 样式不推图床（地址写 NOPUSH，只看数用）。`--no-check` 不跑规则回归。
- 日里的脚本、源稿、`frame.css`、`rules_frame.json` 这里只读不改。

文件：`fy_shell.py`（总装）、`fy_shell_prompt.py`（提示词）、`fy_shell_rules.py`（显示正则）、`fy_shell_css.py`（样式、推图床）、`fy_shell_descr.py`（简介页）、`fy_shell_check.mjs`（规则回归）、`fy_css_manifest.json`（图床上推过哪几份）、`bench/`（复刻台）。

## 接口（给并世界书的那一支）

- 外壳的 `world_bk` 里只有提示词切出来的常驻条目，都在文件夹 `00·核心运行`：前五条是主提示词的五节（统一运行驱动、骨架、单轮协议、正文输出档位、固定名词），后头是这一纪的常驻（迷宫纪那一张两条：前传、1001 年）。下标、标题、钥匙在 `外壳_<纪>.接口.json` 的「常驻条目」里。
- **日里全本里这一纪的常驻那一条（文件夹 `40·X纪｜常驻与时钟`，正文以 `# X纪·常驻｜这一局在…` 起头）外壳已经带了，并世界书的时候别并第二份。** 标题列在接口文件的「别再并进来」。
- 别的字段（提示词、正则、样式格、简介页、快捷指令、卡名、简介）并的时候不用动。
- 迷宫纪那一张两份常驻的钥匙（跟对方的门控一个路子，认凭证头一行和回复底座上的年份）：
  - 前传：`纪元：迷宫纪(?:[2-9]|[1-9]\d|[1-9]\d\d|1000)年|纪元：迷宫纪｜开局时段：`，深度 2。
  - 1001 年：`(?:<br>|hud-meta">|纪元：|§底座｜)迷宫纪(?:100[1-9]|10[1-9]\d|1[1-9]\d\d)年`，再加老建档页的凭证（头一行没有「纪元：」，认「命途已确认」）。日里那边拿黑名单挡掉带着别的纪元的凭证，这里写成“从头到「命途已确认」中间没出现过「纪元：」”的一段式子（三个状态的自动机展开的，没有前后顾，拿两万条随机串对过）。深度 4：哪一轮回复没写底座，往回再看一条。
  - 旧 HTML 状态栏的回复（老档）认 `hud-meta">迷宫纪1001年`。
  - 要对方配合的：前传的条目和 1001 年的条目也照年份分开醒（对方本来就是这么转的）；两份常驻要是对方那头也转了一份，只留外壳这两条。

## 一、提示词

照 `底稿/状态栏/大框/主提示词/` 的源稿（`prompt_src.py` 读的那一套）切。风月的提示词分在前置提示、后置词和常驻世界书里：

| 放哪 | 是什么 |
|---|---|
| `pre_pt` | 01 角色声明那一大节（8630 字） |
| 常驻世界书五条 | 02 统一运行驱动、03 骨架、04 单轮协议、05 正文输出档位、06 固定名词。钥匙是怎么都中的正则，次序和深度照线上那张卡原来那五条 |
| 常驻世界书 | 这一纪的常驻。月银纪、纷争纪、山铜纪三张各只有一纪，做成怎么都中的一条；迷宫纪那一张两条，各认各的年份 |
| `ptx`、`posttxt` | 前置词、后置词照源稿 |

单纪的卡里说别纪的那几句照这一张改了（`fy_shell_prompt.edits`，对不上就停）：

- 骨架开头“别的纪里哪几行的栏写法不一样……照那一纪的常驻”：单纪的卡写成“这一张卡的局在 X……照 X 的常驻”；迷宫纪那一张写成“前传的局里……照前传的常驻”。
- “凭证没写纪元、上文也没有底座的局，照迷宫纪 1001 年开”：月银纪那一张写 月银纪 1690 年万兽·焚原，纷争纪写 元年执式者，山铜纪写 2 年雨城清查（日里那张卡输入框菜单里的开局口令）；迷宫纪那一张不改。
- “月银纪、纷争纪早年没有命路的局……”：月银纪、纷争纪各留自己那半句，山铜纪、迷宫纪拿掉。
- 固定名词末一句、统一运行驱动里“别的四纪的旅伴条”：照这一张说。
- 骨架里“玩家点一下就填进输入框”换成“玩家照着说或者自己改”（风月上分支点不了）。
- 这一纪的常驻头上【调用】那一行“凭证里写着……就是这一局”换成“这一张卡只有 X，每一轮都用”；1001 年的常驻里“月银纪、纷争纪、山铜纪、迷宫纪前传的局不用这一条”只留前传。
- 迷宫纪那一张的后置词多半句“历史里带标签的旧回复不要照抄”（老档库里的旧回复发给模型还是 HTML）。

每轮常驻的字数（pre_pt 加五条加这一纪的常驻加前置词后置词）：月银纪 36,889，纷争纪 38,144，山铜纪 39,806，迷宫纪前传的局 41,501、1001 年的局 35,669。日里那张同一局的数是一样的东西（主提示词 30,152、后置词 939 加这一纪的常驻），风月这边没有多带。

没接的：用户在平台上自己改过的那几处（身份那一句、成年那两节、九位旅伴体态那一行，11-08 起走 `merge_user_fy.py` 留着的），这一回外壳照源稿出，没有并。迷宫纪那一张要顶替线上的卡，并不并、怎么并等主会话定。

这一回添的：

1. **转换那一组**：迷宫纪那一张顶替线上老卡，“转”（旧 HTML 回复转成记录，132 条，四纪大框 11-23 拿掉了，这里从 `rules_convert.json` 取回来）和“稳”（模型写歪了的兜底）都放两份。另外三张是新卡，没有旧回复，只放“稳”。
2. **一张卡一纪**：别纪的字眼记号、认纪元、传唱战报碑那几行拿掉。这一纪的字眼记号不看日期直接落（日期写歪了页上的字也照这一纪）。页上写齐四纪说法的那几处字（`<span class="lw">`）拆回这一纪的。地图页只有迷宫纪那一张有。专名表（1001 年的词）月银纪、纷争纪、山铜纪三张不带（日里那边这三纪的回复本来也不认它）。
3. **认纪元**：日里是在回复里放一个空记号加一段 `<style>`，风月的回复里不能带 `<style>`，只留空记号（`<i class="sz-era era-moon" data-y="…">`），材质由样式照它换。认不出年份的回复算这一张的那一纪（迷宫纪那一张算 1001 年）。
4. **钟点**：照 11-04 换成空记号，只认到小时（夜里两扇暗一档照旧）。
5. **主角立绘**（11-10 的功能，风月以前没有）：日里那三条往回复里写一段样式，这里换成给主角的对话框、面板上那个人形、检定面板主角那一边挂属性。写预设的挂 `data-pc="族属-性别-体格"`，样式里一个预设一条；自己贴图的挂 `data-pcu` 和行内的大写变量（`--UFC`、`--UAR`、`--UDL`）。
6. **行内 style 的自定义属性换大写**：平台会把 `--v` 改成 `-V`。11-04 只有 `--v --m --h --n --a1` 到 `--a6`，这一个月新添了 `--hv --hm`（队友浮栏）、`--lv --cap --xv --xm --bn --pg`（伟业页）、`--a --b`（检定面板）。名单从规则里现数，规则和样式一起换，往后日里再添新的不用改这里。

这一个月日里新添的显示层都在里头：四纪的材质和字眼、队友浮栏、战斗特效和超凡演出、神力那一行、检定面板、背包图标、伟业页、家业页、魔宠坐骑、扩展页。

## 四、简介页

换成薄壳（两万一千字），门面的页面、数据和图从图床取，认指针，跟日里用同一套门面（`底稿/门面/共用/make_thin.py` 的模板，这里不改它，图床上的门面分支也一个字没动）。风月这一头不一样的三样都只写在卡里这一段薄壳里：

1. **每张卡直接开到它那一纪的书**：薄壳往取回来的外壳页里先塞一小段脚本，等外壳的 `Shell.openBook` 有了就翻开这一纪的书。月银纪、纷争纪、山铜纪各翻自己那一本；迷宫纪那一张翻“此刻”（1001 年那一本），前传那一本从牌桌上进。这一张卡没有的纪（书尾翻下一本、牌桌上选了别的纪、月银纪那几张上点“此刻”那张牌）拦下来，底下出一句“这一张卡里只有 X。别的纪元各是另一张卡，从那一张的简介页进。”牌桌还回得去（大图书馆的入口在牌桌上）。
2. **没有“点一下填进输入框”**：确认页和接续旅印里那一枚拿掉，“复制”做成主钮，说明换成“复制下来，回到聊天的输入框里粘贴，再发送。”
3. **图床连不上时的退路**：一页简式建档（`lite_page.py` 的那一页），只留这一张卡里的纪，拿掉填输入框那一枚。日里那一页里有平台的指令名，风月的屏蔽词不让带。

### 门面要是想做得更干净（交主会话定，没有动）

薄壳里那一小段是从外头拦的，外壳往后改了类名、按钮的写法，它就失效（失效了也只是退回日里的样子：先看见牌桌、多一枚点了没反应的“填进输入框”）。要它不靠拦，得改门面的外壳 `底稿/门面/小样_外壳/shell.js`（日里也在用，别的子任务眼下正改着这个文件，我没碰）。薄壳已经往 `FRONT_CFG` 里带了三格，外壳认了就行：

- `FRONT_CFG.nofill`：`const inRili = window.parent && window.parent !== window;` 那一行前头加 `!CFG.nofill &&`。外壳里本来就有不在框里时的那一套写法（只给“复制”），这样风月直接走它。
- `FRONT_CFG.start`：外壳装好以后（`window.Shell = Shell;` 后头）`if (CFG.start && (CFG.books[CFG.start])) openBook(CFG.start);`。
- `FRONT_CFG.only`：收 `goto` 那一句、`#openBook` 的点击、`nowCard` 的点击三处，书不在 `CFG.only` 里就不开，出一句话。牌桌（`index.html`）上别纪的牌要不要压暗，另说。

日里的薄壳不带这三格，改了对日里没影响。

## 六、验过什么

- **规则回归**（`fy_shell_check.mjs`，每回出外壳都跑）：
  - 甲、转法：风月的规则跟同一份日里写法逐条回复比，显示、存库、存了再显示、流式切刀四路，一字不差。迷宫纪 79 条样本（含旧 HTML 回复 27 条）、2641 刀；另外三张各 52 条、1704 刀。问题 0。
  - 乙、改法：这一张卡的规则跟日里原样的规则比（只拿这一纪的样本），除了平台差别（`<style>`、大写变量、点击属性、钟点记号、主角立绘挂的属性、字眼拆回这一纪）一字不差。问题 0。
  - 一条回复显示一遍最久三十几毫秒。
- **常驻的钥匙**（`fy_shell_prompt.selftest`）：前传、1001 年两条拿十一种凭证和回复试过，各醒各的。
- **复刻台**（`bench/fy_shell_bench.py`，用的是 11-04 照风月前端代码搭的 `tools/rili_bench/static_bench_fy.mjs`）：电脑宽 1920×945、手机宽 390×844，一纪一组，迷宫纪另跑前传、旧 HTML 回复、前传和 1001 年混在一屏。截图在 `out/发布卡_风月_四纪/复刻台/`。看到的：四纪的框、两扇、楣、座、材质、地名牌、页签都出来了；队友浮栏、咏唱框的法阵、检定面板、面板的六维盘、伟业页的书、背包的格子都在；迷宫纪那一张前传的回复换成了浅色委托单的材质，混在一屏时跟着最新一条。

## 七、没在真页面上看过的

1. 整张的样子：只在复刻台上看过，复刻台没有平台自己的样式。
2. `@import` 的样式一份 1.2 到 1.4MB，只钉了 `cdn.jsdelivr.net` 一个镜像。载得慢的时候回复先是没样式的一片字；这个镜像连不上就一直没样式。探针只测过通不通，没测过慢的时候什么样。
3. 新添的行内大写变量、`<s>` `<del>` `<u>` 这几个当壳用的标签（浮栏、检定面板用的）过不过得了平台的标签过滤。照 11-04 读的前端代码它们在放行的名单里。
4. 队友浮栏的 sticky、战斗特效的动画、重击震一下，在风月的滚动容器和虚拟列表里稳不稳。
5. 主角自己贴的图：行内 style 里写 `url('…')`，平台重写行内 style 的时候留不留得住，没测过。预设那一路不靠它。
6. 迷宫纪那一张 703 条正则、前传和 1001 年换材质的那几条 `:has()`，手机上卡不卡。
7. 简介页薄壳在风月的框里整页换上去（`document.write`）行不行。探针测过跑脚本、取图床，没测过这一下。
8. 真模型写得对不对：这一回没有试写。

## 八、要用户在风月上先看一眼的

1. 导入以后看编辑页：正则条数（迷宫纪 703，另外三张 439），样式格是不是只有一行 `@import`，常驻那几条在不在。

## 九、要主会话或用户定的

1. 这一纪的常驻外壳带了，对方并世界书的时候别并第二份（见“接口”）。
2. 用户在平台上自己改过的那几处提示词和旅伴体态，这一回没并。
3. 三张新卡的卡名和简介是草稿，封面、背景图照的是线上那张。
4. 样式只钉了一个镜像。要稳一点可以再加一行别的镜像的 `@import`（两份都载，下载和样式重算翻倍），或者样式格里留一小段兜底（没样式时先把各页和页签藏起来，只露正文）。眼下照“只留 `@import`”做的。
5. 门面外壳认不认 `start`、`only`、`nofill`（见第四节末）。
6. 迷宫纪那一张 1001 年没有一键开局的快捷指令（要凭证）。图床连不上时走薄壳里的简式建档。
