# 风月版｜世界书切纪、门控转换、对账、打包

这一份是“世界书”那一半的说明（11-25）。外壳那一半（提示词切法、显示正则、样式、简介页）见同目录 `外壳_说明.md`。末尾「进度」一节是接手以后一段一段记的流水。

用户定的：风月按纪元拆四张，迷宫纪（顶替线上那张 1001 年底卡，里头是前传 2 到 1000 年加 1001 年那一局）、月银纪、纷争纪、山铜纪。先发迷宫纪和月银纪。

## 一、东西在哪，怎么重打

脚本（都在 `底稿/风月版/`，只用标准库，仓库根上跑）：

| 脚本 | 管什么 |
|---|---|
| `fy_gate.py` | 门控转换：日里一条的“触发词表、触发方式、黑名单”转成风月的一条 RE2 钥匙。直接跑是自测 |
| `fy_msgs.py` | 一张卡的局里会出现的消息：凭证（从 `slim_card.cases` 来）、回复的底座、逐年扫的那一串 |
| `fy_lore.py` | 切卡：每张带哪些条，逐条转钥匙，出 `世界书_转换.json`、`转换清单.md`、`转换报告.json` |
| `fy_sim.py` | 对账：同一段文字，日里的判法和风月的钥匙醒的结果逐条比，出 `对账.md`、`对账报告.json` |
| `build_fy_era.py` | 打包：外壳加转好的世界书，出 `导入/` 里的小底卡、世界书几份、整卡、`导入说明.md`、`清单.json` |

输出在 `out/发布卡_风月_四纪/<纪名>/`（不进库）。

**重打一条命令**（全本重打了、源稿改了都是它；四张一起一刻钟到二十分钟，大半花在对账上：山铜纪一分半、迷宫纪两分钟、月银纪四分半、纷争纪六分钟）：

```
python -I -X utf8 底稿/风月版/build_fy_era.py --all
```

- 只打某一张：后头写 `maze`、`moon`、`strife`、`bronze`（也认纪名）。
- `--all` 是先转（`fy_lore.py`）、再对账（`fy_sim.py`，带锚的消息上有不一样的就停）、再打包。不加 `--all` 只打包，读现成的 `世界书_转换.json`。**外壳重出了、世界书没动，不加 `--all` 重跑一遍就行。**
- 全本不在默认的位置：`--src 全本.json`。三张老纪卡多带底卡的哪些文件夹：`--base core|std|all`（见第三节）。
- 对账嫌慢、调试的时候：`--step 50`（逐年每五十年取一年）。正式打不加。
- 凭证的样子、主线的名字、潮汐的写法都是每回从 `slim_card.cases` 现取的，本体改了这里跟着变，不用手改。

  - 另外三张，底卡只带“规则核”那十五个文件夹里、这一纪的局里醒得了的（`--base core`：00 核心运行、01 建档、05 数值位阶、06 命路、07 命星、08 种族寿命、09 职业魔法、10 货币装备、18 怪物生态、19 旅行医疗、20 队伍关系、21 委托结算、90 到 92 功能）。底卡后头的通用规则（神域、七十二域、势力家业、魔宠坐骑、咏唱、算式）照门控带。

## 四、门控转换的规矩（`fy_gate.py`）

日里的判法：一条消息里，触发成立（任一、或者两个词都中），而且黑名单一个不中。风月一条只有一个 RE2 正则，没有黑名单，没有前后顾。做法是把每个词按最外层的 `|` 拆成支，分成四类：**锚**（认底座或凭证头一行的“纪元：某纪N年”）、**日期**（锚后头还带季月旬）、**开局**（“开局时段：…”）、**题**（话题词、潮汐里的页名主线名）。然后：

1. **纪元钥匙拿掉**。单纪卡里“认这一纪”的那个词恒真，拿掉，只剩话题（月银纪 239 条、纷争纪 507、山铜纪 256、迷宫纪 18）。两个词都恒真的写成怎么都中（三张老纪卡各 2 条）。别纪的黑名单在这张卡里碰不上，也拿掉。迷宫纪那一张前传和 1001 年是两局，这一层不拿。
2. **年份窗**。锚拿这张卡里会出现的全部纪元年份逐个试，变成年份的集合；黑名单里的年份从集合里减掉；集合再写回一条紧凑的年份正则（一千两三百条到一千八百条）。“这个人哪一年以后不在了”就这样反过来成了“只在哪些年醒”。碰到卡的年份上限的那一段当“往上都算”，写到五位数。
3. **自己报年份的开局**（第二十二张那种“开局时段：某某｜年份：N”）：凭证里年份那一格跟纪元的年份是同一个数，并进年份窗。
4. **两支**。“同时满足甲和乙”写成 `甲[\s\S]*乙|乙[\s\S]*甲`。
5. **行内否定**（碑、史诗、遗迹、旅伴这一类“自己那条主线的几幕里不醒”的；迷宫纪 72 条、月银纪 83、纷争纪 180、山铜纪 126）。黑名单里的潮汐（页·主线·一幕）写成“底座那一行从年份往后不含这几样”，开局时段写成“凭证头一行的开局时段不是这几样”，泛的“开局时段：”写成“年份后头不是凭证”，带日期的写成“年后头不接这个日期”。
   - 话题可以在底座那一行里（地点那一格、潮汐里的主线名），也可以在后头的行里。在行里的时候，题后头剩下的半行照“读到黑名单潮汐的哪半截”接着挡（`Avoid` 记这个位置）：`犁的年月·机兵化犁·收束` 认，`…·一幕` 不认。
   - 凭证的正文里写着“主线「页·主线」的开局”，黑名单里整条主线的潮汐也中它：这张卡认得的凭证里中了的，那几种开局时段一起挡。
   - 这一类只写“锚在前”那一支：一条消息之内题总在锚后头（底座是回复的头一行）。
6. **潮汐那一路**。第一个词里除了年份还列着潮汐（`崛起·(?:环山北口|王仓|…)`）的：年份不在窗里、靠潮汐认的，写成“黑名单以外的年份，同一行里有这个潮汐”，再跟题拼。题在潮汐后头（正文里）、在潮汐前头（同一行的地点那一格）两边都写（五六百条到七百条）。黑名单正好是这个潮汐往后延的（`…·鸦旗·收束`），写成“潮汐后头不接那一截”。
7. **两个词中的是同一处字的**单列一支：题落在潮汐的字里（主线名里带着人名），或者题本身就是带着潮汐的一截（`犁的年月·擎天之心·`）。
8. **拆两条**。只认玩家裸打的那一支（日里写成“前头没有 §底座”的前后顾）风月分不出消息是谁说的，拆成两条：一条只扫玩家认话题，一条只扫回复认 §预载 那一行。
9. **整段没有不许的锚**（迷宫纪 419 条）。底卡 1001 年的条目没有锚要求、可黑名单挡着前传的年份：写成“整段文字里这一纪的锚只许是某些年份”。
10. **书目**（大图书馆那三十来条）：一厅一条、每本书各认各的年份，拆成“年份窗加这几本书名”几支。
11. **前后顾**。落在一支末尾的 `甲(?!乙)` 改成“甲后头是结尾或者不是乙开头”；“某几个人名里的一个(?!某字).{0,16}另一个”这一种把那个否定摊进间隔里（`spread_lookahead`，自测里拿三万句随机的话跟原写法比过）。改不了的不进卡、列清单，这一回四张都是 0 条。

钥匙出来以后过 `re2_problems`：前后顾、反向引用、过一千的重复、RE2 不认的转义、给汉字加的转义，有一样就不进卡。这是照 RE2 的规矩查写法，**没有拿真的 RE2 引擎跑过**（本机没有）。

## 五、对账（`fy_sim.py`）

同一段文字，日里的判法（`slim_card._hit`：触发加黑名单）和风月的钥匙（Python 的 re）各判一回，逐条比。拿这几样消息比：

- **零** 原样的凭证和回复，什么都不接。这一纪每条主线的凭证、五种幕的回复、自己报年份的凭证，迷宫纪另加 1001 年的两种凭证和回复。
- **甲** 上面那些后头另起一行接条目自己的字，一个字一回；回复再接一行 §预载。
- **地** 话题写在底座那一行的地点那一格里、正文不再提：每条主线的一幕和收束、每一页的自由。
- **乙** 逐年扫（月银纪 1 到 10100 年、纷争纪 1 到 11050、山铜纪 2 到 960、迷宫纪 2 到 1030）：每年一条回复、一条自己报年份的凭证，原样比一回、接上全部的字再比一回。认年份的条目一年不落，不认年份的每 173 年取一年。
- **丙** 玩家裸打的一句，只有条目自己的字。

另核一遍切卡：没带进这张卡的条目，照日里的判法在这张卡的消息里醒不醒得了。

**结果（11-25，四张）**：

| 卡 | 比了多少回 | RE2 不认 | 带锚的消息上不一样 | 裸打一句别的不一样 | 没带可日里醒得了 |
|---|---|---|---|---|---|
| 迷宫纪 | 1670 万 | 0 | 0 | 0 | 0 |
| 月银纪 | 3190 万 | 0 | 0 | 0 | 0 |
| 纷争纪 | 5670 万 | 0 | 0 | 0 | 0 |
| 山铜纪 | 1170 万 | 0 | 0 | 0 | 0 |

不算毛病、只记数的三样：

- 裸打的一句上日里不醒、风月醒：纪元钥匙拿掉的条目本来就该这样（日里要等回复里写到才醒，风月玩家一提就醒，快一轮）。迷宫纪 18 条、月银纪 239、纷争纪 509、山铜纪 258。
- 1001 年的老凭证（没有“纪元：”那一行）上同样的情形，118 回。
- 没有 §底座 的“回复”里提到话题：拆两条的条目日里醒、风月不醒。回复照骨架都有 §底座，这种消息不该有。

**11-25 接手时对账改了什么（免得往后看不懂为什么数变了）**：

- 原来的对账每回都把条目自己的字另起一行接在消息后头，没拿原样的消息比过，也没试过话题写在底座那一行里。添了“零”“地”两组以后，旧钥匙在山铜纪 69 条、月银纪 89 条、纷争纪 41 条、迷宫纪 10 条上日里醒、风月不醒（碑、史诗、遗迹、旅伴：话题就写在潮汐里的主线名上，或者写在地点那一格里，钥匙把整行吃完了才去找话题）。这是真毛病，照第四节第 5、6 条改了。
- 条目的字里是潮汐一截的（`页·主线·`）不再当话题另起一行接。潮汐只写在回复的底座上，玩家不会单打它；把它接在别的主线的凭证后头是造不出来的消息。它醒不醒由“零”那一组比。交接时挂着的 #3642（擎天之心）、#3066、#3067（席恩）那几回差别就是这种造出来的消息上的。
- 拿去写地点那一格的只收单说就中的字（“某某.{0,16}某某”里拆出来的一个人名不算话题）。
- “某某.{0,16}某某”这种正则的题，拼几句真配得上的（甲和乙）接上去比。

## 六、知道的不一样、没解决的

逐条都在各张 `转换清单.md`「转了、可有地方不是原样的」一节，这里说类：

1. **只写“锚在前”的**（行内否定那一类全部，加年份窗太长的；迷宫纪 72 条、月银纪 80、纷争纪 180、山铜纪 126）。风月把往回几条消息连起来扫，要是玩家的话排在上一条回复前头，这些条目要等回复里写到才醒。这跟日里一样（日里也是回复里写到了才醒），不比日里差。
2. **正则的题只认底座那一行以后**（“两个人名挨着”那一种，迷宫纪 42 条、纷争纪 37、山铜纪 51）。两个人名挨着的句子只会在正文里，不会在地点那一格里。
   - 连带一样没照搬的：日里那边这种正则会跨着地点那一格和潮汐去配（地点写了一个人名、十六个字以内的潮汐主线名里又带着另一个人名，月银纪 #3315 薇丝拉之路就配得上）。这是日里那边碰巧，风月不认，对账也不拿它比。
3. **没有锚的词带着年份黑名单**（月银纪 #3066、#3067 席恩两条）：两个词都不带锚、黑名单挡年份。风月写成“窗里的年份在前、潮汐和题在后”；日里那边玩家裸打一句“万兽·九步冷泉·…席恩”也醒，风月不醒。潮汐玩家不会裸打。
4. **题的字面接得上黑名单潮汐的半截**（山铜纪 #3642 一处）：底座那一行里不单认它，这一条另有“题本身带着潮汐”那一支管着，对账是 0。
5. **黑名单里纪元交界那一个月的锚没挡**（纷争纪 #139、#548、#553 三条底卡条目，黑名单是“纪元：山铜纪”）：这三条只扫玩家的话，玩家的话里不会有山铜纪元年的底座，对账是 0。
6. 风月是把几条消息连起来扫的，对账是一条一条比的。连起来以后，上一条回复的锚配这一条玩家的话，条目会比日里早一轮醒；跨年、换主线的那一两轮，旧底座还在往回看的范围里，会多醒一两轮。
7. 加权条目没进卡（第二节）；三张老纪卡没带底卡的 1001 年世界内容（第三节）。

## 七、导之前要知道的风险

- **分份导累计到这么大存不存得住，没有在风月上确认过。** 探针第四轮一份份导到第五份才碰上 5000 条的线，前四份（3870 条、连底卡 22MB 上下）每一份存没存住当时没有回话。迷宫纪这一张是 4008 条、18.7MB，只有分份这一条路。
- **钥匙比探针试过的长。** 探针里导进去过的最长 1225 字；这一回迷宫纪、山铜纪各有 37 条过 1200 字，最长 2037 字（迷宫纪“这一段旅伴之间”那十二条，黑名单里列着同一页十二条主线）。平台收不收、跑不跑得动没试过。先导迷宫纪正好试这个。
