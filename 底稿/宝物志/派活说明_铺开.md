## 二、一条长什么样

- **标题**：照分份表抄，一个字不改。`## X纪·残权｜…`、`## X纪·神器｜…`、`## X纪·宝物志｜…`，X纪只有月银纪、纷争纪、山铜纪、迷宫纪四个（前传和 1001 年都是迷宫纪）。规则写 `## 奥尔德兰·规则｜宝物·…`。管一段年份的末尾写年份窗（665 到 1000），1001 年的末尾写（迷宫纪1001年），管整纪的不写。
- **文件夹**：残权、神器、名录写 `65·X纪｜宝物志`；规则写 `10·货币、装备与制作`。
- **骨架**照样稿，分四种，小标题跟着这一条自己的东西走，别一份里条条同一套：
  - 残权 1001 年那一条：【调用】、是什么（出自哪一尊，那一尊的名字只给 AI，十六尊里的除外）、样子、怎么上来的和经手的人、眼下在哪、本事｜Unique 三条（各配一行数值）、身上长出来的、对上它、扶正、锁。
  - 残权露面那一窗的条：【调用】、是什么、样子、露面那一回、这一段里会出的事（各时段，只取底座年份所在的那一段）、本事三条、身上长出来的、对上它、扶正（这一窗的神怎么应，照定数第三节第 3 条）、锁。写到窗的末年为止。
  - 神器：【调用】、是什么、样子、谁的、本事三条、正史里在谁手里（各时段）、神倒下以后去了哪里（活着的神不写）、对上它、锁。七神圣物那五件加一段“露出来的线索”和“借一回”。
  - 规则、名录：【调用】、是什么、几条规矩或者账（照分份表要点），写法，裁定锁。
- **长度**：残权 1001 年那一条 1600 到 2200 字，别的窗 1200 到 1800 字；神器 1800 到 2600 字；规则 2500 到 3200 字；名录 3000 到 3800 字（1001 年那一条到 4500）。写不满的别注水，记进备注。
- **只给 AI 的段**：整段的，小标后头头一句写“只给 AI。”；一句的，句首写“只给 AI，”。整条只给 AI 的（四执政那一条、失钥），在【调用】里写明。哪些东西只给 AI 照定数第八节第 3 条。
- **门控**（同时满足，范围 用户与助手，深度 2，句式一个字不差照下面）：
  - 月银纪：`〔月银纪·正则〕` 加一条触发正则，整纪的黑名单 无。
  - 纷争纪：`〔纷争纪·正则〕`。年份窗的黑名单抄 `底稿/真龙/稿/Z06_单条的龙和几对.md` 里墙西的石脊那一条（两段都要：底座年份那一段，和“开局时段：第二十二张｜年份：”那一段），只挡窗以前的年份，到纪末的不挡后头。
  - 山铜纪：`〔山铜纪·正则〕`，黑名单抄 `山铜纪/补卷/补卷_73_新料_律法志.md` 里带年份窗的那几条。
  - 前传：`〔迷宫纪前传·正则〕`，黑名单抄 `迷宫纪前传/补卷/补卷_68_黑潮新仗_上.md`（两段，后一段是“开局时段：空白委托｜年份：”），挡窗以前的年份。
  - 1001 年：`/(?:<br>|hud-meta">|纪元：)迷宫纪(?:100[1-9]|10[1-9]\d|1[1-9]\d\d)年/` 加一条触发正则，黑名单 无。
  - 规则（R 份）：不挂纪的钥匙，触发写一两条正则，黑名单照分份表（挡月银纪写 `/(?:<br>|hud-meta">|纪元：)月银纪/`，再挡纷争纪10993年以前的写法照纷争纪那一条两段）。范围、深度同上。
  - 样子照这一条抄：`> 条目设置：文件夹 65·迷宫纪｜宝物志，触发（同时满足）〔迷宫纪前传·正则〕、`/触发正则/`，黑名单 `/…/`，范围 用户与助手，深度 2。`
  - 触发只挂这一条自己的专名和问法：正名、俗名、扶正后名，它独有的样子（“鞍后座上没人”“一直鼓着的黑帆”），那一尊的名字配“的残权”“留下的”。**“残权”“残权遗物”“封印院”“灰斗篷”“扶正”“神器”这几个全卷常见的词各件的条不许单挂，只有 R 份挂，而且要写成问法。** 样稿里“封印院里那一(?:件|把)”这一支也不许，五十件会一起醒。两三个字的俗名先跑 `python -I -X utf8 底稿/神域/tools/trig_freq.py`（用法看它头上）数一数全卷出现几回，几十回以上的配上限定写成问法。一条触发里单字的分支不许有，量词不过二十五个，不套量词。
  - 年份窗写完逐年试：纷争纪 `python -I -X utf8 tools/yeartest.py <文件>`，月银纪 `tools/yeartest_moon.py`，山铜纪和迷宫纪 `tools/yeartest_era.py <文件> 山铜纪 947`、`… 迷宫纪 1000`，窗两头各差一年的都要对。

## 三、写什么、不写什么

- **卡里现成的一处不改**：名字、年份、事件、锁。神谱各尊那一条、七十二域、补卷_77 九件、碎碑矿坑主线、前传那几张委托写过的不重写，接上去；对不上的记进备注，不替卡改，也不绕着写。
- **定数里的一处不改**：出自哪一尊、样子的抓手、露面和收回的年份、经手的人、1001 年在哪、扶正要做的事。定数没写的细处你来补（封法、看守的规矩、这一回出了什么事、一句只有拿它的人说得出的话），补的标（★），要紧的记进备注。本事三条照定数那一行的抓手写成三条，配数值，数值只写启源那一档（#583 承载律），只用卡里有的词。
- **只往回写**：露面那一窗的条写到 1000、947、纪末为止，往后它去了哪里一个字不写，也不写“往后：只给 AI 对照”那一行。1001 年那一条写得出它从露面到 1001 年的全部来路。
- **往大里写**：一件残权是一尊神死后剩下的力气，拿着它的人看见的是看得见的魔法，天亮晚一刻钟、一城的火往一处倒、一支队伍整群拐弯。逆位的毛病也写成看得见的事，不写成心理描写，也不写成规则怪谈。克制只放在锁里。
- **残权不是魔神**：打碎一件不算杀了一尊，祂不复活，东西不说话、不显灵（样稿锁）。拿着残权的人不写成魔神附体。
- **传奇怎么死**：拿着残权的传奇照旧只死在“什么杀得死传奇”那四样手里；残权第三条算不算神性，照定数第二节第 7 条（主会话定了以前，写手照倾向写，记进备注）。
- **名字**：叙述和 NPC 叫俗名为主，封印院的卷、圣堂的人叫正名，扶正以后叫扶正后名。1001 年那一条里，NPC 叫不出那一尊的名字，十六尊里的叫得出（定数第二节第 8 条）。
- **玩家在场**：照 CLAUDE.md。露面那一回、在逃的那几十年、扶正那一件事，玩家碰得上的就写他在场能做什么、做了会怎样、要付什么，不写拦不下、拿不到。锁里“不作掉落、买卖、奖励”管的是主持的模型，玩家要拿到写成剧情的路。
- **指本体**：只指全纪都醒的条（规则、势力、国史、地点、战役、`奥尔德兰·神域｜X之域`），写条目全名，不加「」。神谱是另一包，不指；补卷_77 是人物条和名器条，不指；主线、旅伴、人物条不指。要用的事写进句子。
- **典故**：定数每一件写了借的是什么。照写作口径借样子不借名字，卡面里不点神话和经书里的名字（米达斯、耶利哥这些一个也不出现），备注里可以写。
- **别的作品**：原神原文只学做法，不搬句子，写完跑 ngram。
- **起名**：能不起就不起，定数里的人都不起名。要起的先跑 `python -I -X utf8 tools/namegrep.py 名字…`、`python -X utf8 tools/collide.py 名字…`，报无才用，再 `python -X utf8 tools/namepairs.py 名字…` 看有没有太像的，然后看 `底稿/宝物志/起名登记/` 里别的份和规划份登记了什么，最后写进 `底稿/宝物志/起名登记/<份名>.txt`（一行一个）。器物的名字这一轮不许另起，定数里有。

## 四、口气

照样稿：叙述者在场，肯交代，先说是什么、谁的、哪一年、在哪、出了什么事；一件东西后头跟着一件事；一条里有几处小事是活的（看守进去换盐要蒙眼，矮人一年往酒囊里倒一回酒）。

样稿自己有口癖，铺开别跟着长：

- **“那一X”“这一X”**：一条里至多三四处，成串的换成名字、俗名，或者省掉。
- “谁也……”“看见的是真的”这一路收尾一条至多一处。“不写成甲，也不写成乙”只许在锁里用一回。
- “身上长出来的”别条条写成“一天比一天……，最后……”一个架子，换着写，有的从一件事写起，有的从旁人看见的写起。
- 「扶正」那一段别条条写成“要有一个拿着它的人，……，再送到……的神殿”。要做的事放在前头，写成一件看得见的事，送去神殿那一句一份里写一两回就够，别的条一句带过。
- 一份八件东西最容易写成一张名单。每一件至少要有一件演得出来的事（露面那一回、在逃那几十年里的一回、封印院里那一间屋出过的一回事）。

咏唱只在该有词的地方写（封词、收场的共祷、扶正时立的誓），全本照咏唱口径四拍、末句落【术名】，一条里全本不过一段；白话短本一口气说完。

## 五、写完自查（都要跑，结果写进备注）

在仓库根上跑，Windows 用 `python`：

```
python -I -X utf8 tools/cardscan.py <你的文件>            # 合计要 0
python -I -X utf8 tools/check_people_v7.py <你的文件> .   # 硬问题要 0
python -I -X utf8 tools/authormark.py <你的文件>          # 合计要 0
python -I -X utf8 tools/regex_check.py <你的文件>         # 见下
python -X utf8 tools/ngram.py <你的文件> 语料             # 跟原神语料撞六字串的改掉
python -I -X utf8 tools/baguscan.py <你的文件> --lines    # 一类一类看命中的句子
```

regex_check 眼下有两处认不了宝物志（规划份没改脚本，主会话会改）：文件夹上限还是 64，65 会报“文件夹跟标题的纪对不上”，这一类硬问题照数记进备注，别的硬问题要 0；`## 奥尔德兰·` 起的标题它不数，R 份跑出来会报“标题和条目设置数目对不上”，R 份自己写一段 python 把每条触发、黑名单的正则 `re.compile` 一遍、数一数量词，结果写进备注。cardscan 只看四纪的标题，R 份的正文另用 check_people_v7 和 authormark 查。

再加年份窗的逐年试（第二节末尾）。然后不靠脚本对三样：定数（名字一个字一个字对，年份、出自哪一尊、1001 年在哪、扶正要做的事）、只给 AI 的东西有没有漏到明面（那一尊的名字、冠、沉灯会、复古邪派、下落不明的实在位置）、有没有写出窗以后的事。

## 六、交什么、别碰什么

- 稿子写进 `底稿/宝物志/稿/<份名>_<名>.md`（分份表里写了文件名），条目一条接一条。C4 的定局之剪从样稿抄，只做定数 Q51 那一行写的改动。文末 `## 设计备注（不进卡）`：条目表（标题、纪和窗、门控、文件夹）、跟本体哪几条接、新起的东西、拿不准的。
- 备注写 `底稿/宝物志/备注/<份名>.md`：自查各项的数、八股查出来改了什么（举几处改前改后）、卡里对不上的、定数里没有而你补了的、没写的和缘故。
- 只动你名下的稿子、备注、起名登记那一个 txt。定数、样稿、方向稿、清点、卡的源稿、别的份的文件一律不改。不提交、不推送、不起后台任务、不再派子任务。
- 临时文件放你自己的 scratchpad 子目录。写文件用 Write、Edit，别拿 bash heredoc 写带反斜杠的东西。
- 最后回话十行以内：写了几条、多少字、自查各项的数、要主会话定的事。
