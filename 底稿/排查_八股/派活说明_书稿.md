# 书稿八股排查｜派活说明（11-24 夜）

用户原话：“记得拿skill那些排查扫一遍看看有没有八股，套话，废话，没有意义的故弄玄虚之类的情况。已有的书籍也扫一下，有的话就修。”

“已有的书籍”是门面大图书馆的书稿，`底稿/门面/第二轮/大图书馆/书稿/` 一百九十六个文件，约一百零六万字，是这个世界里的人写的书（教本、戏本、游记、童话、账簿、祷文……），玩家在介绍页的大图书馆里翻着读。你是其中一份的排查人：把名下的书一本一本读完，照口径判，有毛病的修，没毛病的不动。

## 一、先读

1. `底稿/排查_八股/口径.md` 全文。拿不准的时候照它指的路读四份 skill 的原文（三份 zip 解到你自己的 scratchpad 子目录），western-fantasy-prose 的第七节「短篇与世界内读物」跟书稿最对口。
2. 根目录 `CLAUDE.md` 的「写作口径（必须守）」里「卡面」（标点、禁词、东方语感的字）、「台词」两节。书稿当初照它写的，你改出来的句子不能带进禁用的标点（——、—、；、…、！）和禁词。
3. `底稿/排查_八股/书稿分份.md` 里你那一份的书单。

## 二、怎么查

1. 先跑一遍数数：`python -I -X utf8 tools/baguscan.py <书稿路径> --lines`（仓库根上跑，可以一次给几本）。命中不等于有错，是给你指地方。
2. 一本一本从头读到尾。这些书大体是写得好的，有叙述者、肯交代，别为了交差硬改。要找的是：
   - **同一个姿态用了又用**：一本书里“站了很久”“看了一会儿”“一句话也没说”“没有人知道”“他没有回头”出现五六回，卷卷收在一个人不说话、一样东西搁着上。留最要紧、后文接得上的一两处，别的换成那个人做了什么、说了什么，或者把那件事的下落直接说出来。
   - **谜语人**：称号、代称指到篇外，谁对谁做了什么要读的人猜；一件事悬着，这本书里没有下落，卡里也没有。书里的人可以有不肯说的事，可读的人得知道他不肯说的是哪一件。
   - **废话**：说清了的事再解释一遍，段尾补一句感悟，看得见的事再说一遍，“换句话说”“也就是说”。
   - **套话**：不是……而是……成串，仿佛、似乎，三连排比，身体反应。
   - **骨架**：每卷、每段一个收法；句子一连十句一个长度；单句成段成串；每个人说的是同一个意思。
   - **改过头的克制**：通篇短句、情绪抽干、处处留白、把大事写小写土。这一批书最可能有的是这一样。
   - **翻译腔、假大空**：照口径第一节第 5 条。
3. 判这一本：没毛病（不动）、轻改（几处）、重改（一卷以上要重理）。重改以前先在备注里写一句为什么。

## 三、怎么改

- 照口径第二节：把那件被顶替的事做了，只换同义词等于没改；意思不加不减，篇幅大致持平；实物从这本书自己和卡里现成的设定取，卡里没有的不编，记进备注。
- 删掉一句空话可以，别拿一句新编的俏皮话、新编的细节去换它（头几份有人把“极光没有第二次”换成了自己编的一句，退回去了）。要换就换成这本书上下文里已经有的事。整段整卷重复的别删成一句，记进备注留给主会话定。
- 一处一处拿 Edit 改，不拿脚本批量换。
- 书各有各的声口（孩子的童谣、书记的账、老兵的口述、学者的笔记），改完还得是这个人在说话。歌、诗、祷词、誓词、童谣的叠句是有意的重复，不算毛病，原文只许换个别用词，行数和格式不动。
- 这本书的作者本来就话少、冷的，冷着留，只收他重复的姿态。
- 改完回头看有没有改过头（口径第一节第 7 条）。

## 四、不许动的

- 头上的 `> 厅｜`、`> 作者｜`、`> 成书｜`、`> 装帧｜`、`> 篇幅｜` 几行，`#`、`##`、`###` 标题行，扉页、藏书票、目录、署名落款的格式。
- **所有 `〔…〕` 记号整个不动**：`〔图…〕` 插图标记（图是照这一行画的，七百多张已经画好审过了，一个字不能改）、`〔正文取自…〕`、`〔注N〕`、`〔剧透〕`、`〔涂黑〕` 这些。插图标记前后直接描写画面的句子，里头的数、样子、谁在哪一边不改。
- 事实、年份、数、人名地名专名、书名、谁对谁做了什么。发现事实对不上、年份打架，只记进备注，不改。
- 不加章节、不删章节、不调章节次序。
- 文件名不改。别的文件一律不碰，不跑 `build_lib.py`，不提交，不推送，不再派子任务。临时文件放你自己的 scratchpad 子目录。

## 五、改完自查

```
python -I -X utf8 tools/baguscan.py <你改过的书> --lines      # 跟改前比一比
git -C . diff -U0 -- <你改过的书> | grep -E "^[-+](〔|#|> )"   # 应当没有输出：记号、标题、头上那几行没动过
git -C . diff --stat -- 底稿/门面/第二轮/大图书馆/书稿/        # 只该有你名下的书
```

再看一眼 diff，确认没有带进禁用标点（——、—、；、…、！）。

## 六、交什么

备注写 `底稿/排查_八股/备注/书稿_<份名>.md`：一本一行，判了什么（没毛病／轻改／重改）、改了几处、主要是哪一类；全份挑五六处写出改前改后；拿不准没动的；顺手发现的硬伤（只记不改）。

最后回话十行以内：读了几本、各判了多少、一共改了多少处、有没有要主会话定的事。
