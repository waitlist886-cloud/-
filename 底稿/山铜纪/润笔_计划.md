## 二、润笔：改什么

默认轻润色。只改认得出毛病的句子，好句子不动，不为改而改。事实、年份、人名、数目、因果、谁做的谁知道、锁的力度一样不变。

要收的毛病，照这个次序找：
1. 指代不清。比如第一条开局“七十多年里帐子换成了房子，墙是地基底下挖出来的烧黑的白石……营没有墙”，前一个墙是房子的墙，后一个是营的围墙，读着打架，改成“房子的墙……营没有围墙”。主语丢了、两个人谁说的分不清、“他”指两个人，都照上下文补实。
2. 三样并排。看意思不看标点，没有各自信息的第三样删掉或者并掉，写成有关系的话。真是三样各管一事的（三个步骤、三条约）留着。
3. 同一个句架子连用。一段里、一条里、相邻几条里，句子一个形状，收尾一个样子（一句格言、一句冷观察、“两种说法一起传”出现两回、“说，‘……’”连着几段收尾），换着写。旅伴条的关系、关系推进、破裂、正史里的下场、坎，同一份里几个人别一个架子。
4. 那一X 口癖。指着一件读者知道的事（那一夜、那一年、那一本书、那一位）留着。只当冠词用的，一句里叠了两三个的，改成“那”“这”或者不要（那一顶灰帐子改那顶灰帐子，那一块山铜板改那块山铜板）。不追数，读着顺为准。
5. 故弄玄虚。意思藏着、要读者猜的句子，照 chinese-prose-register 把交代说出来，一段至多一处余韵。给 AI 看的东西写明白，只给 AI 的那一层就写明只给 AI。
6. 一个一个、照旧、往后、头一回这几个词扎堆的地方，留有用的那一个。
7. 给作者看的话写进了卡面（这一份、主会话、计划、照某某份、版本说明、“是这一页定的”），挪进设计备注。cardscan 报的照它改。
8. 【调用】压短，写清什么时候用、管哪几年、这个人是谁。默认收束是给模型的摘要，删重复，不删事。
9. 台词。台词样例、初见、关系推进里的引语、主线里的对白，照 genshin-dialogue-voice 的路子过一遍：一人一把尺子，长短错开，该问就问，该对人说就对人说，最重的往小处收。改过的台词抽出来跑 voice_check.py（--ban 管禁用标点），零警告。碑背面照第五版的写法是名字加家里人一句，不在这一轮改台词。
10. 人物和旅伴的情感内核照 jrpg-lore-writing 查一遍：是私人的事（饥饿、孤独、欠了谁、一个约定、想再见一面），不是跟一道命令、一个衙门的关系。山铜纪里机构多（审判庭、凯撒法庭、议政院、契约法庭、研究所），主线可以写制度，人别写成职员。
11. 命星照 CLAUDE.md 命星一节查：一句说清是什么再补一句人味，被动写清数值，主动写清怎么用、冷却、阶梯，限制句数少于本事，世界反应别成套。主动末尾、世界反应的句架子成串的换开。Art 不写固定数值。
12. 尺度和高魔：世道那一栏先把整条墙、两块大陆、巨城摆出来再落到这一处，照尺度和巨城两节。山铜纪是仗打完以后，不硬塞，缺的补一两句。

不做的：
- 条目设置、固定锚定、底座、体态数据、## 标题、### 星标题一个字不动（check_protected 逐行对）。真有硬伤（年份黑名单错了、未成年写了三维）报给主会话，主会话来改。
- 星不改名，不加不减。
- 不新开主线，不改碑的正面和背面（碑那一份只查跟页上对不对得上）。
- 不改中式口语以外的叫法，专名照旧。
- 不改别人那几份的文件，碰到要跨文件同步的，写进交稿的清单。

## 三、补足：补什么

1. 传承行，照 Art传承表_定稿.md 第八节之七那十八处。
2. 不合理处。这一份里前后打架的（年纪和年份对不上、谁死了又出场、地名一处一个叫法、默认收束跟幕里的不一样），照主线的幕改实，收束、默认收束、各人条目跟着改。跟纪元钟（山铜纪/补卷/第一项_常驻与纪元钟.md）、本页时段总纲、别的页对不上的，先看哪一边对：页上写得细的照页，页跟底卡打架的照底卡，拿不准的写进清单。
3. 薄的地方。一个人的条目明显比同份里别人薄（手写活人层只有一句、下场一句带过、初见没有动作），一个遗迹只有样子没有在那里会碰上的事，照同份别人的分量补实。补的东西写在这一页已有的人和事里头，不新起大设定，新起的小设定标★，记进设计备注。
4. 伏笔。这几段跟前纪元、前几页、后几页有关的人、地方、东西，grep 一遍纷争纪七页、月银纪交出去的线头和山铜纪别的页，接不上的接上（只改自己的文件），这一页埋下的东西往后几页回收了没有，没有的写进清单。
5. 迷宫纪。活进迷宫纪的人和东西（七魔神将、巴尔缇娜、索恩薇娅、格拉德、布洛姆加、芙莉莲、几家的根、众手之典、渊月长廊、曜石审判庭），跟底卡那几条对一遍（src/rili_v7.json，条目号在各份设计备注里），有冲突的照底卡改，或者写进清单。

## 五、怎么做

1. 动手以前把自己那几个文件 HEAD 的版本存一份在 scratchpad 的 polish/<份名>/before/ 里，往后的对照都拿它比，主会话中途提交不影响。
2. 读三份写作 skill 和 natural-chinese-review.md（rewrite-natural-prose 已在上下文里的话不用重读），读自己的文件，读本页的计划（底稿/山铜纪/<页>_计划.md）和纪元钟里这几段的年份。
3. 一条一条改，用 Edit 小改，不整份重写。分段源稿的格式不动：主线和旅伴在前，`## 星`，人物（标题以（人物）结尾）、`## 山铜纪·遗迹｜`、`## 山铜纪·案子｜`，最后 `## 这一份的设计备注`。
4. 改完每个文件跑：
   - `python3 -I -X utf8 tools/cardscan.py 文件`，合计 0。
   - `python3 -I -X utf8 tools/check_people_v7.py 文件 .`，硬问题 0。
   - `python3 -X utf8 tools/ngram.py 文件 <原神语料目录>`，hits 0。语料目录 /tmp/claude-0/-home-user-claudeuse/ac3b7386-5775-58fd-8a7e-6c4338f693a4/scratchpad/work/aldran/语料。
   - `python3 -I tools/check_protected.py before/文件 文件`，只许报自己有意改的（应该没有）。
   - 改过的台词抽出来跑 voice_check.py，零警告。
   - 新起的名字跑 tools/collide.py 和 tools/namepairs.py，再 grep 纷争纪/ 和 山铜纪/。
   - 不拼页，拼页主会话做。
5. 不 git add、不提交、不推。
6. 每个文件的设计备注末尾加一节 `### 10-23 润笔与补足那一轮`：改了哪几类（不逐句列，举一两处有代表的），修了哪些不合理（逐条），补了什么（★逐条），传承行改了哪几处，检查结果。
7. 交稿的话：一段总的，再列「跨文件要同步的」（文件、哪一句、怎么改）、「拿不准要主会话定的」，主会话照这两样收口。
