# 全卷声口检查（10-23）

## 一、缘起和范围

用户 10-23 的话：“等这些做完再用原神声口台词skill检查一遍现有所有角色的声口，要符合他们的核心性格人设与当前状态。”这些指的是纷争纪、山铜纪的命名扫查（见根目录 命名扫查_10-23.md）。

现有所有角色，照月银纪、纷争纪、山铜纪三纪的页来过：月银纪史诗十五页、诸国期六页、萨尔维斯六页、纷争纪七页、山铜纪六页。查的是带声口的条目，旅伴条（【独立声口｜X】那一块）、凡世至强（【独立声口｜X（传奇）】）、人物条里写了声口和台词的。一共四百二十二块声口，外加人物条里的。

## 二、照什么查

用 genshin-dialogue-voice（解开的源文件在 scratchpad 的 gdv/genshin-dialogue-voice/，先读 SKILL.md，再按要用的读 references/ 里的 status、temper、relations、occasions、openings、anti-patterns、no-punct、transfer）。配 western-fantasy-prose 对话那一节、jrpg-lore-writing（人物写什么）、chinese-prose-register。

每一个人对三样：
1. **核心人设。** 性格底色、底线、身份，声口那一块和台词样例要从这里长出来。底色写着爱说话、嘴硬心软、怕生、端着、天然的，台词就得听得出来，不能人人一样冷。
2. **当前状态。** 这一页这个人多大、在哪、刚经过什么、跟谁在一起、手里有什么事。孩子照孩子说（句子短，拿自己名字自称，字面理解），老人照老人说（自称带年纪，一件事讲两遍，把死说得轻），刚出事的、身份变了的、伤着的，口气跟着变。同一个人在几页里都有条目的，各页的声口要接得上，变了的地方要有这一页的事撑着。
3. **原神那几条尺子。**
   - 每一句先定对谁说，样例里至少一半是冲着一个人说的（叫人、问人、接人的话）。
   - 身份给惯例（这一行的开口、报到的话、谈价、问诊、规矩），性格给破功（念砸、说漏、改口、嘴硬露馅）。
   - 一把尺子：他先注意到什么，什么话题都绕回去的那一两件事。
   - 地位不在句子长短，在谁定话题、谁收场、谁可以不接话。称呼是刻度，您留给以服务为业的人、讲礼数的场合和故意的客气。
   - 最重的地方往小处收，顶点上没有人讲大道理。
   - 形状错开：一个人的几句长短要差开，冷陈述加弦外之音只给一两个人，而且他们也要有一句具体的照顾或玩笑。人人一个腔就是改的对象。
   - 特殊自称、口癖只给少数人，有固定场合，有例外。
   - 不许的：自报性格，直陈情绪（我很难过），喊口号，译制片腔（我的朋友、伙计、听着），原作的人名地名专有词，照抄原句。

## 三、改什么、不改什么

改：声口那一块的句式、注意什么、称谓、情绪、不写几行（可以添一行尺子、一行破功，写进现有的行里也行，别把一块写得比原来长一倍），台词样例（三到六句，改完零警告），初见那一句，关系推进和坎里的引语，主线里这个人明显不像他的那一两句对白。

不改：人物的设定和事实，条目设置、固定锚定、底座、体态数据、## 标题、### 星标题，史诗和歌、二十二张、碑（碑背面照第五版是名字加一句，不归这一轮），旁人的条目。台词样例里出自主线的原话，主线改了样例跟着改，样例改了主线那一句要不要跟，看是不是同一个场合。

标点照卡面口径：不用破折号、分号、省略号、感叹号（第一页执式者那两个感叹号是用户留的，不动），引语用“”，一句在同一行收住。没有省略号和感叹号的时候照 no-punct.md 用停顿词、改口、重复、语气词顶。

## 四、怎么做

1. 动手以前把自己那几个文件 HEAD 的版本存到 scratchpad 的 voice/<份名>/before/。
2. 一页一页来：先把这一页每个带声口的人列一张小表（多大、什么身份、这一页的处境、性格底色里最要紧的两样、现在的声口有什么毛病），再改。
3. 每一页改完，把这一页全部台词样例写成「说话人：台词」抽到一个临时文件，跑 `python3 -I -X utf8 <gdv>/scripts/voice_check.py 文件 --ban "…！—；"`，人和人之间一个腔的报警要清掉，单人的冷陈述、长短差照尺子看（性格本来就冷的留着，在交稿里写一句为什么）。原神台词语料这个环境里没有，--corpus 不跑。
4. 每个文件跑 cardscan、check_people_v7、ngram（原神语料目录 /tmp/claude-0/-home-user-claudeuse/ac3b7386-5775-58fd-8a7e-6c4338f693a4/scratchpad/work/aldran/语料）、authormark，check_protected 对 before/ 那一份，受保护的行一行不动。
5. 纷争纪改分段源稿（parts 到 parts7），不拼页，主会话照原来的次序 cat。月银纪三卷没有分段，直接改页。山铜纪改分段，不拼页。
6. 不 git add、不提交。
7. 每一页的设计备注末尾加一节「10-23 声口那一轮」：改了谁、为什么（一人一句），留着没改的冷声口写一句为什么，体检的数。纷争纪写在那一页的 notes 分段里，山铜纪写在各段文件的设计备注里。
8. 交稿：一段总的，再列「跨页要对的」（同一个人在别的页上的声口要跟着改的）、「拿不准的」。
