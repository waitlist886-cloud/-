# 纷争纪 · 天黑以后 · 回顾说明（2026-10-19）

这一轮照方向第二版第九节第四步，把二十二张回顾了一遍，看六样：命名，称号，死者，比喻的喻体，档，锁。另照 western-fantasy-prose 的自查清单、jrpg-lore-writing 的七条、chinese-prose-register 的清单各过了一遍。改了十处，加了一栏牌角，都落进了 天黑以后_二十二张_第二版.md，第一版留档。你定的四件写在第一节，改动的对照在第九节。

## 一、你定的四件

1. **两本账用。** 第二十张页边那一行不动，门合上时，第一位离归来只差几十年。照真相层第二版第三节，重聚万年起步，头一位陨落定在一千零三十年前后（★），聚回来要到一万一千零三十年前后，止戈封闭在一万零九百九十三年以前，差三十几年。第十张的年岁照旧是九百八十年至一千零五十年，歌里不报年份。进卡时写进 #40，魔神头一回下场排在一千零三十年前后，#108 斯卡索那一条补一句，祂是头一位陨落的正神。#40 原条说第一位陨落的正神没有具名，这一处是改底卡，进卡清单里单列。
2. **牌角用罗马数字。** 第二版每张加了一栏牌角，第一到第二十一张是 I 到 XXI，第二十二张没有数。照真相层第二版第四节，本地人认不得这些字，从别处来的人才会觉得少了一张。牌角只进二十二张的总条，时段页里不放。
3. **复沓用尚未终了。** 第十、十二、十三、十五、十六、十七、二十一，七张照旧。
4. **第一张两个感叹号留着。** 灯里那一句照卷十三原话，check_people_v7 报的两条算例外，往后每一轮都照这个算。

## 八、三份 skill 的清单

- **western-fantasy-prose**：大事落到名字、数目、动作、留下来的东西、见过的人里的两样以上，二十一首都有，最少的雨城也有名字刻在墙里、号角生了锈。专名都有着落，头一回露面跟一句交代。卡面上破折号、分号、省略号一个没有，冒号只在标签行。量级不由叙述者评，强弱交给数目和旁人的反应，三千残兵、九百名龙裔、三十八个斥候、四百一十二卷。
- **jrpg-lore-writing**：没有一首拿规章当内核。离制度最近的三首看过一遍：待核的心在书记舍不得去核，按伤排队的心在瑟蕾娅先抬上来的那个生角的伤兵，读名字的心在古伦那一只手。
- **chinese-prose-register**：每一首都有一个人在唱，开头两三句交代是谁、在哪、出了什么事。每一节有一句落点，最后一句停在一样实物、一个动作或者一句短话上。第一版第六张和第八张都收在我记着他们的名字上，路数重了，第六张改成停在那把铁刀上，见第九节。
