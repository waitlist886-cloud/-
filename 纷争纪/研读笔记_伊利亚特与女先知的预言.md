# 研读笔记｜伊利亚特与女先知的预言（2026-10-18）

读的是伊利亚特第二、四、五、六、十二、十六、十八、二十四卷，埃达里的女先知的预言全篇，另配三样小的，瓦夫斯鲁兹尼尔之歌第四十一节，至高者之言第七十七、七十八节，赫西俄德《工作与时日》开头讲两种纷争、五个时代的两段。英文本是巴特勒译的伊利亚特，贝洛斯译的诗体埃达，伊夫林-怀特译的赫西俄德，瓦夫斯鲁兹尼尔之歌那一节用的是琼·杨的译文。中文叫法照罗念生、王焕生译本（人民文学出版社 2003）。出处在末尾。

照规矩，原文一句不抄，下面都是我转述的，只记它怎么写。借的是做法，希腊和北欧的人名、神名、地名一个不进卡。

为什么是这两部。萨尔维斯借了埃涅阿斯纪，写一座城怎样立起来。纷争纪是一万一千年的仗，加上诸神一位一位地死。伊利亚特是写长仗的祖本，它不替那场仗找意义，一个一个地数死者，最后收在一场葬礼上，正合底卡那一句不得为这场战争编造意义（#1282）。女先知的预言是一个看得见开头、也看得见结尾的声音，一节一节讲诸神怎样走到末日。前一部管歌，就是表线。后一部管页边，就是暗线。

## 一、伊利亚特

### 读了哪几卷，各有什么

- **第二卷，船表**。诗人先请缪斯来，说你们当时都在场，什么都知道，我们凡人只听过传闻。又说就算有十条舌头，那一大群人的名字也报不完，所以只报领头的和船数。往下一家一条，哪一片地方，哪几座城，谁领头，多少条船。有几条里插着一件小事。普罗特西拉奥斯第一个跳上岸，第一个死，家里的妻子还在哭，房子只盖了一半。菲罗克忒忒斯被蛇咬了，扔在一座岛上，他的人照样报上，换了一个人领。歌人塔米里斯夸口唱得过缪斯，被弄残了，从此弹不了琴。
- **第四卷，西摩埃西奥斯**。他母亲从伊达山下来看羊，在西摩埃斯河边生下他，名字就从这条河来。他没来得及报答父母的养育，就被埃阿斯一枪刺穿胸口，倒在土里，像河边洼地里一棵白杨，被造车的人砍倒，要弯成车轮，搁在河岸上晾着。整部诗有两百四十个左右点了名的死者，大多都有这么两三行。
- **第五卷，狄奥墨得斯伤神**。他一枪刺中阿佛洛狄忒的手腕，神流出来的不是血，是灵液，因为神不吃面包，不喝酒。她母亲狄奥涅抚着伤处说，跟神打的人活不长，孩子不会坐在他膝上叫他父亲。后来他又刺中阿瑞斯的肚子，阿瑞斯吼得像九千到一万个兵一齐喊。宙斯骂他是天上最可恨的一个，还是叫人给他治好了，因为他是自己的儿子。
- **第六卷，格劳科斯**。格劳科斯和狄奥墨得斯在两军之间碰上。狄奥墨得斯问他是谁家的，他说人的世代就像树叶，风吹落一批，春天林子里又长出一批，说完还是把家世从头讲了一遍。两人发现祖父辈是朋友，于是不打了，换了铠甲，格劳科斯拿值一百头牛的金甲换了值九头牛的铜甲。诗里说他吃了亏，是神拿走了他的心智。同一卷后半，赫克托尔回城跟安德罗马刻告别，他还活着，家里的女人就先为他哭了一场，觉得他回不来了。
- **第十二卷，称羊毛**。两军相持，谁也压不过谁，像一个本分的女人做活养孩子，拿秤称羊毛，一头羊毛一头秤砣，称得一样平，挣的是一点微薄的工钱。同一卷里两边扔石头，扔得像冬天落雪。
- **第十六卷，萨尔佩冬**。宙斯想把儿子萨尔佩冬从战场上救走。赫拉说你救了你的，别的神也有儿子在打，人人都要救自己的。你若真疼他，就让他死在阵上，死后叫死神和睡神把他抬回故乡。宙斯听了，往地上洒了一阵血雨，算是给儿子送行。萨尔佩冬死后，阿波罗把他从阵上抬出来，在河里洗净，换上不朽的衣裳，死神和睡神把他送回吕西亚，族人给他起坟立柱。
- **第十八卷，盾**。赫菲斯托斯给阿喀琉斯打一面盾。最里面是天、地、海，日头和群星。往外是两座城。一座太平，有人娶亲，火把照着新娘过街，女人站在门口看。广场上两个人为一笔命价争执，老人们坐在石凳上一个一个出判词，判得最公道的那一位得两塔兰同金子。另一座被围，城外两支军队商量是把城抢光还是分走一半。城里的人出城埋伏，劫了牛羊，杀了牧人，两边在河边打起来。纷争、骚乱和凶煞在人堆里走，凶煞拖着三个人的脚后跟，一个受了伤，一个没受伤，一个已经死了。再往外是犁地，金子打的田，犁过去的地方是黑的，看着就像真翻过的土。割麦，地主拄着杖站在一边，不说话，心里高兴。葡萄园，一个孩子弹着琴唱林诺斯歌。牛群往河边去，两头狮子扑倒了领头的公牛，狗只敢远远地叫。山里一片羊圈。一块跳舞的场子，转起来像陶工试他的轮子。最外一圈是大洋河。画上的人在走，牛在叫，琴在响。
- **第二十四卷，三段挽歌**。赫克托尔的尸身运回城，三个女人轮着哭他。妻子安德罗马刻哭的是往后，她成了寡妇，孩子还小，他死的时候没躺在床上，没给她留一句能记一辈子的话。母亲赫卡柏哭的是神疼他，生前疼，死后也疼，尸身被拖了那么多天，还像刚死的。海伦哭的是二十年里他没对她说过一句难听的话，别人骂她，他还拦着。全诗收在他的葬礼上，最后一句只说驯马的赫克托尔就这样下葬了。

### 可借的做法

1. **一个死者一段小传**。伊利亚特写仗的分量，压在两百多个有名有姓的死者身上，不压在形容词上。一个死者两三行，常见的几样是父亲是谁，生在哪条河边，名字从哪来，没来得及做的一件事，怎么死的，末了一个从太平日子里取的比喻。死的多半是敌人，诗照样给他一段。
2. **比喻从太平日子里取**。狮子扑牛，冬天落雪，女人称羊毛，造车的人砍白杨。仗打得最紧的地方，诗偏偏开一扇窗，让人看一眼田里和家里。比喻长，一个比喻自己就是一幅小画。
3. **盾上画着整个世界**。神给一个注定要死的人打一面盾，盾上的仗只占一小块，大半是娶亲、断案、犁地、割麦、摘葡萄、放牛、跳舞，最外一圈是大洋河。画上的东西会动，会响。这面盾就是那个人要离开的整个世界。
4. **点将**。歌人先认自己报不全，凡人只听过传闻。往下一家一条，地方，领头的，人数，一条里插一件小事。不在场的也报上，人不在，名字在。
5. **凡人伤神**。神的伤写得很实，伤在哪，流出来的是什么，为什么不是血，喊起来像多少人一齐喊。代价由神自己说出来，跟神打的人活不长。
6. **神要救自己人，没救**。宙斯救得了儿子，可是一救，别的神都要救自己的，规矩就破了。他只往地上洒一阵血雨，然后叫人把尸身抬回家，起坟立柱。
7. **世代像一样东西**。一个人被问起家世，先说人的世代跟树叶一样，一批落，一批长，说完还是把家世讲了。
8. **换甲**。两个敌人在阵前认出祖上有交情，换了铠甲，换得不公平，诗把这一笔记了下来。
9. **三段挽歌**。同一个死者，三个人各从自己跟他的关系哭起，妻子哭往后，母亲哭神，外人哭他待自己的好。第六卷还有一种倒过来的，人还活着，家里先哭过他一场。
10. **收在葬礼上**。全诗不收在胜利上，收在一场葬礼上，最后一行是死者的称号。
11. **固定的称号**。驯马的赫克托尔，捷足的阿喀琉斯。有名的人每回出场都带着一个称号，唱的人和听的人都靠它认人。

### 落到纷争纪的哪里

| 做法 | 落在 |
|---|---|
| 一个死者一段小传 | 每一首歌至少点一个死者的名字，第二十一首摇篮曲可以不点 |
| 比喻从太平日子里取 | 每首两三个长比喻，喻体取那个年代、那个唱歌的人手边的东西 |
| 盾 | 每一张的牌面，大事旁边留一角平日，第二十一张用得最足 |

| 神要救自己人，没救 | 十初陨，只借血雨和抬尸起坟两样，别的神来没来不裁定（#42 朱亚能把重创的同僚救回来），默许只在页边 |
| 世代像一样东西 | 八长守，精灵看人族一代一代上墙，喻体换成精灵自己的东西，不用树叶 |

### 不借的

- 一个人的怒气撑起全篇那一路。纷争纪是二十一段年岁，没有哪个人从头走到尾。
- 凌辱尸身那一段。
- 十条舌头、树叶、白杨、狮子这些比喻的原样。做法照借，喻体换成奥尔德兰的东西。

## 二、女先知的预言

### 它是什么样的

- 一位女先知开口，请神的各族都静下来听，说万军之父要她讲旧事。她记得最早的巨人，记得九个世界。
- 往下是一部从开天到末日的史，一节一件事，节与节之间不接话。诸神起屋造炉，在庭院里下金棋，什么都不缺，直到三个巨人族的少女来了（第八节）。世上第一场神与神的仗。巴德尔死了。兄弟相杀，姐妹的儿子坏了亲族，斧的年月，剑的年月，盾牌裂开，风的年月，狼的年月，然后世界塌下去（第四十五节）。日头变黑，大地沉进海里，星星从天上掉下来（第五十七节）。大地又从海里升起来，是绿的（第五十九节）。诸神在伊达平原上碰头，说起从前（第六十节）。从前那几枚金棋子，又立在草里（第六十一节）。巴德尔回来了（第六十二节）。最后一条黑龙驮着死人从山下飞来，先知说，我该沉下去了（第六十六节）。
- 复沓。还想知道得更多吗，这一句一共出现九回，在第二十七、二十九、三十四、三十五、三十九、四十一、四十八、六十二、六十三节。开头二十六节一回也没有，末日正当中那十几节也没有，大地重新变绿以后又问了两回，最后三节不问。

### 可借的做法

1. **一个看得见首尾的声音**。先知不在局里，她记得开天以前，也看得见末日以后。她不评谁对谁错，只一件一件说出来。
2. **一节一件事**。节与节之间没有接话的句子，跳着走，读的人自己把空补上。
3. **复沓**。同一个短句隔几节回来一次，问听的人还要不要往下听。它把一节一节的碎片拴成一个声音，也让人觉得说话的人知道得比说出来的多。
4. **按打仗的东西给年月起名**。斧的年月，剑的年月，风的年月，狼的年月，一个年代就叫那时候在动的东西。
5. **金棋**。诸神太平的时候在桌边下金棋，末日以后，同一副金棋子又立在草里。一局棋从头摆到尾。
6. **沉下去**。先知说到她看不见的地方就停。最后一节是一条驮着死人的黑龙，亮起来的地方后头还压着一点暗。

### 落到纷争纪的哪里

| 做法 | 落在 |
|---|---|
| 看得见首尾的声音 | 页边那只手，卷十三页边那一行就是它写的 |
| 一节一件事 | 页边一张一行，连起来读才是中层那一局 |
| 复沓 | ★页边，挑七张在那一行后头添同一个短句，第二十二张不添，见方向第二版第五节 |
| 按打仗的东西给年月起名 | 十八机兵那首歌，牌面上正好是铁狗和铁狼，也给牌名那一轮当一路构词 |
| 金棋 | 中层那一局本来就是一张桌子边上的事，牌是桌上的东西，落到世上以后从土里找到，拿出来还是新的。只借这个做法，棋、下棋这些字不进卡（#97、#73） |
| 沉下去 | 第二十二张的页边，说到不在册子上的那一个就停 |
| 日头变黑，大地又绿 | 十六落冠写太阳神死在沙海那一下，二十一雨城写天亮以后，只借这一黑一绿，画面用奥尔德兰的 |

### 不借的

- 第二十节那三位少女，她们的井，那棵树。碰 #73 四个名字那条线，借了就是在画上替世界把这件事说破。第二十一张原来画的井因此改掉，见方向第二版。
- 第六十二节死者回来。纷争纪的传奇和神死了都不回来，不复活，不转生（#929、#932、#107、#108），神谕又说此后不再有新的神（#41）。
- 先知是被神叫来问话的那一层。页边没有问话的人，只有画牌的人自己的一行字。
- 北欧的专名、神名、地名。

## 三、配的三样小的

### 瓦夫斯鲁兹尼尔之歌，第四十一节

- 英灵战士每天在奥丁的庭院里厮杀，挑出要死的人，然后骑马下场，坐在一起，伤都好了，一同饮宴。
- 落在魔神那一边以为的事。死了明天照样站起来，所以不急，也不怕，这就是真相层第二版第三节说的，魔神以为重聚以后还是自己。第八张页边那一行（那一边不急，以为死了还能回来）和第十五张页边那一行（门要关，这一边不知道）从这里来。只在页边，歌里不写。

### 至高者之言，第七十七、七十八节

- 牲口会死，亲族会死，自己也会死，可一个人挣下的好名声不死。下一节又说一遍，世上只有一样东西不死，就是一个死人做过的事留下的名声。
- 落在纷争纪是连账都还在的一纪（#929），刻名石、伤亡册、人皮图上的名字，都是这一句的样子。反过来是无字碑（#929 第十则），那些人有名字，是后来的人没记住。无字碑立在白碑停战碑群旁，是停战以后的东西，歌里用不上，进卡时可以挂在时段页或条目里。第七张的刻名石，第十七张艾瑟莉娅把名字背下来，第十八张那三十八个名字，都在这一句底下。

### 赫西俄德《工作与时日》，两种纷争和五个时代

- 开头说世上的纷争不只一种，有两种。一种挑起仗和争吵，谁也不爱它。另一种年纪更大，神把它安在大地的根底下，它叫懒人也去干活，看见邻居富了就跟着去犁地种树。陶工跟陶工较劲，木匠跟木匠较劲，乞丐眼红乞丐，歌人眼红歌人。
- 这本书是赫西俄德写给他兄弟佩耳塞斯的劝告，一条一条讲什么时候犁地，什么时候出海，什么时候别去。
- 往下讲五个时代，金，银，铜，英雄，铁。英雄那一代夹在铜和铁中间，是唯一不拿金属起名的一代，一群半神的人，大半死在仗里。
- 落在纷争纪这个名字底下有两样东西，一样打仗，一样逼人干活。长垒上各族的工兵比着砌，战法学院一代一代传灯，薇拉·铜舌那台明天还能烧的炉子，都是后一样。歌里两样都要有，第七、九、十一张写后一样写得最多。劝告那个形状给第九张，战法学院的先生一条一条教学生。
- 另有一处对上的。奥尔德兰的纪名早就有了，月银、纷争、山铜，纷争纪正好是夹在两个金属名字中间、不拿金属起名的那一纪，又是传奇们死在仗里的那一纪。这是碰巧对上，不照着改，卡里也不提。

## 四、借了以后最容易写歪的地方

- 点名的死者写成一串名单，只有名字没有事。一个死者至少带两样，出身、名字的来由、没做完的事、怎么死的。
- 比喻写成天象大词，或者每首都是农活。喻体看谁唱，矮人取石头和锤，精灵取林子，兽耳取路，半身人取车和账本，魔族取血誓和角。
- 页边的复沓写成俏皮话，或者冲着玩家说话。句子平，不带你。
- 把英雄气唱进来，替仗找意义。伊利亚特一路数死人，收在葬礼上，借的就是这一点，#1282 那一句照守。
- 一张牌把这些手法都用上。一首歌挑一两样，方向第二版第六节逐张那一栏写的就是挑哪几样。
