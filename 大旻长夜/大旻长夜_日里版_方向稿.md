## 三｜状态栏：紧凑记录行，前端展开

1. 为什么。原卡每轮让 AI 写一整套 HTML（八块面板、几百个标签）。同一条回复两种写法比过：样本一 HTML 写法一万三千二百字（半角字九千一百），记录行写法三千六百字（半角字二十），估算的 token 从六千四降到三千四上下。省下来的是标签，不是内容，八块面板的每一栏都还在。
2. 写法。除正文外一行一条：“§”加一个记名字，全角“｜”分栏，栏序照主提示词第七节的骨架。记名字：

| 面板 | 记名 |
|---|---|
| 玄枢推演 | §枢（十二行，项名照写） |
| 山河行卷 | §卷（时间｜标题｜地点｜天气｜核心矛盾，下面是正文），§验（天机验算） |
| 命主玉牒 | §身 身世名牒，§命 命关天衡，§技 武藏真传，§赋 天赋神通，§缘 红尘因果，§私 风月私牒，§物 随身百宝，§业 家业金契，§事 今朝牵系 |
| 群英照鉴 | §详（核心详牒头）＋ §项，§简（现场简牒） |
| 万里照影 | §铭 |
| 天下风闻 | §讯（一类一行，几条用“；”隔开），§向（四野），§策（四行行策，“自定其途”前端补） |
| 天时经纬 | §限（急、近、远、未），§雷（当境风雷十一行），§候（夜潮体感），§州（诸州回响） |
| 光阴藏卷 | §近，§经，§因，§刻 |
| 功能轮 | §档＋§存（存档），§评（差评受理），§示（读档提示） |

   AI 不用写面板头、分节头：显示正则认出同一组记名连着的头一行，自己插面板和分节，所以写漏一块也不会串。时间写“玄熙某年某月某日·某时”，地点由大到小用“·”连，这两栏后面触发要用。
3. 前端。167 条显示正则（仅 AI、仅影响聊天显示），全过 safe-regex，两条样本展开成一整块、无残留。存进历史、发给 AI 的始终是记录行，下一轮 AI 照着记录行写。样子照原卡的“玄铁朱墙”重画：行卷是一卷手卷，左边一道朱红，时辰盖成朱印；面板是一块块军牒，一块一个颜色（推演紫、玉牒金、照鉴青、风闻朱、经纬铜、藏卷玉）；六维、先天一格一数，境界和生命状态一签一项，随身一格一件，武藏天赋是玉简卡；四野是四个方位章；行止抉择是四支签，点一下行动就填进输入框；刻限按急近远上色；当境风雷的五幕画成五个菱，走到哪一幕亮到哪一个；藏卷是一条时间线。
4. 整页：读行卷头的时辰和天气，夜里顶上一盏暖光，两侧是朱墙的暗红；下雨、下雪落在两侧桌面上，正文那一列不挡。
5. 旧回复只留行卷和三块档案，推演、风闻、经纬收起来，往上翻不再一屏一屏的行策和刻限。
6. 截图在 状态栏/截图/（宽屏十一张、手机七张、介绍页一张）。复刻台是本地仿的，字体、平台主题、真模型写歪的样子要到真页面上看：主要看手机上玉牒那几格挤不挤、雨的密度、旧回复收起来以后够不够用。
7. 旧对话里原来的 HTML 回复照原样显示：紧凑版把原卡的组件样式也带着。

## 四｜世界书触发

查出来的：

1. 1275 条全部只认玩家的话。AI 自己写出来的人物、走到的地方、命主身上的武学和道途，都叫不醒条目。原卡要求“重要固定人物出场先调用其灵魂档案”“若检测到短版，先调用对应世界书恢复完整卡”“每轮根据当前年月确定长夜十候”，这三件在原来的触发下做不到，模型只能凭记忆。
2. 长夜十候一条两千四百字，只有玩家打出“长夜十候”“夜潮体感”这些字才醒，可天时经纬每轮都要写当前一候。
3. 首轮凭证里的“联动：武夫、仕途、敏、精”“边界；造化”这类字，会把兵家、仕途两门道途总纲和医家序列二叫醒，一千九百字白进上下文。
4. 人物灵魂档案、武功术法、命格三类，每条都抄同一段裁定套话，合计六万六千八百字；几条一起醒的时候，同一段话进上下文好几遍。
5. 存档、读档、查看、差评、铭刻这些功能命令放在系统位置，离玩家的命令最远。

写法上的讲究：日里一条条消息分开算，触发范围对整条条目生效，所以“玩家的话随便提到就醒”和“AI 的回复只认几栏”写成两个正则放在同一条里，前一个只在整条消息没有记录行的时候才认（玩家的话没有 § 行）。新正则都带 m 标志按行认，紧凑版两千四百四十三个触发词和黑名单在 Node 里逐个建过、全过 safe-regex，最长那条（十候）一百九十九字。

## 五｜前端洗稿与玄幻润笔（样稿）

介绍页的文字在脚本数据里，二十一万字：势力七十方（十万八千字）、州郡和山河图（八万字）、武学和命格目录（两万字）、十六位女主档案（九千字）、首页和卷册说明（七千字）。拿国风那份技能的扫描跑过，黑名单命中两百一十处，大多是人物档案里直接写“害怕”“恐惧”；真正的腔在句子上，按每万字数：

- 顿号连排、末尾一个“与”的清单（财政、党争、门阀、灵灾、租界条约和天下商主同时拉扯）五十一处，分号九十二个；
- “真正”九处，“必须”九处，“承担”七处，“秩序、体系、结构、代价”这四个抽象词加起来十六处；
- 人物写“他最怕……”“他的善良来自……”“真正的软处是……”，拿心理说明代替一个动作，光“最怕”“真正恐惧”这两种写法就有六十五处。

定调照国风技能：古今混融为主（蒸汽和超凡用本朝的叫法，官署文书的口气），正史江湖为辅（年号、地名、价钱落地），借冷峻白描的看客。改法五条：清单留一两样最能看见的，其余拆掉；抽象词换成一样东西（“秩序机器”换成“一张税票、一道封锁线”）；“真正的……是……”删，换成那个人做的一件事；心理说明换成动作或一句他会说的话；名字、年龄、职衔、数字、条目之间的关系一个不动。
