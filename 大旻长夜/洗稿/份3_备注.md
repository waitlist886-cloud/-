# 份3 备注（山河1：十二个州郡，633 条）

## 结果
- 改了 340 条，没改 293 条。校验：问题 0 条，分号 73→0，平均长短 1.00，340 条里 209 条比原文短或一样长，最长 1.18 倍，最短 0.81 倍；改过的这些条合计 17642 字→17668 字。
- 十二州各改：神京 44，江南机织城 30，淮扬漕运带 27，重云港 29，三京大运河 29，西域商站 27，黑潮海岸 27，闽广船坞 25，山海关 26，临波郡城 26，南洋海路 24，玉门轨道关 26。

## 照什么改的
- 一州一州连着读完再动笔。同一州里重复的几段保持一字一样：mainline 每一句都是一、三、五幕里的原句；conflict 就是四幕的开头；route 和 entryAnchor 一字不差；longTerm 末尾的“**裁定锁**：”后面照抄洗过的 verdict。这几样用脚本逐州核过。
- 清单：一串抽象名词拆成“谁管什么”（“龙首总漕口管船期和票据，河伯平码洲验实货……”），或者换成看得见的东西（“海权、工业与后勤的交汇处”改成“管海的、造船的、运补给的，都在这里碰头”）。具体物件的清单留着。
- 抽象词：秩序、制度改成规矩、章程；承担改成担、扛；必须改成得、要；持续改成接着、一直；真正删掉。“数据”改成读数，“舆论”多半改成口风。
- 心理说明改成动作：小箩“会害怕并拒绝继续”改成“会躲开，再不肯带路”；鲍大娘“害怕灯下的人已经变了”改成“灯下那人变没变，她却不敢认”；骨核“学习船员的恐惧”改成“船员每慌一回，它也跟着学一回”。
- 分号全部拆成句号或逗号。长句拆短，“能否”“是否”有的改成“X不X”，有的照留，免得篇幅涨上去。
- 叙事裁定：“必须……禁止……”改成“要……不许……”，还是官署交代差事的口气。
- 黑名单：#332 的“仿佛”、#364 和 #536 的“真正的”都去掉了。改后全文没有一丝、某种、这一刻、“不是……而是……”，一条里至多一个比喻。

## 故意没动的（293 条）
- 不该动的：地名、场景名和所属地（scenes 第 0、2 栏）、人物的 scene 和 identity、subtitle、events（就是五幕的幕名）、幕名、autoDate。
- 风波所系、可闻风波那两栏（subs 第 3 栏、scenes 第 4 栏）：页面上当标签用，是事件钩子的清单，照留。
- 照原文、没改的 22 条（drop 掉的）：
  - 十一条“可从……切入”的入局清单（#111 #161 #215 #270 #326 #376 #420 #468 #513 #553 #600）。原句本来就短，也具体，改了只会变长。神京那条后半句“地区会自行发展”有腔，洗了，前半句也照这个格式留。
  - 十条跨区传导的地名清单（#186 #241 #295 #352 #402 #443 #491 #537 #578 #625）。只改了神京 #79（原来是一整句）和江南 #136（“制度”改“规矩”）。
  - 四条离场自转本来就干净（#342 #481 #485 #525），一条属地描述本来就好（#150 税卡关楼）。

## 拿不准的，请过目
1. #56 神京一幕的末句“龙脉异常从此有了姓名和伤口”是升华句，删了。要留的话接回去就行。
2. #336 西域五幕的末句“提醒每一代人水从谁的生活里流过”也是升华，可里头有一件事（月影一直留在井里），所以压短留着。
3. #525 顾飞墨“可能被捕或被收买对象盯上”有歧义（被收买的人盯上，还是成了别人要收买的对象），照原文没动。
4. #582 阿榕“被当成资料样本后发怒”写成了“她也会摔勺子”，是把怒气落到一个动作上。不想添动作的话改回“也会发火”。
5. 几处换了说法，意思应当没变：#64“更高效的中央秩序”改成“一套更快、由中央一手抓的规矩”；#76“神京的解释权开始向下分散”改成“怎么解释，也不再由神京一家说了算”；#489“边界社会固化”改成“关里关外却从此分了家”；#33“街头情绪”改成“满街的火气”；#417 和 #427“启动远程夺舵”改成“隔空夺舵”；#60“在公开责任、社会恐慌和救人时限之间选边”改成“当众认责，压住满城恐慌，还是赶在时限前救人”。
6. #465 和 #476 的“万人灯火”保留“万人”，写成“万人的灯火”。
7. 原文自己的问题，没改：山海关那一州，谢停雪的 identity 写的是“昆仑天关守将”（#482），跟山海关对不上，要不要查请你定。
