# 九重天阙两面：武夫
- **正途**：拿自己的身子去挡。护人、守擂、撑缺口，武誓当众立、当众还，伤病记在自己身上，传艺不拿徒弟的命换名声。慢，筋骨里干净。
- **恶途**：拿别人的身子垫拳。功夫一分不假，挨打、残废、填血食的换成了旁人，长得也快。
- **下三阶**：叩门是在黑拳场打死一个不肯认输的人，满场下注的当见证。真劲拿欠债的苦力当活桩，一套打法在三个人身上试成。武魁当众把一个成名武者打成废人，武誓立的是“挡路者断骨”。
- **中三阶**：意罡铸体的血食从菜人市买。宗师开馆收上百个穷孩子往死里练，熬出三个能打的，余下的从后门抬走。承天挑一场明知要烧掉一条街的决战，赢了，本心就是赢。
- **上三阶**：镇山河以屠止屠，乱军连同被裹挟的乡民杀到十年没人敢起事。不灭躯的圣域扎在年年给他交壮丁和血食的地方。武圣答“力量为我所用”。名号照旧，懂行的人一进他的圣域就看得出：弱的人先跪。
- **去处与迹象**：租界码头的黑拳场、帮会打手堂、豪门护院，魔门外坛也收。陪练换得勤，徒弟名册上划掉的比留下的多，伤好得太快。民间叫“吃桩拳”。
- **代价与回头**：逆纹长在筋骨里，断一顿血食旧伤齐发。越往上越疯，长夜也往身上拽，影子先慢半拍；誓约册上一笔笔记成仇（幕后层，不明说）。回头得自废吞来的那份罡，吞得多跌得深，再把打残的人一个个养起来。

# 九重天阙两面：剑客
- **正途**：剑为担当出鞘。护人、断邪、斩自己的旧念，拔剑后的后果自己扛，剑理留给后人。养剑慢，剑心定。
- **恶途**：剑名拿别人的血磨。锋是真锋，名声起得快，血是旁人的，挑的多半是比自己弱一截的。
- **下三阶**：问锋为夺一柄好剑，斩了剑的主人。剑客在窄巷、野地、带伤时各斩一个不该死的人。剑魁当众连挑一家武馆，挑到那家封门。
- **中三阶**：剑意拿一座镇子圈域，剑痕合拢时镇里有人没走出来。剑宗的剑理让弟子拿命去验，活着回来的招才进剑谱。剑心斩执念的法子，是斩了让他起执念的那个人。
- **上三阶**：剑仙斩神救城是真的，余波剁开半个外城。太虚的剑境靠一代代上门挑战的人喂。剑圣答“剑是我，为我出，剑后留坟”，三样也一致。名号一个字不差，行家看他的剑痕就认得：多年不收锋，路过还割人。
- **去处与迹象**：五岳剑盟除名的弃徒、豪门门客里的剑供奉、接黑单的散剑。挑战帖只发给弱一截的，剑上缺口多，一个也不刻名。民间叫“磨剑人”，被挑过的门派叫“磨刀石”。
- **代价与回头**：逆纹走在剑意里，剑心一偏，决断就成了只知斩杀。疯、污染和长夜的拉扯随剑域一起长，誓约册上的仇也是（幕后层，不明说）。回头要折剑散意，多半跌一阶，再去每一块磨刀石门前认账。

# 九重天阙两面：兵家
- **正途**：命令带人出去，也带人回来。战功经得起复盘，伤亡和抚恤记在主将名下，军魂是信出来的。
- **恶途**：胜仗拿别人的命换。战报经得起查，坟是旁人的；填线、弃子、驱民在前，都算兵法。这种将多半会打仗，升得也快。
- **下三阶**：执戈带十个人押货，货到了，回来三个。队率两回都赢，一回把伤兵留下断后，一回拿向导去趟雷。都尉拿一营人的命换一场能写进战报的胜仗。
- **中三阶**：将军补给靠沿途征光粮，撤退时炸桥，把友军留在对岸挡追兵。都督的军制靠连坐、押军属、欠饷纵抢立住，兵真不散。庙算整军见证登神，军魂是血煞和恐惧拧成的，阵亡的人锁在旗里散不掉。
- **上三阶**：兵主把一座城留给敌军作饵，趁屠城合围，战局真改了。天策的军制靠军籍和债契拴人，他不在也转。兵圣答“为我而战，何时止看我”。名号照旧，懂行的人看他展旗：营里先冷三分，旗里有哭声。
- **去处与迹象**：门阀私军、边镇自治的堡兵、私掠船队、万国雇佣兵团。战报阵亡数整齐，老兵稀少，番号常换。当兵的管这种主将叫“磨盘”，一营一营往里填。
- **代价与回头**：逆纹缠在军魂上，一场大败，锁在旗里的人一齐反噬；疯与长夜的拉扯顺着军魂传给全营，誓约册上的仇按人头记（幕后层，不明说）。守城走正途、撤退走恶途的将不少，纹上两样都有。回头要散军魂放亡者走，跌阶失军，再给阵亡者立名、补抚恤。

# 九重天阙两面：帝王
- **正途**：接过没人愿担的事。治下的人自愿认他，赏罚有据，饥荒、民怨和失败扛在自己肩上，权柄交得出去。
- **恶途**：权柄拿别人的命垫高。认他的人是真认，只是怕出来的；被压、被迁、被删的人替他付账，位子坐稳得快。
- **下三阶**：持符接过一条街，头一桩规矩是把不服的人吊在牌坊下，余下的人真服了。令主一个周期税粮、治安都好看，靠的是告密和抽丁。封侯开闸淹了邻县的田，保住自家的城。
- **中三阶**：王权定基时把不服的姓氏整族迁走，田产充公。摄政压住继承危机靠一场宫变，章程只认他挑的人。天命把国家的愿望收进自己身上，怨恨引到一族人头上，让他们替国家挨恨。
- **上三阶**：真龙的中兴是真中兴，换它的是一场献祭或一次灭族。无疆的国体只认一种人是完整的人，余下的是地基。圣君把天下当私产，帝道的塌口就在脚下。名号也叫真龙、无疆、圣君，明眼人看得出国运倒流，从民间往上抽。
- **去处与迹象**：割据的藩镇、门阀宗主、海上称王的岛主，旧日王庭也有。治下太平，没人敢说话，驱逐令比告示多，仓满民瘦。民间叫“饿龙”。
- **代价与回头**：逆纹落在国运里，治下一旦不认，神姿反噬成疯王。疯与长夜的拉扯跟着国运灌进来，誓约册上的仇数这一条最重（幕后层，不明说）。回头要交出权柄、开仓、给被删被迁的人复名，逆纹一道道断，多半还要跌阶。

# 九重天阙两面：仕途
- **正途**：签字的人担责任。政令落地经得起复查，敢在上压下拿主意，不拿冤案换太平，错了先认自己的。
- **恶途**：政绩自己拿，罪名别人背。案卷齐整，政绩实打实，升得比同年快，替罪的名字总备着一个。
- **下三阶**：吏员的账经得起查，少的那笔记在一个不识字的佃户名下。主簿的错是自己出的，革职的是下面的书吏。县令砍一个外乡人的头平了民愤，县里真太平了。
- **中三阶**：知府灾年行政链不断，饿死的不进册子，报灾的先进牢。巡抚的新法办成了，反扑落在州县小吏头上。尚书签了那份要命的字，责任事先分到一串已死、已退的人头上。
- **上三阶**：宰执拿一场大狱压党争、一轮加派压财政，国家真没塌。公器的圣域里错的法也有力，压人和公道一样落地。冢宰答“权由章程自转，责由下面担”。名号照旧，懂行的人看他用印：印下总压着另一个人的名字。
- **去处与迹象**：门阀把持的部院和档案房、旧榜同年会、州县的刑房。他升一级，下面革一个，每桩错事都有个签字小吏顶着。百姓叫这种官“纸刀”。
- **代价与回头**：逆纹压在印信上，冤案越多案卷越沉，失位那天一并找回来。越往上，他经手的文书越常出错字，那是长夜在拽；誓约册上的仇一笔不少（幕后层，不明说）。清官也有拿替罪羊过关的一回，纹上便清逆交错。回头要自请降黜、翻案，把替罪的名字一个个洗干净，纹断了，阶也掉。

# 九重天阙两面：师者
- **正途**：教人成为他自己。尊重学生的意志，认错，认被超越，弟子的失败也算老师的因果。
- **恶途**：把学生削成自己的样子。学问不掺假，学派铺得快，学生是削出来的，削坏的扔掉。
- **下三阶**：蒙师用戒尺和饿饭教会一个孩子，孩子会了，也怕了。讲席把末几名当众羞辱、逐出，及格的人数好看。名师教出一个只会照老师选的学生，扬名的事他做，罪也他顶。
- **中三阶**：山长的书院乱世里一天没停，收的是交得起谱钱的，穷学生拿去顶差役。宗师的学派靠删谱铺开，异议弟子的名字一抹，从此找不到差事。师表由满堂弟子见证，答“教他们成为我”。
- **上三阶**：圣师开了一州的民智，另一半人写成“不可教”。文脉的圣域只容一个答案。至圣让后来者只走他铺的那条路。名号不变，行家听他的弟子说话就知道：一个腔，遇事一个答案，老师一句话就改主意。
- **去处与迹象**：门阀的谱牒院、族学家塾、科场同年会、讲武堂。被除名的学生投不进别家门，书院门口常贴“来历待核”。民间叫“刻木偶的先生”。
- **代价与回头**：逆纹落在弟子身上，弟子的崩溃和背叛一齐回到他那里，强塑人格还会污染师道。疯与长夜的拉扯顺着师承往下传，誓约册上的仇按学生记（幕后层，不明说）。回头要放学生走，把删掉的名字补回谱，公开藏着的方子和原卷，断纹降阶。

# 九重天阙两面：医家
- **正途**：救命不瞒风险。药不够时自己取舍、自己担，失败病例公开，救一人也护着旁人的命。
- **恶途**：医术拿别人的命练。救活的是真救活了，名声起得快，死的、残的、替伤的都是没人撑腰的那些。
- **下三阶**：问脉救下富户的儿子，抽的是同屋一个无籍学徒的血。医师在贫民坊里练成三类病，治坏了没人追。名医那张救命方在十几个不知情的人身上试出来，失败的不进病历。
- **中三阶**：国手以别人的生命力为引，抽一营伤兵的精气救一位将军。药王的章程靠一批签了卖身契的试药户撑着。回生救付得起的，伤势挪到舍掉的人身上。
- **上三阶**：医圣止住大疫，解药是在疫区活人身上种出来的。造化的圣域靠病人的本源养，进来的病好了，寿短了。医祖给命标价排序。名号照旧，同行看得出：他手下的伤是挪走的，没消。
