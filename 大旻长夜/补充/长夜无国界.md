# 九重天阙的两面｜正途与恶途总则
- 序列认的是成就的分量和众人的承认，不认善恶。九重天阙逐序列里写的那一套，是大旻各法统认可的正途；每条道途另有恶途：同一个序列名，同一种威能，走法相反。
- 正途的成就落在“替人担着”上：慢，规矩多，真理纹章清正，道心稳。恶途的成就落在“让别人担着”上：快，代价转到别人身上；纹章带逆纹，越往上，疯狂、污染和长夜的牵引越重，誓约册里记着的仇也越多。上三阶的恶途圣位，名义上一样，懂行的人认得出来。
- 同一个人可以半正半恶，也可以中途回头。回头要付账：降阶、断纹、还债，三样至少一样。
- 每条道途都有正人和恶人。恶途的人一样能晋升，一样强，有谋划、有退路，不因为“恶”就降智或自取灭亡；正途的人也会犯错、会累、会被拖进灰处。
- 玩家走哪一条都照常结算：恶途来得快，账记在别人头上，迟早有人来讨；正途慢，能交到别人托付的东西。
- 民间认恶途，靠的是旁人的下场：跟着他的人越来越穷、越来越空、越来越怕，他却越走越高。

# 九重天阙两面：资本
- **正途**：交换服务于人。账房守信，掌柜在危机里守住别人的信用，执衡替一城担下兑付。
- **恶途**：风险留给别人，利钱留给自己。恶途的资本序列，民间叫“吃灾的”“放灾债的”。
- **恶仪九阶**（序列名照旧）：
  - 账房：做成一笔对方看不懂的交易，风险全落在对方身上，对方还自愿画了押。
  - 行商：跑通一条靠赊欠拴住沿途小户的商路，货到哪里，债就跟到哪里。
  - 掌柜：市场危机里不救信用，低价收走别人的信用。别家倒了，铺面、客户和账都归了他，街坊还谢他接手。
  - 会首：让一城的兑付离不开自己，再在关口挤兑同行，拿别人的倒闭换自己坐大。
  - 财阀：立一种让损失自动流向最弱一方的制度，除外条款、风险名册、连环保，他不在场，它照样吃人。
  - 执衡：四阶仪式里把大规模债务与欲望的回流引到别人头上，自己一分不担，照样推开神关。恶途执衡开门那一夜，常有一条街或一家厂替他还了账。
  - 商主：用契约让几个国家只能向自己借钱；或者做空一座城，账上欠着的灾真的落下来。
  - 万通：拿全球的债务链和押在灾上的钱凝成圣域，圣域里的人按账本喘气。
  - 圣衡：以“一切皆可定价”完成的圣衡，历史承认的是账，不是人。至今没人见过，鲸落联席会里有人在等这个位置。
- **认得出的迹象**：合同附录一层套一层；灾前一个月他的保费先涨；灾后他的铺子总是头一个开张。
- **代价与回头**：恶途资本的圣域靠债撑着，债一抽就塌；挤兑、清算和被转嫁过的人家是他们的天敌。越往上，越像一本会走路的账。回头的法子是废约、核销、把转出去的账收回来自己担。
- **正途的人**：江南商帮里守信的老号，圣金联里做小额互保的年轻人，都走正途，也都斗不过灾险局的大账，只能一处一处地挡。

# 九重天阙两面：欢愉
- **正途**：承认欲望，尊重选择。戏台、疗愈、调停、节庆，让人在欢喜里还是自己。
- **恶途**：拿走别人拒绝的能力，把人的怕和馋收成自己的力量。民间叫“收宴的”“摆长宴的”。
- **恶仪九阶**（序列名照旧）：
  - 觉欲：看准一个人的渴望或恐惧，拿它当第一张筹码。
  - 魅惑：一次诱惑里不停手，对方说了不，他让对方以为那是自己的意思。对方清醒时挣得开，挣开以后记得。
  - 使徒：主持一场让人回不去的宴。散席以后，来的人只认得宴上的那个自己。
  - 欲宗：灾后承载上千人的欲望回流，却让他们的自我塌下去，好让回流全归自己。
  - 欢宴：立一座靠债契和忘忧撑着的极乐馆。
  - 欲界：让大量参与者在不能退出的条件下见证。门开着，人走不出去。花照夜的欲界就是这样开的门。
  - 原欲：不去终止大规模精神崩溃，而是借它：灾后夜宴把一城的怕、悔、馋收成一场狂欢。
  - 欢城：把一座城的欲望织成圣域，城里的人醒不过来，也不想醒。
  - 欢喜：把众生变成玩物的那一种欢喜。秘教在泰西的本馆，据说有人走到过欢城门口。
- **认得出的迹象**：他走过的地方，人越来越离不开他，散了宴就空；身边的人常说不出自己为什么留下。
- **代价与回头**：越往上越离不开回流，宴一停，自己先空。誓约册里的欲望债契会反噬，七原罪污染先吃自己。回头要散宴、毁契、把人放走，往往降阶。
- **正途的人**：百戏行的柳惊鸿拒绝过花照夜的“解放”；秘教里也有人正在从恶途往外走。
- 写法：能力必须允许抵抗，强制关系照禁写；写黑暗、奇诡、克制，不写露骨。

# 长夜无国界｜总纲
长夜不是大旻一国的灾。凡是记人名、修道路、立誓约的地方，都有自己的名册、道路册和誓约册，也就都有长夜可吃的东西。泰西诸邦、新洲、沙洲、极北和教廷本部，这些年各有各的灵灾，各国官署都在遮掩。
- **公开层**：外国报纸只登煤烟毒雾、铁路事故、极夜反常、神学争议。侨民、船员和领事告示带回零碎消息，神州多数人只当是洋人那边也不太平。
- **隐藏层**：使馆密电、保险行的灾险表、观测团的年报，记着各国本土灵灾的地点和日期，对得上神州的长夜十候。驻旻的万国人物，人人身后都压着一封本土来的催促信。
- **真相层**：泰西压住长夜的法子，是把自家的错乱顺着外部标准推到网的边上：条约港、殖民地、租界外的县。大旻是世上最后一头还活着的鲸，七千年没断过的名册，二十四个节点，亿万人的誓约。吞旻对他们来说，既是掠夺，也是续命（见鲸落的真意）。
- **人**：万国的人里有贪的、狠的，也有自家城里亲人正在雾里失名、急得睡不着的。组织的终点照旧是吞旻；个人的急，可能让他更狠，也可能让他在某一夜改了主意。
- **写法**：海外的事只通过电报、外国报刊、侨民、船员、外国人物的言行和货价进神州，写明来源和时差；官方说法和传言分开；海外的真相跟神州的一样，按幕后真相解锁链一层一层放。

## 海外灵灾：雾都·失名雾
- **是什么**：雾都河上的黄灰雾，大约从玄熙三十年起，入夜就漫上岸。在雾里走过的人，教区名册上那一行会变成空白，工钱单上打出空行，邻居想不起他的脸。
- **官面说法**：煤烟毒雾、工伤失踪、贫民外迁。
- **民间办法**：雾都工联起家靠的就是这个。每班开工前，把全班的名字念三遍；念过的人，雾里走不丢。夜校的老师说，名字被人大声叫过，雾就吃不下。神京外城的街坊后来也学会了互相喊名报数，没人教过他们。
- **牵连神州**：雾都的厂子日夜开工，要神州的煤和棉。失名雾一重，雾都就停工、罢工、对神州禁运机器，津海的夜校和工联驻旻书记跟着紧张。
- **两面**：雾都工联的人在雾里护着工人；也有工厂主拿失名雾当省钱的法子，雾里少了几个人，工钱单上就少了几行。
- **知情者**：工联上层和几位驻旻书记知道失名雾是长夜；泰西官方只认“空气问题”。

## 海外灵灾：极北·长极夜
- **是什么**：冰海诸港的极夜一年比一年长。玄熙四十七年这一冬比往年多出九天，捕鲸船在冰面上见到整副鲸骨，四周没有鲸。
- **官面说法**：冰期反常、海流改道。
- **冰港怎么活**：冰港人最早学会跟长夜相处。灯油按天配给，全港轮流守灯，谁家的灯先灭，就去敲谁家的门。他们卖极夜里活下来的手艺，也在悄悄往南找新港。
- **牵连神州**：港主伊万·白熊想让冰港成为不受大国吞并的自由补给地；冰港地下封着一艘比航海史还老的冰船，全知之眼盯着它。冰船跟长夜有没有关系，冰港人自己也说不清。往后几年，冰港的船队会南下停进辽东和津海。
- **两面**：冰港人不拒遇险船、不卖冬粮给囤积者；冰港的商人也借北线危机索要矿区和冬港，救援航道一年比一年像前进基地。
- **知情者**：老水手人人知道极夜在变长；冰船的事只有港主和几位老领航知道一半。

## 海外灵灾：黑海·潮闭
- **是什么**：黑海舰盟本土那片海，出海口时开时闭。船驶出海峡，过几天从反方向回到自家港口，航海钟上的日子却少了几天。水兵管这叫潮闭。
- **官面说法**：风暴季、航道淤塞、海图错误。
- **舰盟的急**：潮闭的日子一年比一年长，本土海路一断，舰盟就只剩东方的锚地能用。他们把护航变成驻军、把驻军变成条约，急就急在这里。驻东海提督手里有一份密令：黑潮失控时，抢夺神州的封印技术。
- **两面**：舰盟的水兵也救过落水的神州船工；舰盟的保险部门却按潮闭的日子给东方航线加价，加出来的钱由神州的货主付。
- **知情者**：舰盟高级军官和保险部门知道；水兵只知道回家的路越来越短，也越来越怪。

## 海外灵灾：新洲·昨日列车与空穗年
- **是什么**：新洲的横贯铁路上，有列车在出发前一天到站；两份测绘图对不上，一座镇子在这一份上有，那一份上没有。往后几年，西部麦田开始结空穗，穗子沉，籽是空的。
- **官面说法**：时刻表错误、地方欺诈、病虫害。
- **商团的急**：粮和路是新洲的命，所以商团在神州要的正是粮仓、铁路、矿权和雇佣治安。他们买神州的粮食期货，比买自家的放心。驻旻代表只收到一封比一封急的电报。
- **两面**：新洲人真心信竞争和合同，也真把神州的铁路修通了；合同的小字里写着，粮荒的年份，神州的粮先装船。
- **知情者**：商团董事会和铁路保险商知道昨日列车不是错表。

## 海外灵灾：沙洲·双星夜
- **是什么**：沙洲的星象院记下同一颗星出现在两个位置。商队在星下立的誓约开始作废，盖过印的契纸，隔夜印泥变成了沙。神州昆仑在玄熙十二年就记过同样的双星，那时没人往外说。
- **官面说法**：星象院说是天象异常，宫廷说是叛党伪造契约。
- **牵连神州**：沙洲靠商路和誓约活着，誓约一乱，水井和商队都乱。星象院在悄悄收购神州钦天旧档和西域商站的誓约译本，想借一份没乱过的记录把自家的星钉住。西域商站管异域誓约翻译，这份差事一年比一年重。
- **两面**：沙洲使节想建水利与商路联盟，替边民争水；宫廷里也有人想拿神州的旧档去换苏丹的绝对权力。
- **知情者**：星象院和苏丹近臣知道；商队只知道星下的话不作数了。

## 海外灵灾：教廷本部·神谕稀落
- **是什么**：大约从玄熙二十七年起，教廷本部的神谕一年比一年稀。圣徒榜上的名字开始褪色，一位圣徒褪尽了，供他的圣物也凉下去。
- **官面说法**：信仰考验期；本部严禁讨论。
- **本部的急**：神谕越稀，本部越要人名。灵魂登记、教籍、洗礼簿、墓葬登记，每多记一个名字，圣徒榜就多撑一页，本部是这么信的。所以它在神州最想要教育、医疗、孤儿、婚姻、墓葬和灵魂登记。
- **两面**：神州教区的慈惠院真在救人，守着“不以食物和药品强迫改宗”的修女不止一个；本部的指令却一年比一年硬，要的是名字。
- **知情者**：本部枢机知道。神州副使玛尔塔·维奥拉二十年没听见神谕，却被宣传成“圣声常伴”，她不知道本部也一样。

# 域外黑手｜资本：灾险、风险名册与做空一座城
资本道途讲契约、信用、债务与需求。到了执衡以上，契约能挪动的不只是钱：誓约册承认债务和保险，灾厄压下来的时候，也顺着债务走，谁欠得最多，谁先替这座城还账。圣金联里专做这件事的一张桌子，内部叫灾险局，主事在泰西本部，神州的人只见过签名。
- **灾险表**：按灵灾风险给街区定级。定得低的街区，保费和借贷利息一起涨，涨到修不起屋顶、买不起药，下一次灵灾就真落在那里。
- **风险名册**：名字标红的人投不了保、借不到钱、上不了船。誓约册里没了他的位置，活人先在账上死了。津海的风险名册就是这么用的。

- **养灾**：赈粮晚到三天，煤船改道，信用在节点换约前一天抽走，都不必亲手放火。
- **灾后拍卖**：封锁区里的地契、厂房、船契，灾后照账拍卖，圣金联优先。
