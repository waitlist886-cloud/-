# 迷宫纪前传世界书补卷｜第七十八份｜繁荣上的四支冒险团

> 补卷第七十八份，四条，进 46·迷宫纪｜人物。11-14 迷宫纪整理与前传补完那一轮，繁荣的年月里起的四支冒险团，垛口上的太阳、众水让路、银轨骑士团、怒涛之帆，公会传奇名录上十三个人年轻时在这几支里，丁二写的。新起的设定标★，汇在末尾的设计备注。

## 迷宫纪·冒险团｜垛口上的太阳

【调用】迷宫纪前传的回合里，说到垛口上的太阳、嘉黎丝·奥伯恩、墙头的白火、茜西莉·埃克尔、东坡之弓、哈利勒·焰垣、东坡第二段那一截温的墙头、断门往北二十里那一座老钟台的时候，人在白碑长垒的东坡、断门、星坠的岩台也用。管457年到1000年，457年以前没有这一支，只取底座年份所在的那一段，往后的事不提前说。东坡照迷宫纪·地点｜白碑东坡（繁荣的年月）那一条。

- **是什么。** 457年星坠冒险者学院同一届的三个孩子在岩台上起的一支队，两个东坡人，一个西坡人（★）。两年以后西坡那一个回了墙那一面，剩下两个没有改名，在白碑长垒的东坡守了四百来年，一个死在863年第二段的墙头，一个死在903年北边那一座老钟台，是同一面墙（★）。
- **立队（★）。** 452年秋，墙下村的学堂把嘉黎丝和茜西莉一起报进了星坠，同桌是苍焰角城来的炎角哈利勒。457年三个人满了十六岁，觉醒那一夜坐在岩台的断口上，嘉黎丝说长垒上守夜最冷，往后三个人就去当垛口上的太阳，哈利勒说太阳只有一个，说完了头一个举手。实习两年有学院背书，队名用不上，三个人揣了两年。459年毕业，两年实习的记录攒下来，三个人的印都到了营火，头一回自己揭单子，书记问队名，嘉黎丝念了出来，脸红到耳根，没有改口。
- **人。**
  - 嘉黎丝·奥伯恩｜人族，441年生在水门段城墙下的墙下村，奥伯恩家三代在东坡守备里当兵，号台的台壁上刻着她祖父的名字（★）。一头亚麻色的长发编成辫子盘在脑后，一双浅蓝的眼睛，左手掌心一块白疤，是七岁那年去摸墙头的火盆烫的。她一念咒文就走调，星坠的咏唱课考了三回没过，导师说火又不听你唱，往后她点火不出声，手一抬就有（★）。名字凝住那一年她二十六岁，离凡人的极点还远。往后她在第二段守了十几个冬天，约480年走到了顶，到了传奇（★）。
  - 台词样例：“墙上守夜冷，那我们就去当垛口上的太阳。”／“不念。一念就走调。”／“第二段哪一级台阶是松的，我闭着眼都踩得出来，你信不信？”／“单子就差一位，我按了。你回你的钟台去，听见没有？”
  - 茜西莉·埃克尔｜人族，441年生，墙下村种麦人家的女儿，跟嘉黎丝会走路起就在东坡的台上追晒粮的鸽子（★）。一头带蓝光的黑发扎成高马尾，一双浅绿的眼睛，右手三根手指套着磨旧的皮指套。弓是东坡守备换下来的一张老角弓，弓梢裂过，拿麻线缠着。她三十一岁那一年名字凝在老钟台上，往后十来年一冬一冬上墙，约485年到了传奇（★）。
  - 台词样例：“我数过一回墙上的脸，一百四十一张。往后墙上站着的人，我一个也不想少数。”／“西坡上站的是谁我看不清，我只看得清往墙上爬的。”／“你又先按了？”／“箭还我做什么。”
  - 哈利勒·焰垣｜魔族炎角，441年生在苍焰角城，父亲是西坡边军的旗官，十一岁被父亲送进了星坠，说学会了东边的话，往后守墙少吃亏（★）。额上两支短角，角尖一点火，黑发的发梢叫火燎成了焦红，一双琥珀色的眼睛。459年毕业回了西坡进边军，守了四百来年墙，约880年军团调他回苍焰角城带新兵（★）。
  - 台词样例：“太阳从东边出来，往西边落，我们这一队东坡西坡各占一头。”／“换防的时候，第二段见。”／“这支箭是你的吧？扎在我跟前那个垛口上，我替你拔回来了，燎黑了一截，别嫌。”
- **散了的那一回（★）。** 459年毕业，哈利勒说他父亲在西坡守了一辈子墙，他得回去。分手那天三个人站在东坡第二段墙头那一截石栏边上，318年西坡往东坡递火把的焦痕还在，他说这一队东坡西坡各占一头，就算没散。往后过营册上垛口上的太阳那一行写两个名字，换防的时候三个人隔着那一截石栏说几句话，说的多半是星坠饭厅里的豆子，两边的兵都装作没看见。
- **往后（★）。**
  - 约462年两个人揭了第二十八层那一张白边，下去数那一段守城的残响墙上的脸，数了三天，一百四十一张，只报给了贴单子的那一家。上来以后茜西莉说墙上不能没有人，两个人回了东坡，冬天墙头缺人，东坡守备年年贴单子，她们年年按印上墙。
  - 约467年霜潮爬上第二段的墙头，嘉黎丝在垛口上放出那一道白火，顺着墙头往两边烧出去十里，霜潮从垛口一路化成了水。那一夜十里墙头没落一层霜，西坡的兵也看见了东边墙头上那一道白，墙头的白火是东坡守备的兵先叫开的（★）。
  - 约472年墙外漫上来一股潮，西坡那一面叫围了九天，茜西莉在断门往北二十里那一座老钟台上隔着墙往西坡射了九天箭，西坡的垛口一个也没丢。西坡的兵说垛口外头的潮里插满了她的箭，远看像一片芦苇，东坡之弓是那九天守垛口的兵先叫开的（★）。第十天换防，哈利勒在第二段那一截石栏上放了一支她的箭，箭杆叫他角上的火燎黑了一截，她收着，往后没有再射出去。
  - 863年缄口之辇那一张斩首的单子差最后一位，嘉黎丝抢在茜西莉前头按了印。辇上的钟一响，墙上的人都发不出声，她的火本来就不出声，照旧往辇上烧，烧开了头一层车帷，帷上的嘴合在了她身上。茜西莉在北边那一座老钟台上望着第二段墙头那一点白，望着它灭了。
  - 903年清露月墙东墙西的潮同一天压上来，茜西莉站上那一座老钟台往西坡射，西坡的潮里压上来一团裹着神性的黑雹，她三十箭射散了雹心，第三十一箭以前那一团雹砸塌了钟台，她跟着钟台落进了潮里。哈利勒那时候在苍焰角城带新兵，她的名字是他从电报房的纸带上读到的。
- **名字留在哪（★）。** 东坡第二段墙头那一截石栏，冬天落了雪化得最快，两边换防的兵走到这里先把手往石头上按一下，863年以后照旧是温的。那一座老钟台塌成了一堆白石，903年以后没有再砌，东坡的弓手从石堆里扒出那一支燎黑的箭插在石堆顶上，打那里过的弓手往旁边添一支。
- **会碰上的事。**
  - 467年以后的冬夜，东坡守备的新兵头一回上第二段守夜，老兵叫他把手套摘了，往墙头上贴一贴（★）。
  - 472年以后，茜西莉在老钟台上擦弓，有人问她西坡那九天怎么撑过来的，她说数着，一张脸一张脸地数（★）。
- **玩家碰得上。** 457年到459年玩家能是星坠同一届的孩子，跟他们在岩台上起这个名字，或者陪嘉黎丝去求导师让她过咏唱那一课。472年那九天玩家能替茜西莉递箭，也能翻过墙头去西坡，人过了墙就是越了线，九天过去以后东坡守备和西坡的营官都要在断门问这一回。863年那一张单子玩家按了印，最后一位落在谁身上照玩家做的事走。903年玩家在老钟台上，能替她挡那一团黑雹，或者把她拽下台。
- **只给 AI。** 两个人照名录第二册那两行，长相停在名字凝住那一刻（★）。嘉黎丝的火不出声是她身上那一份天赋，咏唱课没过是它头一回露出来。老钟台在断门往北二十里东坡的第七层台上，比墙头高出两人，纷争纪砌墙的时候就有，不是903年墙头上那七座（★）。472年隔墙射箭跟318年隔墙递火一样，两边没有追究，也没有立成规矩，头一回隔着墙传令照旧是903年断门钟台那一回。第二十八层那一家的先祖在不在墙上，照迷宫纪·公告板｜繁荣的年月那一条，不裁定。

### 裁定锁
- 457年以前没有垛口上的太阳这一支，459年以后册子上是两个人。
- 嘉黎丝的名字约467年凝在东坡第二段的墙头，863年殁在同一段，茜西莉的名字约472年凝在东坡那一座老钟台，903年清露月殁在同一座钟台，长相停在二十六岁、三十一岁，这几样照名录不改。
- 863年那一回八位传奇三位英雄去，回来三位传奇两位英雄，这个数不改。
- 哈利勒是西坡的兵，不上名录，不替他添伟业，也不替两边传令。
- 锁管的是主持的 AI。玩家在场插手了，往后照玩家做的事走，救下了谁照活着写。

## 迷宫纪·冒险团｜众水让路

【调用】迷宫纪前传的回合里，说到众水让路、韦恩妲·沃尔辛、南岸水门、塔芮雅·涧鳞、莫格兰、肋骨路标、乌嘎·坳石、砸星的锤的时候，人在阿卡迪亚的井口、水门段城、天脊的涧谷、坑沿、天脊北麓也用。管449年到1000年，449年以前没有这一支，只取底座年份所在的那一段，往后的事不提前说。929年那一回照迷宫纪·战役｜相持里的斩首那一条。

- **是什么。** 449年开春阿卡迪亚井口凑起来的一支队，三个十几岁的孩子起的名，一个四十九岁的白骸按的队长印（★）。不到两年三个孩子各回了各的家，那一张四个人按印的单子，白骸揣了四百七十多年（★）。约929年四个人的印在天脊北麓那一张斩首的单子上又挨在了一起，一个也没有回来（★）。
- **立队（★）。** 449年开春，水门段城闸工家的韦恩妲·沃尔辛满了十六岁，在井口挂了号，拉上了天脊下山来的龙裔塔芮雅和坑沿村子里的半兽人乌嘎，三枚见习的印凑不成一支队。委托厅的板子跟前站着一个白骸，叫莫格兰，416年挂的号，印是月桂，他看了三个人一会儿，替她们把印按在了最上头。韦恩妲说队名叫众水让路，她七岁就拿木剑划开过闸口的水，往后天下的水都得给她让路，乌嘎笑得把水囊打翻了，莫格兰低头削完手里那一截骨头，才抬起眼来。他没有姓，家里没钱抱他去墓城的钟楼底下念名字，这一张是他头一回在一个名字底下按印。
- **人。**
  - 韦恩妲·沃尔辛｜人族，433年生在水门段城，沃尔辛家几代守南岸那一道闸（★）。一头浅铜色的长发剪到肩上，一双海绿的眼睛，右眉梢一粒小痣。一柄窄刃长剑，剑脊上刻着她父亲凿的水位线。451年冬父亲病倒，她回去接了那一道闸。约458年白碑河春汛冲开了南岸那一道闸，她站在闸口拿剑往水里一划，水在剑尖前头立成一道墙，立了一个白天，水门段城底下三个村子的人搬空了，南岸水门是那三个村子的人先叫开的（★）。那年她二十五岁，往后脸上再没添一道纹，守了二十年闸，也往上走了二十年，约478年踏进了传奇（★）。
  - 台词样例：“这名字是我起的，要脸红也是我脸红，你们笑什么？”／“水划得开。”／“我父亲站不起来了，闸不能空着，我回去。”／“莫格兰，那一张你还揣着呢？这么些年，你一回也没扔？”
  - 塔芮雅·涧鳞｜龙裔，431年生在天脊南麓的涧谷，449年十八岁，龙裔老得慢，看着跟韦恩妲一般大（★）。一身铜绿的细鳞从颈侧铺到手背，背后一对收得很拢的翼，一头墨绿的短发，一双金色的竖瞳，一把背厚刃宽的砍刀。451年秋谷里来人接她，涧谷的孩子满了二十要回谷里认鳞（★）。约463年一场以太风把山洪赶向下游的龙裔村子，她张翼落在洪头上一刀劈下去，洪水分成两股绕过了村子，谷里多出一道干了的河床，劈河是那个村子的人先叫开的（★）。那年她三十二岁，看着二十出头，往后守着谷口，又往上走了三十来年，约497年才到传奇（★）。
  - 台词样例：“谷里的规矩，满了二十得回去认鳞，不回去，谷里的鳞就不认我了。”／“我在上面，你们走。”／“认完鳞就回来，名字别改啊。”
  - 莫格兰｜魔族白骸，约400年生在阿卡迪亚外环的契约民街，449年四十九岁，看着二十出头（★）。高，瘦，皮肤白得像瓷，两只手从腕子往下是白骨，一头象牙白的直发，一双淡青的眼睛。他生来肋骨比别的白骸多，拆下一根，过些日子又长出一根（★）。插桩那一年他八十八岁，看着二十七八，又往深里走了十五年，约503年成了传奇（★）。
  - 台词样例：“印我替你们按了。名字你们自己起，起多响都行。”／“第九层那一道门我撬过。骨头的事，你们别往外说。”／“骨头有的是。”／“我没有姓。头一回按在一个名字底下，是这三个孩子的单子。”
  - 乌嘎·坳石｜半兽人，433年生在星坑盆地坑沿的村子。449年十六岁，个子比莫格兰还高半头，下唇两颗獠牙，一头黑亮的粗辫子，一双黄绿的眼睛，使一柄长柄石锤。451年夏她母亲生了一对双胞胎，她回了坑沿村，往后带大了弟妹和自己的孩子，锤一直挂在门后头，盆地里起兽、坑沿塌口子，都是她头一个出门（★）。约529年天上落下一块烧着的陨星往坑沿的村子砸，她抡锤迎上去，一锤把它砸成四瓣，四瓣落在没人的坡上，坑沿往后多了四个小坑，砸星的锤是村里的孩子先叫开的（★）。那一锤是她九十六岁那年在英雄最后那一截砸的，当夜就到了传奇。半兽人壮年长，英雄又老得慢，她看着五十上下，往后一直是那一夜的样子（★）。
  - 台词样例：“众水让路？那石头呢，石头也让？”／“我母亲一回生了两个，家里缺人手。锤我带走，名字给你们留着。”／“莫格兰，那张纸你揣了这么多年，都揣软了吧？”／“我先按。”

  - 柯拉丽·博尔曼｜人族，约561年生在黑石湾湾里打鱼的船家，577年十六岁（★）。一头蜂蜜色的长发拿麻绳扎着，一双蓝绿的眼睛，左眉骨一道鱼钩划的疤，一杆长枪的枪头是她父亲船上的鱼叉改的。名字凝住那年她二十八岁，左眉骨那一道疤也停在了那一年，守码头那些年一年一年往上走，约612年到了传奇（★）。
  - 台词样例：“帆是你们的，锚是我们的。船都走了，码头上总得有人。”／“那根桩？我小时候就坐在上头钓鱼。”／“一夜。天亮了你们再来收拾。”
  - 雷纳托·温泽｜人族，约561年生在银帆港，577年十六岁（★）。一头雾蓝的短发，一双深蓝的眼睛，右手背上一道缆绳勒出来的旧疤，使一柄单手剑。约603年那一道浪脊是他英雄最后那一截，船队靠岸那天他四十二岁，名字凝住，当天就到了传奇（★）。

- **没散的那一支（★）。** 466年以后两个人年年夏天跟船走北海，船换过三条，单子上打头的一直是这两个名字。约490年起她们冬天在冻土岭的过营屋过冬，下过那一口冰井，下到第十二层那一片冻到底的海，芮瑟按着头顶那一整块冰说这一片海冻了很久，她推不动，涅沙在冰底下弹了一夜琴，冰里冻着的长船一条也没有动。
- **带出来的那一支（★）。** 约577年，柯拉丽和雷纳托都是十六岁，在镰月商港的码头上找船，芮瑟和涅沙一个替一个按了担保印。柯拉丽说帆是你们的，锚是我们的，给新队起名叫怒涛之锚。不到两年柯拉丽回了黑石湾守码头，雷纳托上了芮瑟和涅沙的船，名字没改。

  - 约589年一群海魔趁着夜潮爬上黑石湾的码头，柯拉丽一个人守在码头尽头，一杆枪守了一夜，天亮的时候码头上的海魔叠成了一道墙，港里的船一条没烧，码头枪是黑石湾的船家先叫开的（★）。966年潮退以前最后一回往黑石湾里压，压上来的是一截陨落的神的残响，她站在码头尽头那一根桩上，一枪钉住它往港里伸的那一只手，手退回海里，把她也带了下去。湾里的船家举着灯站在码头上，看见海面平了，桩上空了（★）。
  - 约603年一道潮脊压向护航的船队，雷纳托踩上浪脊跑了十里，一剑一剑把浪脊削平，船队从削平的海上开了过去，浪脊之剑是护航船队的水手先叫开的（★）。约932年黯潮军港外，一道带着神性的浪脊绕着军港转，转一圈高一丈，他踩上浪脊一剑一剑往下削，湾里的人看着浪脊上那一点剑光一圈比一圈慢，削到第九圈，浪脊塌下来，他跟着沉进了湾里。柯拉丽那一夜在码头尽头那一根桩上坐到天亮（★）。
- **名字留在哪（★）。** 黑石湾码头尽头那一根桩，往后船家出海以前拿手拍一下。银帆港外那一片礁底下，499年拉的鲸筋断了几根，剩下的往后潮大的夜里还响，港里的渔家说那是深礁家的琴。
