# 迷宫纪前传世界书补卷｜比武与赛事

## 迷宫纪·风土｜双人守环擂

【调用】迷宫纪820到849年、971到1000年，玩家在擂环城参加双人守环擂，或说到两人守一环、换手抢环时用。绮露茵那一场只在828到839年起一次。★

- **两个人的配合。** 擂环城约800年从打谷场长起来，约810年场上铺石，约820年通了列车支线。双人守环擂从820年起在公开台开，休整中的冒险队常来凑一场，一边两人，抢的是场心一只立在矮座上的铁环。有人用盾托起同伴，有人让冰从剑背长出去，把对手脚前的路封住。观众买票来看这一瞬怎样翻过去。★
- **什么时候打。** 每旬五日和十日的下午，公开台轮着打六场。850到970年场子改作操练，双人擂停办，971年蝉鸣月中旬五日恢复，往后照旧日子开场。城心两块颜色不同的石板仍是开场前裁判踩过的旧石板，赛用铁环摆在两块之间。★

### 六场都用的规矩

1. 一队两人，按试招时看得见的本事分组，先抽出对手。每场限一刻钟，开场各站在距铁环十步的线后，武器换钝刃，法术先向裁判演示，自己说得出怎么收住才准用。★
2. 把铁环拿在手里并在场内守住连续十息，便赢这一场。裁判举指计数，失手、转交搭档或双脚出线便重新从一数。环掉地上仍可争，不能藏进袋里，也不能用召来的东西代拿。★
3. 认输、失去行动能力或双脚出外圈的人离场，搭档可一人接着打。双方各退一人，就由剩下的两人争环。一队全退场，另一队当场胜。★
4. 时限到，比较双方各自连续持环的最长一回，长的胜，相同为平局。举手、裁判压旗或有人受伤，先停手救人。裁判查清是意外便择日重赛，故意追打者判负。★
5. 抽签后退出，不罚钱，替补队接位。开打以后换人算本队认输。场外的人可以喊主意，加护、放术、推人都不算场上的本事，受助的一方取消这一场成绩。★

- **谁请酒。** 入场比武免费，看台一人十便士。每场胜队得六枚索恩，平局双方各得两枚，钱从看台收入出。赢家要请输家喝酒，常拿酒杯当铁环，在桌上再比划一回刚才那一下。赛用铁环留在台上，冠军拿走的是绣着环纹的肩带。★
- **等着玩家。** 828到839年的一场，猫耳魔剑士绮露茵独自坐在挑战者门边，她的搭档赶车晚了。她会让剑尖走过的石缝结起薄冰，能封住四步宽的一处缺口，守环却总差最后两息。玩家可以临时与她搭档，试着守住那两息，也可替她打听列车，换到后面一场。赛后她要弄清自己究竟该去抢环，还是该把环交给别人，这要由真正打过的那场来答。★

### 裁定锁

- 擂环城的场上不分生死，不写成奴隶角斗、地下死斗或故意杀人的表演。停手、认输与救治是具体有人执行的赛规，不凭空给全场不死之身。
- 新手台、公开台、名号台照擂环城本来的分法。双人守环擂写的是公开台，不把英雄、传奇塞进普通组供玩家轻易击败。
- 971年蝉鸣月中旬五日以前只见整修与练习，不提前办恢复后的正式赛。★
- 绮露茵初遇时二十六岁，此后按年份长。铁环不是遗物，获胜不自动授印或凝名，玩家输赢都能接着来。★

## 迷宫纪·风土｜三浪赛

【调用】迷宫纪520到849年、971到1000年，玩家在曜沙湾玩三浪赛，或提到三浪赛的贝旗、踩板绕浮标时用。乌茨林那件事只在532到543年起一次。★

- **等三道浪。** 曜沙湾约500年通车后热闹起来，鳞民教外来人踩浪板，520年起有人拿三道浪比一场。长曦月到坠叶月，每旬六日午后雨停了就开，站门口的教习把三面贝旗插进黑砂，路过的人也能借板试。黑潮里白墙旅店住着伤兵，只在浅水教人，三浪赛到971年长曦月才恢复。★
- **水上的路。** 近岸插两列浮标，夹出一条二十步宽的水道。向海那头有候浪绳，离岸四十步，向岸的终线在齐腰深处。三只小浮标从左到右错开，浪板要依次从第一只左边、第二只右边、第三只左边滑过。鳞民教习能把一条十步长的水脊推平，让摔倒的人抓着板喘气，真正比赛仍用海里来的浪。★

### 三道浪怎么比

1. 每组四人，抽签排第一趟的先后。借用同样长的木板，先各练一次从板上跳进水里、再趴回板面，能自己回来才进候浪绳。报名五便士，包含借板和三趟。★
2. 一人一趟，前一个离开水道，教习才给下一个举旗。从举旗起等来的第一道可乘的浪出发，站上板算起步，顺着三只浮标绕向终线。三轮换次序，上一轮最后一个下一轮先来。★
3. 站着过终线得两分，三个浮标全绕对再加一分。中途落水，本趟零分，抱板游出侧面，岸上划掉一面贝旗，再等下一轮。★
4. 每人三趟，分高的赢。并列者各加一趟，只比这趟的分，再相同便并列领奖。日落钟响、教习收旗或浪越过外侧红浮标，全组停赛，已完成轮数相同才比较，否则退报名钱。★
5. 自己长着鳍、鳞或尾巴照常下水，比的是站板。推浪的术、牵板的风和附魔板留给散场后的试演，比赛只靠身体与木板，撞翻别人的板便退出本组。★

- **赢什么。** 第一名得三十便士和一整碗果汁刨冰，并列冠军平分三十便士，每人照得一碗。教习先把奖金放在贝旗旁，差额由租板所得补，不临时向落水最多的人收钱。★
- **等着玩家。** 532到543年，鳞民游侠乌茨林来比三浪赛。他平日用窄板在近礁追鱼，转弯快，换上赛用的宽板却总把板头压进浪里。第二轮结束，他的两趟都是零分，第三趟若能站着冲过线，他就肯把那张近礁鱼群图借给同组的人看。玩家可以陪他练最后一次起身，或请教习示范宽板的站法，也可照常争冠。鱼群图标着三处水下石拱，从拱下游过去能看见白天躲在礁背的荧蓝鱼群，是一趟赛后能去的小游历。★

### 裁定锁

- 黑砂来自火山玻璃，不是黑潮污染。三浪赛是休假时的乐事，日落钟仍在日落时响，不为比赛改钟点。
- 520年以前已有踩浪板的人，没有本条写定的三浪赛。971年恢复也等长曦月开始，风浪不合适就停。
- 鳞民的救援术只整理水道旁一小段浪，不平整海湾，不借神迹保证参赛者获胜。
- 乌茨林初遇时二十四岁，此后按年份长。鱼群图是近礁游历的路线，不能换成通往深潮秘地的钥匙。★

## 迷宫纪·风土｜风铃巡空赛

【调用】迷宫纪760到849年、971到1000年，长曦月上旬风铃祭有人参加风铃巡空赛、双人空艇竞速，或询问巡空赛的三道风门时用。赛蓓琅那件事只在772到783年起一次。★

- **铃响以后升帆。** 高岚城的空艇竞速约760年添进风铃祭。本条这场绕城巡空，照高原旧习，长曦月上旬风季头一阵风到、家家挂铃的那一天午后起飞。崖壁泊架上排六艘小空艇，一艇两人，舵手看前路，另一人掌帆与晶匣。艇底黄铜叶片伸开，风晶匣吐出的青光托起船腹，六道影子一道接一道从城墙上掠过去。★
- **城外一圈。** 从泊架飞出，绕过三处插长旗的石台，再回到泊架外的终线。每处石台外侧吊着两只相距十步的风铃，双铃之间就是风门，三门依次挂白、赤、青三色旗。赛路只绕高岚城外崖，半个钟头飞得完，山路信使照旧另跑山路。★

### 驾艇的五条

1. 每组至多六艇，赛会借出同样大小的小艇，每艇配三只装满的风晶匣。舵手与掌帆者各一，赛前练飞半个钟头。自家的快艇可在散场后飞，不混进这一组。★
2. 同一声号起飞，白、赤、青三门依次穿过，船头和船尾都过了门才算。漏门须绕回来补，撞断铃绳停到石台检修，没补齐三门就不算完赛。★
3. 每只晶匣可额外催风三次，每次让帆鼓满十息，三匣用尽还能靠天然风慢飞。换匣的人要离开帆索一会儿，舵手须先把艇稳住，怎么分配九次催风由两人商量。★
4. 可乘同一阵风、挑门内上侧或下侧的路，艇身之间留两条船宽。朝别人的帆放术、拖挂另一艘艇、让飞兽牵引，均退出本场。有人落水、落崖或艇上升起求救红布，全组先落最近石台，救援后重新排赛。★
5. 三门齐过，先把整艘艇驶过终线者胜，肉眼分不清先后便并列。风门铃绳横着绷直不落，裁判收旗，全组降落，祭上照常挂铃吃饭，竞速留到下一个适飞的长曦月日子作补赛。★

- **奖和赌。** 参赛每艇交一枚索恩，归还完好的借艇便退。第一名得十二枚索恩、当年换下的青门旧铃，并列者分赏钱，各得一只同样的旧铃。钱由泊架上的艇主凑，收不齐先缩赏钱再开赛。看客可对押谁先过终线，赌钱在地上交，船上两人忙着看风。★
- **等着玩家。** 772到783年的赛前，狐耳风术士赛蓓琅找人替她掌帆。她试出一条路，青门上方有向内卷的风，顺着进去能少转半圈，可第三只晶匣得在青门前换好。她会在掌心托起一团小旋风，让玩家看清帆要往哪边偏，却不肯再替对方拽一次索。玩家能与她练熟后参赛，也能提出较慢而稳的走法。赢了以后她愿带搭档去高原上看一处天然风柱，草籽能在柱中悬半天，落下来时绕着人下雨。★

### 裁定锁

- 约700年才有载人空艇，约730年高岚才有泊架，本赛从760年起。风铃巡空赛是既有节赛的一种走法，不另设一个节日。★
- 850到970年这场绕城赛停办，借艇用于运药与接人，971年风铃祭恢复。黑潮年月其他地方的个人竞速与飞行不由本条裁定。★
- 风门是实体旗与铃，过门不传送，不改天象。参赛时风术用在本人的艇与索上，不能抢改同场别人的风。
- 赛蓓琅初遇时二十五岁，此后按年份长。天然风柱只在当季形成，不认作神迹，也不拿它指引航道。★

## 迷宫纪·风土｜归炬赛

【调用】迷宫纪460到849年、971到1000年，玩家参加阿卡迪亚开印日的归炬赛，或说到第三层带火上来、归炬赛的三盏灯时用。黛卓蕾那件事只在480到491年起一次。★

- **在井里开赛。** 460年起，公会在萌芽月上旬一日开印后办归炬赛，召集近年入行的队伍，从第三层营地带一盏火回井口。平日替人拿货、探路的人，这一天可以让整条街记住自己的队名。850到970年停办，971年的开印日恢复。井边仍先取新火、开印、请新人喝头一杯，轮到这场赛，参赛的人才各自下井。★
- **三盏灯。** 每队在第三层营地领一盏油灯，灯里引的是营地炉火。赛会另在第二层当天探清的一段岔路放三只大灯，罩分别涂赤、青、白色，每灯旁备同色布带。赤灯挂在一扇倒悬的石门里，青灯立在浅水中央，白灯放在吃晶匣光的黑廊尽头。三处走完，再由第一层回井口。灯的位置随那天的路改变，看守每盏灯的老手认得来路，能领人退回营地。★

### 把火带回来的五条

1. 每队四人，至少有一名月桂旅印的老手带队，其余三人持见习或营火旅印。赛会借油灯与备用火绒，参赛免费。所有队先到第三层营地，抽签定出发次序，每队隔一刻钟出发，终点按各队实际用时比较。★
2. 出发前给每队看当天入口到三盏灯的草图，看一刻钟后留在营地。三灯的先后自己挑，各取一条同色布带系在灯柄上，再带着油灯回井口，不能分成两组走。★
3. 倒悬的门下要有人托住灯、有人沿门框攀进去，浅水可以结冰、搭板或直接蹚，黑廊用真火照路。三处由各队自己的本事解决，允许互相搭手，不许拆掉别队正在用的桥和绳。★
4. 三色齐全、四人全到、油灯亮着，才算完赛。灯熄了可用火绒重燃，自己耽搁的时间照算。老手接应、伤者先送医，受助的队伍仍可走完领饭，当天不争名次。★
5. 出发满两个钟头就停赛，由各处老手领回营地。正常完赛的队里用时最短者胜，用时相同平分赏钱。哭声变近、水晶骤亮、通路重组或发现赛路上有魔物，立刻收灯撤人，这一天不重新开赛。★

- **街上等着。** 冠军全队得八枚索恩和一面由自己挑颜色的队旗，完赛的人各得一碗加肉的热汤。最后一队提灯走出井口，街边会给他们让出一条路，刚下井时吹得最响的队，有时恰是最后回来的。★
- **等着玩家。** 480到491年的一场，持月桂旅印的人族祭司黛卓蕾在第三层等一名队员。她能张开五步宽的淡金护罩，挡住拱顶落下的一阵碎石，可她带的两个新人一到黑廊就贴在一起，谁也不肯先举灯。玩家入队后能带他们往前试，教其中一人把火举到同伴肩外，也能改走明廊，从另一头接近白灯。明廊多走一刻钟，最后取灯的几步仍得照亮，举灯的人还得等身后的同伴跟上。★

### 裁定锁

- 开印日是萌芽月上旬一日，归炬赛不挪到停战纪念日。遇封井或路变就取消，节日在地上照过。
- 本赛460年才有，不把七阶、星坠名册或三币推到420年、246年以前。约650年以后浅层已有雾门，所走的是普通通层门，人与火都亲自过门，术不隔雾施放。
- 赛道只用头三层，不闯守层者的战场，不靠圣歌或复归兜底，不用比赛成绩顶替旅印升阶。
