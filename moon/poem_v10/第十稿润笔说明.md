# 天亮以前·第十稿 润笔说明

这一稿是在第九稿上润笔。情节、名号、神的尊号和唱名的位置都没动，你点名要留的三句也没动。第九稿原样留在 天亮以前_v9/，设计说明仍看那边的 新骨架与说明.md。这一回改的分四类，新起的设定照规矩标★，列在后面。

## 一、前后矛盾和逻辑不通

- **第二歌，千像的头。** 千像伏下来是一道山梁，它的头装不进渔网，背不起来。渔网又是透的，那双睁着的眼睛一路都会看人。这一回补了一节：头一落地就缩回巴掌大小，同它那些伏在山道上的族类一样（★）。他解下海豹皮裹了三层，叫眼睛朝里，再拿渔网兜住。到了锁礁，他抖落海豹皮，才把头举起来。
- **第二歌，首节的谜面。** 原稿“那双眼睛只睁开过三回”跟正文对不上：它望过城，望过天，在盾里又睁开过一回。改成“在人间只留下过三处石头，一座城，一座岛，一座还举着酒杯的宴厅”。
- **第二歌，石谷里的孩子。** 原稿“这一伸，便是数百年”报了个对不上的年数，改成“便伸到了今天”。
- **第三歌，谁封进了冰棺。** 北境的战士都封进了冰棺，原稿没交代他为什么还站着。改成无春那一口寒息，封住的是“凡向它跪过的”人。浅滩上站着的，是“一个从没跪过的少年”（★）。
- **第三歌，老王的年数。** 原稿写老王教过少年第一次握枪，又写他“在雪线外流浪了二十年”，可少年那年才十七岁，两样对不上。改成“老王不肯跪它，失了王冠，在雪线外流浪了十年”。年数对上了，他为什么没被那一口寒息封住，也有了交代：他从没向它跪过（★）。
- **第五歌，那杆矛的去向。** 正文写烬笛“带着那一杆矛逃回了黑丘，坠进火口”，可首节又把这杆矛当成留下来的遗物。补了一行：“开春那杆矛叫火口吐了出来，落在丘顶，矛尖的霜还没化。”（★，写第五歌史诗页时补的）
- **第八歌，凝名和老去。** 序歌定的规矩是名字一凝，人就踏进传奇，不再老。原稿第八歌却写她的名字“凝住了”，人照旧一年年老下去。改成名字唱过了第三个国，“却总凝不住”，到火口那一夜才凝成传奇。
- **第八歌，那条胳膊。** 序歌目录唱“长厅梁上那一条兽臂”，可正文里那条胳膊第二夜就叫它的母亲摘走了，再没回来。改成潭底那个没有名字的东西“怀里搂着那条断臂”。她把胳膊也扛了回来，又钉上了长厅的梁（★）。
- **第五歌，冠上的兽核。** 卡里写万兽期一开头，王冠上镶的就是自己斩下那头兽的曜核，原稿第五歌却说“开始镶起兽核”。改成“兽核越镶越多”，正好跟第七歌的“镶满了”、第十二歌的“都镶着”接成一条往上走的线。
- **第十三歌，珠湾人。** 原稿说“珠湾的人，八十年前便都沉了”，可潮门坡上住的就是老珠湾的后人。改成“珠湾，八十年前便沉进了海里”。

## 二、出戏，不西幻

- 第一歌：竹筐改成柳条筐，北境的雪原上没有竹。
- 第五歌：仓廪改成粮仓，“知晓天下的事”改成“知晓世间万事”。
- 第七歌：酒馆里“喝过三碗的人”改成“三杯”。
- 第十一歌：“封了蜡的牍”改成“封了蜡的信”，“持此牍者”改成“持此信者”。
- 第十二歌：“让上一顿饭的工夫”改成“让上一首采珠调的工夫”。
- 第十四歌：少主改成王子，蓑衣改成皮斗篷，“脸上没有表情”改成“脸色淡得像灰”，她是灰烬的女主人。

## 三、不合原神 skill 的写法

- 叙述句不用感叹号。第一、二、三歌叙述里各有一处，都改了，引语里的照留。
- 不用拟声词。第四歌“肩骨咯咯地响”改成“一节节地响”。
- 不用“从那以后”替读者总结因果。第五歌改成“往后逢着想不通的事，他只消把拇指含进嘴里，答案便会自己游上来”。第二歌的“自那以后”也改了。
- 叙述的人不对读者说“你”。第一歌“等你看见它们的时候”改成“等人看见”。
- 不把反转讲破。第十歌原稿“他这才明白……不是凡人”，换成一个画面：“满脊的焦石还冒着烟，她跪着的地方，一点灰也没有沾上她的衣角。”
- 叙述里不用“看一看”“坐一坐”这类动词重叠。序歌和第一、二、三、七歌各改一处，童谣和人物说的话里照留。
- 不用填充词。第一歌“一遍遍”改成“反复地”，第三歌“缓缓站起”改成“直起了身”。
- 引子和首节不复述同一句传说。第二到第七歌，再加第十、第十二、第十五歌，引子原来跟首节说的是同一件事。这些引子都换了一句新的“据说”，首节没动（★，新传说见第五节）。

## 四、润笔

- **起头的“那是”。** 十三歌的首节都以“那是一……”起头，十三歌的年代节都是“那是……的年岁”，多数歌两节接连都是“那是”。这一回错开了。第四到第七、第九、第十一、第十二、第十四歌的首节改成器物名词句起头。第八、第十、第十三、第十五歌的年代节，换掉了“那是……的年岁”。第五、七、十二歌“那是诸王的冠上”是有意的复唱，留着。第一歌两处都留，立这个格。
- **第二歌。**
  - 一段里两回“宛如……湖”。铜盾递过来那一行，改成“盾面上，还映着少年自己的那一张脸”，跟后来“映不出持盾者的面容”对上。
  - 臂膀那一行原有两个比喻，并成一个。
  - 千像伏在城门下那句“像一道沉睡的山梁”去掉了，前面已经写过它伏成一道山梁，换成“青苔覆满了脊背”。
- **第三歌。** “立下了一纸盟约”出戏，兽不签纸，换成“踏裂浅滩上的一块冰，同那少年立了约”。最后一个对手原稿是“那不是兽，而是一个凡人”，换成“踏上浅滩，摘下了旧兜帽”，下一行接“是北境往昔的老王”。
- **第四歌。** 豹皮上“一闪一闪”的电纹，两处都改成“细碎的电光在毛尖间游走”。
- **第七歌。** 首节“像是被谁硬生生崴断的”改成“被一座山硬生生崴断的”。那座山就是后面趴下来“是一列烧红的山”的那条龙，谜面在这里先埋上。
- **第十歌。** 盾墙“像一张撕开的纸”改成“像一块劈开的冰”。
- **序歌。** “凡人管这个，叫踏进了传奇”抬成“凡人把这一步，唤作踏进传奇”。

## 五、新起的设定（★）

1. 千像的头一落地，就缩回巴掌大小，同它的族类一样。
2. 无春那一口寒息，封住的是凡向它跪过的人。埃蒙从没跪过。
3. 夜啼的母亲在潭底搂着那条断臂。英嘉连胳膊一起扛了回来，钉回长厅的梁上。
4. 北境往昔的老王是因为不肯向无春跪，才失了王冠，在雪线外流浪了十年。
5. 引子里的新传说：
   - 二 镜中石瞳：持着它的人，一辈子没有回过一次头。
   - 三 鸦栖之石：青石腰上那道痕，是一根腰带勒出来的。
   - 四 雷纹豹裘：披过它的人，没有一个死在刀剑底下。
   - 五 冰矛抵眉：它只掷出过一回，掷进了一支笛子里。
   - 六 九步冷泉：泉边九步远的那一块地上，从来不长草。
   - 七 焚原断刃：握过它的人，此后望见再大的东西，也只当是当年那一条龙。这半句原来就有，去掉的是四国那一半。
   - 十 千鼓空角：角下那一副跪着的骨头，额头朝着山下。
   - 十二 珠湾沉冠：每逢一年里最大的那一回退潮，它便往水面浮近一些。
   - 十五 日冕之晨：头一个戴着它抬起头来的，是一个守火的老人。

## 六、没改的，为什么

- 名号、尊号、神唱名的位置、你点名要留的三句，全都没动。
- 第二歌伊斯卡图、第四歌赫斯陶仍点了名，照第三版的口径：这首诗是天亮以后、众神被认出来之后才唱的。卡里月银纪神祇那一条写着“黄金裔的神亲没人点破”，管的是那一纪的局。诗是后来的人唱的，两边不冲突。月银纪史诗那几页的调用里已写明，点出神名的那几句，是金冕城立国以后才添进去的。
- 后几歌那种民谣口气，像“嘴最损的那个石匠”“我跑不动，我老了”，是有意留下的明暗，没往上抬。
- “深渊借着……将一句话吹进了它的……”和“唱到第三个国，名字凝住了”是全诗的复唱，每歌换的是风和耳朵，留着。

## 五、改题（写第七歌史诗页以前）

- 第四、五、六歌原题不焚之裘、不眠之矛、不盈之泉，三首连着都是不什么之什么，读着像一个模子，第五歌又跟名号不眠一夜重了两个字。改成雷纹豹裘、冰矛抵眉、九步冷泉，各取引子里那一样东西。正文一字未动，史诗页的标题、主线钥匙和触发词一并改了。

## 六、第七、八歌对上焚原一代的旅伴稿（写第七歌史诗页时）

- 地名换回千穗国这一套，麦仓城改穗塔城，双桥城改双虹城，石磨城改鸣轮城，青麦原改千穗原，青麦河改穗河（★）。焚原一代旅伴第七稿照你在页面上的批注，按原神早期蒙德那种取法改过一回，诗的第一到第八稿也一直用着，第九稿起诗里又用回了第一批条目里的旧名，这一回对齐。穗河比青麦河少一个字，四行各补了一个字，各节照旧对齐。
- 双虹城点名那一节，“守门的应了”改成“敲钟的应了”。守南门的罗南是那一天没应它的人，绑在悬赏柱上站着死的，应了它的守门人跟他打架。
- 第八歌英嘉压风箱改成八年，九岁压到十七岁，跟旅伴稿对上。
