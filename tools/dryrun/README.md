# 本地干跑（tools/dryrun）

不上平台，先在本地照日里的拼法把一轮的提示词拼出来，自己当主持照着写一条回复，再把回复过一遍卡里的显示正则截图。用来在导进平台以前抓记录行对不上、条目醒错醒多、提示词说不清这一类毛病。只用 Node 自带的东西和本机的 Chrome，不装包。

卡默认读 `out/发布卡_四纪大框/奥尔德兰_四纪大框_原介绍页_全本.json`（本体加七包 DLC），同目录 `…_原介绍页.json`（切过 DLC 的本体）拿来标哪些条目是 DLC 才有的。

## 一局怎么跑

一局一个目录，放在 `tools/dryrun/runs/<开局名>/`。

1. 挑开局：`python -I -X utf8 tools/dryrun/cases.py` 列出各条主线的凭证头一行，后头跟主线名里的几个字就印整段最小凭证。门面建档页出的完整凭证更像真的，把它存成 `轮1_玩家.txt`。
2. 拼第 N 轮：`node tools/dryrun/assemble.mjs <局目录> N`。要有 轮1..N 的玩家、轮1..N-1 的回复。写出
   - `轮N_全文.txt`：发给模型的全文（主提示词、醒了的条目照优先级、历史、前置词加玩家的话加后置词）
   - `轮N_醒.md`：醒了哪些条目、谁叫醒的、中的哪个字，按文件夹汇总
   - `轮N_新醒.txt`：这一轮新醒的条目正文（当主持只读这一份加头一轮读过的就够）
   - `轮N_睡回去.txt`、`轮N_醒.json`，数记进 `汇总.json`
   - `why=标题里的字,字`：不拼全文，只把这几条为什么醒、为什么不醒逐词列出来
   - `card=本体卡 base=none tag=本体`：换一张卡对着跑，只写 `轮N_全文_本体.txt`、`轮N_醒_本体.md`
   - `brief=1` 不印按文件夹的表
3. 当主持写回复：照 `轮N_全文.txt` 写 `轮N_回复.txt`。第二轮起没变的行不用手抄，写 `轮N_回复.草稿.txt`，没变的行写记号，再 `node tools/dryrun/carry.mjs <局目录> N` 补成整条（记号写法在 carry.mjs 头上：`@@抄 行首的字`、`@@抄组 全名`、`@@改 整行`、`@@添 整行`）。
4. 渲染：`node tools/dryrun/render.mjs <更早的回复.txt,…,这一轮的回复.txt> <局目录>/轮N_图 [mobile=1]`。出正文、正文末尾、检定面板和技横幅各一张、每个页签一张，`检查.txt` 里是各页看得见的字、残留的 § 和竖线、没取到的图。功能轮（入局、旅印、存档）带代码块的加 `md=1`：过完正则以后照平台粗过一遍 markdown（空行分块、围栏成 `<pre><code>`、块里换行成 `<br>`），另截一张 `00_正文_代码块1.png`，`检查.txt` 多一栏代码块的折行、底色、字体。不加的话代码块显成字面的三个反引号。样式照显示正则末一条插的 link 的文件名到 `底稿/状态栏/外链样式/out/` 找本地那一份，立绘和图标照常从图床取。
5. 看条目：`node tools/dryrun/show.mjs <下标,下标|标题里的字> [max=字数] [set=1]`。

## 照着平台的哪些口径

写在 lib.mjs 头上，都是仓库里以前探针量出来的：一条消息一条消息分开扫，AND 不跨消息，黑名单只挡同一条消息；扫描深度 N 是往回看 N 条消息，玩家这一条算第 1 条；触发范围只扫那一种角色的消息，前置词、后置词不算；「应用到全部」的显示正则先改过回复，世界书扫的、下一轮发给模型的是改过以后的字；加权条目每轮重抽，触发概率照掷；多条同时醒优先级数小的在前。

没量过、照最自然的读法定的：条目正文接在主提示词后头、中间空一行；历史全带，不截；条目醒了没有总量上限。真平台要是截历史或者限条数，这里报的字数是上限。

骰子和加权条目用局名加轮号当种子，同一轮重拼结果一样。`轮N_醒.md` 里加权条目的标题印的是头一个选项，抽中的那一个看 `轮N_全文.txt`。

## 这一支不管的

不调模型，回复是人（或者会话里的模型）照全文写的。不验平台的保存、导入和字数线。截图是复刻台上的样子，真页面上的字体、滚动和点按要另看。
