# 山铜纪 台词重写试稿

你说「重写一遍看看」，这一份就是照新做的台词技能 genshin-dialogue-voice，把第四版的六块样碑背面和双王少女时的声口重写了一遍。第四版本身没动，你看过觉得方向对，我再并进去。

## 一、旧稿哪里不对

拿技能里的体检脚本量了第四版的二十八行背面，报了四条警告。

- 二十八行全是冷陈述，句号收尾，不带语气词，不问，也不对谁说。原作同一场合随便抽二十八句，冷陈述超过五成五的组不到二十分之一。
- 一个语气词也没有。
- 一句问话也没有。
- 句子差不多一样长，长短差 0.28，原作同样大小的组九成五在 0.32 以上。形状也是一个，一件事，逗号，一个后果。

脚本不报的还有一样，没有一个人在跟谁说话。背面刻的是在场的人说的话，可这些话听不出是说给谁听的。

毛病在我。冷句子加弦外之音本来只该给一两个人，血誓派那一个和巴尔缇娜，我给了所有人，二十八个人就成了一个腔。

## 二、这一稿怎么写的

几条做法都出自技能。

1. 先定他对谁说。有人对读碑的人说你们，有人跟刻碑的说话，有人叫一个名字，赫姆，里德，孩子。
2. 一个人一把尺子。收血人量的是路和鞋钱，铸钟匠量的是钟坏没坏，苇棚区的孩子惦记白面包下回还发不发，索恩薇娅在台阶底下数台阶。
3. 最重的地方往小处收。城烧了一夜，铸钟匠说的是钟没坏，你放心吧。跟着去送死的人只说我去了。
4. 冷着说又话里有话的，只留给本该这样说的几个人，血誓派的一个人，审判庭的书记，巴尔缇娜的两句。剩下的冷句子都是平铺的事，下去九个，上来一个，是我。
5. 有人先问一句，有人先嘘一声，句子有长有短。

第四版定的是一人一行、一句话、四十字以内。这一稿不少行是两三句短话，总长还在四十字以内，最长的一行三十九字。这条规矩改不改，在第六节问你。

## 四、少女巴尔缇娜和少女索恩薇娅

第四版每人六样，这一稿每人十来样。添的是技能里说的那五样，这一行的惯例，尺子和话题回收点，不做的事，自称和它的开关，怎么破功。

### 1. 巴尔缇娜

- 称呼：先问名字，问完就叫名字，几百年都记得。不给人起外号，孩子也叫名字。索恩薇娅不肯报名字的那些日子叫她里德，第三顿饭以后叫索恩薇娅。
- 魔女大人：索恩薇娅这样叫她，她每回都纠正，还记得是第几回。
- 客气：对谁都用你。谈条件的时候反倒客气起来，请字多了，一条一条说清楚。
- 句子：认真。先说她要做什么，再说对方得答应什么。帮人不白帮，要的从来不是钱，是一个名字和一个来领的人。
- 先注意到：孩子，门洞，篮子，谁家少了一个人。
- 接话：玩笑接得慢，常常走出去十几步才笑。跟索恩薇娅吵架吵得很认真，吵完把对方说对的那一条复述一遍，剩下的照旧不同意。
- 初见面：报全名和从哪里来，接着问你叫什么。问到姓，只说是雨城一个接生的老妇人给的，为什么是这一个，她没问过（页七的锁）。
- 惯例：进一个地方，先问这里有几个孩子，有没有没人领的。名字记在随身的本子上，名字底下写谁来领（★，千子名册就是这么一本一本记出来的）。
- 尺子：天黑以前，谁来领。这是玛蒂尔德留给她的那一句。一份条约她先问孩子归谁，一场仗她先问伤员谁抬。
- 回收点：名字，和谁来领。
- 口癖：我记一下。只在有人报名字的时候说。例外只有一回，索恩薇娅第三顿饭报了名字，她说的是我知道。
- 不做的事：不答应做不到的事，不起外号，不讲价，不拿魔女两个字说自己。
- 自称：平常是我。替雨城谈条件的时候主语换成雨城，雨城可以收，雨城不收钱，说回自己就换回我。
- 破功：不会讲价，人家报多少给多少，索恩薇娅看见了就把钱袋抢过去。红水那一回，她在宫门外差点叫出自己的名字。

### 2. 索恩薇娅

- 称呼：给人起外号。叫巴尔缇娜魔女大人，半是挖苦，叫了五十多年，只叫过一回名字（河滩那一段，★）。对贵族一口一个您，叫得很甜。苇棚区的人和孩子，她叫名字。
- 客气：对贵族最客气的时候，是她在算账的时候。真生气了，玩笑就停了，句句是您。
- 句子：快，答应得快，玩笑多，一句正经话夹在两句玩笑中间说。被问急了，拿一句笑话挡回去，接着说换个问题。
- 先注意到：谁在撒谎，谁饿着，粮在哪里。
- 接话：俏皮话一定接，还要多接一句。跟巴尔缇娜吵起来不让。
- 初见面：只报里德，苇棚区的。问名字，她说等你请她吃过三顿饭再说，真到第三顿才报。
- 惯例：接活先问两样，给多少，管不管饭。进一户人家先看锅里，进一座城先看粮仓。
- 尺子：面包。什么都折成面包算，这份赏银够苇棚区吃几天，这场雨让几户少吃一顿。
- 回收点：吃饭。
- 不做的事：怕打仗的话一句不说，不说自己饿，不叫巴尔缇娜的名字。问她怕不怕，她拿开饭的钟挡回去，那一句是笑话，也是真话。
- 自称：平常是我。跟贵族讨价的时候换成我们苇棚区的人，讨完了换回我。
- 破功：被人当真道谢就接不住，说好了好了，吃饭。

### 3. 样句

同一个场合两个人各一句，放在一起，是为了听出两个人不一样。

**初次见面**

- 巴尔缇娜：巴尔缇娜·格雷恩，从雨城来。你叫什么名字？我记一下，下回就不用问了。
- 索恩薇娅：里德，苇棚区的。名字？等你请我吃过三顿饭再说。

**对一个孩子**

- 巴尔缇娜：你叫什么名字呀？不想说也行，我在这儿等着。

**魔女大人**

- 索恩薇娅：魔女大人，早。
- 巴尔缇娜：第三十回了。是巴尔缇娜。
- 索恩薇娅：三十回了还记着数，魔女大人记性真好啊。

**接活**

- 索恩薇娅：先说两样。给多少，管不管饭。
- 巴尔缇娜：雨城可以收他们，不收钱。有两样要请你答应。孩子的名字，你自己报给我。等仗打完了，请你来领。

**下雨**

- 巴尔缇娜：索恩薇娅，下雨了。门洞那边的篮子得盖油布，我去看一眼。你先回去吧，别等我吃饭。
- 索恩薇娅：下雨了，码头停工。今晚苇棚区一半人吃不上饭，另一半在说自己吃过了。伞借我。

**跟贵族讨价**

- 索恩薇娅：我们苇棚区的人不懂规矩，您多担待。
- 索恩薇娅：您说得对，您说得太对了。所以您仓里那三百袋麦子，借两百袋给南段，不算多吧？

**真生气了**

- 索恩薇娅：您再说一遍。您说苇棚区的人天生就懒，是吗？

**看穿**

- 索恩薇娅：你说没见过那车粮。你说这话的时候，看了三回仓门。
- 巴尔缇娜：你说城里没有孩子了。那门口晾着的小衣服是谁的呢？

**被问到怕不怕**

- 索恩薇娅：怕？怕开饭的钟不响。别笑啊，这是真的。好了，换个问题。
- 巴尔缇娜：怕。每回进一座没去过的城，我都怕门洞里有篮子，天黑了还没人领。

**被道谢**

- 索恩薇娅：好了好了，吃饭。谢什么呀，下回多给我盛一勺就行。
- 巴尔缇娜：他叫什么名字？你再说一遍，我记一下。谢就不用了。

**吵完架**

- 巴尔缇娜：嗯，你说得对的那一条，我记下了。另外两条，我还是不同意。

**水闸那一天（607年）**

- 索恩薇娅：号角我劈了。谁还想吹第二遍，拿嘴吹吧。
- 巴尔缇娜：这块碑我砸了。立新的可以，烙了印的人，名字刻在最上面。

**说起对方**

- 巴尔缇娜：她吃面包，总是先掰一半揣起来。我问揣给谁，她说留着明天吃。第二天那一半，总在别人手里呢。
- 索恩薇娅：魔女大人记得住一千个孩子的名字，记不住面包多少钱一个。人家要五个铜币，她给五个银币，还说谢谢。

两个人各说对方一件小事，都不下评语。

**打起来**

- 巴尔缇娜：孩子先走。
- 索恩薇娅：这边我顶着。跑。

### 4. 三段对话

三段连起来看，是索恩薇娅的名字从不给到给，再到她头一回叫巴尔缇娜的名字。

**第三顿饭**（607年以后，★）

头一回见面她说吃过三顿饭再报名字，这是第三顿。

- 索恩薇娅：第三顿了。索恩薇娅。
- 巴尔缇娜：我知道。
- 索恩薇娅：谁告诉你的？
- 巴尔缇娜：第二顿饭的时候，店主就这么叫你。我等你自己说。

**红水**（615年，宫门外的石阶底下）

巴尔缇娜扮成精灵法师艾尔维娜·灰叶进殿受赏，索恩薇娅在石阶底下等了一下午。

- 索恩薇娅：灰叶大人，殿上好玩吗？
- 巴尔缇娜：是巴，咳，灰叶就灰叶吧。不好玩。
- 索恩薇娅：给了什么？
- 巴尔缇娜：一枚银叶。我问能不能换成药，他们说宫里给的东西不能换。
- 索恩薇娅：那就是能换。出了宫门往东第三家，收银叶，不问来路。
- 巴尔缇娜：你怎么知道？
- 索恩薇娅：苇棚区的人，谁家没当过东西？
- 巴尔缇娜：银叶有你一半。我欠着。
- 索恩薇娅：欠着可以，利息照算。对了，赏银少了两成，你看见了吗？
- 巴尔缇娜：没有。少了？
- 索恩薇娅：三千发下来两千四。我记着呢。
- 巴尔缇娜：记着做什么？
- 索恩薇娅：等我哪天也立块碑。

巴尔缇娜走出去十几步，才笑出来。

这一段跟己碑背面那两行对得上，精灵法师说欠着一半，佣兵里德说少的两成记下了。立块碑那一句在当时是玩笑，五十多年后成了真。

**河滩**（661年，★，第四版第三节那条河岸）

巴尔缇娜动身去签第十一稿那天早上，苇棚区的河滩。

- 巴尔缇娜：签完就回来。
- 索恩薇娅：巴尔缇娜。
- 巴尔缇娜：你叫我名字了。
- 索恩薇娅：叫错了。魔女大人，签完了，请我吃饭啊。
- 巴尔缇娜：好。回来就请。

这是她五十多年里头一回叫名字，马上改了口，又要一顿饭。头一回见面她拿三顿饭换名字，这一回拿一顿饭送人走。这顿饭后来没有吃成，两人这一纪再不同席（#49）。长大以后那一句「我记得那条河岸。你当年说会回来，而我来迟了。」（#874），说的就是这天早上。

两个人的语气词都比原作的中位少。巴尔缇娜认真，索恩薇娅的活泼放在问句和快上，西幻卡里我不想让她们句句带啊呀。

两份都过了卡面扫描（禁词、标点、冒号、引号、月相）和原神撞句（武器和圣遗物文本，台词语料十个字以上一字不差的），都是 0。新起的两个名字赫姆、莉娜查过不撞。

体检脚本这回修了一处。原来数语气词时，什么、怎么的么也算了进去，约占二十分之一。修完以后照同一批说话人把原作那张表重算了一遍，语气词最冷的那一档从 0.07 落到 0.05，问号的中位从 17% 落到 16%，别的几乎不动，技能里的数跟着改了。

## 六、要你定的

1. 背面的规矩改不改。第四版是一人一行、一句话、四十字以内。这一稿想改成一两句话，四十字以内，可以对着人说（读碑的人、刻碑的、一个名字），可以问一句，冷句子一块碑一两行。
2. 新添的三个人留不留，甲碑的高座的守火人，乙碑铸钟匠的搭档赫姆，戊碑莉娜的母亲。
3. 碑上两处小事。丙碑那一行要不要补一句，背面有一行刻得特别浅，凑近了用手摸才读得出来。戊碑的守门人要不要就是瑟尔卡。
4. 双王这几样新添的要不要，都是★。巴尔缇娜不会讲价，口癖是我记一下，千子名册是随身的本子一本一本记出来的，红水那一回差点在宫门外叫出自己的名字。索恩薇娅拿三顿饭换名字，五十多年只叫过一回巴尔缇娜，放在661年河滩那天早上。
5. 并进第四版，还是另出第五版。并进去的话，第四版跟着改这几处，第一节背面那一条规矩，六块样碑的背面和丙碑的碑那一行，六块各管一样里乙那一条的卖饼的，己那一条改成苇棚区那一个在台阶底下数了一下午，第三节两份少女声口换成这一稿的（接生婆一并换成接生的老妇人）。

第四版第八节那十四件还等你定，这一份没碰它们。
