# 研读笔记：原神里跟山铜纪同一类的故事

11-18。用户看了山铜纪剧情大纲第三版以后说，可以看看原神语料里别的类似的故事或者剧情，参考一下。读的是这几样：旧贵族，背叛自己那家的人，盗贼和义贼，地下的反抗，被上头攥在手里的本事。

只记做法，不搬句子，原文一句不引。原神的文本版权归米哈游，语料不进仓库。借来的东西落在山铜纪哪里，写在根目录 山铜纪剧情大纲_第四版.md 第二节，下面说第几条都是指那一节里的。

## 一、怎么找的

- 语料是 语料/ 下的武器文本和圣遗物文本（BWIKI，11-03 抓的）。台词语料在会话临时目录，有任务、闲聊、提示、语音、信件，书籍那部分没抓到。
- 拿几组词在器物文本里一件一件数命中，贵族与家名，宗室与旧家，盗与义贼，地下与暗巷，起义与反抗，传承、师承与偷学，禁曲与秘法。按命中几组排，挑出四十来件，细读了二十来件。
- 查的两支小脚本在会话临时目录（gsearch.py、gitem.py），没进仓库。要重写照这一句：器物文本照 ## 和 ### 切成一件一件，数每件命中几组词，按命中的组数排。

## 二、旧贵族怎么写（蒙德的几件）

1. **宗室几件**（五件武器加一套圣遗物）。
   - 做法：几件共用一个叠句的骨头。这门本事起先是什么样子，守着人的，从人群里长出来的，谁都学得到的。后来成了什么样子，门第的，摆给人看的，关起门的。腐朽不写成谁作恶，写成一样好东西的用处一代一代被悄悄换掉。有一件把从前那几回反抗一样一样点了名，说最后推倒它的那一下，只是最后一只手。
   - 落到山铜纪：白石谱的扉页（第1条）。长夜也不是一夜坏的，是三百年里一样一样换掉的。
2. **宗室猎枪。**
   - 做法：兵器本身有门第，剑是上头的，枪是平民和角斗场的。上头的孩子夜里一个人偷练下头的兵器。
   - 落到山铜纪：页上已经有这样的事。城卫枪术是墙上的枪，白辉逐阶枪术是冠台的枪，约 400 年奎林的阶前架叫冠台收走。海伦妮夜里偷学会侍女的后梯谣，也是上头的孩子学下头的东西。不另加。
3. **宗室秘法录。**
   - 做法：宫廷魔导师教贵族魔法，跟贵族一起坏了。雕像上刻着当初的誓，没有人再念。
   - 落到山铜纪：673 年克莱门斯家主举的那杆铳是协会大魔导送的（页上现成），教的人和用的人一起往上走。谱的扉页刻着、没人念，用的是后半个做法（第1条）。
4. **西风长枪。**
   - 做法：一个为了让家族重回荣光什么都肯做的人。他是先祖荣光这一个动机的暗面，同一个动机，跟正面的那个人用在相反的地方。
   - 落到山铜纪：克莱门斯家主（第2条）。
5. **钟剑。**
   - 做法：贵族家里的人加入了反抗。起义败了，他受了什么罚没人说得清，那是血统替他挡下的。他后来另起一个地下的组织，新秩序立起来以后，这个组织替新秩序做亮处不便做的事。
   - 落到山铜纪：炬身上留着一截特权（第7条）。第二版写过灰雨以后蛾子分家，一部分走到亮处，这里可以多一层，走到亮处的那几伙往后也替新朝做暗处的事（★，可要可不要）。
6. **狼的武功歌。**
   - 做法：只替贵族打剑的铁匠白送了一把剑。他儿子在一旁看会了一门剑法，多年后披一件破斗篷用出死去骑士的剑法，人群认出来，喊出那个旧名字。技艺靠看传下去，名字跟着技艺回来。
   - 落到山铜纪：第二版的侠影（暗巷，约 405 到 420 年，四十个人同时是那个剑客）已经是这样，第三版的偷艺一节也是。不另加。
7. **松籁响起之时。**
   - 做法：禁的是声音，一组和弦，一首歌。反抗靠声音认人，起事的信号是一首民歌从来没人唱过的后半段。教会里分出一伙人，在地窖里供没有头衔的圣人。
   - 落到山铜纪：668 年春宴夜后梯开了（第5条）。用的是我们自己的后梯谣，那首谣本来就开仆门，借的只是一首歌里有一句平时不唱。
8. **风鹰剑，暗巷三件。**
   - 做法：外邦的角斗奴隶，三句话的格言。贵族少年读了歌颂先祖仁政的长诗，偷出家传的剑去劫富济贫，剑从不见血，后来埋了剑出海。歌把他唱得比真的好，穷人从歌里得了勇气。
   - 落到山铜纪：三句誓（纷争纪索名之誓）是我们自己的。底卡 #985 暗巷歌谱和它的虚构侠影本来就是从暗巷来的，第二版已经用了。这一回不再加，往后写侠影别再往暗巷那几个细节上靠，剑不见血，埋剑出海，都不用。

## 三、地下的人怎么写（挪德卡莱、枫丹、稻妻的几件）

9. **长夜之誓**（挪德卡莱的一套圣遗物）。
   - 做法：一个组织的来历写成一道誓在几代人手里的样子。头一个是被处死的大盗，往后是替众人讨来自治、为此起了誓的人，再往后是一代一代守这道誓的人，有违了命令去救孩子、被判了又因为起誓得赦的，有没有头衔、只戴着老盔的后人。一件只写一个人一刻，誓不变，人一直换。
   - 落到山铜纪：只借结构。炬那把剑往后在炬手里传（第三版第四节），往后铺开时可以照这个排几个持剑的人，一人一刻。这一套的意象跟我们撞得近（第五节第2条），所以不借它的灯，不借它的誓词。
10. **万能钥匙，罗网勾针。**
    - 做法：两个阶层的人互为镜子，一个是装成贵族的农家女，一个是藏起姓氏的贵族。两个人争一个大盗的名号，输的要把贵族的金子分给缺的人。后来他把罪全担了，因为他的姓，处决要悄悄办。她用一辈子去解他留下的谜。名号是传下去的，不是谁生来的。
    - 落到山铜纪：百锁那个名号可以是传的，一代一个，往下传要比一场（可要可不要，第四版没列）。
11. **乌髓孑灯。**
    - 做法：开头一个意象，权力是一块砖一块砖垒起来的塔，要紧的那一块不肯，塔就塌。黑市的头子在大盗的骨头前头起誓，立了头一套盗贼的规矩，后来叫自己的管家毒死了。结尾说，真的公平是谁也不来定这套规矩。
    - 落到山铜纪：长夜是几万只手撑着的（第3条），蛾子没有头（第6条）。
12. **霜辰。**
    - 做法：一个人争王位，为的是往后没有人再称王。
    - 落到山铜纪：页上已有。索恩薇娅斩冠以后自己坐上去，不许铸自己的脸，第三版第五节也写了斩冠的人自己成了王。不另借。
13. **最初的大魔术。**
    - 做法：下水道城里的两个小贼长成了魔术师和她的助手。台上的光一样照包厢，也照站着看的人。城里整肃的那回，台词成了宣言。
    - 落到山铜纪：第二版的白石之夜（约 598 年，半身人幻术师在上城的庆典上叫拱门冲着一位十四家的继承人冒烟）就是这样的事。这一回只添一样，那夜她说的几句，往后成了蛾子嘴里的话（★）。
14. **灰河渡手。**
    - 做法：地下的头子。整肃用的是一个干干净净的词。一套写完，结在一张合照上。
    - 落到山铜纪：洁墙的清查、上城的验门已经是这样。不另加。
15. **柔灯挽歌。**
    - 做法：灰里生的孩子，没有老师，看见什么枪法就学会什么。公义那边把她收去当差，叫她去追当初救过她的人。
    - 落到山铜纪：七年巡礼的猎人（第4条）。页上其实早有一个，格拉德 881 年替焦门氏破的辙口那座门，是谷里逃出去的人立的城。
16. **裁断，赦罪**（一对）。
    - 做法：两件武器各讲一个人。贵族的女儿乔装下了灰河，头一天就叫一个灰河的年轻人认出来，认出她的是她身上太干净。她父亲说过，家名能给人富贵，也能把人送进灰河。她跟他约好，他要是为了荣华变了心，就由她来审他。他本想借她往上爬，后来背叛的时候说过两个理由，说了太多回，自己也分不清哪个是真的。一个从上往下走，一个从下往上走。
    - 落到山铜纪：帘后人的两个理由（第6条）。撞车见第五节第1条，底卡 #953 炭巷长女和第二页的炭巷那段，有几处骨头是这一对的。
17. **波乱月白经津。**
    - 做法：一个哑巴孤儿把一个流派的剑练过了整个流派，不肯当家主，他的学生后来另立了一派。
    - 落到山铜纪：底下自己生的火不封进谱（第8条）。
18. **炉火融炼之心，角斗士的终幕礼。**
    - 做法：前一套是年轻的矮人在行会里一步一步往上走，斗赢了公爵，旧贵族作乱的时候武装了城里的豪侠，立了新的长桌，几百年后把笔还给老师。后一套是角斗场的奴隶，虚荣是他的锁链，结在一个不肯照处置奴隶那样处置他的女孩身上。
    - 落到山铜纪：十四家之乱里号墙贴雇团的活（页上现成）跟前一套是一路，不另加。后一套不用。

## 四、台词语料里查了什么

- 只数了几样在任务对话里出现几回。劳伦斯家四十来回，在谈吐与仪态、旧日的阴云、循礼知心几段任务里。温妮莎二十来回，眼狩令一百多回，教令院七百多回，盗宝团三百多回。帕西法尔、雷德米勒在台词语料里一回也没有，器物文本里的写法是帕西法尔。
- 劳伦斯那几段没细读。往后写海伦妮在码头上怎么被人看、克莱门斯这个姓在下街是什么分量，可以翻这几段看旧贵族的后人在城里怎么被人看。

## 五、撞得近的，往后要避开

1. **底卡 #953 炭巷长女，第二页炭巷那段**（山铜纪/parts2/c_炭巷.md）。
   - 跟裁断、赦罪那对骨头一样的有三处。她父亲那句家名能给人富贵、也能把人送进河里。她头一天就叫炭巷的人认出来，认出她的是身上没有煤灰。认她的人开口问的是上面哪一家的姑娘下来了。
   - 句子都改写过，正文拿 ngram 对原神语料，六字串 0 处。洗稿层 #953 放行那行里留着两句洗以前的原句，那是给检查脚本放行用的，不进卡。
   - 往后写炭巷和石楠，这三处骨头不再往下用。换不换写在第四版第六节，倾向换父亲那句和认出她的线索。
2. **长夜之誓。** 长夜、火炬、扑火的蛾子、灯，这几样意象那套里都有。我们的长夜是山铜纪 368 到 668 年那三百年的名字（10-22 起），蛾子的名字出自纷争纪补卷_36 的蚀光蛾和血誓派骂人的话，炬的价钱落在手上（家纹烫进手心）。往后写蛾子和炬，不用灯，不写守望与牺牲那类誓词，不写一个人逆着光扑上去的单篇。
3. **无座。** 无座之火的无座，跟最初的大魔术里没有座位的站票，两个字一样，意思不同。我们的是不归哪一座高座的火，照留。
4. **里德。** 原神灰河那两件里各有一个人叫里德。我们的里德是苇，苇棚区的人多姓里德，页上京特也是里德，跟那两个不相干，照留。
5. **逐火之蛾。** 跟崩坏3那个组织一字不差，第二版第十节问过，照倾向照用。
