# 山铜纪世界书补卷｜比武与赛事

## 山铜纪·风土｜断刃旗擂

【调用】山铜纪80到947年，玩家在金鸢城下街找人比武、参加断刃旗擂，或说到三面断刃旗、抢旗回线时用。贝茨贡那件事只在128到139年起一次。★

- **下街的空场。** 佣兵行会附近有一片铺沙的空场，三根短旗杆顶上各绑半截断剑。约80年起，几个等活的团在这里比抢旗，后来雇主也来挑人。持盾的矮人、背弓的游侠和提着短杖的法师混着上，最受欢迎的是临时凑的团把老团赶下场。每旬末日午后开擂，清场的号一响，看客便往屋檐上爬。★
- **剑和术都上场。** 场中宽四十步，两端各画一道归旗线。开赛前，场边法师竖起三截齐腰石墙，每截四步宽，墙与墙之间留五步空隙。冰会沿着靴底爬，盾面能把迎面的小火弹撞散，绕墙的人则要防对手从沙下拱起一块石头。石墙是当场施术竖的，散场拆去。★

### 下场的五条

1. 两队各三人，用同一批钝刃、短杖和练习弓。行会先看双方各试一招，把本事相近的配在一起，每人赛前说定两样自己会用的术或武技，带来的护甲照旧穿。没有队伍的人可在旗杆旁找搭档。★
2. 三旗插在场心，双方站在各自的归旗线后，同时起步。每人一次拿一旗，亲手带回自家线后才得一分，该旗随即收起。旗落地，双方都能再拿。先得两分的赢。★
3. 可以架盾、推人、绊脚、挡路，练习兵器碰到躯干或四肢一下，裁判便叫双方分开。挨到第三下的人退场，所持旗落在原地。冻住脚、叫风推倒只算妨碍，不算碰中，能挣脱就继续跑。★
4. 兵器碰中头颈、使用说定之外的招式、从场外给人加护，都由裁判停场。故意伤人的判负，误伤先救人，再由双方决定重赛或散场。认输和双脚越过边线都算退场，压旗以后收手。★
5. 一刻钟到，分高的赢。平分便把未得分的旗收走，场心重放一旗，两队各挑一名尚未退场的人争最后一分。某队已无人留场，另一队胜，两队都空了则平局散场。★

- **赢什么。** 下场不收钱，赢家全队得两枚奥利芬和旗杆上一条旧旗带。三连胜再得三枚奥利芬，随后休场，让别的团上。钱由当天来挑人的雇主凑，付不齐就只办练习场，开打以前讲清楚。围观押注另算，不拿输掉一场抵卖身钱。669年以后付足色新朝奥利芬。★
- **等着玩家。** 128到139年的一场擂里，矮人盾手贝茨贡缺一个搭档。他背的塔盾展开能护住身旁两个人，旧伤却让他转身慢。对手法师每回只冻他盾后的那只脚，快腿的队员随即绕过去夺旗。他想找人守住左侧，好让自己亲手送回一旗。玩家可与他搭档、替他试一种转身的办法，也可站到对面去赢他。真正要补的是两个人之间那几步空隙，胜负由场上决定。★

### 裁定锁

- 擂赛不是军功、行会档次或凝名的凭据。山铜纪没有公会旅印，场边不报面板数值。
- 赛前说定的招式必须是参赛者已经会的，不因报名添能力。场边法师的石墙挡不住英雄或传奇全力一击，强到普通擂场接不住的人另约空地切磋，不混进这场抢旗。
- 禁止杀伤是赛规，不是护命神术。七神不亲自下场作裁判或救人，伤者送白烛医棚。
- 贝茨贡初遇时一百一十岁，此后按年份长。玩家改变了搭档、场地或赛规，双方认可后照这一局进行，不预定谁赢。★

## 山铜纪·风土｜剑杖盾

【调用】山铜纪130到947年，玩家在金鸢城下街赌厅玩剑杖盾，或提到剑杖盾的十二张牌、剑牌压杖牌时用。布桑涅的赌局只在342到353年起一次。★

- **十二张牌。** 下街的地下赌厅约130年起流行这套小牌，佣兵收工来玩，法师学徒来玩，偶尔也有藏起纹章戒指的贵族。厚纸牌各画剑、杖、盾四张，每样标一到四点。好牌用银粉描边，翻开的剑会掠过牌面，盾举起，杖顶亮出指头大的一点火，过三息又伏回纸上。这是赌厅法师添的幻景，寻常墨牌也能玩。★
- **桌边。** 一桌两名玩家，一名发牌人。旁人看得见已翻开的牌，看不见手牌。楼梯口挂着当夜的赌额，最小的一桌押五便士，桌上摊着用来换零的铜币。新手常输在舍不得先出那张四点牌，留到最后，才发现它恰好受制于对方剩下的花色。★

### 坐下就能玩

1. 双方各押五枚便士，合成十枚放在桌心，这局中途不加注。先把十二张摊开点齐，发牌人洗牌，双方各切一次，再轮流各发三张，余下六张盖住不用。★
2. 一局打三手。每手各选一张扣在桌上，两张都落桌才同时翻开，用过的牌留在各人面前，不收回手里。★
3. 花色不同，只看相克，剑胜杖，杖胜盾，盾胜剑，点数不管用。花色相同才比点数，大的胜。胜一手得一分，十二张各不相同，每手都能分出胜负。★
4. 三手打完，分高的拿桌心十枚便士。弃局便由对方拿走桌心的钱，每局赢下的钱当局交清。第一手即使输了，余下两张仍可能翻盘。★
5. 发牌人不从桌心抽钱，赌厅另向每位坐桌的人收一便士，管五局的座位与灯。玩到一半离桌，余下几局可以让给别人。开牌前发现少牌、重牌或背面有记号，整局重洗，开牌后查实则退还本局押钱并换牌。★

- **能押的东西。** 初学桌只收便士。熟客可先把一件东西交给发牌人，由双方说定值多少，再换成同额赌筹，牌理不变。护命的药、当夜住处和回程所需的钱由本人先留在钱袋里，没人替他扣下来。赌厅里也有不押钱的桌，输的人替同桌把酒端来。★
- **等着玩家。** 342到353年，布桑涅这名人族女游侠带来一张自己画的空塔草图，愿拿它赌一场不收钱的牌。她要挑明天同去探塔的同伴，先把自己的三张牌全翻给玩家看，再让玩家照常留着暗牌打满三手。赢她便能决定明天先走哪条路，输了就陪她从塔外绕一圈。图上两条入口，一条门外积着齐膝的灰，一条有新鲜兽爪印。玩家可以接这场牌，也可以请她先讲塔里的危险，能否同行由双方另谈。★

### 裁定锁

- 十二张每张仅一张，不能凭空发出同花同点的两张。三手合计三分，一局不会平分。
- 牌上的幻景不识谎、不读心、不替谁改点。默认双方按洗牌所得的手牌行动，主持不偷看玩家选牌以后才替对手换牌。
- 剑杖盾的三样图只是牌面，不规定三类命路相克。赌局不借神与魔神的权柄决定输赢。
- 布桑涅初遇时三十二岁，此后按年份长。她的草图是当年探过的长垒空塔外缘，不是地图上固定新增的一座名塔，也不预告塔底宝物。★

## 山铜纪·风土｜沉塔竞寻

【调用】山铜纪616到947年，玩家来到金鸢河上游旧船坞，碰上退水后的一场沉塔竞寻，或说到竞寻的翼片、塔窗取物时用。科普岱那件事只在624到635年起一次。★

- **红水以后。** 615年炉心封住，旧船坞底下的浮塔仍沉在那里。616年起，宫里准许受雇的团在退水露出的外廊捡取散件，几家收旧魔导器的商人便合出赏钱，让团互相比着找。水退得够低、外廊查过能走，才开一场。竞寻的人背着绳，法师托起水面上两三块碎石，游侠踩过去，把绳头扣在对岸塔窗上。★
- **这回找什么。** 开赛先让大家看三幅图，画的是外廊守卫胸前脱落的三片铜翼，每片掌心大小，缺口各不相同。三片都曾在浅水里看见，落在哪个窗洞后面却没有找准。旧廊横着沉进河床，原来的门在脚下，原来的窗成了朝天的井口。仍能活动的两具守卫沿一条四十步长的石槽拖行，胸口的青光掠过墙面，碰到活物便抬臂拍下。★

### 竞寻的五条

1. 一场至多三队，每队二到四人，从同一座坞边石台一起出发。日头过中天开场，两个钟头后回到石台结赛，每队可先看一刻钟外廊，但先看时不下水取物。★
2. 三片铜翼各记一分，带到石台才算数。一个队拿几片都行，取到就可以先送回一片再下去。旧件上吻合的缺口是认物的凭据，撕下一片完好的守卫胸甲不能顶替。★
3. 可以搭桥、浮石、潜水、引开守卫，也可和另一队合力搬开堵路的塔梁，取出前先说定那一片归谁。已拿在手里的东西归持有队，打人夺物的队退赛，丢弃的散件仍可捡。★
4. 路只到当日露出的外廊，以入口两根红绳为界，深处封炉的门保留原样。水涨过绳底、守卫出了外廊或有人吹出求救的三声哨，赛即停，所有队沿绳上岸，停止以后不再取件计分。★
5. 正常结束，分高的一队胜，同分平分赏钱。提前停赛也只算已经送到石台的翼片，全无得分便散场。两钟头到仍在水下的人，由坞边留守者接应，超过时限带回的翼片另作寻常收购。★

- **赏钱和旧物。** 胜者拿八枚奥利芬，收件商另按每片两枚奥利芬收三片铜翼，卖不卖由取件的队定。铜翼只是旧守卫的零件，铜中残存的青纹能在水下亮一刻钟，干了便暗，修魔导器的人看重的是没断的纹。别的收获按进坞前谈好的份额分，宫里与行会的份已经从八枚赏钱里扣清，不临上岸再扣。★
- **等着玩家。** 624到635年，矮人法师科普岱站在坞边等一支队伍。他会把三步宽的浅水压平十息，露出一截能走的河床，足够人穿过塔窗。可其中一片铜翼嵌在守卫拖行的石槽里，取出来，守卫便能转进另一条廊。玩家可先设障、把守卫引向空窗，或换一种取法。他想带回这片纹路去修一双能握紧工具的旧义手，愿把自己的赏钱让给帮他的人，铜翼则按收件价买下。★

### 裁定锁

- 615年的封炉照旧成立，竞寻只探外廊，不重开炉心，不解释封炉者隐藏的身份。
- 遗迹不重组，取走的旧件不会再长。此场办过就记住所得与损毁，下一场须有退水新露出的别段及别的实物，没有便不开。
- 这里有真守卫、暗流和塌梁，没有赛事护命，也没有圣歌复归。科普岱的术只压平浅水，不能截河，不能排干浮塔。
- 科普岱初遇时一百二十七岁，此后按年份长。玩家救人、合作、退赛或改了分法，按当场的决定与后果结算。★
