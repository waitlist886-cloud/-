# 两纪进卡 v8｜月银纪与纷争纪全卷（2026-10-21）

v7 那张卡里是月银纪一万零八十一年。这一回把纷争纪也套了进去：七页、二十二张的总条、补卷一百七十多条，加上月银纪这几轮新写的帝国史、风土、地点、国史和战役。从第一堆火到灰雨城那一夜，两万一千多年都在一张卡里了。底卡照进卡清单改了三十五条正文，另给三十三条旧条目加了黑名单，介绍页的纷争纪年表照七页改了年份。平台导入没有做，测试卡和 src/rili_v7.json 都没有动。

## 钥匙和开局口令

纷争纪新起的钥匙：

- 〔纷争纪·正则〕：底座、潮汐格或口令里写着纷争纪，或者写着山铜纪元年（纷争纪最后那一个月，灰雨城那一夜，底座写山铜纪元年）。
- 七把时段钥匙，照七页切年份：灰的年月（元年到120）、白石的年月（121到300）、灯的年月（301到1050）、炮的年月（1051到4500）、浮塔的年月（4501到8800）、铁狼的年月（8801到10800）、号角的年月（10801到11034）。每把都认第二十二张报的年份。
- 二十一把主线钥匙，照七页每条主线条目设置后头写好的那一句。

## 校验

- 问题 0 条：触发词 1 到 20 个，最长的一条三百来字，正则不套量词、不超 25 个量词（10-13 探针三实测，这两样平台会丢；后行断言和惰性量词实测能用，卡里也一处没用），正文没有禁用标点（感叹号只在灯里那一句），冒号只在标签行，「」都找得到条目，标题不撞底卡，同名的加了页名。
- 开局口令只发一句：
  - 月银纪四十四条，各醒 4 到 16 条、7761 到 18583 字，跟 v7 一样。
  - 纷争纪五十七条（二十一段各两种写法、抽一张、第二十二张十四个年份、赤原加黄金裔），各醒 2 到 7 条、5491 到 21914 字。
  - 两纪的口令叫醒底卡 0 条，叫醒别纪的条目 0 条。
- 口令加一幕回复（回复里把那一幕的人和地方都点一遍，算的是最重的情况）：月银纪 8060 到 26347 字；纷争纪 23174 到 53503 字，炮的年月最重，因为诺伦的星和凡世至强、陨落账、命路两条规则跟着醒。
- 纷争纪的局里：
  - 二十一段的回复加四句寻常的话，底卡只醒 #589 圣堂，是玩家说到圣堂的时候。
  - 拿纷争纪条目的 2416 个触发词各写一条回复，底卡醒 10 条，都是写东西和技艺本身的遗物条、命星条（#928、#326、#1012、#993、#1015、#983、#990、#940、#938、#473），常驻已经写了今天的条目一律当后世看，只记不挡。加了锚的八条全挡住了。

## 留着没做、要你定的

1. **导入和体积。** 卡 14.6MB，v7 那张 11MB 也还没在平台上导过。你说导哪一张，我照做；超了的话可以拆成两张（月银纪一张、纷争纪一张，各带底卡），或者把几条长的拆小。平台导入、覆盖测试卡照旧等你明说。
2. **卡上的账目栏。** promptSizeBytes、lorebookLength 照 v7 没动，还是底卡原数（4753232、1545544）；照实算是 11775766 和正文三百六十多万字。要不要照实写，跟导入一起定。
3. **纷争纪的局里打月银纪的地名。** 第二批那二十二条月银纪地点（神渡城、穹都、白冠城、北辰塔、千湖这一路）只认玩家打出来的地名，纷争纪的局里玩家一打也会醒，一个词一条，一条一千字上下。常驻写了同一处地方有纷争纪那一条的照那一条。要收的话，改成跟页上一样认月银纪的底座，这样迷宫纪的局里查旧史也查不到了，所以这一版没改。
4. **纷争纪第一轮的量。** 最重的一回五万多字。平台要是吃不消，可以把旅伴条改成要那一段主线的钥匙同时在才醒，或者把两条规则的触发收窄。
5. **底卡里别处的塞壬。** #538 统一成了赛壬，#477、#537、#739、#740、#745、#1066 和介绍页还写塞壬，介绍页里有一处是页面脚本里的键名，改了怕弄坏页面，这一版没统一。
