# 反馈模板

复制下面一份，照着填，填不上的格子空着就行。截图直接附在后头。

## 报毛病

```
【毛病】
卡：迷宫纪1001年／月银纪
设备：手机或电脑，型号和浏览器
模型：
年代和开局：回复最上头写着年份和地点的那一行，抄过来
第几轮：
出了什么事：
贴一段：那一条回复的原文，或者截图
本来该是什么样：
每回都这样吗：每回／偶尔／就这一回
```

## 提意见

```
【意见】
卡：迷宫纪1001年／月银纪
说的是哪里：哪条主线、哪位旅伴、状态栏哪一页、简介页哪一本书
喜欢的：
别扭的：
想要的：
```

## 填的时候

- 状态栏没排版、露出 § 开头的字，截一张整屏的图，再把那条回复复制下来贴上，两样都有最好查。
- 剧情、人物的事，说清是哪一句、哪一段读着不对，比“感觉怪”好改得多。
- 一次报一件，几件事分几份报。
