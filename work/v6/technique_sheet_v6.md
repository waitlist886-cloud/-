# 第六稿补记：原神用词那一档（自用，不进卡）

读的是用户贴的几段和它们所在的整套（天之美赐、纺月的夜歌，各五件），只学做法，不搬句子。

- 名词前挂带判断、带来历的定语，不只挂颜色：受诅的坑底，铁铸般的巨爪，染血的雪，锈了四十年的刀，死寂的核心。
- 动词往大里选：扣碎，染红，倾泻，席卷，逡巡，陨落，砸穿，蚀尽，倾压，轰然坠落。
- 比的东西往天上够，东西越大，拿来比的越大：连夜空的星辰也因之失色，像坠地的冷星，如决堤的春汛。一歌里这种句子一两处，不重样。
- 和合本的语域：凡……的，尽数，遗民，列城，翌年，犹自，仇雠，所过之处。一节一两个，别连用。
- 年代拿光和物的样子来定（那是……的年岁），全诗只留一两处，第六歌一处就够，别和别处撞。
- 称号留给它自己的那一歌：日轮只给托纳修，第十四歌以前的太阳写烈日。
- 收着写的地方照旧平：账本、规矩、回家、短台词。华丽句旁边要有平句，平句才显出华丽句的分量。
