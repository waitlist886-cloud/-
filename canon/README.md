- 故事：万兽期两千五百年前后，曜冠山脉的雷带。雷角鹿替山下站在峰顶挨雷，鹿王站了一千个夏天，听了天外漏进来的一句话，把一整个夏天的雷顶下了山，白了一路林子，人叫它千鼓。牧人凯恩生在它头一回下山的那一夜，头一口气吸进去的是雷，笑了，门口坐着穿灰衣的女人。五国联军进白林三千人回来不到三百。凯恩带狼耳的卡娅在雷季上山，卡娅在黑脊上举枪替他引雷，峰顶上他跟千鼓角力到半夜，快断气时那个女人现了身，第一口气与最后一口气，塞维娅，没接他这口气，反给他渡了一口。他朝千鼓弯腰，说了山下欠它的那句话，把那一整个夏天的雷含进了胸膛，天从山顶一圈圈晴开，五国的人抬头看见。名号山顶一息，含雷者，凯恩。往后他只能低声说话，咳一声山那边亮一下，那一口气到今天没吐出来，祂坐在他门口等。
- ★：千鼓、凯恩、卡娅、曜冠山下五国、雷带的鹿群替山下挨雷这层说法；塞维娅是卡里现成的神，这是祂在月银纪头一回露面。凯恩是传奇，不老死，留给后面的长诗。
